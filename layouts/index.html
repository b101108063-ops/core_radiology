Core Radiology · 使用說明

Core Radiology 是一本以影像為主的診斷放射學教材，適合放射科住院醫師、醫學生及需要判讀影像的臨床醫師。

  • 每個章節頁面涵蓋完整主題，附高解析度原始影像與標註。
  • 點擊任何影像可放大檢視，支援縮放、平移與雙圖對比。
  • 右側目錄會隨閱讀位置自動高亮，頂部顯示閱讀進度。
  • 左側欄可搜尋全書關鍵字，章節可摺疊以快速跳轉。
