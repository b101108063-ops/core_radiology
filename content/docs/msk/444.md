![Page 444](/core_radiology/images/msk/page-444.png)

## 頸椎 / Cervical Spine

## 頸椎創傷 / Cervical Spine Trauma

### 重要間距測量 / Important Interval Measurements

| 間距 | 正常值 | 異常意義 |
|------|--------|---------|
| **Basion-Dental 間距** | < **12 mm** | >12 mm 提示顱頸分離 (Craniocervical Dissocation) |
| **Atlanto-Dental 間距 (ADI)** | 成人 < **2.5 mm**；兒童 < **5 mm** | >正常值提示韌帶鬆弛及半脫位 |

#### 解剖標記
| 標記 | 說明 |
|------|------|
| **C1（Atlas）** | 支撐頭部（像希臘神撐著地球）；無椎體；通過側塊提供結構支撐 |
| **C2（Axis）** | 允許旋轉 |
| **Dens (C2)** | C2 的齒狀突起 |

### 頸椎側位片的評估線條 / Lines on Lateral Cervical Spine Radiograph

| 線條 | 路徑 | 臨床意義 |
|------|------|---------|
| **前椎體線 (Anterior Vertebral Line)** | 追蹤椎體前緣；前椎前軟組織位於此線前方 |
| **後椎體線 (Posterior Vertebral Line)** | 追蹤椎體後緣 + 脊髓腔前緣；脊髓腔為後椎體線與棘突椎板線之間的空間 |
| **棘突椎板線 (Spinolaminar Line)** | 追蹤脊髓腔後緣 |
| **棘突線 (Spinous Process Line)** | 追蹤棘突後緣尖端 |

### 脊髓腔評估 / Spinal Canal Assessment
| 測量 | 說明 |
|------|------|
| 脊髓腔 | 後椎體線與棘突椎板線之間的空間 |

### 臨床要點 / Clinical Key Points
1. **Basion-Dental 間距 > 12 mm** = 顱頸分離
2. **Atlanto-Dental 間距 (ADI) > 2.5 mm (成人)** = 韌帶鬆弛/半脫位
3. **C1 = Atlas** = 無椎體，通過側塊支撐頭部；**C2 = Axis** = 允許旋轉
4. **所有頸椎側位片都應評估** 四條線的連續性與平滑度
5. **脊髓腔** = 後椎體線與棘突椎板線之間的空間
