# Musculoskeletal Imaging - Page 364

![Page 364](/core_radiology/images/msk/page-364.png)

## 乾癬性關節炎 / Psoriatic Arthritis

### 疾病概述 / Disease Overview
- 臨床表現：銀屑病患者出現關節病變
- 最常侵犯**手部**
- **骨質礦化通常保持正常**（與 RA 骨質疏鬆不同）
- 骶髂關節炎存在時通常為**不對稱**

### 臨床類型 / Clinical Patterns

| 類型 | 特點 |
|------|------|
| 寡關節炎 | 少數關節受侵犯 |
| 多關節炎 | 多關節受侵犯 |
| 脊椎關節病變 | 粗大不對稱骨橋形成 |
| **殘毀性關節炎 (Arthritis Mutilans)** | 嚴重型，常侵犯手部，少見於足部 |

### 手部 X 光特徵 / Hand Radiographic Features

| 特徵 | 說明 |
|------|------|
| **香腸指 (Sausage Digit)** | 整根手指瀰漫性軟組織腫脹，為 psoriatic arthritis 特徵性表現 |
| **鉛筆-杯狀侵蝕 (Pencil-in-Cup)** | 遠端指骨呈錐形 + 近端關節面呈杯狀；最常見於 DIP |
| **關節半脫位** | 導致手指縮短 telescope 現象 |
| **Main-en-lorgnette（ opera-glass hand）** | 嚴重關節破壞導致手指 telescope 畸形 |
| **絨毛骨膜炎 (Fluffy Periostitis)** | 骨膜新生骨 |
| **關節邊緣模糊侵蝕** | |

### 足部 X 光特徵 / Foot Radiographic Features

| 特徵 | 說明 |
|------|------|
| **大拇趾 IP 和 MTP** | 最常受侵犯部位 |
| **象牙質趾骨 (Ivory Phalanx)** | 骨質緻密化；對乾癬性關節炎相對特異 |
| **蹠側跟骨骨刺** | 跟骨骨刺伴有骨膜反應；退化性跟骨骨刺無反應性新骨 |

### 脊椎侵犯 / Spinal Involvement
- 粗大骨橋（側方粗大骨性突起）
- 有時難以與反應性關節病鑑別

## 反應性關節炎 / Reactive Arthropathy

### 疾病概述 / Disease Overview
- 又稱：Reiter 關節病（舊稱）
- 發病機制：感染性腹瀉、尿道炎或宮頸炎後的炎症性關節炎
- 骶髂關節炎通常為**不對稱**（與乾癬性關節炎相同）

### 臨床特徵 / Clinical Features
- 主要侵犯**足部**
- 表現與乾癬性關節炎相似

### 早期 X 光表現 / Early Radiographic Findings
- 瀰漫性軟組織腫脹
- 關節間隙狹窄
- 侵蝕性邊緣侵蝕
- 關節旁骨質疏鬆
- 後期骨質礦化保持正常

### 跟骨侵犯 / Calcaneal Involvement
| 表現 | 說明 |
|------|------|
| 侵蝕 | 後上跟骨為常見部位（鄰近滑囊炎） |
| **骨膜反應 (Enthesophytes)** | 附著點處骨質增生 |
| **絨毛骨膜炎** | 跟骨常見 |
| 跟腱炎 | 軟組織增厚 |

### 手部侵犯 / Hand Involvement
- IP 和 MTP 關節
- 侵蝕 + 骨幹骨膜炎

### 脊椎侵犯 / Spinal Involvement
- 粗大骨橋形成
- 與乾癬性關節炎難以鑑別

### 臨床要點 / Clinical Key Points
1. **香腸指**：整指瀰漫腫脹 = 乾癬性關節炎特徵
2. **Pencil-in-Cup**：DIP 侵蝕 = 乾癬性關節炎特徵
3. **Ivory Phalanx**：蹠骨緻密化 = 乾癬性關節炎特異表現
4. **退化性跟骨骨刺無反應性新骨；乾癬性骨刺有絨毛骨膜反應**
5. **反應性關節炎**：主要由足部侵犯；後上跟骨侵蝕為典型表現
6. 反應性關節炎 = 感染後關節炎（腹瀉/尿道炎/宮頸炎）
