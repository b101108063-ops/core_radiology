## 二頭肌腱脫位 / Biceps Tendon Dislocation

| 項目 | 說明 |
|------|------|
| 相關損傷 | 與橫韌帶和二頭肌滑輪損傷同時發生 |
| 向內側脫位 | 與肩胛下肌腱撕裂相關（與二頭肌腱撕裂主要與岡上肌損傷相關不同）|
| 最佳影像位置 | **軸向 MRI**；溝空，肌腱通常可見於溝內側 |

## 不穩定性概述 / Instability: Overview

### 定義 / Definition
| 項目 | 說明 |
|------|------|
| 定義 | 活動時肱骨頭相對於關節盂的異常運動，產生疼痛、彈響或不穩定感覺 |
| 表現形式 | 脫位、半脫位或顯微不穩定（反覆性運動）|

### 盂肱關節穩定性的來源 / Stability of the Glenohumeral Joint

| 穩定性類型 | 組成 |
|-----------|------|
| **動態穩定結構** | 旋轉袖、二頭肌腱 |
| **靜態穩定結構** | 骨性關節盂凹窩、唇緣、CHL、SGHL、MGHL、IGHL |

### 不穩定性分類 / Instability Classification

| 類型 | 特徵 |
|------|------|
| **創傷性 (Traumatic)** | 單方向；與 Bankart 病灶相關；手術治療；簡稱 **TUBS** |
| **非創傷性 (Atraumatic)** | 可為：AIOS（獲得性/不穩定/過度使用/手術）或 AMBRI（先天的/多方向的/雙側的/康復/下關節囊移位）|

### TUBS vs AMBRI 記憶 / TUBS vs AMBRI Memory Aid
| 簡稱 | 含義 |
|------|------|
| **TUBS** | Traumatic, Unidirectional, Bankart, Surgical |
| **AMBRI** | Atraumatic, Multidirectional, Bilateral, Rehabilitation, Inferior shift |

### 不穩定性的放射學分類
| 方向 | 發病率 |
|------|--------|
| **前側不穩定** | 絕大多數（**95%**）|
| 後側 | 少見 |
| 多方向 | 少見 |
| 上方 | 罕見 |

### 臨床要點 / Clinical Key Points
1. **二頭肌腱脫位** = 向內側脫位入肩胛下肌；與肩胛下肌腱撕裂相關
2. **TUBS** = 創傷性/單方向/Bankart/手術
3. **AMBRI** = 非創傷性/多方向/雙側/康復/下關節囊移位
4. **95% 的肩關節不穩定**為前側方向
5. **軸向 MRI** 為二頭肌腱脫位的最佳影像位置
