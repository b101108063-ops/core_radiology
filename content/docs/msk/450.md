## 肩關節滑囊 / Shoulder Bursae

### 肩峰下/三角肌下滑囊 / Subacromial and Subdeltoid Bursae
| 項目 | 說明 |
|------|------|
| 正常溝通 | 肩峰下與三角肌下滑囊正常情況下**彼此相通** |
| 與盂肱關節的關係 | 此複合肩峰下/三角肌下滑囊**正常時不與盂肱關節相通** |

### 注射對比劑的臨床意義 / Clinical Significance of Contrast Injection
| 發現 | 意義 |
|------|------|
| 注入盂肱關節的對比劑若延伸至肩峰下/三角肌下滑囊 | 暗示**完全旋轉袖撕裂** |

## 喙肩弓與夾擊症候群 / Coracoacromial Arch and Impingement Syndrome

### 夾擊症侯群概述 / Impingement Syndrome Overview
| 項目 | 說明 |
|------|------|
| 定義 | 臨床診斷；有多種病因和 MRI 表現 |
| 原始描述 | 穿過喙肩弓的結構（岡上肌腱、二頭肌腱、肩峰下滑囊）的慢性壓迫/刺激 |

### 夾擊症侯群分類 / Classification

| 類型 | 說明 |
|------|------|
| **外在性夾擊** | 由關節外部的結構異常引起 |
| — 原發性外在性夾擊 | 由喙肩弓解剖變異引起（肩峰下骨刺、鉤狀肩峰、AC 關節骨刺、Os Acromiale、肥厚喙肩韌帶）；年輕運動員（投擲/反覆過頭運動）常見 |
| — 喙突下夾擊 | 較少見；當喙突肱骨間距變窄時發生 |
| **內在性夾擊** | 與盂肱關節不穩定相關；由旋轉袖及關節囊異常引起，無喙肩弓異常 |

### 臨床要點 / Clinical Key Points
1. **肩峰下/三角肌下滑囊**正常時彼此相通，但不與盂肱關節相通
2. **對比劑從盂肱關節延伸至肩峰下滑囊** = 完全旋轉袖撕裂
3. **外在性夾擊** = 喙肩弓結構異常（原發性）/ 喙突下（次發性）
4. **內在性夾擊** = 旋轉袖/關節囊問題，無喙肩弓異常
5. **慢性外在性夾擊** → 岡上肌腱、二頭肌腱退化、部分或完全撕裂
