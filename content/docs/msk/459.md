# Musculoskeletal Imaging - Page 459

![Page 459](/core_radiology/images/msk/page-459.png)

## 不穩定性相關病灶 / Instability: Associated Lesions

### 大多數「字母湯」病灶的位置
- 位於關節盂的**前下側**，與 IGHL 前束相關

---

### Bankart 病灶 / Bankart Lesion

| 項目 | 說明 |
|------|------|
| 定義 | 前下側唇緣的損傷（前側脫位的結果）|
| 病理 | 前下側唇緣從關節盂剝離，肩胛骨骨膜被掀起 |
| 復發風險 | 骨性 Bankart 可導致復發性脫位 |

#### GLOM 徵象 / GLOM Sign (Glenoid Labrum Ovoid Mass)
| 項目 | 說明 |
|------|------|
| 機制 | 唇緣向上遷移，形成團塊狀物 |
| 鑑別診斷 | GLOM、脫位二頭肌腱、氣泡（關節造影後）|

#### 骨性 Bankart / Bony Bankart
| 項目 | 說明 |
|------|------|
| 定義 | 前下側關節盂緣的骨折 |
| 後果 | 關節盂功能不全 → 復發性脫位 |

---

### Hill-Sachs 病灶 / Hill-Sachs Lesion
| 項目 | 說明 |
|------|------|
| 定義 | 前側脫位時，後外側肱骨頭的撞擊骨折 |
| 軸向影像診斷 | 滾動瀏覽連續切片：正常肱骨頭在 3 個連續切片（由上而下）中應呈圓形 |
| 輕微 Hill-Sachs | 僅表現為此位置的骨髓水腫，無骨折 |

---

### ALPSA (Anterior Labro-Ligamentous Periosteal Sleeve Avulsion)
| 項目 | 說明 |
|------|------|
| 與 Bankart 的差異 | 肩胛骨骨膜**完整** |
| 唇緣位移方向 | 因仍附著於骨膜，**向下內側**移位（而非向上）|

---

### Perthes 病灶 / Perthes Lesion
| 項目 | 說明 |
|------|------|
| 定義 | 前下側唇緣撕脫，唇緣仍附著於肩胛骨骨膜 |
| 診斷困難 | 因唇緣可能仍在解剖位置；需 **MR 關節造影 + ABER 位** |
| ABER 位 | 外展-外旋位 |

---

### HAGL (Humeral Avulsion of the IGHL)
| 項目 | 說明 |
|------|------|
| 定義 | IGHL 肱骨附著點的撕脫 |
| 位置 | 與 Bankart/ALPSA/Perthes 相反（肱骨側 vs 關節盂側）|
| 相關損傷 | 與肩胛下肌腱撕裂相關 |

### BHAGL (Bony HAGL)
| 項目 | 說明 |
|------|------|
| 定義 | HAGL + 肱骨解剖頸的骨質撕脫骨折 |

### 臨床要點 / Clinical Key Points
1. **Bankart** = 前下唇緣剝離（骨膜掀開）；唇緣向上移位
2. **Hill-Sachs** = 前脫位時後外側肱骨頭撞擊
3. **ALPSA** = 骨膜完整；唇緣向下內側移位
4. **Perthes** = 唇緣仍在解剖位置（難診斷）；需要 ABER 位 MR 關節造影
5. **HAGL** = IGHL 肱骨端撕脫（與 Bankart 損傷方向相反）
