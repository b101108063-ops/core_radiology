# Musculoskeletal Imaging - Page 373

![Page 373](/core_radiology/images/msk/page-373.png)

## 關節炎評估（續）/ Arthritis Evaluation (Continued)

### D — 分布（續）(Distribution)

#### 腕關節：腕掌關節 (CMC)

| CMC 關節表現 | 疾病 |
|-------------|------|
| **骨刺、無侵蝕** | 退化性關節炎 |
| **骨刺、有侵蝕** | 侵蝕性退化性關節炎 (Erosive OA) |
| **侵蝕、無骨刺** | 痛風 |

#### 腕關節：瀰漫性（泛腕骨侵犯）

| 情況 | 疾病 |
|------|------|
| 瀰漫性侵犯 | **發炎性關節病** |
| 外傷後退化 | 可發生於腕關節任何部位 |

### E — 侵蝕 (Erosions)
- 侵蝕最早出現於**骨骼「裸露區」(Bare Area)**：即關節邊緣、軟骨附著處內側
- 病程進展：侵蝕可進一步擴展至整個關節，嚴重時可導致**關節完全破壞**

| 侵蝕類型 | 疾病關聯 |
|---------|---------|
| **可變性侵蝕分布** | **類風濕關節炎**：第二、三掌骨頭橈側、拇指近節指骨底部、尺骨莖突 |
| **筆筒狀侵蝕 (Pencil-in-Cup)** | **乾癬性關節炎** |
| **海鷗狀侵蝕 (Gullwing Erosion)** | **侵蝕性退化性關節炎** |
| **皮質懸垂邊緣 (Overhanging Margin)** | **痛風**（慢性痛風石侵蝕後皮質重塑） |

### S — 軟組織腫脹 (Soft-tissue Swelling)

| 軟組織腫脹類型 | 臨床意義 |
|---------------|---------|
| **關節周對稱性腫脹** | 類風濕關節炎特徵（關節積液 X 光表現），亦可見於任何發炎性關節病 |
| **關節周不對稱性腫脹** | 退化性關節炎：骨刺及關節囊/韌帶增厚所致 |
| **DIP 腫脹** | **希伯登結節 (Heberden Node)** |
| **PIP 腫脹** | **布夏爾結節 (Bouchard Node)** |
| **整根手指香腸樣腫脹** | 手部：**乾癬性關節炎**或**反應性關節病** |
| **足部香腸樣腫脹** | 更常見於**反應性關節病** |
| **結節狀軟組織腫脹** | 痛風石、結節病、澱粉樣變性、**多中心性網狀組織球增生症 (Multicentric Reticulohistiocytosis)** |

### 臨床要點 / Clinical Key Points
1. **CMC 骨刺 + 侵蝕 → 侵蝕性退化性關節炎；CMC 侵蝕無骨刺 → 痛風**
2. **筆筒狀侵蝕 → 乾癬性關節炎；海鷗狀侵蝕 → 侵蝕性退化性關節炎**
3. **皮質懸垂邊緣 → 痛風**（慢性痛風石的特徵性表現）
4. **香腸指（手部）→ 乾癬或反應性關節炎；香腸趾（足部）→ 反應性關節炎**
5. **Heberden 結節 = DIP 退化；Bouchard 結節 = PIP 退化**
