# Musculoskeletal Imaging - Page 348

![Page 348](/core_radiology/images/msk/page-348.png)

## 感染——化膿性椎間盤炎/骨髓炎 / Infection – Pyogenic Discitis/Osteomyelitis

### 疾病概述 / Disease Overview
- **化膿性椎間盤炎/骨髓炎**：由細菌感染椎間盤及其相鄰椎體
- 最常見病原菌：**金黃色葡萄球菌 (Staphylococcus aureus)**
- 感染途徑：多為**血行播散 (Hematogenous Source)**

### 發病機制 / Pathophysiology
| 族群 | 感染起始部位 |
|------|-------------|
| **成人** | 血管化的軟骨下骨（先感染，再擴散至椎間盤） |
| **兒童** | 椎間盤（先感染，再擴散至椎體終板） |

### 影像診斷要點 / Diagnostic Key Points

| 檢查 | 典型表現 |
|------|----------|
| **MRI（T1）** | 病變椎體骨髓低信號（取代正常骨髓信號） |
| **MRI（T2）** | 椎間盤高信號；相鄰終板界限不清 |
| **X 光** | 早期：僅見椎間隙高度喪失；晚期：椎體塌陷 |
| **CT** | 椎間隙高度喪失、相鄰終板侵蝕、急性後凸成角 |

### 臨床特徵 / Clinical Features
- 腰痛、發燒
- 脊柱活動受限
- 附近軟組織感染（椎旁或硬膜外膿腫）常見

### 鑑別診斷 / Differential Diagnosis
- 化膿性 vs. 結核性椎間盤炎（見下節）
- 退化性椎間盤疾病：無發燒、無軟組織膿腫

### 臨床要點 / Clinical Key Points
1. **MRI 是首選**：對早期病變敏感
2. **T1 低信號 + T2 高信號** = 骨髓炎的典型表現
3. 成人先感染骨頭，兒童先感染椎間盤

## 結核性骨髓炎——Pott 病 / Tuberculous Osteomyelitis – Pott Disease

### 疾病概述 / Disease Overview
- **Pott 病**：結核分枝桿菌 (*Mycobacterium tuberculosis*) 感染椎體
- 與化膿性椎間盤炎關鍵區別：**結核菌缺乏蛋白水解酶，椎間盤通常不受侵犯**
- 約 10% 患者有活動性肺結核

### 發病機制 / Pathophysiology
- 結核菌不破壞椎間盤 → 椎間隙高度保留（與化膿性感染鑑別要點）
- 椎體前方楔形壓縮 → **駝背畸形 (Gibbus Deformity)**

### Gibbus 畸形 / Gibbus Deformity
- 定義：急性成角的後凸
- 病因：
  - 結核性椎體壓縮骨折
  - 先天性症候群（軟骨發育不全、黏多醣貯積症）

### 影像診斷要點 / Diagnostic Key Points

| 特徵 | 化膿性感染 | 結核性感染 (Pott 病) |
|------|-----------|---------------------|
| 椎間盤 | 常受侵犯 | **通常保留** |
| 椎體侵犯 | 雙側相鄰終板 | 椎體前方楔形壓縮 |
| 畸形 | 不一定 | **典型駝背畸形** |
| 膿腫 | 椎旁/硬膜外 | 大範圍、冷膿腫 |
| 肺結核 | 少見 | 約 10% 合併活動性肺 TB |

### 臨床要點 / Clinical Key Points
1. **椎間盤是否保留**是鑑別結核性與化膿性感染的關鍵
2. **駝背畸形**是結核性脊柱感染的典型表現
3. Pott 病患者需排查活動性肺結核
4. 兩者均可導致硬膜外膿腫，但結核性膿腫範圍通常更大
