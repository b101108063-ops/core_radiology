## 腰椎/胸椎 / Lumbar/Thoracic Spine

## 腰椎/胸椎創傷 / Lumbar/Thoracic Spine Trauma

### 三柱概念 / Three Column Concept
| 柱子 | 組成 |
|------|------|
| **前柱** | 椎體前方 2/3 + 前縱韌帶 |
| **中柱** | 椎體後 1/3 + 後縱韌帶 |
| **後柱** | 後側結構 + 後側韌帶（棘上、棘間韌帶，黃韌帶）|

#### 穩定性評估 / Stability Assessment
| 損傷情況 | 穩定性 |
|---------|--------|
| **保留兩柱** | 通常穩定 |
| **三柱皆嚴重損傷** | 最可能不穩定 |
| **兩柱損傷** | 可能穩定或不穩定 |

---

### Chance 骨折 / Chance Fracture

| 項目 | 說明 |
|------|------|
| 別名 | 安全帶骨折 (Seat Belt Fracture) |
| 機制 | 突然減速時脊柱急性前屈（屈曲-牽扯損傷）|
| 骨折特徵 | 水平分裂：從後方的棘突或椎板開始，向前延伸穿過椎體 |

---

### 脊椎滑脫症 / Spondylolysis

| 項目 | 說明 |
|------|------|
| 定義 | 椎弓峽部 (Pars Interarticularis) 骨折 |
| 病因 | 慢性應力或急性骨折 |
| X 光斜位片表現 | 「Scottie Dog」頸部缺陷 |
| 後果 | 導致脊椎前移症 (Spondylolisthesis)：一個椎體相對於另一個的前-後半脫位 |

### 臨床要點 / Clinical Key Points
1. **三柱概念** = 前柱/中柱/後柱；兩柱保留=通常穩定
2. **Chance 骨折** = 安全帶損傷 + 屈曲-牽扯 + 從後方向前方穿過椎體的水平骨折
3. **脊椎滑脫症 (Spondylolysis)** = 椎弓峽部骨折（"Scottie Dog" 頸部缺損）
4. **脊椎前移症 (Spondylolisthesis)** = 椎體相對前移（由脊椎滑脫症引起）
5. **Crossover Sign** = Pincer-type FAI = 前壁越過後壁
