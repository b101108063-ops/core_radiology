# Musculoskeletal Imaging - Page 361

![Page 361](/core_radiology/images/msk/page-361.png)

## 膝關節類風濕關節炎 / Rheumatoid Arthritis in the Knee

### 侵犯模式 / Pattern of Involvement
- RA 可侵犯膝關節**全部三個間室**
- OA 通常首先侵犯**內側脛股間室**

### X 光特徵 / Radiographic Features
| 表現 | 說明 |
|------|------|
| 三間室對稱性軟骨狹窄 | 與 OA 內側偏心性狹窄不同 |
| 骨刺 | 繼發性 OA 時可見 |
| **無明顯侵蝕** | 與手部小關節不同 |

### 臨床要點 / Clinical Note
- 膝關節 OA 伴骨刺 + 對稱性軟骨狹窄 → 需考慮**繼發性骨關節炎**

## 脊椎類風濕關節炎 / Rheumatoid Arthritis in the Spine

### 侵犯概況 / Overview
| 項目 | 說明 |
|------|------|
| 侵犯率 | 高達 70% 的 RA 患者 |
| 侵犯部位 | **頸椎**為主；胸腰椎**幾乎不受侵犯** |
| 疾病程度相關性 | 疾病越嚴重、病程越久，侵犯率越高 |

### 頸椎 RA 一般模式 / General Pattern
| 表現 | 說明 |
|------|------|
| 多節段半脫位 | 齒突、關節突、椎體終板、棘突侵蝕 |
| 骨質疏鬆 | 與 OA 無骨質增生相反 |
| **齒突侵蝕** | 齒突侵蝕為特徵性表現 |
| 無骨質增生 | 與 OA 鑑別要點 |

### 寰樞椎半脫位 (Atlantoaxial Subluxation)

#### 定義 / Definition
- 齒突-寰椎間距 (ADI)：前齒突後緣至 C1 前環後緣的距離

| 人群 | 診斷標準 |
|------|----------|
| 成人 | > 2.5 mm |
| 兒童 | > 5 mm |

#### 半脫位類型 / Types

| 類型 | 病因 | 特點 |
|------|------|------|
| **前脫位（最常見）** | 橫韌帶鬆弛（相鄰滑囊炎） | 需屈曲位 X 光才能顯示 |
| **後脫位** | 齒突侵蝕或骨折 | |
| **垂直半脫位（齒突上突）** | C1–C2 關節侵蝕塌陷 | 齒突向上突入枕骨大孔，壓迫中腦 |
| **旋轉半脫位** | 關節侵蝕 | |
| **側方半脫位** | 齒突侵蝕 | |

#### 垂直半脫位 / Vertical Subluxation (Atlantoaxial Impaction)
- C1–C2 關節侵蝕塌陷
- 齒突向上突入**枕骨大孔 (Foramen Magnum)**
- 齒突側位片通常不可見；C1 前弓可下沉至 C2 椎體水平

## 肩關節類風濕關節炎 / Rheumatoid Arthritis in the Shoulder

### 影像特徵 / Imaging Features
| 表現 | 說明 |
|------|------|
| **慢性旋轉袖撕裂** | 導致典型的高騎肱骨 (High Riding Humerus) |
| **肱骨頭外側侵蝕** | 滑膜炎症沿軟骨-骨交界處侵犯 |
| **鎖骨遠端「筆尖樣」侵蝕** | 肩鎖關節侵蝕特徵 |

---

## 肘關節類風濕關節炎 / Rheumatoid Arthritis in the Elbow

- 約 **1/3** 的 RA 患者侵犯肘關節

### 臨床要點 / Clinical Key Points
1. **膝關節 RA**：三間室均可能受侵犯；無明顯侵蝕（不同於手部）
2. **頸椎 RA**：齒突侵蝕 + 多節段半脫位；**頸椎為主，胸腰椎幾乎不受侵犯**
3. **ADI > 2.5mm（成人）**= 前寰樞椎半脫位
4. **垂直半脫位**：齒突向上突入枕骨大孔 → 壓迫中腦
5. **肩關節 RA**：高騎肱骨 + 鎖骨遠端筆尖樣侵蝕
