# Musculoskeletal Imaging - Page 359

![Page 359](/core_radiology/images/msk/page-359.png)

## 侵蝕性骨關節炎 / Erosive Osteoarthritis

### 疾病概述 / Disease Overview
- 結合了**類風濕關節炎的臨床表現**（腫脹）與**骨關節炎的影像學表現和分布**
- 好發族群：**老年女性**

### 手部侵蝕性骨關節炎 / Erosive OA of the Hands

#### 好發部位 / Sites of Involvement
- 分布與退化性 OA 相同：**DIP、第一 CMC、PIP**
- **侷限於手部**

#### X 光特徵 / Radiographic Features
- **海鷗翼徵 (Gull-Wing Sign)**：DIP 關節中心侵蝕 + 邊緣骨刺
- 為侵蝕性 OA 的特徵性表現

## 類風濕關節炎 (RA) / Rheumatoid Arthritis (RA)

### 疾病概述 / Disease Overview
- **自體免疫疾病**：滑膜為免疫攻擊目標
- **類風濕因子 (Rheumatoid Factor, RF)**：對抗 IgG 的抗體，激活補體級聯反應
  - RF 陽性非特異性（可見於其他疾病）
- 臨床表現：**對稱性關節疼痛、腫脹、晨間僵硬**

### 侵犯順序 / Disease Progression
1. **首發**：手部小關節（腕、MCP、PIP）
2. **足部**：早期即可能侵犯（足部 X 光為常規檢查）
3. **進程**：頸椎、膝、肩、髖

### X 光特徵性表現 / Radiographic Hallmarks of RA

| 表現 | 說明 |
|------|------|
| **邊緣侵蝕 (Marginal Erosions)** | 最早發生在關節囊內「無軟骨區 (Bare Area)」——關節囊附著處裸露骨 |
| **軟組織腫脹** | 反映滑膜炎 |
| **瀰漫性對稱性關節間隙狹窄** | 均勻性軟骨丢失 |
| **關節周圍骨質疏鬆 (Periarticular Osteopenia)** | 反映滑膜炎性充血 |
| **關節半脫位** | 疾病晚期表現 |

### 無軟骨區 (Bare Area) 解剖 / Anatomical Concept
- 定義：關節囊內關節軟骨附著線以內的裸露骨區域
- 為 RA **最早侵蝕部位**

### RA vs. OA——手部鑑別診斷

| 特徵 | 類風濕關節炎 (RA) | 骨關節炎 (OA) |
|------|------------------|--------------|
| MCP 侵犯 | **典型** | 少見 |
| DIP 侵犯 | 少見 | **典型** |
| 骨刺 | 無 | 有 |
| 邊緣侵蝕 | **有** | 無 |
| 骨質疏鬆 | **有** | 無 |
| 軟骨下硬化 | 無 | 有 |

### 臨床要點 / Clinical Key Points
1. **侵蝕性 OA**：海鷗翼徵 + DIP 中心侵蝕
2. **RA**：RF 陽性 + 對稱性小關節侵犯 + 邊緣侵蝕 + 關節周圍骨質疏鬆
3. **Bare Area**：關節囊內裸露骨區 = RA 最早侵蝕部位
4. 足部 X 光為 RA 常規檢查（早期可能僅足部受侵犯）
