# Musculoskeletal Imaging - Page 435

![Page 435](/core_radiology/images/msk/page-435.png)

## 髖關節肌肉截面解剖 / Cross-Sectional Anatomy of Hip Musculature

### 重要肌肉與結構標註 / Key Structures

| 區域 | 肌肉/結構 |
|------|----------|
| 前側 | 髂腰肌、股直肌、縫匠肌 |
| 外側 | 闊筋膜張肌、臀小肌、臀中肌 |
| 後側 | 臀大肌、股方肌、上下孖肌、閉孔內外肌、梨狀肌 |
| 大轉子附著 | 臀中肌、臀小肌、閉孔內肌、梨狀肌 |
| 小轉子附著 | 髂腰肌 |

### 股骨頭解剖 / Femoral Head Anatomy
| 項目 | 說明 |
|------|------|
| 軟骨覆蓋 | 股骨頭大部分有關節軟骨覆蓋 |
| 凹窩 (Fovea Capitis) | 中央凹陷，**圓韌帶 (Ligamentum Teres)** 附著處（此處無軟骨）|

### 大/小轉子 / Greater and Lesser Trochanters
| 結構 | 附著肌肉 |
|--------|---------|
| **大轉子** | 臀中肌、臀小肌、閉孔內肌、閉孔外肌、梨狀肌 |
| **小轉子** | 髂腰肌 |

### 重要臨床提醒
| 發現 | 臨床意義 |
|------|---------|
| **成人小轉子骨折** | 除非另有證明，應視為**病理性骨折** |

### 臨床要點 / Clinical Key Points
1. **大轉子** = 臀中肌、臀小肌、閉孔內肌、梨狀肌的共同附著點
2. **小轉子** = 髂腰肌附著點；成人小轉子骨折 = 病理性骨折（除非另有證明）
3. **股骨頭凹窩** = 圓韌帶附著處，無軟骨覆蓋
4. **股直肌**起源於前下髂棘 (AIIS)；**縫匠肌**起源於前上髂棘 (ASIS)
5. **坐骨神經**穿過梨狀肌下方（臀大肌深層）
