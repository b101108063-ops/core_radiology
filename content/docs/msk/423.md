# Musculoskeletal Imaging - Page 423

![Page 423](/core_radiology/images/msk/page-423.png)

## 垂直/縱向撕裂 / Vertical / Longitudinal Tear

### 影像特徵 / Imaging Features
| 項目 | 說明 |
|------|------|
| 方向 | 弧形撕裂，**沿半月板弧度走向** |
| 矢狀切片表現 | 撕裂呈垂直方向，**與半月板邊緣保持固定距離** |

## 桶柄狀撕裂 / Bucket-Handle Tear

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 為廣泛垂直撕裂的結果，內側半月板（最常見）的游離內緣被**移位或翻轉** |

### 影像診斷要點 / Imaging Findings

| 徵象 | 說明 |
|------|------|
| **Absent Bow Tie Sign（蝴蝶結消失徵）** | 最重要的診斷發現：在相鄰 4 mm 矢狀切片上，**少於兩個「蝴蝶結」** |
| 移位的半月板碎片 | 最常見位置：**髁間窩 (Intercondylar Notch)** |

### 特殊徵象 / Special Signs

| 徵象 | 移位方向 | MRI 切片 |
|------|---------|---------|
| **Double Delta Sign** | 向前移位 | 矢狀切片 |
| **Double PCL Sign** | 向後移位（僅內側半月板）| 矢狀切片 |

### 臨床要點 / Clinical Key Points
1. **垂直/縱向撕裂** = 弧形走向，矢狀切片上與邊緣保持固定距離
2. **桶柄狀撕裂** = 內側半月板最常見 + 廣泛垂直撕裂後翻轉
3. **Absent Bow Tie Sign** = 桶柄狀撕裂最敏感的 MRI 發現
4. **Double PCL Sign** = 移位的半月板碎片在髁間窩（矢狀切片上類似兩條 PCL）
5. **Double Delta Sign** = 向前移位（矢狀切片）
