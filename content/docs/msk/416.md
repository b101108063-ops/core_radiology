# Musculoskeletal Imaging - Page 416

![Page 416](/core_radiology/images/msk/page-416.png)

## 踝關節肌腱解剖 / Ankle Tendon Anatomy

### 前側伸肌腱群（內踝至外踝）/ Anterior Extensor Tendons
| 排序（由內至外）| 肌腱 | 簡稱 |
|----------------|------|------|
| 脛骨前肌 | Tibialis Anterior | Tom |
| 拇長伸肌 | Extensor Hallucis Longus | Harry |
| 趾長伸肌 | Extensor Digitorum Longus | Dick |

> **記憶口號**：「Tom, Harry, and Dick」

---

### 後側屈肌腱群 / Posterior Flexor Tendons
| 排序（由內至外）| 結構 |
|----------------|------|
| 脛骨後肌 | Posterior Tibial Tendon |
| 趾長屈肌 | Flexor Digitorum Longus |
| 脛後動靜脈 | Posterior Tibial Artery |
| 脛後神經 | Posterior Tibial Nerve |
| 拇長屈肌 | Flexor Hallucis Longus |

> **記憶口號**：「Tom, Dick, ANd Harry」
> （AN = Artery + Nerve 夾在中間）

---

### 外踝肌腱群 / Lateral Ankle Tendons

| 肌腱 | 說明 |
|------|------|
| **腓骨長肌 (Peroneus Longus)** | 繞過足底，附著於內側楔骨與第一蹠骨 |
| **腓骨短肌 (Peroneus Brevis)** | 附著於第五蹠骨底部 |

---

### 踝關節韌帶 / Ankle Ligaments

#### 外側韌帶複合體 / Lateral Ankle Ligaments
| 韌帶 | 說明 |
|------|------|
| **ATFL (前距腓韌帶)** | 最常見損傷的韌帶 |
| **PTFL (後距腓韌帶)** | 非常強韌，很少損傷 |
| **跟腓韌帶 (CFL)** | 損傷頻率次高 |

### 臨床要點 / Clinical Key Points
1. **伸肌腱記憶**：「Tom, Harry, and Dick」（由內至外）
2. **屈肌腱記憶**：「Tom, Dick, ANd Harry」
3. **ATFL** = 踝關節扭傷中最常見損傷的韌帶
4. **腓骨短肌** = 附著於第五蹠骨底部（Zone 1 avulsion 骨折的結構）
5. **踝關節扭傷** = 所有關節損傷中最常見
