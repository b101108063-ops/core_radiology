## 肩峰形態與方向 / Acromial Shape and Orientation

### Bigos 肩峰分類 / Bigos Classification

| 分型 | 形態 | 與夾擊症的關係 |
|------|------|----------------|
| **Type I** | 平坦型 | 不易造成夾擊 |
| **Type II** | 彎曲型 | 可能造成夾擊 |
| **Type III** | 鉤狀 (Hooked) | 為肩峰下撞擊的主要形態因素 |
| **Type IV** | 凸面型 | 可能造成夾擊 |

### 臨床注意
- 肩峰形態與夾擊症的關聯仍有爭議
- 鉤狀肩峰 (Type III) 或凸面肩峰 (Type IV) 可能促進外在性夾擊，導致旋轉袖撕裂

---

## Os Acromiale / 肩峰骨

| 項目 | 說明 |
|------|------|
| 定義 | 肩峰的持續性附屬骨化中心，見於高達 **15%** 的患者 |
| 最佳評估位置 | 軸向影像 |
| 臨床意義 | 可能是無症狀的正常變異；但若出現**骨髓水腫**，提示可能是疼痛的原因 |
| 治療 | 切除或融合 |

## 旋轉袖 / Rotator Cuff

### 旋轉袖解剖 / Anatomy of the Rotator Cuff

| 肌肉 | 位置 | 附著點 |
|------|------|--------|
| **岡上肌 (Supraspinatus)** | 肩胛骨後側 | 大結節 |
| **岡下肌 (Infraspinatus)** | 肩胛骨後側 | 大結節 |
| **小圓肌 (Teres Minor)** | 肩胛骨後側 | 大結節 |
| **肩胛下肌 (Subscapularis)** | 肩胛骨前側 | **小結節** |

### 功能
| 功能 | 說明 |
|------|------|
| 旋轉袖 | 為盂肱關節的關鍵主動穩定結構 |

### 臨床要點 / Clinical Key Points
1. **Os Acromiale** = 肩峰附屬骨化中心（15%）；骨髓水腫時為疼痛原因
2. **Type III (鉤狀) 肩峰** = 夾擊症的主要形態因素
3. **旋轉袖肌肉** = 岡上肌、岡下肌、小圓肌（均附著於大結節）+ 肩胛下肌（附著於小結節）
4. 旋轉袖為盂肱關節的**主動穩定結構**
5. 臨床上肩峰形態對夾擊症的影響仍存在爭議
