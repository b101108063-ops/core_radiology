# Musculoskeletal Imaging - Page 365

![Page 365](/core_radiology/images/msk/page-365.png)

## 結締組織疾病 / Connective Tissue Disorders Affecting the Joints

### 全身性紅斑狼瘡 (SLE) / Systemic Lupus Erythematosus (SLE)

#### 疾病概述 / Disease Overview
- 關節異常見於約 **90%** 的 SLE 患者

#### X 光特徵 / Radiographic Features
| 表現 | 說明 |
|------|------|
| **MCP 和 PIP 可復位性半脫位** | SLE 的關鍵 X 光徵象 |
| PA 位時手部受壓對準正常 | 半脫位在**Nørgaard 位（ball-catcher）**或**斜位**時才顯現 |

#### Nørgaard 位 (Ballcatcher's View)
- 又稱：Ball-catcher 或 "You're in good hands with Allstate" 位
- 手不受限於 X 光板上 → 半脫位得以顯現

---

### Jaccoud 關節病 / Jaccoud Arthropathy

#### 疾病概述 / Disease Overview
- 歷史定義：反覆風濕熱後導致
- 目前觀點：SLE 與 Jaccoud 關節病可能為同一疾病
- 兩者皆為 **Type III 過敏反應**
- X 光表現相同：**手部可復位性半脫位**

---

### 硬皮病 (Scleroderma) / Systemic Sclerosis (Scleroderma)

#### 疾病概述 / Disease Overview
- 全身性膠原血管疾病
- 膠原蛋白沉積於**皮膚和軟組織**
- 手指尖端最先受侵犯 → 遠端軟組織萎縮

#### X 光特徵 / Radiographic Features

| 表現 | 說明 |
|------|------|
| **遠端指骨吸收 (Acroosteolysis)** | 遠端指骨遠端骨質吸收；為特徵性表現 |
| **軟組織和關節旁鈣化** | 常見；導致皮膚緊縮、纖維化 |
| **關節攣縮** | 皮膚纖維化導致 |

#### Acroosteolysis 鑑別診斷 / Differential Diagnosis

| 病因 | 特點 |
|------|------|
| **硬皮病** | 常伴隨鈣化 |
| 神經病變 | 無鈣化 |
| 聚氯乙烯暴露 | 無鈣化 |
| 凍瘡/燒傷 | 拇指通常豁免（因握拳時保護） |
| 甲狀旁腺功能亢進 | 伴隨**骨膜下骨質吸收** |
| Hajdu-Cheney 症候群 | 罕見；自體顯性；身材矮小、顱面異常 |

---

### 多發性肌炎/皮肌炎 / Polymyositis and Dermatomyositis

#### 疾病概述 / Disease Overview
- 特發性肌肉炎症（多發性肌炎）或肌肉+皮膚炎症（皮肌炎）
- 關節異常罕見；可有輕微關節周圍骨質疏鬆

#### 影像特徵 / Imaging Hallmark
| 表現 | 說明 |
|------|------|
| **軟組織鈣化** | 為特徵性表現 |
| 肌肉內鈣化 | 最常見 |
| 皮下鈣化 | 與硬皮病相似 |

---

## 晶體沉積性關節病 / Crystal Deposition Arthropathies

### 氫氧基磷灰石沉積症 (HADD) / Calcium Hydroxyapatite Deposition Disease (HADD)

#### 疾病概述 / Disease Overview
- 又稱：**鈣化性肌腱炎 (Calcific Tendinitis)**
- 晶體沉積於**關節旁組織**
- **關節軟骨和滑膜不受侵犯**

#### 好發部位 / Common Sites
| 部位 | 說明 |
|------|------|
| **肩關節：岡上肌腱** | 旋轉袖中最常受侵犯 |
| **頸椎：椎前肌（Longus Coli）** | 可致頸痛、吞嚥困難、發燒、椎前積液；可類似椎前膿腫 |

#### Milwaukee Shoulder（關節內型）
- 肩關節內型
- 導致旋轉袖和盂肱關節**快速破壞**

### 臨床要點 / Clinical Key Points
1. **SLE**：MCP/PIP 可復位性半脫位；Nørgaard 位才能顯示
2. **Jaccoud = SLE**：兩者 X 光表現相同（可復位性半脫位）
3. **硬皮病**：遠端指骨吸收 + 軟組織鈣化
4. **Acroosteolysis**：硬皮病伴鈣化最典型
5. **HADD**：晶體沉積於關節旁；軟骨和滑膜不受侵犯
6. **Milwaukee Shoulder**：HADD 關節內型 → 肩關節快速破壞
