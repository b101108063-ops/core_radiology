# Musculoskeletal Imaging - Page 446

![Page 446](/core_radiology/images/msk/page-446.png)

## 頸椎骨折（續）/ Cervical Spine Fractures (Continued)

### 爆裂骨折 / Burst Fracture
| 項目 | 說明 |
|------|------|
| 機制 | 與 Jefferson 骨折類似（軸向負荷）|
| 位置 | 發生於頸椎較低位置（C2-C7）|

---

### Flexion Teardrop 骨折 / Flexion Teardrop Fracture

| 項目 | 說明 |
|------|------|
| 地位 | 最嚴重的頸椎損傷，但可能維持生命 |
| 機制 | 過度屈曲 + 壓迫；導致相關節段椎體向後位移至脊髓腔 |
| X 光關鍵發現 | 前下椎體的撕脫骨片（前縱韌帶撕脫）；受影響椎體變短（旋轉）|
| 後果 | 可導致**前脊髓徵候群 (Anterior Cord Syndrome)**：錐體束和前脊髓丘腦束受壓迫 → 完全癱瘓 + 痛溫覺喪失；背柱通常完整（保留觸覺和振動覺）|

---

### Extension Teardrop 骨折 / Extension Teardrop Fracture

| 項目 | 說明 |
|------|------|
| 與屈曲型差異 | **穩定** |
| 好發位置 | 頸椎較高位置（C2 或 C3）|
| X 光表現 | 與屈曲型相似的前下撕脫碎片；但**無半脫位，棘突椎板線未中斷** |

---

### Clay-shoveler's 骨折 / Clay-Shoveler's Fracture
| 項目 | 說明 |
|------|------|
| 定義 | 棘突的移位撕脫骨折 |
| 機制 | 強制屈曲 |
| 好發位置 | 下頸椎/上胸椎（C6-T1）|

---

### 雙側關節面脫位（鎖定關節面）/ Bilateral Interfacetal Dislocation (Locked Facets)

| 項目 | 說明 |
|------|------|
| 機制 | 過度屈曲；所有脊椎韌帶完全斷裂，相關椎體前移位 > **50%** |
| 穩定性 | **不穩定**；脊髓損傷風險高 |
| 好發位置 | 下頸椎 |
| **Naked Facet Sign** | 上關節突未被相鄰下關節突覆蓋 |
| **Perched Facets** | 較輕微的變異：下關節突懸於上位椎的下關節突上；前移位 > 3 mm 但 < 50%（為鎖定關節面的過渡型）|

---

### 單側關節面脫位 / Unilateral Interfacetal Dislocation
| 項目 | 說明 |
|------|------|
| 機制 | 過度屈曲 + 向脫位對側旋轉 |
| 穩定性 | **穩定** |

---

### Grisel 症候群 / Grisel Syndrome
| 項目 | 說明 |
|------|------|
| 定義 | 繼發於發炎性腫塊（通常為咽喉炎或咽後膿胸）的**非創傷性寰樞椎旋轉半脫位** |

### 臨床要點 / Clinical Key Points
1. **Flexion Teardrop** = 最不穩定頸椎骨折；前脊髓徵候群
2. **Extension Teardrop** = 穩定；無半脫位（與屈曲型鑑別）
3. **Locked Facets** = 前移位 > 50% + 高脊髓損傷風險
4. **Naked Facet Sign** = 雙側鎖定關節面的特徵
5. **Grisel 症候群** = 非創傷性寰樞椎半脫位（咽喉炎後）
