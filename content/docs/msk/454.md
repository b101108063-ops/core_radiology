# Musculoskeletal Imaging - Page 454

![Page 454](/core_radiology/images/msk/page-454.png)

## 完全厚度旋轉袖撕裂 / Full-Thickness Rotator Cuff Tear

### 影像表現 / Imaging Findings
| 發現 | 說明 |
|------|------|
| MR 關節造影 | 對比劑從盂肱關節延伸至肩峰下/三角肌下滑囊 |
| 無對比劑時 | 異常信號穿過整個肌腱厚度；幾乎都有肌腱缺口 |

### 好發統計 / Statistics
| 發現 | 說明 |
|------|------|
| 最常受傷 | **岡上肌**（與部分撕裂相同）|
| 岡上肌撕裂 + 岡下肌撕裂 | 約 30-40% 的岡上肌撕裂同時有岡下肌撕裂 |
| 單獨岡下肌撕裂 | 少見；可見於後側不穩定 |

### 類風濕性關節炎的完全厚度撕裂
| 發現 | 說明 |
|------|------|
| 經典型影像 | 肱骨頭向上移位，嚴重時可與肩峰對撞 |

### 完全厚度撕裂分類 / Classification by Size
| 大小 | 尺寸 |
|------|------|
| 小型 | < 1 cm |
| 中型 | 1-3 cm |
| 大型 | 3-5 cm |
| **巨型 (Massive)** | > 5 cm |

## 旋轉袖萎縮 / Rotator Cuff Atrophy

### 病因 / Etiology
| 病因 | 說明 |
|------|------|
| **慢性旋轉袖撕裂** | 最常見原因 |
| 脫神經萎縮 (Denervation) | 較少見；通常與唇旁囊腫相關 |

### 脂肪浸潤時間 / Timeline
- 損傷後 **4 週內**可能出現脂肪退化，且通常**不可逆**
- 肌肉退化程度與手術修復預後相關

### Goutallier 分類 / Goutallier Classification
| 分級 | 表現 |
|------|------|
| **Grade 0** | 正常肌肉，無脂肪 |
| **Grade 1** | 少許脂肪條紋 |
| **Grade 2** | 脂肪浸潤，肌肉為主 |
| **Grade 3** | 脂肪浸潤，脂肪與肌肉等量 |
| **Grade 4** | 脂肪浸潤，脂肪為主 |

### 臨床要點 / Clinical Key Points
1. **完全厚度撕裂** = 對比劑延伸至滑囊 + 肌腱連續性中斷
2. **Goutallier Grade 3-4** = 脂肪為主 = 預後差，手術修復效果有限
3. **岡上肌 + 岡下肌同時撕裂** = 30-40%（常見組合）
4. **類風濕性關節炎** = 肱骨頭向上移位與肩峰對撞
5. **巨型撕裂 (> 5 cm)** = 修復困難，預後較差
