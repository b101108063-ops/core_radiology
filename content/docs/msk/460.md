# Musculoskeletal Imaging - Page 460

![Page 460](/core_radiology/images/msk/page-460.png)

## 前下側不穩定病灶總結 / Summary of Anterior-Inferior Instability Lesions

### 前下側不穩定病灶比較表 / Comparison of Anterior-Inferior Instability Lesions

| 病灶 | 骨膜 | 唇緣位置 | 方向 |
|------|------|---------|------|
| **正常** | 完整 | 前下側唇緣完整 | — |
| **Bankart** | 掀起 | 從關節盂剝離 | 向上移位 |
| **ALPSA** | 完整 | 仍在解剖位置但套疊成團 | 向下內側移位 |
| **Perthes** | 完整 | 仍在解剖位置（很難看到）| 可能無位移 |
| **HAGL** | — | IGHL 肱骨端撕脫 | — |
| **BHAGL** | — | HAGL + 骨質撕脫 | — |

### 圖解記憶要點
| 病灶 | 關鍵特徵 |
|------|---------|
| **Bankart** | 唇緣從關節盂剝離 + 骨膜掀起 |
| **ALPSA** | 唇緣套疊成團 + 骨膜完整 + 向下內側位移 |
| **Perthes** | 唇緣仍在解剖位置（最難診斷）|
| **HAGL** | IGHL 肱骨附著點撕脫 |

### 臨床要點 / Clinical Key Points
1. **Bankart** = 唇緣剝離 + 骨膜掀起（經典型前下不穩定損傷）
2. **ALPSA** = 骨膜完整 + 唇緣向下內側移位
3. **Perthes** = 唇緣仍在解剖位置（需要 ABER 位 MR 關節造影才能確診）
4. **HAGL** = IGHL 肱骨端撕脫（與 Bankart 的唇緣側不同）
5. **BHAGL** = HAGL + 骨質（為 HAGL 的骨性變異）
