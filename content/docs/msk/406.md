## 地中海貧血 / Thalassemia

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 遺傳方式 | 自體隱性，先天性貧血 |
| 病因 | α 或 β 血紅蛋白亞基缺陷 |
| 與鐮刀型疾病相似點 | 骨骼三大表現相同：梗塞、骨髓增生、感染 |
| 與鐮刀型疾病不同點 | 骨髓擴張更明顯（因貧血可能更嚴重）|

### 各部位特徵 / Location-Specific Features

| 部位 | 表現 |
|------|------|
| **手部** | 骨髓擴張 → 指骨/掌骨**增寬及變方 (Widening & Squaring)** |
| **顱骨** | **「頭髮豎立條紋」(Hair-on-End Striations)**：骨髓擴張的經典表現 |
| **面部骨骼** | 骨髓擴張可能使鼻竇消失 → 典型**齧齒類面容 (Rodent-likeFacies)** |
| **長骨** | 骨髓擴張可能導致**Erlenmeyer Flask 畸形** |

## 骨髓纖維化 / Myelofibrosis

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 好發年齡 | 老年患者 |
| 病理 | 骨髓進行性纖維化 |
| 結果 | 貧血 + 脾腫大 |
| 骨骼表現 | 骨髓纖維化 → **骨骼瀰漫性硬化** |

### 影像特徵 / Imaging Features
| 發現 | 說明 |
|------|------|
| CT | 脾腫大 + **骨骼瀰漫性密度增加** |

## 肥大細胞增多症 / Mastocytosis

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 病因 | 肥大細胞異常增生 |
| 骨骼表現 | 骨髓對浸潤肥大細胞的反應 → **瀰漫性骨質疏鬆** 或 **硬化** |

### 臨床要點 / Clinical Key Points
1. **地中海貧血** = α/β 血紅蛋白缺陷 → 骨髓擴張比鐮刀型疾病更顯著
2. **齧齒類面容** = 地中海貧血面部骨骼骨髓擴張（鼻竇消失）
3. **Hair-on-End 条纹** = 地中海貧血/鐮刀型疾病顱骨骨髓擴張
4. **骨髓纖維化** = 老年人 + 脾腫大 + 骨骼瀰漫性硬化
5. **Erlenmeyer Flask 畸形** = 地中海貧血/高雪氏症（骨髓擴張使長骨塑形異常）
