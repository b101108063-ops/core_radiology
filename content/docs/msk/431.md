## 髕骨外側脫臼 / Lateral Patellar Dislocation

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 創傷後表現 | 即使髕骨已回復正常位置，仍留有獨特的損傷型態 |
| 典型骨挫傷分布 | **外側股骨髁** + **髕骨內側關節面** |
| 結構損傷 | 內側支持帶 (Medial Retinaculum) 撕裂 |

### 影像特徵 / Imaging Features
| 發現 | 說明 |
|------|------|
| MRI 骨髓水腫型態 | 外側股骨髁 + 髕骨內側 Facet 的典型水腫 |
| 持續性外側半脫位 | 可見髕骨完全移向外側 + 內側支持帶完全撕裂 |

## Osgood-Schlatter 病 / Osgood-Schlatter Disease

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 脛骨粗隆的**軟骨發育不良 (Osteochondrosis)** |
| 病因 | 反覆性微創傷 |
| 好發年齡 | **青少年** |

### 影像特徵 / Imaging Features

| 檢查 | 發現 |
|------|------|
| **X 光** | 脛骨粗隆增大並碎裂 + 鄰近軟組織水腫 |
| **MRI** | 遠端髕骨肌腱信號增加；脛骨粗隆內骨髓水腫；Hoffa 脂肪墊水腫 |

### 臨床要點 / Clinical Key Points
1. **髕骨外側脫臼** = 即使復位後仍留有：外側股骨髁 + 內側髕骨Facet骨髓水腫
2. **Osgood-Schlatter** = 青少年 + 脛骨粗隆軟骨發育不良 + 反覆微創傷
3. **MRI 診斷 Osgood-Schlatter**：遠端髕骨肌腱 + 脛骨粗隆 + Hoffa 脂肪墊水腫
4. **Osgood-Schlatter X 光**：脛骨粗隆增大/碎裂
5. **創傷性髕骨脫臼** → 內側支持帶撕裂為主要穩定性結構
