## 膝關節與膝關節 MRI / Knee and Knee MRI

## 膝關節創傷 / Knee Trauma

### 膝關節脫臼 / Knee Dislocation

| 項目 | 說明 |
|------|------|
| 好發方向 | 可向任何方向脫臼，**前側脫臼**最常見 |
| 血管損傷風險 | **非常高**（膕動靜脈）|
| 臨床注意 | 即使遠端脈搏仍可觸及，仍可能存在血管損傷 |
| 建議 | 所有膝關節脫臼建議做 **CT 血管造影 (CTA)** |

#### 圖解要點
- 關節間隙明顯增寬
- 可見骨片
- 膕動靜脈完全創傷性阻塞

---

### 髕骨骨折 / Patellar Fracture

| 病因 | 骨折類型 |
|------|---------|
| 直接撞擊 | 通常為**粉碎性骨折** |
| 伸肌機制突然過度張力 | 通常為**分離性骨折 (Distracted Fracture)** |

#### 二分/多分裂髕骨 vs 骨折鑑別 / Bipartite/Multipartite Patella vs Fracture
| 特徵 | 二分/多分裂髕骨 | 骨折 |
|------|----------------|------|
| 邊緣 | **皮質化 (Well Corticated)** | 銳利、不規則 |
| 癒合方式 | 正常變異 | 創傷性 |

#### 髕骨正常變異 / Normal Variants
| 變異 | 表現 |
|------|------|
| **二分/多分裂髕骨** | 皮質化邊緣 |
| **髕骨背側缺損 (Dorsal Defect of Patella)** | 髕骨上關節面（背側）圓形透亮區 |

---

### 脛骨平台骨折 / Tibial Plateau Fracture

| 項目 | 說明 |
|------|------|
| 分類 | **Schatzker 分類** |
| 穩定性 | **外側平台骨折**比內側平台骨折**更穩定** |

### 臨床要點 / Clinical Key Points
1. **膝關節脫臼** = 前側最常見 + 高血管損傷風險 + CTA 建議
2. **髕骨分離性骨折** = 伸肌機制過度張力（如跳躍者腿）
3. **二分髕骨** = 皮質化邊緣（與骨折不規則邊緣鑑別）
4. **Schatzker 分類** = 脛骨平台骨折的標準分類
5. **內側平台骨折** = 比外側平台骨折更不穩定
