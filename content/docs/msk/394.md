## 骨髓炎術語 / Terminology of Osteomyelitis

| 術語 | 定義 |
|------|------|
| **骨髓炎 (Osteomyelitis)** | 骨骼（骨髓）感染 |
| **骨炎 (Osteitis)** | 皮質的發炎/感染 |
| **骨膜炎 (Periostitis)** | 骨膜的發炎/感染 |
| **死骨 (Sequestrum)** | 壞死骨片段，被肉芽組織與存活骨組織分開；需手術切除否則為復發感染巢穴 |
| **骨包殼 (Involucrum)** | 包繞壞死骨的存活骨質 |
| **骨包殼開口 (Cloaca)** | 骨包殼上的開口 |
| **竇道 (Sinus Tract)** | 感染通至皮膚表面的管道 |
| **Brodie 膿腫 (Brodie Abscess)** | 亞急性骨髓炎形式：中央低密度 + 周邊硬化；X 光上需與**骨樣骨瘤**鑑別 |

## 血源性骨髓炎 / Hematogenous Osteomyelitis

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 好發年齡 | 嬰兒及兒童 |
| 好發部位 | 長骨的**骨幹端 (Metaphysis)**（血流緩慢，有利細菌侵襲） |

### 年齡相關的侵犯模式 / Age-Specific Patterns of Infection Spread

| 年齡 | 感染傳播特徵 |
|------|-------------|
| **嬰兒 (< 12 個月)** | 感染可達骨幹端、骨骺及關節（因跨骺板血管橋接） |
| **較大兒童** | 感染通常侷限於**骨幹端**（血管不再跨骺板） |
| **成人** | 骺板已閉合，但血源性骨幹端感染不常見 |

### 解剖圖解

| 年齡 | 示意 |
|------|------|
| **嬰兒** | 血管**跨過**骺板 → 感染可達骨骺與關節 |
| **兒童** | 血管**不跨過**骺板 → 感染侷限於骨幹端 |
| **成人** | 骺板閉合 |

### 臨床要點 / Clinical Key Points
1. **死骨 (Sequestrum)** = 需手術切除的手術病灶（慢性感染復發源頭）
2. **Brodie 膿腫** = 亞急性骨髓炎 = X 光上需與骨樣骨瘤鑑別
3. **嬰兒骨髓炎**：感染可跨越骨骺板侵犯關節（因有跨板血管）
4. **兒童骨髓炎**：感染侷限於骨幹端（血管不跨板）
5. **骨膜下骨質吸收** = 甲狀旁腺功能亢進；**骨膜炎** = 骨膜感染
