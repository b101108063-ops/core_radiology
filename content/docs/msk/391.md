# Musculoskeletal Imaging - Page 391

![Page 391](/core_radiology/images/msk/page-391.png)

## 細胞來源不明病變 / Lesions of Unknown Cell Origin

### 良性：單純性骨囊腫 (SBC) / 單房性骨囊腫 (UBC) / Benign: Simple Bone Cyst (SBC) / Unicameral Bone Cyst (UBC)

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 兒童及青少年骨骼生長的**局部良性障礙**所致 |
| 囊腔特徵 | 空心或充滿液體 |
| 好發位置 | **肱骨或股骨近端骨幹**；亦可見於跟骨、髂骨、脛骨 |

#### 影像特徵 / Imaging Features
| 特徵 | 說明 |
|------|------|
| **位置** | **永遠位於骨骼中央 (Central)**（與 NOF 的偏心性不同） |
| **骨膜反應** | 無病理性骨折時**無骨膜反應**（與 ABC 不同） |
| **MRI** | 可見**液體層次 (Fluid-Fluid Levels)**（非特異性） |

#### 常見併發症 / Complications
| 併發症 | 說明 |
|--------|------|
| **病理性骨折** | 高達 **66%** 的病例 |
| **游離骨碎片徵 (Fallen Fragment Sign)** | 皮質骨折碎片掉入囊腔；為 SBC 的**病徵性表現**（年輕患者 + 典型位置） |

#### 治療 / Treatment
- **非手術治療**：囊內注射**甲基去炎松 (Methylprednisolone)** 可誘導骨質生成

---

### 良性：動靜脈畸形骨囊腫 (ABC) / Benign: Aneurysmal Bone Cyst (ABC)

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 兒童及青少年的**膨脹性多囊性病變**（「動靜脈畸形樣」） |
| 組織學 | 由充滿血液的竇道 (Sinusoids) 和實性纖維元素組成 |
| 重要特徵 | 可**續發於既有腫瘤**（切片時可能只取到 ABC 區域而漏掉真正腫瘤） |

#### ABC vs SBC 鑑別 / ABC vs SBC

| 特徵 | ABC | SBC |
|------|-----|-----|
| 位置 | 骨骼內任何位置（中心或偏心） | 永遠中心性 |
| 脊柱 | 可發生於脊柱後柱 | 少見 |
| 骨膜反應 | 常見「支撐狀 (Buttressing) 平滑骨膜反應」 | 無 |
| 液體層次 | 有 | 有 |

#### 治療 / Treatment
- 刮除術、切除術、或微創治療

---

### 惡性：釉質質瘤 / Malignant: Adamantinoma

| 項目 | 說明 |
|------|------|
| 定義 | 非常罕見的**低度惡性**腫瘤 |
| 好發位置 | **脛骨**（特徵性） |
| X 光特徵 | **肥皂泡樣 (Soap-bubble Appearance)** 外觀 |
| 鑑別診斷 | 與纖維結構不良**不易區分** |

### 臨床要點 / Clinical Key Points
1. **SBC** = 兒童 + 中心性 + 無骨膜反應 + 游離骨碎片徵（66% 病理性骨折）
2. **ABC** = 兒童/青少年 + 膨脹性多囊 + 任何位置（中心或偏心）+ 支撐狀骨膜反應
3. **ABC 可續發於既有腫瘤**：切片回報 ABC 時需警惕未發現的真正腫瘤
4. **液體層次** = 非特異性，可見於 ABC、SBC、巨細胞瘤、血管擴張型骨肉瘤
5. **Adamantinoma** = 脛骨 + 肥皂泡樣 + 低度惡性（與纖維結構不良鑑別困難）
