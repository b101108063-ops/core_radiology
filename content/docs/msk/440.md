# Musculoskeletal Imaging - Page 440

![Page 440](/core_radiology/images/msk/page-440.png)

## 缺血性壞死 / Avascular Necrosis (AVN)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 骨骺或軟骨下骨的局灶性缺血 |
| 後果 | 骨小樑壞死 → 應力骨折風險增加 → 若未治療，最終塌陷 → 續發性退化性關節炎 |
| 通用術語 | **骨壞死 (Osteonecrosis)** = 骨頭與骨髓壞死 |

### 股骨頭血供的特殊性 / Femoral Head Susceptibility
| 項目 | 說明 |
|------|------|
| 主要血供 | **旋股內側动脉**，進入股骨頸後發出後上骨骺分支，沿股骨頸走向供應股骨頭 |
| 受損風險 | 囊內骨折可破壞此血供 |

### AVN 病因 / Etiology
| 病因 | 說明 |
|------|------|
| **創傷性** | 囊內骨折（股骨頭/頸）；運動員的短暫性半脫位 |
| **非創傷性** | 通常為全身性：紅血球異常（鐮刀型）、骨髓填充異常（高雪氏症）、藥物（類固醇、酒精、移植後免疫抑制）|

#### 全身性原因的臨床提示
| 發現 | 可能的全身性原因 |
|------|----------------|
| **脾腫大 + AVN** | 高雪氏症 |
| **小鈣化脾臟 + AVN** | 鐮刀型紅血球疾病 |

### 好發位置 / Common Sites
| 排名 | 位置 |
|------|------|
| **最常見** | **近端股骨頭** |
| **第二常見** | **近端肱骨頭** |

### Ficat 分期 / Ficat Staging System (X 光)

| 分期 | X 光表現 | 治療 |
|------|---------|------|
| **Stage 1** | X 光正常；MRI 或骨掃描可見 AVN | 核心減壓 (Core Drilling) |
| **Stage 2** | 囊性變與硬化改變 | 同 Stage 1 |
| **Stage 3** | 軟骨下骨塌陷導致股骨頭失去正常球形；X 光可見**新月徵 (Crescent Sign)** | 治療多樣 |
| **Stage 4** | 股骨頭變扁平 + 續發性退化性關節炎 | 關節置換 |

### MRI 分類系統 / MRI Classification Systems
| 系統 | 說明 |
|------|------|
| **Modified Ficat 系統** | 臨床上更有用（考慮缺血導致塌陷的進展）|
| **Mitchell 系統** | 僅描述 MRI 信號變化 |

### AVN MRI 表現 / MRI Features of AVN
| 表現 | 說明 |
|------|------|
| **地理性軟骨下病變** | T1 上被蛇行低信號邊緣勾勒；典型位置：股骨頭前上側，冠狀影像上相當於 10-12 點方向 |
| **雙線徵 (Double Line Sign)** | T2 MRI 上可見；由周邊低信號邊緣 + 內部高信號帶組成；被認為是 AVN 的**特徵性病徵** |
| **骨髓水腫** | 50% 的病例可見；與疼痛臨床相關 |

### AVN 報告要素 / Complete AVN Description Should Include
| 要素 | 說明 |
|------|------|
| 塌陷的存在 | CT 最敏感，X 光次之 |
| T1 信號異常大小 | 以股骨頭受累區域百分比表示 |
| 髖臼續發性受累 | 有無 |

### 臨床要點 / Clinical Key Points
1. **AVN** = 股骨頭最常見；旋股內側动脉血供受損為主要機制
2. **雙線徵 (Double Line Sign)** = T2 上周邊低信號 + 內部高信號 = AVN 特徵性表現
3. **Ficat Stage III** = 新月徵 (Crescent Sign) = 軟骨下塌陷
4. **類固醇/酒精 + AVN** = 考慮非創傷性 AVN
5. **高雪氏症線索** = 脾腫大 + AVN；**鐮刀型** = 小鈣化脾臟 + AVN
