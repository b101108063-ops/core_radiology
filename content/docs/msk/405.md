# Musculoskeletal Imaging - Page 405

## 造血系統骨病 / Hematologic Bone Disease

## 鐮刀型紅血球疾病 / Sickle Cell Disease

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 遺傳方式 | 自體隱性遺傳；β-血紅蛋白鏈缺陷 |
| 病理 | 紅血球變形為鐮刀狀 → 微血管阻塞 |

### 骨骼三大表現 / Three Osseous Manifestations
| 表現 |
|------|
| 骨骼梗塞 (Bone Infarcts) |
| 骨髓炎風險**大幅增加**（約 100 倍）|
| 骨髓腔擴張/增生 (Marrow Expansion/Hyperplasia) |

### 鐮刀型紅血球骨骼梗塞 / Sickle Cell Bone Infarcts
| 併發症 | 說明 |
|--------|------|
| 梗塞/缺血性壞死 | 由於鐮刀狀紅血球造成微血管阻塞 |
| 椎體終板缺血性壞死 | 導致特徵性 **H 形/Lincoln-log 椎體** |
| 股骨頭缺血性壞死 | 常見（圖中雙側股骨頭變扁並硬化 = Ficat Stage IV）|

#### 鐮刀型紅血球指炎 (Dactylitis) / 手足症候群 (Hand-Foot Syndrome)
| 項目 | 說明 |
|------|------|
| 好發 | 幼童（手腳指持續有造血骨髓）|
| 誘發因素 | 寒冷加重的微血管阻塞 |
| X 光表現 | 軟組織腫脹 + 骨膜反應 |

### 鐮刀型紅血球骨髓炎 / Sickle Cell Osteomyelitis
| 項目 | 說明 |
|------|------|
| 風險 | 約 100 倍增加 |
| 最常見病原 | **沙門氏菌**（而非金黃色葡萄球菌）|

### 鐮刀型紅血球骨髓擴張 / Sickle Cell Marrow Expansion
| 部位 | X 光/MRI 表現 |
|------|-------------|
| MRI T1 | 瀰漫性低信號（反映瀰漫性紅（細胞性）骨髓）|
| 長骨 | 骨髓刺激 → 骨髓腔增寬 + 骨小樑粗大 → 骨質疏鬆 + 功能不全性骨折風險增加 |
| 顱骨 | 骨髓擴張 →「頭髮豎立」條紋 (Hair-on-End) + 骨髓腔增寬 |

### 臨床要點 / Clinical Key Points
1. **鐮刀型紅血球疾病** = 自體隱性 β-鏈缺陷 → 鐮刀狀紅血球 + 微血管阻塞
2. **H 形椎體** = 鐮刀型紅血球疾病/高雪氏症的椎體缺血性壞死特徵
3. **鐮刀型骨髓炎** = 沙門氏菌（而非葡萄球菌）— 100 倍風險增加
4. **Dactylitis** = 幼童鐮刀型紅血球疾病的手足症候群（寒冷誘發）
5. **T1 瀰漫性低信號** = 骨髓擴張（紅骨髓取代黃骨髓）
