## 類澱粉關節病 / Amyloid Arthropathy

### 疾病概述 / Disease Overview
- 罕見的非炎症性關節病
- **β-褶皺片層氨基酸**浸潤骨骼、關節和軟組織

### 相關疾病 / Associated Conditions

| 類型 | 相關疾病 |
|------|----------|
| 原發性全身性類澱粉沉積症 | 單株漿細胞病 |
| 續發性類澱粉沉積症 | 慢性發炎或感染 |
| 透析相關類澱粉沉積症 | 長期血液透析患者（β2-微球蛋白積聚） |

### 臨床特徵 / Clinical Features
- **肩墊徵 (Shoulder-Pad Sign)**：肩關節周圍巨大軟組織結節疊加於萎縮性肩部肌肉上

### 影像特徵 / Imaging Features
| 表現 | 說明 |
|------|------|
| 關節軟骨破壞 | 關節內沉積 |
| 軟組織結節 | |
| 侵蝕 | 可出現 |
| 特徵 | **非特異性；可類似 RA** |

## 褐黃病 (Ochronosis) / Ochronosis (Alkaptonuria)

### 疾病概述 / Disease Overview
- **黑尿病 (Alkaptonuria)** 的結締組織表現
- 發病機制：缺乏 homogentisic acid oxidase → homogentisic acid 聚合物積聚於內臟、椎間盤和關節

### 臨床特徵 / Clinical Features
- 尿液暴露於空氣中變黑

### 影像特徵 / Imaging Features
| 表現 | 說明 |
|------|------|
| **每個椎間盤水平都有椎間盤鈣化** | ochronosis 特異性表現 |
| 椎間隙狹窄 | 伴隨椎間盤鈣化 |

### 臨床要點 / Clinical Key Points
- **椎間盤廣泛鈣化** = ochronosis 的特異性表現

## 多中心性網狀組織球增多症 / Multicentric Reticulohistiocytosis

### 疾病概述 / Disease Overview
- 罕見疾病
- 含脂質的巨噬細胞沉積於軟組織和關節旁肌腱
- 形成**皮膚結節**和**邊緣硬化的侵蝕**

### 影像特徵 / Imaging Features

| 特點 | 說明 |
|------|------|
| **DIP 對稱性侵犯** | 特徵性表現 |
| 侵蝕邊界清楚、硬化 | |
| 軟組織結節 | |
| 骨質密度保持正常 | |
| 關節破壞可能快速進展 | 可呈現關節殘毀性關節炎 (Arthritis Mutilans) 表現 |

## 血友病性關節病 / Hemophilic Arthropathy

### 疾病概述 / Disease Overview
- **X 染色體隱性遺傳**
- 第 VIII 因子（血友病 A）或第 IX 因子（血友病 B/Christmas 病）缺乏 → 反覆出血

### 最常侵犯關節 / Common Sites
| 關節 | 說明 |
|------|------|
| **膝關節** | 最常見 |
| **肘關節** | |
| **踝關節** | |

### 發病機制 / Pathophysiology
| 過程 | 結果 |
|------|------|
| 反覆關節積血 | 滑膜肥厚 + 充血 |
| 充血 | 骨骼端增大 + 骨骺早閉 |

### 特徵性影像表現 / Characteristic Imaging Findings

| 部位 | 表現 |
|------|------|
| **肘關節** | 橈骨頭增大 + 滑車切跡增寬 |
| **膝關節** | 髕骨方化 + 髁間切跡增寬 |
| 關節周圍軟組織密度增加 | 滑膜含鐵血黃素沉積 |
| 關節間隙狹窄 | 續發性關節炎 |

### 血友病假腫瘤 / Pseudotumor of Hemophilia
| 特點 | 說明 |
|------|------|
| 性質 | 良性病變 |
| 病因 | 反覆骨內或骨膜下出血 |
| 影像特徵 | 骨質 scalloping（扇形壓跡）+ 壓迫性骨侵蝕 + 軟組織腫塊 |
| X 光特徵 | 邊界清楚、硬化 |
| MRI | 因不同階段血製品而呈複雜表現 |

### 鑑別診斷 / Differential Diagnosis
- 幼年型特發性關節炎 (JIA) 同樣可引起關節充血
- 膝關節：髁間切跡增寬
- 肘關節：橈骨頭增大
- 兩者表現相似

### 臨床要點 / Clinical Key Points
1. **類澱粉關節病**：肩墊徵 + 可類似 RA
2. **Ochronosis**：所有椎間盤皆有鈣化 = 特異性表現
3. **多中心性網狀組織球增多症**：DIP 對稱侵犯 + 邊緣硬化侵蝕 + 皮膚結節
4. **血友病**：橈骨頭增大（肘）+ 髕骨方化（膝）+ 髁間切跡增寬
5. **血友病假腫瘤**：反覆出血導致扇形骨質壓跡 + 軟組織腫塊
