---

### 距骨頸骨折 / Talar Neck Fracture

#### Hawkins 分類 / Hawkins Classification
| 分型 | 說明 |
|------|------|
| I 型 | 無移位 |
| II 型 | 移位 + 距下關節脫臼 |
| III 型 | 距骨體脫臼（踝 + 距下關節）|
| IV 型 | 距骨頭脫臼 |

#### 併發症 / Complication
- 距骨頸骨折可能**破壞距骨血供** → **缺血性壞死 (AVN)** 風險

---

### Hawkins 徵象 / Hawkins Sign

| 項目 | 說明 |
|------|------|
| 定義 | 踝關節固定後 **6-8 週**，前後位 X 光上出現的**軟骨下透亮帶** |
| 機制 | 主動性充血的骨質再吸收（代表血流供應存在）|
| 臨床意義 | **好的預後指標**：表示距骨圓頂血供完整 |
| 缺失意義 | 提示**缺血性壞死** |

### 距骨血供與預後總結 / Blood Supply Summary

| 發現 | 意義 |
|------|------|
| **Hawkins 徵象存在** | 血供完整 = 預後良好 |
| **Hawkins 徵象缺失** | 缺血性壞死風險高 |

### 臨床要點 / Clinical Key Points
1. **距骨頸骨折** = Hawkins 分類（I-IV 型）；血供破壞 → 缺血性壞死風險
2. **Hawkins 徵象** = 固定後 6-8 週出現軟骨下透亮帶 = 血供存在的標誌
3. **Hawkins 徵象缺失** = 缺血性壞死即將或已經發生
4. **距骨體從踝穴脫出** = III/IV 型損傷 → 極高缺血性壞死風險
5. **距骨骨折** = 最常見的骨折位置是**頸部**
