## 瀰漫性骨病 / Diffuse Bone Disease

## 骨質疏鬆症 / Osteoporosis

### 疾病定義 / Definition
| 項目 | 說明 |
|------|------|
| 定義 | **T 分數 (T-score) < -2.5** |
| T 分數意義 | 健康年輕女性平均骨密度低 **2.5 個標準差** |
| 參考標準 | Z 分數為與年齡匹配女性的標準差（不用於診斷骨質疏鬆）|

### 骨質疏鬆的病因分類 / Etiologic Classification

#### 維生素/營養缺乏 / Vitamin or Nutritional Deficiencies
| 病因 | 表現 |
|------|------|
| **軟骨病 (Osteomalacia)** | Looser zone（假骨折線）|
| 酒精中毒 | 骨質疏鬆 |
| **低磷酸酯酶症 (Hypophosphatasia)** | 骨質疏鬆 |
| **壞血病 (Scurvy)** | Wimberger sign |

#### 內分泌障礙 / Endocrine Disturbances
| 病因 | 表現 |
|------|------|
| **甲狀旁腺功能亢進** | 骨膜下骨質吸收 |
| **庫欣氏病 / 任何內源性/外源性類固醇增加** | 骨質疏鬆 |

#### 瀰漫性惡性腫瘤 / Diffuse Malignancy
| 病因 | 說明 |
|------|------|
| 多發性骨髓瘤 | 瀰漫性骨質脫礦 |

#### 遺傳性病因 / Genetic Causes
| 病因 | 說明 |
|------|------|
| **成骨不全 (Osteogenesis Imperfecta)** | 骨質疏鬆 |
| **高雪氏症 (Gaucher Disease)** | 骨質疏鬆 |
| **貧血**（鐮刀型、地中海型）| 骨髓擴張導致骨質疏鬆 |

### 局灶性骨質減少的病因 / Focal Osteopenia Etiologies
| 病因 |
|------|
| 固定不動/廢用 (Immobility/Disuse) |
| 反射性交感神經營養不良 (RSD/CRPS) |
| 暫時性髖關節區域骨質疏鬆 (Transient Regional Osteoporosis of the Hip) |

### 臨床要點 / Clinical Key Points
1. **T-score < -2.5** = 骨質疏鬆；T-score -1 為骨密度低於年輕女性平均值 1 SD
2. **軟骨病** = Looser zone（假骨折線）為特徵性表現
3. **Wimberger sign** = 壞血病的特徵（牙槽周圍骨質吸收）
4. **甲狀旁腺功能亢進 + 類固醇** = 骨質疏鬆的常見內分泌原因
5. **局灶性骨質疏鬆**：廢用、RSD、暫時性髖關節骨質疏鬆
