# 非創傷性脊椎異常 / Nontraumatic Abnormalities of the Spine

## 脊椎正常解剖 / Normal Spine Anatomy

### 椎骨 / Vertebral Body
- 每節椎骨由前方錐體（皮質骨+海綿骨+骨髓）及後方元素（椎弓根、板狀突、橫突、棘突）組成
- C3至L5椎體大致長方形，前後高度相等
- 相鄰椎體終板大致平行
- **椎弓根**：正位片上每節椎骨兩側各見一橢圓形陰影
- **Scottie Dog Sign**（斜位片）：腰椎斜位投影時，各結構模擬蘇格蘭爹利犬輪廓，耳=上關節突，腿=下關節突，鼻=橫突，眼=椎弓根，頸=椎弓峽部（pars interarticularis）

### 椎間盤 / Intervertebral Disks
- **組成**：中央膠凍狀髓核（nucleus pulposus）+外層纖維環（annulus fibrosus，含內纖維軟骨+外軟骨纖維/Sharpey fibers）
- 髓核位於椎間盤後側區域

### 脊椎韌帶 / TABLE 22.1 Ligaments of the Spine
| 韌帶 | 連接 |
|------|------|
| 前縱韌帶 | 椎體前方 |
| 後縱韌帶 | 椎體後方 |
| 黃韌帶 | 相鄰椎骨板狀突，位於椎管後方 |
| 棘間韌帶 | 棘突之間 |
| 棘上韌帶 | 棘突尖端 |

### 脊椎正常MRI信號
- **T1加權**：椎體（含骨髓）呈高信號；椎間盤低信號；腦脊髓液（CSF）低信號（暗）；皮質骨低信號
- **T2加權**：椎間盤稍高於椎體；CSF高信號（亮）；皮質骨低信號

## 腰痛概論 / Back Pain Overview

**80%美國人一生中會經歷某種腰痛**
常見病因：椎間盤突出、椎間盤退化、關節炎、椎管狹窄、骨質疏鬆壓迫骨折、脊椎骨髓炎、轉移性腫瘤、創傷

---

## 椎間盤突出 / Herniated Disks
- **定義**：椎間盤向後或後外側突出，壓迫神經根
- **好發部位**：頸椎C4-C5、C5-C6、C6-C7；腰椎L3-L4、L4-L5（最常見）、L5-S1
- **後外側突出**（最常見，>60%）：決定臨床症狀（神經根受壓）
- **MRI為首選檢查**；CT可見椎間盤物質壓迫神經根或硬膜囊
- **MRI T2**：脫出之椎間盤物質為低信號局限性突出，超出纖維環範圍
- **椎間盤脫出類型**：
  - **突出（Protrusion）**：仍與母盤相連
  - **脫出（Extrusion）**：完全脫離母盤
  - **後峽部修補症候群（Postlaminectomy Syndrome）**：術後持續疼痛

---

## 椎間盤退化性疾病 / Degenerative Disk Disease (DDD)
- **機制**：年齡增長→髓核脫水退化→椎間盤高度逐漸喪失
- **真空椎間盤現象（Vacuum Disk Phenomenon）**：退化時組織釋放氮氣，椎間盤內見氣體密度
- **X光特點**：椎間盤狹窄；終板緻密化（eburnation）；邊緣骨贅
- **MRI T2特點**：脫水椎間盤信號降低（變暗）

---

## 關節突關節退化 / Osteoarthritis of Facet Joints
- **定義**：關節突關節為真關節（含軟骨、滑膜、滑液），會發生退化性關節炎
- **頸椎**：鈎突關節（uncovertebral joints/Luschka joints）為骨贅常見部位，可侵入神經孔
- **腰椎**：關節突關節炎可致神經孔狹窄
- **X光特點**：關節間隙狹窄、軟骨下硬化

---

## 椎弓峽部裂與脊椎滑脫 / Spondylolysis and Spondylolisthesis

### 椎弓峽部裂 / Spondylolysis
- **定義**：單側或雙側**椎弓峽部（pars interarticularis）**骨折
- **好發部位**：L5-S1
- **病因**：主要為重複性微創傷（非急性外傷）

### 脊椎滑脫 / Spondylolisthesis
- **定義**：雙側峽部裂→一節椎骨向前滑脫於下一節之上（L5於S1最常見）
- **分型**：
  - **峽部性脊椎滑脫（Spondylolytic）**：因峽部裂所致
  - **退化性脊椎滑脫（Degenerative）**：無峽部裂，因關節突關節炎導致，多見於女性
- **前移（Anterolisthesis）**：向前滑脫；**後移（Retrolisthesis）**：向後滑脫
- **臨床**：大多數無症狀，最常見症狀為腰痛

---

## 瀰漫性特發性骨骼骨質增生 / Diffuse Idiopathic Skeletal Hyperostosis (DISH)
- **定義**：韌帶附著處（entheses）形成骨質/鈣化'excrescences'，為附著點病（enthesopathy）之一
- **好發**：50歲以上男性；胸椎下段及頸椎最常見
- **影像特點**：
  - **連續至少4節椎骨**前方或前外側之厚實橋接鈣化/骨化（前縱韌帶）
  - 骨化與椎體間有細小間隙
  - **椎間盤及關節突關節通常保留**（與僵直性脊椎炎鑑別要點）
- **後縱韌帶骨化（OPLL）**：可致頸椎椎管狹窄、脊髓壓迫；CT/MRI顯示更佳

---

## 脊椎壓迫骨折 / Compression Fractures of the Spine
- **病因**：骨質疏鬆（最常見）；女性多於男性
- **好發部位**：胸椎中段及上腰椎
- **影像特點**：
  - **以前上方及上方終板為主**，後方結構通常保留
  - 同一椎體**前後高度差>3mm**或**高度較相鄰椎體減少>20%**
  - **楔形變形**→胸椎後凸加劇（所謂「Dowager's hump」）
- **臨床**：通常無神經功能缺損（因骨折位於椎體前部，遠離脊髓）
- **MRI**：可鑑別骨質疏鬆性與腫瘤性骨折

---

## 椎管狹窄 / Spinal Stenosis
- **定義**：椎管或神經孔因軟組織或骨質異常而變狹窄，可為先天性或後天性
- **後天性病因**：
  - 軟組織：黃韌帶肥厚、椎間盤突出、後縱韌帶骨化（OPLL）
  - 骨質：先天性椎管窄、骨疣、關節突關節炎、脊椎滑脫
- **好發部位**：頸椎及腰椎
- **症狀**：神經根疼痛、脊髓病變；腰椎區域可致**神經性跛行（Neurogenic Claudication）**（步行時疼痛加劇，屈曲時緩解）

**影像特點**
: - X光：椎管前後徑≤10mm；CT為骨質評估最佳；**MRI為首選**（軟組織因素）
: - 黃韌帶肥厚+骨質增生→椎管容量減少

---

## 脊椎惡性腫瘤 / Malignancy Involving the Spine
- **概述**：骨骼轉移比原發性骨腫瘤常見25倍；80%發生於中軸骨骼（脊椎、骨盆、顱骨、肋骨）
- **椎體轉移**：好發於椎體後方（血供豐富）；可致整個椎體包括椎弓根破壞
- **骨質疏鬆vs.轉移性骨折**：轉移性骨折通常破壞整個椎體包括椎弓根；骨質疏鬆性骨折則保留後方結構
- **成骨性轉移**：前列腺癌（男）、乳癌（女）
- **溶骨性轉移**：肺癌、乳癌、甲狀腺癌、腎細胞癌
- **多發性骨髓瘤**：最常見原發性骨腫瘤；可致嚴重骨質疏鬆或多發壓迫骨折

**影像檢查首選**
: - **核醫Tc-99m MDP骨掃描**：全身篩查，靈敏度高但特異性低
: - **MRI**：最早偵測骨轉移；T1低信號（相對於正常高信號骨髓），T2高信號

---

## 椎間盤炎/脊椎骨髓炎 / Diskitis/Osteomyelitis of the Spine
- **病因**：幾乎皆伴鄰近椎骨骨髓炎；血行播散（泌尿路或軟組織感染）；**腰椎最常見**；金黃色葡萄球菌最常見
- **兒童vs.成人**：兒童先累及椎間盤再蔓延至椎骨；成人先累及椎骨再蔓延至椎間盤
- **X光特點**（數週至數月才出現）：椎間盤狹窄、相鄰椎骨終板不規則
- **確診**：CT（敏感性高，可見椎旁膿腫）；**MRI最敏感**（T1：終板低信號；T2/STIR：高信號）

---

## 僵直性脊椎炎 / Ankylosing Spondylitis
- **定義**：慢性進行性關節炎，特点为骶髂关节及脊椎关节突关节融合+椎旁软组织受累
- **特點**：年輕男性多見；從骶髂關節開始**上行性**侵犯（骶髂→腰椎→胸椎→頸椎）
- **實驗室**：幾乎全部患者HLA-B27阳性（一般人群約5-10%）
- **本質為附著點病（enthesopathy）**：韌帶/關節囊附著處發炎→鈣化→骨化

**影像特點**
: - **骶髂關節炎為標誌**：雙側對稱，最終導致骨性融合（ankylosis），關節間隙變薄白線或完全消失
: - **脊椎骨化（Syndesmophytes）**：纖維環外層骨化，產生連接相鄰椎骨的薄骨橋
: - **竹竿脊柱（Bamboo Spine）**：進行性syndesmophyte形成，模擬竹竿外觀

---

## 臨床要點 / Clinical Key Points

1. **MRI為脊椎疾病首選檢查**（軟組織分辨力最優）
2. **椎間盤突出**：好發L4-L5及L5-S1（>60%後外側）；MRI首選
3. **椎間盤退化**：髓核脫水→椎間盤高度喪失+邊緣骨贅；真空椎間盤現象為晚期表現
4. **關節突關節炎**：常與椎間盤退化共存；可致神經孔狹窄
5. **椎弓峽部裂**：單/雙側pars骨折；雙側→脊椎滑脫
6. **DISH**：≥4節連續椎骨前方韌帶骨化；椎間盤及關節突關節通常保留
7. **骨質疏鬆性壓迫骨折**：以前上方終板為主；後方結構保留；無神經缺損
8. **椎管狹窄**：後天性比先天性常見；神經性跛行為典型症狀；MRI首選
9. **脊椎轉移**：80%位於中軸骨；前列腺癌（成骨）、肺癌/乳癌（溶骨）；椎弓根破壞有提示意義
10. **多發性骨髓瘤**：最常見原發性骨腫瘤；可致骨質疏鬆或溶骨性破壞
11. **椎間盤炎/骨髓炎**：腰痛+椎間盤狹窄+終板破壞；MRI最敏感
12. **僵直性脊椎炎**：HLA-B27(+)；骶髂關節炎（雙側對稱）為標誌；上行性侵犯脊椎；竹竿脊柱
