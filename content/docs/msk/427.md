# Musculoskeletal Imaging - Page 427

![Page 427](/core_radiology/images/msk/page-427.png)

## ACL 損傷（續）/ ACL Injury (Continued)

### ACL 損傷的次級發現 / Secondary Findings of ACL Injury

| 發現 | 說明 |
|------|------|
| **特徵性骨挫傷型態** | 外側股骨髁 + 後外側脛骨平台的骨髓水腫（高度提示 ACL 損傷）|
| **PCL 二次屈曲 (Buckling)** | 脛骨前移位導致 PCL 彎曲（陽性 Drawer 徵）|

### Segond 骨折 / Segond Fracture
| 項目 | 說明 |
|------|------|
| 定義 | 脛骨平台外側的**撕脫骨折** |
| 相關損傷 | 與 **ACL 損傷**及**髂脛束 (IT Band) 損傷**相關 |
| IT Band 附著點 | Gerdy's Tubercle（脛骨近端外側）|
| 病理基礎 | 被認為是**外側關節囊韌帶**的剝離 |

#### 重要臨床提醒
- Segond 骨折在 X 光上**容易被忽略**，但診斷意義重大
- 一旦發現，建議安排 **MRI**

### 臨床要點 / Clinical Key Points
1. **外側股骨髁 + 後外側脛骨平台骨髓水腫** = ACL 損傷的特徵性次級發現
2. **Segond 骨折** = 脛骨平台外側撕脫 = ACL + IT Band 損傷的標誌
3. **Segond 骨折 X 光容易漏診** → 建議 MRI
4. **PCL Buckling** = 陽性 Drawer 徵（脛骨前移）
5. **ACL 重建後復健進度** → 監測移植韌帶走向（避免過陡或過鬆）
