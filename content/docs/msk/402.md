# Musculoskeletal Imaging - Page 402

![Page 402](/core_radiology/images/msk/page-402.png)

## 腎性骨營養不良 / Renal Osteodystrophy

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 病因 | 維生素 D 代謝異常（軟骨病）+ 長期腎衰竭的**續發性甲狀旁腺功能亢進**共同作用 |
| 與單純軟骨病不同 | **Looser Zone 在腎性骨營養不良中並不常見** |

### 特異性 X 光表現 / Characteristic Findings
| 發現 | 說明 |
|------|------|
| **Rugger Jersey Spine** | 椎體終板硬化（交替性硬化/溶骨帶）|
| 軟組織/血管鈣化 | 常見 |
| 骨膜下骨質吸收 | 與續發性甲狀旁腺功能亢進一致 |

### 腎衰竭的其他骨骼併發症 / Additional Bone Disorders in Renal Failure
| 併發症 | 說明 |
|--------|------|
| 骨髓炎 | 感染風險增加 |
| 缺血性壞死 | 若使用類固醇則風險增加 |
| 澱粉樣變性 | 慢性透析相關 |

## 甲狀腺/甲狀旁腺相關疾病 / Thyroid/Parathyroid Related Disorders

### 甲狀腺功能低下 / Hypothyroidism
| 項目 | 說明 |
|------|------|
| 兒童表現 | 骨骼及牙齒成熟延遲 |
| 特異性表現 | 子彈形椎體 (Bullet-shaped Vertebral Bodies)、顱骨 Wormian Bones |
| 關聯 | **股骨頭骨骺滑脫 (SCFE)** |

### 甲狀旁腺功能低下 / Hypoparathyroidism
| 項目 | 說明 |
|------|------|
| 最常見原因 | 甲狀旁腺切除術後（治療甲狀旁腺功能亢進）|
| 發病機制 | 甲狀旁腺素不足 → 鈣質沉積失調 |
| 沉積部位 | 皮下組織及基底核 |

---

### 偽副甲狀腺功能低下 / 偽-偽副甲狀腺功能低下 / Pseudohypoparathyroidism & Pseudo-Pseudohypoparathyroidism

| 項目 | 偽副甲狀腺功能低下 | 偽-偽副甲狀腺功能低下 |
|------|-------------------|---------------------|
| PTH 受體 | 缺陷 | 正常 |
| PTH 水準 | 升高 | 正常 |
| 臨床表徵 | 相同（肥胖、圓臉、矮小、短指）| 相同 |

#### 特異性 X 光發現 / Characteristic Radiographic Finding
| 發現 | 說明 |
|------|------|
| **第四或第五掌骨縮短** | 診斷要點 |
| 第四掌骨縮短的鑑別診斷 | Turner 症候群 |

---

### 甲狀腺功能亢進 / Hyperthyroidism
| 項目 | 說明 |
|------|------|
| 對兒童影響 | 骨骼成熟加速 |
| 甲狀腺性杵狀指 (Thyroid Acropachy) | 罕見；表現為多骨（中軸/手/足的掌骨、蹠骨、指骨）**骨幹的骨膜反應**；見於已治療的甲狀腺功能亢進 |

### 臨床要點 / Clinical Key Points
1. **Rugger Jersey Spine** = 腎性骨營養不良（終板硬化，與佩吉氏病的椎框椎體不同）
2. **第四/第五掌骨縮短** = 偽副甲狀腺功能低下（與 Turner 症候群鑑別）
3. **甲狀腺功能低下** = 子彈形椎體 + Wormian Bones + SCFE
4. **甲狀腺性杵狀指** = 已治療的甲狀腺功能亢進 + 骨膜反應
5. **甲狀旁腺功能低下** = 術後或自發性 → 皮下鈣化、基底核鈣化
