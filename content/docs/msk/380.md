# Musculoskeletal Imaging - Page 380

![Page 380](/core_radiology/images/msk/page-380.png)

## 軟骨形成性病變 / Cartilage-Forming (Chondro-) Lesions

### 良性：滑膜軟骨瘤病/骨軟骨瘤病 / Benign: Synovial Chondromatosis / Osteochondromatosis

| 特徵 | 說明 |
|------|------|
| 性質 | **非腫瘤性滑膜化生**，關節內形成分葉狀軟骨結節（可骨化或否） |
| 通常為 | 單關節病變 |
| 好發位置 | **膝關節**最常見；肩關節、髖關節、肘關節亦可發生 |
| 臨床表現 | 關節內結節可造成**機械性侵蝕**及**續發性退化性關節炎** |
| 骨化時 | 稱為「骨軟骨瘤病」(Osteochondromatosis) |

### 影像診斷要點 / Imaging Features

| 檢查 | 表現 |
|------|------|
| **X 光** | 關節內多發大小相近的圓形游離體，可有程度不一的礦化 |
| **MRI** | 取決於骨化程度與軟骨基質；已礦化或骨化時：多發低信號球形/圓形病灶 |
| **CT** | 確認礦化型態最佳工具 |

### 鑑別診斷 / Differential Diagnosis

| 病變 | 鑑別點 |
|------|--------|
| **退化性關節炎游離體** | 數量少、大小形狀多變；滑膜軟骨瘤病：數量多、大小均勻 |
| **色素沉著絨毛結節性滑膜炎 (PVNS)** | MRI 上皆可見多發關節內低信號灶，X 光可區分：PVNS 無鈣化，滑膜軟骨瘤病有圓形鈣化體 |

### 臨床要點 / Clinical Key Points
1. **滑膜軟骨瘤病** = 單關節 + 多發均勻大小圓形游離體（沿關節滑膜分布）
2. **關節周軟骨內及黏液囊**：肩關節常沿**肱二頭肌長頭肌腱鞘**分布
3. **X 光可區分**：滑膜軟骨瘤病（鈣化游離體）vs PVNS（無鈣化）
4. **MRI 侷限**：多發關節內低信號灶為非特異性，需結合 X 光確診
5. **罕見惡性變**：可由滑膜軟骨瘤病惡化為軟骨肉瘤
