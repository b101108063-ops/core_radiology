# Musculoskeletal Imaging - Page 455

![Page 455](/core_radiology/images/msk/page-455.png)

## 粘連性關節囊炎 / Adhesive Capsulitis

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 臨床名稱 | 五十肩 (Frozen Shoulder) |
| 病理 | 關節囊和滑膜的發炎導致增厚和攣縮 |
| 診斷 | 主要為臨床診斷 |
| MRI 表現 | 關節囊和滑膜增厚 > **4 mm**（在腋下窩水平評估）|

---

## 肩關節韌帶與旋轉間隙 / Shoulder Ligaments and Rotator Interval

### 旋轉間隙解剖 / Anatomy of the Rotator Interval
| 項目 | 說明 |
|------|------|
| 位置 | 岡上肌與肩胛下肌肌腱之間的三角形區域 |
| 包含結構 | 喙肱韌帶 (CHL)、二頭肌長頭 (LHBT)、上關節盂韌帶 (SGHL) |

### 喙肱韌帶 (CHL) / Coracohumeral Ligament
| 項目 | 說明 |
|------|------|
| 起點 | 喙突外側面 |
| 終點 | 肱骨大結節（與岡上肌腱混合）|
| 功能 | 與 SGHL 共同構成二頭肌滑輪，穩定關節內二頭肌腱；位於關節囊外 |

---

### 肩關節盂韌帶 / Glenohumeral Ligaments (GHL)

| 韌帶 | 起點 | 終點 | 特點 |
|------|------|------|------|
| **上 (SGHL)** | 肩胛上結節 | 小結節 | — |
| **中 (MGHL)** | 肩胛上結節 | 小結節 | 1/3 患者先天缺失；撕裂與上方唇緣撕裂相關 |
| **下 (IGHL)** | 關節盂下唇 | 肱骨解剖頸 | **最重要的穩定結構**（外展+外旋時）；矢狀切片可清楚看到三個組成 |

#### IGHL 三個組成 / IGHL Components (Sagittal View)
| 組成 | 功能 |
|------|------|
| **前束 (Anterior Band)** | 提供前側穩定性 |
| **腋下窩 (Axillary Pouch)** | 關節囊組成 |
| **後束 (Posterior Band)** | 提供後側穩定性；IGHL 是唯一有後側成分的 GHL |

### 二頭肌長頭附著 / Long Head Biceps Tendon Attachment
- 與 SGHL、MGHL 共同附著於前上方關節唇緣

### 臨床要點 / Clinical Key Points
1. **粘連性關節囊炎** = 五十肩 = 關節囊增厚 > 4 mm（MRI）
2. **旋轉間隙** = 岡上肌與肩胛下肌之間的三角形區域（包含 CHL、LHBT、SGHL）
3. **IGHL** = 維持外展+外旋穩定性的最重要結構
4. **GHL 由唇緣衍生**，構成關節囊的一部分
5. **MGHL** = 1/3 患者先天缺失
