# Musculoskeletal Imaging - Page 403

![Page 403](/core_radiology/images/msk/page-403.png)

## 特發性骨病 / Idiopathic Bone Disease

## 佩吉氏病 / Paget Disease

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 老年人可見的進行性骨質吸收與形成的調節障礙 |
| 發病率 | 80 歲以上患者可達 10%；40 歲以下罕見 |
| 病因 | 未明（可能與副黏液病毒有關）|

### 臨床症狀 / Clinical Symptoms
| 症狀 | 說明 |
|------|------|
| 骨疼痛 | 常見 |
| 骨骼增大/彎曲 | 骨質增大與變形 |
| 顱神經壓迫 | 壓迫症狀 |
| 高輸出性心臟衰竭 | 骨骼血流增加 |

### 好發部位 / Distribution
| 優先順序 | 部位 |
|---------|------|
| 最常見 | **顱骨、脊椎、骨盆** |
| 其次 | 股骨近端、脛骨近端、肱骨近端 |
| 少見 | 肋骨、肩胛骨 |

### 三個病理階段 / Three Sequential Phases

| 階段 | 特徵 |
|------|------|
| **Phase I：溶骨期** | 蝕骨細胞活化 → 活躍骨質吸收 |
| **Phase II：混合期** | 持續骨質吸收 + 新骨形成 |
| **Phase III：硬化期** | 以骨質密度增加和硬化為主 |

### 佩吉氏病慢性期表現 / Chronic Paget Features
| 發現 | 說明 |
|------|------|
| 皮質增厚 | 骨皮質變厚 |
| 粗大不規則骨小樑 | 粗大、紊乱的骨小樑 |
| 骨骼膨大 | 骨骼增寬 |
| 俗稱 | 正常骨骼的「漫畫版」(Caricature of Normal Bone) |

### 各部位特徵性表現 / Location-Specific Findings

#### 顱骨 (Skull)
| 階段 | 表現 |
|------|------|
| **溶骨期 (Phase I)** | 地圖樣溶骨區 = **局限性骨質疏鬆 (Osteoporosis Circumscripta)** |
| **混合期 (Phase II)** | **棉絮顱骨 (Cotton Wool Skull)**：像用棉花棒沾顏料塗抹的結果 |

#### 椎體 (Vertebral Bodies)
| 階段 | 表現 |
|------|------|
| **混合期** | **椎框椎體 (Picture Frame Vertebral Body)**：椎體周邊密度增加（與腎性骨營養不良的 Rugger Jersey 不同） |
| 硬化期 | **象牙椎 (Ivory Vertebral Body)**：彌漫性硬化 |

#### 骨盆 (Pelvis)
| 發現 | 說明 |
|------|------|
| 不對稱粗大骨小樑增厚 |  特徵 |
| **髂恥線、髂坐骨線增厚** |  特徵 |
| **髖臼前突 (Acetabular Protrusio)** | 可能發生 |

### 併發症 / Complications
| 併發症 | 說明 |
|--------|------|
| 病理性骨折 | 常見 |
| 惡性變（最常見：骨肉瘤）| 需警惕 |
| 續發性巨細胞瘤 | 可能 |
| 續發性退化性關節炎 | 軟骨下骨質脆弱 |

### 臨床要點 / Clinical Key Points
1. **佩吉氏病** = 老年人 + 骨質增大/彎曲 + 顱骨/脊椎/骨盆優先侵犯
2. **三階段**：溶骨期 → 混合期 → 硬化期（可重疊，不一定按順序）
3. **棉絮顱骨** = 佩吉氏病顱骨混合期的特徵
4. **椎框椎體** = 佩吉氏病（周邊硬化）vs Rugger Jersey（終板硬化）
5. **骨肉瘤** = 佩吉氏病最常見的惡性變併發症
