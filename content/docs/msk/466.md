# 骨骼創傷 / Trauma to the Bony Skeleton

## 急性骨折辨識 / Recognizing an Acute Fracture

### 骨折定義
- **骨折（Fracture）**：骨皮質連續性中斷
- **完全骨折**：皮質全層斷裂（成人多見）
- **不完全骨折**：僅部分皮質斷裂（兒童骨骼較軟，常見於骨軟化成人）
  - **柳枝骨折（Greenstick Fracture）**：僅累及一側皮質，未完全斷裂
  - ** Torus/Buckle骨折**：皮質受壓縮而鼓起

### 骨折線特點
- 骨折線比其他骨內線條（如營養管）**更黑（更低密度）**
- 皮質驟然中断
- 骨折線通常較直，但轉彎處角度比生長板更尖銳
- 骨折邊緣常不規則

### 診斷陷阱（TABLE 23.1）
| 結構 | 與急性骨折鑑別要點 |
|------|------------------|
| **籽骨（Sesamoids）** | 肌腱內生成，關節周圍；完全被皮質包繞；雙側對稱 |
| **副小骨（Accessory Ossicles）** | 附屬骨骺/骨突骨化中心未融合；雙側對稱 |
| **骨突（Apophyses）** | 為生長中心，肌腱附著處；未融合前可模擬骨折 |
| **未癒合骨折碎片** | 無皮質包繞；雙側不對稱 |

## 脫位與半脫位 / Dislocations and Subluxations
- **脫位（Dislocation）**：構成關節的兩骨不再接觸
- **半脫位（Subluxation）**：構成關節的兩骨部分接觸

## 骨折描述 / Describing Fractures

### 碎片數量（TABLE 23.2）
| 類型 | 定義 |
|------|------|
| **簡單骨折（Simple）** | 兩碎片 |
| **粉碎骨折（Comminuted）** | >2碎片 |
| **節段骨折（Segmental）** | 游離骨段夾於兩骨折端之間 |
| **蝴蝶骨片（Butterfly Fragment）** | 中央碎片呈三角形之粉碎骨折 |

### 骨折線方向（TABLE 23.3）
| 方向 | 機制 |
|------|------|
| **橫向（Transverse）** | 力垂直於骨長軸 |
| **斜向/對角線（Diagonal/Oblique）** | 力沿骨長軸方向 |
| **螺旋形（Spiral）** | 扭力/扭矩（常伴韌帶/肌腱損傷）|

### 碎片空間關係（四大參數）
1. **移位（Displacement）**：遠折段相對於近折段的偏移
2. **成角（Angulation）**：遠折段與近折段之夾角
3. **短縮/分離（Shortening/Distraction）**：短縮=重疊；分離=骨端分開
4. **旋轉（Rotation）**：長骨骨折時，近端關節與遠端關節朝向不同

### 與大氣相通與否
- **閉合性骨折（Closed）**：骨折端與外界不相通
- **開放性/複合骨折（Open/Compound）**：骨折與外界相通（骨片段穿透皮膚）

## 撕脫骨折 / Avulsion Fractures
- **機制**：肌腱或韌帶用力收縮，將附著處骨片撕離
- **好發人群**：年輕運動員
- **好發部位（TABLE 23.4 骨盆撕脫骨折）**：
  - 髂前上棘（ASIS）→縫匠肌
  - 髂前下棘（AIIS）→股直肌
  - 坐骨結節→膕繩肌
  - 股骨小粗隆→髂腰肌
- **癒合**：可產生大量骨痂（exuberant callus），類似腫瘤

## 疲勞/應力骨折 / Stress Fractures
- **機制**：反覆微骨折累積，最終導致骨折
- **特點**：X光片**初期可達85%正常**（數天至數週後才出現骨膜新骨或骨痂）
- **診斷**：MRI最敏感（立即可見）；核醫骨掃描6-72小時內陽性；CT敏感性最低
- **好發部位**：股骨近端、脛骨近端、跟骨、第二/三蹠骨（行軍骨折/March fracture）

## 常見骨折 eponyms

### Colles骨折
- **定義**：橈骨遠端骨折，**背側成角**，跌倒時伸手撐地（FOOSH）所致
- 常伴尺骨莖突骨折

### Smith骨折
- **定義**：橈骨遠端骨折，**掌側成角**（Colles反轉型），跌倒時手背著地

### Jones骨折
- **定義**：第五蹠骨基底約2cm處**橫向骨折**，踝關節蹠屈+內翻受傷
- 癒合時間可較長（血供較差區域）

### Boxer骨折
- **定義**：第五掌骨頸骨折，**掌側成角**，通常因撞擊（打架/牆壁）

### March骨折
- **定義**：第二/三蹠骨之應力/疲勞骨折

### Lisfranc骨折-脫位
- **定義**：中足關節（第一至第五蹠骨與對應楔骨/骰骨之間）的脫位或骨折-脫位
- **特點**：可為隱匿性（X光可正常），需CT/MRI確診

## 隱匿骨折提示 / Subtle Fractures to Look For

### 舟骨（Scaphoid/Navicular）骨折
- **臨床**：鼻煙窩（anatomic snuffbox）壓痛+跌倒伸手撐地
- **特點**：X光可為陰性（需反覆檢查或MRI）
- **缺血性壞死風險**：腰部（waist）骨折可阻斷近端血供→近端骨頭缺血性壞死（相對密度增加）

### 橈骨頭骨折
- **成人肘關節最常見骨折**
- **後方脂肪墊徵（Positive Posterior Fat-pad Sign）**：外傷性關節積液時，屈肘側位片可見肱骨背側脂肪墊被推移呈月牙形透亮線

### 兒童肱骨髁上骨折（Supracondylar Fracture）
- **兒童肘關節最常見骨折**
- **前臂骨線（Anterior Humeral Line）**：側位片上此線應通過肱骨小頭中1/3；骨折時此線位置異常
- 可伴**後方脂肪墊徵**

### 肩關節脫位
- **前脫位**（更常見）：肱骨頭位於肩胛盂前下方
- **後脫位**：肱骨頭固定於內旋位，各投照位均似「燈泡」；Y位片可確認肱骨頭位於肩峰下方

### 老年人髖部骨折
- **股骨頸骨折**：股骨頭與股骨頸交界處
- **X光技巧**：患側下肢內旋位投照以顯示股骨頸
- **特點**：皮質階梯样中斷；撞擊時可見骨質密度增加（撞擊區）

| 徵象 | 說明 |
|------|------|

| 骨膜反應 | 有時為骨折癒合時才首次發現 |

## 骨折癒合 / Fracture Healing

### 癒合階段
1. **初期（立即）**：骨折處血腫形成
2. **數週**：噬骨細胞移除壞死骨，骨折線輕度增寬
3. **數週至數月**：新骨（骨痂）開始橋接骨折間隙
4. **8-12週後**：骨重塑（remodeling），機械力逐漸恢復骨骼原有形狀

### 癒合類型
- **內骨痂（Endosteal/Internal healing）**：骨折線逐漸模糊至消失
- **外骨痂（Periosteal/External healing）**：外骨痂形成，橋接骨折處

### 影響癒合因素
| 加速癒合 | 延遲癒合 |
|---------|---------|
| 年輕 | 高齡 |
| 早期制動 | 制動延遲 |
| 制動時間充足 | 制動時間不足 |
| 良好血供 | 血供差 |
| 適當礦化 | 類固醇、骨質疏鬆、骨軟化 |

### 癒合併發症
- **延遲癒合（Delayed Union）**：癒合時間超出預期
- **畸形癒合（Malunion）**：癒合位置機械性或美容上不可接受
- **骨不連（Nonunion）**：骨折線光滑、硬化，骨端分離；可形成假關節（pseudarthrosis，含滑膜）

## 脊椎創傷 / Spinal Trauma

### 概述
- 脊椎骨折比四肢骨折少見，但因可能伴脊髓損傷而後果嚴重
- **CT已替代傳統X光**成為脊椎創傷首選檢查（可多平面重建）
- **胸腰椎最常見**：L1、L2、T12佔所有胸腰椎骨折>50%
- **最常見類型**：壓迫骨折

### 三條頸椎線（Three Cervical Lines）
- 側位片上，三條平滑弧線應相連續：
  1. **最前方線**：所有椎體前緣連線
  2. **中間線**：所有椎體後緣連線
  3. **最後方線**：所有椎板與棘突交界處連線
- 任何偏離應懷疑半脫位或骨折

### Jefferson骨折（C1）
- **機制**：軸向負荷（如跳水撞擊池底）
- **骨折**：C1前弓及後弓（經典為4處骨折）
- **X光特點**（张口位）：C1側塊相對於C2**雙側側向偏移**
- **CT**：確診
- **特點**：為自我減壓性骨折（椎管寬度足夠），通常無神經缺損

### Hangman's骨折（C2後方元素）
- **機制**：過伸-壓縮損傷（如車禍時前額撞擊擋風玻璃，頸部過伸）
- **骨折**：C2後方元素（椎弓峽部）
- **特點**：骨折將C2椎體後部與前部分離，前部可向前滑脫於C3上
- **臨床**：通常無神經缺損（與頸部懸吊損傷不同）

### Burst骨折
- **機制**：高能量軸向負荷（車禍、跌落）
- **好發**：頸椎、胸椎、上腰椎
- **機制**：上位椎間盤撞入下位椎體→椎體爆裂；骨碎片向後打入椎管
- **特點**：後縱韌帶常完整；多伴神經功能缺損（骨片侵入椎管）
- **確診**：CT（顯示骨片在椎管內最佳）

### Chance骨折
- **機制**：安全帶損傷（僅使用腰帶，無肩帶）；乘客屈曲位時受傷
- **好發**：胸腰椎交界處（T12-L2）
- **骨折**：水平穿過椎體、椎弓根、棘突
- **特點**：可伴腹腔臟器損傷（十二指腸、胰臟、腸系膜）

### Locked Facets（關節突關節鎖定）
- **機制**：過屈損傷
- **特點**：下關節突向前滑至上位椎體上關節突前方
- **X光/CT特點**：側位/矢狀面上，關節突位置逆轉；屈曲位時上方椎體向前滑脫≥椎體AP徑的50%
- ** Naked Facet Sign**：CT横断面顯示上關節突「裸露」

## 病理性骨折 / Pathologic Fractures

### 不足性骨折（Insufficiency Fractures）
- **定義**：機械強度降低的骨骼在正常或生理應力下發生骨折
- **好發**：停經後骨質疏鬆女性
- **好發部位**：骨盆、胸椎、骶骨、脛骨、跟骨
- **X光特點**：多顯示為**硬化帶**（而非透亮線），代表癒合中
- **Honda Sign**：骶骨雙側垂直骨折+水平骨折，模擬汽車標誌

### 病理性骨折
- **定義**：骨骼有預存病變（局部或全身性）時發生的低能量骨折
- **病因**：骨質疏鬆、佩吉氏病、骨囊腫、骨腫瘤（良性/惡性）
- **特點**：外傷輕微或無明顯外傷史
- **癒合延遲**：病理性骨折癒合時間通常延長
- **治療**：需同時處理基礎疾病

## 臨床要點 / Clinical Key Points

1. **骨折定義**：骨皮質連續性中斷；完全骨折=全層皮質斷裂；不完全骨折=部分皮層
2. **診斷陷阱**：籽骨、副小骨、骨突融合中心可模擬骨折；均有皮質包繞且雙側對稱
3. **骨折描述四大參數**：碎片數量、骨折線方向、碎片空間關係、是否開放
4. **骨折線方向**：橫向（垂直力）、斜向（長軸力）、螺旋形（扭力）
5. **移位/成角/短縮/旋轉**：描述遠折段與近折段關係
6. **撕脫骨折**：肌腱/韌帶用力收縮；年輕運動員；骨盆常見
7. **應力骨折**：X光初期85%正常；MRI最敏感；好發蹠骨、脛骨、股骨頸
8. **Colles骨折**：橈骨遠端+背側成角；Smith骨折=掌側成角（反Colles）
9. **隱匿骨折**：舟骨（注意AVN）、橈骨頭、後脫位（肩）、髖部骨折
10. **脂肪墊徵**：提示肘關節外傷性積液（應考慮橈骨頭骨折）
11. **骨折癒合**：內骨痂（骨折線模糊）+外骨痂（橋接）；多種因素影響癒合速度
12. **骨不連**：骨折線光滑硬化+骨端分離；幾乎無癒合可能
13. **脊椎創傷**：CT為首選；Jefferson骨折（C1側塊偏移）和Hangman's骨折（C2後方元素）通常無神經缺損
14. **Burst骨折**：椎體爆裂+骨片侵入椎管；多伴神經功能缺損
15. **Chance骨折**：安全帶損傷；需排除腹腔臟器損傷
16. **病理性骨折**：外傷輕微；有預存骨骼病變；癒合延遲
17. **不足性骨折**：骨質疏鬆女性；骶骨Honda sign；骨盆常見
