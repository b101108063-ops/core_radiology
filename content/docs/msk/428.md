# Musculoskeletal Imaging - Page 428

![Page 428](/core_radiology/images/msk/page-428.png)

## ACL 重建後併發症 / Post-ACL Reconstruction Complications

### 重建後正常表現 / Normal Post-Op ACL Graft
| 項目 | 說明 |
|------|------|
| 走向 | 移植韌帶應**平行於髁間窩**，位於 **Blumensaat 線（X 光上沿髁間屋頂繪製的線）**後方 |
| 過陡問題 | 伸直時移植韌帶可能被股骨夾擊 (Impingement) |
| 過鬆問題 | 移植韌帶無法提供足夠穩定性 |

###  Cyclops 病變 / Cyclops Lesion
| 項目 | 說明 |
|------|------|
| 定義 | Hoffa 脂肪墊內的**結節狀疤痕組織** |
| 發生於 | ACL 重建術後 |
| MRI 表現 | Hoffa 脂肪墊前方，移植 ACL 前方的結節狀軟組織訊號 |

## 後十字韌帶 / Posterior Cruciate Ligament (PCL)

### 正常解剖 / Normal Anatomy
| 項目 | 說明 |
|------|------|
| 強度/厚度 | 比 ACL **更強、更粗** |
| 起源 | 股骨髁間窩（比 ACL 更前方）|
| 附著點 | 脛骨平台後方 |
| 信號 | 所有序列正常皆為**低信號** |
| 損傷頻率 | 比 ACL **少得多** |

### PCL 撕裂 / PCL Tear
| 項目 | 說明 |
|------|------|
| 發生率 | 完全性 PCL 纖維撕裂並不常見 |
| MRI 表現 | PCL **鬆弛度增加**，伴/不伴 T2 加權像異常高信號 |

### PCL 損傷特徵 / PCL Injury Characteristics
| 發現 | 說明 |
|------|------|
| 間質撕裂 (Interstitial Tear) | 厚度增加 + 異常信號 + 鬆弛 |
| 完全撕裂 | 纖維明顯連續性中斷 |
| 治療 | PCL 撕裂比 ACL 撕裂**較少被修復** |

### 臨床要點 / Clinical Key Points
1. **重建後 ACL** = 應平行於髁間窩，位於 Blumensaat 線後方
2. **Cyclops 病變** = ACL 重建術後 Hoffa 脂肪墊的結節狀疤痕
3. **PCL** = 比 ACL 更強韌；所有序列正常為低信號
4. **PCL 撕裂** = 鬆弛度增加為主（T2 高信號可見可不見）
5. **PCL 損傷**比 ACL 少見，修復頻率也較低
