## 頸椎特殊骨折概覽 / Overview of Named Cervical Spine Fractures

### 各頸椎層級的特殊骨折 / Named Cervical Spine Fractures

| 位置 | 骨折類型 | 說明 |
|------|---------|------|
| **C1** | **Jefferson 骨折** | 軸向力導致前弓和後弓對稱骨折 |
| **C2** | **齒突骨折 (Odontoid Fracture)** | I 型：齒突尖部（通常穩定）；II 型：齒突基部（不穩定）；III 型：延伸至 C2 椎體 |
| **C2** | **Hangman's 骨折** | 過度伸展損傷導致 C2 椎弓骨折 |
| 頸椎 | **Clay-shoveler's 骨折** | 屈曲損傷導致棘突骨折 |
| 頸椎 | **Flexion Teardrop 骨折** | 最不穩定的頸椎損傷；後縱韌帶/棘突椎板線中斷 |

---

### Jefferson 骨折 / Jefferson Fracture
| 項目 | 說明 |
|------|------|
| 機制 | 頭頂急性軸向撞擊 |
| 骨折特徵 | C1 前弓和後弓的對稱骨折 |
| X 光開口位 (Open-mouth) 表現 | C1 側塊向外側移位 |
| 確診工具 | **軸向 CT** |

---

### 齒突骨折 / Odontoid Fracture

| 分型 | 骨折位置 | 穩定性 |
|------|---------|--------|
| **Type I** | 齒突尖部 | **穩定**；保守治療 |
| **Type II** | 齒突基部 | **不穩定**；通常手術融合 |
| **Type III** | 齒突延伸至 C2 椎體 | 不穩定至穩定不定 |

#### Type I 齒突骨折的鑑別診斷
| 項目 | 說明 |
|------|------|
| **Os Odontoideum** | 齒突尖部的正常變異性次級骨化中心 |

---

### Hangman's 骨折 / Hangman's Fracture
| 項目 | 說明 |
|------|------|
| 定義 | C2 的創傷性脊椎滑脫症 (Spondylolysis) |
| 機制 | 過度伸展 + 牽扯；導致雙側 C2 椎弓骨折 |
| X 光特徵 | **棘突椎板線中斷** |
| 不穩定指標 | C2 在 C3 上位移 > **3 mm** |

### 臨床要點 / Clinical Key Points
1. **Jefferson 骨折** = C1 頂部軸向撞擊 + CT 確診
2. **齒突 Type II** = 不穩定（需要手術融合）
3. **Hangman's 骨折** = C2 椎弓骨折（創傷性脊椎滑脫症）
4. **Flexion Teardrop** = 最不穩定的頸椎骨折（屈曲+壓迫）
5. **C2 在 C3 上位移 > 3 mm** = Hangman's 骨折不穩定
