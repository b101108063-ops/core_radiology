# Musculoskeletal Imaging - Page 429

![Page 429](/core_radiology/images/msk/page-429.png)

## 內側副韌帶 / Medial Collateral Ligament (MCL)

### 正常解剖 / Normal Anatomy
| 項目 | 說明 |
|------|------|
| 起源 | 內側股骨髁後方面 |
| 附著點 | 脛骨內側干骺端（鵝足 (Pes Anserinus) 深層）|
| 結構特點 | 與關節囊及內側半月板纖維交織；為**關節囊外結構**，關節鏡看不到 |

### MCL 損傷分級 / MCL Injury Grading
| 分級 | 定義 | MRI 表現 |
|------|------|---------|
| **Grade 1**（扭傷）| 內側軟組織高信號，韌帶信號正常 | 韌帶未受損 |
| **Grade 2**（嚴重扭傷/部分撕裂）| 韌帶內高信號或部分纖維中斷 | 部分撕裂 |
| **Grade 3**（完全撕裂）| MCL 完全中斷 | 完全撕裂 |

### Pellegrini-Stieda 病變 / Pellegrini-Stieda Lesion
| 項目 | 說明 |
|------|------|
| 定義 | 內側股骨髁內側的**創傷後鈣化** |
| 病因 | 可能為 MCL 撕脫損傷的後遺症 |

## 外側副韌帶複合體 / Lateral Collateral Ligament (LCL) Complex

### 組成 / Components
| 由後向前排序 | 結構 |
|-------------|------|
| 最後 | **股二頭肌腱 (Biceps Femoris Tendon)** |
| 中間 | **LCL** |
| 最前 | **髂脛束 (Iliotibial Band)** |

#### 重要附著點
| 結構 | 附著點 |
|------|--------|
| 股二頭肌腱 + LCL | 腓骨頭（常為共同腱）|
| 髂脛束 | Gerdy's Tubercle（脛骨近端外側）|

### LCL 損傷 / LCL Injury
| 項目 | 說明 |
|------|------|
| 發生率 | 比 MCL 損傷**少見** |
| 特點 | 通常伴隨其他後外側角結構損傷 |
| 後外側角損傷 | **外科急症**：不及時處理預後差 |

### 後外側角複合體 / Posterolateral Corner
| 結構 |
|------|
| 股二頭肌腱、LCL、髂脛束 |
| 弓狀韌帶 (Arcuate Ligament)：Y 形，連接腓骨與股骨外側 |
| 腓骨韌帶 (Popliteofibular Ligaments)：重要外側穩定結構 |
| 腘肌腱 (Popliteus Tendon)：附著於股骨外側 |

---

## 髂脛束症候群 / Iliotibial Band Syndrome

| 項目 | 說明 |
|------|------|
| 病因 | 股骨前外側與髂脛束之間的摩擦 |
| 臨床表現 | 前外側膝關節疼痛；常見於**跑步者** |
| MRI 表現 | 髂脛束**淺層及深層**的液體 |

### 鑑別診斷 / Differential Diagnosis
| 病變 | 說明 |
|------|------|
| IT Band 症候群 | 非手術治療 |
| 外側半月板撕裂 | 可能需要手術 |

### 臨床要點 / Clinical Key Points
1. **MCL Grade 3** = 完全撕裂（韌帶連續性中斷）
2. **Pellegrini-Stieda** = MCL 撕脫後遺症（內側股骨髁鈣化）
3. **後外側角損傷** = 外科急症（不及時治療預後差）
4. **IT Band 症候群** = 跑步者膝痛（非手術治療）
5. **LCL 複合體**：股二頭肌 → LCL → IT Band（由後至前）
