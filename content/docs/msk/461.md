# Musculoskeletal Imaging - Page 461

![Page 461](/core_radiology/images/msk/page-461.png)

## 後側不穩定性 / Posterior Instability

| 項目 | 說明 |
|------|------|
| 發病率 | 不常見，僅占不穩定性的 **< 5%** |

### 相關損傷 / Associated Injuries
| 損傷 | 說明 |
|------|------|
| **PHAGL** | 後側 HAGL |
| **Reverse Bankart** | 後側關節盂骨折 |
| **Reverse Hill-Sachs / Trough Sign** | 前內側撞擊 |
| 岡下肌、小圓肌撕裂 | 這些旋轉袖肌肉附著於大結節後側 |

### 先天性原因 / Congenital Cause
| 原因 | 說明 |
|------|------|
| **後側關節盂發育不良 (Hypoplastic Posterior Glena)** | 後側不穩定的先天性原因 |

### Bennett 病灶 / Bennett Lesion
| 項目 | 說明 |
|------|------|
| 別名 | 投擲者外生骨疣 (Thrower's Exostosis) |
| 定義 | 與後側唇緣損傷相關的關節外後側骨化 |
| 好發族群 | 棒球投手常見 |
| 病因 | 被認為是 IGHL 後束撕脫的結果 |
| 確診 | 腋位片可確認骨化 |

## SLAP 病灶 / Superior Labrum Anterior Posterior (SLAP) Tear

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 以二頭肌腱附著處為中心的**前-後方向**上唇撕裂 |
| 二頭肌腱附著 | 前上方唇緣 |
| 分類數量 | 最初 4 型，現已增至 **10 種**亞型 |

### SLAP 分型 / SLAP Classification

| 分型 | 特徵 |
|------|------|
| **Type I** | 上唇邊緣毛糙但無明確撕裂；二頭肌腱完整 |
| **Type II**（最常見）| 上唇磨損 + **上唇剝離**；與慢性反覆微創傷最相關 |
| **Type III** | 上唇的**桶柄狀撕裂**（類似膝半月板桶柄狀撕裂）|
| **Type IV** | 上唇桶柄狀撕裂 + **延伸至二頭肌腱** |

### 臨床要點 / Clinical Key Points
1. **後側不穩定** = < 5%；與後側 HAGL、reverse Bankart 相關
2. **Bennett 病灶** = 棒球投手常見 = IGHL 後束撕脫後的後側骨化
3. **SLAP Type II** = 最常見的 SLAP 類型 = 上唇剝離
4. **SLAP Type IV** = 上唇桶柄狀撕裂延伸至二頭肌腱
5. **SLAP** = 與二頭肌腱附著相關的前-後方向上唇撕裂
