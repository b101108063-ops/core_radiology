# Musculoskeletal Imaging - Page 442

![Page 442](/core_radiology/images/msk/page-442.png)

## 股骨髖臼撞擊症 / Femoroacetabular Impingement (FAI)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 關節活動末端時，股骨與髖臼的不正常撞擊 |
| 後果 | 年輕運動員的髖臼唇撕裂；加速髖關節退化性關節炎 |
| 爭議 | 是否有重要的退化原因；影像發現與臨床症狀的相關性仍有爭議 |

### FAI 類型 / Types

| 類型 | 異常部位 | 特徵 |
|------|---------|------|
| **Cam-type** | 股骨頭/頸連接部 | 股骨頭-頸交界處骨質增生 |
| **Pincer-type** | 髖臼 | 髖臼過度覆蓋 |
| **Mixed-type（混合型）** | 兩者皆有 | 最常見形式 |

### Cam-type 撞擊症 / Cam-type Impingement

| 項目 | 說明 |
|------|------|
| 病因 | 兒童股骨頭骨骺滑脫 (SCFE)、Legg-Calve-Perthes 病、發育性髖關節發育不良後遺症（髖臼覆蓋不足）、骨折畸形癒合 |
| 好發族群 | **年輕運動男性** |
| **Pistol-grip 畸形** | 股骨頭-頸連接處的異常形態，狀似老式手槍（頭/頸=握把；骨幹=槍管）|
| **Alpha 角** | 測量股骨頭-頸部異常程度；> **55°** 為異常 |
| 治療 | 股骨骨質整形術 (Femoral Osteoplasty) |

#### Alpha 角測量
| 測量方式 | 定義 |
|---------|------|
| 方法 | 在斜軸向 MRI 或 CT 上測量；第一條線：穿過股骨頸中心並等分股骨頭；第二條線：連接股骨頭中心至股骨頭/頸最 proximal 異常輪廓 |

---

## Pincer-type 撞擊症 / Pincer-type Impingement

| 項目 | 說明 |
|------|------|
| 病因 | 髖臼過度覆蓋 |
| 好發族群 | **中年女性** |
| **Crossover Sign（交叉徵）** | 前上方髖臼壁在前後位 X 光上越過後壁（又稱顱側髖臼後翻 (Cranial Acetabular Retroversion)）|
| 治療 | 髖臼邊緣手術切除 (Acetabular Rim Trimming) |

---

## 混合型撞擊症 / Mixed-type Impingement
| 說明 |
|------|
| 最常見的 FAI 形式；同時具有股骨頭-頸連接處與髖臼的異常 |

### 臨床要點 / Clinical Key Points
1. **Cam-type** = 股骨頭/頸連接部異常 + pistol-grip 畸形 + Alpha 角 > 55°
2. **Pincer-type** = 髖臼過度覆蓋 + crossover sign + 中年女性
3. **混合型** = 最常見的 FAI 類型
4. **Alpha 角** = 在斜軸向 MRI/CT 上測量；> 55° 為異常
5. **Pistol-grip 畸形** = Cam-type FAI 的特徵性形態
