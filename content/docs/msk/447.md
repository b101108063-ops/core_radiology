## 肩鎖關節 / Acromioclavicular (AC) Joint

### AC 關節損傷分級 / AC Joint Separation Classification

| 分級 | 損傷描述 | X 光表現 |
|------|---------|---------|
| **Grade I** | AC 韌帶扭傷 | X 光正常 |
| **Grade II** | AC 韌帶斷裂 + CC 韌帶完整 | AC 關節增寬 |
| **Grade III** | AC + CC 韌帶皆斷裂 | CC 間隙增寬 25-100%（對側對比）|
| **Grade IV** | 鎖骨遠端向後移位至斜方肌 | 鎖骨向後脫位（CT/腋位片可見）|
| **Grade V** | 嚴重 Grade III | CC 間隙增寬 > **100%** |
| **Grade VI** | 鎖骨遠端向下脫位 | 極罕見 |

### 測量標準 / Measurement Norms
| 測量 | 正常值 |
|------|--------|
| AC 關節間隙 | < **5 mm** |
| CC 距離 | < **11-13 mm**（正常變異大）；兩側差 > **50%** 為異常 |
| 檢查技巧 | 手持重物的被動奉引力可能揭示隱匿損傷 |

## 盂肱關節脫位 / Glenohumeral Dislocation

### 前側盂肱關節脫位 / Anterior Glenohumeral Dislocation

| 項目 | 說明 |
|------|------|
| 發病率 | **最常見**的肩關節脫位類型 |
| 機制 | 直接暴力作用於手臂；肱骨頭通常向前下方向脫位 |
| 確診位置 | **腋位片 (Axillary View)** |
| 病理機制 | 肱骨頭回彈時，後外側撞擊前下關節盂 → 可造成肱骨頭、關節盂或兩者皆骨折 |

### Hill-Sachs 病灶 / Hill-Sachs Lesion
| 項目 | 說明 |
|------|------|
| 定義 | 肱骨頭後外側的**壓迫骨折** |
| 機制 | 肱骨頭後外側撞擊關節盂前下緣 |
| X 光最佳顯現位置 | 手臂內旋位的 AP 片 |

### Bankart 病灶 / Bankart Lesion
| 項目 | 說明 |
|------|------|
| 定義 | 關節盂前下緣的損傷 |
| 內容 | 通常僅涉及軟骨性唇緣 |
| **Bony Bankart** | 關節盂骨質的骨折 |

### 臨床要點 / Clinical Key Points
1. **前側脫位** = 最常見的肩關節脫位；腋位片確診
2. **Hill-Sachs** = 肱骨頭後外側壓迫骨折（撞擊關節盂前下緣）
3. **Bankart** = 前下關節盂唇緣損傷
4. **AC 關節損傷** = CC 距離增寬 > 100% = Grade V
5. **Bony Bankart** = 關節盂骨質骨折
