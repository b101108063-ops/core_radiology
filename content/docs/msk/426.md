## 膝關節韌帶 / Knee Ligaments

## 前十字韌帶 / Anterior Cruciate Ligament (ACL)

### 正常解剖 / Normal Anatomy
| 項目 | 說明 |
|------|------|
| 起源 | 股骨髁間窩 |
| 附著點 | 脛骨平台前方，脛骨棘外側 |
| 穩定性 | 脛骨附著點比股骨起點更強韌 |
| 組成 | 兩束：**前內側束 (Anteromedial Band)**（較小）+ **後外側束 (Posterolateral Band)**（較大）|

### ACL 撕裂 / ACL Tear
| 項目 | 說明 |
|------|------|
| 病因 | 通常為急性創傷 |
| MRI 表現 | 韌帶纖維**明顯連續性中斷**或異常走向及信號 |

### 相關損傷 / Associated Injuries
| 損傷 | 說明 |
|------|------|
| **O'Donoghue 三聯徵** | ACL 撕裂常伴隨**半月板撕裂**和 **MCL 撕裂** |
| 後外側角損傷 | 也常與 ACL 損傷同時出現 |

### 臨床要點 / Clinical Key Points
1. **ACL** = 股骨髁間窩 → 脛骨平台前方（脛骨棘外側）
2. **兩束結構**：前內側束（較小）+ 後外側束（較大）
3. **O'Donoghue 三聯徵** = ACL + MCL + 半月板（內側）撕裂
4. **ACL 撕裂 MRI** = 纖維連續性中斷或信號/走向異常
5. **後外側角損傷** = 常與 ACL 損傷同時存在
