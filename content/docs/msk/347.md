# Musculoskeletal Imaging - Page 347

![Page 347](/core_radiology/images/msk/page-347.png)

## 關節突關節病變 / Facet Arthropathy

### 疾病概述 / Disease Overview
- **關節突關節 (Facet Joints)**：是滑膜關節，可發生與大關節相同的退化性病變
- 退化表現包括：軟骨丢失、骨刺增生、硬化、骨下囊性變

### 臨床特徵 / Clinical Features
- 腰痛 (Low back pain)
- 活動受限
- 可導致**神經孔狹窄 (Neural Foraminal Narrowing)**

### 影像診斷要點 / Diagnostic Key Points
- 關節突關節位於神經孔內側
- 退化性病變可導致神經孔狹窄

### 鑑別診斷 / Differential Diagnosis
- 關節突關節病變 vs. 椎間盤病變：兩者可同時存在

## 滑膜囊腫 / Synovial Cyst

### 疾病概述 / Disease Overview
- 硬膜外囊腫，與**關節突關節病變**相關
- MRI 特徵：
  - **T2 高信號**
  - T1 信號多變（取決於內部是否出血）
- 與關節突關節的連續性有時在 MRI 上難以顯示
- 關節突關節硬膜外注射可顯示囊腫顯影

### Tarlov囊腫 vs. 滑膜囊腫

| 特徵 | 滑膜囊腫 (Synovial Cyst) | Tarlov囊腫 (Tarlov Cyst) |
|------|--------------------------|--------------------------|
| 位置 | 硬膜外，與關節突關節相關 | 骶神經根鞘內 |
| 病因 | 關節突關節退化 | 先天性/特發性 |
| 症狀 | 常有症狀（疼痛、神經根症狀） | 通常無症狀 |
| 與關節病變關聯 | 相關 | **不相關** |

## 高信號區（環形裂隙）/ High Intensity Zone (Annular Fissure)

### 疾病概述 / Disease Overview
- **高信號區 (High Intensity Zone, HIZ)**：T2 加權影像上纖維環內的高信號區域
- 代表**纖維環裂隙或撕裂**
- 可能是疼痛的原因之一

### 術語對照 / Terminology
| 英文術語 | 中文 | 說明 |
|----------|------|------|
| Annular fissure | 環形裂隙 | 纖維環裂隙 |
| Annular tear | 環形撕裂 | 與外傷相關，建議使用「裂隙」 |

## 非退化性肥厚性疾病 / Non-Degenerative Hypertrophic Diseases

### 彌散性特發性骨質增生 (DISH)

#### 疾病概述 / Disease Overview
- **DISH (Diffuse Idiopathic Skeletal Hyperostosis)**：至少延伸 4 個椎體水平的流動性前緣骨刺
- 與退化性椎間盤疾病是獨立過程，但常同時出現
- DISH：**椎間盤間隙保持完好**（與退化性疾病鑑別要點）

#### 臨床特徵 / Clinical Features
- 通常無症狀或輕微症狀
- 可導致頸椎前緣骨刺相關症狀

#### 臨床要點 / Clinical Key Points
- 即使輕微創傷也可能導致骨折（因脊椎活動度降低）
- 與**後縱韌帶骨化 (OPLL)** 相關

---

### 後縱韌帶骨化 (OPLL)

#### 疾病概述 / Disease Overview
- **OPLL (Ossification of the Posterior Longitudinal Ligament)**：後縱韌帶的鈣化與骨化
- 可導致**椎管狹窄**及脊髓前部受壓

#### 影像診斷要點 / Diagnostic Key Points
| 檢查方式 | 表現 |
|----------|------|
| **CT** | 最佳檢查：可清楚顯示椎管前部異常骨化 |
| **MRI** | 椎管前部低信號 |

#### 臨床特徵 / Clinical Features
- 起始於頸椎，可向下延伸至胸椎
- 可導致脊髓病變 (Myelopathy)

## 術後脊椎 / Postoperative Spine

### MRI 對比劑使用原則
- 術後 MRI 通常需注射對比劑
- 目的：**區分復發性椎間盤疾病與疤痕組織**

### 復發性椎間盤 vs. 疤痕組織

| 特徵 | 復發性椎間盤 | 疤痕組織 |
|------|-------------|----------|
| T2 信號 | 低信號 | 低信號 |
| 增強模式 | **周邊強化** | **全程強化** |
| 手術預後 | 需考慮再次手術 | 症狀緩解機會較低 |

### 臨床要點 / Clinical Key Points
1. **DISH**：前緣骨刺 ≥ 4 個椎體 + 椎間隙保留
2. **OPLL**：CT 是最佳診斷工具
3. **術後 MRI**：對比劑是區分復發與疤痕的關鍵
4. 疤痕組織存在會降低症狀緩解的成功率
