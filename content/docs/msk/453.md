# Musculoskeletal Imaging - Page 453

![Page 453](/core_radiology/images/msk/page-453.png)

## 肌腱退化/肌腱病 / Tendinosis / Tendinopathy

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 肌腱的黏液樣退化，**無活動性發炎** |
| MRI 表現 | 瀰漫性或局灶性增粗；T1、T2 上信號介於中等（不像液體那樣高信號）|
| 魔法角現象 | 可模擬退化或部分撕裂（55° 時短 TE 序列的假象）|

---

## 旋轉袖撕裂概述 / Overview of Rotator Cuff Tears

### 撕裂分型 / Tear Classification
| 分型 | 說明 |
|------|------|
| **部分厚度撕裂** | 信號異常僅在部分厚度，未穿透整個肌腱 |
| **完全厚度撕裂** | 允許滑囊與盂肱關節之間相通 |

### 重要解剖區 / Important Anatomical Zones
| 區域 | 說明 |
|------|------|
| **足印 (Footprint)** | 肌腱在大結節的附著處 |
| **關鍵區 (Critical Zone)** | 岡上肌腱遠端約 1 cm 處，接近足印的血供不足區 |

## 部分厚度旋轉袖撕裂 / Partial-Thickness Rotator Cuff Tear

### 好發統計 / Injury Statistics
| 肌肉 | 受傷頻率 |
|------|---------|
| **岡上肌** | 最常受傷 |
| 岡下肌 | 第二常見 |
| 小圓肌 | 最少受傷 |

### 部分撕裂分類 / Partial Tear Classification

| 分型 | 說明 |
|------|------|
| **關節面撕裂 (Articular-surface)** | **最常見**（約占 90%） |
| 滑囊面撕裂 (Bursal-surface) | 少見 |
| 肌腱內撕裂 (Intrasubstance) | 少見 |

### PASTA 病灶 / PASTA Lesion
| 項目 | 說明 |
|------|------|
| 全名 | Partial Articular Supraspinatus Tendon Avulsion |
| 定義 | 岡上肌腱關節面在足印處的撕脫型部分撕裂 |
| 頻率 | 最常見的部分撕裂類型 |

### PAINT 病灶 / PAINT Lesion
| 項目 | 說明 |
|------|------|
| 全名 | Partial Articular Tear with Intratendinous Extension |
| 定義 | 延伸至肌腱內的關節面部分撕裂 |

### 臨床要點 / Clinical Key Points
1. **PASTA** = 部分厚度關節面岡上肌腱撕脫（最常見的部分撕裂）
2. **魔法角現象** = 55° 方向的假性高信號（短 TE 序列）
3. **完全厚度撕裂** = 滑囊與盂肱關節相通（對比劑可見）
4. **關節面撕裂** = 最常見的部分撕裂（90%）
5. **PAINT** = 關節面撕裂延伸至肌腱內部
