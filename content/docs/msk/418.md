# Musculoskeletal Imaging - Page 418

![Page 418](/core_radiology/images/msk/page-418.png)

## 踝關節骨折 / Ankle Fractures

### Danis-Weber 分類 / Danis-Weber Classification

| 分型 | 骨折位置 | 穩定性 |
|------|---------|--------|
| **Weber A** | 腓骨遠端骨折，**踝關節完整** | 穩定 |
| **Weber B** | 腓骨中段橫斷骨折（經過韌帶聯合），通常伴部分韌帶聯合破裂 | 中度不穩定 |
| **Weber C** | 腓骨高位骨折（**超過韌帶聯合水平**），通常伴完全韌帶聯合破裂 + 踝穴不稳定 | 不穩定 |

### 韌帶聯合 (Syndesmosis) 解剖
| 結構 | 說明 |
|------|------|
| 韌帶聯合 | 連接遠端脛骨與腓骨的纖維韌帶複合體（腓骨遠端嵌入脛骨切跡）|
| 前/後脛腓韌帶 | 形成韌帶聯合的主要結構 |
| 骨間膜 | 連接脛骨與腓骨全長，位於韌帶聯合之上 |

### Lauge-Hansen 分類對照 / Lauge-Hansen Classification

| 受傷機制 | Danis-Weber 對應 |
|---------|----------------|
| 旋後-內收 (Supination-Adduction) | Weber A |
| **旋後-外旋 (Supination-External Rotation)** | **Weber B** |
| 旋前-外旋 (Pronation-External Rotation) | **Weber C** |

## 特殊踝關節骨折命名 / Named Ankle Fractures

| 骨折名稱 | 特徵 |
|---------|------|
| **Tillaux 骨折** | 青少年特有的**胫骨遠端骨骺 Salter-Harris III 型骨折**（外側） |
| **Triplane 骨折 (Marmor-Lynn 骨折)** | 脛骨遠端三個骨折面：垂直骨骺骨折 + 水平骺板骨折 + 斜行干骺端骨折 |
| **Wagstaffe-LeFort 骨折** | 前脛腓韌帶附著處的腓骨遠端前側撕脫骨折 |
| **Maisonneuve 骨折** | 高位腓骨骨折 + 骨間膜撕裂或內踝骨折；單獨踝關節片可能只見踝穴輕微增寬，需加照近端 |

---

### Pilon 骨折 / Pilon Fracture
| 項目 | 說明 |
|------|------|
| 定義 | 遠端脛骨垂直方向的**粉碎性骨折**，導致脛骨穹頂 (Tibial Plafond) 破壞 |
| 病因 | **軸向負荷創傷**（如高處坠落）|

### 臨床要點 / Clinical Key Points
1. **Weber B** = 最常見的踝關節骨折類型（旋後-外旋機制）
2. **Weber C** = 高位腓骨骨折 + 完全韌帶聯合破裂 = 不穩定
3. **Tillaux 骨折** = 青少年外側胫骨骨骺 Salter-Harris III 型
4. **Triplane 骨折** = 三個骨折面（垂直 + 水平 + 斜行）= 青少年
5. **Maisonneuve 骨折** = 高位腓骨骨折 + 踝穴增寬（需加照小腿近端）
6. **Pilon 骨折** = 軸向負荷 → 遠端脛骨粉碎性垂直骨折
