## 維生素缺乏性骨病 / Vitamin-Deficiency Bone Disease

### 壞血病 / Scurvy

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 維生素 C 缺乏症 (Hypovitaminosis C) |
| 發病機制 | **蝕骨細胞需要維生素 C 才能形成成熟的骨質基質** → 全身性骨質疏鬆 |

#### 特異性 X 光徵象 / Characteristic Radiographic Signs
| 徵象 | 說明 |
|------|------|
| **Wimberger 環徵 (Wimberger Ring Sign)** | 骨骺硬化（因骨骺骨化紊亂）|
| **Pelkin 骨折 (Pelkin Fracture)** | 骨幹端角落骨折 (Metaphyseal Corner Fracture) |
| **緻密骨幹端線** | 骨幹端緻密硬化線 |

---

### 軟骨病 / Osteomalacia

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 維生素 D 缺乏導致骨質基質礦化障礙 |
| 兒童名稱 | 佝僂病 (Rickets) |
| 成人名稱 | 軟骨病 (Osteomalacia) |

#### 影像特徵 / Imaging Features
| 特徵 | 說明 |
|------|------|
| 全身性骨質疏鬆 | 瀰漫性骨質密度下降 |
| **Looser Zone（假骨折線）** | 高度特異性：皮質應力性骨折，被礦化不良的骨質基質填充；X 光呈皮質透亮線 |

#### 常見 Looser Zone 位置 / Common Sites for Looser Zones
| 位置 | 說明 |
|------|------|
| 股骨近端內側（承重區）| 最常見 |
| 肩胛骨遠端 | 常見 |
| 恥骨 | 常見 |

#### 併發症 / Complication
- **功能不全性骨折 (Insufficiency Fracture)**

## 內分泌性骨病 / Endocrine Bone Disease

### 肢端肥大症 / Acromegaly

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 生長激素過剩的臨床症候群 |
| 若發生於骨骼未成熟時 | 骨骼縱向生長 → **巨人症 (Gigantism)** |
| 若發生於骨骼成熟後 | 骨骼無法延長，改為遠端/周邊增大及增寬 |

#### 各部位特徵 / Location-Specific Features

| 部位 | 表現 |
|------|------|
| **頭部** | 額竇增大、顱骨增厚、下頜增大 |
| **手部** | 掌骨頭鳥嘴狀骨刺 (Beak-like Osteophytes)、遠節指骨鋤頭樣過度生長 (Spade-like Overgrowths)；關節間隙早期增寬，後期因續發性退化變窄 |
| **足部** | **跟墊厚度 > 24 mm** 為特徵（正常 150 lb 者為 24 mm，每增加 25 lb 加 1 mm）|

### 臨床要點 / Clinical Key Points
1. **Wimberger 環徵** = 壞血病（骨骺硬化）；Pelkin 骨折 = 壞血病（骨幹端角落骨折）
2. **Looser Zone** = 軟骨病的特徵性 X 光表現（皮質應力性骨折線）
3. **肢端肥大症** = 掌骨頭鳥嘴狀骨刺 + 遠節指骨鋤頭樣增大 + 跟墊 > 24 mm
4. **維生素 C 缺乏** → 蝕骨細胞無法形成成熟骨質 → 壞血病
5. **維生素 D 缺乏** → 骨質基質礦化不良 → 軟骨病
