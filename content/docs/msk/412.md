## Lisfranc 骨折-脫臼（續）/ Lisfranc Fracture-Dislocation (Continued)

### Lisfranc 損傷分類 / Classification

| 類型 | 脫臼方向 |
|------|---------|
| **同側脫臼 (Homolateral)** | 所有蹠骨一起向**外側**脫臼 |
| **分歧脫臼 (Divergent)** | 第一蹠骨向**內側**脫臼；第二至五蹠骨向**外側**脫臼 |

### 蹠跗關節對線評估 / Lisfranc Joint Alignment Assessment

| 位置關係 | 說明 |
|---------|------|
| 第一蹠骨底部外側 ↔ 內側楔骨外側 | 應對線 |
| 第二蹠骨底部內側 ↔ 第二楔骨內側 | 應對線 |
| 第三蹠骨底部內側 ↔ 第三楔骨內側 | 應對線 |
| 蹠跗關節背面輪廓 | 應為**連續性** |

- **負重 X 光**為最敏感的檢查方法
- 微小的 Lisfranc 對線異常也可能是嚴重韌帶損傷的信號

### 重要臨床提醒
- Lisfranc 關節損傷即使是微小的對線異常也預示嚴重的韌帶損傷

## 中足與後足創傷 / Midfoot and Hindfoot Trauma

### 常見骨折概覽 / Overview of Common Fractures

| 部位 | 骨折類型 |
|------|---------|
| **距骨頸骨折** | 分類：Hawkins 分類 |
| ** Chopart 骨折-脫臼** | 距舟關節 + 跟骰關節 |
| **跟骨骨折** | 多種分類：Essex-Lopresti、Sanders (CT) |

### 臨床要點 / Clinical Key Points
1. **Lisfranc 同側脫臼** = 所有蹠骨向外側移位
2. **Lisfranc 分歧脫臼** = 第一蹠骨內側 + 其餘蹠骨外側
3. **負重 X 光** = 評估 Lisfranc 損傷最敏感的方法
4. **Kohler 病** = 兒童舟狀骨缺血性壞死（自限性）
5. **Müeller-Weiss 病** = 成人女性舟狀骨缺血性壞死（較嚴重）
