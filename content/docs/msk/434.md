## 膝關節軟組織（續）/ Knee Soft Tissues (Continued)

### 貝克氏囊腫 / Baker's Cyst

| 項目 | 說明 |
|------|------|
| 定義 | 膕窩囊腫，由**球閥式**與膝關節的交通形成 |
| 典型位置 | **半膜肌腱**與**腓腸肌內側頭**之間 |
| 記憶口號 | **「Baker's M&M」**（半膜肌 + 腓腸肌）|

#### 重要鑑別診斷
| 鑑別 | 說明 |
|------|------|
| **膕部动脉瘤 (Popliteal Aneurysm)** | 需排除的重要鑑別診斷 |

## 髖關節解剖 / Hip Anatomy

### 髖臼骨骼組成 / Bony Acetabulum
| 骨骼 | 位置 |
|------|------|
| **髂骨 (Ilium)** | 上方 |
| **恥骨 (Pubis)** | 前方 |
| **坐骨 (Ischium)** | 後方 |

### 軟骨、唇緣與韌帶 / Cartilage, Labrum, and Ligaments

| 結構 | 說明 |
|------|------|
| 髖臼關節軟骨 | 馬蹄形薄關節軟骨覆蓋 |
| **非軟骨覆蓋區 (Pulvinar)** | 髖臼中央無軟骨覆蓋 |
| **唇緣 (Labrum)** | 纖維軟骨性結構，圍繞髖臼周邊約 **270 度**；前下方由**橫韌帶**取代（該區無唇緣）|
| **橫韌帶 (Transverse Ligament)** | 形成**圓韌帶 (Ligamentum Teres)** 的纖維 |
| **圓韌帶** | 連接股骨頭中央凹窩 (Fovea) |

### 臨床要點 / Clinical Key Points
1. **Baker's Cyst** = 半膜肌 + 腓腸肌內側頭之間（M&M 記憶）
2. **Tennis Leg** = 蹠肌腱或腓腸肌內側頭撕裂
3. **髖臼由三塊骨頭組成**：髂骨 + 恥骨 + 坐骨（三輻軟骨連接處）
4. **唇緣** = 圍繞髖臼周邊 270 度（前下方由橫韌帶取代）
5. **圓韌帶** = 橫韌帶延伸 + 連接股骨頭凹窩
