# Musculoskeletal Imaging - Page 372

![Page 372](/core_radiology/images/msk/page-372.png)

## 關節炎評估（續）/ Arthritis Evaluation (Continued)

### C — 鈣化 (Calcification)

| 晶體沉積疾病 | 關節炎類型 |
|-------------|-----------|
| **CPPD（軟骨鈣化症）** | 軟骨鈣化 (Chondrocalcinosis) |
| **羥磷灰石沉積症 (HADD)** | 肌腱鈣化 (Calcific Tendinitis) |
| **尿酸鈉單水合物（痛風）** | 軟組織鈣化（痛風石內尿酸結晶促成鈣質沉積） |

#### 軟骨鈣化 (Chondrocalcinosis)
- 成因：軟骨內**焦磷酸鈣 (CPPD) 結晶沉積**
- 可為特發性，或與**甲狀旁腺功能亢進**、**血色素沉著症**相關

#### 肌腱鈣化 (Calcification of Tendons)
- 主因為**羥磷灰石結晶沉積**（又稱鈣化性肌腱炎）
- CPPD 亦可見肌腱鈣化

#### 軟組織鈣化 (Soft-tissue Calcification)
- 痛風石內尿酸結晶可促進鈣質沉積
- 其他原因：**硬皮病、皮肌炎/多發性肌炎、系統性紅斑狼瘡**

### C — 軟骨間隙 (Cartilage Spaces)

| 軟骨間隙表現 | 疾病關聯 |
|-------------|---------|
| **軟骨間隙保留** | 痛風（通常軟骨間隙完整，局部變窄可能由痛風石造成） |
| **不對稱性狹窄** | 退化性關節炎、痛風 |
| **對稱性狹窄** | 發炎性關節病（類風濕關節炎） |
| **軟骨間隙增寬** | **肢端肥大症**（疾病早期可見，繼發性退化前出現） |

### D — 分布 (Distribution)

#### 手部：遠端指間關節 (DIP) 與近端指間關節 (PIP)

| 情況 | 疾病 |
|------|------|
| **有骨刺、無侵蝕** | 退化性關節炎 |
| **有骨刺、有侵蝕** | 侵蝕性退化性關節炎 (Erosive OA) |
| **無骨刺、有侵蝕** | 乾癬性關節炎 |

#### 手部：掌指關節 (MCP) 與 PIP

| 情況 | 疾病 |
|------|------|
| **無新生骨形成** | 類風濕關節炎 |
| **僅 MCP 侵犯 + 侵蝕** | 類風濕關節炎 |
| **僅 MCP 侵犯 + 骨刺** | **CPPD** 或 **血色素沉著症** |

### 臨床要點 / Clinical Key Points
1. **軟骨鈣化 → CPPD**（特發性或與甲狀旁腺亢進/血色素沉著症相關）
2. **對稱性軟骨狹窄 → 發炎性關節病；不對稱 → 退化性關節炎或痛風**
3. **軟骨間隙增寬 → 肢端肥大症**（早期特徵）
4. **DIP 骨刺無侵蝕 → 退化性關節炎；DIP 無骨刺有侵蝕 → 乾癬性關節炎**
5. **MCP 骨刺 → 優先考慮 CPPD 或血色素沉著症**
