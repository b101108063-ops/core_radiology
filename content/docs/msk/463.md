## 肩胛上神經夾擊於肩胛棘切跡 / Suprascapular Nerve Entrapment at Spinoglenoid Notch

| 項目 | 說明 |
|------|------|
| 遠端肩胛上神經功能 | **僅支配岡下肌** |
| 夾擊結果 | **僅岡下肌**孤立性萎縮 |

---

## 神經夾擊病變總結 / Summary of Entrapment Neuropathies

| 位置 | 受累神經 | 受累肌肉 | 囊腫來源 |
|------|---------|---------|---------|
| **肩胛上切跡（近端）** | 肩胛上神經（近端分支）| 岡上肌 + 岡下肌 | 上唇撕裂相關 |
| **肩胛棘切跡（遠端）** | 肩胛上神經（遠端分支）| **僅岡下肌** | 不明 |
| **四邊空間** | 腋神經 | 小圓肌（±三角肌）| — |

### 四邊空間邊界 / Quadrilateral Space Borders
| 邊界 |
|------|
| 肱骨（外側）|
| 三頭肌長頭（內側）|
| 小圓肌（上方）|
| 大圓肌（下方）|

## Parsonage-Turner 症候群 / Parsonage-Turner Syndrome

| 項目 | 說明 |
|------|------|
| 定義 | 特發性臂神經叢病變 |
| 與旋轉袖的關係 | 可能導致旋轉袖萎縮 |
| 診斷 | 排除性診斷 |
| 必須排除的結構性原因 | 腫塊或囊腫壓迫神經等 |

### 臨床要點 / Clinical Key Points
1. **肩胛棘切跡夾擊** = 遠端肩胛上神經 → 僅岡下肌萎縮
2. **肩胛上切跡夾擊** = 近端肩胛上神經 → 岡上肌 + 岡下肌萎縮
3. **四邊空間** = 腋神經 → 小圓肌（±三角肌）
4. **Parsonage-Turner** = 特發性臂神經叢病變（排除性診斷）
5. 所有神經夾擊病變都需要排除結構性原因（腫塊、囊腫）再確診
