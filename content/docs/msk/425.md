# Musculoskeletal Imaging - Page 425

![Page 425](/core_radiology/images/msk/page-425.png)

## 盤狀半月板 / Discoid Meniscus

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 半月板的先天性發育異常範圍，從半月板厚度增加到完全圓盤狀 |
| 診斷標準 | 半月板任何部分延伸至**脛骨平台中央** |
| MRI 診斷標準 | 標準 4 mm 矢狀切片上，連續 **3 個或以上切片**可見橢圓形或蝴蝶結狀半月板（等於 12 mm 內外側厚度）|

### 臨床特徵 / Clinical Features
| 項目 | 說明 |
|------|------|
| 好發年齡 | 兒童 |
| 症狀 | 關節線疼痛、彈響、鎖住（兒童/青少年常見原因）|
| 好發側 | **外側半月板**較常見 |
| 併發症 | 易發生囊性退化和撕裂；即使無撕裂也可能引起症狀 |

### 臨床要點 / Clinical Key Points
1. **盤狀半月板** = 先天性發育異常（兒童）+ 蝴蝶結形態超過 3 個切片
2. **外側半月板**較內側更常受影響
3. **即使無撕裂**，盤狀半月板也可能有症狀
4. **MRI 診斷標準**：12 mm 厚度（3 個 4 mm 切片）= 盤狀半月板
5. **兒童關節線疼痛/鎖住** → 優先考慮盤狀半月板
