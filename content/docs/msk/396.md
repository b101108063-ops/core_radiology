## 糖尿病足骨髓炎的鑑別診斷 / Differential Diagnosis of Diabetic Foot Osteomyelitis

### 糖尿病足骨髓炎 vs 神經病變性關節病 (Charcot Joint)

| 特徵 | 糖尿病足骨髓炎 | 神經病變性關節病 |
|------|---------------|-----------------|
| **好發部位** | 依潰爛位置而定 | 中足 (Midfoot) |
| **關節受累** | 單關節/鄰近骨頭 | 多關節 (Polyarticular) |
| **連續性軟組織感染** | 有（幾乎一定有） | 無 |
| **相關潰爛/竇道** | 有（幾乎一定有） | 無 |
| **皮質完整性** | 通常**中斷** | 皮質通常完整 |
| **骨髓信號異常** | 有 | 有 |

### 重要鑑別點 / Key Differentiator
- **有、無連續性軟組織感染/潰爛/竇道** = 區分兩者的關鍵

## 亞急性與慢性骨髓炎 / Subacute and Chronic Osteomyelitis

### Brodie 膿腫 / Brodie Abscess
| 項目 | 說明 |
|------|------|
| 定義 | 亞急性骨髓炎的特殊病變型態：侷限性骨髓腔感染，被肉芽組織與硬化骨質包繞 |
| 本質 | 實質上即為**骨髓腔內膿腫** |

### 慢性骨髓炎 / Chronic Osteomyelitis
| 項目 | 說明 |
|------|------|
| 病程 | 慢性感染 > 6 週 |
| X 光特徵 | 混合性溶骨/硬化表現 + 皮質增厚 |
| 鑑別診斷 | 活動性 vs 非活動性慢性骨髓炎可能困難（活動性 serial X 光可見新骨膜反應） |

### 硬化性骨髓炎 (Garré 骨髓炎) / Sclerosing Osteomyelitis (Garré)
| 說明 |
|------|
| 為慢性骨髓炎的罕見形式，特徵為骨質硬化與增厚 |
| 鑑別診斷：**淋巴瘤、硬化性轉移、骨樣骨瘤** |

## 特殊病原菌 / Specific Organisms

| 病原菌 | 特徵性臨床情況 |
|--------|---------------|
| **金黃色葡萄球菌 (S. aureus)** | 血源性骨髓炎**最常見原因** |
| **沙門氏菌 (Salmonella)** | 鐮刀型紅血球疾病患者；好發**骨幹**（與骨幹梗塞不易區分） |
| **綠膿桿菌 (P. aeruginosa)** | 典型由**腳底穿刺傷（穿鞋）**引起 |
| **結核菌 (M. tuberculosis)** | 脊椎感染最常見（又稱**Pott 病**）|

### 臨床要點 / Clinical Key Points
1. **糖尿病足**：骨髓炎 vs 神經病變性關節病 — 潰爛/竇道 + 皮質中斷 → 骨髓炎
2. **Brodie 膿腫** = 亞急性骨髓炎（需與骨樣骨瘤鑑別）
3. **Garré 硬化性骨髓炎**需與淋巴瘤、硬化性轉移、骨樣骨瘤鑑別
4. **鐮刀型紅血球疾病 + 骨髓炎** → 考慮沙門氏菌（非葡萄球菌）
5. **Pott 病** = 結核性脊椎炎
