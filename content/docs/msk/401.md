# Musculoskeletal Imaging - Page 401

![Page 401](/core_radiology/images/msk/page-401.png)

## 甲狀旁腺功能亢進（骨的雷克林豪森氏病）/ Hyperparathyroidism (Recklinghausen Disease of Bone)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 甲狀旁腺激素 (PTH) 過剩 |
| 正常生理 | 低血鈣時，甲狀旁腺分泌 PTH 維持血鈣（透過刺激蝕骨細胞）|

### 分型 / Classification

| 分型 | 病因 | 血鈣 | 血磷 |
|------|------|------|------|
| **原發性** | 甲狀旁腺腺瘤（自主性分泌過剩）| **高** | 低 |
| **續發性** | 腎衰竭致低血鈣，正常甲狀旁腺代償性分泌過剩 | 通常正常 | — |
| **第三型 ( Tertiary)** | 長期續發性後，甲狀旁腺失去調控，自主分泌 | 高 | — |

### 影像診斷要點 / Radiologic Hallmarks

| 發現 | 部位/說明 |
|------|-----------|
| **瀰漫性骨質脫礦** | 全身骨骼 |
| **骨膜下骨質吸收** | 最特異性表現 |
| **軟骨下骨質吸收** | 鎖骨胸骨端、恥骨聯合、膝關節 |

### 各部位特徵性表現 / Location-Specific Findings

| 部位 | 表現 |
|------|------|
| **顱骨** | 經典型「椒鹽顱骨 (Salt-and-Pepper Skull)」：骨小樑吸收所致 |
| **手部** | **第二、三中節指骨橈側的骨膜下骨質吸收/ scalloping**：對甲狀旁腺功能亢進有特異性 |
| **鎖骨** | 骨膜下骨質吸收好發於**肩峰端（遠端）** |
| **膝關節** | 股骨近端脛骨內側骨幹端的骨膜下骨質吸收 |
| **牙齒** | 牙槽周圍骨質吸收（齒板 (Lamina Dura) 消失）|
| **棕色瘤** | 原發性更常見 |
| **軟組織鈣化、骨膜反應、硬化** | 續發性更常見 |

### 實驗室異常 / Lab Abnormalities
| 項目 | 說明 |
|------|------|
| PTH | **升高** |
| 血鈣（原發性）| **升高** |
| 血磷（原發性）| **降低** |

### 併發症 / Complications
| 併發症 | 說明 |
|--------|------|
| 功能不全性骨折 | 骨質脆弱 |
| 韌帶/肌腱斷裂 | 傾向增加 |

### 臨床要點 / Clinical Key Points
1. **甲狀旁腺功能亢進** = 骨膜下骨質吸收（手部第二、三中節指骨橈側最特異）
2. **椒鹽顱骨** = 顱骨骨小樑吸收（甲狀旁腺功能亢進特徵）
3. **棕色瘤** = 原發性甲狀旁腺功能亢進更常見（需與巨細胞瘤鑑別）
4. **原發性**：高血鈣 + 低血磷；**續發性**：腎衰竭相關
5. **CPPD 沉積**：原發性甲狀旁腺功能亢進更常見
