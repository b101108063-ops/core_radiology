### 重要解剖關係
| 關係 | 說明 |
|------|------|
| 岡上肌腱 | 穿過肩峰下空間，最易受夾擊影響 |
| 二頭肌腱 | 長頭通過節稷間溝，與旋轉袖病變相關 |
| 唇緣 | 围绕关节盂，增加盂肱關節深度 |

### 臨床要點 / Clinical Key Points
1. **矢狀切片** = 評估旋轉袖肌肉萎縮和脂肪浸潤的最佳平面
2. **冠狀切片** = 評估岡上肌腱和肩峰下滑囊的最佳平面
3. **軸向切片** = 評估唇緣和後側關節囊
4. **二頭肌腱** = 長頭通過節稷間溝，為常見疼痛來源
5. 旋轉袖肌腱在**大結節**匯聚
