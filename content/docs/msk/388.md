# Musculoskeletal Imaging - Page 388

![Page 388](/core_radiology/images/msk/page-388.png)

## 造血細胞來源病變 / Lesions of Hematopoietic Origin

### 良性：巨細胞瘤（破骨細胞瘤）/ Benign: Giant Cell Tumor (Osteoclastoma)

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 骨骺溶骨性病變，**偏心性**位於長骨關節端 |
| 年齡 | 骨骼已成熟 (Skeletally Mature) 的 **20-40 歲**患者 |
| 起源 | 起源於骨幹端，穿過已閉合的**骨骺板**侵犯骨骺 |
| 細胞來源 | 與蝕骨細胞相似的**多核巨細胞** |

#### 影像診斷要點 / Imaging Features
| 部位 | 特徵 |
|------|------|
| X 光 | 偏心性溶骨性病變，**直達關節面軟骨下骨**，骨骺/骨幹端皆可延伸 |
| 好發位置 | **膝關節附近**（股骨遠端、脛骨近端） |

#### 良惡性與預後 / Behavior and Prognosis
| 項目 | 說明 |
|------|------|
| 良性 | 大多數為良性 |
| 惡性變 | 約 5%；原發病灶的影像學**無法區分**良惡性 |
| 相關疾病 | 佩吉氏病或甲狀旁腺功能亢進可見多灶性巨細胞瘤 |

#### 治療 / Treatment
- 刮除術 (Curettage) 或廣泛切除 (Wide Resection)

### 良性：嗜酸性肉芽腫（朗格漢斯細胞組織球增生症）/ Benign: Eosinophilic Granuloma (Langerhans Cell Histiocytosis, LCH)

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 免疫調節障礙疾病，由**組織球異常增生**所致 |
| 好發年齡 | 兒童 **5-10 歲** |

#### 各部位典型表現 / Location-Specific Findings

| 部位 | 表現 |
|------|------|
| **顱骨** | 特徵性**斜面邊緣溶骨性病變 (Beveled Edge)** |
| **下頜骨/上頜骨** | 齒槽骨吸收 → 游離齒 (Floating Tooth) |
| **脊柱** | **扁平椎 (Vertebra Plana)**：椎體完全塌陷 |
| **長骨** | 侵襲性溶骨性病變 + 常見**蔞層狀骨膜反應**（可似淋巴瘤或尤文氏肉瘤） |

---

### 惡性：尤文氏肉瘤 / Malignant: Ewing Sarcoma

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | **高度惡性的小圓細胞腫瘤**（與 PNET 相似） |
| 好發年齡 | 兒童及青少年；男性較多 |
| 臨床表現 | 非特異性，常有**疼痛**；可伴有發燒等全身症狀（與骨髓炎不易區分） |

#### 流行病學 / Epidemiology
| 項目 | 說明 |
|------|------|
| 發病率 | 兒童原發性骨腫瘤中**第二常見**（僅次於骨肉瘤） |

#### 影像診斷要點 / Imaging Features
| 特徵 | 說明 |
|------|------|
| 骨質破壞 | **穿鑿狀 (Permeative)** 破壞 |
| 骨膜反應 | **侵襲性**（蔞層狀、日光放射狀） |
| 常伴隨 | **軟組織腫塊** |

#### 侵襲性溶骨性病變的兒童鑑別診斷 / Differential Diagnosis in Children
| 病變 |
|------|
| 骨髓炎 (Osteomyelitis) |
| 嗜酸性肉芽腫 (Eosinophilic Granuloma) |
| 尤文氏肉瘤 (Ewing Sarcoma) |
| 神經母細胞瘤骨轉移 (Metastatic Neuroblastoma) |

### 臨床要點 / Clinical Key Points
1. **巨細胞瘤** = 骨骼成熟者 + 膝關節附近 + 偏心性溶骨 + 直達關節面
2. **巨細胞瘤**起源於骨幹端但穿過骨骺板侵犯骨骺（與其他骨腫瘤不同）
3. **扁平椎 (Vertebra Plana)** = 嗜酸性肉芽腫（LCH）的特徵（兒童）
4. **尤文氏肉瘤** = 兒童 + 穿鑿狀破壞 + 侵襲性骨膜反應 + 軟組織腫塊
5. **尤文氏肉瘤發燒** = 與骨髓炎臨床表現重疊，鑑別困難
