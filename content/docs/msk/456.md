# Musculoskeletal Imaging - Page 456

![Page 456](/core_radiology/images/msk/page-456.png)

## 二頭肌腱 / Biceps Tendon

### 二頭肌腱解剖 / Anatomy of the Biceps Tendon
| 項目 | 說明 |
|------|------|
| 起點 | 上方唇緣 (Superior Labrum) |
| 走勢 | 通過結節間溝 (Intertubercular Groove) |
| 滑囊鞘 | 與盂肱關節相通；滑囊鞘內少量液體可能為正常 |

### 二頭肌滑輪 / Biceps Pulley
| 項目 | 說明 |
|------|------|
| 定義 | 穩定二頭肌腱於溝內的囊韌帶複合體 |
| 組成 | SGHL + CHL + 肩胛下肌腱遠端纖維 |

---

## 二頭肌腱撕裂 / Biceps Tendon Tear

| 統計 | 說明 |
|------|------|
| 岡上肌撕裂 + 二頭肌損傷 | 約 **33%** 的岡上肌腱撕裂伴有二頭肌損傷（完全/部分撕裂或退化）|
| 撞擊風險 | 二頭肌腱因位於岡上肌腱下方而易受損 |

### 急性撕裂表現
| 發現 | 說明 |
|------|------|
| 肌肉遠端回縮 | 急性撕裂時，二頭肌肌肉可向遠端回縮 |
| 空的結節間溝 | 可能表示完全撕裂伴回縮或二頭肌腱脫位 |

---

## 二頭肌腱半脫位 / Biceps Tendon Subluxation

| 項目 | 說明 |
|------|------|
| 定義 | 肌腱從溝內移位，但仍與溝接觸 |
| 相關損傷 | 與橫韌帶損傷相關 |

### 橫韌帶 / Transverse Humeral Ligament
| 項目 | 說明 |
|------|------|
| 功能 | 附著於大結節與小結節，正常時將二頭肌腱固定於溝內 |

### 臨床要點 / Clinical Key Points
1. **二頭肌滑輪** = SGHL + CHL + 肩胛下肌腱遠端纖維
2. **二頭肌腱半脫位** = 肌腱離開但仍與溝接觸
3. **33% 的岡上肌撕裂**伴有二頭肌損傷
4. **空的結節間溝** = 完全撕裂伴回縮，或二頭肌腱脫位
5. **橫韌帶** = 穩定二頭肌腱於溝內
