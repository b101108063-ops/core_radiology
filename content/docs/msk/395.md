# Musculoskeletal Imaging - Page 395

![Page 395](/core_radiology/images/msk/page-395.png)

## 血源性骨髓炎（續）/ Hematogenous Osteomyelitis (Continued)

### 致病菌與感染途徑 / Pathogens and Routes

| 項目 | 說明 |
|------|------|
| 病原 | 血源性感染通常為**單一病原**；血培養陽性時可直接針對該菌種治療，通常不需切片 |
| 感染擴展 | 骨髓炎由內向外發展：先感染骨髓腔，再經 **Haversian 與 Volkmann 管**蔓延至皮質及骨膜 |

### 年齡相關的骨膜反應差異 / Age-Related Periosteal Reaction Differences

| 年齡 | 骨膜特徵 | X 光表現 |
|------|---------|---------|
| **嬰兒/兒童** | 骨膜疏鬆附著於骨頭 | 感染易使骨膜掀起，X 光上呈**旺盛性骨膜炎 (Exuberant Periostitis)** |
| **成人** | 骨膜緊密附著 | 骨膜炎通常較不顯著 |

### 成人血源性骨髓炎 / Adult Hematogenous Osteomyelitis
- **成人血源性骨髓炎最常影響脊椎**

### 慢性骨髓炎 / Chronic Osteomyelitis
| 組成 | 說明 |
|------|------|
| **死骨 (Sequestrum)** | 感染性壞死組織 |
| **骨包殼 (Involucrum)** | 包繞死骨的存活骨質 |
| **骨包殼開口 (Cloacae)** | 骨包殼上的孔洞 |
| **竇道 (Sinus Tract)** | 竇道通向皮膚；慢性竇道引流增加**鱗狀細胞癌**風險 |

### 早期 X 光改變 / Early Radiographic Changes
| 發現 | 說明 |
|------|------|
| 區域性骨質疏鬆 | 早期反應性充血 |
| 軟組織腫脹 | 侷限性 |
| 軟組織脂肪層消失 | 骨筋膜層次模糊 |
| 骨髓腔病變 | 局灶性、邊界不清的骨幹端低密度病變 |

### 骨幹端病變的特殊情況 / Epiphyseal Involvement in Young Children
- 在幼童，骨髓病變可**跨越骨骺板**（因跨骺板血管可能仍通暢）
- 骨膜反應可能呈侵襲性（蔞層狀），**可模擬尤文氏肉瘤**

## 連續性感染骨髓炎 / Contiguous Focus Osteomyelitis

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 感染穿透骨膜與皮質，再侵入骨髓腔 |
| 成人最常見原因 | **糖尿病足潰瘍**蔓延至骨骼（神經病變導致創傷未被察覺 + 血管儲備受損） |

### 感染途徑 / Pathway
軟組織感染 → 骨膜與皮質穿透 → 骨髓腔侵犯

### 臨床要點 / Clinical Key Points
1. **血源性骨髓炎**：嬰兒/兒童易見旺盛性骨膜炎；成人以脊椎最常見
2. **慢性骨髓炎**的竇道引流增加鱗狀細胞癌風險
3. **糖尿病足骨髓炎**：連續性蔓延為最常見機制
4. **蔞層狀骨膜反應**可模擬尤文氏肉瘤（需結合臨床與切片）
