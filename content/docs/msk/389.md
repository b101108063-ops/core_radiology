# Musculoskeletal Imaging - Page 389

![Page 389](/core_radiology/images/msk/page-389.png)

## 惡性：多發性骨髓瘤 / 漿細胞瘤 / Malignant: Multiple Myeloma (MM) / Plasmacytoma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | **40 歲以上患者最常見的原發性惡性骨腫瘤** |
| 本質 | 漿細胞惡性增生 |

### 影像診斷要點 / Imaging Features

| 表現 | 說明 |
|------|------|
| **顱骨 X 光** | 無數小型溶骨性病變（「真的洞」） |
| **長骨 X 光** | 穿鑿狀或瀰漫性骨質破壞；皮質內 scalloping |
| **最嚴重形式** | 瀰漫性骨髓瘤病 (Diffuse Myelomatosis) + 內皮 scalloping |

### 骨髓瘤 vs 轉移性病變的鑑別 / Myeloma vs Metastases

| 特徵 | 多發性骨髓瘤 | 轉移性腫瘤 |
|------|-------------|-----------|
| 起源 | 紅骨髓 | 依原發灶而異 |
| **椎體後柱 (Pedicles)** | 通常**不受侵犯** | 常受侵犯 |
| 骨掃描 | **通常為陰性** | 通常為陽性 |

### 變異型 / Variants

#### 硬化性骨髓瘤 (Sclerosing Myelomatosis)
| 組成 | 說明 |
|------|------|
| 關聯 | **POEMS 症候群** |

#### POEMS 症候群
| 字母 | 組成 |
|------|------|
| **P** | 多發性神經病變 (Polyneuropathy) |
| **O** | 器官腫大 (Organomegaly)（肝/脾） |
| **E** | 內分泌障礙 (Endocrine Disturbances)（閉經/男性女乳症） |
| **M** | 單株免疫球蛋白病 (Monoclonal Gammopathy) |
| **S** | 皮膚病變 (Skin Changes)（多毛症、色素沉著） |

### 單一性漿細胞瘤 / Solitary Plasmacytoma
| 項目 | 說明 |
|------|------|
| 定義 | 單一腫瘤 |
| 預後 | **大多數患者在 5 年內會發展為全身性多發性骨髓瘤** |

### 臨床要點 / Clinical Key Points
1. **多發性骨髓瘤** = 40 歲以上最常見的原發性惡性骨腫瘤 = 無數顱骨溶骨性病變
2. **骨髓瘤起源於紅骨髓** → 不侵犯椎體後柱（與轉移瘤不同）
3. **骨掃描陰性** = 骨髓瘤的特徵（與大多數轉移瘤不同）
4. **POEMS 症候群**：多發性神經病變 + 器官腫大 + 內分泌障礙 + 單株免疫球蛋白 + 皮膚病變
5. **單一性漿細胞瘤**：5 年內大多數會進展為全身性骨髓瘤
