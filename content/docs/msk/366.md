# Musculoskeletal Imaging - Page 366

![Page 366](/core_radiology/images/msk/page-366.png)

## 軟骨鈣化症 (CPPD) / Calcium Pyrophosphate Dihydrate Deposition Disease (CPPD)

### 疾病概述 / Disease Overview
- 又稱：**軟骨鈣化症**；晶體為**正性雙折射菱形結晶**
- 別名：**「終極模仿者」(Great Mimicker)**——可模擬多種關節病

### 臨床表現類型 / Clinical Manifestation Types

| 類型 | 發生率 |
|------|--------|
| 假性骨關節炎 (Pseudo-OA) | 最常見 |
| 假痛風 (Pseudogout) | 10–20% |
| 假類風濕關節炎 (Pseudo-RA) | 2–6% |
| 假神經病變性關節炎 (Pseudoneuropathic) | < 2% |
| 無症狀 | 10–20% |

### 相關疾病 / Associated Conditions
- 特發性（最常見）
- **血色素沉著症 (Hemochromatosis)**
- **甲狀旁腺功能亢進 (Hyperparathyroidism)**
- **低磷酸酯酶症 (Hypophosphatasia)**
- 50 歲以下罕見

### 影像診斷要點 / Diagnostic Key Points

| 特徵 | 說明 |
|------|------|
| **軟骨鈣化 (Chondrocalcinosis)** | 透明軟骨或纖維軟骨（半月板）鈣化；為 CPPD 特徵性表現 |
| X 光敏感度 | 膝、腕、骨盆（恥骨聯合）X 光對軟骨鈣化幾乎 100% 敏感 |

### CPPD 各關節侵犯 / Joint-Specific Findings

#### 腕關節 (Wrist)
| 特點 | 說明 |
|------|------|
| 典型侵犯部位 | **三角纖維軟骨複合體 (TFCC)** |
| 晚期併發症 | **SLAC 腕 (Scapholunate Advanced Collapse)**：豆狀骨與舟狀骨分離 + 頭狀骨近端遷移 |
| SLAC 腕原因 | RA、外傷亦可導致 |

#### 膝關節 (Knee)
| 特點 | 說明 |
|------|------|
| 首先侵犯 | 髕股間室 |
| 全部間室 | 病程進展後全部間室可受侵犯 |
| **孤立性髕股間室退化** | 高度提示 CPPD |
| **軟骨下囊性變明顯** | 高度提示 CPPD |

#### 手部 (Hands)
| 特點 | 說明 |
|------|------|
| 典型侵犯部位 | **第二、三 MCP 關節** |
| 特徵性骨刺 | 掌骨頭橈側**鉤狀或懸垂式骨刺 (Hook-like/Drooping Osteophytes)** |
| 血色素沉著症 | MCP 侵犯範圍更廣（可侵犯所有 MCP）|

### 臨床要點 / Clinical Key Points
1. **CPPD = 終極模仿者**：可模擬 OA、RA、神經病變性關節炎
2. **軟骨鈣化 (Chondrocalcinosis)**：CPPD 的標誌性 X 光表現
3. **孤立性髕股關節炎**：高度提示 CPPD
4. **TFCC 鈣化**：腕關節 CPPD 最常見部位
5. **SLAC 腕**：CPPD 晚期併發症（豆狀骨/舟狀骨分離 + 頭狀骨近端移位）
6. **鉤狀掌骨頭骨刺**：手部 CPPD 特徵（第二、三 MCP）
