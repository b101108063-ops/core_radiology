# Musculoskeletal Imaging - Page 390

![Page 390](/core_radiology/images/msk/page-390.png)

## 惡性：淋巴瘤 / Malignant: Lymphoma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 原發性骨淋巴瘤**非常罕見**，好發於 **40 歲以上成人** |
| X 光表現 | 侵襲性溶骨性病變；但也可能為**象牙質（彌漫性硬化）椎體**的重要鑑別診斷 |
| 特徵 | 常伴隨**鄰近軟組織腫塊** |

---

## 脂肪來源病變 / Fat (Lipo-) Lesions

### 良性：脂肪瘤 / Benign: Lipoma

#### 骨內脂肪瘤 (Intraosseous Lipoma)
| 項目 | 說明 |
|------|------|
| 發病率 | 不常見的良性腫瘤 |
| 好發位置 | **跟骨**、股骨粗隆下區、脛骨/腓骨遠端、蹠骨 |
| 影像特徵 | 取決於脂肪、鈣化、纖維組織及周邊硬化的程度；常見**中央或環狀鈣化** |
| X 光鑑別 | 跟骨內囊腫樣病灶：骨內脂肪瘤 vs 單純性骨囊腫 vs 動靜脈畸形骨囊腫 |

#### 軟組織脂肪瘤 (Soft-tissue Lipoma)
| 項目 | 說明 |
|------|------|
| 發病率 | **最常見的軟組織腫瘤** |
| 重要特徵 | 高達 **1/3 的脂肪瘤可能含有少量非脂肪組織**；少量非脂肪組織的存在**並不表示惡性變** |

---

### 惡性：脂肪肉瘤 / Malignant: Liposarcoma

#### 鑑別診斷：脂肪瘤 vs 分化良好脂肪肉瘤
| 特徵 | 分化良好脂肪肉瘤（又稱非典型脂肪瘤）|
|------|-------------------------------------|
| **病灶大小** | **> 10 cm** |
| **分隔厚度** | 粗厚分隔 |
| **軟組織成分** | 球形或結節狀軟組織 |
| **脂肪含量** | **< 75%** 脂肪 |

---

## 脊索來源病變 / Notochordal Lesions

### 惡性：脊索瘤 / Malignant: Chordoma

| 項目 | 說明 |
|------|------|
| 定義 | 起源於**脊索殘餘**的惡性病變 |
| 好發位置 | **軸向骨骼中線**：蝶枕區 (Spheno-occipital)、C2 椎體、或**薦尾骨** |
| X 光特徵 | **高度破壞性**，邊緣呈不規則扇貝狀 (Irregular Scalloped Borders) |
| 鈣化 | 病灶內可見鈣化；此鈣化為**壞死所致，非骨質形成** |

### 臨床要點 / Clinical Key Points
1. **骨淋巴瘤** = 40 歲以上 + 侵襲性溶骨或硬化 + 軟組織腫塊
2. **骨內脂肪瘤** = 跟骨最常見 + 中央/環狀鈣化為特徵
3. **軟組織脂肪瘤** = 最常見軟組織腫瘤；1/3 可含少量非脂肪組織
4. **分化良好脂肪肉瘤** = > 10 cm + 粗分隔 + < 75% 脂肪
5. **脊索瘤** = 軸向中線 + 蝶枕/C2/薦尾 + 扇貝狀邊緣 + 壞死性鈣化
