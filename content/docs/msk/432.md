## 剝脫性骨軟骨炎 / Osteochondrosis Dissecans (OCD)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 影響關節軟骨與骨頭的骨軟骨病變，被認為由**反覆性創傷**引起 |
| 好發年齡 | **青少年** |
| 病因 | 軟骨脫水而變硬，每次關節負重時傳遞更大力量至軟骨下骨 |

### OCD 分期 / OCD Staging

| 分期 | X 光表現 | T2 加權表現 | 穩定性 |
|------|---------|------------|--------|
| **Stage 1** | 正常 | 骨髓水腫 | 穩定 |
| **Stage 2** | 半圓形碎片 | 軟骨缺陷；低信號線周圍病灶 | 可能穩定 |
| **Stage 3** | 半圓形碎片（可移動）| 碎片周圍高信號線 | **不穩定** |
| **Stage 4** | 缺陷或游離體 | 缺陷/游離體 | **不穩定** |

### OCD 好發位置 / Common OCD Locations

| 關節 | 位置 |
|------|------|
| **膝關節（最常見）** | 內側股骨髁**外側** |
| **踝關節（第二常見）** | 距骨圓頂後內側或前外側 |
| **肘關節（體操/投擲運動員）** | 肱骨小頭前外側 |

### 不穩定型病灶 / Unstable Lesion
| 指標 | 說明 |
|------|------|
| MRI 表現 | 液體敏感序列上，碎片與底層骨頭之間有**曲線形高信號** |
| 意義 | 碎片與骨頭之間有液體間隔 = **不穩定** |

### 臨床要點 / Clinical Key Points
1. **OCD** = 青少年 + 反覆性創傷 + 膝關節內側股骨髁外側最常見
2. **OCD MRI 最重要的目標** = 判斷碎片穩定性
3. **T2 高信號線在碎片與骨頭之間** = 不穩定（需要手術）
4. **剝離 (Delamination)** = 軟骨下表面與骨頭的分離性損傷
5. **Stage 3-4 OCD** = 不穩定，需手術治療
