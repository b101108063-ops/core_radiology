# Musculoskeletal Imaging - Page 369

![Page 369](/core_radiology/images/msk/page-369.png)

## 幼年型特發性關節炎 (JIA) / Juvenile Idiopathic Arthritis (JIA)

### 疾病概述 / Disease Overview
- 舊稱：幼年型類風濕關節炎 (Juvenile Rheumatoid Arthritis)
- 16 歲以下兒童的慢性炎症性關節病總稱

### 臨床分類 / Clinical Classification

| 類型 | 說明 |
|------|------|
| **單關節/少關節型（最常見）** | 單一或少數關節（膝、踝、肘、腕） |
| **多關節型** | 系統性疾病；侵犯手、足、頸椎 + 單/少關節型關節 |
| **Still 病** | 全身性；< 5 歲；急性發燒、皮疹、淋巴結病、心包炎、輕微關節痛 |

### X 光特徵 / Radiographic Hallmarks
- **骨骺未閉合兒童的骨骼長度或形態異常**
- 原因：關節充血導致骨骼改變

### 生長發育異常 / Growth Disturbances
| 時期 | 表現 |
|------|------|
| 早發疾病 | 生長障礙更常見 |
| 骨骼改變 | 骨骼端過度生長 + 擴大（氣球樣） |
| 關節改變 | 骨骼成熟提前 + 骺板融合 |

### 各關節表現 / Joint-Specific Findings

#### 手部 (Hand)
| 表現 | 說明 |
|------|------|
| **第五掌骨縮短 (Brachydactyly)** | 骺板過早融合 |

#### 膝關節 (Knee)
| 表現 | 說明 |
|------|------|

| 干骺端展開 (Metaphyseal Flaring) | |
| 軟骨間隙均勻狹窄 | |

#### 肘關節 (Elbow)
| 表現 | 說明 |
|------|------|
| **橈骨頭增大** | 特徵性表現 |
| 滑車切跡增寬 | |
| 軟骨間隙均勻狹窄 | |
| 與血友病相似 | |

#### 髖關節 (Hip)
| 表現 | 說明 |
|------|------|
| 對稱性軟骨間隙狹窄 | |

#### 強直 (Ankylosis)
| 部位 | 說明 |
|------|------|
| 腕關節 | 常見 |

### 兒童頸椎強直鑑別診斷 / Differential Diagnosis
| 疾病 | 說明 |
|------|------|
| **JIA** | 頸椎強直 |
| **Klippel-Feil 症候群** | 頸椎分節失敗 |

### 臨床要點 / Clinical Key Points
1. **JIA**：骨骼成熟提前 + 骺板過早融合 → 肢體不等長/短縮
2. **腕關節和頸椎強直**：JIA 常見（與成人 RA 不同）
3. **Klippel-Feil 症候群**：兒童頸椎強直的鑑別診斷（分節失敗）
4. **Still 病**：全身性 JIA；< 5 歲；發燒 + 皮疹 + 心包炎
5. **JIA vs. 血友病**：兩者均呈現髁間切跡增寬和橈骨頭增大（相似）
