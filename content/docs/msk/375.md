## 骨質破壞型態：邊緣分析 / Bone Destruction Patterns: Margin Analysis

### 邊緣分析原則 / Margin Analysis Principles
- 分析骨病變的**邊緣地帶（正常骨與病變骨之間的過渡區）**有助於判斷侵襲性
- **邊緣清晰**（銳利邊界）：通常代表生長緩慢、侵襲性較低的病灶
- **邊緣模糊**（寬过渡区）：代表快速生長、高度侵襲性病灶

### Lodwick 骨質破壞分類 / Lodwick Classification of Bone Destruction

| 分型 | 特徵 | 侵襲性 |
|------|------|--------|
| **Type 1：地理性破壞 (Geographic)** | 薄層過渡區，邊緣可為硬化性或清晰 | 非侵襲性至低侵襲性 |
| — Type 1A | 邊緣為薄層硬化帶 | 幾乎均為非侵襲性 |
| — Type 1B | 邊緣清晰明確 | 通常為非侵襲性 |
| — Type 1C | 邊緣任何部分模糊 | 具侵襲性潛力 |
| **Type 2：蟲蝕狀破壞 (Moth-eaten)** | 幾乎無法界定任何邊界 | **侵襲性** |
| **Type 3：穿鑿狀破壞 (Permeative)** | 多發性微小孔洞浸潤骨質 | **高度侵襲性** |

- Type 3 常見於：**淋巴瘤、白血病、尤文氏肉瘤**

### 腫瘤新生骨質 / New Matrix Created by Tumor

| 腫瘤類型 | 基質礦化特徵 | X 光表現 |
|---------|-------------|---------|
| **骨樣病變（惡性骨肉瘤）** | 骨質基質 | 蓬鬆、雲霧狀骨影（"fluffy, cloud-like"） |
| **軟骨來源的病變**（良性內生軟骨瘤或惡性軟骨肉瘤） | 軟骨基質 | **環弧狀 (Ring & Arc)** 或**爆米花狀 (Popcorn-like)** 礦化 |
| **纖維結構不良 (Fibrous Dysplasia)** | 玻璃樣基質 | 骨髓腔透明度下降，骨小樑模糊（"Ground Glass"） |

### 特殊徵象 / Unique Features

| 徵象 | 疾病 |
|------|------|
| **游離骨碎片徵 (Fallen-fragment Sign)** | 單純性（單房性）骨囊腫合併病理性骨折 |
| **囊狀/膨脹性外觀** | 動靜脈畸形 (Aneurysmal Bone Cyst) |
| **鎖骨遠端吸收 或 腫瘤性鈣化** | 甲狀旁腺功能亢進（可見棕色瘤） |

### 患者年齡與侵襲性病變 / Patient Age and Aggressive Lytic Lesions

| 年齡 | 最可能的侵襲性溶骨性病變 |
|------|------------------------|
| **> 40 歲** | **轉移性腫瘤** 或 **骨髓瘤** |
| **< 20 歲** | 嗜酸性肉芽腫、感染、或**尤文氏肉瘤** |

### 病變位於骨內的位置 / Location Within Bone

| 位置 | 常見病變 |
|------|---------|
| **偏心性 (Eccentric)** | 巨細胞瘤、軟骨母細胞瘤、動靜脈畸形骨囊腫、 non-ossifying fibroma、軟骨黏液樣纖維瘤 |
| **中央性 (Central)** | 單純性骨囊腫、內生軟骨瘤、纖維結構不良 |

### 臨床要點 / Clinical Key Points
1. **Lodwick Type 1（地理性）→ 良性或低侵襲性；Type 2-3 → 侵襲性**
2. **蟲蝕狀或穿鑿狀破壞 + 40歲以上**：優先考慮轉移或骨髓瘤
3. **軟骨基質礦化**：環弧狀或爆米花狀 = 軟骨性腫瘤
4. **雲霧狀骨質**：骨肉瘤特徵（細胞成骨性分化）
5. **鎖骨遠端吸收 + 棕色瘤**：高度提示**甲狀旁腺功能亢進**
6. **年輕人侵襲性溶骨性病變**：嗜酸性肉芽腫 > 感染 > 尤文氏肉瘤
