# Musculoskeletal Imaging - Page 346

![Page 346](/core_radiology/images/msk/page-346.png)

## 椎間盤脫出與游離碎片 / Herniated Disc and Sequestered Fragment

### 疾病概述 / Disease Overview
- **椎間盤脫出 (Herniated Disc)**：髓核向後突出至纖維環之外
- **游離碎片 (Sequestered Fragment)**：脫出的椎間盤物質與原椎間盤分離，可向上或向下遷移
- 游離碎片的存在可能妨礙微創手術的進行，外科醫師需預先知情

### 臨床特徵 / Clinical Features
- 腰痛 (Low back pain)
- 放射性疼痛 (Radicular pain)
- 感覺異常或運動無力

### 影像診斷要點 / Diagnostic Key Points
| 類型 | MRI 特徵 |
|------|----------|
| 正常 | 正常椎間盤信號 |
| 突出 (Protrusion) | 纖維環後方局限性突出 |
| 向下遷移 | 脫出物沿椎體後方向下移動 |
| 游離碎片 | 脫出物與母盤完全分離，可遷移 |

### 鑑別診斷 / Differential Diagnosis
- **椎間盤突出 vs. 游離碎片**：游離碎片與母盤無連續性
- 椎間盤脫出 vs. 骨質增生：骨質增生信號與骨一致

## 一般退化性變化 / General Degenerative Changes

### 椎間盤脫水 (Disc Desiccation)
- 隨年齡增長，椎間盤含水量減少
- **T2 縮短**：T2 加權影像呈低信號（黑盤徵）

### 椎間隙高度喪失 / Loss of Disc Space Height
- 可影響多個椎間隙水平

### 骨刺 / Osteophytes
- 可向前或向後突出
- 頸椎前緣骨刺可能導致吞嚥困難 (Dysphagia)
- 向後突出可導致椎管或神經孔狹窄

### 軟骨終板內凸 (Schmorl's Node)
- 椎間盤向相鄰椎體終板突出
- 形成終板處圓形骨質缺損
- 急性 Schmorl's node：T2 加權影像可呈高信號，可致背痛

## 脊椎骨終板變化——Modic 改變 / Vertebral Endplate Changes – Modic Changes

### Modic 類型分類 / Classification

| 類型 | T1 信號 | T2 信號 | 病理基礎 | 臨床意義 |
|------|---------|---------|----------|----------|
| **Type 1** | 低信號 | 高信號 | 骨髓水腫與發炎 | 與活動性背痛相關，術後預後較佳 |
| **Type 2** | 高信號 | 高信號 | 脂肪組織增生 | 慢性骨髓缺血，症狀較輕 |
| **Type 3** | 低信號 | 低信號 | 骨質硬化 | 臨床意義不明 |

### 黃韌帶內摺/肥厚 / Ligamentum Flavum Infolding/Hypertrophy
- 黃韌帶位於椎板後方、椎管後部
- 黃韌帶肥厚可導致**椎管狹窄 (Spinal Canal Stenosis)**
- "內摺 (Infolding)"、"向內屈曲 (Inward Buckling)"、"肥厚 (Hypertrophy)" 皆用於描述此現象

### 臨床要點 / Clinical Key Points
1. **椎間盤脫出**：游離碎片的手術難度較高
2. **Modic Type 1**：預測腰椎手術較佳結局
3. **Modic Type 2**：通常與慢性、無活動性症狀相關
4. **黃韌帶肥厚**：是椎管狹窄的重要原因之一
