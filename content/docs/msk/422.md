# Musculoskeletal Imaging - Page 422

![Page 422](/core_radiology/images/msk/page-422.png)

## 半月板黏液樣變性 vs 撕裂 / Myxoid Degeneration vs Tear

### 黏液樣變性 / Myxoid Degeneration
| 特徵 | 說明 |
|------|------|
| MRI 表現 | 半月板內信號增加，**但未延伸至半月板關節面** |
| 臨床意義 | 通常無症狀，不需治療 |

### 半月板撕裂 / Meniscal Tear
| 特徵 | 說明 |
|------|------|
| MRI 表現 | 線性信號增加，**延伸至半月板關節面** |
| 形態 | 半月板形態通常異常 |
| MRI 敏感度/特異度 | **均 > 90%** |

---

## 斜行/水平撕裂 / Oblique / Horizontal Tear

| 項目 | 說明 |
|------|------|
| 術語 | 斜行與水平撕裂有時可交換使用 |
| 嚴格定義 | 水平撕裂**平行於脛骨平台**；斜行撕裂**與平台呈輕微角度** |

### 臨床特徵 / Clinical Features
| 特徵 | 說明 |
|------|------|
| 發生率 | **最常見的半月板撕裂類型** |
| 好發位置 | **內側半月板後角** |
| 病因 | 通常為**退化性**（非創傷性）|

### 相關發現 / Associated Findings
| 發現 | 說明 |
|------|------|
| 半月板旁囊腫 (Parameniscal Cysts) | 可伴隨水平/斜行撕裂出現 |

### 臨床要點 / Clinical Key Points
1. **半月板黏液樣變性** = 信號增加但**不**延伸至關節面（無需治療）
2. **半月板撕裂** = 信號增加**延伸至**關節面 + 形態異常
3. **斜行/水平撕裂** = 最常見類型 + 內側半月板後角 + 通常退化性
4. **半月板旁囊腫** = 水平撕裂的常見伴隨發現
5. **MRI 診斷半月板撕裂** = 敏感度與特異度皆 > 90%
