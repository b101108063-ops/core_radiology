# Musculoskeletal Imaging - Page 379

![Page 379](/core_radiology/images/msk/page-379.png)

## 骨肉瘤亞型（續）/ Osteosarcoma Subtypes (Continued)

### 血管擴張型骨肉瘤 / Telangiectatic Osteosarcoma

| 特徵 | 說明 |
|------|------|
| 性質 | 純溶骨性破壞性肉瘤，影像上可能類似良性**動靜脈畸形骨囊腫 (ABC)** |
| **MRI 鑑別關鍵** | 病灶內有**實性結節狀成分 (Solid Nodular Components)** → 傾向血管擴張型骨肉瘤 |
| 骨質基質 | **不產生任何骨質基質**（與其他骨肉瘤不同） |
| 病理 | 腫瘤內血管豐富，大囊腔內充滿血液（"血管豐富"） |
| 預後 | 新治療方式提升存活率，略優於傳統型骨肉瘤 |

### 皮質旁骨肉瘤 / Parosteal (PAR-osteal) Osteosarcoma

| 特徵 | 說明 |
|------|------|
| 起源 | **外層骨膜 (Outer Periosteum)**，屬皮質旁 (Juxtacortical) 骨肉瘤 |
| 好發位置 | **股骨遠端後側骨幹端**（最常見） |
| 外觀 | **花椰菜樣外生性形態**（諧音：par-BOIL cauliflower before eating） |
| 影像特徵 | 皮質與病變間可能見**低密度線 (Lucent Line)** |
| 患者年齡 | 通常 **30-40 歲**（比其他亞型年長） |
| 預後 | 所有骨肉瘤中**惡性度最低**，5 年存活率約 **90%** |

### 皮質內骨肉瘤 / Periosteal (PERI-osteal) Osteosarcoma

| 特徵 | 說明 |
|------|------|
| 起源 | **內層骨膜 (Inner Periosteum)**，屬皮質旁骨肉瘤 |
| 影像特徵 | 皮質增厚 + 侵襲性骨膜反應 + 軟組織腫塊 |
| 組織學 | 可呈現軟骨樣分化 (Chondroid Differentiation) |
| 好發位置 | **股骨或脛骨骨幹 (Diaphysis)** |
| 患者年齡 | 通常 **< 20 歲** |

### 各亞型預後比較 / Prognosis Comparison

| 亞型 | 預後 |
|------|------|
| **Parosteal** | 最佳（5 年存活 ~90%，低度惡性） |
| **Periosteal** | 中等（較傳統型佳） |
| **Telangiectatic** | 略優於傳統型（新型治療） |
| **Conventional** | 傳統預後 |

### 骨肉瘤轉移 / Metastasis
- 骨肉瘤最常轉移至**肺部**
- 肺轉移灶通常**鈣化**（因腫瘤產生骨質基質）

### 臨床要點 / Clinical Key Points
1. **Telangiectatic = 純溶骨性 + 囊性外觀 + 實性結節區分 ABC**
2. **Parosteal = 股骨遠端後側 + 花椰菜樣 + 30-40 歲 + 預後最佳**
3. **Periosteal = 皮質內層起源 + 軟骨樣分化 + < 20 歲 + 股骨/脛骨骨幹**
4. **骨肉瘤 → 肺部鈣化性轉移**：最常見的遠處轉移
5. **記憶口訣**：PAR-BOIL Cauliflower（皮質旁）；PERI-osteal（皮質內）
6. **影像策略**：懷疑 Telangiectatic 型時，MRI 的實性結節成分為關鍵鑑別點
