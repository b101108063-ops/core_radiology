# Musculoskeletal Imaging - Page 378

![Page 378](/core_radiology/images/msk/page-378.png)

## 良性：骨母細胞瘤 / Benign: Osteoblastoma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 良性成骨性腫瘤，**組織學上與骨樣骨瘤相同**，但大小 > 2 cm |
| 發病率 | 約為骨樣骨瘤的 1/4 |
| 年齡 | 青少年/年輕成人（與骨樣骨瘤相同） |
| 疼痛特點 | 與骨樣骨瘤不同，**疼痛通常不被阿斯匹靈緩解** |

### 好發位置 / Location
| 位置 | 說明 |
|------|------|
| **脊柱後柱**（最常見） | 頸椎至薦椎皆可發生 |
| 股骨、脛骨 | 長骨亦可發生 |

### 影像特徵 / Imaging Features
| 特徵 | 說明 |
|------|------|
| X 光表現 | 溶骨性病變 + 礦化（最常見） |
| 侵襲性變異（罕見） | 可有大型軟組織腫塊，但**無轉移潛能** |
| 繼發性 ABC | 脊柱病灶常見繼發性動靜脈畸形骨囊腫 |

### 鑑別診斷 / Differential Diagnosis
- 年輕人後脊柱溶骨性病變：**骨母細胞瘤** vs **動靜脈畸形骨囊腫 (ABC)**
- 若病灶內有**任何礦化** → 傾向骨母細胞瘤

## 惡性：骨肉瘤 / Malignant: Osteosarcoma

### 疾病概述 / Disease Overview
- 骨肉瘤是**異質性惡性腫瘤**群組，腫瘤細胞起源於**骨質細胞譜系**，多數亞型皆產生**骨質基質 (Osteoid Matrix)**
- 可分為**原發性**與**繼發性**（由佩吉氏病或放射治療後產生；佩吉氏病相關骨肉瘤預後極差）

### 影像診斷要點 / Imaging Hallmarks
| 表現 | 說明 |
|------|------|
| 骨質破壞 | 溶骨性/成骨性或混合性 |
| **骨質基質 (Osteoid Matrix)** | 蓬鬆雲霧狀礦化（確診關鍵） |
| 侵襲性骨膜反應 | 日光放射狀、Codman 三角 |
| 軟組織腫塊 | 常伴隨 |

### 主要亞型 / Major Subtypes

| 亞型 | 占比 | 年齡/好發 | 特徵 |
|------|------|-----------|------|
| **傳統型（髓內型）** | 75% | 青少年/年輕成人；膝關節附近（股骨/脛骨骨幹端） | 骨髓腔內骨質基質 + 皮質破壞 + 侵襲性骨膜反應 + 軟組織腫塊 |
| 血管擴張型 (Telangiectatic) | — | 與傳統型相似 | 純溶骨性破壞（見下節） |
| 皮質旁型 (Parosteal) | — | 30-40 歲；股骨遠端後側 | 皮質外生長，花椰菜樣外觀（見下節） |
| 皮質內型 (Periosteal) | — | < 20 歲；股骨/脛骨骨幹 | 皮質增厚 + 侵襲性骨膜反應（見下節） |

### 臨床要點 / Clinical Key Points
1. **傳統型骨肉瘤** = 青少年膝關節附近 + 蓬鬆雲霧狀骨質基質 + 侵襲性骨膜反應
2. **骨肉瘤 4 大影像特徵**：骨質破壞 + 骨質基質 + 侵襲性骨膜反應 + 軟組織腫塊
3. **早期骨肉瘤**：可能只表現為輕微骨質硬化，易被忽略
4. **脊柱後柱溶骨性病變 + 礦化 → 骨母細胞瘤（> 2 cm）**
5. **疼痛不被阿斯匹靈緩解**：骨母細胞瘤與骨樣骨瘤的臨床鑑別點
