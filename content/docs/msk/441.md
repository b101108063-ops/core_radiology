# Musculoskeletal Imaging - Page 441

![Page 441](/core_radiology/images/msk/page-441.png)

## 短暫性骨髓水腫 / Transient Bone Marrow Edema (TBME)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 別名 | 髖關節短暫性骨質疏鬆症 (Transient Osteoporosis of the Hip) |
| 性質 | 排除性診斷；可能代表多種疾病的組合（交感神經過度活化、應力骨折、短暫性缺血）|

### 臨床特徵 / Clinical Features
| 項目 | 說明 |
|------|------|
| 病程 | 傳統認為是**自限性**，持續數月 |
| 好發族群 | 年輕至中年人（**男性較常見**；首見於妊娠晚期女性）|
| 症狀 | 嚴重髖關節疼痛 |

### 影像表現 / Imaging Features
| 檢查 | 表現 |
|------|------|
| **X 光** | 股骨頭區域性骨質疏鬆；軟骨間隙保留；無關節炎次發性徵象、無侵蝕或髖臼形態異常 |
| **MRI T1** | 瀰漫性低信號，對應 T2 高信號；信號異常可從股骨頭延伸至股骨頸 |

### 重要臨床提醒
| 提醒 | 說明 |
|------|------|
| TBME 可能為「廢紙簍」診斷 | 必要時始終評估是否有其他病變解釋這些發現（如：T1 上軟骨下低信號線可能是骨折；AVN 小病灶也可能可見）|

## 唇緣損傷 / Labral Injury

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 髖臼唇為纖維軟骨環，功能上加深髖臼 |
| 與肩關節的差異 | 股骨髖臼關節為球窩關節，本質穩定，不像肩關節那樣依賴韌帶與肌肉支撐 |
| 命名爭議 | 有人建議稱為「剝離 (Detachment)」而非「撕裂」，但術語使用不一致 |

### 病因 / Etiology
| 病因 | 說明 |
|------|------|
| 急性創傷 | 可造成唇緣剝離 |
| **慢性反覆微創傷** | 更常見的原因 |
| 危險因素 | 股骨髖臼發育不良（發育性髖關節發育不良）、**股骨髖臼撞擊症 (FAI)** |

### 診斷方法 / Diagnosis
| 方法 | 說明 |
|------|------|
| **MR 關節造影** | 最佳診斷工具；顯示對比劑局部浸潤至唇緣部分下方 |
| 好發位置 | **前上方 (Anterosuperior)** 最常見 |
| 注意 | 髖關節下方**無唇緣** |

### 臨床要點 / Clinical Key Points
1. **TBME** = 自限性 + 股骨頭/頸瀰漫性信號異常（排除其他病變）
2. **TBME** 的 X 光 = 區域性骨質疏鬆 + 軟骨間隙保留
3. **唇緣損傷** = 典型為慢性反覆微創傷；MR 關節造影最佳
4. **唇緣損傷最常見位置** = 前上方 (Anterosuperior)
5. **股骨髖臼撞擊症 (FAI)** = 年輕運動員髖關節疼痛的重要原因
