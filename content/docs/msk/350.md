# Musculoskeletal Imaging - Page 350

![Page 350](/core_radiology/images/msk/page-350.png)

## 脊髓縱裂畸形 / Diastematomyelia

### 疾病概述 / Disease Overview
- **Diastematomyelia（脊髓縱裂畸形）**：先天性脊髓分裂
- 可導致**脊柱側彎 (Scoliosis)**
- 兩條半脊髓存在於同一硬膜囊內（部分類型）或各自位於獨立硬膜囊

### 影像診斷要點 / Diagnostic Key Points

| 檢查 | 典型表現 |
|------|----------|
| **MRI（T2 冠狀位）** | 兩條半脊髓之間 CSF 信號（呈現為分隔） |
| **MRI（T2 軸位）** | 單一 CSF 空間內兩條半脊髓 |
| **X 光** | 可見伴發胸腰椎右旋性脊柱側彎 |

### 臨床特徵 / Clinical Features
- 背部疼痛
- 下肢無力或感覺異常
- 脊柱側彎（可能為首發表現）

### 鑑別診斷 / Differential Diagnosis
- Diastematomyelia vs.  tethered cord：兩者均可導致脊柱側彎
- 完全性分裂 vs. 部分性分裂（有或無骨性/軟骨性中隔）

### 臨床要點 / Clinical Key Points
1. **先天性脊髓分裂**：是兒童脊柱側彎的病因之一
2. **MRI（T2 冠狀位 + 軸位）**是確診的關鍵序列
3. 發現脊髓縱裂時應同時評估是否合併拴繫

## 脂肪性終絲 / Fatty Filum

### 疾病概述 / Disease Overview
- **終絲 (Filum Terminale)**：連接脊髓圓錐與尾骨的細絲狀結構
- **脂肪性終絲**：終絲內含有脂肪組織

### 臨床意義 / Clinical Significance

| 合併情況 | 臨床意義 |
|----------|----------|
| 脂肪性終絲 + 脊髓縱裂 | 需手術治療 |
| 脂肪性終絲 + 脊髓拴繫 | 需手術治療 |
| 脂肪性終絲（單獨存在） | 通常無臨床意義 |

### 影像診斷要點 / Diagnostic Key Points
- **T1 加權 MRI**：高信號病變位於終絲（脂肪組織特徵性表現）
- 需確認是否同時合併脊髓縱裂或拴繫

### 臨床要點 / Clinical Key Points
1. **脂肪性終絲**：T1 高信號是特徵性表現
2. **臨床評估**：需確認是否合併脊髓縱裂或拴繫症候群
3. 單獨存在的脂肪性終絲若無症狀，通常無需治療
