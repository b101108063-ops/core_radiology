## 骨骼與關節基礎 / Basics of Bones and Joints

### 長骨解剖 / Anatomy of a Long Bone

| 部位 | 說明 |
|------|------|
| **骨骺 (Epiphysis)** | 骨端，軟骨下方的海綿骨區域 |
| **骺板 (Physis/Growth Plate)** | 軟骨生長板，負責縱向生長 |
| **幹骺端 (Metaphysis)** | 骨骺與骨幹之間的過渡區 |
| **骨幹 (Diaphysis)** | 骨的長軸主體部分 |

### 滑膜關節解剖 / Anatomy of a Synovial Joint

| 結構 | 說明 |
|------|------|
| **關節軟骨 (Articular Cartilage)** | 覆蓋關節面的透明軟骨 |
| **滑膜 (Synovium)** | 分泌滑液 |
| **關節腔 (Joint Space)** | 充滿滑液 |
| **無軟骨區 (Bare Area)** | 關節囊內關節囊附著處，無軟骨覆蓋；為**類風濕關節炎**最早侵蝕部位 |

## 關節炎總論 / Arthritis Overview

### 關節炎分類 / Classification of Arthritis

| 類別 | 代表性疾病 |
|------|-----------|
| **退化性 (Degenerative)** | 骨關節炎 (Osteoarthritis) |
| **發炎性 (Inflammatory)** | 類風濕關節炎、脊椎關節病變、幼年型特發性關節炎 |
| **晶體沉積性 (Crystal Deposition)** | 痛風、軟骨鈣化症 (CPPD)、氫氧基磷灰石沉積症 |
| **血液性疾病 (Hematologic)** | 血友病 |
| **代謝性 (Metabolic)** | 痛風、假痛風 |

### 關節炎共同特徵 / Hallmark Findings
- **軟骨破壞** → X 光表現為關節間隙狹窄

## 骨關節炎 (OA) / Osteoarthritis (OA)

### 疾病概述 / Disease Overview
- 又稱：**骨關節病 (Osteoarthrosis)** 或 **退化性關節病 (Degenerative Joint Disease, DJD)**
- **軟骨機械性磨損**：局部機械因素改變導致軟骨崩解
- OA 不僅影響軟骨，還涉及：**骨、韌帶、半月板、關節囊、滑膜、肌肉**

### 好發部位 / Common Sites
- 承重關節（膝、髖）
- 手部特定分布

### X 光特徵性表現 / Radiographic Hallmarks of OA

| 表現 | 說明 |
|------|------|
| **不對稱性關節間隙狹窄** | 非均匀性軟骨丢失 |
| **軟骨下骨硬化 (Subchondral Sclerosis)** | 軟骨丢失後的反應性骨重塑 |
| **骨刺 (Osteophytosis)** | 關節邊緣骨質增生 |
| **軟骨下囊性變 (Subchondral Cystic Change)** | 關節液通過軟骨缺損突 入骨頭 |
| **無關節周圍骨質疏鬆** | 與發炎性關節炎鑑別要點 |

### 鑑別診斷要點 / Differential Diagnosis
- 軟骨下囊性變廣泛時需考慮 **CPPD（軟骨鈣化症）**

### 臨床要點 / Clinical Key Points
1. **退化性關節炎**：軟骨下硬化 + 骨刺 + 軟骨下囊性變 + 無發炎性侵蝕
2. **軟骨下囊性變**：關節液通過軟骨缺損突入骨頭
3. 年輕患者或非典型位置（肩、肘、踝）出現 OA 時，應排查外傷史或潛在關節炎
