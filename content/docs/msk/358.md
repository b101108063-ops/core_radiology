# Musculoskeletal Imaging - Page 358

![Page 358](/core_radiology/images/msk/page-358.png)

## 髖關節骨關節炎 / Osteoarthritis in the Hip

### X 光特徵 / Radiographic Features
- 關節間隙狹窄
- 骨刺
- 軟骨下囊性變
- 軟骨下硬化

### 股骨頭移位方向——OA vs. RA / Femoral Head Migration Patterns

| 移位方向 | 疾病 | 說明 |
|----------|------|------|
| **上外側移位 (Superolateral)** | 骨關節炎（典型） | 股骨頭向上外側移位 |
| **內側移位 (Medial)** | 骨關節炎（較少見） | 股骨頭向內移位 |
| **軸向移位 (Axial)** | 類風濕關節炎（典型） | 股骨頭同心圓性向下移位 |
| **嚴重軸向移位** | 嚴重 RA | 髖臼突出 (Protrusio Deformity) |

### 臨床特徵 / Clinical Features
- 雙側侵犯為典型表現
- 髖臼軟骨流失 → 股骨頭軸向（向下）移位
- 嚴重 RA 可導致**髖臼突出畸形 (Protrusio Deformity)**：股骨頭向內超過髂坐線（男 >3mm，女 >6mm）

## 脊椎退化性變化 / Degenerative Change in the Spine

### 椎間盤解剖 / Intervertebral Disc Anatomy
- **椎間盤**：由三部分組成
  - 纖維環 (Annulus Fibrosus)
  - 髓核 (Nucleus Pulposus)
  - 軟骨終板 (Cartilaginous Endplates)
- 椎體終板：覆蓋透明軟骨，與其他關節軟骨相似

### 脊椎骨關節炎 / Spinal Osteoarthritis
- **骨關節炎只影響滑膜關節**
- 脊椎可發生骨關節炎的關節：
  - 關節突關節 (Facet/Zygapophyseal Joints)
  - 寰樞關節 (Atlantoaxial Joint)
  - 鉤椎關節 (Uncovertebral Joints, C3–C7)
  - 肋椎關節 (Costovertebral Joints)
  - 骶髂關節 (Sacroiliac Joints)

### 退化性椎間盤疾病 (DDD) / Degenerative Disc Disease (DDD)
- 椎間盤脫水
- 終板硬化
- 骨刺增生

### 真空現象 / Vacuum Phenomenon
- **椎間盤內氣體**（多為氮氣）
- **退化性疾病的特異性表現**
- ⚠️ 需與 **Kümmel 病** 鑑別：

|  | 真空現象 | Kümmel 病 |
|---|----------|-----------|
| 位置 | 椎間盤內 | 椎體壓縮骨折內 |
| 病因 | 退化 | 骨折後骨壞死 |

### DDD 併發症 / Complications of DDD
- **脊椎椎管狹窄 (Spinal Stenosis)**
- **神經孔狹窄 (Neural Foraminal Stenosis)**
- **退化性脊椎滑脫 (Degenerative Spondylolisthesis)**

### DISH vs. DDD

| 疾病 | 特徵 |
|------|------|
| **DISH** | 前緣橋接骨刺 ≥ 4 椎體；椎間隙正常；骶髂關節正常 |
| **DDD** | 椎間盤退變；終板硬化 |

## 骶髂關節骨關節炎 / Osteoarthritis in the Sacroiliac (SI) Joint

### 解剖要點 / Anatomical Note
- 骶髂關節**僅下1/2**為滑膜關節
- 上1/2為韌帶結合關節 (Syndesmosis)
- **OA 變化僅見於下1/2（滑膜部分）**

### 臨床要點 / Clinical Key Points
1. **髖關節 OA**：股骨頭**上外側移位**為典型；RA 為**軸向移位**
2. **Protrusio Deformity**：股骨頭超過髂坐線，男 >3mm，女 >6mm
3. **脊椎 OA**：只影響滑膜關節（關節突、寰樞、鉤椎、肋椎、骶髂關節下1/2）
4. **真空現象**：椎間盤內氣體 = 退化性病變特異性；非 Kümmel 病
5. **DISH**：前緣橋接骨刺 ≥ 4 椎體 + 椎間隙及骶髂關節正常
