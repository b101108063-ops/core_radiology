# Musculoskeletal Imaging - Page 392

![Page 392](/core_radiology/images/msk/page-392.png)

## 骨骼轉移 / Osseous Metastasis

### 流行病學 / Epidemiology
- 骨骼轉移比原發性骨腫瘤**常見十倍以上**
- 大多數轉移發生於**紅骨髓**，最常見於**中軸骨骼**（脊椎、骨盆、肋骨）

### 病理性骨折的影像線索 / Imaging Clues to Pathologic Fracture

| 發現 | 意義 |
|------|------|
| **椎體後柱或椎體後部受侵犯** | 高度暗示轉移性病灶（與骨質疏鬆壓迫骨折鑑別） |
| **小轉子骨折** | 應懷疑病理性骨折 |
| **單一性胸骨病灶** | 若患者有乳腺癌病史，**高度預測為轉移** |

### 溶骨性與成骨性轉移 / Lytic vs Blastic (Sclerotic) Metastases

| 溶骨性轉移 (Lytic) | 成骨性/硬化性轉移 (Blastic/Sclerotic) |
|--------------------|---------------------------------------|
| **肺癌**（最常見的純溶骨性） | **乳腺癌**（可為溶骨或成骨） |
| **乳腺癌** | **前列腺癌、精原細胞瘤** |
| 甲狀腺癌 | 泌尿道上皮細胞癌 (TCC) |
| 腎細胞癌 | 黏液性腫瘤 |
| 胃癌、結腸癌（可為溶骨或成骨） | 類癌症瘤 |

## 良性腫瘤模擬病變 / Benign Tumor Mimics

### 骨化性肌炎 / Myositis Ossificans

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 創傷後骨骼肌內的**異位骨化 (Heterotopic Bone Formation)** |
| 創傷史 | 可能被遺忘或為輕微創傷 |
| 好發位置 | **肘關節和大腿**（易受創傷部位） |

#### 與骨旁骨肉瘤的鑑別 / MO vs Parosteal Osteosarcoma

| 病變 | 鈣化特徵 |
|------|---------|
| **骨旁骨肉瘤** | 通常**中心部**鈣化更緻密 |
| **骨化性肌炎** | 通常**周邊**鈣化更緻密 |

#### 病程演變 / Evolution Over Time

| 時間 | 表現 |
|------|------|
| **第 1-2 週** | 僅有軟組織腫塊 |
| **第 3-4 週** | 形成無定形骨質基質；鄰近骨頭可見骨膜反應（此階段最似早期骨肉瘤） |
| **第 5-8 週** | 病灶**周邊**成熟為緻密骨質 |
| **達 6 個月** | 骨化持續成熟 |
| **> 6 個月** | 通常開始縮小 |

#### 重要臨床提醒 / Critical Clinical Note
- **疑似骨化性肌炎時不應進行切片**：組織學可能類似肉瘤，導致不必要的手術

### 臨床要點 / Clinical Key Points
1. **轉移性病灶** >> 原發性骨腫瘤（10 倍以上）
2. **椎體後柱受累** → 轉移；無後柱受累 → 骨質疏鬆
3. **小轉子病理性骨折** → 高度懷疑惡性
4. **骨化性肌炎** = 周邊鈣化優先成熟（與骨旁骨肉瘤相反）
5. **骨化性肌炎疑似時禁止切片**：組織學可能誤判為肉瘤
6. **肺癌** = 最常見純溶骨性轉移；**前列腺癌** = 最常見成骨性轉移
