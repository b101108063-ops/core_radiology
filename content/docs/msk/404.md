## 佩吉氏病（續）/ Paget Disease (Continued)

### 長骨佩吉氏病 / Long Bones

| 階段 | 表現 |
|------|------|
| **溶骨期 (Phase I)** | 從關節端向骨幹進展，邊緣清晰（稱為「草葉狀/火焰狀邊緣 (Blade of Grass / Flame-shaped Margin)」）可與腫瘤區分 |
| 進展後 | 可導致長骨彎曲及**髖內翻畸形 (Coxa Vara Deformity)** |

---

## 遺傳性高磷酸酯酶血症（幼年型佩吉氏病）/ Hereditary Hyperphosphatasia (Juvenile Paget Disease)

| 項目 | 說明 |
|------|------|
| 遺傳方式 | 自體隱性遺傳 |
| 好發年齡 | 嬰兒及幼童 |
| X 光特徵 | 皮質增厚、骨小樑增厚、骨質疏鬆 + 全身骨骼彎曲（嚴重變形）|
| 與成人佩吉氏病的鑑別 | 患者年輕、廣泛侵犯；但外觀與成人佩吉氏病相似 |
| 特徵差異 | **幼年型佩吉氏病可見關節端保留 (Epiphyseal Sparing)** |

## 骨質石化病（大理石骨病）/ Osteopetrosis

| 項目 | 說明 |
|------|------|
| 發病機制 | 蝕骨細胞的碳酸酐酶極度缺乏 → 骨質無法被吸收 |
| X 光特徵 | **全身骨骼瀰漫性顯著硬化** |
| 併發症 | 骨骼極度脆弱 → **常見多發性骨折** |

### 椎骨特徵 / Vertebral Features
| 表現 | 說明 |
|------|------|
| 夾心椎/三明治椎 (Sandwich/Rugger Jersey Appearance) | 與腎性骨營養不良相似；但骨質硬化更為廣泛 |

## 高雪氏症 / Gaucher Disease

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 病因 | 自體隱性基因缺陷：葡萄糖腦苷脂酶 (Glucocerebrosidase) 缺乏 |
| 病理 | 異常腦苷脂沉積於變性巨噬細胞（高雪氏細胞）|
| 高雪氏細胞後果 | 骨骼梗塞、骨髓腔擴張、肝脾腫大 |

### X 光特徵 / Imaging Features

| 特徵 | 說明 |
|------|------|
| **錐形燒瓶畸形 (Erlenmeyer Flask Deformity)** | 長骨異常塑形的結果（骨髓腔不漸細）|
| **H 形椎體** | 終板缺血性壞死所致 |

### H 形椎體的鑑別診斷 / Differential Diagnosis of H-shaped Vertebral Bodies
| 疾病 | H 形椎體 | 脾臟大小 |
|------|---------|---------|
| **高雪氏症** | 有 | 脾腫大 (Splenomegaly) |
| **鐮刀型紅血球疾病** | 更常見 | 脾臟自發性梗塞（萎縮）|

### 臨床要點 / Clinical Key Points
1. **佩吉氏病長骨**：火焰狀/草葉狀邊緣為溶骨期特徵（可與腫瘤區分）
2. **幼年型佩吉氏病**：全身骨骼彎曲 + 皮質/骨小樑增厚 + 關節端保留
3. **骨質石化病** = 骨質無法吸收 → 全身硬化 + 脆性骨折
4. **高雪氏症**：Erlenmeyer Flask 畸形 + H 形椎體 + 脾腫大
5. **H 形椎體**：高雪氏症 vs 鐮刀型紅血球疾病（脾臟大小是關鍵鑑別點）
