# Musculoskeletal Imaging - Page 415

![Page 415](/core_radiology/images/msk/page-415.png)

## 距骨軟骨病變 / Osteochondral Lesion of the Talus

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 涵蓋慢性反覆微創傷引起的**剝脫性骨軟骨炎 (Osteochondrosis Dissecans)** 和急性創傷性軟骨骨折的總稱 |
| 命名 | 「Osteochondrosis Dissecans」優於舊稱「Osteochondritis Dissecans」（尾碼 -itis 具誤導性，此病變並非發炎性）|

### 影像表現 / Imaging
| 檢查 | 表現 |
|------|------|
| X 光 | 距骨圓頂**新月狀透亮區 (Crescentic Lucency)** |
| MRI | 與膝關節軟骨病變 MRI 表現相似（見膝關節章節）|

## 後足附骨聯合 / Hindfoot (Tarsal) Coalition

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 兩塊附骨異常融合，可致後足疼痛 |
| 發病年齡 | 青少年（聯合開始骨化時顯現）|
| 聯合類型 | 纖維性 (Fibrous)、軟骨性 (Cartilaginous)、或骨性 (Osseous) |

### 分型 / Types
| 類型 | 發生率 |
|------|--------|
| **距跟聯合 (Talocalcaneal)** | 絕大多數之一；最常見於**中距下關節面 (Middle Subtalar Facet)** |
| **跟舟聯合 (Calcaneonavicular)** | 絕大多數之一 |

### 距跟聯合影像徵象 / Talocalcaneal Coalition Imaging Signs

| 徵象 | 說明 |
|------|------|
| **C 徵象 (C Sign)** | 側位 X 光上：融合的中間距骨與載距突 (Sustentaculum Tali) 形成連續 C 形輪廓（並非敏感，但見到時有幫助）|
| **距骨鳥嘴徵 (Talar Beak Sign)** | 側位 X 光上：距骨前上角的三角形鳥嘴狀骨質增生 |

### 跟舟聯合影像徵象 / Calcaneonavicular Coalition Imaging Signs

| 徵象 | 說明 |
|------|------|
| **食蟻獸徵象 (Anteater Sign)** | 側位 X 光：跟骨前突細長延伸，看起來像食蟻獸的鼻子 |

### 臨床要點 / Clinical Key Points
1. **Osteochondrosis Dissecans** = 軟骨病變（非發炎，舊稱已被取代）
2. **C 徵象** = 距跟聯合的特徵（側位片）；**食蟻獸徵象** = 跟舟聯合
3. **距骨鳥嘴徵** = 距跟聯合的側位片特徵
4. **後足附骨聯合** = 青少年後足疼痛的常見原因（附骨間異常融合）
5. **CT** = 確認附骨聯合的最佳工具（纖維性聯合可由硬化與軟骨下囊性變確診）
