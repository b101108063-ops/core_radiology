## 內踝韌帶與肌腱 / Medial Ankle Ligaments and Tendons

### 內側韌帶複合體：三角韌帶 (Deltoid Ligament Complex)

| 組成 | 說明 |
|------|------|
| **後脛距韌帶 (Posterior Tibiotalar)** | 三角韌帶深層 |
| **脛跟韌帶 (Tibiocalcaneal)** | 三角韌帶淺層 |
| **脛舟韌帶 (Tibionavicular)** | 三角韌帶淺層 |
| **前脛距韌帶 (Anterior Tibiotalar)** | 三角韌帶淺層 |

### 彈力韌帶複合體 (Spring Ligament Complex)
| 組成 | 說明 |
|------|------|
| 舟狀骨韌帶 (Calcaneonavicular Ligaments) | MRI 上通常無法個別解析 |
| 跟骨內側韌帶 (Superomedial Calcaneonavicular) | — |
| 斜蹠內側韌帶 (Medioplantar Oblique Calcaneonavicular) | — |
| 蹠縱韌帶 (Inferoplantar Longitudinal Calcaneonavicular) | — |

> **功能**：與**脛後肌腱**共同維持足的縱弓
> **後脛肌腱斷裂** = 獲得性扁平足最常見的原因（糖尿病患者特別常見）

---

### 內踝屈肌腱詳細說明 / Medial Ankle Tendons Detail

| 肌腱 | 附著點 |
|------|--------|
| **脛後肌腱** | 主束：舟狀骨結節 + 內側楔骨；蹠側束：第二至四蹠骨底部；回歸束：跟骨載距突 |
| **趾長屈肌腱** | 第二至五遠節趾骨底部 |
| **拇長屈肌腱** | 行走於籽骨之間（不與籽骨連接），附著於拇趾遠節趾骨底部 |

### 附骨隧道內容物（由前向後）/ Tarsal Tunnel Contents (Anterior to Posterior)
| 排序 | 內容 |
|------|------|
| Tom | **Posterior Tibial tendon** |
| Dick | **Flexor Digitorum longus tendon** |
| ANd | **Posterior Tibial Artery + Nerve** |
| Harry | **Flexor Hallucis longus tendon** |

> **記憶口號**：「Tom, Dick, ANd Harry」（AN = Artery + Nerve）

### 臨床要點 / Clinical Key Points
1. **三角韌帶 (Deltoid)** = 內踝最重要的穩定韌帶複合體
2. **Spring Ligament** = 維持縱弓（與後脛肌腱共同作用）
3. **後脛肌腱斷裂** = 獲得性扁平足最常見原因（糖尿病患者高風險）
4. **附骨隧道 (Tarsal Tunnel)** = 後內踝的屈肌腱/血管/神經通道
5. **趾長屈肌** = 附著於第二至五趾；**拇長屈肌** = 行走於籽骨之間
