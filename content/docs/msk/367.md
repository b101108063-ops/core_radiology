# Musculoskeletal Imaging - Page 367

![Page 367](/core_radiology/images/msk/page-367.png)

## 痛風 / Gout

### 疾病概述 / Disease Overview
- **尿酸單鈉結晶沉積**引起的炎症性關節病
- 高尿酸血症原因：

| 原因 | 說明 |
|------|------|
| **排泄減少**（更常見） | 通常由腎功能不全引起 |
| **生成過多**（較少見） | 通常見於較年輕患者 |

- 從高尿酸血症到臨床痛風發作約需 **10–20 年**
- 結晶特徵：**負性雙折射針狀結晶**（存在於中性粒細胞內）

### 好發部位 / Common Sites
- **第一拇趾 (MTP)** 最常見
- 可侵犯任何關節

### X 光特徵 / Radiographic Hallmarks

| 表現 | 說明 |
|------|------|
| **邊緣清楚的侵蝕，伴懸垂邊緣 (Overhanging Margins)** | 痛風特徵性表現 |
| 軟組織痛風結節 (Tophi) | 尿酸結晶在軟組織內沉積 |
| 關節間隙通常保持正常 | 直至疾病晚期 |
| 骨質礦化正常 | 與 RA 骨質疏鬆不同 |

### 臨床要點 / Clinical Key Points
- 痛風發作與尿酸結晶沉積相關；從高尿酸血症到痛風臨床發作需 10-20 年

## 血色素沉著症 / Hemochromatosis

### 疾病概述 / Disease Overview
- 自體隱性遺傳疾病；鐵代謝異常
- 關節侵犯見於 **50%** 的血色素沉著症患者
- 發病機制：鐵 + 焦磷酸鈣結晶沉積

### 臨床表現 / Clinical Presentation
| 症狀 | 說明 |
|------|------|
| 青銅色色素沉著 | 皮膚鐵沉積 |
| 糖尿病 | 胰島細胞損傷 |
| 肝硬化 | 肝臟鐵沉積 |
| 充血性心臟衰竭 | 心肌鐵沉積 |
| 關節病 | 關節侵犯 |

### 手部 X 光特徵 / Hand Radiographic Features
| 特點 | 說明 |
|------|------|
| MCP 關節為典型侵犯部位 | 第一至第三 MCP 掌骨頭呈**鳥嘴狀骨刺** |
| **與 CPPD 相似**（限於第二、三 MCP 時） | 兩者難以鑑別 |
| **CPPD**：通常侵犯第二、三 MCP | |
| **血色素沉著症**：可侵犯所有 MCP | 鑑別要點 |

### 臨床要點 / Clinical Key Points
- 所有 MCP 廣泛侵犯 → 傾向血色素沉著症（而非 CPPD）

## 肢端肥大症 / Acromegaly

### 疾病概述 / Disease Overview
- **生長激素過多**導致關節病
- 發病機制：關節軟骨增大 → 隨後退行性變

### X 光特徵 / Radiographic Features

| 時期 | 表現 |
|------|------|
| **早期** | 關節間隙**增寬**（軟骨增生）；為與所有其他關節病的鑑別要點 |
| **晚期** | 繼發性骨關節炎；軟骨間隙狹窄 |

### 手部特徵性表現 / Characteristic Hand Findings
| 表現 | 說明 |
|------|------|
| 掌骨頭鳥嘴狀骨刺 | |
| **指骨末端擴大 (Spade-like Terminal Tuft Enlargement)** | 特徵性表現 |

### 臨床要點 / Clinical Key Points
1. **痛風**：邊緣清楚侵蝕 + 懸垂邊緣 + 軟組織結節；關節間隙保持正常直至晚期
2. **血色素沉著症**：所有 MCP 廣泛侵犯 + 鳥嘴狀骨刺
3. **Acromegaly**：**早期關節間隙增寬**（唯一軟骨增生的關節病）；指骨末端擴大
4. **CPPD vs. 血色素沉著症**：前者通常僅第二、三 MCP；後者侵犯所有 MCP
