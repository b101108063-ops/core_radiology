## 滑膜 / Synovium

## 色素沉著絨毛結節性滑膜炎 / Pigmented Villonodular Synovitis (PVNS)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 滑膜的良性增生性病變，現被認為屬於**腫瘤** |
| 好發位置 | **膝關節**（最常見，遠超其他部位）|
| 關節外對應病變 | **腱鞘巨細胞瘤 (Giant Cell Tumor of Tendon Sheath)** |

### 臨床表現 / Clinical Features
| 項目 | 說明 |
|------|------|
| 症狀 | 膝關節疼痛與腫脹 |
| 特徵 | 因過去出血，關節積液為**反覆性深棕色** |

### 病程特徵 / Disease Characteristics
| 特徵 | 說明 |
|------|------|
| 分布 | 可**瀰漫性**或**局灶性**影響關節 |
| 局灶性 PVNS | 臨床上可能類似內部紊亂 |

### MRI 表現 / MRI Features
| 發現 | 說明 |
|------|------|
| 反覆出血 | 關節內殘留**含鐵血黃素 (Hemosiderin)** |
| 含鐵血黃素特性 | **順磁性** → T1 延長 + T2 縮短 |
| 信號特徵 | **T1、T2 皆呈低信號** |
| 梯度回波序列 | 因磁化率效應呈現極暗訊號 ("blooming") |

---

## 樹枝狀脂肪瘤 / Lipoma Arborescens

| 項目 | 說明 |
|------|------|
| 定義 | 關節內滑膜脂肪組織的過度增生，形成**分葉狀/球狀**關節內脂肪團塊 |
| 治療 | 滑膜切除術 (Synovectomy)，以預防過早退化性關節炎 |

### 臨床要點 / Clinical Key Points
1. **PVNS** = 膝關節疼痛/腫脹 + 反覆深棕色關節積液 + T1/T2 雙低信號
2. **PVNS 的低信號** = 含鐵血黃素沈積（磁化率效應）
3. **梯度回波**上 PVNS 極暗 = 因磁化率 artifact
4. **Lipoma Arborescens** = 滑膜脂肪過度增生 → 分葉狀脂肪團塊
5. **PVNS** vs **Lipoma Arborescens**：PVNS = 低信號（血黃素）；Lipoma Arborescens = 脂肪信號
