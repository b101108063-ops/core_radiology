# Musculoskeletal Imaging - Page 357

![Page 357](/core_radiology/images/msk/page-357.png)

## 手部骨關節炎 / Osteoarthritis in the Hand

### 好發部位（依發生率排序）/ Sites of Involvement
| 部位 | 說明 |
|------|------|
| **DIP（遠端指間關節）** | 最常見；第二 DIP 為手部 OA 最常見位置 |
| **第一腕掌關節 (CMC)** | 拇指根部 |
| **PIP（近端指間關節）** | |

### X 光特徵 / Radiographic Features
- 關節間隙狹窄
- 軟骨下硬化
- 骨刺增生
- **無侵蝕**（與 RA 鑑別要點）

### 特殊臨床現象 / Special Clinical Features

| 現象 | 位置 | 說明 |
|------|------|------|
| **Heberden 結節** | DIP | 軟組織腫脹 |
| **Bouchard 結節** | PIP | 軟組織腫脹 |

### 與 RA 鑑別 / Differential with Rheumatoid Arthritis

| 特徵 | 骨關節炎 (OA) | 類風濕關節炎 (RA) |
|------|-------------|------------------|
| MCP 侵犯 | 少見 | **典型** |
| DIP 侵犯 | **典型** | 少見 |
| 侵蝕 | 無 | 有 |
| 骨刺 | 有 | 無 |

## 肩關節骨關節炎 / Osteoarthritis in the Shoulder

### 影像檢查 / Imaging
- **Grashey 位**（肩關節後前斜位，外旋 40 度）：顯示肩胛骨與肱骨頭關節面，最佳顯示威尼斯間隙狹窄

## 足部骨關節炎 / Osteoarthritis in the Foot

### 好發部位 / Sites of Involvement
| 部位 | 臨床意義 |
|------|----------|
| **第一蹠趾關節 (MTP)** | 最常見；可致 **Hallux Rigidus**（僵硬拇指，由背側骨刺引起） |
| **距舟關節 (Talonavicular Joint)** | 背側骨刺原因之一 |

---

## 膝關節骨關節炎 / Osteoarthritis in the Knee

### 膝關節三個間室 / Three Compartments

| 間室 | 位置 |
|------|------|
| 內側脛股間室 | 膝內側 |
| 外側脛股間室 | 膝外側 |
| 髕股間室 | 髕骨與股骨之間 |

### OA 典型模式 / Typical OA Pattern
- **不對稱性**：最常侵犯**內側脛股間室**
- 嚴重 OA 可侵犯全部三個間室

### 影像診斷原則 / Imaging Principle
> **骨刺決定是否存在 OA；關節間隙狹窄程度決定 OA 嚴重程度**

### 檢查選擇 / Imaging Choice
- **站立負重 X 光**（屈膝位）：最佳顯示脛股間室軟骨空間狹窄
- 雙側膝關節同時侵犯為典型表現

### 臨床要點 / Clinical Key Points
1. **手部 OA**：DIP > PIP > 第一 CMC；MCP 通常不受侵犯
2. **Heberden/Bouchard 結節**：OA 特徵性軟組織腫脹
3. **膝關節 OA**：內側脛股間室最常見；站立負重片最準確
4. **Hallux Rigidus**：MTP 背側骨刺導致僵硬拇指
