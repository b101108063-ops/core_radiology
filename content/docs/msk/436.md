## 髖臼骨折 / Acetabular Fracture

### 影像評估要點 / Imaging Evaluation
| 發現 | 意義 |
|------|------|
| **髂恥線 (Iliopectineal Line) / 髂坐骨線 (Ilioischial Line) 中斷** | 可能代表髖臼前柱或後柱骨折 |

#### 重要界線 / Important Lines
| 界線 | 代表的結構 |
|------|-----------|
| **髂恥線 (Iliopectineal Line)** | 髖臼**前柱**的邊界 |
| **髂坐骨線 (Ilioischial Line)** | 髖臼**後柱**的邊界 |
| 髖臼**前壁**與**後壁** | 通常可直接看到投影於股骨頭上；後壁位於更外側 |

### 分類 / Classification
| 分類系統 | 說明 |
|---------|------|
| **Judet-Letournel 分類** | 最廣泛使用，描述 **10 種**髖臼骨折類型 |

#### 五種基本型 / Five Elementary Patterns
| 骨折類型 |
|---------|
| 後壁骨折 |
| 後柱骨折 |
| 前壁骨折 |
| 前柱骨折 |
| 橫向骨折 |

#### 五種複合型 / Five Combination Patterns
（基本型的組合）

### 重要事實
| 項目 | 說明 |
|------|------|
| **後壁骨折** | 最常見的單一骨折元素（單獨或與其他損傷合併）|

## 近端股骨骨折概覽 / Overview of Proximal Femur Fractures

### 「髖關節骨折」的含義 / "Hip Fracture" Definition
| 骨折類型 | 囊內/囊外 |
|---------|-----------|
| 股骨頭骨折 | **囊內 (Intracapsular)** |
| 股骨頸骨折 | **囊內 (Intracapsular)** |
| 轉子間骨折 | 囊外 (Extracapsular) |
| 轉子下骨折 | 囊外 (Extracapsular) |

### 股骨頭/頸部血供與缺血性壞死 / Blood Supply & AVN Risk
| 項目 | 說明 |
|------|------|
| 股骨頭主要血供 | **旋股外側动脉**；在股骨頸底部形成環並發出上行分支至股骨頭 |
| 囊內骨折風險 | 這些血管可能在囊內骨折時受損 → **缺血性壞死 (AVN)** |
| 圓韌帶 | 只有少量血供來自其內的小血管 |

### 囊外骨折特徵 / Extracapsular Fracture Features
| 項目 | 說明 |
|------|------|
| 病因 | 通常為直接創傷（如摔倒），影響老年人 |
| 缺血性壞死風險 | **罕見**（旋股內側动脉及其分支通常不受影響）|
| 其他血供 | 來自附著於大小轉子的肌肉（臀中肌/小 → 大轉子；髂腰肌 → 小轉子）|

### 臨床要點 / Clinical Key Points
1. **髖臼骨折分類** = Judet-Letournel 分類（10 種）
2. **後壁骨折** = 最常見的髖臼骨折
3. **囊內骨折**（頭、頸）= 高缺血性壞死風險
4. **囊外骨折**（轉子間、轉子下）= 缺血性壞死罕見
5. **髂恥線中斷** = 前柱骨折；**髂坐骨線中斷** = 後柱骨折
