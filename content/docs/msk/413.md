# Musculoskeletal Imaging - Page 413

![Page 413](/core_radiology/images/msk/page-413.png)

## Chopart 骨折-脫臼 / Chopart Fracture-Dislocation

### 解剖基礎 / Anatomy
| 項目 | 說明 |
|------|------|
| Chopart 關節 | 由**距舟關節 (Talonavicular)** 與**跟骰關節 (Calcaneocuboid)** 組成 |

### 臨床特徵 / Clinical Features
| 項目 | 說明 |
|------|------|
| 病因 | 通常為**高能量創傷** |
| 常見伴隨骨折 | 跟骨、骰骨、舟狀骨 |

---

## 跟骨骨折 / Calcaneal Fracture

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 發病率 | **最常見的跗骨骨折** |
| 病因 | 高能量創傷，如**高處坠落**（「情人骨折」(Lover's Fracture)）|

### 高處坠落相關損傷 / Associated Injuries
| 損傷 | 說明 |
|------|------|
| 腰椎骨折 | 高關聯性 |
| 創傷性主動脈破裂 | 高關聯性 |
| 腎血管蒂撕脫 | 高關聯性 |

> **臨床建議**：創傷性跟骨骨折確診時，建議進一步影像檢查腰椎及/或腹部

---

### Boehler 角 / Boehler Angle

| 測量方式 | 正常值 | 診斷值 |
|---------|--------|--------|
| 由兩條線形成：跟骨後結節上極 → 後關節面上極；前突上極 → 後關節面上極 | **20-40°** | **< 20° 即可診斷跟骨骨折** |

#### Boehler 角示意圖要點
| 組成線 | 連接點 |
|--------|--------|
| 第一條線 | 跟骨後結節上極 → 後關節面下極 |
| 第二條線 | 跟骨前突上極 → 後關節面上極 |

> **注意**：正常 Boehler 角（20-40°）**不能排除**跟骨骨折（輕微骨折可能角仍正常）

---

### 跟骨骨折分類 / Classification

| 分類系統 | 類型 |
|---------|------|
| **Essex-Lopresti 分類** | 不波及距下關節（25%）vs 延伸至距下關節（75%）|
| **Sanders 分類**（CT） | 依冠狀面 CT 的粉碎碎片數量分型 |

---

### 跟骨 Stress Fracture / Calcaneal Stress Fracture

| 表現 | 說明 |
|------|------|
| X 光 | 跟骨內蓬鬆狀硬化帶，皮質完整 |
| Boehler 角 | **正常**（與創傷性骨折不同）|

### 臨床要點 / Clinical Key Points
1. **跟骨** = 最常見的跗骨骨折（高處坠落）
2. **Boehler 角 < 20°** = 高度提示跟骨骨折（但正常不能排除）
3. **創傷性跟骨骨折** → 建議加做腰椎/腹部影像（高能量損傷）
4. **跟骨 Stress Fracture** = 蓬鬆狀硬化帶 + 皮質完整 + Boehler 角正常
5. **情人骨折 (Lover's Fracture)** = 高處坠落導致的跟骨骨折
