# Musculoskeletal Imaging - Page 371

![Page 371](/core_radiology/images/msk/page-371.png)

## 結節病 / Sarcoidosis

### 疾病概述 / Disease Overview
- 是一種**多系統性肉芽腫疾病**
- **肺部表現**（淋巴結病變 + 肺實質病變）為大多數患者的主要表現
- 骨骼侵犯罕見

### 骨骼影像特徵 / Skeletal Manifestations
- **手指特徵性病變**：中節或遠節指骨**花邊狀溶骨性病變 (Lace-like Lytic Lesions)**
- 可伴隨**急性或慢性多關節炎**（但無特異性 X 光表現）
- **踝關節侵犯**：雙側踝關節炎或合併結節性紅斑，應懷疑結節病並安排胸部 X 光

## 手部關節炎評估：ABCDEs 法則 / Evaluation of the Hands for Arthritis: ABCDEs

### A — 對線 (Alignment)
| 發現 | 疾病關聯 |
|------|---------|
| **不可復位的半脫臼** | **類風濕關節炎 (RA)** |
| **可復位的半脫臼** | **系統性紅斑狼瘡 (SLE)** 或 **Jaccoud 關節病**（SLE 無侵蝕性病变） |
| **關節脫臼** | 晚期類風濕關節炎 |

### B — 骨質密度 (Bone Mineral Density)

| 評估方式 | 正常標準 |
|---------|---------|
| 第二掌骨骨幹皮質厚度 | 至少占骨幹總寬度的 **1/3** |

| 骨質密度類型 | 臨床意義 |
|-------------|---------|
| **全身性骨質減少** | 任何關節病晚期皆可見 |
| **瀰漫性骨質疏鬆** | 晚期類風濕關節炎 |
| **關節周骨質疏鬆** | 類風濕關節炎早期或任何發炎性關節病早期 |

### B — 骨質增生 (Bone Creation)

| 骨質增生類型 | 說明 |
|------------|------|
| **骨刺 (Osteophyte)** | 軟骨退化後關節邊緣的軟骨內骨化；**退化性關節炎的標誌**，亦可見於 CPPD、血色素沉著症 |
| **骨膜新生骨 (Periosteal New Bone)** | 侵蝕性變化的修復反應；**乾癬性關節炎**與**反應性關節病**常見，成人 RA 少見 |

### 臨床要點 / Clinical Key Points
1. **不可復位半脫臼 → 類風濕關節炎；可復位半脫臼 →  SLE 或 Jaccoud 關節病**
2. **皮質厚度 < 1/3 掌骨寬度**：骨質疏鬆（發炎性關節病的警訊）
3. **骨刺 = 退化性關節炎**（但 CPPD、血色素沉著症也可見）
4. **骨膜反應 = 乾癬/反應性關節炎**（成人 RA 不常見）
5. **手部骨質疏鬆**：區分發炎性與非發炎性關節病的重要參考
