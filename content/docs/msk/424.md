# Musculoskeletal Imaging - Page 424

![Page 424](/core_radiology/images/msk/page-424.png)

## 放射狀/橫向撕裂 / Radial / Transverse Tear

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 方向 | 垂直方向撕裂，**垂直於半月板弧度** |
| 與縱向撕裂鑑別 | 縱向撕裂**沿著**半月板弧度；放射狀撕裂**垂直於**弧度 |

### 影像診斷要點 / Imaging Findings

| 徵象 | 說明 |
|------|------|
| **Marching Cleft Sign** | 在連續矢狀切片上，放射狀撕裂**相對於半月板邊緣的位置會改變**（與縱向撕裂的固定距離不同）|
| **Ghost Meniscus Sign（幽靈半月板徵）** | 當切片平面正好穿過放射狀撕裂時，**半月板組織消失**（通常描述為後角消失，但前角也可能發生）|

### 臨床特徵 / Clinical Features
| 項目 | 說明 |
|------|------|
| 預後 | 與高**半月板突出 (Meniscal Extrusion)** 發生率相關 |
| 併發症 | 若未治療，可能導致**退化性關節炎** |

## 半月板囊腫 / Meniscal Cyst

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 半月板旁的局限性液體聚集 |
| 形成機制 | 關節液透過半月板撕裂**延伸至半月板外** |

### 臨床特徵 / Clinical Features
| 特徵 | 說明 |
|------|------|
| 最常見相關撕裂 | **水平撕裂** |
| 重要性 | 即使半月板被切除，囊腫仍可持續造成症狀 |
| 關節鏡限制 | 並非所有囊腫都能被關節鏡看到 |

### 臨床要點 / Clinical Key Points
1. **放射狀撕裂** = 垂直於半月板弧度 + Marching Cleft Sign
2. **Ghost Meniscus Sign** = 半月板後角/前角消失（放射狀撕裂）
3. **放射狀撕裂** = 高半月板突出風險 → 關節炎
4. **半月板囊腫** = 最常見於水平撕裂；需手術時一併處理
5. **半月板囊腫** = 即使半月板被切除，症狀仍可持續
