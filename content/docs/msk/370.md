# Musculoskeletal Imaging - Page 370

![Page 370](/core_radiology/images/msk/page-370.png)

## 神經病變性關節病 (夏科氏關節) / Neuropathic Arthropathy (Charcot Joint)

### 疾病概述 / Disease Overview
- 又稱：**夏科氏關節 (Charcot Joint)** — 由神經感覺障礙引起的破壞性關節炎
- 感覺喪失導致軟骨與骨質嚴重退化、骨碎片形成
- 臨床特徵：關節通常**無痛性腫脹**（即使已有嚴重結構破壞）

### 病因分類 / Etiology

| 病因 | 常見侵犯部位 |
|------|-------------|
| **糖尿病周邊神經病變** | 踝關節、足部（最常見） |
| **脊髓空洞症 (Syringomyelia)** | 上肢（肩關節） |
| 慢性酒精中毒 | 足部 |
| 澱粉樣變性 (Amyloid) | 足部 |
| 脊髓腫瘤 | 取決於腫瘤位置 |
| 梅毒、痲瘋（罕見） | 各關節 |

### 臨床分型 / Clinical Classification

| 分型 | 特徵 | 好發部位 |
|------|------|---------|
| **肥厚型 (Hypertrophic)** | 關節結構嚴重破壞、脫臼/半脫臼、碎片、骨質增生、無脫鈣 | 足、踝（中軸骨） |
| **萎縮型 (Atrophic)** | 骨質快速大量吸收、邊緣銳利如手術刀痕 | 肩關節（與脊髓空洞症相關） |

### 影像診斷要點 / Diagnostic Key Points

#### 肥厚型 X 光特徵
- **「關節內的無政府狀態」**：破壞 + 脫臼 + 碎片 + 結構紊亂 + 無脫鈣
- **Lisfranc 關節半脫臼**：第一與第二蹠骨間距增寬；第二蹠骨基底偏移
- 典型表現：足部跗蹠關節 (Tarsometatarsal joint) 脫位與骨質增生

#### 萎縮型 X 光特徵
- **肱骨頭快速吸收**：邊緣銳利如外科手術切除
- 高度提示：**脊髓空洞症**（建議做頸椎 MRI 確診）

### 鑑別診斷 / Differential Diagnosis
- 嚴重退化性關節炎（但無神經病變、無碎片）
- 感染性關節炎（骨質破壞但無明顯骨質增生）
- 痛風（侷限性侵蝕，無廣泛結構破壞）

### 臨床要點 / Clinical Key Points
1. **夏科氏關節 = 無痛性嚴重關節破壞**：即使 X 光看起來很糟，患者可能不痛
2. **糖尿病足部**為最常見原因：踝關節與足部中段
3. **Lisfranc 關節脫臼**：糖尿病神經病變的特徵性表現
4. **肩關節萎縮型神經病變**：高度提示脊髓空洞症
5. **肥厚型 vs 萎縮型**：生長速度決定表現型（慢＝肥厚，快＝萎縮）
