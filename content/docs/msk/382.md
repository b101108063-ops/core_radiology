# Musculoskeletal Imaging - Page 382

![Page 382](/core_radiology/images/msk/page-382.png)

## 症候群：軟骨發育不全症候群 / Syndromes: Familial Enchondromatoses

### Ollier 症候群
| 項目 | 說明 |
|------|------|
| 特徵 | **多發性內生軟骨瘤**（無靜脈畸形） |
| 惡性變風險 | 升高（軟骨肉瘤） |

### Maffucci 症候群
| 項目 | 說明 |
|------|------|
| 特徵 | **多發性內生軟骨瘤 + 靜脈畸形**（靜脈畸形產生靜脈石/phleboliths） |
| 惡性變風險 | 比 Ollier 更高（軟骨肉瘤） |
| X 光特徵 | 手足部廣泛膨脹性內生軟骨瘤 + 多發靜脈石（軟組織內圓形鈣化） |

## 良性：骨軟骨瘤 / Benign: Osteochondroma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 良性軟骨帽狀骨質外生性生長，常有柄 |
| 發病率 | **最常見的良性骨病變** |
| 臨床表現 | 可觸及腫塊；通常在骨骼成熟時停止生長 |

### 影像診斷要點 / Imaging Features
| 特徵 | 說明 |
|------|------|
| **皮質延續性** | 宿主骨皮質與骨軟骨瘤皮質**連續** |
| **骨髓腔相通** | 骨髓腔與骨軟骨瘤骨髓腔**相通** |
| 生長方向 | 起源於**骨幹端 (Metaphysis)**，向**骨骺反方向**生長 |

### 併發症 / Complications
| 併發症 | 說明 |
|--------|------|
| **惡性變軟骨肉瘤** | 罕見；警示：無骨折的疼痛 + **軟組織腫塊** |
| **軟骨帽厚度 > 2 cm (MRI)** | 高度暗示已惡性變為軟骨肉瘤 |

### 家族性骨軟骨瘤病 / Familial Osteochondromatosis (Multiple Hereditary Exostoses)
| 項目 | 說明 |
|------|------|
| 遺傳方式 | 自體顯性遺傳性骨質發育不良 |
| 好發部位 | **膝關節**最常見 |
| 惡性變風險 | 升高（軟骨肉瘤） |

### 臨床要點 / Clinical Key Points
1. **骨軟骨瘤** = 最常見的良性骨腫瘤 = 皮質連續 + 骨髓腔相通 + 外生性軟骨帽
2. **骨軟骨瘤生長方向**：起源於骨幹端，向骨骺反方向（遠離關節）生長
3. **軟骨帽厚度 > 2 cm (MRI)** = 高度暗示惡性變軟骨肉瘤
4. **Ollier = 內生軟骨瘤 alone；Maffucci = 內生軟骨瘤 + 靜脈石**
5. **無骨折的疼痛 = 骨軟骨瘤惡性變的紅旗**
