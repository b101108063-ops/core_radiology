# Musculoskeletal Imaging - Page 360

![Page 360](/core_radiology/images/msk/page-360.png)

## 手部與腕關節類風濕關節炎 / Rheumatoid Arthritis in the Hand and Wrist

### 常見侵犯關節 / Common Joints Involved
| 關節 | 受侵情況 |
|------|----------|
| **MCP（掌指關節）** | 典型侵犯 |
| **PIP（近端指間關節）** | 典型侵犯 |
| **腕骨關節** | 典型侵犯 |
| **DIP（遠端指間關節）** | **通常不受侵犯** |

### 早期 X 光表現 / Early Radiographic Changes
| 表現 | 病理基礎 |
|------|----------|
| **軟組織腫脹** | 滑膜炎 |
| **關節周圍骨質疏鬆** | 滑膜充血 |

### 早期侵蝕部位 / Early Erosions Sites
- 第二、三掌骨頭**橈側**
- 近端指骨基部**橈側和尺側**
- **尺骨莖突 (Ulnar Styloid)**

### 晚期關節畸形 / Late-Stage Deformities

| 畸形名稱 | 表現 |
|----------|------|
| **Boutonnière 畸形** | PIP 屈曲 + DIP 過伸 |
| **天鵝頸畸形 (Swan Neck)** | PIP 過伸 + DIP 屈曲 |
| **MCP 處手指尺側半脫位** | 手指向尺側偏移 |

### 腕關節 / Wrist
- 晚期 RA 少見的情況：關節**強直 (Ankylosis)**（軟骨完全丢失後的纖維骨性融合）
- **幼年型特發性關節炎 (JIA)** 腕關節強直發生率較 RA 更高

### 類風濕結節 / Rheumatoid Nodules
- 常見於前臂伸側

## 足部類風濕關節炎 / Rheumatoid Arthritis in the Feet

### 常見侵犯部位 / Common Sites
| 部位 | 說明 |
|------|------|
| **MTP（蹠趾關節）** | 前足最常見；約 20% 患者以此為首發部位 |
| **距跟前舟關節 (Talocalcaneonavicular Joint)** | 中足常見 |

## 髖關節類風濕關節炎 / Rheumatoid Arthritis in the Hip

### 股骨頭移位 / Femoral Head Migration
| 疾病 | 移位方向 |
|------|----------|
| **RA** | **軸向（同心圓性）移位** |
| **OA** | 上外側移位 |

### Protrusio Deformity（髖臼突出畸形）
- 定義：股骨頭向內超過**髂坐線 (Ilioischial Line)**

| 性別 | 診斷標準 |
|------|----------|
| 男性 | > 3mm |
| 女性 | > 6mm |

- 常見於：**嚴重 RA**

### 臨床要點 / Clinical Key Points
1. **RA 手部**：MCP、PIP、腕骨典型侵犯；**DIP 通常不受侵犯**
2. **Boutonnière 畸形**：PIP 屈曲 + DIP 過伸
3. **天鵝頸畸形**：PIP 過伸 + DIP 屈曲
4. **早期 RA**：軟組織腫脹 + 關節周圍骨質疏鬆
5. **MCP 尺側半脫位 + 尺側偏移**：RA 特徵性表現
6. **足部 MTP**：約 20% 為 RA 首發部位
7. **RA vs. OA 髖關節**：軸向移位 vs. 上外側移位
