# Musculoskeletal Imaging - Page 430

![Page 430](/core_radiology/images/msk/page-430.png)

## 伸肌機制與髕骨 / Extensor Mechanism and Patella

### 伸肌機制正常解剖 / Normal Anatomy of Extensor Mechanism
| 結構 | 說明 |
|------|------|
| 股四頭肌腱 | 附著於髕骨 |
| **髕骨** | 為籽骨，包埋於股四頭肌腱內 |
| 髕骨肌腱 | 附著於脛骨粗隆 |

#### 股四頭肌起源 / Quadriceps Origin
| 肌肉 | 起源 |
|------|------|
| 股外側肌、股內側肌、股中間肌 | 股骨 |
| 股直肌 | 前下髂棘 (AIIS) |

---

### 高位髕骨與低位髕骨 / Patella Alta and Patella Baja

| 類型 | 定義 |
|------|------|
| **Patella Alta (高位髕骨)** | 異常偏高的髕骨 |
| **Patella Baja (低位髕骨)** | 異常偏低的髕骨 |

#### Insall-Salvati 比值 / Insall-Salvati Ratio
| 測量方式 | 定義 |
|---------|------|
| 公式 | 髕骨肌腱長度 ÷ 髕骨長度 |
| 正常值 | 0.8 - 1.2 |
| > 1.2 | 高度提示 **高位髕骨 (Patella Alta)** |
| < 0.8 | 高度提示 **低位髕骨 (Patella Baja)** |

> 建議使用屈膝 30 度時的矢狀 MRI 或側位 X 光測量

---

### 股四頭肌腱撕裂 / Quadriceps Tendon Tear

| 項目 | 說明 |
|------|------|
| 臨床表現 | **膝關節伸直功能喪失** |
| 最常見位置 | 距髕骨 **2 cm 內** |
| X 光表現 | 可見**低位髕骨 (Patella Baja)**（因髕骨下降）|

---

### 髕骨肌腱損傷 / Patellar Tendon Injury

| 項目 | 說明 |
|------|------|
| 臨床表現 | **膝關節伸直功能喪失**（與股四頭肌腱撕裂相同）|
| 與股四頭肌腱撕裂的差異 | 造成**高位髕骨 (Patella Alta)**（髕骨向上移位）|

### 髕骨肌腱退化 (Jumper's Knee) / Patellar Tendinosis (Jumper's Knee)
| 項目 | 說明 |
|------|------|
| MRI 表現 | 髕骨肌腱**增粗** |

### 臨床要點 / Clinical Key Points
1. **Insall-Salvati 比值 > 1.2** = 高位髕骨；< 0.8 = 低位髕骨
2. **股四頭肌腱撕裂** = 髕骨下降（低位髕骨）→ 膝關節伸直喪失
3. **髕骨肌腱撕裂** = 髕骨上升（高位髕骨）→ 膝關節伸直喪失
4. **Jumper's Knee** = 髕骨肌腱增粗（退化性，非發炎性）
5. **伸肌機制任何撕裂** → 膝關節伸直功能立即喪失
