# Musculoskeletal Imaging - Page 437

![Page 437](/core_radiology/images/msk/page-437.png)

## 股骨頭骨折-脫臼 / Femoral Head Fracture-Dislocation

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 關聯 | 與**後側髖關節脫臼**同時發生 |
| 併發症 | **缺血性壞死 (AVN)** 和**創傷後關節炎** |

### Pipkin 分類 / Pipkin Classification

| 分型 | 股骨頭骨折位置 | 特徵 |
|------|--------------|------|
| **Type I** | 中央凹窩**下方** | 圓韌帶中断 |
| **Type II** | 中央凹窩**上方** | 圓韌帶仍附著於骨折碎片上 |
| **Type III** | Type I 或 II + **合併股骨頸骨折** | — |
| **Type IV** | Type I 或 II + **後上方髖臼緣骨折** | — |

## 股骨頸骨折（囊內）/ Femoral Neck Fracture

### 解剖分類 / Anatomic Classification
| 骨折位置 | 說明 |
|---------|------|
| **Subcapital（股骨頭下）** | 緊鄰股骨頭下方；**最常見** |
| **Transcervical（經頸部）** | 通過股骨頸 |
| **Basicervical（基底部）** | 位於股骨頸底部 |

### Garden 分類 / Garden Classification
（用於 Subcapital 骨折，按外翻移位程度分級）

| 分期 | 骨折特徵 | 預後 |
|------|---------|------|
| **Stage I** | 嵌入性或不完全骨折；頭/頸部骨小樑呈**外翻位 (> 180°)** | **穩定，預後良好** |
| **Stage II** | 完全、非移位骨折；骨小樑呈輕度**內翻位 (~160°)** | 預後良好 |
| **Stage III** | 完全、部分移位骨折；骨小樑更明顯**內翻 (< 160°)** | 預後較差 |
| **Stage IV** | 完全、移位骨折；股骨頭骨小樑與髖臼對線正常（正常解剖對線）| 預後最差 |

### Garden 分類記憶 / Garden Classification Memory Aid
| 類型 | 角度 | 對線 |
|------|------|------|
| **Valgus（外翻）** | > 180° | Stage I（穩定）|
| **Varus（內翻）** | < 160° | Stage III-IV（不穩定）|

> **記憶**：「"Fair" Lady → Valgus > 180°」（外翻 = 穩定）；「"Vulgar" Mouth → Varus < 160°」（內翻 = 不穩定）

### 臨床要點 / Clinical Key Points
1. **Pipkin I/II** = 股骨頭骨折（取決於與中央凹窩的關係）；I 型圓韌帶中断
2. **Garden Stage I** = 嵌入性外翻骨折 (> 180°) = 穩定
3. **Garden Stage IV** = 完全移位 = 預後最差
4. **股骨頭骨折-脫臼** → 後側髖關節脫臼的併發症
5. **股骨頸骨折** → 囊內 = 缺血性壞死風險高
