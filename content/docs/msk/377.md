# Musculoskeletal Imaging - Page 377

![Page 377](/core_radiology/images/msk/page-377.png)

## 良性：骨樣骨瘤 / Benign: Osteoid Osteoma

### 疾病概述 / Disease Overview
- **骨樣骨瘤**是一種良性成骨性病灶，以**骨樣組織巢 (Nidus)** 為特徵，周圍被反應性骨質硬化包繞
- 病因未明（曾提出發炎性、血管性及病毒性病因）

### 臨床特徵 / Clinical Features
| 項目 | 說明 |
|------|------|
| **典型表現** | 青少年或年輕成人 + **夜間疼痛，服用阿斯匹靈可緩解** |
| 好發位置 | 下肢長骨（股骨、脛骨）**骨幹 (Diaphysis)** 最常見 |
| 約 20% | 位於脊柱後柱 (Posterior Elements)；可導致**疼痛性脊柱側彎** |

### 影像診斷要點 / Diagnostic Key Points

| 檢查 | 表現 |
|------|------|
| **X 光 / CT** | 低密度 Nidus，周圍伴隨硬化；Nidus 內部常有中央鈣化 |
| **MRI** | Nidus 在 T1 加權呈低信號；反應性骨髓水腫可掩蓋病灶，在 T2 加權影像上病變可能不清楚 |
| **骨掃描** | 陽性；**雙密度徵 (Double Density Sign)**：Nidus 區域高度攝取 + 鄰近反應性骨質硬化對應的攝取 |

### MRI 診斷陷阱 / MRI Diagnostic Pitfall
- **單獨使用 MRI 判讀骨樣骨瘤可能漏診**
- CT 是確認 Nidus 的最佳工具
- 建議結合骨掃描與 CT

### 治療 / Treatment
- **放射科介入：射頻燒灼術 (Radiofrequency Ablation)** — 首選微創治療
- 外科刮除術 (Curettage) 或切除術

### 鑑別診斷 / Differential Diagnosis
- 骨皮質膿瘍（感染性）
- 應力性骨折
- 低度惡性骨肉瘤（巨大骨樣骨瘤 > 2 cm，需警惕）

### 臨床要點 / Clinical Key Points
1. **夜間疼痛 + 阿斯匹靈緩解 + 青少年**：骨樣骨瘤的經典三聯徵
2. **CT 上低密度 Nidus + 周圍硬化**：確診工具
3. **雙密度徵 (Double Density Sign)**：骨掃描診斷骨樣骨瘤的特徵
4. **MRI 可能漏診**：CT 為首選；懷疑時建議做骨掃描
5. **脊柱後柱病灶 + 疼痛性脊柱側彎**：需排除骨樣骨瘤
6. **射頻燒灼術**：微創治療首選（取代傳統開放手術）
