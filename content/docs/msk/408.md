## 創傷學基礎 / Basics of Trauma

## 骨折 / Fractures

### 術語 / Terminology

#### 骨折方向 (Fracture Direction)
| 類型 |
|------|
| 橫向 (Transverse) |
| 斜向 (Oblique) |
| 螺旋形 (Spiral) |

#### 遠端片段位置 (Position of Distal Fragment)
| 位置類型 | 說明 |
|---------|------|
| **移位 (Displaced)** | 骨折片段分開 |
| **短縮 (Foreshortened)** | 骨折端重疊 |
| **分離 (Distracted)** | 骨折端拉開 |

#### 遠端片段的角度 (Angulation of Distal Fragment)
| 角度方向 | 說明 |
|---------|------|
| **遠端內翻 (Apex Medial Angulation)** | 遠端片段內翻（圖中：遠端片段外側）|
| **遠端外翻 (Apex Lateral Angulation)** | 遠端片段外翻（圖中：遠端片段內側）|

#### 特殊骨折類型 / Special Types
| 類型 | 說明 |
|------|------|
| **粉碎性骨折 (Comminuted)** | 骨折碎片 > 2 塊 |
| **分節性骨折 (Segmental)** | 有一段游離骨塊（片段）|

### 描述要點 / Key Description Points
描述長骨骨折時，應涵蓋：
1. **骨折位置**（近端、骨幹中段、遠端）
2. **骨折方向**（橫向/斜向/螺旋形）
3. **角度**（內翻/外翻）
4. **遠端片段位置**（移位/短縮/分離）
5. **是否延伸到關節面**（非常重要！）

### 臨床要點 / Clinical Key Points
1. **骨折描述必備四要素**：位置 + 方向 + 角度 + 移位程度
2. **粉碎性骨折** = 超過 2 個骨折碎片
3. **延伸到關節面的骨折** = 必須在報告中特別說明（影響治療決策）
4. **分節性骨折** = 有獨立的片段 (Segment)
5. **短縮 vs 分離**：短縮 = 重疊；分離 = 拉開（影響復位方式）
