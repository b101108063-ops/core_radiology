## 髖關節 MRI 技術 / Hip MRI Technique

### 金屬髖關節置換成像 / Imaging Metallic Hip Arthroplasties

| 技術要點 | 建議 |
|---------|------|
| 磁場強度 | 盡可能低 |
| 序列 | 使用快速自旋迴波 (FSE) 而非 GRE |
| 接收頻寬 | 盡可能提高（會增加雜訊，需相應增加 NEX）|
| 假影方向 | 可導向頭-腳方向，使內外側區域（鬆動可見處）不被遮擋 |
| 體素大小 | 減小切片厚度 + 增加矩陣大小 |

## 髖關節 MRI 適應症 / Indications for Hip MRI

### 隱匿性創傷性骨折 / Occult Traumatic Fracture
| 項目 | 說明 |
|------|------|
| X 光敏感度 | 對**非移位股骨頸骨折**的檢測相對不敏感 |
| MRI 表現 | T1、T2 上呈低信號骨折線 + T2 高信號水腫 |
| 額外價值 | MRI 可顯示疼痛的其他病因（如：**薦骨骨折**可表現為髖關節疼痛）|

### 隱匿性 Stress 骨折 / Occult Stress Fracture

#### 分類 / Classification
| 類型 | 定義 |
|------|------|
| **Fatigue 骨折** | 正常骨骼承受異常應力 |
| **功能不全性骨折** | 脫礦骨骼承受正常應力 |

#### 影像特徵 / Imaging Features
| 檢查 | 表現 |
|------|------|
| X 光 | 出現時，通常呈現為**硬化帶** |
| MRI | 類似急性創傷骨折：低信號骨折線 + T2 高信號水腫 |

#### 典型位置 / Classic Location
| 位置 | 說明 |
|------|------|
| **股骨頸內下方** | Stress 骨折經典型位置 |

#### 股骨頭 vs 股骨頸 Stress 骨折鑑別 / Superior Femoral Head vs Neck
| 病變 | T1 低信號線形狀 |
|------|---------------|
| **AVN** | 平滑、凹向關節面（concave）|
| **軟骨下功能不全性骨折** | 不規則、低信號骨折線，凸向關節面（convex）|
| 病史幫助 | AVN 通常有類固醇或酒精使用史 |

#### 骨質疏鬆治療相關 / Bisphosphonate-Related
| 位置 | 說明 |
|------|------|
| 股骨骨幹外側 | 可能是雙磷酸鹽使用的副作用 |
| 橫向骨幹骨折 | 可能是雙磷酸鹽使用的副作用 |

#### 治療與追蹤 / Treatment & Follow-up
| 項目 | 說明 |
|------|------|
| 治療 | 通常為保守治療 |
| 追蹤時機 | 8 週後 MRI |
| 癒合指標 | 追蹤時水腫消退 |
| 持續水腫 | 提示治療失敗 |

### 臨床要點 / Clinical Key Points
1. **隱匿性股骨頸骨折** → X 光不敏感；MRI 可確診
2. **股骨頭 Stress 骨折** vs **AVN**：T1 低信號線形狀可鑑別（AVN = concave；骨折 = convex）
3. **疲勞骨折** = 異常應力/正常骨；**功能不全性骨折** = 正常應力/骨質疏鬆
4. **雙磷酸鹽**可能導致非典型股骨骨折（骨幹外側/橫向）
5. **8 週追蹤 MRI** = 水腫消退 = 癒合；持續水腫 = 治療失敗
