# Musculoskeletal Imaging - Page 376

![Page 376](/core_radiology/images/msk/page-376.png)

## 骨腫瘤與腫瘤樣病變：按細胞來源分類 / Bone Lesions Organized by Cell of Origin

### 成骨性病變 (Bone Forming / Osteo- Lesions)

#### 良性/偶發性：內生骨島 (Enostosis / Bone Island)

| 特徵 | 說明 |
|------|------|
| 本質 | 骨髓腔內小型骨質增生病灶，為極常見的**偶發性發現** |
| X 光表現 | 小型尖刺狀成骨性病灶 |
| 臨床意義 | 需與以下鑑別：**成骨性轉移、骨樣骨瘤、低度惡性骨肉瘤** |
| **巨大變異型 (> 2 cm)** | 與低度惡性骨肉瘤的鑑別最困難 |
| 骨掃描 | 通常為**正常**（與轉移性成骨病灶不同） |

#### 相關症候群

| 症候群 | 特徵 |
|--------|------|
| **骨斑點症 (Osteopoikilosis)** | 自體顯性遺傳；多發性骨島 + 疤痕瘤 (Keloid) 形成 |
| **條紋狀骨病 (Osteopathia Striata)** | 良性無症狀性骨質硬化發育不良；長骨可見線性硬化帶；骨盆可見扇形硬化；骨掃描通常正常 |

#### 良性/偶發性：骨瘤 (Osteoma)

| 特徵 | 說明 |
|------|------|
| 生長速度 | 緩慢 |
| 起源 | **骨皮質**（非骨髓腔）——與骨島不同 |
| 好發位置 | 顱骨皮質或額竇/篩竇 |
| 相關症候群 | **Gardner 症候群**（自體顯性）：多發性骨瘤 + 腸道息肉 + 軟組織desmoid腫瘤 |

#### 良性：骨膜增生性骨病 (Melorheostosis)

| 特徵 | 說明 |
|------|------|
| 別名 | 又拼作 melorrheostosis |
| X 光表現 | 皮質增厚、不規則，典型呈**蠟燭流痕狀 (Candle-wax Dripping)** |
| 臨床表現 | 疼痛、活動範圍減少、腿部彎曲、腿長不一致 |
| 皮膚表現 | 患處區域可見硬皮病樣皮膚病變 |
| 好發位置 | 單一下肢，侷限於單一**皮節 (Sclerotome)** 分布區（一條感覺神經支配區） |
| 骨掃描 | 特徵性高度攝取 |

### 臨床要點 / Clinical Key Points
1. **骨島** vs **骨瘤**：骨島起源於骨髓腔；骨瘤起源於皮質
2. **巨大骨島 (> 2 cm)** 需與低度惡性骨肉瘤鑑別
3. **骨掃描正常** = 骨島（偶發性良性）；骨掃描陽性的成骨病灶需排除轉移
4. **Gardner 症候群**：骨瘤 + 腸道息肉 + Desmoid 腫瘤（有大腸癌風險）
5. **Melorheostosis** = 單一皮節分布 + 蠟燭流痕狀皮質增厚 + 骨掃描高度攝取
