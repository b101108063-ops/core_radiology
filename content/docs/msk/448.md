# Musculoskeletal Imaging - Page 448

![Page 448](/core_radiology/images/msk/page-448.png)

## 後側盂肱關節脫位 / Posterior Glenohumeral Dislocation

| 項目 | 說明 |
|------|------|
| 發病率 | 僅占所有肩關節脫位的 **2-3%** |
| 病因 | 通常為嚴重肌肉痙攣（如癲癇發作或電擊）；後側拉肌肉比前側推肌肉更強 → 頭向後移位 |
| 確診困難度 | 比前側脫位**困難得多**（標準正面片可能看起來接近正常）|
| 確診位置 | **Transscapular Y view 或腋位片** |

### 影像線索 / Imaging Clues
| 發現 | 說明 |
|------|------|
| **Lightbulb Sign** | 手臂固定內旋時，肱骨頭的形態（後脫位常見）|
| **Trough Sign（Reverse Hill-Sachs）** | 肱骨頭前內側的壓迫骨折（撞擊後關節盂緣）|

### 正常 X 光對比 / Normal vs. Dislocation
| 檢查 | 正常 | 後脫位 |
|------|------|--------|
| **Grashey (40° 斜位)** | 肱骨頭與關節盂之間有清晰間隙 | **重疊** |
| 腋位片/Y view | — | 肱骨頭向後移位 |

## 下側盂肱關節脫位（Luxatio Erecta）/ Inferior Glenohumeral Dislocation (Luxatio Erecta)

| 項目 | 說明 |
|------|------|
| 發病率 | 約 1% 的脫位（罕見）|
| 機制 | 直接暴力作用於完全外展的手臂 |
| 常見併發症 | **旋轉袖撕裂**、大結節骨折 |
| 神經血管損傷 | **腋神經或腋动脉**可能受損 |

### 臨床要點 / Clinical Key Points
1. **後側肩關節脫位** = 癲癇/電擊後 + 困難確診（標準 X 光可能正常）
2. **Trough Sign** = Reverse Hill-Sachs = 後側脫位撞擊的特徵
3. **Lightbulb Sign** = 後側脫位時手臂固定內旋的形態
4. **Luxatio Erecta** = 手臂外展受傷 + 向下脫位
5. **後側肩關節脫位**：Grashey 片上肱骨頭與關節盂重疊 = 高度懷疑
