# Musculoskeletal Imaging - Page 381

![Page 381](/core_radiology/images/msk/page-381.png)

## 良性：內生軟骨瘤 / Benign: Enchondroma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 成熟玻璃軟骨細胞殘餘的良性病變 |
| X 光特徵 | 長骨中可見特徵性**軟骨基質 (Chondroid) 礦化**：爆米花狀或環弧狀 |
| 部位 | 骨髓腔中心性分布 |

### 鑑別診斷 / Differential Diagnosis

| 病變 | 鑑別要點 |
|------|---------|
| **骨髓腔梗塞 (Medullary Infarct)** | 呈蛇行動脈曲張樣硬化（serpentine sclerosis）；MRI 可區分 |
| **軟骨肉瘤 (Chondrosarcoma)** | 需結合臨床（疼痛）與影像（皮質破壞/軟組織腫塊） |

### MRI 鑑別 / MRI Differentiation
- 內生軟骨瘤：T2 加權像呈特徵性**分葉狀高信號**
- 骨髓腔梗塞：各序列皆呈低信號（纖維化/硬化）

### 手部內生軟骨瘤 / Enchondroma in Hands
| 特徵 | 說明 |
|------|------|
| X 光表現 | 通常**無可見軟骨基質礦化**，呈地理性溶骨性病變 |
| 常見併發症 | **病理性骨折** |

### 惡性變警訊 / Malignant Transformation Red Flags
| 警訊 | 臨床意義 |
|------|---------|
| **新出現疼痛（排除骨折後）** | 高度警覺惡性變 |
| **軟組織腫塊** | 暗示惡性變 |
| **皮質破壞** | 暗示惡性變 |
| **皮質增厚** | 需排除惡性變 |

### 治療 / Treatment
- **刮除術 (Curettage)**：主要治療方式

### 臨床要點 / Clinical Key Points
1. **內生軟骨瘤 = 爆米花狀/環弧狀礦化**：長骨骨髓腔中心的特徵
2. **T2 分葉狀高信號**：內生軟骨瘤的 MRI 特徵（區分骨髓梗塞）
3. **手部內生軟骨瘤**：無礦化，地理性溶骨性 + 病理性骨折
4. **新疼痛（無骨折）= 惡性變的紅旗警訊**
5. **Ollier 與 Maffucci 症候群**：多發性內生軟骨瘤，惡性變風險升高
