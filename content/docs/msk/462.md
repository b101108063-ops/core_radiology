# Musculoskeletal Imaging - Page 462

![Page 462](/core_radiology/images/msk/page-462.png)

## GLAD 病灶 / Glenoid Labral Articular Disruption (GLAD)

| 項目 | 說明 |
|------|------|
| 定義 | 前下唇緣的淺層撕裂 + 相鄰關節盂軟骨損傷 |
| 與 Bankart/ALPSA/Perthes 的差異 | 雖然發生在同一位置（前下唇緣），但 GLAD **通常不是由不穩定性引起或與之相關** |
| 後果 | 可能導致創傷後關節炎和關節內游離體 |

---

## 唇旁囊腫 / Paralabral Cysts

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 形成機制 | 與半月板旁囊腫形成機制相同：唇緣撕裂處關節液滲出形成囊腫 |
| 位置 | 通常在唇緣旁的軟組織內；可延伸至骨頭 |

### 臨床重要性 / Clinical Significance
| 項目 | 說明 |
|------|------|
| 唇緣撕裂的特異性 | 即使未見唇緣異常信號，唇旁囊腫也是唇緣撕裂的**高度特異性發現** |
| 神經壓迫 | 唇旁囊腫可壓迫神經，導致**神經夾擊病變** |

---

## 神經夾擊病變 / Entrapment Neuropathies

### 四邊空間症候群 / Quadrilateral Space Syndrome

| 項目 | 說明 |
|------|------|
| 位置 | 腋窩後側 |
| 邊界 | 肱骨（外側）、三頭肌長頭（內側）、小圓肌（上方）、大圓肌（下方）|
| 通過結構 | **腋神經** + **旋肱後动脉** |
| 腋神經功能 | 支配小圓肌和三角肌 |

#### 四邊空間神經夾擊表現
| 表現 | 說明 |
|------|------|
| 小圓肌感覺異常 | 可能出現 |
| 小圓肌萎縮 | 可能出現，伴/不伴三角肌受累 |

---

### 肩胛上神經夾擊於肩胛上切跡 / Suprascapular Nerve Entrapment at Suprascapular Notch

| 項目 | 說明 |
|------|------|
| 近端肩胛上神經功能 | 支配**岡上肌和岡下肌** |
| 常見原因 | **上唇撕裂相關的唇旁囊腫** |
| 夾擊結果 | 岡上肌 + 岡下肌**同時**萎縮 |

### 臨床要點 / Clinical Key Points
1. **GLAD** = 前下唇緣淺層撕裂 + 軟骨損傷（與不穩定性無關）
2. **唇旁囊腫** = 高度特異性的唇緣撕裂指標
3. **唇旁囊腫**可壓迫神經導致夾擊病變
4. **四邊空間** = 腋神經通過（小圓肌 + 三角肌支配）
5. **肩胛上神經近端夾擊** = 岡上肌 + 岡下肌同時萎縮
