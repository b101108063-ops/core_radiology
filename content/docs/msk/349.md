## 血管性病變 / Vascular Lesions

### 硬膜動靜脈瘻 (dAVF) / Dural Arteriovenous Fistula (dAVF)

#### 疾病概述 / Disease Overview
- **dAVF (Dural Arteriovenous Fistula)**：最常見的脊髓血管畸形
- 好發族群：老年男性
- 典型症狀：背痛 + 進行性脊髓病變 (Progressive Myelopathy)
- 屬於 **Cognard Type V** 硬膜動靜脈瘻

#### 影像診斷要點 / Diagnostic Key Points

| 檢查 | 典型表現 |
|------|----------|
| **MRI** | 脊髓周圍流空信號（Flow Voids）；脊髓腫脹；T2 髓內異常高信號 |
| **CT 脊髓造影** | 蛛網膜下腔蛇形充盈缺損 |

#### 臨床特徵 / Clinical Features
- 背部疼痛
- 進行性下肢無力
- 感覺障礙
- 膀胱功能障礙

### 脊髓梗塞 / Spinal Cord Infarction

#### 疾病概述 / Disease Overview
- 脊髓血液供應在**上胸椎或胸腰交界處**最脆弱（血供不穩定區）
- 主要供血：**Adamkiewicz 動脈 (Artery of Adamkiewicz)**

#### 影像診斷要點 / Diagnostic Key Points

| 檢查 | 典型表現 |
|------|----------|
| **MRI（T2）** | 脊髓受影響區域高信號；脊髓可能腫脹 |
| **DWI** | 彌散受限（受限擴散） |
| **MRI（T1）** | 脊髓可能腫大 |

#### 臨床特徵 / Clinical Features
- 腸道和膀胱功能障礙
- 會陰區感覺喪失
- 雙下肢運動和感覺功能受損

#### 風險因素 / Risk Factors
- 主動脈手術（最常見）
- 主動脈瘤
- 血管炎
- 鐮狀細胞貧血
- 血管畸形
- 椎間盤脫出

#### 典型影像徵象 / Characteristic Imaging Sign
- **「貓頭鷹眼徵」(Owl Eye Appearance)**：軸位 T2 可見對稱性高信號聚焦於髓內灰質前角
- 鐮狀細胞貧血和慢性類固醇使用患者更常見伴發椎體梗塞

### 臨床要點 / Clinical Key Points
1. **dAVF**：老年男性 + 進行性脊髓病變 + 脊髓周圍流空 → 高度懷疑
2. **Adamkiewicz 動脈**是下胸髓的主要供血血管，手術損傷可致梗塞
3. **脊髓梗塞**：外傷後 "貓頭鷹眼徵" 高度提示診斷
4. 鐮狀細胞貧血和類固醇使用增加脊髓及椎體梗塞風險

## 先天性異常 / Congenital Abnormalities

### 脊髓拴繫症候群 / Tethered Cord Syndrome

#### 疾病概述 / Disease Overview
- 臨床症候群：背部/腿部疼痛、步態痙攣、下肢感覺減退
- **正常**：脊髓圓錐 (Conus) 應終於 **L2 下緣**以上
- **拴繫**：圓錐終於 L2 下緣以下

#### 病因 / Etiology
- 脊髓被以下結構拴繫：
  - 增厚的終絲 (Thickened Filum Terminale)
  - 脂肪瘤 (Lipoma)

#### 影像診斷要點 / Diagnostic Key Points
- MRI 是最佳檢查
- 確認圓錐終止水平
- 確認拴繫原因（終絲增厚或脂肪瘤）

### 臨床要點 / Clinical Key Points
1. **圓錐終止水平**：正常應高於 L2 下緣
2. **MRI**：確診圓錐水平和拴繫原因
3. 步態異常 + 背部疼痛 + 下肢感覺減退 → 需排除拴繫
