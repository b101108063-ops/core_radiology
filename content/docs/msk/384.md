# Musculoskeletal Imaging - Page 384

![Page 384](/core_radiology/images/msk/page-384.png)

## 纖維來源病變 / Lesions of Fibrous Origin

### 良性：非骨化性纖維瘤 / 纖維皮質缺損 / Benign: Nonossifying Fibroma (NOF) / Fibrous Cortical Defect (FCD)

| 項目 | 說明 |
|------|------|
| 別名 | 有時稱為 **fibroxanthoma** |
| 本質 | 兒童/青少年長骨（尤其腿部）的**無症狀常見偶發性** X 光病灶 |
| 組織學 | 與纖維皮質缺損相同；通常病灶 > 2 cm 或有症狀時才稱 NOF |
| 起源 | **骨膜 (Periosteum)** |

### 影像特徵 / Imaging Features
| 表現 | 說明 |
|------|------|
| X 光 | 低密度病變 + 狹窄過渡區 + 硬化邊緣 + **無基質礦化** |
| CT/MRI | 可見皮質變薄或中斷（皮質被纖維組織置換） |
| 自然病程 | 成年後多數病灶會**自發性硬化消退** |

### 鑑別診斷 / Differential Diagnosis
| 病變 | 鑑別點 |
|------|--------|
| 單純性骨囊腫 | 中心性（NOF 為偏心性） |
| 內生軟骨瘤 | 有軟骨基質礦化 |
| 骨纖維結構不良 | 玻璃樣基質，無明確硬化邊緣 |

## 惡性：惡性纖維組織球瘤 / Malignant: Malignant Fibrous Histiocytoma (MFH)

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 現名 | **未分化多形性肉瘤 (Undifferentiated Pleomorphic Sarcoma, NOS)** — 現已重新命名 |
| 名稱爭議 | 儘管名稱有爭議，**「MFH」仍為放射科醫師常用術語** |
| 「纖維」意涵 | 顯微鏡下呈現纖維外觀（但細胞起源未定） |

### 臨床特徵 / Clinical Features
| 特徵 | 說明 |
|------|------|
| 發病率 | **成人最常見的軟組織肉瘤** |
| 好發年齡 | 中老年人 |
| 好發部位 | **大腿**、腹膜後（最常見）；任何肢體皆可發生 |
| 骨內病變 | 少見；呈**侵襲性溶骨性病變** |

### 骨內 MFH 影像特徵 / Intracortical MFH
| 特徵 | 說明 |
|------|------|
| 表現 | 侵襲性溶骨性病變 |
| 影像 | 難與其他侵襲性骨腫瘤區分，需病理確診 |

### 臨床要點 / Clinical Key Points
1. **非骨化性纖維瘤 (NOF)** = 青少年腿部偏心病灶 + 硬化邊緣 + 無礦化 + 自發性消退
2. **NOF vs FCD**：大小 > 2 cm 或有症狀時稱 NOF，否則為 FCD（同一病變）
3. **MFH** = 成人最常見軟組織肉瘤 = 大腿/腹膜後
4. **骨內 MFH** = 侵襲性溶骨性病變（需與其他骨腫瘤鑑別）
5. **未分化多形性肉瘤 (UPS)** = MFH 的現代官方名稱
