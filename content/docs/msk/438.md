# Musculoskeletal Imaging - Page 438

![Page 438](/core_radiology/images/msk/page-438.png)

## Garden 分類圖解 / Garden Classification Diagram

### Stage I：嵌入性/不完全骨折
| 特徵 | 說明 |
|------|------|
| 頭/頸骨小樑角度 | **> 180°（外翻）** |

### Stage II：完全、非移位骨折
| 特徵 | 說明 |
|------|------|
| 頭/頸骨小樑角度 | 約 **160°（輕度內翻）** |

### Stage III：完全、部分移位骨折
| 特徵 | 說明 |
|------|------|
| 頭/頸骨小樑角度 | **< 160°（明顯內翻）** |

### Stage IV：完全、移位骨折
| 特徵 | 說明 |
|------|------|
| 對線 | 股骨頭骨小樑與**髖臼**對線（正常解剖對線） |

## 轉子下骨折（囊外）/ Subtrochanteric Fracture

### 定義 / Definition
| 項目 | 說明 |
|------|------|
| 定義 | 骨折位於**小轉子或其下方** |

### 分類系統 / Classification Systems
| 系統 | 使用者 |
|------|--------|
| **Fielding 分類** | 骨科醫師 |
| **Seinsheimer 分類** | 骨科醫師 |

### 臨床要點 / Clinical Key Points
1. **Garden Stage I** = 外翻嵌入 = 穩定（預後良好）
2. **Garden Stage III/IV** = 內翻移位 = 不穩定
3. **轉子間骨折** = 囊外骨折（Evans/Boyd-Griffin 分類）
4. **轉子下骨折** = 小轉子或其下方（Fielding/Seinsheimer 分類）
5. **囊外骨折** vs **囊內骨折**：囊外骨折缺血性壞死風險低
