# Musculoskeletal Imaging - Page 387

![Page 387](/core_radiology/images/msk/page-387.png)

## 血管來源病變 / Lesions of Vascular Origin

### 良性：血管瘤 / Benign: Hemangioma

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 良性病變，典型位於**椎體**，由內皮細胞排列的血管腔組成 |
| 臨床 | 通常為**偶發性發現**；少數可伴軟組織腫塊並造成神經壓迫 |

#### 影像診斷要點 / Imaging Features

| 檢查 | 表現 |
|------|------|
| **X 光 / CT** | 粗大、垂直排列的骨小樑，呈**燈心絨條紋狀 (Corduroy Striations)** |
| **CT 軸向像** | **圓點徵 (Polka-dot Sign)**：骨小樑橫截面所見 |
| **MRI T1+T2** | T1、T2 皆呈**高信號**（因病灶內含有脂肪） |
| **MRI T2** | 典型呈明顯高信號 |

#### 病理機制 / Pathophysiology
- 血管瘤內血管通道造成骨質吸收
- 反應性導致骨小樑增厚

### 惡性：骨血管肉瘤 / Malignant: Angiosarcoma of Bone

| 特徵 | 說明 |
|------|------|
| 行為 | 具侵襲性，外觀與行為皆呈現高度惡性 |
| 轉移 | 常轉移至**肺部** |

### 臨床要點 / Clinical Key Points
1. **椎體血管瘤** = 圓點徵 (CT) + 燈心絨條紋 (X 光/CT) + T1/T2 高信號 (MRI)
2. **T1、T2 皆高信號** = 血管瘤內脂肪成分（與其他骨腫瘤不同）
3. **椎體偶發性血管瘤**：最常見的椎體良性腫瘤，通常無需治療
4. **血管肉瘤** = 侵襲性骨腫瘤 + 肺部轉移
