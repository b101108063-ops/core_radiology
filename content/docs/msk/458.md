# Musculoskeletal Imaging - Page 458

![Page 458](/core_radiology/images/msk/page-458.png)

## 關節唇緣解剖 / Anatomy of the Glenoid Labrum

### 功能 / Function
| 項目 | 說明 |
|------|------|
| 定義 | 纖維軟骨性環狀結構，位於關節盂軟骨上 |
| 功能 | 增加關節盂表面積與深度；活動時產生吸力，將肱骨頭吸附於關節盂 |

### 唇緣位置描述 / Labral Location Description
| 描述方式 |
|---------|
| 六分法 (Sextants)：上、上後、上前、下前、下、下後 |
| 鐘面法 (Clock Face)：12 點上方、9 點左側、3 點右側、6 點下方 |

---

## 唇緣正常變異 / Labral Normal Variants

| 變異 | 發生率 | 特徵 |
|------|--------|------|
| **唇緣下孔 (Sublabral Foramen)** | 10% | 前上方段未附著於骨性關節盂 |
| **Buford 複合體 (Buford Complex)** | 6.5% | 索狀 MGHL + 前上方唇緣缺失 |

### Buford 複合體 vs 病理性撕裂
| 特徵 | Buford 複合體 | 病理性撕裂 |
|------|--------------|------------|
| MGHL | 索狀結構 | 可能缺失或撕裂 |
| 唇緣 | 前上方缺失 | 前上方撕裂 |

### 唇緣固定於唇緣的結構
| 結構 |
|------|
| 肩關節 GHL |
| 二頭肌腱 |
| 關節囊 |

### 臨床要點 / Clinical Key Points
1. **唇緣下孔** = 10% 正常變異（前上方未附著）
2. **Buford 複合體** = 6.5% = 索狀 MGHL + 前上方唇緣缺失
3. **唇緣** = 增加關節盂表面積與深度（像個墊圈）
4. **唇緣位置描述**：六分法或鐘面法
5. 識別正常變異可避免將 Buford 複合體誤認為病理性撕裂
