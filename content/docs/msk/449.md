# Musculoskeletal Imaging - Page 449

![Page 449](/core_radiology/images/msk/page-449.png)

## 脫位及相關後遺症 / Dislocations and Associated Sequelae

### 前側脫位相關損傷圖解 / Anterior Dislocation Findings

| 損傷 | 位置 | 說明 |
|------|------|------|
| **Hill-Sachs 病灶** | 肱骨頭後外側 | 壓迫骨折（向前撞擊關節盂） |
| **Bankart 病灶** | 關節盂前下緣 | 唇緣損傷；Bony Bankart = 骨質骨折 |

### 後側脫位相關損傷圖解 / Posterior Dislocation Findings

| 損傷 | 位置 | 說明 |
|------|------|------|
| **Trough Sign（Reverse Hill-Sachs）** | 肱骨頭前內側 | 後側撞擊後關節盂的壓迫骨折 |
| **Reverse Bankart** | 關節盂後側 | 後側關節盂唇緣損傷 |

### 圖解記憶 / Visual Memory Aid

| 前側脫位 | 後側脫位 |
|----------|----------|
| Hill-Sachs（後外側肱骨頭）| Trough Sign（前內側肱骨頭）|
| Bankart（前下關節盂）| Reverse Bankart（後關節盂）|

### MRI/關節造影表現 / MR Arthrogram Findings
| 發現 | 說明 |
|------|------|
| Hill-Sachs | 軸向 T1 脂肪抑制 MR 關節造影：後外側肱骨頭楔形壓迫骨折 |
| Trough Sign | 前內側肱骨頭線性壓迫骨折 |

### 臨床要點 / Clinical Key Points
1. **前側脫位** = Hill-Sachs（後外側）+ Bankart（前下）
2. **後側脫位** = Trough Sign（前內側）+ Reverse Bankart（後側）
3. **Hill-Sachs** = 向前撞擊前下關節盂；**Trough Sign** = 向後撞擊後關節盂
4. **Reverse Hill-Sachs** = Trough Sign 的另一名稱
5. 所有肩關節脫位患者都應注意**神經血管損傷**（尤其下側脫位的腋神經）
