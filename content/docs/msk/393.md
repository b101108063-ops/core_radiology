# Musculoskeletal Imaging - Page 393

## 棕色瘤 / Brown Tumor

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 甲狀旁腺功能亢進患者可見的**良性溶骨性病變** |
| 發病機制 | 甲狀旁腺素升高 → **蝕骨細胞活性增加** → 骨質吸收 |
| X 光特徵 | **無特異性**，影像學上與巨細胞瘤**不易區分** |

### 甲狀旁腺功能亢進的相關發現 / Associated Features of Hyperparathyroidism

| 發現 | 說明 |
|------|------|
| **骨質減少** | 常見 |
| **骨膜下骨質吸收 (Subperiosteal Bone Resorption)** | 最特徵性表現：好發於**第二、三中節指骨橈側**及**鎖骨肩峰端** |
| **軟組織鈣化** | 可見 |

### 實驗室異常 / Lab Abnormalities
| 項目 | 說明 |
|------|------|
| 甲狀旁腺素 (PTH) | **升高** |
| 血鈣 | **升高** |
| 血磷 | **降低** |

### 續發性甲狀旁腺功能亢進的特殊發現 / Secondary Hyperparathyroidism
| 發現 | 說明 |
|------|------|
| 腎性骨病變 (Renal Osteodystrophy) | 若為腎衰竭引起，可見以下表現 |
| **Rugger Jersey Spine** | 脊柱 Alternating 硬化帶（條紋狀）|

## 骨髓炎概述 / Osteomyelitis Overview

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 骨骼的感染 (Bone Marrow Infection) |
| 臨床表現 | 表現多樣；若未治療，為**慢性進行性骨質破壞**的最終共同路徑 |

### 分類方式 / Classification

| 分類依據 | 類型 |
|---------|------|
| **感染途徑** | 血源性 / 連續蔓延 / 直接接种 |
| **病程** | 急性 / 慢性 |

### 年齡相關的好發模式 / Age-Specific Patterns

| 年齡 | 常見病原及途徑 |
|------|--------------|
| **成人** | 通常由**連續蔓延或直接接种**引起（糖尿病足感染、開放性骨折、術後感染）；通常為**多菌種感染** |
| **兒童** | **血源性傳播**更常見，主要病原為**金黃色葡萄球菌 (S. aureus)** |

### 臨床要點 / Clinical Key Points
1. **棕色瘤** = 甲狀旁腺功能亢進 + 溶骨性病灶（與巨細胞瘤不易區分）
2. **骨膜下骨質吸收** = 甲狀旁腺功能亢進的**最特徵性 X 光表現**（第二、三中節指骨橈側）
3. **Rugger Jersey Spine** = 腎性骨營養不良/續發性甲狀旁腺功能亢進
4. **骨髓炎** = 成人多為多菌種糖尿病足感染；兒童多為血源性葡萄球菌
5. **棕色瘤切片需警慎**：組織學上與巨細胞瘤難以區分
