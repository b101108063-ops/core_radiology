### 透亮性骨骺（含骨骺相當物）病變的鑑別 / Lucent Epiphyseal (and Epiphyseal Equivalent) Lesions

> **骨骺相當物包括**：骨突 (Apophyses)、髕骨、腕骨、跟骨

#### 記憶口訣：**GEIChA**

| 字母 | 病變 | 關鍵特徵 |
|------|------|---------|
| **G** | **巨細胞瘤 (Giant Cell Tumor)** | 骨骺關閉？偏心？達關節面？ |
| **E** | **嗜酸性肉芽腫 (Eosinophilic Granuloma)** | < 30 歲？ |
| **I** | **感染 (Infection)** | 骨骺關閉（骨幹端可能性更高）|
| **C** | **軟骨母細胞瘤 (Chondroblastoma)** | 主要侵犯中軸骨骼？ |
| **h** | (留空) | — |
| **A** | — | — |

| 特徵 | 病變 |

### 象牙質（瀰漫性硬化）椎體的鑑別 / Ivory (Diffusely Sclerotic) Vertebral Body

| 病史 | 病變 |
|------|------|
| **前列腺癌或乳腺癌病史** | **成骨性轉移** |
| **椎體擴張？** | **佩吉氏病** |
| **椎旁軟組織腫塊？** | **淋巴瘤** |

| 其他考量 | 說明 |
|---------|------|
| 骨質疏鬆/骨膜下骨質吸收等甲狀旁腺功能亢進表現 | **棕色瘤** |
| 軟骨基質？ | **內生軟骨瘤** |

### 臨床要點 / Clinical Key Points
1. **瀰漫性硬化骨骼**：先問續發性甲狀旁腺功能亢進（腎性骨營養不良）→ 小脾臟（鐮刀型）→ 脾腫大（骨髓纖維化）
2. **透亮性骨骺病變**：用 **GEIChA** 口銵記憶（巨細胞瘤、嗜酸性肉芽腫、感染、軟骨母細胞瘤）
3. **象牙椎**：前列腺/乳腺癌 → 成骨性轉移；無病史 → 佩吉氏病或淋巴瘤
4. **地面玻璃樣基質** → 纖維結構不良
5. **FAMEB** = 肋骨膨脹性病變的鑑別口銵
