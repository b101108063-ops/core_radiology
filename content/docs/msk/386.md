# Musculoskeletal Imaging - Page 386

![Page 386](/core_radiology/images/msk/page-386.png)

## 纖維結構不良（續）/ Fibrous Dysplasia (Continued)

### 顱底纖維結構不良 / Skull Base Fibrous Dysplasia

| 特徵 | 說明 |
|------|------|
| CT 表現 | 顱底膨脹性病變，基質呈**霧狀玻璃樣**礦化（如蝶骨） |
| MRI 表現 | 信號極不均勻（FLAIR 呈高度異質性），易被誤認為惡性腫瘤 |
| 確診工具 | **CT** 為首選（CT 可清楚顯示特徵性玻璃樣基質） |

### 顱底膨脹性病變的鑑別診斷 / Differential Diagnosis of Expansile Skull Base Lesions

| 病變 | 年齡 | CT 特徵 |
|------|------|---------|
| **纖維結構不良** | 兒童/年輕成人 | 玻璃樣基質 |
| **佩吉氏病** | 老年人 | 骨質增厚、混合性硬化/溶骨 |

## 症候群 / Syndromes

### McCune-Albright 症候群
| 組成 | 說明 |
|------|------|
| 三聯徵 | **多骨型纖維結構不良** + **性早熟 (Precocious Puberty)** + **皮膚牛奶咖啡斑 (Café au Lait Spots)** |

### Mazabraud 症候群
| 組成 | 說明 |
|------|------|
| 組成 | **纖維結構不良** + **肌肉內黏液瘤 (Intramuscular Myxomas)** |
| 特徵 | 黏液瘤傾向發生於身體的**同一區域** |

### 臨床要點 / Clinical Key Points
1. **顱底玻璃樣基質 + 年輕人** → 高度提示纖維結構不良
2. **McCune-Albright 症候群** = 多骨型 FD + 性早熟 + 牛奶咖啡斑
3. **Mazabraud 症候群** = FD + 肌肉內黏液瘤（同一身體區域）
4. **CT > MRI** 用於顱底纖維結構不良的确診（MRI 信號可誤導）
