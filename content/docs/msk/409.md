## 疲勞/應力性骨折 / Stress Fracture

### 疾病分類 / Classification

| 類型 | 定義 |
|------|------|
| **疲勞骨折 (Fatigue Fracture)** | 正常骨骼承受異常反覆應力（如軍人、運動員）|
| **功能不全性骨折 (Insufficiency Fracture)** | 異常骨骼（骨質疏鬆、代謝性骨病）承受正常應力 |
| **病理性骨折 (Pathologic Fracture)** | 正常應力作用於被潛在病變（如腫瘤、感染、纖維結構不良、佩吉氏病）削弱的骨骼 |

> **注意**：「應力骨折」通常與「疲勞骨折」混用，但兩者並非同義詞

## MRI 基礎 / Basics of MR

## 肌腱 / Tendons

### 正常肌腱信號 / Normal Tendon Signal
| 序列 | 信號 |
|------|------|
| 所有 MRI 序列 | **低信號（黑暗）** |

### 魔法角現象 / Magic Angle Phenomenon
| 項目 | 說明 |
|------|------|
| 原理 | 肌腱纖維沿單一方向排列（各向異性），當肌腱與磁體主磁場呈 **55 度** 時，會產生假性信號增加 |
| 受影響序列 | 短 TE 序列（T1、質子密度、GRE）|
| 不受影響 | T2 加權序列（通常不受魔法角影響）|
| 與真正肌腱病變的鑑別 | 魔法角現象在**長 TE** 時會消失，且肌腱形態正常 |

---

### 腱鞘炎 / Tenosynovitis

| 項目 | 說明 |
|------|------|
| 定義 | 肌腱周圍的發炎 |
| 病因 | 反覆性動作、發炎性關節炎、感染 |
| MRI 表現 | 液體完全環繞肌腱 |

#### 診斷陷阱 / Pitfall
- 液體可沿與關節相通的肌腱鞘溝通（如肩關節的肱二頭肌長頭肌腱）→ **這不是腱鞘炎**
- 足部後脛肌腱鞘少量液體也可能是正常變異

#### 狹窄性腱鞘炎 / Stenosing Tenosynovitis
| 表現 | 說明 |
|------|------|
| 特徵 | 肌腱鞘內多發局限性液體聚集 |
| 好發位置 | 踝關節內側（os trigonum 症候群時的屈拇長肌腱）；腕關節（de Quervain 狹窄性腱鞘炎）|

---

### 黏液樣變性（肌腱退化）/ Myxoid Degeneration (Tendinosis)

| 項目 | 說明 |
|------|------|
| 病因 | 老化或過度使用 |
| 命名 | 與「肌腱炎 (Tendinitis)」同義；**不應使用「肌腱炎」**，因並非真正的發炎 |

#### MRI 表現
| 發現 | 說明 |
|------|------|
| 信號 | 肌腱內部中等信號（介於肌肉與液體之間）|
| 形態 | 肌腱可正常大小或增粗 |
| 肌腱內液體信號 | 應懷疑**部分撕裂**（MRI 有時難以可靠區分退化與部分撕裂）|

---

### 部分撕裂 / Partial Tear

| 項目 | 說明 |
|------|------|
| 定義 | 肌腱纖維不完全性中斷 |
| MRI 表現 | 肌腱可增粗、變薄或內部呈液體信號 |

---

### 完全撕裂 / Complete Tear

| 項目 | 說明 |
|------|------|
| 定義 | 肌腱完全性中斷 |
| MRI 表現 | 肌腱**連續性中斷**；常見肌腱殘餘片段**回縮** |

### 臨床要點 / Clinical Key Points
1. **魔法角現象** = 55 度角時短 TE 序列假性高信號；長 TE 或形態正常可區分
2. **腱鞘炎** = 液體完全環繞肌腱（注意與正常關節溝通鑑別）
3. **Stenosing Tenosynovitis** = 多發局限性液體腔（de Quervain = 腕關節；FHL = 踝關節）
4. **肌腱退化 (Tendinosis)** = 肌腱內部中等信號（不是「肌腱炎」）
5. **完全撕裂** = 肌腱連續性中斷 + 回縮
