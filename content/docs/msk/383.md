# Musculoskeletal Imaging - Page 383

![Page 383](/core_radiology/images/msk/page-383.png)

## 良性：軟骨母細胞瘤 / Benign: Chondroblastoma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 良性病變，**偏心性位於長骨骨骺**，骨骼未成熟患者 |
| 好發位置 | **膝關節附近**或**肱骨近端** |
| 年齡 | 骨骼未成熟（青少年） |

### 影像診斷要點 / Imaging Features
| 檢查 | 表現 |
|------|------|
| **X 光** | 僅約 50% 可見軟骨基質礦化 |
| **CT** | 幾乎所有病例皆可見軟骨基質鈣化 |
| **MRI** | T2 加權像呈**低或中等信號**（與其他軟骨病變不同） |

### 重要特徵 / Key Feature
- **軟骨母細胞瘤是軟骨病變中唯一 T2 通常呈低/中等信號者**（其他軟骨病變 T2 通常高信號）

### 治療與預後 / Treatment & Prognosis
| 治療方式 | 說明 |
|---------|------|
| 刮除術 (Curettage) | 主要治療 |
| 冷凍手術 (Cryosurgery) | 輔助治療 |
| 射頻燒灼術 (RFA) | 微創治療選項 |
| 局部復發率 | 低 |
| 罕見惡性變 | 可能，但極罕見 |

## 良性：軟骨黏液樣纖維瘤 / Benign: Chondromyxoid Fibroma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 發病率 | **極罕見**的良性軟骨腫瘤 |
| 好發位置 | **膝關節附近（脛骨或股骨）骨幹端** |
| X 光特徵 | 通常有**硬化性邊緣**；軟骨基質礦化少見 |
| MRI | T2 加權像呈**高信號** |

## 惡性：軟骨肉瘤 / Malignant: Chondrosarcoma

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | **軟骨來源的惡性腫瘤** |
| 原發性亞型 | 傳統型（髓內型）、去分化型、黏液樣型、清晰細胞型 |
| 續發性 | 源自內生軟骨瘤（尤其 Maffucci/Ollier）、佩吉氏病、骨軟骨瘤（尤其家族性） |

### 傳統型軟骨肉瘤影像特徵 / Conventional Chondrosarcoma Features
| 特徵 | 說明 |
|------|------|
| X 光 | 骨髓腔內膨脹性病變 + **環弧狀軟骨基質礦化** |
| 皮質 | 增厚 + **內皮質 scalloping（鋸齒狀侵蝕）** |
| 常伴隨 | **軟組織腫塊** |

### 去分化型軟骨肉瘤 / Dedifferentiated Chondrosarcoma
| 特徵 | 說明 |
|------|------|
| 性質 | **高度侵襲性** |
| 組織學 | 可含有纖維肉瘤或骨肉瘤成分 |

### 骨軟骨瘤惡性變的軟骨帽厚度 / Cartilage Cap Thickness
| 厚度 | 意義 |
|------|------|
| **> 2 cm (MRI)** | 高度暗示已惡性變為軟骨肉瘤 |

### 臨床要點 / Clinical Key Points
1. **軟骨母細胞瘤** = 青少年骨骺偏心病灶 + T2 低信號（唯一 T2 低信的軟骨腫瘤）
2. **軟骨黏液樣纖維瘤** = 極罕見 + 膝關節附近 + 硬化邊緣
3. **軟骨肉瘤** = 環弧狀礦化 + 皮質 scalloping + 軟組織腫塊
4. **去分化型** = 軟骨肉瘤 + 纖維肉瘤/骨肉瘤成分 = 高度侵襲性
5. **骨軟骨瘤軟骨帽 > 2 cm** = 惡性變軟骨肉瘤的強烈暗示
