# Musculoskeletal Imaging - Page 362

![Page 362](/core_radiology/images/msk/page-362.png)

## 血清陰性脊椎關節病 / Seronegative Spondyloarthropathies

### 疾病概述 / Disease Overview
- 四種炎症性關節病的總稱
- **類風濕因子陰性 (Seronegative)**
- 患者通常 **HLA-B27 陽性**

### 四種血清陰性脊椎關節病

| 疾病 | 特徵 |
|------|------|
| **僵直性脊椎炎 (Ankylosing Spondylitis)** | 對稱性骶髂關節炎 |
| **乾癬性關節炎 (Psoriatic Arthritis)** | 不對稱骶髂關節炎 |
| **反應性關節炎 (Reactive Arthritis)** | 不對稱骶髂關節炎 |
| **發炎性腸病關節炎 (IBD-associated Arthropathy)** | 對稱性骶髂關節炎 |

### 助記法 / Mnemonic
- **對稱性**：IBD + Ankylosing spondylitis（都以母音開頭）
- **不對稱**：Psoriatic + Reactive（都以子音開頭）

---

## 骶髂關節炎——脊椎關節病的特徵 / Sacroiliitis: Hallmark of Spondyloarthropathies

### 解剖基礎 / Anatomical Basis
- 骶髂關節**僅下1/2**為滑膜關節
- 骶髂關節炎**首先侵犯髂骨面**

### 骶髂關節炎對稱性分類 / Symmetry Classification

| 對稱性 | 疾病 |
|--------|------|
| **對稱性** | IBD相關關節炎、僵直性脊椎炎 |
| **不對稱性** | 乾癬性關節炎、反應性關節炎 |

### 單側骶髂關節炎 / Unilateral Sacroiliitis
- **最重要病因：感染性關節炎**
- 好發族群：免疫抑制患者、靜脈藥物濫用者
- 臨床表現：發燒 + 骶髂關節疼痛

---

## 發炎性腸病關節炎 / Inflammatory Bowel Disease (IBD) Associated Arthropathy

### 相關疾病 / Associated Conditions
| 疾病 | 說明 |
|------|------|
| 潰瘍性結腸炎 | IBD 最常見類型 |
| 克羅恩病 (Crohn's Disease) | 可伴隨骶髂關節炎 |
| 惠普病 (Whipple's Disease) | 罕見 |
| 胃繞道術後 | 可伴隨骶髂關節炎 |

### 骶髂關節炎特徵
- **典型為對稱性**
- 與 Crohn 病骶髂關節炎可同時存在

### IBD 影像特徵 / Imaging Features

| 檢查 | 表現 |
|------|------|
| **CT** | 骶髂關節對稱性硬化 + 侵蝕（髂骨面） |
| **腸道 CT** | 腸壁增厚 + 壁分層 + 強化 |

### 臨床要點 / Clinical Key Points
1. **血清陰性脊椎關節病**：RF 陰性 + HLA-B27 陽性
2. **對稱性骶髂關節炎**：IBD + 僵直性脊椎炎（都以母音開頭）
3. **不對稱骶髂關節炎**：乾癬性 + 反應性（都以子音開頭）
4. **單側骶髂關節炎**：需優先排除感染性關節炎
5. **骶髂關節炎首先侵犯髂骨面**
