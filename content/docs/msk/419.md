## 阿基里斯肌腱損傷 / Achilles Tendon Injury

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 發病率 | **最常見的踝關節肌腱損傷** |

### 阿基里斯肌腱退化 (Achilles Tendinosis)
| 項目 | 說明 |
|------|------|
| X 光表現 | 肌腱**增粗** |
| 注意 | 阿基里斯肌腱增粗**非特異性**：亦可見於**高血脂症候群患者的黃瘤 (Xanthomas)** |

### 阿基里斯完全斷裂 / Complete Achilles Rupt�
| 項目 | 說明 |
|------|------|
| 診斷 | 通常為臨床檢查確診 |
| X 光表現 | 肌腱輪廓**中斷**；Kager's 脂肪墊內軟組織增加 |

### Kager's 脂肪墊 / Kager's Fat Pad
| 邊界 | 說明 |
|------|------|
| 前界 | 拇長屈肌 |
| 下界 | 跟骨 |
| 後界 | 阿基里斯肌腱 |

#### Kager's 脂肪墊軟組織增加的鑑別診斷 / Differential of Increased Soft Tissue in Kager's Fat Pad
| 診斷 | 說明 |
|------|------|
| **阿基里斯肌腱損傷** | 斷裂或退化 |
| **副腓腸肌 (Accessory Soleus Muscle)** | Kager's 脂肪墊中最常見的軟組織腫塊 |
| **Haglund 病** | 遠端阿基里斯肌腱增粗相關的跟骨後滑囊炎；不合腳的鞋子可為病因（「Pump Bumps」）|

### 臨床要點 / Clinical Key Points
1. **阿基里斯肌腱** = 最常見損傷的踝關節肌腱
2. **阿基里斯增粗** = 非特異性（可為退化或黃瘤）
3. **Kager's 脂肪墊** = 跟骨、屈拇長肌、阿基里斯肌腱之間的三角形脂肪墊
4. **Haglund 病** = 跟骨後滑囊炎 + 阿基里斯遠端增粗（鞋子摩擦）
5. **完全斷裂** = 臨床上確診；X 光可見輪廓中斷 + Kager's 脂肪墊軟組織增加
