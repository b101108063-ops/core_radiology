![Page 397](/core_radiology/images/msk/page-397.png)

## 特定解剖位置的骨髓炎 / Osteomyelitis at Specific Locations

### 手部與手指 / Hand and Fingers
| 部位 | 感染情境 |
|------|---------|
| 掌骨與指骨 | **咬傷後**感染 |

### 足趾 / Toe
| 部位 | 感染情境 |
|------|---------|
| **遠節趾骨** | 踢到腳趾 + 甲床受傷（骨膜緊鄰甲床）|

### 脊椎 / Spine
| 項目 | 說明 |
|------|------|
| 成人脊椎骨髓炎/椎間盤炎 | 可由血行動脈傳播、脊椎手術、或泌尿生殖道感染經**Batson 靜脈叢**蔓延引起 |
| 感染起點 | 脊椎椎體**軟骨下區**，而後蔓延至終板、椎間盤、相鄰椎體 |
| 兒童椎間盤炎 | 認為是因為持續有血管的椎間盤**直接血源播種**所致 |

## 骨髓炎影像學檢查 / Imaging Osteomyelitis

### X 光檢查 / Radiographs
| 項目 | 說明 |
|------|------|
| 角色 | 疑似骨髓炎時的**首選初步檢查** |
| 限制 | 通常需 **10-14 天**才會出現 X 光可見的變化 |

### 早期影像學發現 / Early Radiographic Findings

| 感染類型 | 早期發現 |
|---------|---------|
| **血源性骨髓炎** | 區域性骨質疏鬆（反應性充血）→ 低密度骨髓病變 |
| **連續性骨髓炎** | 軟組織腫脹 → 皮質侵蝕 |

### 核醫學與 MRI / Nuclear Medicine and MRI

| 檢查 | 特點 |
|------|------|
| **三相 Tc-99m MDP 骨掃描** | 症狀後 **24-48 小時**內即呈陽性；急性骨髓炎：三相皆陽（血流、血池、延遲相）|
| **蜂窩性組織炎** | 僅血流、血池相陽，延遲相陰性 |
| **MRI** | **3-5 天內**即可檢出早期骨髓炎；敏感度類似核醫，特異度更高 |

### MRI 骨髓炎的特徵 / MRI Hallmarks of Osteomyelitis
| 發現 | 說明 |
|------|------|
| 正常脂肪骨髓信號被取代 | 骨髓炎的標誌 |
| T2 高信號 / T1 低信號 | 水腫與滲出 |
| 皮質高信號（通常各序列皆低）| 皮質感染 |
| **高陰性預測值** | MRI 陰性可幾乎排除骨髓炎 |
| 對比劑 (Gd) | 有助於顯示液體聚集與壞死骨（死骨不強化）|

### 白血球掃描 (WBC Scan) / WBC Scintigraphy
| 項目 | 說明 |
|------|------|
| 原理 | 骨髓被感染取代時，白血球與硫膠體掃描呈**不一致**所見（感染區：WBC 攝取增加 + 硫膠體減少）|
| 限制 | **脊椎骨髓炎敏感度低**（因感染被包覆，白血球無法進入）|
| 製劑 | 可用 **In-111 WBC** 或 **Tc-99m HMPAO-WBC**；In-111 輻射劑量較高、需 24 小時、影像雜訊多 |

### 臨床要點 / Clinical Key Points
1. **遠節趾骨骨髓炎**：踢到腳趾 + 甲床損傷
2. **Batson 靜脈叢**：泌尿生殖道感染可逆行蔓延至脊椎
3. **X 光需 10-14 天**才顯現變化 → 早期骨髓炎陰性不能排除
4. **三相骨掃描**：急性骨髓炎三相皆陽；蜂窩性組織炎延遲相陰性
5. **MRI 陰性**可幾乎排除骨髓炎（高陰性預測值）
