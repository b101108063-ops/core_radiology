## 骨髓炎影像學（續）/ Imaging Osteomyelitis (Continued)

### WBC 掃描與硫膠體掃描的聯合應用 / Combined WBC and Sulfur Colloid Scintigraphy

| 掃描類型 | 感染骨髓 | 健康骨髓 |
|---------|---------|---------|
| **WBC 掃描** | 攝取增加 ↑ | 正常 |
| **硫膠體掃描** | 減少 ↓（被感染取代）| 正常 |

- **不一致的結果** = 骨髓感染的高度特異性指標

### 各檢查的敏感度/特異度總結 / Sensitivity/Specificity Summary

| 檢查 | 敏感度 | 特異度 |
|------|--------|--------|
| X 光 | 低（需 10-14 天）| 中 |
| 三相骨掃描 | 高 | 中 |
| WBC 硫膠體聯合掃描 | 高 | **高** |
| MRI | **高** | **高** |

## 軟組織感染 / Soft-tissue Infections

### 化膿性關節炎 / Septic Arthritis

#### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 關節感染 |
| 診斷金標準 | **關節抽吸 (Joint Aspiration)** |
| 影像/臨床標誌 | **關節積液 (Joint Effusion)** |

#### 兒童好發部位 / Pediatric Location
| 項目 | 說明 |
|------|------|
| 好發位置 | **髖關節** |
| 機制 | 股骨近端骨髓炎**連續性蔓延**（該骨幹部位位於髖關節囊內）|
| 後果 | 若未治療，可導致快速關節破壞，最終**關節強直 (Ankylosis)** |

#### 特殊族群 / Special Populations
| 族群 | 常見感染部位 |
|------|------------|
| **靜脈藥物濫用者** | 薦腸關節 (Sacroiliac Joint) 及**胸鎖關節 (AC Joint)** |

#### 臨床要點 / Clinical Key Points
1. **關節抽吸** = 診斷化膿性關節炎的金標準
2. **兒童髖關節**：股骨近端骨髓炎可連續性蔓延至髖關節（骨幹位於關節囊內）
3. **未治療的化膿性關節炎**：快速關節破壞 → 關節強直
4. **靜脈藥癮者**：薦腸關節及胸鎖關節為好發部位
