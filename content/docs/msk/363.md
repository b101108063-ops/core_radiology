# Musculoskeletal Imaging - Page 363

![Page 363](/core_radiology/images/msk/page-363.png)

## 僵直性脊椎炎 / Ankylosing Spondylitis (AS)

### 疾病概述 / Disease Overview
- 好發族群：**年輕男性** + **HLA-B27 陽性**
- 臨床表現：背部疼痛與僵硬
- 關節外表現：肺纖維化（以上葉為主）、主動脈炎、心臟傳導障礙

### 早期 X 光徵象 / Early Radiographic Signs
- **骶髂關節對稱性侵蝕、關節間隙增寬、硬化**

### 脊椎侵犯演進順序 / Sequential Spinal Involvement

| 階段 | 表現 | 說明 |
|------|------|------|
| **Romanus 病灶** | 椎體終板前上/下緣侵蝕 | 纖維環附著處的附著點炎 (Enthesitis) |
| **閃亮角徵 (Shiny Corner)** | Romanus 病灶處的硬化 | 代表既往 Romanus 病灶演變 |
| **椎體終板方化 (Squaring)** | 椎體邊緣骨質丢失 + 侵蝕 | |
| **纖細韌帶骨化 (Delicate Syndesmophytes)** | 鄰近椎體邊緣之間的骨性連接 | 代表疾病進入晚期 |
| **竹椎 (Bamboo Spine)** | 脊椎完全強直 | 晚期表現 |

### 特殊影像徵象 / Characteristic Signs

| 徵象 | 說明 |
|------|------|
| **Romanus 病灶** | 椎體前上/下緣侵蝕（附著點炎） |
| **閃亮角徵** | 椎體角部骨質硬化（Romanus 病灶演變） |
| **竹椎** | 脊椎完全強直 + 均勻骨橋形成 |
| **匕首徵 (Dagger Sign)** | 棘突融合形成的單一垂直緻密影 |
| **Andersson 病灶** | 完全強直脊椎中的假關節（骨折不癒合） |

### 嚴重併發症 / Serious Complications
- 完全強直的脊椎即使受到**輕微創傷**也極易骨折
- 外傷後疼痛 → 需 **CT** 評估（即使輕微創傷）

### 臨床要點 / Clinical Key Points
1. **Romanus 病灶**：椎體角部侵蝕 = AS 最早脊椎表現
2. **Shiny Corner**：Romanus 病灶演變後的硬化
3. **竹椎**：脊椎完全強直 = AS 晚期特徵
4. **Andersson 病灶**：強直脊椎中的假關節
5. 完全強直脊椎輕微創傷即可骨折 → CT 為首選檢查
