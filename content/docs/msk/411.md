## 前足（續）/ Forefoot (Continued)

### 蹠骨 Stress Fracture / Metatarsal Stress Fracture

| 項目 | 說明 |
|------|------|
| 最早 X 光徵象 | 勉強可見的線性皮質透亮線 |
| 典型表現 | 通常在骨膜炎和骨痂形成後才在 X 光上可見 |

---

### 種子骨骨折 / Sesamoid Fracture

| 項目 | 說明 |
|------|------|
| 病因 | 第一蹠趾關節 (MTP) 的極端過度伸展或背側脫臼（可為暫時性）|
| 附著結構 | 屈拇短肌 (Flexor Hallucis Brevis) 附著於種子骨；內側頭附著於脛側（內側）種子骨；外側頭附著於腓側（外側）種子骨 |

#### 二分種子骨 vs 種子骨骨折鑑別 / Bipartite Sesamoid vs Fracture
| 特徵 | 二分種子骨 | 種子骨骨折 |
|------|-----------|-----------|
| 形狀 | 圓形 | 不規則 |
| 邊緣 | 完全皮質化 (Corticated) | 銳利、不規則 |
| 大小 | 兩部分之和**大於**對側種子骨 | 通常與對側相似 |

#### Turf Toe
- 「Turf Toe」用於描述第一 MTP 關節的各種損傷，包括**種子骨骨折**

---

### Lisfranc 骨折-脫臼 / Lisfranc Fracture-Dislocation

| 項目 | 說明 |
|------|------|
| 關節名稱 | 蹠跗關節 (Tarsometatarsal Joint) |
| 名稱由來 | 拿破崙戰爭中的法國外科醫師 Lisfranc（在此關節處進行截肢）|
| 穩定性關鍵 | 多條韌帶，其中 **Lisfranc 韌帶**最為重要 |
| Lisfranc 韌帶 | 連接**內側楔骨**與**第二蹠骨底部**的骨間韌帶複合體 |

### 治療與預後 / Treatment & Prognosis
| 項目 | 說明 |
|------|------|
| 治療 | **手術** |
| 未治療後果 | 致殘性退化性關節炎 + 縱弓變平 |

### Lisfranc 關節對線評估要點 / Alignment Evaluation
| 標誌 | 位置關係 |
|------|---------|
| 第一蹠骨底部外側 vs 內側楔骨外側 | 應對線 |
| 第二蹠骨底部內側 vs 第二楔骨內側 | 應對線 |
| 第三蹠骨底部內側 vs 第三楔骨內側 | 應對線 |
| 第四蹠骨底部內側 vs 骰骨內側 | 斜位片較易觀察 |
| 蹠跗關節背面輪廓 | 應為連續性 |

### 臨床要點 / Clinical Key Points
1. **蹠骨 Stress Fracture** = 最早徵象為皮質線性透亮線（X 光早期可能陰性）
2. **二分種子骨** = 圓形 + 完全皮質化邊緣（與種子骨骨折不規則邊緣鑑別）
3. **Lisfranc 韌帶** = 內側楔骨 → 第二蹠骨底部（足部最關鍵的穩定韌帶）
4. **Lisfranc 損傷** = 手術治療；漏診/未治療 → 嚴重退化性關節炎
5. **種子骨骨折** = Turf Toe 的一部分（MTP 關節過度伸展損傷）
