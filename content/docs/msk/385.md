# Musculoskeletal Imaging - Page 385

![Page 385](/core_radiology/images/msk/page-385.png)

## 纖維結構不良 / Fibrous Dysplasia

### 疾病概述 / Disease Overview
| 項目 | 說明 |
|------|------|
| 定義 | 良性、先天性**非腫瘤性**疾病，特徵為正常鬆質骨被異常纖維組織取代 |
| 好發年齡 | 兒童及年輕成人 |
| 類型 | 單骨型 (Monostotic) 或 多骨型 (Polyostotic)；多骨型常為單側分布 |

### 好發部位與 X 光特徵 / Location and X-ray Features

| 部位 | X 光特徵 |
|------|---------|
| **長骨** | 骨幹端 (Metadiaphyseal) 中心性；常導致**弓形畸形**（如股骨近端的「牧羊杖狀畸形」(Shepherd's Crook Deformity)） |
| **肋骨或長骨** | 基質通常模糊，呈**玻璃樣 (Ground Glass)** |
| **骨盆** | 常呈囊狀 |
| **顱底** | 膨脹性生長；MRI 上可呈極不均勻信號 |

### 常見併發症 / Common Complications
| 併發症 | 說明 |
|--------|------|
| **病理性骨折** | 最常見併發症，常見於**股骨頸** |
| 囊性變 | 骨盆病變常呈囊狀外觀 |

### MRI 特徵 / MRI Features
| 發現 | 說明 |
|------|------|
| T1/T2 信號 | 不均勻；取決於纖維組織與黃骨髓比例 |
| 液體レベル | 囊性變時可見（年輕成人髖臼上方囊性病灶的鑑別診斷之一） |

### 鑑別診斷 / Differential Diagnosis
| 病變 | 鑑別要點 |
|------|---------|
| 動靜脈畸形骨囊腫 (ABC) | 長骨中心性病灶的鑑別 |
| 軟骨母細胞瘤 | 青少年骨骺偏心病灶 |
| 佩吉氏病 (Paget Disease) | 顱底膨脹性病灶：年齡為關鍵（纖維結構不良 = 兒童/年輕人；佩吉氏病 = 老年人） |

### 臨床要點 / Clinical Key Points
1. **纖維結構不良** = 玻璃樣基質 + 中心性分佈 + 骨骼未成熟患者的弓形畸形
2. **牧羊杖狀畸形 (Shepherd's Crook)** = 股骨近端纖維結構不良的特徵性表現
3. **病理性骨折** = 纖維結構不良最常見的併發症（股骨頸）
4. **顱底膨脹性病變**：年輕人 → 纖維結構不良；老年人 → 佩吉氏病
5. **骨盆囊性病灶**：年輕成人需考慮囊性纖維結構不良 vs 單純性骨囊腫
