## BI-RADS：乳房攝影鈣化詞典 / BI-RADS: Mammographic Calcification Lexicon

### 良性鈣化分類 (Typically Benign Calcifications)

| 類型 | 說明 |
|------|------|
| **皮膚鈣化 (Skin Calcifications)** | 圓形鈣化 |
| **血管鈣化 (Vascular Calcifications)** | 血管壁鈣化 |
| **透X線中心型鈣化 (Lucent-Centered Calcifications)** | 中心透X線 |
| **粗大或「爆米花」樣鈣化 (Coarse or "Popcorn-like" Calcification)** | 大塊爆米花樣 |
| **蛋殼樣/邊緣樣鈣化 (Eggshell or Rim Calcification)** | 薄環狀 |
| **大型棒狀鈣化 (Large Rod-Like Calcifications)** | 棒狀分布 |
| **牛奶樣鈣化 (Milk of Calcium)** | 重力分層 |

### 粗大不均質鈣化 (Coarse Heterogeneous Calcifications)

### 高度可疑惡性 (Higher Probability of Malignancy)

| 類型 | 說明 |
|------|------|
| **細多形性鈣化 (Fine Pleomorphic Calcifications)** | 形狀大小各異 |
| **細線性或細線性分支狀鈣化 (Fine Linear or Fine Branching Calcifications)** | 導管內分布 |

### 分布分類 (Distribution)

| 分布類型 | 說明 |
|----------|------|
| **Grouped/Clustered（簇狀）** | ≥5個鈣化/<1cc |
| **Segmental（節段性）** | 導管系統分布 |
| **Linear（線性）** | 排列成線 |
| **Regional（區域性）** | >2cc大體積 |
| **Diffuse/Scattered（彌散/散在）** | 隨機分布 |

### 臨床要點 / Clinical Key Points
- 鈣化的**形態和分布**共同決定惡性可疑程度
- **細多形性**和**細線性分支狀**鈣化為高度可疑
- 節段性分布提示導管系統受累，高度可疑
- 簇狀分布（≥5個鈣化/<1cc）是活檢的重要指徵
