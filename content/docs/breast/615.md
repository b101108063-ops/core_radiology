# Breast Imaging - Page 615

![Page 615](/core_radiology/images/breast/page-615.png)

## BI-RADS乳房攝影腫塊詞彙總結 / BI-RADS Mammographic Mass Lexicon Summary

### BI-RADS腫塊描述系統 (Mass Description System)

#### 大小 (Size)
| 測量單位 |
|----------|
| 厘米 (Centimeters) |

#### 形狀 (Shape)

| 形狀 | 可疑程度 |
|------|----------|
| **圓形 (Round)** | 低 |
| **橢圓形 (Oval)** | 低 |
| **分葉狀 (Lobular)** | 中等 |
| **不規則 (Irregular)** | **高** |

#### 邊緣 (Margins)

| 邊緣 | 可疑程度 |
|------|----------|
| **境界清楚 (Circumscribed)** (<75%可見) | **低** |
| **遮擋 (Obscured)** | 中等 |
| **微小分葉 (Microlobulated)** | 中-高 |
| **邊界不清 (Indistinct)** | 高 |
| **毛刺狀 (Spiculated)** | **非常高** |

#### 密度 (Density)

| 密度 | 說明 |
|------|------|
| **透X線 (Radiolucent)** | 脂肪密度 |
| **低密度 (Low Density)** | 低於周圍 |
| **等密度 (Equal Density)** | 與周圍相等 |
| **高密度 (High Density)** | 高於周圍 |

#### 形狀-邊緣-密度組合要點 (Shape-Margin-Density Key Points)
- **境界清楚 + 透X線 = 良性**（如油囊、纖維腺瘤）
- **不規則形狀 + 毛刺狀邊緣 = 高度可疑**
- **新發**病灶即使所有形態特徵看似良性也需進一步評估
- 大小測量決定病灶是否生長，是重要的隨訪參數

#### 臨床要點 / Clinical Key Points
- BI-RADS詞彙標準化了乳房攝影報告
- 邊緣特徵是最重要的惡性預測因子
- **毛刺狀邊緣**是最可疑的BI-RADS描述符
- 結合形狀、邊緣和密度可提高診斷準確性
