# Breast Imaging - Page 592

![Page 592](/core_radiology/images/breast/page-592.png)

## 血管緊張素轉換酶抑制劑腎圖 / ACE Inhibitor Renogram

### 疾病名稱 (Disease Name)
**ACE抑制劑腎圖 (ACE Inhibitor Renogram)**

### 臨床特點 (Clinical Features)
- ACE抑制劑腎圖對**腎动脉狹窄 (Renal Artery Stenosis)** 具有相對特異性，是高血壓的常見原因之一
- 使用的放射性藥物為 **Tc-99m MAG3**，少數情況使用 Tc-99m DTPA
- 在代償性腎动脉狹窄中，血流減少刺激**腎素-血管緊張素系統**：
  - 腎素 (Renin) → 血管緊張素I (Angiotensin I) → 血管緊張素II (Angiotensin II)
  - 血管緊張素II收縮**出球小動脈 (Efferent Arteriole)** 以維持腎小球濾過率 (GFR)
- ACE抑制劑（如 Captopril 25-50 mg）使用後，出球小動脈舒張，導致 GFR 下降

### 診斷要點 (Diagnostic Key Points)
- 若患者正在服用ACE抑制劑，應在檢查前 **48小時至1週** 停藥
- 檢查中需維持靜脈通路，以備低血壓時補充液體
- 陽性標準（取決於放射性藥物）：

| 藥物 | 陽性標準 |
|------|--------|
| **MAG3**（腎小管製劑） | 2-3分鐘時單腎攝取率<40%；皮質活性差異>20%；達峰時間延遲>2分鐘 |
| **DTPA**（腎小球製劑） | GFR下降導致攝取和排泄減少 |

### 鑑別診斷 (Differential Diagnosis)
- 脫水導致的腎圖異常
- 膀胱出口阻塞
- 慢性腎功能衰竭

### 臨床要點 / Clinical Key Points
- ACE抑制劑腎圖是診斷**腎动脉狹窄**的重要功能性檢查
- 停用ACE抑制劑是確保檢查準確性的關鍵前提
- MAG3對腎功能減退的患者仍能保持較好的攝取和分泌功能
