# Breast Imaging - Page 614

![Page 614](/core_radiology/images/breast/page-614.png)

## 伴隨特徵與案例分析 / Associated Features and Case Analysis

### 伴隨特徵 (Look for Associated Features)

| 特徵 | 說明 |
|------|------|
| **結構扭曲 (Architectural Distortion)** | 從中心點發出的輻射狀線狀密度，無明確可見腫塊；高度提示癌（但有良性原因）；若無手術或創傷史，應活檢 |
| **微鈣化 (Microcalcifications)** | 可與惡性導管鈣化相關 |
| **皮膚回縮 (Skin Retraction)** | 最常見於術後；也可能代表促結締組織增生性腫瘤反應 |
| **乳頭回縮 (Nipple Retraction)** | 乳頭的牽拉或成角；**回縮與內陷不同**（內陷為整個乳頭向內，發育性，可為雙側，若穩定不一定為惡性） |
| **皮膚增厚 (Skin Thickening)** | 可代表水腫或放射治療後改變 |
| **網狀結構增粗 (Trabecular Thickening)** | 乳房纖維間隔增粗；可見於水腫或放射治療後患者 |
| **腋窩淋巴結腫大 (Axillary Adenopathy)** | 可為正常或可疑，取決於淋巴結形態；淋巴結脂肪門被置換時需評估，特別是新發時 |

---

### 案例分析 (Example Case)

#### 病史與影像發現
| 項目 | 描述 |
|------|------|
| **病灶** | 新發、等密度、圓形、**2 cm** |
| **位置** | CC體位可見內側乳房 |
| **邊緣** | 微小分葉狀 |
| **伴隨發現** | 無相關微鈣化或結構扭曲 |

#### 進一步評估
- 局部壓迫和超聲顯示： apparent的微小小葉狀邊緣實際為重疊的纖維腺體組織
- 腫塊真實邊緣為**境界清楚**

#### 病理結果
- **良性纖維腺瘤**

#### 臨床要點 / Clinical Key Points
- 新發腫塊即使形態疑似良性仍需充分評估
- 局部壓迫和超聲可澄清被遮擋的邊緣
- 案例說明：微小小葉狀邊緣可由正常組織重疊造成
