# Breast Imaging - Page 613

![Page 613](/core_radiology/images/breast/page-613.png)

## BI-RADS腫塊密度、形狀與位置 / Mass Density, Shape, and Location

### 密度描述 (Describe the Density)

| 密度類型 | 說明 |
|----------|------|
| **透X線 (Radiolucent)** | 脂肪密度 |
| **低密度 (Low Density)** | 低於周圍組織 |
| **等密度 (Equal Density/Isodense)** | 與周圍組織相等 |
| **高密度 (High Density)** | 高於周圍組織 |

#### 臨床特點 (Clinical Features)
- 大多數形成可見腫塊的乳腺癌密度**等於或高於**周圍纖維腺體組織
- **乳腺癌從不含有脂肪**（理論上乳腺癌可包繞含有脂肪的良性病變）
- **邊界清楚且透X線的腫塊為良性**

---

### 形狀描述 (Describe the Shape)

| 形狀 | 說明 |
|------|------|
| **圓形 (Round)** | 球形 |
| **橢圓形 (Oval)** | 橢圓/蛋形 |
| **分葉狀 (Lobular)** | 波狀輪廓 |
| **不規則 (Irregular)** | 非圓、非橢圓、非分葉 |

#### 臨床特點 (Clinical Features)
- 乳腺癌可表現為任何形狀
- **不規則形狀最可疑**

---

### 位置描述 (Describe the Location)

#### 象限定義 (Quadrant Nomenclature)

| 象限 | 說明 |
|------|------|
| **Upper Outer Quadrant (UOQ)** | 外上象限 |
| **Upper Inner Quadrant (UIQ)** | 內上象限 |
| **Lower Outer Quadrant (LOQ)** | 外下象限 |
| **Lower Inner Quadrant (LIQ)** | 內下象限 |

#### 診斷要點 (Diagnostic Key Points)
- 對側乳房的鏡像對應象限：名稱相同的對側象限
  - 例如：左乳房外上象限的鏡像是右乳房的外上象限
- **乳暈下 (Subareolar)** 或**腋尾 (Axillary Tail)** 用於定位時，不必指定象限
- **時鐘法**用於超聲定位，乳房攝影**首選象限法**

---

### 大小測量 (Measure the Size)
- **大小本身是惡性的較差預測因子**，但可決定病灶是否在生長
