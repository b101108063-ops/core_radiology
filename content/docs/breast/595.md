# Breast Imaging - Page 595

![Page 595](/core_radiology/images/breast/page-595.png)

## 感染與炎症顯像 / Infection and Inflammation Imaging

### 標記白細胞顯像 (Labeled Leukocyte Imaging)

#### In-111氧克服白細胞 (Indium-111 Oxine WBCs)

##### 臨床特點 (Clinical Features)
- **正常分布**：脾臟 > 肝臟 >> 骨髓
- 感染顯像於 **24小時** 進行

##### 診斷要點 (Diagnostic Key Points)

| 優勢 | 劣勢 |
|------|------|
| 無生理性腸道積聚，可評估腹部/腸道感染 | 標記程序繁瑣 |
| 可同時行Tc-99m硫膠體或Tc-99m MDP骨掃描 | 輻射劑量較高 |
| 適用於骨掃描異常基礎上的骨髓炎評估（如假體） | 脊椎骨髓炎準確性低於鎵 |

#### Tc-99m HMPAO白細胞 (Tc-99m HMPAO WBCs)

##### 臨床特點 (Clinical Features)
- Tc-99m半衰期短，可給予更高放射性活度，計數更好，吸收劑量更低，成像更早
- **主要劣勢**：未結合的Tc-99m HMPAO複合物在胃腸道和泌尿生殖道有生理性攝取
  - 腎臟活動出現較早，腸道活動在1-2小時後出現
  - 由於半衰期短，延遲成像不實用

##### 優勢比較 (Advantages Comparison)

| 比較項目 | In-111 WBC | Tc-99m HMPAO WBC |
|----------|------------|-------------------|
| 半衰期 | 67小時 | 6小時 |
| 腹部/腸道評估 | ✓（無腸道干擾） | ✗（有腸道干擾） |
| 延遲成像 | ✓ | ✗ |
| 輻射劑量 | 較高 | 較低 |
| 同時骨掃描 | ✓ | ✓ |

##### 臨床要點 / Clinical Key Points
- **In-111 WBC**：首選腹部/腸道感染、骨髓炎假體評估
- **Tc-99m HMPAO**：兒童首選（輻射劑量低）

---

### 臨床應用 (Clinical Applications)

#### 肝細胞癌 (Hepatocellular Carcinoma, HCC)

##### 臨床特點 (Clinical Features)
- 肝臟局灶性**鎵攝取增加**提示HCC
- 鎵攝取減少時HCC可能性極低

#### 鎵-鉈聯合顯像 (Combined Gallium and Thallium Imaging)

##### 鑑別診斷記憶法 (Mnemonic)

| 腫瘤/疾病 | 鎵-67 | 鉈-201 |
|-----------|-------|--------|
| **卡波西肉瘤 (Kaposi Sarcoma)** | ✗ | **✓** (KaT) |
| **結核/非典性分枝桿菌** | **✓** (TuG) | ✗ |
| **淋巴瘤 (Lymphoma)** | **✓** | **✓** |

##### 臨床要點 / Clinical Key Points
- 鎵-鉈聯合顯像是免疫抑制患者鑑別診斷的重要工具
- 卡波西肉瘤：**鉈攝取**，**不攝取鎵**
- 結核：**鎵攝取**，**不攝取鉈**

---

#### 骨髓炎 (Osteomyelitis)

##### 診斷要點 (Diagnostic Key Points)
- 陽性的**三相Tc-99m MDP骨掃描**對骨髓炎的特異性：**僅在X光片正常時特異性高**
- X光片異常時：**鎵顯像**或**WBC顯像**可提高特異性
- 脊椎骨髓炎和椎間盤炎：鎵顯像優選
- **感染性假體**：WBC顯像（通常用In-111）+ Tc-99m硫膠體

##### 結果判讀 (Result Interpretation)

| 顯像結果 | 意義 |
|----------|------|
| WBC↑ + 硫膠體↓（不一致區域） | 骨髓被WBC取代 = **骨髓炎** |
| WBC正常 + 硫膠體正常 | 正常骨髓 |

##### 臨床要點 / Clinical Key Points
- 三相骨掃描正常 + X光片正常 → 可排除骨髓炎
- 鎵顯像提高陽性骨掃描對骨髓炎的特異性
- 假體周圍感染：WBC+硫膠體不一致提示感染
