# Breast Imaging - Page 634

![Page 634](/core_radiology/images/breast/page-634.png)

## 實性腫塊：纖維腺瘤 / Solid Masses: Fibroadenoma

### 纖維腺瘤 (Fibroadenoma)

#### 臨床特點 (Clinical Features)
- 纖維腺瘤是年輕女性常見的**良性腫瘤**
- 是該年齡組最常見的**可觸及腫塊**
- 臨床表現：**堅實、可移動的腫塊**

#### 診斷要點 (Diagnostic Key Points)

| 檢查 | 典型表現 |
|------|----------|
| **乳房攝影** | 橢圓形或分葉狀、等密度、境界清楚腫塊；老年女性的**透明變性纖維腺瘤**含粗大「爆米花」樣鈣化，具有明確良性特徵 |
| **超聲** | 橢圓形、境界清楚、均質低回聲腫塊；偶有組織學良性纖維腺瘤可有不規則邊緣、內部回聲不均或聲影等可疑特徵 |

#### BI-RADS 3分類標準 (BI-RADS 3 Criteria)
| 特徵 | 要求 |
|------|------|
| **形狀** | 橢圓形 |
| **方向** | 平行（寬:高>1.4，寬>高） |
| **邊緣** | 全部境界清楚 |
| **回聲** | 非顯著低回聲 |

- 滿足以上標準的假定纖維腺瘤可歸為**BI-RADS 3**，假陰性率**0.5%**

---

### 纖維腺瘤變異型 (Fibroadenoma Variants)

| 類型 | 特點 |
|------|------|
| **複雜性纖維腺瘤** | 含增生元素和內部囊腫，乳腺癌風險略增加 |
| **幼年性纖維腺瘤** | 見於青少年，特徵為生長迅速 |
| **巨大纖維腺瘤** | 腫塊>8 cm |

#### 鑑別診斷 (Differential Diagnosis)
- 纖維腺瘤與**葉狀腫瘤**成像表現可相同，特別是較大時

#### 臨床要點 / Clinical Key Points
- 透明變性纖維腺瘤的「爆米花」樣鈣化是**明確良性**表現
- 滿足所有超聲良性標準的纖維腺瘤可歸為BI-RADS 3
- 任何可疑特徵都需活檢
- 複雜性纖維腺瘤增加乳腺癌風險
