# Breast Imaging - Page 630

![Page 630](/core_radiology/images/breast/page-630.png)

## 超聲腫塊BI-RADS詞典總結 / BI-RADS Ultrasound Mass Lexicon Summary

### 超聲腫塊描述系統 (Ultrasound Mass Description System)

#### 形狀 (Shape)

| 形狀 | 可疑程度 |
|------|----------|
| **橢圓形 (Oval)** | 低 |
| **圓形 (Round)** | 中等 |
| **不規則 (Irregular)** | **高** |

#### 方向 (Orientation)

| 方向 | 可疑程度 |
|------|----------|
| **平行 (Parallel)** | 低 |
| **非平行 (Not Parallel)** | **高** |

#### 邊緣 (Margins)

| 邊緣 | 可疑程度 |
|------|----------|
| **境界清楚 (Circumscribed)** | 低 |
| **邊界不清 (Indistinct)** | 中等 |
| **成角 (Angular)** | 中-高 |
| **微小分葉 (Microlobulated)** | 中-高 |
| **毛刺狀 (Spiculated)** | **非常高** |

#### 邊界 (Boundary)

| 邊界 | 說明 |
|------|------|
| **突變界面 (Abrupt Interface)** | 清晰分界 |
| **回聲暈 (Echogenic Halo)** | 過渡區 |

#### 內部回聲模式 (Internal Echo Pattern)

| 回聲 | 說明 |
|------|------|
| **無回聲 (Anechoic)** | 無內部回聲 |
| **低回聲 (Hypoechoic)** | 低-level回聲 |
| **等回聲 (Isoechoic)** | 與脂肪相同 |
| **高回聲 (Hyperechoic)** | 高於脂肪 |
| **複雜 (Complex)** | 混合回聲 |

#### 後方超聲特徵 (Posterior Acoustic Features)

| 特徵 | 說明 |
|------|------|
| **無 (None)** | 無後方改變 |
| **增強 (Enhancement)** | 後方回聲增強 |
| **聲影 (Shadowing)** | 後方聲束衰減 |
| **聯合 (Combined)** | 混合模式 |

#### 臨床要點 / Clinical Key Points
- **毛刺狀邊緣**和**非平行方向**是超聲最可疑的兩個徵象
- 良性腫塊需具備多個良性特徵
- 單一可疑特徵即需活檢
