# Breast Imaging - Page 623

![Page 623](/core_radiology/images/breast/page-623.png)

## 乳房攝影檢查技術與問題解決 / Mammographic Workup and Problem Solving

### 局部壓迫 (Spot Compression)

#### 臨床特點 (Clinical Features)
- 局部壓迫是對乳房局部區域進行壓迫，可獲得更好的分辨率
- 幾乎總是評估可疑乳房攝影異常的**下一步檢查**

#### 診斷要點 (Diagnostic Key Points)
| 應用 | 說明 |
|------|------|
| **鈣化評估** | 通常使用局部壓迫放大 |
| **腫塊或不對稱評估** | 通常不需要放大 |
| **結構扭曲** | 放大後可能變得不明顯 |

- 若不對稱在局部壓迫後「消失」，可認為是重疊的正常柔韌纖維腺體組織
- 若異常在壓迫後形狀無明顯變化，則為可疑，需進一步評估邊緣
- 較小的壓迫裝置可獲得更精確的壓迫，但可能丟失解剖標誌

---

### XCC（誇大CC體位）(Exaggerated CC Views)

| 體位 | 說明 |
|------|------|
| **XCCL（外側誇大CC）** | 將外側乳腺組織拉入探測器 |
| **XCCM（內側誇大CC）** | 將內側乳腺組織拉入探測器 |

---

### 滾動位（CC變體）(Rolled Views)

#### 臨床特點 (Clinical Features)
- 通過將乳房頂部和底部向相反方向移動獲得
- 有助於定位僅在CC位可見的病變

#### 診斷要點 (Diagnostic Key Points)
| 操作 | 意義 |
|------|------|
| RCCM（頂部滾向內側）病變向內移動 | 病變位於乳腺**上部** |
| RCCM病變向外移動 | 病變位於乳腺**下部** |

---

### 減壓成像 (Reduced Compression)

- 可用於成像後方深部病變（全壓迫時可能滑出探測器）

---

### 真側位（ML或LM）(True Lateral View)

#### 臨床特點 (Clinical Features)
- ML位：X線首先穿過內側乳房，探測器置於外側
- LM位：探測器置於內側

#### 診斷要點 (Diagnostic Key Points)
| 應用 | 說明 |
|------|------|
| **牛奶樣鈣化診斷** | 側位片上鈣質沉積於囊腫底部，呈新月形 |
| **病變三角測量** | 有助於定位僅在MLO位可見的病變 |
| **立體定向活檢計劃** | 有助於手術規劃 |

#### 臨床要點 / Clinical Key Points
- 真側位是確診**牛奶樣鈣化**的關鍵體位
- 病變在側位上的移動方向有助於定位（內側：上升；外側：下沉）
