# Breast Imaging - Page 596

![Page 596](/core_radiology/images/breast/page-596.png)

## 轉移性神經內分泌腫瘤顯像 / Metastatic Neuroendocrine Tumor Imaging

### 腎外嗜鉻細胞瘤 (Extra-adrenal Pheochromocytoma)

#### 臨床特點 (Clinical Features)
- I-123 MIBG 對腎外嗜鉻細胞瘤的敏感性：**63-100%**
- 敏感性降低的原因：
  - 腫瘤細胞去分化
  - 膜轉運蛋白改變
  - 藥物干擾

#### 診斷要點 (Diagnostic Key Points)
- **In-111 pentetreotide** 是另一選擇
- **F-18 FDG PET** 在轉移性腎外嗜鉻細胞瘤評估中的作用正在發展
- 大多數腫瘤為 **FDG avid**（FDG攝取陽性）

#### 臨床要點 / Clinical Key Points
- 敏感性範圍寬，需結合臨床和解剖影像
- FDG PET在檢測轉移灶方面有優勢

### 轉移性類癌/神經內分泌腫瘤 (Metastatic Carcinoid/Neuroendocrine Tumor)

#### 臨床特點 (Clinical Features)
- **In-111 pentetreotide (Octreoscan)** 是類癌腫瘤成像的首選製劑
- 幾乎總是執行 **SPECT** 顯像

#### 診斷要點 (Diagnostic Key Points)
| 參數 | 數值 |
|------|------|
| 敏感性 | **82-95%** |
| 特異性 | 約 **50%** |

- **假陽性原因**：
  - 生理性攝取附近的「熱點」（腦垂體、甲狀腺、肝臟、脾臟、泌尿系統、腸道）
  - 良性炎症過程：炎症、**Graves病**、結節病
  - 炎症假陽性的原因：活化淋巴細胞表達**奧曲肽受體 (Octreotide Receptors)**

#### 影像學表現 (Imaging Findings)
- CT顯示腸繫膜腫塊伴粗大鈣化（類癌特徵性表現）
- SPECT-CT融合：下腹部攝取增高灶與CT上的鈣化腸繫膜腫塊一致
- 其他攝取灶定位於腸道，代表生理性腸道攝取

#### 鑑別診斷 (Differential Diagnosis)
- 生理性腸道攝取
- 炎症性疾病（肉芽腫性疾病）
- 其他神經內分泌腫瘤（胃泌素瘤、胰島素瘤、血管活性腸肽瘤）

#### 臨床要點 / Clinical Key Points
- Octreoscan對神經內分泌腫瘤敏感性高，但特異性中等
- 假陽性常見於炎症性疾病
- 需結合CT和解剖影像進行融合判讀
- 類癌的腸繫膜鈣化性腫塊是特徵性表現
