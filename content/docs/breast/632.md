# Breast Imaging - Page 632

![Page 632](/core_radiology/images/breast/page-632.png)

## 含脂肪的境界清楚腫塊 / Fat-Containing Circumscribed Masses

### 含脂肪腫塊概覽 (Fat-Containing Circumscribed Masses Overview)
- 與純脂肪腫塊一樣，所有含脂肪的境界清楚腫塊均為**良性（BI-RADS 2）**

---

### 錯構瘤（纖維腺脂肪瘤）/ Hamartoma (Fibroadenolipoma)

#### 臨床特點 (Clinical Features)
- 錯構瘤又稱**纖維腺脂肪瘤**，是含有脂肪和腺體組織元素的良性腫塊
- 經典乳房攝影表現：**「乳房中的乳房」**，推移正常乳腺組織
- 典型有**假包膜**環繞

#### 診斷要點 (Diagnostic Key Points)

| 檢查 | 表現 |
|------|------|
| **乳房攝影** | 幾乎總是診斷性的；顯示含脂肪和腺體組織的腫塊 |
| **超聲** | 通常不需；可見正常纖維腺體組織和脂肪 |

#### 鑑別診斷 (Differential Diagnosis)
- 脂肪瘤
- 乳腺纖維腺瘤

#### 臨床要點 / Clinical Key Points
- 錯構瘤的「乳房中的乳房」表現是特徵性診斷
- 由於錯構瘤內含有腺體元素，乳腺癌**罕見**可能發生在其內部
- 任何可疑腫塊或鈣化都需進一步檢查

---

### 乳汁囊腫 / Galactocele

#### 臨床特點 (Clinical Features)
- 乳汁囊腫是**乳液的囊性積聚**
- 表現為**哺乳期婦女**可觸及的腫塊

#### 診斷要點 (Diagnostic Key Points)

| 檢查 | 表現 |
|------|------|
| **乳房攝影** | 境界清楚、分葉狀腫塊，含高密度和脂肪混合；經典發現是**脂肪/液體平面**（側位片） |
| **超聲** | 囊性腫塊樣；若穿刺，囊液為奶白色 |

#### 臨床要點 / Clinical Key Points
- 乳汁囊腫是哺乳期的常見良性病變
- **脂肪/液體平面**是特異性診斷標準
