# Breast Imaging - Page 638

![Page 638](/core_radiology/images/breast/page-638.png)

## 囊性乳腺病變 / Cystic Breast Lesions

### 囊腫概覽 (Cystic Lesions Overview)
- **不可能可靠地區分囊性與實性**（乳房攝影）
- 囊腫在局部壓迫下可變得不那麼緻密（因可壓縮性）

---

### 單純囊腫 (Simple Cyst)

#### 臨床特點 (Clinical Features)
- 單純囊腫是**良性充液結構**
- 形狀：圓形、橢圓形或輕度分葉狀
- 邊緣：境界清楚
- 內部回聲：**無回聲**

#### 診斷要點 (Diagnostic Key Points)

| 特徵 | 說明 |
|------|------|
| **後方超聲特徵** | 通過傳輸增加（後方增強） |
| **囊壁** | 薄得幾乎無法感知 |
| **BI-RADS分類** | 滿足所有標準者為**BI-RADS 2** |

#### 治療 (Treatment)
- 引起疼痛或不適的囊腫可**穿刺抽吸**

---

### 複雜囊腫 (Complicated Cyst)

#### 臨床特點 (Clinical Features)
- 複雜囊腫是含**低-level內部回聲**或**分層碎屑**的囊腫

#### 診斷要點 (Diagnostic Key Points)

| 抽吸液性質 | 意義 |
|------------|------|
| 白色、清亮或黃色 | 良性，丟棄 |
| 血性 | 送細胞學檢查 |

#### 臨床處理 (Management)
- 新發複雜囊腫通常歸為**BI-RADS 3**或**穿刺抽吸**
- 若複雜囊腫與內部回聲均勻的實性腫塊無法區分，通常行**核心活檢**

#### 臨床要點 / Clinical Key Points
- 複雜囊腫被認為是良性，但惡性風險不可忽略
- 穿刺液性質決定後續處理
