# 乳房影像 — Learning Radiology 整合 / Learning Radiology Integration

> **来源 / Source:** Learning Radiology (5th Ed.) — Chapter 29: Recognizing the Findings in Breast Imaging

---

## 乳房影像模態概覽 / Breast Imaging Modalities Overview

### 乳房攝影 / Mammography

**原理：** 低劑量 X 光成像，使用差異吸收原理區分脂肪、軟組織及鈣化。

**壓迫（Compression）作用：**
- 減少組織厚度
- 降低散射
- 減少輻射劑量
- 防止移動

**數位乳房斷層攝影 / Digital Breast Tomosynthesis (DBT):**
- 又稱 3D Mammography
- 多角度拍攝後重建薄層影像
- 降低假阳性、增加侵略性癌症偵測率

**標準視野：**
- **頭尾位（Craniocaudal, CC）**
- **內外斜位（Mediolateral Oblique, MLO）**

### 對比增强乳房攝影 / Contrast-Enhanced Mammography (CEM)
- 注射碘對比劑後進行雙能量乳房攝影
- 腫瘤因新生血管（angiogenesis）而增強

### 超音波 / Ultrasound (US)
- 初始檢查用於 < 30 歲有症狀者
- 分離囊腫與實心腫塊的關鍵工具
- 篩檢輔助（Dense breast）

### 磁振造影 / MRI
- 最敏感的乳房影像模態
- 需使用釓對比劑（Gadolinium）
- 適應症：高風險篩檢、植入物完整性評估、新輔助化療反應、對側乳房評估

## 乳房密度 / Breast Density

| 分類 | 內容 |
|------|------|
| a. 幾乎全為脂肪 | 最易發現病灶 |
| b. 分散性纖維腺體 | |
| c. 不均勻緻密 | 可能遮蔽病灶 |
| d. 極度緻密 | 最難發現病灶（密度越高 = 對比越差）|

## 乳房 X 光四大基本發現 / Four Basic Mammographic Findings

### 1. 腫塊 / Masses

**描述重點：**
| 特性 | 選項 |
|------|------|
| 形狀 | 橢圓形、圓形、不規則 |
| 邊緣 | 界線清楚（circumscribed）、被遮蔽（obscured）、微小分葉（microlobulated）、不清（indistinct）、**毛刺（spiculated）** |
| 密度 | 高密度、等密度、低密度、含脂肪 |

**惡性特徵：** 不規則、毛刺狀、高密度  
**良性特徵：** 橢圓形、界線清楚、低密度、**含脂肪 = 幾乎確定良性**

### 2. 不對稱 / Asymmetry
- 單側纖維腺體組織不對稱
- 分類：全域（global）、局灶（focal）、發育中（developing）
- 大多為良性，少數可能為癌症

### 3. 結構扭曲 / Architectural Distortion
- 乳腺正常結構改變而無明確腫塊
- 想像為**無腫瘤的毛刺（Spiculation without mass）**
- 乳腺組織被牵拉（retraction）
- DBT 特別擅長發現

### 4. 鈣化 / Calcifications

| 分類 | 型態 | 分佈 |
|------|------|------|
| **典型良性** | 皮膚、血管、粗大爆米花樣、大桿狀、圓形、環狀、營養不良性、奶鈣（milk of calcium） | 散在性或區域性 |
| **疑似惡性** | 無定型（amorphous）、粗異質性（coarse heterogeneous）、**細多形（fine pleomorphic）**、**細線狀（fine linear）**、**細線分枝狀（fine-linear branching）** | **叢集（grouped）**、**線性（linear）**、**節段性（segmental）** |

## 乳癌類型 / Types of Breast Cancer

### 非侵犯性 / Noninvasive

| 類型 | 特點 |
|------|------|
| **導管癌原位癌（DCIS）** | 限於基底膜內；經由導管蔓延；典型表現為鈣化；通常無可觸及腫塊 |

### 侵犯性 / Invasive

| 類型 | 特點 |
|------|------|
| **侵犯性導管癌（IDC）** | 最常見（70-80%）；可見不對稱、扭曲或腫塊；經淋巴結轉移 |
| **侵犯性小葉癌（ILC）** | 單一細胞排列；常不形成腫塊；影像學上最難發現 |
| **發炎性乳癌** | 少見（1-3%）；紅腫像乳腺炎；預後差 |
| **髓狀癌** | 與 BRCA 基因異常相關；預後較好 |
| **管狀癌** | 約 1-4%；典型為小毛刺狀腫塊；預後最佳 |

## 超音波應用 / Ultrasound Applications

### 良性囊腫超音波標準
- **無回音（Anechoic）**：內部無回音
- **後壁增強（Enhanced Through Transmission）**
- **薄後壁（Thin Back Wall）**

不符合以上標準者需考慮囊腫抽吸或進一步評估。

### 實心腫塊特徵
- 惡性：低回音、邊界不清、毛刺邊緣
- 良性：界線清楚（纖維腺瘤）

---

## MRI 應用 / MRI Applications

### 乳癌在 MRI 的典型表現
- **早期增強**（注射後 2 分鐘內）
- **快速沖洗（Wash-out）**：惡性特徵
- 形態學評估（與 mammography 相同原則）

---

## 影像導引切片 / Image-Guided Biopsy

| 方法 | 適用 |
|------|------|
| **超音波導引切片** | 現今大多數切片；主要用於超音波可見的病灶 |
| **立體定位切片（Stereotactic）** | 主要用於僅在 mammography 可見的鈣化 |
| **MRI 導引切片** | 僅 MRI 可見的病灶 |

**切片後：** 應放置標記夾（Clip）確認切片位置

---

## 手術前定位 / Needle Localization

### 適應症
- 不可觸及的病灶
- 需手術切除的病灶（DCIS、侵襲性癌、非典型導管增生等）

### 流程
1. 將定位針置於病灶附近
2. 鉤絲（Hookwire）引導外科醫師切除正確組織
3. 標本 X 光確認

## 特殊考量 / Special Considerations

### 懷孕期間乳房腫塊
- ≥ 30 歲：先做 mammography
- < 30 歲：先做超音波
- 需排除：囊腫、纖維腺瘤、**乳囊腫（Galactocele）**（含脂肪！）

### 乳頭分泌物
- 大多為良性
- 病理性分泌：自發性、單側、單一導管、血性或漿液性
- 乳頭狀瘤（Papilloma）為血性分泌物最常見原因
- 評估：mammography + 超音波 ± 乳管造影（Ductogram）

### 乳腺炎 / 乳房膿疡
- 最常見病原：*Staphylococcus aureus*
- 與發炎性乳癌臨床及 mammography 表現可相同
- 膿疡：超音波可見腫塊，需與侵襲性乳癌鑑別（膿疡有壓痛）

### 創傷 / Seatbelt Injury
- 特殊受傷模式：三點式安全帶
- 見於內側乳房沿安全帶路徑
- 脂肪壞死後典型表現：**油囊腫（Oil Cysts）**

### 緻密乳房 / Dense Breasts
- 約 50% 人口
- DBT、MRI、US 可輔助篩檢

### 術後乳房 / Postoperative Breast
- 減少整形（Reduction Mammoplasty）：術後變形、脂肪壞死
- 植入物：MRI 為評估植入物完整性的標準

---

## 植入物破裂 / Implant Rupture

| 類型 | 說明 |
|------|------|
| **囊內破裂（Intracapsular）** | 矽膠漏出但仍被纖維包膜包圍；MRI 可見「義大利麵徵（linguine sign）」|
| **囊外破裂（Extracapsular）** | 矽膠游離至乳腺組織；可見「雪暴徵象（snowstorm appearance）」；腋下淋巴結可能變密 |

---

## 臨床要點 / Clinical Key Points

- Mammography 仍是乳癌篩檢的基石
- **緻密乳房**增加偵測難度；DBT 可輔助
- 超音波是區分囊腫與實心病灶的關鍵工具
- MRI 最敏感，用於高風險篩檢、植入物評估、化療反應追蹤
- **四大 mammographic 發現**：腫塊、不對稱、結構扭曲、鈣化
- **Spiculated mass** 是侵襲性乳癌的典型表現
- 影像導引切片取代大多數開放切片
- 不可觸及病灶需手術前 Hookwire 定位
- 乳頭血性分泌物最常見原因：乳頭狀瘤
- 乳腺炎治療後未好轉需考慮發炎性乳癌
- 脂肪壞死油囊腫為創傷後常見
- MRI 是評估矽膠植入物完整性的標準
