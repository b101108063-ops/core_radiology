# Breast Imaging - Page 631

![Page 631](/core_radiology/images/breast/page-631.png)

## 乳腺腫塊：脂肪性病變 / Breast Masses: Fatty Lesions

### 脂肪性腫塊概覽 (Fatty Masses Overview)
- 所有脂肪密度的境界清楚腫塊均為**良性（BI-RADS 2）**

---

### 脂肪瘤 (Lipoma)

#### 臨床特點 (Clinical Features)
- 脂肪瘤是**成熟脂肪細胞**組成的良性病變
- 臨床可表現為可觸及的腫塊（正常乳腺被推開時）

#### 診斷要點 (Diagnostic Key Points)

| 檢查 | 表現 |
|------|------|
| **乳房攝影** | 幾乎完全透X線的境界清楚橢圓形腫塊，可有薄環；與油囊不同，脂肪瘤無周圍鈣化 |
| **超聲** | 與周圍脂肪回聲相同的境界清楚橢圓形腫塊 |

#### 臨床要點 / Clinical Key Points
- 脂肪瘤可完全由乳房攝影確診
- 透X線腫塊是脂肪瘤的診斷性特徵

---

### 油囊（脂肪壞死）/ Oil Cyst (Fat Necrosis)

#### 臨床特點 (Clinical Features)
- 油囊是**脂肪壞死**的一種可能後果
- 可發生於**創傷或手術後**
- 脂肪壞死有多種成像表現，最常見的是**營養不良性鈣化**

#### 診斷要點 (Diagnostic Key Points)

| 檢查 | 表現 |
|------|------|
| **乳房攝影** | 透X線腫塊伴細薄周圍鈣化（「蛋殼樣」） |
| **超聲** | 脂肪壞死超聲表現多變，不理想 |

#### 臨床要點 / Clinical Key Points
- 油囊是脂肪壞死後脂肪皂化的結果
- 典型表現：透X線腫塊伴周圍鈣化
- 脂肪壞死成像表現多樣，需與乳腺癌鑑別
