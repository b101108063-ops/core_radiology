## 毛刺狀腫塊 / Spiculated Masses

### 浸潤性導管癌 (Invasive Ductal Carcinoma, IDC)

#### 臨床特點 (Clinical Features)
- IDC是**最常見**的乳腺癌形式
- 典型乳房攝影表現：**高密度、毛刺狀腫塊**
- 常伴有**惡性型（多形性或細線性分支狀）鈣化**

#### 診斷要點 (Diagnostic Key Points)
| 表現 | 說明 |
|------|------|
| **圓形腫塊** | IDC可表現為 |
| **孤立性鈣化** | IDC可表現為 |
| **結構扭曲** | IDC可表現為 |
| **上述任意組合** | IDC可表現為 |

#### 臨床要點 / Clinical Key Points
- IDC成像表現多變
- 毛刺狀高密度腫塊是IDC的特徵性表現

---

### 浸潤性小葉癌 (Invasive Lobular Carcinoma)

#### 臨床特點 (Clinical Features)
- 占所有乳腺癌的約**10%**
- 乳房攝影**假陰性率**高達**21%**

#### 診斷要點 (Diagnostic Key Points)
| 特徵 | 說明 |
|------|------|
| **生長模式** | 浸潤性生長，圍繞腺體組織 |
| **乳房攝影敏感性** | 低（與周圍組織混合） |
| **微鈣化** | 罕見（與IDC不同） |
| **多灶性/雙側性** | 比IDC更常見 |

#### 臨床要點 / Clinical Key Points
- 浸潤性小葉癌的成像診斷具有挑戰性
- MRI對浸潤性小葉癌的分期優於乳房攝影

---

### 管狀癌 (Tubular Carcinoma)

#### 臨床特點 (Clinical Features)
- **生長緩慢**的癌症
- 典型表現為**小型毛刺狀腫塊**
- 成像表現可在多個既往乳房攝影上保持穩定

#### 診斷要點 (Diagnostic Key Points)
| 特徵 | 說明 |
|------|------|
| **穩定性** | 可在多年內保持穩定（不能因此排除惡性） |
| **預後** | 比IDC NOS好 |
| **可能的前驅病變** | 放射性疤痕 |

#### 臨床要點 / Clinical Key Points
- 儘管生長緩慢，毛刺狀表現必須充分評估
- 管狀癌預後優於IDC NOS
