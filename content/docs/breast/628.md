# Breast Imaging - Page 628

![Page 628](/core_radiology/images/breast/page-628.png)

## 超聲腫塊BI-RADS詞典 / BI-RADS Lexicon for Ultrasound Masses

### 大小和位置 (Size and Position)
- 腫塊應在**三個正交平面**上測量
- 位置標註：時鐘面位置 + 與乳頭的距離

---

### 形狀 (Shape)

| 形狀 | 說明 |
|------|------|
| **橢圓形 (Oval)** | 良性特徵 |
| **圓形 (Round)** | 中等可疑 |
| **不規則 (Irregular)** | 可疑 |

---

### 方向 (Orientation)

| 方向 | 說明 | 臨床意義 |
|------|------|----------|
| **平行 (Parallel)** | 長軸平行於皮膚 | 良性可能性大 |
| **非平行 (Not Parallel)** | 「高>寬」（寬:高<1） | **可疑惡性** |

---

### 邊緣 (Margins)

| 邊緣 | 說明 | 可疑程度 |
|------|------|----------|
| **境界清楚 (Circumscribed)** | 邊界清晰 | 良性 |
| **邊界不清 (Indistinct)** | 無明確邊界 | 中等 |
| **成角 (Angular)** | 邊緣銳角 | 可疑 |
| **微小分葉 (Microlobulated)** | 鋸齒狀邊緣 | 可疑 |
| **毛刺狀 (Spiculated)** | 線狀投影 | **高度可疑** |

---

### 內部回聲模式 (Internal Echo Pattern)

| 回聲類型 | 說明 |
|----------|------|
| **無回聲 (Anechoic)** | 無內部回聲 |
| **低回聲 (Hypoechoic)** | 低-level內部回聲 |
| **等回聲 (Isoechoic)** | 與脂肪回聲相同 |
| **高回聲 (Hyperechoic)** | 高於脂肪回聲 |
| **複雜回聲 (Complex)** | 混合回聲 |

---

### 病變邊界 (Lesion Boundary)

| 邊界類型 | 說明 |
|----------|------|
| **突變界面 (Abrupt Interface)** | 病變與周圍組織清晰分界 |
| **回聲暈 (Echogenic Halo)** | 回聲過渡區，可見於癌症或膿腫 |

#### 臨床要點 / Clinical Key Points
- 超聲BI-RADS詞典標準化了超聲報告
- 形狀、邊緣和方向共同決定惡性可能性
- **毛刺狀邊緣**是最特異的惡性徵象
- **非平行方向**是第二個最特異的惡性徵象
