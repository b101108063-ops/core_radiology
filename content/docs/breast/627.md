# Breast Imaging - Page 627

![Page 627](/core_radiology/images/breast/page-627.png)

## 乳房超聲：分區解剖（續）/ Breast Ultrasound: Zonal Anatomy (Continued)

### 腺體區 (Mammary Zone)

#### 臨床特點 (Clinical Features)
- 腺體區是大多數乳腺病理的發生部位
- 包含**導管、終末導管小葉單位（TDLU）、脂肪、纖維組織和Cooper韌帶**

---

### 乳腺後區 (Retromammary Zone)

#### 臨床特點 (Clinical Features)
- 乳腺後區位於胸大肌淺層
- 包含**脂肪和少量Cooper韌帶**

---

### 乳腺脂肪成像 (Imaging Fat in the Breast)

#### 臨床特點 (Clinical Features)
- 腺體實質脂肪在超聲上呈**低回聲**（與體內其他部位脂肪不同）
- 淋巴結門脂肪、**脂肪瘤**和**脂肪壞死**的脂肪可呈**高回聲**

#### 臨床要點 / Clinical Key Points
- 乳腺脂肪的低回聲特性是正常超聲表現
- 淋巴結門和脂肪瘤的脂肪可呈高回聲

---

### 超聲掃查技術 (Ultrasound Technique)

#### 掃查平面 (Scanning Planes)

| 平面 | 說明 |
|------|------|
| **徑向/反徑向 (Radial/Antiradial)** | 優選，導管解剖呈放射狀 |
| **橫斷/縱斷 (Transverse/Longitudinal)** | 與常規體部超聲相似 |

#### 標註 (Annotation)

| 標註項目 | 說明 |
|----------|------|
| **側別** | 左/右 |
| **時鐘位置** | 時鐘面位置 |
| **乳頭距離** | 與乳頭的距離 |
| **方向** | 徑向/反徑向或橫斷/縱斷 |

#### 臨床要點 / Clinical Key Points
- 完整標註是必需的
- 圖形標註結合乳頭距離記錄更佳
