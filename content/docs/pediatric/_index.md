### 正常解剖 / Normal Anatomy

#### 正常頸部側位像 / Normal Lateral Neck Radiograph

| 結構 / Structure | 說明 / Description |
|---|---|
| 鼻咽部軟組織 / Nasopharyngeal soft tissue | 腺樣體（adenoids）正常大小 |
| 喉部 / Larynx | 聲帶及會厭正常輪廓 |
| 氣道 / Airway | 連續通暢，無狹窄 |

#### 側位頸部X光可見病理部位 / Sites of Pathology on Lateral Neck Radiograph

| 病變 / Lesion | 影像學表現 / Imaging Finding |
|---|---|
| 腺樣體肥大 / Adenoidal hypertrophy | 鼻咽部軟組織增厚 |
| 咽後膿腫 / Retropharyngeal abscess | 椎前軟組織增厚 |
| 膜性會厭炎 / Membranous croup | 聲門下水腫 |
| 急性會厭炎 / Epiglottitis | 拇指徵（thumbprint sign） |
| 哮吼 / Croup | 狹窄徵（steeple sign） |

### 臨床要點 / Clinical Key Points

- **頸部側位X光是評估兒童氣道阻塞的第一線檢查 / Lateral neck radiograph is the first-line study for pediatric airway obstruction**
- 需與臨床病史相結合以確診 / Must be correlated with clinical history for diagnosis
- 鉴别诊断包括：感染性、肿瘤性、血管性病因 / Differential includes infectious, neoplastic, and vascular causes

## 後鼻孔閉鎖 / Choanal Atresia

### 疾病概述 / Disease Overview

**後鼻孔閉鎖**為後鼻腔先天性阻塞，可分為：

| 類型 / Type | 比例 / Percentage |
|---|---|
| 骨性 / Osseous | ~30% |
| 膜性 / Membranous | ~30% |
| 混合型 / Mixed | ~70% |

### 臨床特徵 / Clinical Features

- 幾乎皆伴有某種程度的骨性異常 / Almost always associated with some degree of osseous abnormality
- 常伴隨其他先天性畸形，最常見為**CHARGE 症候群**：
  - **C**oloboma（虹膜或視網膜缺損）
  - **H**eart defects（心臟缺陷）
  - **A**tresia of choanae（後鼻孔閉鎖）
  - **R**etardation of development（發育遲緩）
  - **G**enitourinary anomalies（泌尿生殖系統異常）
  - **E**ar anomalies（耳部畸形）

### 診斷要點 / Diagnostic Key Points

- **CT 軸位像**顯示軟組織完全阻塞雙側後鼻孔
- 骨性側壁增厚、內移
- 翼狀板內移

## 青少年鼻咽血管纖維瘤 / Juvenile Nasopharyngeal Angiofibroma (JNA)

### 疾病概述 / Disease Overview

**青少年鼻咽血管纖維瘤**為：
- 高度血管化的良性錯構瘤
- 僅見於青少年男性
- 好發於蝶齶孔（sphenopalatine foramen）

### 臨床特徵 / Clinical Features

- 腫瘤向鼻咽部及翼齶窩蔓延
- 沿路造成骨質重塑（bony remodeling）
- 主要鉴別診斷：**鼻部橫紋肌肉瘤**（造成骨質破壞）

---

## 鼻部橫紋肌肉瘤 / Nasal Rhabdomyosarcoma

### 疾病概述 / Disease Overview

**鼻部橫紋肌肉瘤**：
- 最常見的兒童軟組織肉瘤
- 頭頸部是常見原發部位
- 侵襲性強

### 診斷要點 / Diagnostic Key Points

- **CT 增強掃描**：破壞性腫瘤，明顯強化
- **MRI fat-suppressed T1**：評估顱內侵犯
- 骨質破壞位於上頜竇後壁、翼狀板

### 臨床要點 / Clinical Key Points

- 需與 JNA 鉴別：橫紋肌肉瘤有骨質破壞，JNA 為骨質重塑
- 可侵犯顳葉內側

## 急性會厭炎 / Epiglottitis

### 疾病概述 / Disease Overview

**急性會厭炎**為會厭的感染性炎症：
- 自從 **Haemophilus influenza** 疫苗普及後已極為罕見
- 真正的急症：氣道可在無預警下阻塞
- 現代病例多好發於免疫缺陷患者（HIV、器官移植受者）

### 臨床特徵 / Clinical Features

- 發熱、咽喉痛、吞嚥困難
- 喘鳴、流口水
- 依據臨床表現與影像學確診

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 側位頸部X光 / Lateral neck | **拇指徵（Thumbprint sign）**：會厭增厚 |
| 側位X光 / Lateral view | **杓狀會厭皺襞增厚** |

### 鉴别诊断 / Differential Diagnosis

- 哮吼（Croup）
- 細菌性氣管炎（Bacterial tracheitis）
- 異物吸入（Foreign body aspiration）

---

## 哮吼（喉氣管支氣管炎）/ Croup (Laryngotracheobronchitis)

### 疾病概述 / Disease Overview

**哮吼**為病毒感染（通常為副流感病毒）：
- 特徵性吸氣性喘鳴與犬吠樣咳嗽
- 好發於嬰兒與幼童
- 為臨床診斷
- 影像學目的：排除其他喘鳴病因

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 正位X光 / Frontal view | **狹窄徵（Steeple sign）**：亞聲門氣管正常肩狀輪廓消失 |
| 側位X光 / Lateral view | 咽下部「氣球樣」擴張 |

### 临床要点 / Clinical Key Points

- **Steeple sign（狹窄徵）**：對稱性亞聲門氣管狹窄
- 需與急性會厭炎鉴別（會厭炎無此徵象）

---

## 異物吸入 / Aspirated Foreign Body

### 疾病概述 / Disease Overview

- 放射性異物（Radiolucent foreign body）X光無法直接顯現
- 需靠**間接徵象**推斷診斷

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 胸部X光 / Chest radiograph | 空氣滯留（Air trapping）- 患側肺透明度增加 |
| 側位X光 / Lateral view | 深吸氣時患側肺容積不減少 |
| 臥位X光 / Decubitus film | 患側（受影響側）持續性膨脹 |

### 鉴别诊断 / Differential Diagnosis

- 哮喘（Asthma）
- 細支氣管炎（Bronchiolitis）
- 先天性大葉性肺氣腫（Congenital lobar emphysema）

---

## 咽後膿腫 / Retropharyngeal Abscess

### 疾病概述 / Disease Overview

**咽後膿腫**為咽後間隙的化膿性感染：
- 兒童非創傷性椎前軟組織腫脹的常見原因之一

### 臨床特徵 / Clinical Features

- 發熱、頸部疼痛、活動受限
- 張口困難
- 可能伴有呼吸道症狀

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 側位頸部X光 / Lateral neck | 椎前軟組織明顯增厚 |
| CT 掃描 / CT scan | 膿腫定位、評估是否可引流 |

### 鉴别诊断 / Differential Diagnosis

- 咽後蜂窩組織炎（Retropharyngeal cellulitis）
- 淋巴瘤（Lymphoma）
- 前腸囊腫（Foregut duplication cyst）

### 臨床要點 / Clinical Key Points

- 咽後假性增厚：頸椎屈曲時X光可見偽影
- 罕見含氣徵象（除非異物穿孔食道）
- **CT 為必需的確認檢查**

## 滲出性（細菌性）氣管炎 / Exudative (Bacterial) Tracheitis

### 疾病概述 / Disease Overview

**滲出性氣管炎**：
- 臨床表現類似急性會厭炎：發熱、喘鳴、呼吸窘迫
- 同樣危及生命
- 好發年齡：**較哮吼大的兒童**
- 病因：**細菌性**（最常見為金黃色葡萄球菌 S. aureus）

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 側位頸部X光 / Lateral neck | 亞聲門及頸部氣管內膜狀影 |
| CT 掃描 / CT scan | 氣管內膜增強、狹窄 |

### 鉴别诊断 / Differential Diagnosis

- 哮吼（Croup）- 病毒性、年齡較小
- 急性會厭炎（Epiglottitis）- 有拇指徵

## 亞聲門血管瘤 / Subglottic Hemangioma

### 疾病概述 / Disease Overview

**亞聲門血管瘤**：
- 良性血管腫瘤
- 造成嬰兒期喘鳴
- **最常見的兒科亞聲門氣管腫塊**

### 臨床特徵 / Clinical Features

- 常伴隨**皮膚血管瘤**（cutaneous hemangiomata）
- 症狀通常在嬰兒期出現

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 正位X光 / Frontal view | 亞聲門氣管**非對稱性**狹窄 |
| 側位X光 / Lateral view | 氣道輪廓改變 |
| CT/MRI | 軟組織腫塊強化 |

### 临床要点 / Clinical Key Points

- 需與對稱性狹窄的哮吼鉴別
- **非對稱性**為關鍵鑑別點

## 喉乳頭瘤病 / Laryngeal Papillomatosis

### 疾病概述 / Disease Overview

**喉乳頭瘤病**：
- HPV 感染引起的**多發性喉結節**
- 造成聲帶增厚、結節狀

### 臨床特徵 / Clinical Features

- 聲音嘶啞
- 呼吸困難
- **增加喉部鱗狀細胞癌風險**（類似HPV與宮頸癌的關聯）
- 乳頭瘤可罕見地播散至肺部，造成多發空洞結節

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 喉鏡 / Laryngoscopy | 多發性乳頭狀結節 |
| 胸部CT / Chest CT | 肺部空洞結節（如播散） |

## 氣管狹窄 / Tracheal Stenosis

### 疾病概述 / Disease Overview

| 類型 / Type | 病因 / Etiology |
|---|---|
| 醫源性 / Iatrogenic | 長期氣管插管 |
| 先天性 / Congenital | 常伴隨血管異常 |

### 臨床特徵 / Clinical Features

- 喘鳴
- 呼吸窘迫
- 喘鳴性質取決於狹窄程度

## 氣管支氣管軟化症 / Tracheobronchomalacia

### 疾病概述 / Disease Overview

**氣管支氣管軟化症**：
- 氣管支氣管軟骨軟弱，導致**呼氣時氣道過度塌陷**
- 可為先天性或後天性（插管、感染、慢性炎症）

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 吸氣相CT / Inspiratory CT | 可能正常 |
| 呼氣相CT / Expiratory CT | 氣道塌陷 >50% 為可疑 |
| 動態氣道透視 / Dynamic airway fluoroscopy | 呼氣時氣道塌陷 |

### 临床要点 / Clinical Key Points

- **氣道橫截面積減少 >50%** 提示氣管軟化症
- 正常人用力呼氣也可達到此閾值，需結合臨床

## 血管環與血管襟 / Vascular Rings and Sling

### 總論 / Overview

**血管環與血管襟**是嬰兒與兒童喘鳴的重要血管性病因：
- 首選評估：**鋇劑食道造影**，必要時行 CT 或 MRI
- **血管環（Vascular ring）**：主動脈弓或大血管完全圍繞氣管與食道
- **血管襟（Vascular sling）**：左肺動脈異常起源於右肺動脈，將氣管以三面「襟住」

### 臨床線索 / Clinical Clues

| 線索 / Finding | 提示 / Suggests |
|---|---|
| 正位胸片見**右側主動脈弓** | 潛在血管性喘鳴 |
| 左主動脈弓 + 喘鳴 | 僅 **肺动脉襟** 可致喘鳴 |

### 三種最重要的血管性喘鳴病因 / Top Three Vascular Causes of Stridor

| 疾病 / Entity | 特徵 / Features |
|---|---|
| **雙主動脈弓 / Double aortic arch** | 氣管與食道皆被圍繞 |
| **右主動脈弓 + 左鎖骨下動脈異常 / Right arch + aberrant left subclavian** | 右弓壓氣管前壁，左鎖骨下繞食道後壁 |
| **肺动脉襟 / Pulmonary artery sling** | 唯一在正常（左）主動脈弓下致喘鳴的血管異常 |

### 正常解剖 / Normal Anatomy

| 結構 / Structure | 位置 / Location |
|---|---|
| 氣管 / Trachea | 前方 |
| 食道 / Esophagus | 後方 |
| 主動脈弓 / Aortic arch | 左側，正常分支 |

**側位像（正常）**：食道與氣管輪廓光滑，無異常壓跡

## 雙主動脈弓 / Double Aortic Arch

### 疾病概述 / Disease Overview

**雙主動脈弓**：
- **最常見的血管環**
- 雙側弓圍繞氣管與食道，可造成喘鳴
- 右弓通常位於上方，口徑較左弓大

### 臨床特徵 / Clinical Features

- 喘鳴（氣管受壓）
- 吞嚥困難（食道受壓）
- 症狀嚴重程度取決於哪個弓較大

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 側位像 / Lateral view | 食道後方壓跡（右弓）+ 氣管前方的壓跡（左弓） |
| CT/MRI | 確認哪個弓為優勢弓（術前關鍵） |
| 食道造影 / Esophagram | 雙側氣管與食道皆有壓跡 |

### 治療 / Treatment

- **手術**：結紮非優勢弓
- 放射科醫師的目標：確認哪個弓為劣勢側

---

## 右主動脈弓合併左鎖骨下動脈異常 / Right Arch with Aberrant Left Subclavian Artery

### 疾病概述 / Disease Overview

**右主動脈弓合併左鎖骨下動脈異常**：
- 第二常見的血管環
- 右弓壓氣管前壁
- 左鎖骨下動脈繞食道後方
- **韌帶（ligamentum arteriosum）完成此環**

### 與左主動脈弓合併右鎖骨下动脉异常的鉴別 / Differentiation from Left Arch with Aberrant Right Subclavian

| 特徵 / Feature | 右弓 + 左鎖骨下 / Right arch + aberrant LSA | 左弓 + 右鎖骨下 / Left arch + aberrant RSA |
|---|---|---|
| 血管環 / Vascular ring | **是 / Yes** | **否 / No**（通常無症狀） |
| 喘鳴 / Stridor | 有 / Yes | 無 / No |
| dysphagia | 少見 / Rare | 少見（稱為 dysphagia lusoria） |

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 正位像 / Frontal view | 右弓使氣管向左偏移 |
| 側位像 / Lateral view | 氣管前壁凹陷 + 食道後壁凹陷 |
| CT/MRI | 確診，與雙主動脈弓难分辨 |

### 臨床要點 / Clinical Key Points

- 側位食道造影與雙主動脈弓**表现相同**，CT/MRI 為確診所必需

## 肺动脉襟 / Pulmonary Artery Sling

### 疾病概述 / Disease Overview

**肺动脉襟**：
- 左肺动脉異常起源於右肺动脉
- 走形於氣管與食道之間，形成「襟」
- 通常僅氣管被壓，有時支氣管中葉也可能受壓

### 臨床特徵 / Clinical Features

- 喘鳴（氣管受壓）
- **唯一在正常（左）主動脈弓下造成喘鳴的血管異常**
- 主動脈分支形態正常

### 相關異常 / Associated Anomalies

- 氣管軟化症（Tracheomalacia）
- **支氣管su异位**（Bronchus suis）：右肺上葉支氣管起源於氣管

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 側位食道造影 / Lateral esophagram | 氣管**後方**壓跡 + 食道**前方**壓跡 |
| CT/MRI | 確認異常肺动脉走形 |

### 关键点 / Key Point

- 異常左肺动脉走形於**氣管與食道之間**

## 左主動弮弓合併右鎖骨下动脉异常 / Left Aortic Arch with Aberrant Right Subclavian Artery

### 疾病概述 / Disease Overview

**左主動弮弓合併右鎖骨下动脉异常**：
- **不是血管環或血管襟**
- **不會造成喘鳴**
- 罕見引起症狀，若有則為**吞嚥困難（dysphagia lusoria）**

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 側位食道造影 / Lateral esophagram | 食道後方小壓跡 |
| CT/MRI | 確認右鎖骨下动脉走形於食道後方 |

## 無名动脉症候群 / Innominate Artery Syndrome

### 疾病概述 / Disease Overview

**無名动脉症候群**：
- 嬰兒期胸腺較大，正常無名动脉可壓迫前方氣管
- 可能造成無名动脉症候群

### 临床要点 / Clinical Key Points

- **不是血管環**
- 此病因是否具有臨床意義仍有爭議

### 臨床要點 / Clinical Key Points

## 新生兒短暫性呼吸急促 / Transient Tachypnea of the Newborn (TTN)

### 疾病概述 / Disease Overview

**新生兒短暫性呼吸急促（TTN）**：
- **新生兒呼吸窘迫最常見的原因**
- 病因：**胎兒肺液清除障礙**
- 正常情況下，前列腺素擴張肺淋巴管吸收多餘液體
- 液體持續存在時，TTN 可能發生

### 危險因子 / Risk Factors

| 危險因子 / Risk Factor | 說明 / Description |
|---|---|
| 剖宮產 / Cesarean delivery | 缺乏陰道分娩的「擠壓」 |
| 母親氣喘 / Maternal asthma | 前列腺素失衡 |
| 母親糖尿病 / Maternal diabetes | 肺液清除延遲 |
| 男性胎兒 / Male sex | 發病率較高 |

### 臨床特徵 / Clinical Features

- 呼吸急促
- 肋間凹陷
- 發紺
- X光表現可能與新生兒肺炎**难以鉴別**

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 胸部X光 / Chest radiograph | 肺水腫表現，常伴有**葉間裂積液** |
| | 肺紋理增粗、肺門模糊 |

### 鑑别診斷 / Differential Diagnosis

| 疾病 / Entity | 區別要點 / Key Differences |
|---|---|
| 新生兒肺炎 / Neonatal pneumonia | 臨床與X光均难分辨 |
| 呼吸窘迫症候群 / RDS | 多見於早產兒 |
| 胎便吸入 / Meconium aspiration | 有胎便接觸史 |

### 臨床要點 / Clinical Key Points

- **TTN 為自限性疾病**，通常在數小時至數天內自行緩解
- 臨床上常先給予抗生素治療（因與肺炎难分辨）
- 無需特殊治療

## 呼吸窘迫症候群 / Respiratory Distress Syndrome (RDS)

### 疾病概述 / Disease Overview

**呼吸窘迫症候群（RDS）**，亦稱**透明膜病（Hyaline Membrane Disease）**：
- **早產兒呼吸窘迫最常見的原因**
- 病因：**表面活性物質不足**（因 II 型肺泡細胞成熟度不足）
- 導致肺順應性降低

### 危險因子 / Risk Factors

| 危險因子 / Risk Factor | 說明 / Description |
|---|---|
| 早產 / Preterm birth | >95% 發生於 **34 週前出生** |
| 母親糖尿病 / Diabetic mother | 足月兒也可能發病 |

### 臨床特徵 / Clinical Features

- 出生後數小時內出現呼吸急促、發紺
- 肋間凹陷、哼鳴
- 需輔助通氣支持

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 胸部X光 / Chest radiograph | **瀰漫性模糊肺實質影** |
| | **空氣支氣管徵（Air bronchograms）** |
| | 肺容積減少（若未插管） |

### 鉴别诊断 / Differential Diagnosis

- 新生兒短暫性呼吸急促（TTN）
- 新生兒肺炎
- 胎便吸入

## 肺間質氣腫 / Pulmonary Interstitial Emphysema (PIE)

### 疾病概述 / Disease Overview

**肺間質氣腫（PIE）**：
- 常與 RDS 合併發生
- 病因：**氣壓創傷**（barotrauma）導致氣體進入肺間質
- 氣體沿淋巴路徑蔓延

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 胸部X光 / Chest radiograph | 肺过度充氣 + 多發小囊腫（氣泡） |
| 可併發 / Complications | 氣縱膈（pneumomediastinum）、氣胸（pneumothorax） |

### 臨床要點 / Clinical Key Points

- 高頻振盪通氣（HFOV）可減少 PIE 嚴重程度

## 支氣管肺發育不良 / Bronchopulmonary Dysplasia (BPD)

### 疾病概述 / Disease Overview

**支氣管肺發育不良（BPD）**，又稱**早產兒慢性肺疾病**：
- RDS（伴或不伴 PIE）持續數天至一週後，若仍有肺部疾病則稱為 BPD
- **臨床定義**：36 週糾正月齡或出生後 28 天仍需氧氣，且X光異常

### 臨床特徵 / Clinical Features

- 持續性氧氣需求
- 慢性呼吸衰竭
- **兒科最常見的慢性呼吸衰竭原因**

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 胸部X光 / Chest radiograph | **輕度過度充氣** + **粗糙間質影** |
| | 與 RDS 的肺容積減少不同 |

### RDS 與 BPD 比較 / RDS vs BPD Comparison

| 特徵 / Feature | RDS | BPD |
|---|---|---|
| 發生時間 / Timing | 出生後即發 | 出生後 >28 天或 36 週糾正月齡 |
| 肺容積 / Lung volume | 減少 / Decreased | 正常或輕度增加 |
| 影像表現 / Imaging | 模糊影 + 空氣支氣管徵 | 粗糙間質影 |

### 臨床要點 / Clinical Key Points

- **BPD = 兒科慢性呼吸衰竭最常見原因**

## 先天性大葉性肺氣腫 / Congenital Lobar Emphysema (CLE)

**先天性大葉性肺氣腫（CLE）**：

- 呼吸窘迫（程度取決於受影響範圍）
- 縱膈移位

| 檢查 / Study | 發現 / Finding |

## 支氣管閉鎖 / Bronchial Atresia

### 疾病概述 / Disease Overview

**支氣管閉鎖**：
- 支氣管分支**中斷**
- 遠端黏液瀦留 + 過度充氣
- 最常受影響部位：**左上葉**

### 臨床特徵 / Clinical Features

- 通常為**成人時意外發現**
- 病因可能與 CLE 相關

### 病理機制 / Pathophysiology

1. 支氣管阻塞
2. 遠端支氣管充滿黏液（無法清除）
3. 形成**管狀黏液囊腫（tubular mucocele）**
4. 遠端氣道通過側支通氣
5. 空氣滯留 → 局部過度充氣

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 胸部X光 / Chest radiograph | 局部肺部過度透光 + 空氣滯留 |
| CT 掃描 / CT scan | 阻塞段遠端的**黏液栓** |
| 超過透明 / Hyperlucent region | 地理形狀的透光增加區域 |

### 臨床要點 / Clinical Key Points

- **左上葉**是最常見發生部位
- 與 CLE 的區別：支氣管閉鎖有黏液栓/黏液囊腫

## 先天性肺部呼吸道畸形 / Congenital Pulmonary Airway Malformation (CPAM)

### 疾病概述 / Disease Overview

**先天性肺部呼吸道畸形（CPAM）**，舊稱**先天性囊性腺瘤樣畸形（CCAM）**：
- 終末細支氣管的**錯構瘤性增生**

### 臨床特徵 / Clinical Features

- 可造成**佔位效應**
- 易**感染**
- 通常建議**手術治療**

### 診斷要點 / Diagnostic Key Points

| 檢查 / Study | 發現 / Finding |
|---|---|
| 超聲 / Ultrasound | 產前可發現 |
| CT 掃描 / CT scan | 多囊性腫塊，可有大囊或小囊 |

### CPAM / CCAM 分型 / Classification (Stocker)

| 類型 / Type | 特徵 / Features | 備註 / Notes |
|---|---|---|
| **Type I** | 一或多個大囊腫（>2 cm） | 最常見形式 |
| **Type II** | 多發小囊腫 | 可伴發腎發育不全 |
| **Type III** | 無數微小囊腫（太小而X光上似實質） | 預後較差 |
| **Type IV** | 單一大囊腫 | 難以與囊性胸膜肺母細胞瘤區分 |

## 肺隔離症 / Pulmonary Sequestration

### 疾病概述 / Disease Overview

**肺隔離症**：

Neonatal bowel obstruction, occurring within the first 24–48 hours of life, is a completely
different entity from childhood or adult obstruction, with different workup and different
etiologies. Unlike in adults, CT plays no role in the workup of neonatal bowel obstruction.

Small left colon, also known as functional immaturity of the colon or meconium plug

name of “meconium plug syndrome.”

therefore important to consider Hirschsprung in a neonate with bowel obstruction
and colitis.

syndrome compared to duodenal atresia.

Neonatal cholestatic jaundice
Approach to pathologic neonatal jaundice

•

•

•

In contrast to the unconjugated hyperbilirubinemia of the benign and self-limited
physiologic jaundice of the newborn, conjugated hyperbilirubinemia is never normal
and is due to hepatic or biliary dysfunction.
There are innumerable causes of conjugated hyperbilirubinemia, including biliary
atresia, Alagille syndrome, bile acid synthetic defects, metabolic disease, alpha-1antitrypsin deficiency, and infectious etiologies.
The goal of imaging is to differentiate between biliary atresia (approximately 25%
of neonatal conjugated hyperbilirubinemia) and “neonatal hepatitis,” which is a
wastebasket diagnoses for all other causes combined. Tc-99m-HIDA hepatobiliary
scintigraphy is the test of choice to distinguish between these two entities.
Patients may be premedicated with 5 days of phenobarbital to stimulate hepatocyte activity prior
to hepatobiliary scintigraphy, although this varies by institution.
The HIDA agent is actively transported into the hepatocyte and excreted (not conjugated) into the bile.

•

Biliary atresia requires prompt repair to prevent irreversible liver damage. The
treatment of neonatal hepatitis is nonsurgical.

Biliary atresia

•

•

•

Biliary atresia is characterized by an obliterative cholangiopathy that affects the intraand extra-hepatic bile ducts, leading to obstructive (conjugated) jaundice. Biliary
atresia leads to progressive cirrhosis and death in early childhood if untreated.

Vesicoureteral reflux (VUR)

•

•

•
•

Vesicoureteral reflux (VUR) is abnormal retrograde reflux of urine from the bladder
into the ureter, which predisposes to acute pyelonephritis, renal scarring, and
irreversible loss of renal function. VUR can be primary (due to an abnormally short
intravesicular portion of the distal ureter) or secondary (due to distal obstruction, such
as from posterior urethral valves or neurogenic bladder).
The typical imaging evaluation of a child with a febrile UTI is controversial and may
involve renal ultrasound and voiding cystourethrogram (VCUG). Renal ultrasound
is not sensitive for the detection of reflux, although some institutions perform
ultrasound as a screening modality. Recent studies suggest that approximately 5% of
children with a UTI and a normal ultrasound have VUR.
Siblings of patients diagnosed with reflux are typically screened with ultrasound: Up to
45% may have reflux, the majority being asymptomatic.
The goal of any treatment of VUR is to prevent pyelonephritis and the resultant renal
scarring, which can lead to irreversible loss of renal function. The treatment can be
either medical (prophylactic antibiotics) or surgical, depending on the grade.
Grades I–III are initially treated medically (prophylactic antibiotics).
Higher grade reflux often is treated surgically.

•
•

Approximately 90% of grade I and II reflux will spontaneously regress after a few years.

Ureteropelvic junction (UPJ) obstruction

•

Ureteropelvic junction (UPJ) obstruction is the most common cause of unilateral
hydronephrosis in children. UPJ obstruction may be caused by an aberrant renal artery
compressing the ureter, aperistaltic segment of the ureter, or can be idiopathic.

Posterior urethral valves (bladder outlet obstruction)

•
•

•

Posterior urethral valves are the most common cause of congenital bladder outlet
obstruction, caused by an obstructing web in the posterior (prostatic) urethra.

dilation of the entire ureter rather than only the prostatic portion.

Prune belly syndrome

•
•
•

Prune belly syndrome is a congenital muscular disorder that affects the abdominal
wall musculature and the smooth muscles of the entire urinary collecting system.
Prune belly may be associated with cryptorchidism.
The muscular defect leads to dilation of the entire collecting system, including the bladder
and both ureters. In contrast to posterior urethral valves, the entire urethra is dilated.

Ureterocele (UVJ obstruction)

•
•

•

•

A ureterocele is focal dilation of the distal ureter within the bladder wall, where the
ureter infolds between the mucosal and muscular layers of the bladder wall.
An ectopic ureterocele is almost always associated with ectopic insertion of the upper
pole ureter in a duplicated system. A simple ureterocele is seen with an orthotopically
(normally) inserting ureter.

obstructed upper pole moiety in a duplex system. Ectopic ureteroceles are almost

Overview of imaging for child abuse

•

•

•

If there is clinical or radiographic concern for child abuse, a complete skeletal survey
using high-resolution bone technique (for children under 2 years of age) should be
performed, including frontal views of all long bones, rib views with obliques, skull,
pelvis, hands/feet, and entire spine. The images are reviewed by the radiologist while
the child is still in the department.
Bone scintigraphy is more sensitive for posterior rib fractures, but has higher radiation
dose than radiography, is insensitive for skull fractures, and cannot evaluate fracture
morphology for age.
The age of fractures is estimated by the presence of callus formation. In general, a
fracture is less than two weeks old if there is no callus, and at least one week old if
there is callus.
These estimates are rough guidelines. A younger child will form callus and heal more quickly.

Porencephaly, where there is replacement of cortex by a cystic structure.

asymptomatic individuals. Additionally, the clinical symptoms of Chiari I are
nonspecific and include headache and malaise, which may not always be attributable
to the inferior protrusion of the tonsils.

nerves. A plexiform subtype is more aggressive and consists of a network of fusiformshaped masses, with malignant degeneration reported in approximately 5%.

benignity.

related to increased flow.

# 兒童呼吸窘迫 / Childhood Respiratory Distress

呼吸窘迫是新生兒最常見的臨床表現之一。診斷線索包括：胎齡、症狀嚴重程度與進展速度、以及胸部 X 光表現。

---

## 新生兒呼吸窘迫 / Newborn Respiratory Distress

### 短暫性新生兒呼吸急促（TTN）/ Transient Tachypnea of the Newborn

**病因：** 常見於剖腹產或急產的嬰兒，因胎兒肺液吸收延遲所致。

**臨床特徵：** 出生後立即出現呼吸急促（tachypnea）及輕度呼吸窘迫，通常不需要插管。給予非侵入性氧氣補充及支持性治療後，症狀通常在數小時內改善，48 小時內完全康復。

**影像學要點：**
- 肺部常呈过度充气（hyperinflated）
- 可見紋理狀、肺門旁線性密度（streaky, perihilar linear densities）
- 葉間裂隙積液（fluid in the fissures）
- 層狀肋膜積液（laminar pleural effusions）

---

### 新生兒呼吸窘迫症候群（NRDS）/ Neonatal Respiratory Distress Syndrome

又稱：透明膜病（Hyaline Membrane Disease）、表面活性物質不足症（Surfactant Deficiency Disorder）

**病因：** 好發於早產兒（胎齡 < 34 週）。主要由於表面活性物質（surfactant）不足，導致肺泡容易塌陷，造成廣泛性肺泡擴張不全。

**臨床特徵：** 早產嬰兒出生後出現嚴重呼吸窘迫，症狀逐漸惡化。包括：發紺（cyanosis）、呻吟聲（grunting）、鼻翼張開（nasal flaring）、肋間及肋下凹陷（intercostal and subcostal retractions）、以及呼吸急促。

**影像學要點：**
- 雙側對稱性瀰漫性毛玻璃狀（ground-glass）或細顆粒狀外觀（finely granular appearance）
- 空氣支氣管徵（Air bronchograms）常見且範圍廣泛，延伸至肺週邊
- 非機械通氣患者：肺部常見充氣不足（hypoaeration）
- 非插管患者若發現肺部過度充氣（hyperinflation），可排除 NRDS

**治療：** 正壓人工呼吸（positive-pressure ventilation）及必要時給予氣管內表面活性物質。

---

### 胎便吸入症候群（MAS）/ Meconium Aspiration Syndrome

**病因：** 常見於過期產兒（postmature infants）。約 15-20% 的懷孕中可見胎便（meconium）。胎便物質造成支氣管阻塞、空氣滯留、以及化學性肺炎。

**臨床特徵：** 幾乎在出生後立即出現嚴重呼吸窘迫。與 NRDS 不同（通常延遲數小時至數天才發病）。可見呼吸急促、缺氧（hypoxia）、以及高碳酸血症（hypercapnia）。

**影像學要點：**
- 肺部過度充氣（hyperinflated）
- 瀰漫性繩索狀密度（ropey densities）
- 局部性肺擴張不全（atelectasis）與空氣滯留性肺氣腫混合存在
- 25% 病例可見自發性氣胸（pneumothorax）及縱隔氣腫（pneumomediastinum）
- 可能併發肺炎（通常無空氣支氣管徵）
- 20% 病例可見少量肋膜積液

**治療：** 支持性治療，包括：抗生素、氧氣、吸入性一氧化氮（NO），必要時使用葉克膜（ECMO）。

---

### 嬰兒慢性肺疾病（CLD）/ Chronic Lung Disease of Infancy

又稱：支氣管肺發育不良（Bronchopulmonary Dysplasia, BPD）

**病因：** 為早期急性肺疾病（常見 NRDS）的後遺症。也可見於胎便吸入症候群及新生兒肺炎後。

**臨床特徵：** 嬰兒依賴氧氣、伴有高碳酸血症及代償性代謝性鹼中毒。可發展成肺動脈高壓及右心衰竭。

**影像學要點：**
- 早期可能難以與 NRDS 晚期區分
- 肺部整體呈過度充氣（hyperaerated）
- 粗大、不規則、繩索狀線性密度（代表肺擴張不全或後期纖維化）
- 局部透亮的囊狀區域（代表空氣滯留性過度擴張）
- 兩者混合使肺部呈海綿狀外觀（sponge-like appearance）

---

### 治療併發症：氣壓傷 / Barotrauma

新生兒呼吸窘迫的治療併發症主要來自正壓通氣，包括：

| 併發症 | 說明 |
|--------|------|
| **肺間質氣腫（Pulmonary Interstitial Emphysema）** | 肺泡破裂，空氣沿支氣管血管鞘逆向擴散，形成肺間質多發小氣囊 |
| **氣胸（Pneumothorax）** | 肺泡破裂，空氣進入肋膜腔 |
| **縱隔氣腫（Pneumomediastinum）** | 空氣沿支氣管血管束擴散至縱隔 |
| **心包膜積氣（Pneumopericardium）** | 罕見，縱隔與心包膜間有交通支，空氣僅見於心臟週圍，不超過大血管根部 |

> ⚠️ **臨床要點：** 上述任何一種情况（TTN、NRDS、MAS、CLD）若病童突然惡化，應高度懷疑氣壓傷。

---

## 兒童肺部疾病 / Childhood Lung Disease

### 反應性氣道疾病 / 細支氣管炎（Reactive Airways Disease / Bronchiolitis）

**定義：** 涵蓋一群以喘鳴（wheezing）、呼吸困難、咳嗽為特徵的兒童疾病。初始發作常稱為「細支氣管炎」。與慢性氣喘不同，通常為暫時性，但可能隨時間演變為氣喘。

**臨床特徵：** 呼吸急促、肋骨凹陷、咳嗽、發燒、流鼻涕。

**影像學要點：**
- 支氣管壁增厚（peribronchial thickening）：常見於肺葉或分段支氣管，X 光可見支氣管壁陰影
- 支氣管軸向觀察呈小甜甜圈狀密度（doughnut-like densities）
- 肺部過度充氣
- 黏液栓塞導致局部肺擴張不全

**治療：** 氣管擴張劑、類固醇、氧氣。

---

### 氣喘（Asthma）

**特點：** 氣喘是臨床診斷，非放射學診斷。胸部 X 光有助於找出病因或併發症。

**誘發事件：** 肺炎（常伴隨發燒）；**併發症：** 黏液栓塞導致肺擴張不全、氣胸、縱隔氣腫。

**影像學要點：** 急性發作期間或之後，肺部過度充氣，橫膈變平。可見如反應性氣道疾病的支氣管壁增厚。

---

### 肺炎（Pneumonia）

**年齡因素：** 年齡是兒童肺炎病因及臨床表現的重要決定因素。

| 年齡組 | 常見致病菌 |
|--------|-----------|
| **新生兒** | B 群 β 溶血性鏈球菌（Group B Streptococcus） |
| **較大嬰兒** | 呼吸道病毒（RSV、副流感病毒、流感病毒、腺病毒） |
| **5 歲以上** | 黴漿菌肺炎（Mycoplasma pneumoniae） |

**臨床特徵：**
- 新生兒：可能僅表現發燒
- 較大嬰兒及兒童：細菌性肺炎常有發燒、寒顫、呼吸急促、咳嗽、胸膜性胸痛、呼吸困難
- 病毒性肺炎：較常見咳嗽、喘鳴、哮吼（stridor），發燒較不顯著

**影像學要點：**
- **細菌性肺炎：** 常見大葉性實質化（lobar consolidation）或圓形肺炎（round pneumonia），10-30% 病例伴肋膜積液
- **病毒性肺炎：** 常見間質性浸潤或斑片狀實質化（支氣管肺炎 pattern）

---

## 臨床要點 / Clinical Key Points

- **新生兒呼吸窘迫**的四大病因：TTN、NRDS、MAS、CLD，各自的 X 光特徵不同，應牢記辨別要點
- **TTN**：肺部過度充氣＋肺門旁線性密度＋葉間裂隙積液 → 48 小時內康復
- **NRDS**：早產兒、雙側對稱毛玻璃顆粒狀＋空氣支氣管徵 → 表面活性物質治療
- **MAS**：過期產兒＋繩索狀密度＋氣胸（25%）→ 支持性治療
- **CLD**：早產兒氧氣依賴＋海綿狀肺部 → 長期追蹤
- **兒童肺炎**：年齡決定病因；細菌性＝大葉性實質化；病毒性＝間質性浸潤
- 任何新生兒呼吸窘迫**突然惡化**，應想到**氣壓傷**併發症

# 辨識兒科疾病 / Recognizing Pediatric Diseases

---

## 頸部軟組織 / Soft Tissues of the Neck

### 扁桃腺與腺樣增殖體肥大 / Enlarged Tonsils and Adenoids

**正常發育：** 新生兒期腺樣增殖體（adenoids）在 X 光上不可見，通常 3-6 個月後才可見。腺樣增殖體於約 6 歲時最大，之後逐漸退化。成人正常狀態下無可見腺樣增殖體。

**臨床特徵：** 鼻塞、口呼吸、反覆或慢性鼻竇炎或中耳炎（因其與耳咽管相近）、吞嚥疼痛、睡眠呼吸中止。

**影像學要點（腺樣增殖體肥大）：**
- 頸部側位 X 光為主要影像檢查；拍攝時頸部應處於伸展狀態
- 腺樣增殖體大小測量並不絕對可靠，臨床上是否造成**鼻咽氣道狹窄或阻塞**才是重點
- 扁桃腺（palatine tonsils）與腺樣增殖體常同時肥大

---

### 急性會厭炎 / Acute Bacterial Epiglottitis

**病因：** 急性細菌性會厭炎可危及生命，導致氣道阻塞。過去最常見致病菌為 **B 型流感嗜血桿菌（Haemophilus influenzae type B）**，自 1985 年疫苗引進後已大幅減少。其他致病菌包括：肺炎鏈球菌、A 群鏈球菌、皰疹病毒、副流感病毒。

**好發年齡：** 3-6 歲。

**臨床特徵：** 與哮吼（croup）相似，須高度警覺。以下情況應懷疑會厭炎：
- 兒童必須坐著才能呼吸
- 看似「哮吼」卻持續惡化
- 無法吞嚥而流口水

經典三聯徵：**流口水（drooling）、嚴重吞嚥困難、伴隨吸氣性喘鳴（inspiratory stridor）的呼吸窘迫**。

> ⚠️ **緊急處置：** 須有熟悉插管的醫師陪同病童。影像檢查並非總是必要，且早期可能呈偽陰性。

**影像學要點（會厭炎）：**
- **會厭增大**：正常會厭不應呈拇指狀（"larger than your thumb"）
- **杓狀會厭皺襞（aryepiglottic folds）增厚**——這是氣道阻塞及喘鳴的真正原因
- 有時可見吸氣時聲門下氣管環形狹窄

---

### 哮吼（喉氣管支氣管炎）/ Croup (Laryngotracheobronchitis)

**病因：** 通常為病毒性，最常見：副流感病毒（類型 1、2、3）、呼吸道融合病毒（RSV）、流感病毒、黴漿菌。好發年齡：6 個月至 3 歲（比會厭炎年幼）。

**臨床特徵：** 典型症狀：似犬吠之深沉咳嗽（barking/brassy cough）、聲音沙啞、吸氣性喘鳴、低燒、呼吸窘迫。

**影像學要點（哮吼）：**
頸部側位軟組織 X 光三個關鍵發現：
1. 下咽部（hypopharynx）擴張
2. 喉室（laryngeal ventricle）擴張
3. 聲門下氣管（subglottic trachea）模糊及狹窄

> 前位 X 光上的「尖塔徵（Steeple sign）」單獨使用並不可靠。

---

## 異物吞入 / Ingested Foreign Bodies

**好發年齡：** 6 個月至 6 歲。超過 80% 會自行排出。

**常見異物：** 硬幣、玩具、雞骨頭（不透 X 光）、魚刺（可透 X 光）。

**滯留位置：** 食道三個天然狹窄處：
- C5-C6 梨狀窩下方（70%，最常見）
- 胸腔入口處
- 主動脈弓處（20%）
- 食道胃交界處（10%）

**特殊危險異物：**
- **硬幣電池（Button batteries）**：須緊急移除，可造成穿孔
- **多枚小磁鐵**：可將腸道不同段吸附在一起造成穿孔，無移動時應考慮手術干預

**臨床特徵：** 吞嚥困難（dysphagia）、吞嚥疼痛（odynophagia）。異物通過後仍可能抱怨頸部疼痛（因異物通過食道時的刺激）。

**影像學要點（食道滯留異物）：**
- 先拍攝頸部及胸部 X 光，必要时加拍腹部
- **食道內硬幣**：前位觀呈圓形、側位觀呈扁平狀（因食道前後徑窄）
- **氣管內硬幣**：前位觀可能呈側面觀（圓形），側位觀呈圓形（因氣道前後徑寬）
- 若高度懷疑不透光異物，考慮口服對比劑或電腦斷層檢查

> ⚠️ 吞入異物的兒童可能同時有嗜異癖（pica），如吃油漆。若 X 光發現長骨骨骺端緻密線，應想到**鉛中毒**。

## 嬰兒心臟肥大辨識 / Recognizing Cardiomegaly in Infants

**新生兒心臟特點：** 嬰兒心臟相對於胸腔大小，本就比成人顯得更大。成人心臟橫徑比 > 50% 為異常，嬰兒可達 **65%** 仍屬正常（因嬰兒無法像成人一樣深吸氣）。

**胸腺（Thymus）干擾：** 嬰兒胸腺可能與心臟重疊，類似心臟擴大。正常胸腺邊緣略呈分葉狀（受肋骨壓迫），且週邊密度較低，可資鑑別。

## Salter-Harris 骨折生長板骨折 / Salter-Harris Fractures — Growth Plate Fractures

**定義：** 生長板（epiphyseal plate/physis）的肥大層（hypertrophic zone）是承受剪切力最脆弱的部位。生長板骨折佔兒童所有骨折的 **30%**，且僅能發生於骨骼未成熟個體。

### Salter-Harris 分型

| 分型 | 骨折內容 | 預後 |
|------|---------|------|
| **Type I** | 僅生長板骨折 | 預後良好 |
| **Type II** | 生長板＋骨幹（metaphysis）骨折 | 最常見（75%），預後良好 |
| **Type III** | 生長板＋骨骺（epiphysis）骨折 | 關節內骨折，預後較差 |
| **Type IV** | 生長板＋骨骺＋骨幹骨折 | 預後差，易早期生長板融合 |
| **Type V** | 生長板擠壓傷（crush injury） | 預後最差，診斷困難 |

### 各型特點

- **Type I**：僅生長板分離，診斷困難（需對側比較）。好發於：指骨、遠端橈骨。**股骨頭骨骺滑脫症（SCFE）** 屬此型。
- **Type II**：最常見（75%），尤其遠端橈骨。預後通常良好。
- **Type III**：關節內骨折，骨折線穿過骨骺進入關節面，長期可能導致退化性關節炎或生長板不對稱融合。
- **Type IV**：骨折線穿越生長板、骨骺與骨幹，預後差，易造成肢體長度差異或角度畸形。
- **Type V**：罕見的擠壓型損傷，幾乎必然導致生長障礙。最常見於：遠端股骨、近端脛骨、遠端脛骨。

> ⚠️ **SCFE（股骨頭骨骺滑脫症）**：好發於較高或較重的**學齡前至青少年男孩**。股骨頭骨骺向內、下、後滑脫。25% 為雙側，15% 可能發生股骨頭缺血性壞死。

---

## 兒童虐待 / Child Abuse

兒童虐待的放射學評估是確診的關鍵。

### 疑似虐待的骨折特徵

| 骨折部位/特徵 | 臨床意義 |
|---------------|---------|
| **遠端股骨、遠端肱骨、腕關節、踝關節的骨幹端角落骨折（Metaphyseal corner fractures）** | 高度疑似虐待，又稱「桶柄狀骨折（bucket-handle fracture）」 |
| **多處骨折不同癒合階段** | 暗示反覆創傷 |
| **嬰兒的螺旋形骨折**（股骨、肱骨、脛骨）| 需高度懷疑虐待 |
| **後側肋骨骨折** | 意外創傷少見，高度疑似虐待 |
| **多發顱骨骨折**（尤其凹陷性、粉碎性、雙側性、跨顱縫）| 高度疑似虐待 |
| **大量骨痂形成但未接受固定** | 暗示反覆創傷未就醫 |
| **掌骨、蹠骨骨折** | 5 歲以下少見意外 |
| **胸骨、肩胛骨骨折** | 5 歲以下少見意外 |
| **椎體骨折及脫位** | 少見意外 |

> ⚠️ **2 歲以下兒童頭部外傷**是虐待致死最常見原因。

## 壞死性腸炎（NEC）/ Necrotizing Enterocolitis (NEC)

**定義：** 新生兒最常見的胃腸道急症（內科及外科）。病因不明，可能與缺血再灌注損傷、腸道蠕動發育不良有關。

**好發族群：** 早產兒；也可見於經歷嚴重應激（敗血症、大手術）的足月兒。

**臨床特徵：** 餵食不耐受、胃排空延遲、腹脹、腹部壓痛、腸音減弱。

**影像學要點（NEC）：**
- 腹部 X 光仍是確診主要工具；急性好發於**終端迴腸**
- **早期**：少許腸道擴張；固定不變的擴張腸氣為非特異性早期表現
- **腸壁增厚**：腸壁間距增加
- **腸壁積氣（Pneumatosis intestinalis）**：確典型表現！腸壁內線狀透亮影，代表黏膜下或漿膜下空氣
- **門靜脈積氣（Portal venous gas）**：肝週邊樹枝狀管狀透亮影
- **游離空氣（Free air）**：預後不良，通常需緊急手術

> ⚠️ 存活的 NEC 病童中，**50%** 會產生長期併發症，最常見：**腸道狹窄（stricture）**及**短腸症候群（short-gut syndrome）**。

---

## 食道閉鎖合併/不合并氣管食道瘻管（TEF）/ Esophageal Atresia with/without TEF

**最常見類型：** 食道閉鎖（盲端）＋氣管與遠端食道間有瘻管連接。

**相關畸形（25% 病例）：**
- VACTERL 症候群：脊椎（Vertebral）、肛門（Anal）、心臟（Cardiac）、氣管食道瘻管/食道閉鎖（TE fistula/Esophageal atresia）、腎臟（Renal）、肢體（Limb）異常
- 約 25% 有 13 對以上肋骨或 6 節以上腰椎
- 常見：肛門閉鎖、十二指腸閉鎖、21 三體症

**臨床特徵：** 出生後早期：嗆到、流口水、分泌物處理困難、嘔吐、吸入、以及呼吸窘迫。

**影像學要點：**
- **單純食道閉鎖（無瘻管）**：腹部無氣體（氣體無法進入腸道）
- **食道閉鎖＋遠端瘻管**（最常見類型）：腸道有氣體（氣體經由瘻管從氣管進入）；X 光可見上段食道盲端擴張；口中軟導管會捲曲於盲端內
- 吸入性肺炎常見，且常位於**右肺上葉**

**治療：** 嬰兒數月大時進行近遠端食道對端吻合。必要時可使用結腸轉位術。

## 臨床要點 / Clinical Key Points

- **頸部軟組織**：腺樣增殖體側位 X 光看鼻咽氣道狹窄；會鼻咽氣道狹窄；會厭炎＝拇指狀會厭＋杓狀會厭皺襞增厚；哮吼＝下咽擴張＋喉室擴張＋聲門下狹窄
- **異物**：硬幣電池須緊急移除；食道硬幣前位圓側位扁；別忘了檢查長骨骺端排除鉛中毒
- **Salter-Harris**：I、II 型預後好；III、IV、V 型易併發生長板早期融合導致畸形
- **SCFE**：青少年男孩＋髖關節疼痛＋股骨頭向內下後滑脫
- **兒童虐待**：干骺端角落骨折、後側肋骨骨折、多處不同癒合階段骨折＝高度警示
- **NEC**：腸壁積氣（pneumatosis intestinalis）是確典型 X 光表現
- **TEF**：腹部無氣體＝單純食道閉鎖；有腸氣＝有遠端瘻管；約半數有 VACTERL 症候群其他異常
