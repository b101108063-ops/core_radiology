# Pediatric Imaging - PDF Page 767

## 支氣管擴張症 / Bronchiectasis

### 疾病概述 / Disease Overview

**支氣管擴張症**為支氣管擴張，多由炎症引起：

| 病因 / Etiology | 說明 / Description |
|---|---|
| 囊性纖維化 / Cystic fibrosis | 兒童最常見原因之一 |
| 變應性支氣管肺麴菌病 / ABPA | 對麴菌的過敏反應 |
| 感染後 / Post-infectious | 嚴重肺炎後 |
| 氣管支氣管巨大症 / Mounier-Kuhn | 彈性組織缺陷 |
| 吸入 / Aspiration | 異物或胃酸 |
| 葉內型肺隔離症 / Intralobar sequestration | 反覆感染後 |

### 診斷要點 / Diagnostic Key Points

| 徵象 / Sign | 說明 / Description |
|---|---|
| **印章環徵（Signet-ring sign）** | 細支氣管擴大，大於相鄰肺血管分支 |

## 單側肺部過度透光 / Unilateral Hyperlucent Lung

### 鑑别診斷流程 / Differential Diagnosis Approach

```
單側肺部過度透光
    │
    ├── 急性呼吸急促？
    │       │
    │       ├── 臥位片上患側肺持續擴張 → 異物吸入
    │       │
    │       └── 可見胸膜線 → 氣胸
    │
    ├── 有閉塞性細支氣管炎病史？→ Swyer-James-MacLeod
    │
    ├── 主要影響上、中葉？→ 先天性大葉性肺氣腫（CLE）
    │
    ├── 反覆感染史？→ CPAM（大囊型）
    │
    └── 體檢或側位X光見胸壁異常？+ 手/手臂異常史？
            │
            └── Poland 症候群
```

## Poland 症候群 / Poland Syndrome

### 疾病概述 / Disease Overview

**Poland 症候群**：
- **自體隱性遺傳**症候群
- 單側胸大肌先天性缺失（完全或部分）
- 同側手臂與手可能伴隨異常：
  - 短掌骨（Short metacarpals）
  - 併指畸形（Syndactyly）

### 臨床特徵 / Clinical Features

- 胸壁輪廓異常
- 可能影響美觀與功能

### 臨床要點 / Clinical Key Points

| 病因 / Etiology | 單側肺部過度透光 |
|---|---|
| 急性 / Acute | 異物吸入、氣胸 |
| 慢性 / Chronic | CLE、Swyer-James-MacLeod、CPAM、Poland 症候群 |
