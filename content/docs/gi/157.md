## Text Content

### 憩室炎 / Diverticulitis

**憩室炎**是結腸憩室的微穿孔和急性發炎。

| 要點 | 說明 |
|------|------|
| 影像學首選 | CT（診斷、分流、評估嚴重程度和併發症） |
| 好發位置 | 左結腸比右結腸常見得多 |
| 與大腸癌鑑別 | 急性憩室炎與微穿孔性大腸癌有時難以區分 |

> 建議在急性發作緩解後進行結腸鏡隨訪（但建議存在爭議）。

---

#### 無併發症憩室炎

| 特點 | 說明 |
|------|------|
| 定義 | 無腸道穿孔的影像學證據 |
| CT 所見 | 腸壁增厚、結腸周圍脂肪條紋，通常圍繞著一個罪魁憩室 |

---

#### 有併發症憩室炎

| 併發症 | 說明 |
|---------|------|
| 結腸周圍/肝膿疡 | 可經皮穿刺引流 |
| 腸道瘻管 | 結腸膀胱瘻最常見（膀胱內氣體提示） |
| 腸腔外氣體 | — |
| 腸阻塞 | — |
| 腸繫膜靜脈血栓 | — |

**手術適應症：** 瘻管存在或復發性憩室炎（保守治療兩次後）。

---

### 網膜附件炎 / Epiploic Appendagitis

**網膜附件炎**是由於正常脂肪垂（appendage）扭轉引起的良性臨床模擬闌尾炎/憩室炎。

| 特點 | 說明 |
|------|------|
| 影像學特徵 | **特異性表現**：卵圓形脂肪衰減病變，緊鄰正常結腸壁，伴輕度周圍脂肪條紋；橫斷面上中央高密度點代表血栓性中央靜脈 |
| 治療 | 消炎藥（**非**抗生素或手術） |

---

### 臨床要點 / Clinical Key Points
> - **憩室炎**：左結腸比右結腸常見；與大腸癌難以區分；建議急性發作緩解後結腸鏡隨訪
> - **網膜附件炎**：特異性 CT 表現（卵圓形脂肪衰減病變緊鄰結腸壁 + 中央高密度點）；消炎藥治療
> - 有併發症憩室炎（膿疡、瘻管等）：膿疡可穿刺引流；瘻管或復發性憩室炎需手術
