# Gastrointestinal Imaging - Page 135

![Page 135](/core_radiology/images/gi/page-135.png)

## Text Content

### 良性食道腫塊 / Benign Esophageal Masses

#### 間質腫瘤 / Mesenchymal Tumor

**良性間質腫瘤**是最常見的黏膜下腫瘤，包括胃腸道基質瘤（GIST）、平滑肌瘤、脂肪瘤、血管瘤等。

| 特點 | 說明 |
|------|------|
| 鋇餐表現 | 平滑、圓形的黏膜下填充缺損 |
| GIST vs. 平滑肌瘤 | 文獻中分類不一，兩者均有被描述為最常見 |

---

#### 腺瘤 / Adenoma

**食道腺瘤**是具有惡性潛能的良性黏膜病變，通常起源於 Barrett 食道。

- 大多數 **<1.5 cm**，通常在內視鏡下切除

---

#### 炎症性息肉 / Inflammatory Polyp

**炎症性息肉**是非腫瘤性的增大胃皺襞，突出至下食道。

- 幾乎均與逆流相關
- 恆與胃皺襞相連
- 起源於黏膜層

---

#### 纖維血管息肉 / Fibrovascular Polyp

**纖維血管息肉**是有蒂的腫瘤，由含有大量脂肪成分的間質成分組成。

| 特點 | 說明 |
|------|------|
| 惡性潛能 | **無**（與食道腺瘤不同） |
| 好發位置 | **頸段食道** |
| 臨床表現 | 可戲劇性地吐出 fleshy mass |
| CT 診斷 | 顯示病灶內脂肪成分可確診 |

---

#### 食道靜脈曲張 / Esophageal Varices

**食道靜脈曲張**最常見原因為**門脈高壓**。

| 類型 | 說明 |
|------|------|
| **上行性（Uphill）靜脈曲張** | 由門脈高壓引起，影響**遠端食道**；血流方向：門靜脈 → 胃左靜脈 → 食道旁靜脈叢 → 奇靜脈/半奇靜脈 → 上腔靜脈 |
| **下行性（Downhill）靜脈曲張** | 少見，由上腔靜脈阻塞引起，影響**近端食道** |

> 靜脈曲張可通過蠕動時大小和形狀的變化與實質腫瘤區分；血栓形成的靜脈曲張可模擬腫瘤。

---

#### 前腸囊腫 / Foregut Duplication Cysts

| 囊腫類型 | 特點 |
|----------|------|
| **食道重複囊腫（Esophageal duplication cyst）** | 鱗狀上皮襯裡，平滑肌壁，通常位於後縱隔；可位於食道外或黏膜下（後者無法與平滑肌瘤區分） |
| **支氣管囊腫（Bronchogenic cyst）** | 呼吸道上皮襯裡；食道囊腫在食道鋇餐和 CT 上無法區分 |
| **神經腸囊腫（Neurenteric cyst）** | 與椎體異常相關 |

---

#### 食道異物 / Esophageal Foreign Body

| 特點 | 說明 |
|------|------|
| 檢測 | 側位 X 光或 CT 檢測不透射線異物最佳 |
| 骨性異物 | 通常卡在**頸段食道** |
| 肉類嵌塞 | 通常發生在**胃食道交界** |
| 穿孔風險 | 若嵌塞 >24 小時，有因壁間缺血導致穿孔的風險 |
| 治療 | 內視鏡下移除（首選）；歷史上有用發泡粒和肉軟化劑，現已少用 |

---

### 臨床要點 / Clinical Key Points
> - **纖維血管息肉**為良性無惡性潛能，好發於頸段食道；CT 顯示脂肪成分可確診
> - **上行性靜脈曲張**由門脈高壓引起，影響遠端食道；**下行性靜脈曲張**由上腔靜脈阻塞引起，影響近端食道
> - 肉類嵌塞最常發生在**胃食道交界**；嵌塞 >24 小時有穿孔風險
