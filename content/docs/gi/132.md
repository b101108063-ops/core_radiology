## Text Content

### 食道 / Esophagus

#### 解剖學 / Anatomy

**咽部（Pharynx）：**

| 部位 | 範圍 |
|------|------|
| **鼻咽（Nasopharynx）** | 顱底至軟腭 |
| **口咽（Oropharynx）** | 口腔後方，懸雍垂至舌骨 |
| **下咽（Hypopharynx）** | 舌骨至環咽肌（C5-6），環咽肌為食道上括約肌 |

- **環咽肌（Cricopharyngeus muscle）**位於 C5-6，是上食道括約肌，分隔咽部與頸段食道
- 食道從頸部延伸至胃食道交界處；遠端食道穿過橫膈裂孔（約 T10）
- 遠端食道的三個解剖學環：A 環（肌肉）、B 環（黏膜）、C 環（橫膈壓跡）

---

#### 食道環與食道蹼 / Esophageal Rings and Webs

##### 食道蹼 / Esophageal Web

**食道蹼**是上食道細薄的前壁皺襞/壓跡，通常無症狀，可為吞嚥困難的原因。

- 與貧血相關存在爭議（**Plummer-Vinson 症候群**）
- 與上食道癌的關聯也有爭議

##### Schatzki 環 / Schatzki Ring

**Schatzki 環**是遠端食道 B（黏膜）環的局灶性狹窄，導致間歇性吞嚥困難。

| 特點 | 說明 |
|------|------|
| 定義 | 需有臨床吞嚥困難症狀 + 影像學上的食道狹窄 |
| 無症狀狹窄 | 稱為下食道環（lower esophageal ring） |
| 影像學 | 上消化道鋇餐檢查比內視鏡更靈敏；典型為胃食道交界處的環形狹窄，幾乎均伴隨裂孔疝氣 |
| 臨床測試 | 大多數有症狀的環不允許 12 mm 藥片通過 |

**環形食道狹窄的鑑別診斷：**
- 局灶性狹窄（focal stricture）
- 胃食道交界上方的肌肉環（A 環）
- 食道癌
- 食道蹼（少見，多位於頸段食道）

---

### 臨床要點 / Clinical Key Points
> - **Schatzki 環**是遠端食道 B 環的環形狹窄，是間歇性吞嚥困難的常見原因，幾乎均伴隨裂孔疝氣
> - **Plummer-Vinson 症候群**：食道蹼 + 貧血，與上食道癌風險增加相關
> - 環形食道狹窄的鑑別包括良性狹窄、Schatzki 環和食道癌
