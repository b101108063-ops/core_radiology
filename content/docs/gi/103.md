# Gastrointestinal Imaging - Page 103

![Page 103](/core_radiology/images/gi/page-103.png)

## Text Content

### 肝細胞癌 / Hepatocellular Carcinoma (HCC)

**肝細胞癌（HCC）**是最常見的原發性肝臟腫瘤。**肝硬化**是 HCC 發生的最大危險因子。

**實驗室：** 約 **75%** 的 HCC 患者**甲型胎兒蛋白（AFP）**升高。

---

#### 影像學特徵

| 特徵 | 說明 |
|------|------|
| **典型增強模式** | 動脉期強化 → 門脈期廓清 |
| **動脉期強化** | HCC 的特徵性影像學表現 |
| **10-20% 為低血供型** | 動脉期相對周圍肝實質呈輕度低強化 |
| **典型 CT/MRI** | 有包膜腫塊，動脉期強化，門脈期廓清 |
| **非對比 CT** | HCC 常呈等衰減，難以檢測 |
| **MRI T2** | 典型呈 T2 稍高訊號（相對於周圍肝實質） |

**特殊表現：**
- **Nodule-in-nodule（結節中結節）**：發育不良結節內出現強化結節，代表早期 HCC

---

#### 侵襲性 / Locally Invasive

HCC 容易局部侵犯至：
- **門靜脈**（最常見）
- **下腔靜脈（IVC）**
- **膽管**

> 對比：轉移性肝病灶較少局部侵犯。

**治療方式：** 部分肝切除、肝臟移植、經皮消融、經導管栓塞

---

### 纖維板型 HCC / Fibrolamellar HCC

**纖維板型肝癌**是 HCC 的亞型，發生於**無肝硬化的年輕患者**。

| 特點 | 說明 |
|------|------|
| 發病年齡 | 年輕（無肝硬化背景） |
| 確診時腫瘤大小 | 常較大 |
| AFP | **不升高**（與典型 HCC 不同） |
| 預後 | 比典型 HCC 好 |
| 包膜 | 無真正包膜（可見假包膜） |

**MRI 特徵：**
- 大型、不均質腫塊
- **中央纖維疤痕**（classic）：T1、T2 均**低訊號**（與 FNH 的 T2 高訊號疤痕不同）
- 10% 可見包膜回縮

> **鑑別診斷**：FNH 的疤痕為 T2 高訊號且延遲強化；纖維板型 HCC 的疤痕為 T2 低訊號。

---

### 臨床要點 / Clinical Key Points
> - **HCC** 典型影像學表現：動脉期強化 + 門脈期廓清；約 75% 患者 AFP 升高
> - **纖維板型 HCC**：年輕患者、無肝硬化、AFP 不升高；MRI 中央疤痕為 **T2 低訊號**（不同於 FNH 的 T2 高訊號）
> - HCC 具有局部侵犯性，常侵犯**門靜脈**；轉移性肝病灶則局部侵犯較少
