# Gastrointestinal Imaging - Page 107

![Page 107](/core_radiology/images/gi/page-107.png)

## Text Content

### 肝臟腺瘤 / Hepatic Adenoma

**肝臟腺瘤**是含有肝細胞、散在 Kupffer 細胞但**無膽管**的良性肝臟腫瘤。

**HIDA 掃描的鑑別價值：**
- 因腺瘤**無膽管**，HIDA 掃描為陰性
- **FNH 含有膽管**，HIDA 掃描為陽性

---

#### 臨床特徵

| 特徵 | 說明 |
|------|------|
| 好發性別 | 女性（與口服避孕藥長期使用相關） |
| 男性患者 | 可能與合成代謝類固醇相關 |
| 破裂風險 | 相对较高，常為首發症狀 |
| von Gierke 病（肝醣儲積症第一型） | 可見多發性肝臟腺瘤 |
| 包膜 | 可有假包膜，延遲強化 |

---

#### 影像學特徵

| 表現 | 說明 |
|------|------|
| **富血供** | 腺瘤缺乏門靜脈引流，因此動脉期呈富血供 |
| **細胞內脂肪** | 同相位/反相位 MRI 可顯示信號丟失（最敏感） |
| **病灶內出血** | 可導致 T1 高訊號 |
| CT 表現 | 非特異性，不均質強化低衰減腫塊 |

> 腺瘤若無脂肪或出血存在，與其他富血供肝臟腫塊（包括 HCC、FNH）難以區分。

---

### 臨床要點 / Clinical Key Points
> - **肝臟腺瘤**與口服避孕藥相關（女性），男性可能與合成代謝類固醇相關；因破裂風險較高，通常建議切除
> - **HIDA 掃描**可鑑別 FNH（有膽管，陽性）與腺瘤（無膽管，陰性）
> - 同相位/反相位 MRI 可檢測腺瘤中的**細胞內脂肪**，是重要的鑑別工具
