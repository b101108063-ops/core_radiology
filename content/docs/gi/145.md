## Text Content

### 小腸 / Small Bowel

#### 小腸解剖 / Small Bowel Anatomy

**小腸壁由外向內的四層：**
1. 漿膜（Serosa）
2. 黏膜下層（Submucosa）
3. 肌肉層（Muscularis）：薄縱肌 + 厚環狀平滑肌
4. 黏膜層（Mucosa）：絨毛、環狀皺襞、腺體、淋巴組織

**Valvulae conniventes** 形成特徵性小腸皺襞圖案。

**血液供應：** 腸繫膜上動脉（SMA）供應空腸和迴腸；小腸系膜將空腸和迴腸固定於後腹壁。

**空腸 vs. 迴腸：** 空腸的皺襞更大、更發達，絨毛也更大。

---

### 小腸阻塞 / Small Bowel Obstruction (SBO)

**最常見原因：** 黏連（既往手術或赫尼亞）；腫瘤、狹窄、腸套疊較少見。

---

#### X 光評估

| 發現 | 說明 |
|------|------|
| 小腸擴張 | 擴張 |
| 多個不同高度的氣液平面 | 立位片可見 |
| 結腸缺乏氣體 | 高度提示阻塞 |
| 假陽性 | 既往結腸切除術的腸阻塞；腹水的腸阻塞 |

---

#### CT 影像診斷

| 要點 | 說明 |
|------|------|
| 小腸擴張直徑 | **≥3 cm**，過渡點至塌陷腸道 |
| CT 可確定的內容 | 過渡點、阻塞原因、併發症（如缺血或嵌頓） |

**系統性分析 SBO 的三步驟：**

1. **找過渡點**：擴張與塌陷腸道的交界處，確定阻塞原因
2. **區分單純性與閉合性阻塞**：閉合性阻塞為「不可錯過」病變，缺血風險極高
3. **評估缺血或即將缺血的徵象**（按嚴重程度排序）：

| 徵象 | 說明 |
|------|------|
| 腸膜血管充血 | 最早表現 |
| 腸道周圍腹水 | 毛細血管通透性增加 |
| 腸壁增厚 | 黏膜下水腫 |
| 腸壁強化消失 | 血管收縮或灌注不足 |
| 腸壁積氣（pneumatosis intestinalis） | 腸壁壞死導致；呈現周邊性小積氣 |

---

#### 小腸糞便徵 / Small Bowel Feces Sign

| 特點 | 說明 |
|------|------|
| 定義 | 小腸內糞便樣物質混合氣泡，類似糞便的 CT 表現 |
| 位置 | 通常在過渡點近端 |
| 幫助 | 有助於定位過渡點；對亞急性或部分性阻塞特別有幫助 |
| 原因 | 細菌過度生長和未消化食物 |

---

### 臨床要點 / Clinical Key Points
> - **閉合性阻塞（Closed-loop obstruction）**是外科緊急情況，缺血風險極高；必須系統性分析過渡點、單純性 vs. 閉合性、缺血徵象
> - **小腸糞便徵**有助於定位過渡點，對部分性阻塞的診斷特別有價值
> - **腸壁積氣（pneumatosis intestinalis）**是腸壁壞死的表現，提示嚴重病變
