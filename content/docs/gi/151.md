## Text Content

### 乳糜瀉（續）/ Celiac Disease (continued)

#### 實驗室與皮膚表現

| 異常 | 說明 |
|------|------|
| 貧血 | 營養吸收不良導致 |
| 白血球減少 | 可見 |
| 免疫球蛋白缺乏 | 可見 |
| 皮膚表現 | **皰疹樣皮膚炎（Dermatitis herpetiformis）**：特徵性皮疹 |

---

### 乳糜瀉的併發症總結

| 併發症 | 特點 |
|---------|------|
| 小腸 T 細胞淋巴瘤 | 重要併發症，可為外生性腫塊、環形增厚或淋巴結增大 |
| 腸套疊 | 無腫瘤 lead point |
| 腸壁積氣 | 非缺血性（不代表腸道壞死） |
| 脾臟萎縮 | 常見 |
| 靜脈血栓栓塞 | 風險增加 |
| **CMLNS** | 乳糜瀉高度特異性，淋巴結中心低衰減 |

---

### 臨床要點 / Clinical Key Points
> - **乳糜瀉**的腸道外表現包括貧血、白血球減少、免疫球蛋白缺乏和皰疹樣皮膚炎
> - 乳糜瀉併發**腸壁積氣**不代表腸道缺血，與其他病因的腸壁積氣意義不同
> - **CMLNS**（化膿性空腸淋巴結症候群）與乳糜瀉的乳頭狀萎縮和脾臟萎縮共同出現時高度特異
