## Text Content

### 胰管內乳頭狀黏液性腫瘤 / Intraductal Papillary Mucinous Neoplasm (IPMN)

**胰管內乳頭狀黏液性腫瘤（IPMN）**最常見於**老年男性**，被稱為「**爺爺瘤（grandfather tumor）**」。

| 特點 | 說明 |
|------|------|
| 生物行為光譜 | 從良性到惰性到侵襲性癌 |
| 起源部位 | 可起源於主胰管或分支胰管 |
| 主胰管型 IPMN | 惡性潛能更高 |

**典型內視鏡表現：** 魚嘴狀乳頭（fish-mouth papilla）湧出黏液

**横断面成像：** 與胰管或分支胰管連續的囊性胰內病變；任何結節狀或強化成分應懷疑惡性

**手術切除建議（一般標準）：**
- 囊腫 **>3 cm**
- 壁上有**附壁結節（mural nodule）**
- 伴隨胰管擴張 **>10 mm**

> 多達 **40%** 的老年男性有胰臟囊腫，可能是衰老的後天性表現而非癌前病變。

### 胰臟內分泌腫瘤 / Pancreatic Endocrine Neoplasms

#### 功能性 vs. 非功能性

| 類型 | 特點 |
|------|------|
| **功能性** | 因內分泌過剩症狀就醫 |
| **非功能性** | 診斷時腫瘤通常較大，可發生囊性變，應作為囊性胰臟腫瘤鑑別診斷 |

**共同特徵：** 傾向富血供，晚期動脉期最佳；大多為實質性（除非腫瘤很大）

---

#### 胰島素瘤 / Insulinoma

| 特點 | 說明 |
|------|------|
| 發生率 | 最常見的胰臟內分泌腫瘤 |
| 症狀 | 低血糖（因胰島素過多） |
| 預後 | 症狀早發、預後最好；僅 **10%** 呈惡性 |

**Whipple's triad（Whipple 三聯徵）：** 低血糖、低血糖的臨床症狀、給予葡萄糖後症狀緩解

---

#### 胃泌素瘤 / Gastrinoma

| 特點 | 說明 |
|------|------|
| 結果 | 胃酸過多 → **Zollinger-Ellison 症候群** |
| 發生率 | 第二常見的胰臟內分泌腫瘤 |
| MEN-1 關聯 | 與 **MEN 1 型**相關；此時常為多發，且常位於**十二指腸**而非胰臟 |
| 典型位置 | **胃泌素瘤三角**：膽囊管與總膽管交界、十二指腸下方、胰臟頸部/體部內側 |

> 高胃泌素水平可導致胃部類癌形成，胃泌素瘤切除後可能消退。

---

### 臨床要點 / Clinical Key Points
> - **IPMN**（「爺爺瘤」）：老年男性為主；主胰管型惡性潛能更高；附壁結節是惡性重要指標
> - **胰島素瘤**：最常見功能性胰島素瘤；Whipple 三聯徵（低血糖 + 症狀 + 葡萄糖緩解）
> - **胃泌素瘤**：第二常見；Zollinger-Ellison 症候群；與 **MEN 1 型**相關時多位於十二指腸
