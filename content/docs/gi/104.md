## Text Content

### 肝臟轉移 / Hepatic Metastases

#### 血供特徵

| 類型 | 腫瘤範例 | 最佳顯像時相 |
|------|----------|--------------|
| **低血供型（大多數）** | 結直腸癌、胰臟癌 | **門脈期**（與 HCC 相反） |
| **富血供型** | 神經內分泌腫瘤、腎細胞癌、黑色素瘤、甲狀腺癌、肉瘤 | 動脉期 |

**轉移性腫瘤：** 雖然由腫瘤血管新生誘導的肝動脈分支供血，但大多數為低血供型，在門脈期最佳

> 大腸癌及胰臟癌轉移通常為低血供型，可在門脈期影像上確診。

**CT 表現：**
- 黏液性大腸癌或卵巢漿液性腫瘤可見鈣化（提示預後較好）
- MRI：T1 低訊號、T2 高訊號；黑色素瘤因黑色素在 T1 呈高訊號

---

### 假性肝硬化 / Pseudocirrhosis

**假性肝硬化**為多發性硬索性肝臟轉移導致的**大結節性肝臟輪廓**，可模擬肝硬化外觀。

| 特點 | 說明 |
|------|------|
| 最常見原因 | **治療後的乳癌轉移** |
| 典型表現 | 肝臟邊緣顯著結節狀 |
| 特徵性表現 | **包膜回縮（capsular retraction）** |
| 肝功能 | 通常正常 |

---

### 肝臟淋巴瘤 / Hepatic Lymphoma

原發性肝臟淋巴瘤**極罕見**。肝臟淋巴瘤浸潤多為**全身性疾病的續發表現**，常伴隨脾腫大及淋巴結病變。

---

### 上皮樣血管內皮瘤 / Epithelioid Hemangioendothelioma

**上皮樣血管內皮瘤**為罕見的血管惡性腫瘤。

**特徵：**
- 多發性球形包膜下腫塊，可相互融合
- 個別腫塊可見光環（halo）或靶徵（target appearance）
- 為**包膜回縮**的原因之一

---

### 肝臟包膜回縮的鑑別診斷 / Differential Diagnosis of Capsular Retraction

| 病因 |
|------|
| 轉移性腫瘤（治療後更常見） |
| **纖維板型 HCC（10% 的纖維板型 HCC 可見）** |
| HCC（少見） |
| **上皮樣血管內皮瘤** |
| **肝內膽管癌（Intrahepatic cholangiocarcinoma）** |
| 融合性肝臟纖維化（肝硬化中，典型位於左肝葉內側段或右肝葉前段） |

---

### 臨床要點 / Clinical Key Points
> - **低血供轉移瘤**（如大腸癌）在**門脈期**最佳；**富血供轉移瘤**（神經內分泌腫瘤、腎細胞癌）在動脉期最佳
> - **假性肝硬化**最常見於治療後乳癌轉移，與真正肝硬化的鑑別點為包膜回縮及正常肝功能
> - **包膜回縮**的病因多樣，包括轉移瘤（治療後）、纖維板型 HCC、上皮樣血管內皮瘤及膽管癌
