### 正子發射電腦斷層 (PET-CT) / Positron Emission Tomography–Computed Tomography (PET-CT)

#### 基礎物理 / Basic PET Physics

- **PET 放射性追蹤劑**（radiotracer）發射正電子（positron），正電子在組織內移動極短距離後與電子碰撞，產生兩個 **511 keV 光子**，幾乎以 180 度相反方向前進
- 兩個高能光子同時被環形偵測器偵測，判定為符合事件（coincidence），可精確定位訊號來源

#### 放射性追蹤劑：氟-18 葡萄糖類似物 / Radiotracer: Fluorine-18 FDG

- **氟-18（F-18）** 為正電子發射體，半衰期 110 分鐘
- **F-18-氟去氧葡萄糖（F-18 FDG）** 為葡萄糖類似物，與葡萄糖競爭透過 **GLUT 1 及 GLUT 3 受體** 進入細胞
- 進入細胞後被磷酸化為 FDG-6-phosphate，但此產物無法進入糖解途徑，**被滞留在細胞內**

#### 攝取定量 / Uptake Quantification

- **標準化攝取值（SUV, Standardized Uptake Value）** 用於半定量分析 FDG 攝取
- **SUV 計算公式**：`SUV = (ROI 活性 × 體重) / 施打活性`
- SUV 受多種因素影響：設備種類、施打後時間、活性外滲情形、肌肉攝取、血糖與胰島素濃度等
- **SUV 不可作為診斷惡性腫瘤的唯一標準**
- 建議採用相對比值（相對於肝臟、小腦或基底核）來評估攝取程度：

| 相對攝取程度 | 與基底核相比 |
|---|---|
| **輕度 / Mild** | <20% |
| **中度 / Moderate** | 20–60% |
| **強度 / Intense** | >60% |

### 臨床要點 / Clinical Key Points
> - FDG 攝取反映的是 **細胞代謝活性**，而非單純的結構異常
> - SUV 數值需謹慎解讀，不同設備與時間點的 SUV **不可直接比較**
> - 低惡性度腫瘤（如支氣管肺泡細胞癌、類癌）可能 **FDG 陰性**，臨床上需注意假陰性
> - 活動性肉芽腫疾病（結核等）可能 FDG 陽性，需注意假陽性

### PET-CT（續）/ PET-CT (Continued)

#### CT 關聯 / CT Correlation

- 大多數現代 PET 檢查以 **PET-CT** 形式執行（兒科例外，可能僅做 PET 以減少 CT 輻射劑量）
- CT 通常使用較診斷型 CT 低的劑量；是否注射靜脈顯影劑依各機構Protocol 而異
- CT 的用途：**解剖定位** 與 **衰減校正**
- 高密度口服顯影劑或金屬植入物可能因衰減校正錯誤產生 **偽影**

#### 病人準備 / Patient Preparation

- FDG 攝取與 **血糖及胰島素濃度** 密切相關
- 胰島素升高會增加肌肉攝取、降低偵測輕度病灶的靈敏度
- 病人應**禁食（NPO）至少 4 小時**，使胰島素降至基礎濃度
- 血糖應控制在 **200 mg/dL 以下**，最好低於 150 mg/dL
- 注射 F-18 FDG 後，病人應在安靜房間休息 **60 分鐘**
  - 說話 → 聲帶 FDG 攝取
  - 走路 → 肌肉 FDG 攝取

#### 正常 FDG 分布 / Normal FDG Distribution

| 器官 / Organ | 正常攝取 / Normal Uptake |
|---|---|
| **腦 / Brain** | 強度攝取（大腦偏好葡萄糖）；可見皮質、基底核、小腦結構 |
| **腎臟、輸尿管、膀胱** | 強度攝取（FDG 經尿液排泄） |
| **唾液腺、扁桃腺、甲狀腺** | 輕至中度對稱攝取 |
| **肝臟 / Liver** | 中度 FDG 攝取，通常不均勻 |
| **腸道 / Bowel** | 瀰漫性輕至中度（正常）；**局灶性腸道攝取應提高警覺** |
| **心臟 / Heart** | 變異性大（取決於胰島素/葡萄糖狀態） |
| **肌肉 / Muscles** | 正常時低攝取；胰島素升高或運動後可增加 |
| **棕色脂肪 / Brown fat** | 代謝活躍；常見於鎖骨上區及肋間；寒冷時活性增加 |

> **Note:** Metformin（ metformin）可增加結腸及小腸 FDG 攝取

### 臨床要點 / Clinical Key Points
> - 熟悉 **正常生理分布** 是正確判讀的基礎；腎臟、膀胱的尿液排泄為正常強度攝取
> - 判讀前需確認病人 **血糖控制、禁食狀態、是否說話或走動**，以排除生理性攝取
> - **棕色脂肪攝取** 在寒冷環境或化療後常見，需與淋巴結或病灶鑑別
> - 乳癌病人在化療後需注意 **G-CSF 刺激** 導致的骨髓 FDG 攝取

### PET-CT 腫瘤適應症 / PET-CT Oncologic Indications

#### 肺癌 / Lung Cancer

- PET-CT 在肺癌的 **初始分期** 與 **治療反應評估** 均有重要角色
- 通常僅 **非小細胞肺癌（NSCLC）** 接受 PET 評估；小細胞肺癌在確診時即視為轉移性
- 初始分期：PET-CT 最常用於評估 **局部腫瘤侵犯** 與 **遠處轉移**
  - 約 10% CT 轉移評估陰性的病人，PET 會發現轉移病灶
- PET 對惡性淋巴結偵測 **靈敏度高但特異性不足**
  - PET 陰性 → 可不需進一步檢查直接手術
  - PET 陽性 → 需縱膈腔鏡確認（縱膈腔鏡為淋巴結分期金標準）

#### 孤立性肺結節 / Solitary Pulmonary Nodule (SPN)

- 評估懷疑惡性的 SPN 為 PET-CT 適應症

| 特性 | 說明 |
|---|---|
| **最小可評估大小** | 通常為 8 mm |
| **惡性 SPN** | 大多數 FDG 攝取陽性 |
| **低惡性度腫瘤** | 支氣管肺泡細胞癌、類癌可能 FDG 陰性（假陰性） |
| **良性結節** | 大多數 FDG 不攝取；活動性肉芽腫可呈陽性（假陽性） |

- **FDG 陰性結節**：短期追蹤合理
- **FDG 陽性結節**：建議切片或手術切除
- **SUV 數值不能作為確切診斷依據**

### 鑑別診斷 / Differential Diagnosis

| 結節特徵 / Feature | 惡性線索 / Malignant | 良性線索 / Benign |
|---|---|---|
| **FDG 攝取** | 強度攝取 | 無攝取或輕度 |
| **大小** | >8 mm，漸增大 | 穩定或縮小 |
| **形狀** | 不規則 | 規則、邊界清楚 |
| **倍增時間** | <20 天或 400 天內快速增大 | >400 天 |

### 臨床要點 / Clinical Key Points
> - 肺癌分期時，PET 陽性縱膈淋巴結 **必須以縱膈腔鏡確認**，不可僅凭 PET 結果否決手術
> - SPN 判讀需結合 **大小、形態、FDG 攝取** 綜合判斷，不可只看 SUV
> - 類癌與支氣管肺泡細胞癌因代謝活性低，PET 可能偽陰性；需結合臨床與 CT 特徵
> - 有結核或肉芽腫疾病流行區域病史時，需注意 FDG 陽性的假陽性可能

### PET-CT 腫瘤適應症（續）/ PET-CT Oncologic Indications (Continued)

#### 大腸癌 / Colon Cancer

- PET-CT 在評估大腸癌 **局部侵犯** 的角色有限（空間解析度低、腸道生理攝取干擾）
- 主要用於 **轉移性疾病** 評估，特別是：
  - 單獨肝轉移可切除或消融時，**術前排除肝外轉移** 為常見適應症
- 治療後追蹤：
  - 建議延遲至初始治療結束 **約 2 個月** 後再執行 PET-CT
  - 原因：治療後初期可能出現 **「flare phenomenon」**，FDG 攝取短暫增加

#### 頭頸部癌症 / Head and Neck Cancer

- PET-CT常用於頭頸部**鱗狀細胞癌**的初始分期，特別是評估區域淋巴結轉移
- 治療後復發評估：
  - 特異性受限（治療後解剖結構改變 + 放射性/化學治療引起發炎）
  - 建議延遲至治療結束 **至少 4 個月** 後再執行 PET-CT

#### 甲狀腺癌 / Thyroid Cancer

- **分化型甲狀腺癌**（乳頭狀、濾泡型）→ 使用 **I-131 放射性碘** 進行追蹤與治療
- **未分化癌或髓質癌** 可能不攝取放射性碘，但 FDG 可能呈陽性
- PET-CT 臨床情境：**甲狀腺球蛋白（thyroglobulin）升高但整個放射性碘掃描陰性** 時

#### 淋巴瘤 / Lymphoma

- PET-CT 在淋巴瘤的 **分期與再分期** 扮演核心角色
- 大多數組織類型（Hodgkin 與非 Hodgkin 淋巴瘤）均 **FDG 攝取陽性**
- 低惡性度淋巴瘤（小淋巴球型、套細胞型）可能 FDG 攝取較低
- 骨髓 FDG 攝取增加判讀注意：
  - **瀰漫性**：可能為 G-CSF 刺激、化療後反彈、或惡性浸潤
  - **局灶性**：惡性浸潤可能性較高

#### 乳癌 / Breast Cancer

- 主要用於 **復發或第四期乳癌** 的分期與治療反應評估
- **常規不建議** 用於第一至三期乳癌術前分期

### 臨床要點 / Clinical Key Points
> - 大腸癌術前 PET-CT 主要目的為排除 **肝外轉移**；局部分期仍需依賴內視鏡與 CT/MRI
> - 頭頸部癌症治療後需等待 **至少 4 個月** 再做 PET-CT，以減少發炎偽影
> - 甲狀腺球蛋白上升但放射性碘掃描陰性時，**FDG PET-CT** 可偵測去分化或遠處轉移
> - 淋巴瘤化療後追蹤時，詢問是否使用 **G-CSF** 非常重要，以避免將藥物性骨髓攝取誤判為疾病進展

### PET-CT 腫瘤適應症（續）/ PET-CT Oncologic Indications (Continued)

#### 甲狀腺癌 / Thyroid Cancer

- **分化型甲狀腺癌**（乳頭狀癌、濾泡型癌）→ 首選 **I-131 放射性碘**（radioiodine）追蹤與治療
- **未分化癌（anaplastic）** 或 **髓質癌（medullary）** 可能不攝取放射性碘，但可能 FDG 攝取陽性
- PET-CT 臨床時機：**甲狀腺球蛋白（thyroglobulin）升高** 但整個放射性碘全身掃描陰性

#### 淋巴瘤 / Lymphoma

- PET-CT 在淋巴瘤的 **分期與再分期** 扮演核心角色
- 大多數組織類型（Hodgkin 與非 Hodgkin 淋巴瘤）均 **FDG 攝取陽性**
- 低惡性度淋巴瘤（小淋巴球型、套細胞型）可能 FDG 攝取較低
- 骨髓 FDG 攝取增加的判讀注意：
  - **瀰漫性骨髓攝取**：可能為 G-CSF 刺激、化療後反彈、或惡性浸潤
  - **局灶性骨髓攝取**：惡性浸潤可能性較高

#### 乳癌 / Breast Cancer

- 主要用於 **復發或第四期（Stage IV）乳癌** 的分期與治療反應評估
- **常規不建議** 用於第一至三期（Stage I–III）乳癌術前分期

### 臨床要點 / Clinical Key Points
> - 甲狀腺球蛋白上升但放射性碘掃描陰性時，**FDG PET-CT** 可偵測去分化腫瘤或遠處轉移
> - 淋巴瘤化療後追蹤時，需詢問是否使用 **G-CSF**，以避免將藥物性骨髓攝取誤判為疾病進展
> - FDG PET-CT 在乳癌主要用於 **復發或轉移** 偵測，非常規早期分期
> - 部分低惡性度淋巴瘤 FDG 攝取可能不足，判讀時需注意假陰性

### PET-CT 腫瘤適應症（續）/ PET-CT Oncologic Indications (Continued)

#### 食道癌 / Esophageal Cancer

- PET-CT 在食道癌初始評估的**主要角色**為識別第四期（Stage IV）患者（不適合手術候選者）
- 新輔助治療（neoadjuvant treatment）後：
  - FDG 攝取下降 **≥30%** 提示預後較佳
  - SUV 無下降者，可考慮更改化療方案

#### PET-CT 角色有限的癌症 / Cancers Where PET-CT Has Limited Role

##### 肝細胞癌 / Hepatocellular Carcinoma (HCC)

- 僅約 **50%** 的 HCC 可被 FDG PET 偵測
- 原因：HCC 含高濃度磷酸酶（phosphatase），使 FDG 去磷酸化後擴散出細胞

##### 腎細胞癌與膀胱癌 / RCC and Bladder Cancer

- 僅約 **50%** 腎細胞癌 FDG 攝取陽性
- 輸尿管或膀胱病灶偵測極度受限（周圍尿液 FDG 背景高）

##### 前列腺癌 / Prostate Cancer

- **FDG PET 不建議** 用於前列腺癌評估
- 較新：Carbon-11 choline PET 已獲 FDA 核准用於攝護腺癌，但尚未廣泛使用

### 臨床要點 / Clinical Key Points
> - 食道癌治療前 PET-CT 可作為 **非手術候選人的初步篩選工具**
> - HCC 因葡萄糖-6-磷酸酶活性高，FDG PET 敏感度低；建議使用 **對比劑強化 CT 或 MRI** 追蹤
> - 前列腺癌 FDG PET 價值有限；膽鹼（choline）或 PMSA 標記 PET 為更合適的分子影像工具
> - 泌尿系統腫瘤（腎細胞癌、膀胱癌）因尿液 FDG 背景干擾，PET-CT 偵測效能受限

### 核醫心臟學 / Nuclear Cardiology

#### 臨床概覽 / Clinical Overview

##### 灌流影像概述 / Perfusion Imaging Overview

- 左心室灌流影像是評估心肌**血流灌注**的工具
- 出現灌流異常時，系統性評估需回答五個問題：

| 問題 | 評估重點 |
|---|---|
| **1. 灌流異常是否可逆？** | 休息時可恢復（可逆性缺陷）vs. 固定缺陷（疤痕） |
| **2. 缺陷有多大？** | 小型 / 中型 / 大型 |
| **3. 缺陷有多嚴重？** | 輕度（心內膜下）/ 中度 / 重度（透壁性） |
| **4. 缺陷在哪個位置？** | 何冠狀動脈分布區域 |
| **5. 是否有其他異常？** | 右心室攝取、缺血性擴張、壁運動異常 |

##### 壓力與影像組成 / Stress and Imaging Components

- 每次灌流檢查有兩個組成：**壓力（stress）** 與**成像（imaging）**
- 壓力類型：
  - 運動壓力（跑步機）
  - 藥理-腎上腺素能（dobutamine）
  - 藥理-血管擴張劑（dipyridamole 或 adenosine）

##### 心肌灌流影像的臨床適應症 / Clinical Applications

| 適應症 | 說明 |
|---|---|
| **急性胸痛的評估** | 心電圖與肌鈣蛋白不明確時，心肌灌流影像可作為把關工具；正常心肌灌流每年心臟事件率僅 0.6% |
| **冠狀動脈狹窄的血流動力學意義評估** | 即使造影顯示狹窄，正常核醫心臟灌流結果提示事件風險較低 |
| **心肌梗塞後風險分層** | 高風險：顯著梗死周圍缺血、不同血管區域缺陷、肺部顯著攝取、左心室瘤、EF <40% |
| **非心臟手術前風險評估** | 術前評估心臟事件風險 |
| **再血管化治療前的活性評估** | 區分冬眠心肌與疤痕組織 |
| **冠狀动脉繞道手術術後評估** | 評估繞道通暢度與心肌狀態 |

> **LVEF 計算公式**：EF = (EDC − ESC) / (EDC − BC)
> - EDC = 舒張末期計數；ESC = 收縮末期計數；BC = 背景計數

### 臨床要點 / Clinical Key Points
> - 心肌灌流掃描正常即便在高預測可能性病人，每年心臟事件率僅 **0.6%**，具有很高的陰性預測值
> - 評估灌流缺陷時需同時回答五個系統性問題：**可逆性、大小、嚴重度、位置、相關異常**
> - 左心室射出分率（EF）可由 **Gated SPECT** 計算，是重要的預後指標
> - 心肌活性評估（冬眠心肌 vs. 疤痕）直接影響再血管化治療的臨床決策

### 核醫心臟學（續）/ Nuclear Cardiology (Continued)

#### 活性評估 / Viability Imaging

- 再血管化治療前（CABG 或 PCI），需確認低灌流區域是否仍有**活性心肌（viable myocardium）**
- **冬眠心肌（hibernating myocardium）**：低灌流但仍有活性，可能從再血管化獲益

##### 活性評估方法 / Viability Imaging Methods

| 方法 | 說明 |
|---|---|
| **Rest–redistribution thallium-201 灌流影像** | 可評估活性與灌流 |
| **F-18 FDG PET（gold standard）** | 僅評估活性，不評估灌流 |

##### FDG PET 活性模式 / FDG PET Patterns

| 模式 | 表現 | 臨床意義 |
|---|---|---|
| **Mismatch（不匹配）** | 灌流缺損區域攝取 FDG | 活性心肌，**可能從再血管化獲益** |
| **Match（匹配）** | 灌流缺損區域無 FDG 攝取 | 非活性疤痕組織，**最佳治療為藥物治療** |

#### 核醫心臟學放射性同位素 / Radionuclides in Nuclear Cardiology

##### Thallium-201（鉈-201）

| 特性 | 說明 |
|---|---|
| **半衰期** | 73 小時 |
| **射線能量** | 69–81 keV 特徵 X 光 |
| **機制** | 鉀類似物，透過 ATP 依賴鈉鉀幫浦主動運輸進入細胞 |
| **攝取與灌流關係** | 直接成正比 |
| **再分布（redistribution）** | 有（缺血活性組織休息後再分布；疤痕則持續缺損） |

##### Technetium-99m Sestamibi（MIBI, Cardiolite）

| 特性 | 說明 |
|---|---|
| **再分布** | **無**（固定於心肌） |
| **機制** | 被動擴散進入心肌，與粒線體膜蛋白結合 |
| **攝取與灌流關係** | 直接成正比 |

##### Rubidium-82（銣-82）

| 特性 | 說明 |
|---|---|
| **類型** | 正電子發射 PET 灌流製劑 |
| **來源** | 鍶-82（Strontium-82）生成 |
| **半衰期** | 76 秒（極短） |
| **特點** | 半衰期短，允許高劑量；但需使用藥理學壓力而非運動 |

### 臨床上要點 / Clinical Key Points
> - **FDG PET mismatch（灌流缺損但有 FDG 攝取）** 代表冬眠心肌，再血管化可能改善心功能
> - **FDG PET match（灌流缺損且無 FDG 攝取）** 代表疤痕組織，藥物治療為主，不建議再血管化
> - Thallium-201 有再分布特性，可同時評估活性與灌流；但半衰期長、輻射劑量高
> - Tc-99m sestamibi 無再分布，需分別注射stress與rest劑量進行顯像
> - Rubidium-82 半衰期極短（76秒），僅能用於藥理學壓力測試

#### 壓力類型 / Types of Stress

##### 運動壓力 / Exercise Stress

- 檢查前需**禁食（NPO）6 小時**（減少內臟血流、降低肝臟與腸道攝取）
- **β-受體阻斷劑與鈣離子通道阻斷劑** 應暫停，以利達到目標心率
- 跑步機多階段運動（Bruce 或 modified Bruce 協定）
- **目標心率** = 85% × (220 − 年齡)

##### 藥理學血管擴張劑 / Pharmacologic Vasodilators

| 藥物 | 機制 | 注意事項 |
|---|---|---|
| **Dipyridamole** | 抑制腺苷去氨酶，使內源性腺苷積聚；使冠狀動脈血流增加 3–5 倍 | 咖啡因與茶鹼（theophylline）會逆轉效果，需停用 24 小時；解毒劑：aminophylline（100–200 mg） |
| **Adenosine** | 與 dipyridamole 生理效果相同，但作用更快速 | 半衰期約 30 秒，不需解毒劑 |
| **Regadenoson** | 腺苷受體激動劑 | 半衰期 2–3 分鐘；給藥方便，單次靜脈注射 |

> **血管擴張劑 stress 原理**：正常冠狀動脈在腺苷作用下擴張，血流增加 3–5 倍；狹窄冠狀動脈無法進一步擴張，該區域在 stress 影像上呈現**相對灌流缺損**

##### Dobutamine（藥理學 stress）

- **β₁ 激動劑**，增加心肌氧氣需求
- 主要用於** adenosine 禁忌症**（嚴重氣喘、COPD、最近攝入咖啡因）

### 臨床要點 / Clinical Key Points
> - 運動壓力需達到 **目標心率（85% 最大心率）** 結果才具診斷價值
> - Dipyridamole/Adenosine/Regadenoson 為血管擴張劑，**禁用於嚴重氣喘或 COPD** 患者（可使用 dobutamine）
> - 咖啡因會阻斷血管擴張劑效果，**需停用 24 小時** 後再執行檢查
> - Dipyridamole stress 後給予 **aminophylline** 需持續監測，因 aminophylline 半衰期比 dipyridamole 短
> - Dobutamine 適用於無法使用血管擴張劑的病人，模擬運動效果增加心肌耗氧

#### 左心室 17 節段模型 / 17-Segment Left Ventricular Model

| 位置 / Level | 節段數 | 節段名稱 |
|---|---|---|
| **心尖 / Apex** | 1 | 心尖（apex） |
| **中段 / Mid** | 4 | 前壁、間隔、下壁、側壁 |
| **基底 / Basal** | 6 | 前壁、前側壁、下側壁、下壁、下間隔、前間隔 |

#### 冠狀動脈分布 / Coronary Artery Territories

| 冠狀動脈 | 顏色 | 主要供應區域 |
|---|---|---|
| **LAD（左前降支 / LAD）** | 淺藍色 | 前壁、間隔、心尖 |
| **LCx（左迴旋支 / Left Circumflex）** | 粉紅色 | 側壁 |
| **RCA（右冠狀動脈 / RCA）** | 橙色 | 下壁、間隔（右優勢者） |

#### 影像判讀要點 / Image Interpretation

- 灌流缺陷大小以 **17 個標準節段** 評估
- 每個節段通常由上表所列冠狀動脈供血，但**個體變異**存在
- 極座標圖（polar plot）將三維左心室展開為二維圖

### 臨床要點 / Clinical Key Points
> - 熟悉 17 節段模型與冠狀动脉分布對應關係，是準確評估灌流缺陷位置與大小的基礎
> - **SA 軸向** 為評估灌流缺陷的主要視圖（甜甜圈結構）
> - 冠狀动脉供血模式存在個體差異，影像判讀時需結合臨床與造影資料
> - 心尖節段由 LAD 供血；下壁與下間隔通常由 RCA 供血（右優勢者）

### 核醫心臟學病例範例 / Sample Nuclear Cardiology Cases

#### 案例一：正常心肌灌流 / Normal Myocardial Perfusion

- 運動壓力（modified Bruce 跑步機協定）下給予 Tc-99m sestamibi 16 mCi
- Rest 與 Stress 影像所見相同且正常
- **正常診斷標準**：stress 與 rest 影像無差異，無固定或可逆性缺陷

#### 案例二：固定缺陷 / Fixed Defect

| 發現 | 說明 |
|---|---|
| **藥物** | Regadenoson 0.4 mg IV + Tc-99m sestamibi 32 mCi |
| **缺陷位置** | 中段與基底下壁（right coronary artery, RCA 分布區） |
| **缺陷類型** | 中等大小**固定缺陷**（stress 與 rest 均可見） |
| **臨床意義** | 代表**疤痕組織或冬眠心肌** |

> 固定缺陷需進一步評估（如 FDG PET viability study）以區分疤痕與可救活的冬眠心肌

#### 案例三：可逆性缺陷 / Reversible Defect

| 發現 | 說明 |
|---|---|
| **藥物** | Regadenoson 0.4 mg IV + Tc-99m sestamibi 29 mCi |
| **缺陷位置** | 前壁（LAD 分布區，黃色箭頭）與側壁（LCx 分布區，紅色箭頭） |
| **缺陷類型** | 大型**嚴重強度部分可逆性缺陷**（stress 可見，rest 消失或減輕） |
| **臨床意義** | 代表**心肌缺血**，反映冠狀動脈狹窄或痙攣 |

### 臨床要點 / Clinical Key Points
> - **固定缺陷**（stress 與 rest 均存在）= 疤痕或冬眠心肌；需進一步活性評估（FDG PET）
> - **可逆性缺陷**（stress 有，rest 消失）= 心肌缺血；提示有意義的冠狀動脈疾病
> - 缺陷大小（大 / 中 / 小）、嚴重度（輕 / 中 / 重）、位置（何冠狀动脉分布區）是系統性描述灌流缺陷的三要素
> - 大型可逆性缺陷（5 個或以上節段）屬於高風險發現

| 特性 | 說明 |

|---|---|---|

| **I-131** | **禁忌** | 需永久停止哺乳 |

### 異位甲狀腺組織 / Ectopic Thyroid

| 類型 | 說明 |
|---|---|
| **舌頭甲狀腺 / Lingual thyroid** | 位於舌根的異位甲狀腺組織 |
| **甲狀腺卵巢囊腫 / Struma ovarii** | 卵巢畸胎瘤內含功能性甲狀腺組織（罕見） |
| **胸骨後甲狀腺 / Retrosternal thyroid** | 最常見於胸骨後甲狀腺腫（substernal goiter） |

### 臨床要點 / Clinical Key Points
> - **I-131 僅用於治療**（甲狀腺癌、甲狀腺毒症），不用於常規診斷成像
> - **I-123** 為甲狀腺診斷掃描的最佳選擇，可同時評估攝取值與形態
> - **Tc-99m pertechnetate** 適合需要快速結果或已注射顯影劑的病人，但影像品質較 I-123 差
> - 懷孕期間 **I-131 絕對禁忌**（通過胎盤且可被胎兒甲狀腺攝取）
> - 哺乳期接受 I-131 治療後需 **永久停止哺乳**

#### 甲狀腺結節 / Thyroid Nodule

#### Graves 病 / Graves Disease

- **病因**：自體免疫疾病，甲狀腺刺激免疫球蛋白（TSI）激活甲狀腺
- **臨床特徵**：甲狀腺毒症、甲狀腺腫大、瀰漫性攝取增加、常見錐體葉（pyramidal lobe）
- **實驗室**：6 小時與 24 小時攝取值均升高

| 指標 | 正常值 | Graves 病 |
|---|---|---|
| **6 小時攝取值** | 6–18% | 升高 |
| **24 小時攝取值** | 10–30% | 升高（常達 50% 以上） |

- **Tc-99m 與 I-123 鑑別**：Graves 病甲狀腺攝取極強，唾液腺常被遮蓋，兩者難以區分
- **治療**：
  - **I-131 放射性碘治療**（首選根治性治療）
  - 抗甲狀腺藥物（methimazole、propylthiouracil）
  - 手術甲狀腺切除（次要選擇）

#### 橋本氏甲狀腺炎 / Hashimoto Thyroiditis

- **病因**：自體免疫甲狀腺炎，為最常見的甲狀腺炎症疾病
- **臨床表現**：甲狀腺腫大，但甲狀腺素水平因疾病階段而異（多數為**甲狀腺功能低下**）
- **影像表現**：多變
  - 瀰漫性高攝取（類似 Graves 病）
  - 斑駁狀攝取（類似多結節性甲狀腺腫）：因淋巴球與淋巴結浸潤造成局部「冷」區

### 臨床要點 / Clinical Key Points
> - 甲狀腺結節中，**不一致結節（Tc-99m 熱/I-123 冷）** 惡性風險最高，強烈建議切片
> - **冷結節** 約 20% 為惡性，最常見為良性囊腫；需結合細胞學結果判斷
> - Graves 病 24 小時攝取值 **>50%** 為典型表現，結合瀰漫性甲狀腺腫大與毒症症狀確診
> - **橋本氏甲狀腺炎** 影像表現多變，可類似 Graves 病或類似多結節性甲狀腺腫；確診需結合甲狀腺抗體檢驗

|---|---|---|

| **Hashimoto 甲狀腺炎** | 多變（可高或斑駁） | 甲狀腺功能低下為主 |

#### I-131 治療適應症 / Therapeutic Indications of I-131

##### 甲狀腺癌術後 / Thyroid Carcinoma Post-Thyroidectomy

- **時機**：甲狀腺癌手術後約 1–2 個月
- **目的**：清除殘餘甲狀腺組織（甲狀腺全切除術後可能仍有殘餘）與潜在轉移病灶
- **準備**：
  - 停用甲狀腺素，使內源性 **TSH 上升**
  - 目標 TSH：**30–50 μIU/mL**（提升殘餘或轉移甲狀腺組織的攝取）
- **劑量原則**：

| 風險分層 | I-131 劑量 |
|---|---|
| **低風險**（腫瘤 <1.5 cm，無甲狀腺包膜侵犯） | <30 mCi |
| **高風險** | 100–200 mCi |

> 新趨勢：T1、T2、N1 甲狀腺癌標準劑量 30 mCi

##### 甲狀腺癌追蹤 / Thyroid Cancer Follow-up

- 甲狀腺癌 I-131 清除術後，以 **甲狀腺球蛋白（thyroglobulin）** 追蹤
- 甲狀腺球蛋白升高 → I-123 掃描評估復發或轉移
- I-123 掃描陽性 → 再次給予 I-131 清除治療
- **抗甲狀腺球蛋白抗體** 存在時，無法以甲狀腺球蛋白監測

##### Graves 病治療 / Treatment of Graves Disease

- I-131 單次口服劑量治療
- **禁忌症**：懷孕、哺乳、無法配合放射安全規範者

### 臨床要點 / Clinical Key Points
> - **亞急性甲狀腺炎** 的攝取降低（冷甲狀腺）與甲狀腺毒症同時出現，與 Graves 病相反（高攝取+高甲狀腺素），為重要鑑別點
> - 甲狀腺癌追蹤時，**甲狀腺球蛋白** 是關鍵腫瘤標記；抗甲狀腺球蛋白抗體陽性干擾監測
> - 甲狀腺癌 I-131 治療前需停甲狀腺素使 TSH 升高，以增加腫瘤細胞攝取
> - Graves 病 I-131 治療劑量個體差異大；治療後需長期追蹤甲狀腺功能（可能發生甲狀腺功能低下）

### 甲狀腺疾病（續）/ Thyroid Disorders (Continued)

#### 多結節性甲狀腺腫的治療 / Treatment of Multinodular Goiter

- I-131 可用於縮小甲狀腺腫體積，特別適合選擇不手術的病人
- 毒性多結節性甲狀腺腫所需 I-131 劑量可能高於 Graves 病劑量
- 可能需要**多次治療**
- 典型劑量：**25 mCi**（毒性多結節性甲狀腺腫）

### 副甲狀腺 / Parathyroid

#### 放射性追蹤劑 / Radiotracer

- **Tc-99m sestamibi**：甲狀腺與副甲狀腺均會攝取，但甲狀腺活性隨時間消退
- 同一製劑亦用於核醫心臟學（心肌灌流）

#### 適應症：副甲狀腺腺瘤 / Indication: Parathyroid Adenoma

- **雙相位顯影（dual-phase imaging）**：早期顯影 + 延遲顯影
  - 早期圖像：甲狀腺與副甲狀腺均攝取
  - 延遲圖像：甲狀腺活性消退，副甲狀腺腺瘤**持續滯留**

| 病灶類型 | 早期圖像 | 延遲圖像 |
|---|---|---|
| **副甲狀腺腺瘤** | 高攝取 | 持續滯留（persistent） |
| **甲狀腺腺瘤** | 高攝取 | 消退（washout） |

- **Tc-99m pertechnetate** 不被副甲狀腺攝取，可作為不確定病例的鑑別工具

### 臨床要點 / Clinical Key Points
> - 多結節性甲狀腺腫 I-131 治療可能需要**多次療程**，劑量通常高於 Graves 病
> - Tc-99m sestamibi **雙相位顯影**是定位副甲狀腺腺瘤的首選非侵入性方法
> - 副甲狀腺腺瘤延遲圖像持續滯留（不消退）與甲狀腺腺瘤的消退模式為關鍵鑑別點
> - 副甲狀腺機能亢進手術前定位時，Sestamibi 掃描可與頸部超聲相互補充

# Nuclear Imaging - Page 569


### 胃腸道影像 / Gastrointestinal Imaging

#### 肝脾影像 / Liver–Spleen Imaging

##### 放射性追蹤劑：Tc-99m 硫膠體 / Radiotracer: Tc-99m Sulfur Colloid

- 硫膠體被**網狀內皮細胞（reticuloendothelial cells）**攝取，主要分布於肝臟、脾臟、骨髓
- 肝內由 **Kupffer 細胞** 攝取（約佔肝臟質量的 10%）
- 分布比例：
  - **肝臟**：80–90%
  - **脾臟**：大部分其餘量
  - **骨髓**：少量（正常時不明顯）

##### 硫膠體掃描的肝臟異常 / Hepatic Abnormalities on Sulfur Colloid Scan

| 類型 | 病灶 | 說明 |
|---|---|---|
| **局灶性攝取減少** | 肝囊腫（最常見）、HCC、腺瘤、膿場 | 肝癌風險族群（肝硬化、肝炎）出現局灶性減少需提高警覺 |
| **局灶性攝取增加** | 局灶性結節性增生（FNH）、肝再生結節、Budd–Chiari 症候群 | FNH 因含 Kupffer 細胞通常與背景難區分；約 1/3 可出現「冷」缺損 |
| **膠體移位（Colloid shift）** | 脾臟與骨髓攝取增加 | 提示肝功能障礙，最常見於肝硬化 |
| **瀰漫性肺攝取** | 非特異性 | 可見於肝硬化、COPD 合併感染、Langerhans 細胞組織球增多症、高血清鋁 |

##### 局灶性結節性增生 / Focal Nodular Hyperplasia (FNH)

| 特性 | 說明 |
|---|---|
| **性質** | 良性肝臟腫瘤 |
| **硫膠體掃描表現** | 多變；最常見與背景肝臟無法區分（因含 Kupffer 細胞）；1/3 可呈現「冷」缺損 |
| **與腺瘤的鑑別** | 腺瘤**不含** Kupffer 細胞，永遠呈現冷缺損 |
| **HIDA 掃描** | FNH 含膽管小管，HIDA 應為陽性（可作為輔助檢查） |

### 臨床要點 / Clinical Key Points
> - 硫膠體掃描中，**局灶性攝取減少** 最常見原因為肝囊腫；HCC、腺瘤、膿場也可表現為冷缺損
> - **FNH** 為含 Kupffer 細胞的良性腫瘤，硫膠體掃描可能正常或呈現不同表現；HIDA 可輔助診斷
> - **膠體移位**（脾臟和骨髓攝取增加）為肝功能障礙的間接徵象，常見於肝硬化
> - 肝硬化病人出現**局灶性減少**需高度懷疑 HCC，並進一步以對比劑 CT/MRI 確認

# Nuclear Imaging - Page 570


### 胃腸道影像（續）/ Gastrointestinal Imaging (Continued)

#### 腸道出血 / Gastrointestinal Bleeding

##### 放射性追蹤劑：Tc-99m 標記紅血球 / Radiotracer: Tc-99m Labeled RBCs

| 技術 | 說明 |
|---|---|
| **體外標記（in vitro）** | 抗凝血 1–3 mL + 氯化亞錫 + 氧化劑混合，再加入 Tc-99m；標記效率 95%；所需時間 >20 分鐘 |
| **體內標記（in vivo）** | 標記效率較差，游離 pertechnetate 較多，影像品質差，臨床上少用 |

- **Tc-99m 硫膠體**可作為替代追蹤劑；血液清除快速，血管半衰期 2–3 分鐘

##### 急性腸道出血 / Acute GI Bleed

- Tc-99m 標記紅血球掃描可偵測低至 **0.2 mL/min** 的出血率（優於血管攝影的 1 mL/min）
- **陽性所見**：腸道內活動性隨時間改變形狀與位置（因蠕動推動腔內血液）
- 可初步區分為**小腸或大腸來源**

#### 胰腺內脾臟 / Intrapancreatic Spleen

- 硫膠體掃描可確認疑似胰腺內脾臟（會顯示攝取）
- Tc-99m 損傷紅血球研究亦可使用

#### Meckel 掃描 / Meckel Scan

##### 放射性追蹤劑：Tc-99m Pertechnetate

- Tc-99m pertechnetate 被**胃黏膜**攝取

##### Meckel 憩室 / Meckel Diverticulum

- 胚胎卵黃管（omphalomesenteric duct）殘留；最常見於**遠端迴腸**
- 約 **10–60%** 含異位胃黏膜，可造成黏膜損傷與腸道出血
- **陽性所見**：右下腹局灶性攝取增加（right lower quadrant）
- 側位圖像有助確認為**前方**（與輸尿管鑑別）

| 鑑別診斷 | 影像特徵 |
|---|---|
| **Meckel 憩室** | 右下腹局灶性固定攝取 |
| **闌尾炎** | 瀰漫性區域性攝取增加（因充血） |
| **腸套疊** | 瀰漫性區域性攝取增加（因腸道炎症/壞死） |

### 臨床要點 / Clinical Key Points
> - 標記紅血球掃描為偵測**活動性胃腸道出血**的首選核醫檢查，敏感度遠高於血管攝影
> - Meckel 掃描用於懷疑 **Meckel 憩室**（尤其兒童或不明原因消化道出血）
> - Meckel 憩室中異位胃黏膜為發炎與出血的根源；約 10–60% 含胃黏膜
> - 標記紅血球掃描可初步定位出血位置，為後續血管攝影或手術介入提供指引

# Nuclear Imaging - Page 571


### 膽道影像（HIDA）/ Hepatobiliary Imaging (HIDA)

#### 放射性追蹤劑：Tc-99m IDA 製劑 / Radiotracers: Tc-99m IDA Agents

| 製劑 | 可顯影膽紅素上限 | 肝臟攝取率 |
|---|---|---|
| **Disofenin** | 20 mg/dL | 90% |
| **Mebrofenin** | 30 mg/dL | 98% |

- 所有 Tc-99m IDA 類似物統稱為「**HIDA 掃描**」
- 兩者均主動運輸進入肝細胞，**不被結合**

#### HIDA 檢查 Protocol / HIDA Protocol

| 步驟 | 說明 |
|---|---|
| **禁食標準** | 檢查前 NPO 6 小時；24 小時內需有進食 |
| **禁食太久（>24 小時）** | 給予膽囊收縮素（CCK）0.02 μg/kg 緩慢輸注以排空膽囊 |
| **顯影時間點** | 注射追蹤劑後立即開始右上限動態顯影 |
| **膽囊可視化** | 出現時 → 急性膽囊炎排除 |
| **標準延遲（90 分鐘）** | 膽囊未顯影 → 給予 morphine 0.04 mg/kg（最多 4 mg）；再等待 30 分鐘 |
| **Morphine 給予前提** | 小腸需有追蹤劑顯示膽道通暢（避免在總膽管阻塞時增加壓力） |
| **Morphine 過敏** | 總顯影時間延長至 4 小時 |

> **CCK 注意**：需緩慢給予否則可能加劇症狀；給予 CCK 後至少等待 2 小時才開始檢查

#### 正常 HIDA 掃描 / Normal HIDA Scan

| 時間點 | 預期所見 |
|---|---|
| **5 分鐘** | 肝臟可見 |
| **15 分鐘** | 膽囊通常可見 |
| **稍後** | 小腸顯影（確認總膽管通暢） |

### 臨床要點 / Clinical Key Points
> - HIDA 掃描確診急性膽囊炎的關鍵：嗎啡給予後 30 分鐘內膽囊**仍不顯影**
> - 膽囊顯影可排除急性膽囊炎；HIDA 對急性膽囊炎敏感度約 **86–98%**
> - 檢查前 **NPO 時間過長（>24 小時）** 或 **近期進食（4 小時內）** 均會造成膽囊不顯影，造成假陽性
> - HIDA 可同時評估膽道通暢性（小腸顯影）與膽囊排空功能

# Nuclear Imaging - Page 572


### 膽道影像（續）/ Hepatobiliary Imaging (Continued)

#### 急性膽囊炎 / Acute Cholecystitis

- 幾乎所有急性膽囊炎患者均有**膽囊管阻塞**
- **90 分鐘顯影 + 嗎啡促進後膽囊仍不顯影**：對急性膽囊炎敏感度 **86–98%**，假陽性率約 **6%**
- **Rim sign（邊緣徵象）**：膽囊窩周圍肝臟攝取增加，提示膽囊窩充血，可能為壞疽性膽囊炎

##### HIDA 假陽性與假陰性 / False Positive and False Negative HIDA

| 假陽性（無急性膽囊炎但膽囊不顯影） | 假陰性（有急性膽囊炎但膽囊顯影） |
|---|---|
| 近期進食（4 小時內）或禁食過久（>24 小時） | 無結石性膽囊炎（膽囊管通暢） |
| 檢查前立即給予 CCK（持續開放膽囊括約肌） | 十二指腸憩室模擬膽囊（側位可鑑別） |
| 嚴重疾病 | 膽道囊腫模擬膽囊 |
| 全靜脈營養（TPN） | |
| 慢性膽囊炎 | |
| 膽囊管膽管癌（罕見） | |

#### 慢性膽囊炎 / Chronic Cholecystitis

- 長期膽囊發炎導致膽囊功能喪失，易形成結石
- 可能為**慢性復發性腹痛**的原因之一
- **HIDA 診斷困難**：大多數慢性膽囊炎 HIDA 掃描可正常

##### 膽囊排空分數 / Gallbladder Ejection Fraction (GBEF)

- **測量方法**：比較 CCK 注射前後膽囊計數
- **異常標準**：GBEF <35% 提示慢性膽囊炎
- **爭議**：排空分數受 CCK 注射速率影響，標準注射 Protocol 尚未建立

### 鑑別診斷 / Differential Diagnosis

| 疾病 | HIDA 特徵 |
|---|---|
| **急性膽囊炎** | 膽囊不顯影（90 分鐘 + 嗎啡後）；rim sign 可能陽性 |
| **慢性膽囊炎** | GBEF <35%；HIDA 可正常 |
| **膽道囊腫** | 膽囊模擬病變（側位鑑別） |
| **十二指腸憩室** | 可模擬膽囊（側位鑑別） |

### 臨床要點 / Clinical Key Points
> - HIDA 對急性膽囊炎高度靈敏，**膽囊顯影可基本排除**急性膽囊炎
> - 造成假陽性的常見原因包括近期進食、禁食過久、CCK 影響；判讀需結合臨床
> - **Rim sign** 陽性提示可能為壞疽性膽囊炎，需提高警覺
> - 慢性膽囊炎的 HIDA 診斷較困難；**GBEF <35%** 可輔助，但標準 Protocol 尚未建立
> - 膽囊排空功能評估需注意 CCK 注射速率對結果的影響
