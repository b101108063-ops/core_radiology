# Nuclear Imaging - Page 569

## Text Content

### 胃腸道影像 / Gastrointestinal Imaging

#### 肝脾影像 / Liver–Spleen Imaging

##### 放射性追蹤劑：Tc-99m 硫膠體 / Radiotracer: Tc-99m Sulfur Colloid

- 硫膠體被**網狀內皮細胞（reticuloendothelial cells）**攝取，主要分布於肝臟、脾臟、骨髓
- 肝內由 **Kupffer 細胞** 攝取（約佔肝臟質量的 10%）
- 分布比例：
  - **肝臟**：80–90%
  - **脾臟**：大部分其餘量
  - **骨髓**：少量（正常時不明顯）

##### 硫膠體掃描的肝臟異常 / Hepatic Abnormalities on Sulfur Colloid Scan

| 類型 | 病灶 | 說明 |
|---|---|---|
| **局灶性攝取減少** | 肝囊腫（最常見）、HCC、腺瘤、膿場 | 肝癌風險族群（肝硬化、肝炎）出現局灶性減少需提高警覺 |
| **局灶性攝取增加** | 局灶性結節性增生（FNH）、肝再生結節、Budd–Chiari 症候群 | FNH 因含 Kupffer 細胞通常與背景難區分；約 1/3 可出現「冷」缺損 |
| **膠體移位（Colloid shift）** | 脾臟與骨髓攝取增加 | 提示肝功能障礙，最常見於肝硬化 |
| **瀰漫性肺攝取** | 非特異性 | 可見於肝硬化、COPD 合併感染、Langerhans 細胞組織球增多症、高血清鋁 |

##### 局灶性結節性增生 / Focal Nodular Hyperplasia (FNH)

| 特性 | 說明 |
|---|---|
| **性質** | 良性肝臟腫瘤 |
| **硫膠體掃描表現** | 多變；最常見與背景肝臟無法區分（因含 Kupffer 細胞）；1/3 可呈現「冷」缺損 |
| **與腺瘤的鑑別** | 腺瘤**不含** Kupffer 細胞，永遠呈現冷缺損 |
| **HIDA 掃描** | FNH 含膽管小管，HIDA 應為陽性（可作為輔助檢查） |

### 臨床要點 / Clinical Key Points
> - 硫膠體掃描中，**局灶性攝取減少** 最常見原因為肝囊腫；HCC、腺瘤、膿場也可表現為冷缺損
> - **FNH** 為含 Kupffer 細胞的良性腫瘤，硫膠體掃描可能正常或呈現不同表現；HIDA 可輔助診斷
> - **膠體移位**（脾臟和骨髓攝取增加）為肝功能障礙的間接徵象，常見於肝硬化
> - 肝硬化病人出現**局灶性減少**需高度懷疑 HCC，並進一步以對比劑 CT/MRI 確認
