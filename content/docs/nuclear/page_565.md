# Nuclear Imaging - Page 565

## Text Content

### 甲狀腺影像 / Thyroid Imaging

#### 甲狀腺用放射性追蹤劑 / Thyroid Radiotracers

##### I-131（放射性碘-131）

| 特性 | 說明 |
|---|---|
| **射線類型** | β 粒子 + 364 keV γ 光子（僅 γ 光子用於成像） |
| **半衰期** | 8 天 |
| **來源** | 產生器（generator）製備 |
| **臨床應用** | **僅用於治療**（甲狀腺癌術後、 Graves 病、甲狀腺毒症） |

##### I-123（放射性碘-123）

| 特性 | 說明 |
|---|---|
| **衰變方式** | 電子捕獲 |
| **射線能量** | 159 keV γ 光子 |
| **半衰期** | 13 小時 |
| **來源** | 加速器（cyclotron）製備；昂貴 |
| **給藥途徑** | 口服 |
| **優點** | 甲狀腺影像品質佳，可測量甲狀腺攝取值 |

##### Tc-99m Pertechnetate（鎝-99m 過鍀酸鹽）

| 特性 | 說明 |
|---|---|
| **射線能量** | 140 keV γ 光子 |
| **半衰期** | 6 小時 |
| **給藥途徑** | 靜脈注射 |
| **與碘的差異** | 不被甲狀腺有機化（trapped），攝取後釋放入血池 |
| **甲狀腺攝取量** | 僅 1–5% 施打劑量 |
| **唾液腺** | 清晰顯影（與 I-123 不同） |
| **適應症** | 近期靜脈顯影劑後、需快速檢查、需 IV 給藥時 |

#### 懷孕與哺乳 / Pregnancy and Breastfeeding

| 製劑 | 懷孕 | 哺乳 |
|---|---|---|
| **所有甲狀腺追蹤劑** | 通過胎盤；胎兒碘攝取始於懷孕 12 週 | — |
| **I-131** | **禁忌** | 需永久停止哺乳 |
| **I-123** | 避免（相對） | 停止哺乳 2–3 天後可恢復 |
| **Tc-99m** | 避免（相對） | 停止哺乳 12–24 小時後可恢復 |

#### 病人準備 / Patient Preparation

- I-123 或 I-131 檢查/治療前需 **TSH 非抑制狀態**
- 停用甲狀腺素 **4 週**，或肌肉注射 **重組 TSH（rTSH）** 兩次

### 異位甲狀腺組織 / Ectopic Thyroid

| 類型 | 說明 |
|---|---|
| **舌頭甲狀腺 / Lingual thyroid** | 位於舌根的異位甲狀腺組織 |
| **甲狀腺卵巢囊腫 / Struma ovarii** | 卵巢畸胎瘤內含功能性甲狀腺組織（罕見） |
| **胸骨後甲狀腺 / Retrosternal thyroid** | 最常見於胸骨後甲狀腺腫（substernal goiter） |

### 臨床要點 / Clinical Key Points
> - **I-131 僅用於治療**（甲狀腺癌、甲狀腺毒症），不用於常規診斷成像
> - **I-123** 為甲狀腺診斷掃描的最佳選擇，可同時評估攝取值與形態
> - **Tc-99m pertechnetate** 適合需要快速結果或已注射顯影劑的病人，但影像品質較 I-123 差
> - 懷孕期間 **I-131 絕對禁忌**（通過胎盤且可被胎兒甲狀腺攝取）
> - 哺乳期接受 I-131 治療後需 **永久停止哺乳**
