# Nuclear Imaging - Page 555

## Text Content

### PET-CT（續）/ PET-CT (Continued)

#### CT 關聯 / CT Correlation

- 大多數現代 PET 檢查以 **PET-CT** 形式執行（兒科例外，可能僅做 PET 以減少 CT 輻射劑量）
- CT 通常使用較診斷型 CT 低的劑量；是否注射靜脈顯影劑依各機構Protocol 而異
- CT 的用途：**解剖定位** 與 **衰減校正**
- 高密度口服顯影劑或金屬植入物可能因衰減校正錯誤產生 **偽影**

#### 病人準備 / Patient Preparation

- FDG 攝取與 **血糖及胰島素濃度** 密切相關
- 胰島素升高會增加肌肉攝取、降低偵測輕度病灶的靈敏度
- 病人應**禁食（NPO）至少 4 小時**，使胰島素降至基礎濃度
- 血糖應控制在 **200 mg/dL 以下**，最好低於 150 mg/dL
- 注射 F-18 FDG 後，病人應在安靜房間休息 **60 分鐘**
  - 說話 → 聲帶 FDG 攝取
  - 走路 → 肌肉 FDG 攝取

#### 正常 FDG 分布 / Normal FDG Distribution

| 器官 / Organ | 正常攝取 / Normal Uptake |
|---|---|
| **腦 / Brain** | 強度攝取（大腦偏好葡萄糖）；可見皮質、基底核、小腦結構 |
| **腎臟、輸尿管、膀胱** | 強度攝取（FDG 經尿液排泄） |
| **唾液腺、扁桃腺、甲狀腺** | 輕至中度對稱攝取 |
| **肝臟 / Liver** | 中度 FDG 攝取，通常不均勻 |
| **腸道 / Bowel** | 瀰漫性輕至中度（正常）；**局灶性腸道攝取應提高警覺** |
| **心臟 / Heart** | 變異性大（取決於胰島素/葡萄糖狀態） |
| **肌肉 / Muscles** | 正常時低攝取；胰島素升高或運動後可增加 |
| **棕色脂肪 / Brown fat** | 代謝活躍；常見於鎖骨上區及肋間；寒冷時活性增加 |

> **Note:** Metformin（ metformin）可增加結腸及小腸 FDG 攝取

### 臨床要點 / Clinical Key Points
> - 熟悉 **正常生理分布** 是正確判讀的基礎；腎臟、膀胱的尿液排泄為正常強度攝取
> - 判讀前需確認病人 **血糖控制、禁食狀態、是否說話或走動**，以排除生理性攝取
> - **棕色脂肪攝取** 在寒冷環境或化療後常見，需與淋巴結或病灶鑑別
> - 乳癌病人在化療後需注意 **G-CSF 刺激** 導致的骨髓 FDG 攝取
