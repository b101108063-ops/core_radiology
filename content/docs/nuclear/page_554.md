# Nuclear Imaging - Page 554

## Text Content

### 正子發射電腦斷層 (PET-CT) / Positron Emission Tomography–Computed Tomography (PET-CT)

#### 基礎物理 / Basic PET Physics

- **PET 放射性追蹤劑**（radiotracer）發射正電子（positron），正電子在組織內移動極短距離後與電子碰撞，產生兩個 **511 keV 光子**，幾乎以 180 度相反方向前進
- 兩個高能光子同時被環形偵測器偵測，判定為符合事件（coincidence），可精確定位訊號來源

#### 放射性追蹤劑：氟-18 葡萄糖類似物 / Radiotracer: Fluorine-18 FDG

- **氟-18（F-18）** 為正電子發射體，半衰期 110 分鐘
- **F-18-氟去氧葡萄糖（F-18 FDG）** 為葡萄糖類似物，與葡萄糖競爭透過 **GLUT 1 及 GLUT 3 受體** 進入細胞
- 進入細胞後被磷酸化為 FDG-6-phosphate，但此產物無法進入糖解途徑，**被滞留在細胞內**

#### 攝取定量 / Uptake Quantification

- **標準化攝取值（SUV, Standardized Uptake Value）** 用於半定量分析 FDG 攝取
- **SUV 計算公式**：`SUV = (ROI 活性 × 體重) / 施打活性`
- SUV 受多種因素影響：設備種類、施打後時間、活性外滲情形、肌肉攝取、血糖與胰島素濃度等
- **SUV 不可作為診斷惡性腫瘤的唯一標準**
- 建議採用相對比值（相對於肝臟、小腦或基底核）來評估攝取程度：

| 相對攝取程度 | 與基底核相比 |
|---|---|
| **輕度 / Mild** | <20% |
| **中度 / Moderate** | 20–60% |
| **強度 / Intense** | >60% |

### 臨床要點 / Clinical Key Points
> - FDG 攝取反映的是 **細胞代謝活性**，而非單純的結構異常
> - SUV 數值需謹慎解讀，不同設備與時間點的 SUV **不可直接比較**
> - 低惡性度腫瘤（如支氣管肺泡細胞癌、類癌）可能 **FDG 陰性**，臨床上需注意假陰性
> - 活動性肉芽腫疾病（結核等）可能 FDG 陽性，需注意假陽性
