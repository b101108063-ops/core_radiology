# Thoracic Imaging - Page 84

## Text Content

### 氣道疾病 / Airways — Diffuse Non-Neoplastic Tracheal Disease

#### 瀰漫性氣管壁增厚的鑑別診斷 / Diffuse Non-Neoplastic Tracheal Thickening

| Tracheal Finding | Likely Diagnosis |
|---|---|
| **Nodular calcification** | **Tracheobronchopathia osteochondroplastica (TPO)** |
| **Smooth concentric thickening + sparing of posterior membrane** | **Relapsing polychondritis** |
| **Subglottic stenosis** | Relapsing polychondritis, amyloidosis |
| **Circumferential thickening** | Tuberculosis |
| **Irregular ± calcification** | TPO |
| **Perilymphatic nodules + hilar adenopathy** | **Sarcoidosis** |
| **+ Vasculitis signs** | **Wegener granulomatosis** |

---

### 復發性軟骨炎 / Relapsing Polychondritis

| Feature | Description |
|---|---|
| **Pathology** | Recurrent inflammation of cartilaginous structures (nose, ear, joints, larynx, trachea, bronchi) |
| **Airway involvement** | 50% of patients; **larynx and subglottic trachea** are most common sites |
| **Demographics** | Middle-aged women |
| **CT findings** | **Smooth tracheal/bronchial wall thickening**; **sparing of posterior membranous trachea**; increased attenuation to frank calcification |

---

### 骨軟骨生成性氣管病 / Tracheobronchopathia Osteochondroplastica (TPO)

| Feature | Description |
|---|---|
| **Pathology** | Multiple submucosal **calcified osteocartilaginous nodules** along tracheal walls |
| **Key CT finding** | **Nodular calcification** of tracheal walls |
| **Sparing** | Posterior membranous trachea (like relapsing polychondritis) |
| **Nature** | Benign |

### 鑑別要點 / Key Distinguishing Features

| Disease | Key CT Feature |
|---|---|
| **Relapsing polychondritis** | Smooth wall thickening; **spares posterior membrane** |
| **TPO** | **Nodular calcification** throughout tracheal wall |
| **Tuberculosis** | Circumferential thickening |
| **Sarcoidosis** | Tracheal stenosis + perilymphatic nodules + adenopathy |
| **Wegener granulomatosis** | Subglottic stenosis + pulmonary nodules/cavities |

### 臨床要點 / Clinical Key Points
> - **Relapsing polychondritis** spares the posterior membranous trachea because it lacks cartilage — always check for this pattern
> - **TPO** presents with nodular calcific deposits on the tracheal wall — benign condition that may be asymptomatic
> - **Subglottic tracheal stenosis** in a patient with systemic vasculitis symptoms → think **Wegener granulomatosis**
> - In diffuse tracheal disease, always check for associated findings (perilymphatic nodules → sarcoidosis; systemic vasculitis → WG)
