## Paget–Schroetter 症候群：鎖骨下靜脈壓迫 / Paget–Schroetter Syndrome: Subclavian Vein Compression

### 臨床特徵 / Clinical Features

- 又稱**上肢深部靜脈血栓或努力性血栓（Effort Thrombosis）**，常見於年輕、肌肉發達的男性。
- 鎖骨下靜脈在胸廓入口受到反覆機械性壓迫，進而形成急性血栓。

### 診斷 / Diagnosis

- **靜脈造影（Venography）**應於中立位及上肢外展位進行，以顯示姿勢相關壓迫。
- 建議雙側評估，以辨識對側潛在的解剖性狹窄。

### 治療 / Treatment

1. 急性期先行**導管溶栓（Catheter-Directed Thrombolysis）**清除血栓。
2. 隨後進行**胸廓出口手術減壓**，解除持續的機械壓迫。
3. 若仍有殘餘狹窄，應先完成減壓，再考慮**經皮腔內血管成形術（PTA）**。
4. 一般避免在未解除壓迫時放置支架，因持續機械應力會造成高失敗率、變形或斷裂。

---

## 臨床要點 / Clinical Key Points

- 年輕肌肉男性出現急性上肢腫脹與血栓時，應考慮 Paget–Schroetter 症候群。
- 診斷需比較中立位與外展位，並評估雙側鎖骨下靜脈。
- 標準策略是**先溶栓、再手術減壓**；殘餘狹窄於減壓後再行 PTA。
