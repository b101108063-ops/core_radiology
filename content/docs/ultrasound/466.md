### 手指創傷 / Finger Injuries

#### 錘狀指 / Mallet Finger

##### 臨床特點 / Clinical Features

- **錘狀指**為**伸肌腱**在遠節指骨處斷裂
- 由指尖直接撞擊引起
- 可伴發**遠節指骨撕脫骨折**

##### 診斷要點 / Diagnostic Key Points

- 臨床檢查：**遠端指間關節（DIP）**無法伸直
- X光評估撕脫骨折

---

#### 紐孔畸形 / Boutonniere Deformity

##### 臨床特點 / Clinical Features

- **紐孔畸形**為伸肌腱**中央束**在近節指骨處損傷
- 最常見於**類風濕性關節炎**，也可為創傷後
- 近端指間關節（PIP）通過外側 slips 脫出並嵌頓
- 導致**PIP屈曲**和**DIP過伸**

##### 鑑別診斷 / Differential Diagnosis

| 畸形 | 損傷位置 | 臨床表現 |
|---|---|---|
| **錘狀指** | 伸肌腱止點（遠節指骨） | DIP無法伸直 |
| **紐孔畸形** | 中央束（近節指骨） | PIP屈曲 + DIP過伸 |

---

#### 掌板骨折 / Volar Plate Fracture

##### 臨床特點 / Clinical Features

- **掌板骨折**是近節指骨掌側的**撕脫骨折**
- 由**過伸損傷**造成
- 常伴發**關節半脫位或脫位**

---

### 拇指創傷 / Thumb Injuries

#### Gamekeeper's（滑雪者）拇指 / Gamekeeper's (Skier's) Thumb

##### 臨床特點 / Clinical Features

- **Gamekeeper's拇指**為**尺側副韌帶（UCL）**在拇指近節指骨基底部損傷
- 由拇指被迫外展造成
- 可伴發**近節指骨基底部撕脫骨折**

##### 併發症 / Complications

- **Stener病灶**：UCL完全斷裂 + 內收肌筋膜嵌頓
- Stener病灶**必須手術治療**

##### 治療原則 / Treatment Principles

| 損傷類型 | 治療方式 |
|---|---|
| **部分撕裂** | 保守治療 |
| **完全撕裂/Stener病灶** | 手術治療 |

---

#### Bennett 骨折 / Bennett Fracture

##### 臨床特點 / Clinical Features

- **Bennett骨折**是拇指掌骨基底部**關節內骨折**
- 骨折線延伸至腕掌關節

---

#### Rolando 骨折 / Rolando Fracture

##### 臨床特點 / Clinical Features

- **Rolando骨折**是Bennett骨折的**粉碎性變異**
- 為拇指掌骨基底部**粉碎性關節內骨折**

##### 鑑別診斷 / Differential Diagnosis

| 骨折類型 | 特點 |
|---|---|
| **Bennett** | 簡單的關節內骨折 |
| **Rolando** | 粉碎性關節內骨折 |

---

### 腕骨創傷 / Carpal Injuries

#### 腕骨骨折分類 / Carpal Fracture Classification

| 骨折類型 | 臨床特點 |
|---|---|
| **舟狀骨骨折** | 最常見；近極骨折AVN風險高 |
| **月骨骨折** | 常為撕脫骨折 |
| **三角骨骨折** | 最佳顯現於側位片 |
| **大多角骨骨折** | 拇指負荷疼痛 |
| **鉤骨鉤骨折** | 腕部尺側疼痛 |

---

### 臨床要點 / Clinical Key Points

| 損傷 | 關鍵特徵 |
|---|---|
| **錘狀指** | DIP無法伸直；伸肌腱止點損傷 |
| **紐孔畸形** | PIP屈曲 + DIP過伸；類風濕性關節炎常見 |
| **Gamekeeper's拇指** | UCL損傷；Stener病灶需手術 |
| **Bennett** | 拇指掌骨基底部關節內骨折 |
| **Rolando** | 粉碎性Bennett骨折 |
| **舟狀骨骨折** | 最常見腕骨骨折；近極血供脆弱 |
