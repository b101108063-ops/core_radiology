### 舟月韌帶損傷 / Scapholunate Ligament Injury

#### 臨床特點 / Clinical Features

- **舟月韌帶損傷**是摔倒伸手扶地（FOOSH）造成的多種損傷模式之一
- **Terry Thomas徵**：舟月間距增寬（如60年代著名演員牙齒間隙）
  - 正常間距：<2-3mm
  - >3-4mm提示SL韌帶斷裂

#### 併發症 / Complications

- **舟月韌帶 advanced collapse（SLAC wrist）**
  - 慢性舟月韌帶損傷的後遺症
  - 可繼發於骨關節炎、CPPD關節病或慢性未治療的SL分離
  - 頭狀骨近端移位填補舟骨與月骨間的異常間隙

#### 影像學表現 / Imaging Findings

| 發現 | 描述 |
|---|---|
| **Terry Thomas徵** | 舟月間距增寬 |
| **SLAC腕關節** | 頭狀骨近端移位 |

---

### 舟狀骨骨折 / Scaphoid Fracture

#### 臨床特點 / Clinical Features

- **舟狀骨骨折**是最常見的腕骨骨折
- 典型由**摔倒伸手扶地（FOOSH）**機制造成

#### 血供與缺血性壞死 / Blood Supply and AVN Risk

| 區域 | 血供特點 | AVN風險 |
|---|---|---|
| **遠端** | 血供丰富 | 低 |
| **近極** | 骨內血供，脆弱 | **高** |

#### 診斷要點 / Diagnostic Key Points

- 舟狀骨血供為**遠端至近端**的骨內血供
- **近極骨折**AVN風險最高
- X光片可能漏診早期骨折；可疑時需CT或MRI

---

### 三角骨骨折 / Triquetral Fracture

#### 臨床特點 / Clinical Features

- **三角骨骨折**在腕部骨折中相對常見
- 通常為**背側撕脫骨折**
- 正位片可能**難以發現**

#### 影像學表現 / Imaging Findings

| 投照位置 | 顯現情況 |
|---|---|
| **正位片** | 可能正常或不明顯 |
| **側位片** | 三角骨背側可見**撕脫碎片**（最佳顯現位置） |

---

### Kienböck病 / Kienböck Disease

#### 定義 / Definition

- **Kienböck病**是月骨的**缺血性壞死（AVN）**

#### 臨床特點 / Clinical Features

- 與**負性尺骨方差**相關（尺骨短於橈骨）
- 病因認為是月骨負荷增加

#### 影像學分期 / Staging

| 分期 | 表現 |
|---|---|
| **I期** | X光正常；MRI可見信號改變 |
| **II期** | 月骨硬化 |
| **III期** | 月骨碎裂、塌陷 |
| **IV期** | 腕關節炎 |

#### 鑑別診斷 / Differential Diagnosis

| 疾病 | 涉及骨骼 | 關聯因素 |
|---|---|---|
| **Kienböck病** | 月骨 | 負性尺骨方差 |
| **Preiser病** | 舟狀骨 | 舟狀骨骨折史 |

---

### 臨床要點 / Clinical Key Points

| 疾病 | 關鍵特徵 |
|---|---|
| **SL韌帶損傷** | Terry Thomas徵；SLAC腕關節後遺症 |
| **舟狀骨骨折** | 最常見腕骨骨折；近極骨折AVN風險高 |
| **三角骨骨折** | 側位片背側撕脫碎片 |
| **Kienböck病** | 月骨AVN；負性尺骨方差 |
| **血供方向** | 舟狀骨：遠端→近端；近極AVN風險最高 |
