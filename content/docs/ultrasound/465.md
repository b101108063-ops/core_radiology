### 前臂骨折脫位 / Forearm Fracture-Dislocations

---

### Monteggia 骨折脫位 / Monteggia Fracture-Dislocation

#### 臨床特點 / Clinical Features

- **Monteggia骨折脫位**的特徵：
  - **尺骨骨折**（通常為中段骨幹）
  - **橈骨頭脫位**於肘關節

#### 影像學表現 / Imaging Findings

| 發現 | 描述 |
|---|---|
| 前臂X光 | **尺骨中段骨折** |
| 肘關節X光 | **橈骨頭脫位** |

#### 鑑別診斷 / Differential Diagnosis

- 需與**Essex-Lopresti骨折**區分：後者為橈骨頭骨折 + 尺骨遠端脫位

---

### Galeazzi 骨折脫位 / Galeazzi Fracture-Dislocation

#### 臨床特點 / Clinical Features

- **Galeazzi骨折**的特徵：
  - **橈骨骨折**（常為遠端1/3）
  - **尺骨遠端脫位**於遠端橈尺關節

#### 影像學表現 / Imaging Findings

| 發現 | 描述 |
|---|---|
| 前臂X光 | **橈骨遠端1/3骨幹骨折**，伴橈向和掌側成角及短縮 |
| 腕關節X光 | **尺骨遠端脫位** |

---

### Colles 骨折 / Colles Fracture

#### 臨床特點 / Clinical Features

- **Colles骨折**是最常見的前臂遠端損傷
- 定義：**橈骨遠端骨折**伴**背側成角**
- 典型由**FOOSH（伸手扶地）**機制造成
- 骨折通常為**關節內骨折**

#### 影像學評估 / Imaging Assessment

| 測量 | 正常值/異常 |
|---|---|
| 橈骨高度 | 丟失提示骨折移位 |
| 傾斜角度 | 背側成角為典型Colles骨折 |
| 關節面一致性 | 評估關節內骨折程度 |

---

### Hutchinson（司機）骨折 / Hutchinson (Chauffeur's) Fracture

#### 臨床特點 / Clinical Features

- **Hutchinson骨折**是橈骨遠端（外側）的骨折
- 骨折線延伸至**橈骨莖突**和**橈腕關節**
- 典型機制：被逆轉發動機把手撞擊

#### 影像學表現 / Imaging Findings

| 發現 | 描述 |
|---|---|
| 骨折位置 | **橈骨遠端外側**，延伸至莖突 |
| 關節受累 | 累及**橈腕關節** |

---

### 臨床要點 / Clinical Key Points

| 骨折類型 | 關鍵特徵 |
|---|---|
| **Monteggia** | 尺骨骨折 + 橈骨頭脫位 |
| **Galeazzi** | 橈骨骨折（遠端1/3）+ 尺骨遠端脫位 |
| **Colles** | 橈骨遠端骨折 + **背側成角**；FOOSH機制 |
| **Hutchinson** | 橈骨遠端外側骨折，延伸至莖突 |
| **最常見前臂遠端骨折** | **Colles骨折** |
