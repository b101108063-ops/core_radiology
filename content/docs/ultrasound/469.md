### 伸肌腱損傷 / Extension Tendon Injuries

#### 正常解剖 / Normal Anatomy

| 結構 | 描述 |
|---|---|
| **遠節指骨** | 伸肌腱止點 |
| **外側伸肌slips** | 會聚於遠節指骨基底 |
| **中節指骨** | 中央束附著處 |
| **伸肌腱中央束** | 附著於中節指骨基底 |

---

#### 錘狀指 / Mallet Finger

##### 臨床特點 / Clinical Features

- **錘狀指**為伸肌腱在**遠節指骨**處斷裂
- 由指尖直接撞擊引起
- 可伴發**遠節指骨撕脫骨折**（臨床重要區分）

##### 診斷要點 / Diagnostic Key Points

- 臨床檢查：**遠端指間關節（DIP）無法伸直**
- X光評估撕脫骨折

---

#### 紐孔畸形 / Boutonniere Deformity

##### 臨床特點 / Clinical Features

- **紐孔畸形**為伸肌腱**中央束**在**中節指骨**處損傷
- 最常見於**類風濕性關節炎**，也可創傷後發生
- 近端指間關節（PIP）通過外側slips脫出並嵌頓
- 導致**PIP屈曲**和**DIP過伸**

---

#### Gamekeeper's（滑雪者）拇指 / Gamekeeper's (Skier's) Thumb

##### 臨床特點 / Clinical Features

- **Gamekeeper's拇指**為**尺側副韌帶（UCL）**在拇指近節指骨基底損傷
- 由拇指被迫外展造成
- 可伴發**近節指骨基底部撕脫骨折**

##### 併發症 / Complications

- **Stener病灶**：UCL完全斷裂 + 內收肌筋膜嵌頓
- Stener病灶**必須手術治療**

##### 治療原則 / Treatment Principles

| 損傷類型 | 治療方式 |
|---|---|
| **部分撕裂** | 保守治療 |
| **完全撕裂/Stener病灶** | 手術治療 |

### 掌骨骨折 / Metacarpal Fractures

#### Bennett 骨折 / Bennett Fracture

- **Bennett骨折**是拇指掌骨基底部**關節內骨折**

#### Rolando 骨折 / Rolando Fracture

- **Rolando骨折**是Bennett骨折的**粉碎性變異**

#### Boxer's 骨折 / Boxer's Fracture

- **Boxer's骨折**是**第5掌骨頸骨折**
- 最常見的掌骨頸骨折

#### 掌板骨折 / Volar Plate Fracture

- **掌板骨折**是近節指骨掌側的**撕脫骨折**
- 由**過伸損傷**造成

---

### 臨床要點 / Clinical Key Points

| 損傷 | 關鍵特徵 |
|---|---|
| **錘狀指** | DIP無法伸直；遠節指骨伸肌腱止點損傷 |
| **紐孔畸形** | PIP屈曲 + DIP過伸；中央束損傷 |
| **Gamekeeper's拇指** | UCL損傷；Stener病灶需手術 |
| **Bennett** | 拇指掌骨基底部關節內骨折 |
| **Rolando** | 粉碎性Bennett骨折 |
| **Boxer's** | 第5掌骨頸骨折；格鬥/拳擊常見 |
