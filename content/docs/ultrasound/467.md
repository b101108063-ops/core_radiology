### 腕骨解剖 / Carpal Bone Anatomy

#### 腕骨名稱 / Carpal Bone Names

| 排 | 腕骨（由橈側至尺側） |
|---|---|
| **近端排** | 舟狀骨、月骨、三角骨、豌豆骨 |
| **遠端排** | 大多角骨、小多角骨、頭狀骨、鉤骨 |

#### 腕骨示意圖 / Carpal Anatomy Diagram

| 結構 | 位置描述 |
|---|---|
| **舟狀骨** | 最常骨折的腕骨；跨越近遠端排 |
| **頭狀骨** | 最大腕骨；位於遠端排中心 |
| **月骨** | 近端排尺側；易發生Kienböck病 |
| **鉤骨鉤** | 腕管尺側；觸診為腕部豆狀骨遠端 |

### Gilula弧 / Arcs of Gilula

#### 定義 / Definition

- **Gilula弧**是腕關節正位片上繪製的三個弧線
- 用於評估腕骨排列和韌帶損傷

#### 正常表現 / Normal Appearance

- 三個弧線應**平滑連續**
- 弧線中斷可能是**韌帶損傷或骨折**的表現

#### 異常表現 / Abnormal Findings

| 發現 | 意義 |
|---|---|
| **弧線不連續** | 腕骨間韌帶損傷（SL斷裂） |
| **腕骨脫位** | 外傷性脫位 |

### 月骨與月骨周圍脫位 / Lunate and Perilunate Dislocation

#### 定義 / Definitions

| 脫位類型 | 定義 |
|---|---|
| **月骨周圍脫位（Perilunate）** | 月骨與橈骨排列正常，但頭狀骨與月骨排列中斷。脫位在月骨*旁邊* |
| **月骨脫位（Lunate）** | 月骨本身脫位（通常掌側），頭狀骨與橈骨仍相對排列正常 |

#### 影像學比較 / Imaging Comparison

| 脫位類型 | 月骨位置 | 頭狀骨位置 | 橈骨關係 |
|---|---|---|---|
| **正常排列** | 與橈骨對齊 | 與月骨對齊 | 三者成一線 |
| **月骨周圍脫位** | 與橈骨對齊 | 與月骨排列中斷 | 月骨-橈骨正常 |
| **月骨脫位** | 掌側脫位 | 與橈骨對齊 | 月骨-橈骨中斷 |

#### 診斷要點 / Diagnostic Key Points

- **月骨周圍脫位**：月骨留在原位（與橈骨對齊），頭狀骨移位
- **月骨脫位**：月骨本身脫位（掌側），頭狀骨與橈骨對齊
- 側位片是區分兩者的關鍵

#### 臨床意義 / Clinical Significance

- 月骨周圍脫位為**高能量創傷**
- 常伴發**舟月韌帶斷裂**
- 若漏診可導致**慢性腕關節不穩定**

---

### 臨床要點 / Clinical Key Points

| 要點 | 說明 |
|---|---|
| **Gilula弧** | 三個平滑弧線；中斷提示韌帶損傷 |
| **月骨周圍脫位** | "Peri"=旁邊；頭狀骨脫位，月骨留在原位 |
| **月骨脫位** | 月骨本身掌側脫位 |
| **側位片** | 區分兩種脫位的關鍵位置 |
| **高能量創傷** | 月骨周圍/脫位需排除其他伴發損傷 |
