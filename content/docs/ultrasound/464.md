### 肘關節脫位 / Elbow Dislocation

#### 臨床特點 / Clinical Features

- **後脫位**是最常見的肘關節脫位類型，橈骨和尺骨同時向後脫位於肱骨
- 常伴發**尺骨骨折**，這些骨折可能比標準肘部X光片所能顯示的更遠端
- 肘關節脫位時應拍攝**前臂X光片**以評估伴發骨折

---

### 橈骨頭骨折 / Radial Head Fracture

#### 臨床特點 / Clinical Features

- **橈骨頭骨折**是成人最常見的肘部骨折
- **脂肪墊徵（Fat Pad Sign）**：因肘關節積液導致前方和/或後方脂肪墊抬高
  - 後方脂肪墊抬高幾乎是骨折的診斷性表現（成人最常見為橈骨頭骨折）
  - **船徵（Sail Sign）**：僅前方脂肪墊抬高，對骨折的特異性較低

#### 診斷要點 / Diagnostic Key Points

- 若發現脂肪墊徵但X光片未見骨折，應拍攝額外視圖（通常為橈骨頭）或行**CT檢查**

---

### 髁上骨折 / Supracondylar Fracture

#### 臨床特點 / Clinical Features

- **髁上骨折**是兒童最常見的肘部骨折

---

### Essex-Lopresti 骨折脫位 / Essex-Lopresti Fracture-Dislocation

#### 臨床特點 / Clinical Features

- **Essex-Lopresti骨折脫位**包含三個要素：
  1. **橈骨頭骨折**
  2. **骨間膜撕裂**
  3. **遠端橈尺關節尺骨脫位**

#### 影像學表現 / Imaging Findings

| 發現 | 描述 |
|---|---|
| 前臂遠端X光 | 遠端橈尺關節**尺骨（內側）脫位** |
| 肘關節X光 | **無移位或輕微移位的橈骨頭骨折** |

#### 鑑別診斷 / Differential Diagnosis

| 損傷類型 | 特點 |
|---|---|
| **Monteggia骨折** | 尺骨骨折 + 橈骨頭脫位 |
| **Galeazzi骨折** | 橈骨骨折（遠端1/3）+ 尺骨遠端脫位 |
| **Essex-Lopresti** | 橈骨頭骨折 + 骨間膜撕裂 + 遠端尺骨脫位 |

---

### 臨床要點 / Clinical Key Points

| 要點 | 說明 |
|---|---|
| **脂肪墊徵** | 後方脂肪墊抬高幾乎診斷骨折；前方單獨抬高為船徵 |
| **兒童最常見** | 髁上骨折 |
| **成人最常見** | 橈骨頭骨折 |
| **Essex-Lopresti** | 需同時評估前臂和腕關節 |
