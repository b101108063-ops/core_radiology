# Neuroimaging - Page 226

![Page 226](/core_radiology/images/neuro/page-226.png)

## 囊性腫瘤伴強化壁結節 / Tumors with a Cyst and an Enhancing Nodule

### 概覽 / Overview

- 少數低級別、分泌液體的腫瘤可呈現為囊性腫塊伴強化壁結節

---

### 毛細血管母細胞瘤 / Hemangioblastoma

| 特徵 | 說明 |
|---|---|
| **WHO分級** | I級（良性）|
| **血管性** | 高度血管性腫瘤 |
| **與VHL的關聯** | 與** von Hippel-Lindau（VHL）綜合徵**相關 |
| **VHL患者比例** | 僅30%的血管母細胞瘤患者有VHL；VHL患者預後更差 |
| **好發位置** | 小腦、延髓、脊髓；顱內罕見 |
| **經典型影像** | 囊性腫塊伴強化壁結節；可見管狀流空血管（流空效應）|
| **其他表現** | 少數可為實性或出血性 |
| **脊髓血管母細胞瘤** | 常伴發**脊髓空洞**（syrinx）|

---

### 多形性黃色星形細胞瘤 / Pleomorphic Xanthoastrocytoma (PXA)

| 特徵 | 說明 |
|---|---|
| **WHO分級** | II級（低級別星形細胞瘤變異型）|
| **好發人群** | 兒童和青少年；典型病史為**慢性癲癇** |
| **最常見位置** | 顳葉；典型為幕上皮層囊性腫塊伴強化壁結節 |
| **硬膜特徵** | 覆蓋的硬膜可增厚並強化 |
| **周圍水腫** | 與病變大小相比，水腫相對輕微 |
| **主要鑑別診斷** | **神經節膠質瘤**（ganglioglioma）；但神經節膠質瘤通常不引起硬膜增厚 |

---

### 神經節膠質瘤 / Ganglioglioma

| 特徵 | 說明 |
|---|---|
| **腫瘤本質** | 罕見的緩慢生長神經膠質腫瘤 |
| **好發人群** | 青少年或年輕成人；典型表現為**藥物難治性顳葉癲癇** |
| **經典型影像** | 顳葉囊性腫塊伴強化壁結節；常伴有鈣化；可引起顱骨重塑和壓跡 |

---

### 囊性腫塊伴強化結節的鑑別診斷 / Differential Diagnosis

| 腫瘤 | 與結節膠質瘤的區別 |
|---|---|
| **JPA** | 後顱窩；兒童；視覺通路與NF1相關 |
| **血管母細胞瘤** | 小腦；成人；與VHL相關；高度血管性（有流空血管）|
| **PXA** | 顳葉；青少年；硬膜增厚強化 |
| **神經節膠質瘤** | 顳葉；年輕成人；癲癇；可見顱骨重塑 |

### 臨床要點 / Clinical Key Points

> - **血管母細胞瘤**：高度血管性囊性腫瘤；小腦最常見；與VHL綜合徵相關（30%患者）；有流空血管
> - **PXA**：顳葉囊性＋強化結節；青少年；慢性癲癇；硬膜增厚是特點
> - **神經節膠質瘤**：年輕成人顳葉癲癇；囊性＋結節＋鈣化
> - 囊性腫塊伴強化結節的組合：JPA、血管母細胞瘤、PXA、神經節膠質瘤
