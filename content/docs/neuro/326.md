# Neuroimaging - Page 326

![Page 326](/core_radiology/images/neuro/page-326.png)

## 先天性眼球病變 / Congenital Orbital Lesions

---

### 持續性原始玻璃體增生症 / Persistent Hyperplastic Primary Vitreous (PHPV)

| 特徵 | 說明 |
|---|---|
| **本質** | 玻璃體內持續存在的胚胎血管膜導致出血、白內障、視網膜脫離 |
| **患者特點** | 通常為足月嬰兒 |
| **超聲/MRI所見** | 眼球小（microphthalmia）；玻璃體密度增加 |
| **與視網膜母細胞瘤/ROP的鑑別** | **無鈣化** |

---

### 眼球缺損 / Coloboma

| 特徵 | 說明 |
|---|---|
| **本質** | 胚胎期眼球溝閉合不全所致 |
| **超聲所見** | 錐形或切跡形畸形 |

### 眼球缺損的類型 / Types

| 類型 | 位置 |
|---|---|
| **視神經缺損** | 向後突出的囊 |
| **虹膜缺損** | 前方 |
| **葡萄膜缺損** | 常伴小眼球和囊腫 |

### 眼球缺損的關聯綜合徵 / Associated Syndromes

| 綜合徵 | 說明 |
|---|---|
| **13/18三體** | 染色體異常 |
| **CHARGE關聯** | 先天發育異常 |
| **VATER關聯** | 先天發育異常 |

---

### 蝶骨翼發育不良 / Sphenoid Wing Dysplasia

| 特徵 | 說明 |
|---|---|
| **關聯** | 神經纖維瘤病1型（NF1）|
| **特點** | 腦脊液搏動通過蝶骨翼缺損傳遞 |
| **典型表現** | 搏動性眼球突出 |

---

### 隔離-視神經發育不良 / Septo-Optic Dysplasia

| 特徵 | 說明 |
|---|---|
| **本質** | 視神經發育不全＋透明隔缺如 |
| **常見並發** | 腦裂畸形（schizencephaly）|

### 腦裂畸形 / Schizencephaly

| 特徵 | 說明 |
|---|---|
| **本質** | 大腦半球的完全厚度裂隙 |
| **結果** | 腦室與蛛網膜下腔相通 |

### 臨床要點 / Clinical Key Points

> - **PHPV**：無鈣化的小眼球；與視網膜母細胞瘤和ROP鑑別
> - **眼球缺損**：與13/18三體、CHARGE、VATER關聯
> - **蝶骨翼發育不良**：NF1的特徵；搏動性眼球突出
> - **隔離-視神經發育不良**：透明隔缺如＋視神經發育不全；常伴腦裂畸形
