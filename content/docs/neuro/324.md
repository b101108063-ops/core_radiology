## 甲狀腺眼病 / Thyroid Eye Disease

### 甲狀腺眼病的病理生理 / Pathophysiology

| 特徵 | 說明 |
|---|---|
| **本質** | 甲狀腺相關眼眶炎症；由淋巴細胞產透明質酸介導 |
| **演變** | 眼眶脂肪增加→眼外肌增大→纖維化 |
| **好發順序** | I'M SLOW |

### 甲狀腺眼病特徵 / Features

| 特徵 | 說明 |
|---|---|
| **好發人群** | 甲狀腺功能異常者（Graves病）|
| **眼眶脂肪增加** | 炎症早期改變 |
| **眼外肌增大** | 炎症後期 |
| **眼球突出** | 常見 |
| **眼外肌受累** | 下直肌→內直肌→上直肌→外直肌 |

### 甲狀腺眼病與假瘤的鑑別 / Differential

| 特徵 | 甲狀腺眼病 | 假瘤 |
|---|---|---|
| **疼痛** | **無痛** | 疼痛 |
| **雙側性** | 常見 | 通常單側 |
| **肌腱受累** | **保留** | **受累** |
| **治療** | 皮質類固醇（臨時）；手術 | 皮質類固醇 |

### 甲狀腺眼病的手術治療 / Surgical Treatment

| 適應症 | 說明 |
|---|---|
| **20%需手術** | 皮質類固醇無效時 |
| **眼眶減壓手術** | 解除視神經在眶尖受壓 |
| **眼眶減壓術** | 眶壁移除解除眶尖壓力 |

### 甲狀腺眼病的神經影像 / Neuroimaging

| 序列 | 所見 |
|---|---|
| **CT/MRI** | 眼外肌增大（肌腹增大，肌腱保留）|
| **冠狀位** | 評估眼外肌大小 |

### 臨床要點 / Clinical Key Points

> - **甲狀腺眼病**：I'M SLOW記憶順序；肌肉增大但保留肌腱是與假瘤的關鍵區別
> - **眼球突出**：甲狀腺眼病的常見臨床表現
> - 20%患者最終需要手術治療
