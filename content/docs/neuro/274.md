# Neuroimaging - Page 274

![Page 274](/core_radiology/images/neuro/page-274.png)

## 其他出血病因 / Additional Hemorrhage Etiologies

---

### 海綿狀血管畸形 / Cavernous Malformation

| 特徵 | 說明 |
|---|---|
| **本質** | 血管錯構瘤，由無正常腦組織介入的低流量內皮襯覆血管組成 |
| **非出血性特徵** | MRI特徵性「爆米花樣」混合高信號（T1/T2）；周圍含鐵血黃素暗環 |
| **出血後MRI** | 出血性血腫的MRI特徵非特異 |
| **確診線索** | 增強圖像上與血腫相鄰的DVA提示近期海綿狀血管畸形出血 |
| **血管造影** | 無確診作用；海綿狀血管畸形在血管造影上隱匿 |

---

### 梗塞的出血性轉化 / Hemorrhagic Transformation of Infarct

| 特徵 | 說明 |
|---|---|
| **臨床識別** | 多數情況下，卒中的臨床或影像診斷在出血轉化前已確立 |
| **自發性出血** | 少數情況下，出血可為梗塞的首發表現 |
| **溶栓後出血** | 約**6-12%**接受血栓溶解治療的患者可發生有症狀的出血 |
| **CT風險因素** | 相對較大的低衰減區和粗大动脉徵提示溶栓後出血風險 |

> **注意**：根據AHA指南，這些發現都不是靜脈tPA的排除標準

---

### 中樞神經系統血管炎 / CNS Vasculitis

| 特徵 | 說明 |
|---|---|
| **本質** | 可為原發性或全身性血管炎的繼發性 |
| **最常見表現** | 腦缺血；少數可表現為明顯出血 |
| **標準MRI所見** | 基底節和皮層下白質多發T2延長區 |
| **血管成像** | CTA/MRA對小血管受累相對不敏感；可顯示大/中等血管的不規則 |
| **確診** | 血管造影是最敏感檢查，顯示多發性狹窄和擴張 |

---

### 煙霧病 / Moyamoya

| 特徵 | 說明 |
|---|---|
| **本質** | 非粥樣硬化性血管病，進行性顱內頸總動靜脈及其近端分支狹窄，導致豆紋側支血管增增殖 |
| **血管造影特徵** | 增大的基底穿通支呈「一縷煙霧」外觀 |
| **MRI所見** | **常春藤徵（Ivy sign）**：FLAIR上溝回內管狀分支高信號結構，代表慢側支血流 |
| **動靜脈瘤** | 煙霧病患者易患動靜脈瘤（尤其後循環）|
| **灌注研究** | 受累血管區域血流量降低 |

### 煙霧病的影像學特徵 / Key Moyamoya Features

| 特徵 | 說明 |
|---|---|
| **顱內ICA近端狹窄** | 進行性 |
| **側支循環** | 豆紋穿通支增殖（煙霧外觀）|
| **常春藤徵** | FLAIR上慢血流的高信號 |

### 臨床要點 / Clinical Key Points

> - **海綿狀血管畸形**：MRI爆米花樣；與相鄰DVA提示近期出血
> - **梗塞出血性轉化**：6-12%溶栓後可發生；粗大动脉徵是CT風險因素
> - **煙霧病**：進行性顱內ICA狹窄＋豆紋側支（煙霧）＋常春藤徵
> - **血管炎**：多發T2延長（深白質/基底節）；血管造影確診
> - 出血病因鑑別需結合**年齡＋位置＋基礎疾病**
