# Neuroimaging - Page 336

![Page 336](/core_radiology/images/neuro/page-336.png)

## 頸部淋巴結分區 II / Cervical Lymph Node Levels II

### AJCC頸部淋巴結分區回顧 / AJCC System Review

| 分區 | 位置 | 邊界標誌 |
|---|---|---|
| **IA** | 頦下區 | 兩側二腹肌前腹之間 |
| **IB** | 下頜下區 | 下頜下腺後緣內側 |
| **IIA** | 頸靜脈上區（前側）| 頸內靜脈前方 |
| **IIB** | 頸靜脈上區（後側）| 頸內靜脈後方、胸鎖乳突肌前方 |
| **III** | 頸靜脈中區 | 舌骨至環狀軟骨 |
| **IV** | 頸靜脈下區 | 環狀軟骨至鎖骨 |
| **VA/VB** | 副神經區 | 斜角肌後方至鎖骨 |
| **VI** | 氣管前區 | 舌骨至胸骨柄上緣 |
| **VII** | 上縱隔區 | 胸骨柄至頭臂靜脈 |

### 淋巴結分區的解剖標誌 / Anatomic Landmarks

| 標誌 | 相關分區 |
|---|---|
| **舌骨** | II/III分界 |
| **環狀軟骨** | III/IV、VA/VB分界 |
| **鎖骨** | IV、VB下界 |
| **胸鎖乳突肌後緣** | IIB/III/IV後界 |
| **前斜角肌後緣** | VB下界 |

### 淋巴結大小標準 / Size Criteria

| 淋巴結 | 短軸直徑 |
|---|---|
| **大多數頸部LN** | >10-15mm |
| **頸靜脈二腹肌LN** | >8mm |

### 鱗狀細胞癌的淋巴結分期 / SCC Staging

| N分期 | 標準 |
|---|---|
| **NX** | 無法評估 |
| **N0** | 無淋巴結轉移 |
| **N1** | 單側單個<3cm |
| **N2** | >3cm或多個 |

### 臨床要點 / Clinical Key Points

> - **頸部淋巴結分區IA-VII**：對鱗狀細胞癌分期至關重要
> - **鱗狀細胞癌**：90%的頭頸部惡性腫瘤
> - **單個轉移淋巴結**：生存率降低50%
> - 淋巴結狀況是頭頸部癌症最重要的預後因素
