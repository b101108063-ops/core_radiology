# Neuroimaging - Page 239

![Page 239](/core_radiology/images/neuro/page-239.png)

## 鞍上區腫塊 / Suprasellar Mass

### 概述 / Overview

| 特徵 | 說明 |
|---|---|
| **鞍上區兒童最常見** | **顱頜囊瘤** |
| **鞍上區成人最常見** | **垂體大腺瘤**（向上延伸）|

### SATCHMO記憶口號 / Mnemonic

| 字母 | 病因 |
|---|---|
| **S** | **S**arcoidosis / 腺瘤的鞍上延伸 |
| **A** | **A**neurysm（動靜脈瘤）|
| **T** | **T**eratoma（畸胎瘤）/ Tolosa Hunt |
| **C** | **C**raniopharyngioma / **C**left cyst（Rathke裂囊腫）|
| **H** | Hypothalamic glioma（成人）/ Hypothalamic hamartoma（兒童）|
| **M** | **M**eningioma / **M**etastasis |
| **O** | **O**ptic nerve glioma |

---

### 顱頜囊瘤 / Craniopharyngioma

| 特徵 | 說明 |
|---|---|
| **本質** | 兒童**最常見的鞍上區病變**；起源於Rathke囊的鱗狀上皮殘留（產生角蛋白）|
| **年齡分布** | 雙峰分布；多數為兒童期病變；也可見於晚年中年人 |
| **位置** | 多數同時累及鞍內和鞍上區；可僅限於鞍內，但幾乎總是與垂體分開 |
| **病理特徵** | 可有牙釉質產生；**幾乎總是鈣化** |
| **囊內液** | 典型囊內為「**機器油**」外觀（由脫屑鱗狀上皮、角蛋白和膽固醇組成）|

### 顱頜囊瘤的MRI特徵 / MRI Features of Craniopharyngioma

| 特徵 | 說明 |
|---|---|
| **囊性成分** | T1高信號（若含蛋白或血液）|
| **實性成分** | 強化 |
| **囊壁/實性元素** | **明顯強化** |
| **CT特徵** | 鞍上區低衰減腫塊伴**粗大鈣化** |

### 顱頜囊瘤 vs Rathke裂囊腫 / Craniopharyngioma vs Rathke's Cleft Cyst

| 特徵 | 顱頜囊瘤 | Rathke裂囊腫 |
|---|---|---|
| **強化** | **幾乎總是強化** | 不強化（可有邊緣強化）|
| **鈣化** | **幾乎總是鈣化** | **不鈣化** |
| **與垂體關係** | **幾乎總是與垂體分開** | 可與垂體融合 |
| **囊內液** | 機器油（含角蛋白/膽固醇）| 取決於蛋白含量 |

---

### 鞍上區病變的年齡分布 / Age-Based Differential

| 人群 | 最常見鞍上病變 |
|---|---|
| **兒童** | **顱頜囊瘤** |
| **成人** | 垂體大腺瘤（向上延伸）|

---

### 臨床要點 / Clinical Key Points

> - **顱頜囊瘤**：兒童最常見鞍上病變；**雙峰年齡分布**；幾乎總是鈣化和強化
> - **機器油囊液**：顱頜囊瘤的特徵性囊內內容物
> - 顱頜囊瘤與Rathke裂囊腫的關鍵鑑別：**強化＋鈣化 vs 無強化無鈣化**
> - SATCHMO口號有助於記憶鞍上區病變譜
> - 鞍上區成人：垂體大腺瘤向上延伸最常見
