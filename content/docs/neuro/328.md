# Neuroimaging - Page 328

![Page 328](/core_radiology/images/neuro/page-328.png)

## 頸動靜脈隙 / Carotid Space

### 頸動靜脈隙解剖 / Anatomy

| 特徵 | 說明 |
|---|---|
| **位置** | 莖突後咽旁間隙（或稱頸動靜脈隙）|
| **範圍** | 從顱底至主動脈弓 |
| **內容物** | 頸總動靜脈、頸總體、顱神經（IX、X、XI、XII）|

### 通過頸動靜脈隙的顱神經 / Cranial Nerves

| 神經 | 說明 |
|---|---|
| **迷走神經（X）** | 全程在頸動靜脈隙內走行至胸腔（唯一）|
| **舌咽神經（IX）** | 僅通過頸動靜脈隙的一部分 |
| **副神經（XI）** | 僅通過頸動靜脈隙的一部分 |
| **舌下神經（XII）** | 僅通過頸動靜脈隙的一部分 |

### 頸動靜脈間隙的血管位移模式 / Vascular Displacement Patterns

| 病變來源 | 位移方向 |
|---|---|
| **頸總體瘤** | 分開頸內和頸外動靜脈 |
| **迷走球瘤** | 頸內/頸外動靜脈向前向內移位 |
| **神經鞘瘤** | 與迷走球瘤相似的位移模式 |

---

### 頸動靜脈隙腫瘤的鑑別 / Differential

| 腫瘤 | 特點 |
|---|---|
| **副神經節瘤** | 高血管性；「鹽和胡椒」MRI；明顯強化 |
| **神經鞘瘤** | 較低血管性；MRI信號多變 |
| **神經纖維瘤** | NF1相關；與神經鞘瘤MRI難以區分 |

### 副神經節瘤 vs 神經鞘瘤 / Paraganglioma vs Schwannoma

| 特徵 | 副神經節瘤 | 神經鞘瘤 |
|---|---|---|
| **血管性** | 高（明顯強化）| 較低 |
| **強化模式** | 均勻強化 | 不均勻強化 |
| **流空效應** | 典型（鹽和胡椒）| 無 |

### 頸動靜脈隙的淋巴結 / Lymph Nodes

| 說明 | 內容 |
|---|---|
| **淋巴結位置** | 頸動靜脈隙周圍 |
| **隙內淋巴結** | **沒有** |

### 臨床要點 / Clinical Key Points

> - **頸動靜脈隙**：頸內/頸外動靜脈+顱神經IX-XII
> - **迷走神經是唯一**全程在頸動靜脈隙內的神經
> - **副神經節瘤**：高血管性；「鹽和胡椒」特徵；沿CN X播散
> - 血管位移模式是頸動靜脈隙腫塊鑑別診斷的關鍵
