# Neuroimaging - Page 313

![Page 313](/core_radiology/images/neuro/page-313.png)

## 岩骨尖 / Petrous Apex

### 岩骨尖解剖 / Anatomy

| 特徵 | 說明 |
|---|---|
| **位置** | 顱骨最內側部分 |
| **鄰近結構** | Dorello管（CN VI）、Meckel腔、顱內頸總動靜脈 |
| **正常成分** | 骨髓和密質骨；約10%有氣化 |

### 膽固醇囊腫 / Cholesterol Cyst (Cholesterol Granuloma)

| 特徵 | 說明 |
|---|---|
| **本質** | 對膽固醇結晶的異物巨細胞反應 |
| **機制** | 初始由阻塞氣房引發（氣化尖更常見）|
| **MRI** | 擴張性腫塊；內部出血；在脂肪抑制上不抑制 |
| **發病率** | 最常見的原發岩骨尖病變 |

---

### 岩尖炎 / Apical Petrositis

| 特徵 | 說明 |
|---|---|
| **本質** | 傳染性乳突炎並發症；感染向內側延伸至氣化岩骨尖 |
| **Gradenigo三聯徵** | 乳突炎＋三叉神經痛（Meckel腔CN V）＋外展神經麻痹（Dorello管）|
| **CT所見** | 岩骨尖氣房混濁＋骨質脫礦和吸收 |
| **MRI** | 強化 |

### 先天性膽脂瘤 / Congenital Cholesteatoma

| 特徵 | 說明 |
|---|---|
| **位置** | 岩骨尖（不同於後天性的中耳）|
| **MRI** | 受限擴散 |

---

### 神經鞘瘤 / Schwannoma

| 特徵 | 說明 |
|---|---|
| **起源** | CN V、VII或VIII |
| **MRI** | 境界清楚的擴張性強化腫塊；可並囊性變 |

### Langerhans細胞組織細胞增生症 / Langerhans Cell Histiocytosis

| 特徵 | 說明 |
|---|---|
| **本質** | 嗜酸細胞和Langerhans細胞的腫瘤性增生 |
| **CT** | 界限清楚的溶骨性病變，無骨硬化邊 |
| **MRI** | 軟組織腫塊伴周圍水腫；明顯強化 |

### 臨床要點 / Clinical Key Points

> - **岩骨尖囊腫**：T1高信號；脂肪抑制不抑制；最常見岩骨尖病變
> - **Gradenigo三聯徵**：乳突炎＋CN V痛＋CN VI麻痹
> - **神經鞘瘤**：邊界清的強化腫塊；可囊性變
> - 10%岩骨尖有氣化→增加膽固醇囊腫和岩尖炎的風險
