# Neuroimaging - Page 260

![Page 260](/core_radiology/images/neuro/page-260.png)

## 梗塞各期的影像學特徵 / Imaging Features by Stage

---

### 急性期（6-72小時）/ Acute Infarct (6-72 hours)

| 特徵 | 說明 |
|---|---|
| **血管性水腫增加** | 血管內皮細胞損傷導致細胞外液滲漏 |
| **出血風險增加** | 受損內皮增加顱內出血風險 |
| **影像所見** | 腦溝消失增加、佔位效應；佔位效應在3-4天達峰 |
| **MRI** | T2高信號（灰質為主）；FLAIR最佳顯示；DWI持續擴散受限 |
| **灌注** | 梗塞核心擴大，半暗帶縮小 |

---

### 早期亞急性期（1.5-5天）/ Early Subacute Infarct

| 特徵 | 說明 |
|---|---|
| **側支循環建立** | 軟膜側支循環重建受累區血流；新血管長入壞死區 |
| **新血管特點** | 不完整BBB→持續血管性水腫增加；佔位效應達峰 |
| **MRI** | T2高信號**同時累及灰質和白質**（對比急性期僅灰質）|
| **ADC** | 不再暗或因水腫而恢復；DWI仍亮（T2穿透效應）|
| **灌注** | 梗塞核心持續擴大，半暗帶進一步縮小 |

---

### 晚期亞急性期（5天-2週）/ Late Subacute Infarct

| 特徵 | 說明 |
|---|---|
| **水腫消退** | 血管性水腫和佔位效應消退是本期特徵 |
| **腦迴強化** | 關鍵影像學所見（可類似腫瘤）；但典型無顯著佔位效應 |
| **強化窗口** | 初始事件後約**6天至6週**可見強化 |

### 強化規則：2-2-2規則 / Enhancement Rule: "2-2-2" Rule

| 時間點 | 說明 |
|---|---|
| **2天** | 強化開始 |
| **2週** | 強化達峰 |
| **2月** | 強化消失 |

---

### 慢性期 / Chronic Infarct

| 特徵 | 說明 |
|---|---|
| **壞死組織清除** | 巨噬細胞清除細胞碎屑；被囊性腦軟化和膠質替代 |
| **Wallerian變性** | 皮質脊髓束受累時可致同側大腦腳和橋腦腹側萎縮 |
| **DWI** | 通常恢復正常 |
| **皮層層狀壞死** | 少數情況下可發生（替代腦軟化）；T1和T2均高信號（脂質負荷巨噬細胞沉積）|

### 各期鑑別要點 / Differential by Stage

| 分期 | 需鑑別的疾病 |
|---|---|
| **亞急性期腦迴強化** | 腫瘤（但腫瘤通常有佔位效應+強化）|
| **佔位效應+強化同時存在** | 需排除腫瘤、感染 |
| **慢性期軟化囊** | 需與囊性腫瘤、術後改變鑑別 |

### 臨床要點 / Clinical Key Points

> - **急性期**：佔位效應增加+出血風險→監測顱內壓
> - **早期亞急性**：T2高信號**從灰質擴展到白質**是特點；佔位效應達峰
> - **晚期亞急性**：腦迴強化≠腫瘤（無顯著佔位效應）；強化「2-2-2」規則
> - **慢性期**：囊性腦軟化形成；DWI恢復正常；注意Wallerian變性
> - **強化+顯著佔位效應共存**：需考慮非單純梗塞的其他診斷
