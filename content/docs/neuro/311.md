# Neuroimaging - Page 311

![Page 311](/core_radiology/images/neuro/page-311.png)

## 內耳疾病 / Inner Ear Pathology

---

### 內耳發育不良 / Cochlear Dysplasia (Mondini Deformity)

| 特徵 | 說明 |
|---|---|
| **本質** | 最常見的先天性耳蝸發育不良；正常2.5圈的發育不全 |
| **正確命名** | 不完全分隔II型；舊名Mondini deformity |
| **特點** | 頂圈和中圈融合，保留獨立的底圈 |
| **與前庭導水管擴大的關聯** | 強關聯 |

---

### Michel發育不全 / Michel Aplasia

| 特徵 | 說明 |
|---|---|
| **本質** | 整個內耳完全缺乏發育 |
| **發病率** | 極罕見 |

---

### 前庭導水管擴大綜合徵 / Enlarged Vestibular Aqueduct Syndrome

| 特徵 | 說明 |
|---|---|
| **臨床影響** | 接觸性運動時可導致進行性聽力損失 |
| **內部參考** | 前庭導水管不應大於后半規管（同層面可見）|

---

### 耳硬化症 / Otospongiosis (Otosclerosis)

| 特徵 | 說明 |
|---|---|
| **本質** | 耳囊的原發性骨發育不良；正常軟骨內骨被不規則海綿骨替代 |
| **好發人群** | 年輕至中年女性；85%為雙側 |
| **兩型** | 窗型和後窗型（迷路性）|

### 耳硬化症分型 / Types

| 分型 | 特點 |
|---|---|
| **Fenestral（窗型）** | 更常見；位於卵圓窗前方；通常影響卵圓窗 |
| **Retrofenestral（後窗型）** | 更嚴重；影響迷路耳囊 |

### 骨質脫鈣的鑑別診斷 / Differential for Cochlear Demineralization

| 患者年齡 | 疾病 |
|---|---|
| **年幼兒童** | 骨質生成不全 |
| **年輕成人** | 纖維發育不良 |
| **老年成人** | Paget病 |
| **任何年齡** | 後窗型耳硬化症 |

### 迷路炎 / Labyrinthitis

| 分期 | 特點 |
|---|---|
| **急性** | 迷路化膿；MRI強化 |
| **纖維性** | 膠原替代；T2信號降低 |
| **骨化性（最終期）** | 骨屑替代；CT最佳 |

### 臨床要點 / Clinical Key Points

> - **Mondini發育不良**：耳蝸發育不全（2.5圈→融合）；前庭導水管擴大
> - **耳硬化症**：年輕女性；85%雙側；後窗型更嚴重
> - **迷路炎三期**：急性（強化）→纖維性（T2低）→骨化性（CT）
