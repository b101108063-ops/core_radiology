# Neuroimaging - Page 273

![Page 273](/core_radiology/images/neuro/page-273.png)

## 腦實質內出血的其他病因 / Other Causes of Intraparenchymal Hemorrhage

---

### 動靜脈瘤破裂出血 / Aneurysmal Hemorrhage

| 特徵 | 說明 |
|---|---|
| **本質** | 非創傷性珠網膜下腔出血的遠遠最常見原因 |
| **血腫位置** | 若為動靜脈瘤破裂所致，血腫通常位於破裂動靜脈瘤附近 |
| **定位線索** | 珠網膜下腔血液分布模式有助定位；但若患者被發現時已平躺，血液會沉積於依賴區，干扰定位 |
| **確診檢查** | CTA是進一步評估非創傷性SAH的首選 |

---

### 動靜脈畸形（AVM）/ Arteriovenous Malformation

| 特徵 | 說明 |
|---|---|
| **本質** | 先天性病變，含異常高流量動靜脈連接，無正常腦組織介入 |
| **年齡** | 與腦澱粉樣血管病不同，AVM出血傾向於影響**年輕患者** |
| **血腫特點** | 若AVM破裂，血腫通常為腦實質內 |

---

### 硬膜動靜脈瘻（dAVF）/ Dural AV Fistula

| 特徵 | 說明 |
|---|---|
| **本質** | 高流量血管畸形，腦膜動靜脈與靜脈竇或皮層靜脈之間的瘻性連接 |
| **最常見類型** | 海綿竇（海綿竇-頸總動靜脈瘻）和後顱窩dAVF |
| **影像學線索** | 擴大的供血動靜脈；擴大或閉塞的靜脈竇；擴大的皮層靜脈 |

---

### 靜脈血栓形成 / Venous Thrombosis

| 特徵 | 說明 |
|---|---|
| **機制** | 皮層靜脈或深靜脈竇血栓形成→靜脈高壓→可能導致腦實質出血 |
| **特徵性位置** | 取決於血栓位置（上矢狀竇→旁矢狀凸面；深靜脈→雙側丘腦）|

---

### 出血性腫瘤 / Hemorrhagic Neoplasm

| 特徵 | 說明 |
|---|---|
| **表現** | 腦腫瘤有時以急性出血為首發表現 |
| **最常見原發腫瘤** | 膠質母細胞瘤 |

### 常見導致出血性轉移的腫瘤 / Tumors Causing Hemorrhagic Metastases

| 腫瘤 | 說明 |
|---|---|
| **絨毛膜癌** | 最易出血 |
| **黑色素瘤** | 常見出血轉移 |
| **甲狀腺癌** | 常見出血轉移 |
| **腎細胞癌** | 常見出血轉移 |
| **乳腺癌/肺癌** | 整體常見，但每例出血較少見 |

### 出血性腫瘤的診斷線索 / Diagnostic Clues

| 線索 | 說明 |
|---|---|
| **水腫超出預期** | 超急性血腫周圍水腫比預期多 |
| **信號不均勻** | 血紅蛋白不同分解階段的不均勻信號 |
| **多發強化病變** | 多發強化病變強烈提示轉移性疾病 |
| **隨訪** | 若診斷不清，出血改善後隨訪MRI |

### 抗血管生成藥物風險 / Avastin Risk

| 藥物 | 風險 |
|---|---|
| **Bevacizumab（Avastin）** | 增加出血性轉移的風險 |

### 臨床要點 / Clinical Key Points

> - **動靜脈瘤破裂**：非創傷性SAH最常見原因；血腫位於破裂瘤附近
> - **AVM**：年輕患者腦實質出血需考慮；擴大的供血動靜脈是特點
> - **dAVF**：後顱窩/海綿竇區域高流量分流
> - **靜脈血栓**：靜脈高壓可致出血性梗塞
> - **出血性腫瘤**：膠質母細胞瘤是最常見原發；絨毛膜癌、黑色素瘤、腎癌、甲狀腺癌是最易出血的轉移
> - **多發強化病變**：高度提示轉移性疾病
