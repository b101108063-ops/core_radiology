# Neuroimaging - Page 288

![Page 288](/core_radiology/images/neuro/page-288.png)

## 頸部感染 / Neck Infections

---

### 咽後膿腫 / Retropharyngeal Abscess

| 特徵 | 說明 |
|---|---|
| **臨床擔憂** | 咽後感染可致氣道受壓 |
| **兒童病因** | 上呼吸道感染蔓延（咽炎等）；淋巴結增大後化膿破裂 |
| **成人病因** | 穿透性損傷（魚刺嵌頓或器械損傷）|

### 咽後膿腫的影像所見 / Imaging Findings

| 檢查 | 所見 |
|---|---|
| **側位頸椎片** | 椎前組織增厚 |
| **CT** | 咽後間隙周圍強化的液體積聚 |

---

### 扁桃體周膿腫 / Peritonsillar Abscess

| 特徵 | 說明 |
|---|---|
| **病因** | 扁桃體淋巴結化膿的並發症 |
| **臨床表現** | 典型「熱土豆音」（hot-potato voice）|

---

### Lemierre綜合徵 / Lemierre Syndrome

| 特徵 | 說明 |
|---|---|
| **本質** | 扁桃體和扁桃體周靜脈的血栓性靜脈炎；常蔓延至頸內靜脈 |
| **好發人群** | 免疫正常的青少年和年輕成人 |
| **最常見病原體** | 厭氧菌**Fusobacterium necrophorum**（正常口腔菌群）|
| **影像所見** | 受累靜脈的增大、血栓形成、壁強化 |
| **並發症** | 可有轉移性肺膿腫 |

---

### Bezold膿腫 / Bezold Abscess

| 特徵 | 說明 |
|---|---|
| **本質** | 耳乳突炎的並發症；乳突尖壞死 |
| **蔓延** | 感染蔓延至鄰近軟組織 |
| **影像所見** | 中耳和乳突氣房的混濁；常有乳突尖骨質侵蝕 |

### 臨床要點 / Clinical Key Points

> - **咽後膿腫**：兒童（感染蔓延）vs 成人（穿透性損傷）
> - **扁桃體周膿腫**：「熱土豆音」=特點
> - **Lemierre綜合徵**：年輕成人；Fusobacterium；血栓性靜脈炎＋頸內靜脈＋肺轉移
> - **Bezold膿腫**：耳乳突炎並發症；乳突尖骨質侵蝕
