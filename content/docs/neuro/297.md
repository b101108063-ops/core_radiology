# Neuroimaging - Page 297

![Page 297](/core_radiology/images/neuro/page-297.png)

## 慢性過敏性真菌性鼻竇炎 / Chronic Allergic Fungal Sinusitis

| 特徵 | 說明 |
|---|---|
| **本質** | 非侵襲性疾病；對真菌的過敏反應 |
| **患者特點** | 免疫正常；有氣喘病史 |
| **CT特徵** | 受累竇擴張且不含氣；壁變薄；竇內容物為混合衰減和異質性曲線形高衰減 |

---

## 急性侵襲性真菌性鼻竇炎 / Acute Invasive Fungal Sinusitis

| 特徵 | 說明 |
|---|---|
| **本質** | 免疫抑制患者的侵襲性感染 |
| **常見病原體** | *Aspergillus*和*Zygomycetes*；Aspergillus可致暴發性疾病 |
| **CT早期** | 非特異性黏膜增厚 |
| **CT晚期** | 局部侵襲、骨質破壞、顱內和眶內蔓延 |
| **與慢性過敏性的對比** | 侵襲性真菌性鼻竇炎CT上**非高密度** |

---

## 鼻竇息合 / Antrochoanal Polyp

| 特徵 | 說明 |
|---|---|
| **本質** | 良性息肉；從上頜竇擴展至鼻咽 |
| **特徵** | 竇口特徵性擴張；可骨質侵蝕並延伸至鼻咽 |
| **治療** | 完全切除是預防復發的關鍵 |

### 鼻竇炎分類 / Sinusitis Classification

| 類型 | 特點 |
|---|---|
| **急性過敏性真菌性** | 免疫正常；有氣喘；竇擴張＋高密度 |
| **急性侵襲性** | 免疫抑制；骨質破壞＋顱內/眶內蔓延 |
| **鼻竇息合** | 單側；擴展至鼻咽；完全切除 |

### 臨床要點 / Clinical Key Points

> - **慢性過敏性真菌性鼻竇炎**：免疫正常；有氣喘；CT高密度竇內容物
> - **急性侵襲性真菌性鼻竇炎**：免疫抑制患者；Aspergillus最危險
> - **鼻竇息合**：從上頜竇擴展至鼻咽；完全切除防復發
