# Neuroimaging - Page 227

![Page 227](/core_radiology/images/neuro/page-227.png)

## 腦室內腫瘤 / Intraventricular Tumors

### 概述 / Overview

| 位置 Location | 常見腫瘤 |
|---|---|
| **側腦室** | 腦室內腦膜瘤、室管膜瘤、神經元腫瘤、脈絡叢腫瘤 |
| **第三腦室** | 脈絡叢乳頭狀瘤、室管膜瘤 |
| **第四腦室** | 室管膜瘤（兒童後顱窩）、髓母細胞瘤 |

---

### 中樞神經細胞瘤 / Central Neurocytoma

| 特徵 | 說明 |
|---|---|
| **腫瘤本質** | 低級別腫瘤；可能起源於神經元 |
| **好發人群** | 年輕成人（青少年至年輕中年人）|
| **預後** | 非常好（預後良好）|
| **典型影像** | 分葉狀腫塊附著於**透明隔**；腫瘤內多發囊性區域；常伴有鈣化 |
| **強化特徵** | 明顯強化 |

---

### 脈絡叢乳頭狀瘤 / Choroid Plexus Papilloma

| 特徵 | 說明 |
|---|---|
| **WHO分級** | I級（乳頭狀瘤）/ III級（癌）|
| **腫瘤本質** | 起源於脈絡叢上皮細胞的低級別腫瘤 |
| **發病率** | **<1歲嬰兒最常見的腦腫瘤**；也可發生於成人 |
| **MRI特徵** | T2高信號分葉狀不均勻腫塊；T1加權圖像上明顯強化 |
| **兒童好發位置** | 側腦室**三角區**（atrium）|
| **成人好發位置** | **第四腦室** |
| **其他位置** | 第三腦室、小腦延髓角（較少見）|
| **乳頭狀瘤與癌** | 影像學上難以可靠區分 |

**花椰菜徵**：乳頭狀瘤呈典型的花椰菜樣外觀

---

### 腦室內腦膜瘤 / Intraventricular Meningioma

| 特徵 | 說明 |
|---|---|
| **典型位置** | 側腦室**三角區** |
| **好發人群** | 老年患者（與其他腦膜瘤相似）|
| **MRI特徵** | T1低信號；T2稍高信號；因高細胞性而**均勻強化** |
| **強化特徵** | 均勻強化有助於與其他腦室內腫瘤鑑別 |

---

### 兒童腦室內腫瘤總覽 / Pediatric Intraventricular Tumors

| 腫瘤 | 典型位置 | 年齡 |
|---|---|---|
| **脈絡叢乳頭狀瘤** | 側腦室三角區（兒童）| <1歲嬰兒最常見 |
| **室管膜瘤** | 第四腦室 | 兒童 |
| **髓母細胞瘤** | 第四腦室/小腦 | 兒童 |

### 臨床要點 / Clinical Key Points

> - **中樞神經細胞瘤**：年輕成人；附著於透明隔；多發囊性區域；預後極好
> - **脈絡叢乳頭狀瘤**：<1歲嬰兒最常見腦腫瘤；兒童位於側腦室三角區；成人位於第四腦室；呈花椰菜樣外觀
> - **腦室內腦膜瘤**：老年患者；三角區；均勻強化（高細胞性）
> - 腦室內腫瘤定位結合患者年齡可大幅縮小鑑別診斷範圍
