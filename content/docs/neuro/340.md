# Neuroimaging - Page 340

![Page 340](/core_radiology/images/neuro/page-340.png)

## 硬膜內髓外腫瘤 / Intradural Extramedullary Lesions

---

### 神經鞘瘤 vs 神經纖維瘤 / Schwannoma vs Neurofibroma

| 特徵 | 神經鞘瘤 | 神經纖維瘤 |
|---|---|---|
| **發病率** | 更常見 | 較少 |
| **年齡** | 老年 | 年輕成人 |
| **NF關聯** | 無特異 | **NF1** |
| **包膜** | **有**（可剝出）| 無 |
| **神經累及** | 偏心（可保留神經）| 環形（需切除神經）|

### 神經鞘瘤的MRI特徵 / Schwannoma MRI

| 特徵 | 說明 |
|---|---|
| **形態** | 啞鈴形（15%同時硬膜內外）|
| **椎間孔擴大** | 典型 |
| **T2** | 高信號 |
| **強化** | 均勻強化 |

### 靶徵 / Target Sign

| 特徵 | 說明 |
|---|---|
| **本質** | T2中心低信號+周邊高信號 |
| **意義** | 提示良性神經鞘瘤 |

---

### 腦膜瘤 / Meningioma

| 特徵 | 說明 |
|---|---|
| **本質** | 良性；起源於蛛網膜帽細胞 |
| **好發人群** | 老年女性 |
| **位置** | 頸椎前/胸椎後 |
| **MRI** | 均勻強化 |
| **CT** | 常鈣化 |
| **經典型所見** | 寬基底硬膜 |

---

### 表皮囊腫 / Epidermoid

| 特徵 | 說明 |
|---|---|
| **本質** | 後天罕見；新生兒腰椎穿刺植入 |
| **T1** | 低信號 |
| **T2** | 高信號 |
| **關鍵特點** | **受限擴散** |
| **鑑別** | Arachnoid囊腫（不受限）|

---

### 皮樣囊腫 / Dermoid

| 特徵 | 說明 |
|---|---|
| **本質** | 先天性；兒童 |
| **內容物** | 巨觀脂肪 |
| **T1** | **高信號**（脂肪）|
| **並發症** | 破裂→化學性腦膜炎 |

### 臨床要點 / Clinical Key Points

> - **神經鞘瘤**：啞鈴形；椎間孔擴大；可手術剝出
> - **神經纖維瘤**：NF1相關；需切除神經
> - **腦膜瘤**：老年女性；胸椎後方；鈣化常見
> - **表皮囊腫**：受限擴散（與arachnoid囊腫的關鍵鑑別）
> - **皮樣囊腫**：T1高信號（脂肪）
