## 顱骨骨折 / Skull Fractures

### 骨折分類 / Classification of Skull Fractures

| 類型 Type | 特徵 Features | 臨床意義 Clinical Significance |
|---|---|---|
| **線性骨折 Linear fracture** | 最常見 | 重點在評估是否伴隨顱內損傷（如硬膜外血腫）|
| **凹陷骨折 Depressed fracture** | 碎片向內凹陷 | 可伴隨 underlying brain injury；可能需要手術抬起 |
| **顱底骨折 Basilar skull fracture** | 線性骨折位於顱底 | 最嚴重；可能伴隨 CSF 漏（鼻漏、耳漏）|

### 線性顱骨骨折 / Linear Skull Fractures

- 最常見的顱骨骨折類型
- 主要重要性在於評估當時是否發生了顱內損傷（如硬膜外血腫）
- 顱頂骨折最常發生於顳骨和頂骨
- **診斷要點**：需使用骨窗（bone window）才能清楚顯示骨折線

### 凹陷性顱骨骨折 / Depressed Skull Fractures

- 多為高能量撞擊，局限於小範圍（如鐵錘敲擊）
- 最常見於額頂區，通常為粉碎性
- 碎片深度超過相鄰骨頭內板時，可能需要手術治療
- 可伴隨 underlying brain injury

### 顱底骨折 / Basilar Skull Fractures

- **最嚴重**的顱骨骨折類型
- 可伴隨硬膜撕裂，導致 CSF 漏
- **臨床表現線索**：
  - 創傷性氣腦（traumatic pneumocephalus）— 腦內有空氣
  - 乳突氣房（mastoid air cells）積液
  - 蝶竇（sphenoid sinus）內有空氣-液平面

## 面部骨折 / Facial Fractures

### 眼眶爆裂骨折 / Blow-out Fracture

| 特徵 Feature | 說明 Description |
|---|---|
| **機制** | irect impact on orbit（如球類撞擊眼部）|
| **骨質薄弱區** | 眼眶下壁（進入上頜竇）或眼眶內壁（進入篩竇）|
| **眼眶氣腫 Orbital emphysema** | 空氣進入眼眶 |
| **眼外肌嵌頓** | 下直肌可嵌頓於骨折處，導致眼球上視受限、複視 |
| **併發症** | 上頜竇內積液（血液）|

**CT 診斷要點（Blow-out fracture）**：
- 眼眶內空氣（orbital emphysema）
- 眼眶下壁或內壁骨折
- 脂肪和/或眼外肌向下突出至上頜竇頂部的軟組織塊
- 上頜竇內積液（血液）

### 三腳骨折 / Tripod Fracture

| 特徵 Feature | 說明 Description |
|---|---|
| **機制** | 鈍性暴力撞擊面部 |
| **骨折線** | 顴額縫（frontozygomatic suture）分離 + 眼眶下壁骨折 + 同側上頜竇外側壁骨折 |
| **CT 表現** | 上頜竇內積血、眼眶氣腫 |

## 顱內出血 / Intracranial Hemorrhage

### 腦膜結構 / The Meninges

| 層次 Layer | 特性 Characteristics |
|---|---|
| **硬膜 Dura mater** | 兩層組成；外層與顱骨無法分離；內層摺疊形成小腦幕和大腦鐮 |
| **蜘蛛膜 Arachnoid** | 無血管的中層；與硬膜之間為潛在性硬膜下腔 |
| **軟膜 Pia mater** | 緊贴腦與脊髓表面；含有供應的血管；與蜘蛛膜之間為蜘蛛膜下腔 |

### 創傷相關顱內出血分類 / Types of Traumatic Intracranial Hemorrhage

| 類型 Type | 位置 Location | 特徵 Features |
|---|---|---|
| **硬膜外血腫 Epidural hematoma** | 硬膜與顱骨內板之間 | 雙凸形（透鏡狀）；不跨越顱縫；95% 伴顱骨骨折 |
| **硬膜下血腫 Subdural hematoma** | 硬膜與蜘蛛膜之間 | 新月形；可跨越顱縫；進入大腦縱裂 |
| **腦實質內出血 Intracerebral hemorrhage** | 腦實質內 | 創傷性腦挫傷；額葉、顳葉常見 |
| **蜘蛛膜下腔出血 Subarachnoid hemorrhage** | 蜘蛛膜下腔 | 討論見「破裂性動脈瘤」章節 |

## 硬膜外血腫 / Epidural Hematoma (Extradural Hematoma)

### 病因與機制 / Etiology and Mechanism

| 要點 Key Point | 說明 |
|---|---|
| **出血來源** | 顱內板與硬膜之間的潛在空間 |
| **常見原因** | 鈍性頭部外傷，通常為摩托車或汽車事故 |
| **血管損傷** | 腦膜中動靜脈（middle meningeal artery/vein）最常見 |
| **顱骨骨折** | 約 95% 伴顱骨骨折（常為顳骨）|
| **好發部位** | 顳頂區 |

### 診斷要點 / Diagnostic Features

| 特徵 Feature | 說明 |
|---|---|
| **CT 密度** | 高密度（hyperdense）|
| **形態** | 雙凸形（biconvex）、透鏡狀（lenticular）|
| **特點** | Extraaxial（軸外）病變 |
| **跨顱縫** | **不可能**（硬膜在顱縫處與顱骨融合）|
| **跨小腦幕** | **可能**（與硬膜下血腫不同）|

> ⚠️ **幾乎所有硬膜外血腫（95%）都伴隨顱骨骨折**

## 硬膜下血腫 / Subdural Hematoma (SDH)

### 病因與機制 / Etiology and Mechanism

| 要點 Key Point | 說明 |
|---|---|
| **發生率** | 比硬膜外血腫更常見 |
| **顱骨骨折** | 通常**不**伴顱骨骨折 |
| **常見原因** | 減速傷（摩托車/汽車事故）年輕患者；跌倒（老年患者）|
| **出血來源** | 橋靜脈（bridging veins）— 從大腦皮質跨至靜脈竇 |
| **位置** | 硬膜與蜘蛛膜之間 |

### 急性硬膜下血腫 / Acute Subdural Hematoma

> ⚠️ **急性硬膜下血腫常預示更嚴重的腦實質損傷、顱內壓升高，死亡率較高**

| 特徵 Feature | 說明 |
|---|---|
| **CT 密度** | 高密度、新月形（crescent-shaped）|
| **形態** | 向腦組織方向凹陷（concave inward）；與硬膜外血腫的雙凸形相反 |
| **跨顱縫** | **可以** |
| **跨中線** | **不行**（但可進入大腦縱裂）|
| **形狀** | 弧形帶狀血液 |

### 亞急性 / 等密度硬膜下血腫 / Subacute / Isodense SDH

| 特徵 Feature | 說明 |
|---|---|
| **密度變化** | 隨時間變為等密度（isodense）|
| **診斷技巧** | 注意單側腦溝消失或偏移 |
| **表現** | 患側腦溝不清或消失；與對側正常側比較 |

### 慢性硬膜下血腫 / Chronic Subdural Hematoma

| 特徵 Feature | 說明 |
|---|---|
| **時間定義** | 受傷後 3 週以上 |
| **CT 密度** | **低密度**（與正常腦組織相比）|
| **特點** | 仍可有佔位效應（中線偏移、大腦縱裂偏移）|

## 腦實質內出血 / Intracerebral Hematoma (Intracerebral Hemorrhage)

### 病因 / Etiology

創傷並非唯一原因：

| 病因 | 說明 |
|---|---|
| **創傷** | 剪切力導致小血管撕裂 |
| **囊狀動脈瘤破裂** | |
| **小血管粥樣硬化** | |
| **血管炎** | |
| **動靜脈畸形（AVM）** | |
| **澱粉樣血管病** | |
| **靜脈血栓形成** | |

###  coup 與 contrecoup 損傷 / Coup and Contrecoup Injuries

| 類型 | 機制 |
|---|---|
| **Coup injury（衝擊傷）** | 撞擊點本身的腦組織損傷 |
| **Contrecoup injury（對側傷）** | 加速/減速損傷，腦組織被推向對側撞擊顱骨內面 |

### 腦挫傷 / Cerebral Contusion

| 特徵 | 說明 |
|---|---|
| **部位** | 額葉底部、顳葉前部；腦表面或近表面 |
| **CT 表現** | 多發性邊界清楚的高密度區 |
| **水腫** | 周圍低密度水腫邊緣 |
| **腦室內出血** | 可出現 |
| **佔位效應** | 常見；可能導致腦疝 |

### 腦內出血的 CT 表現時間演變 / Evolution of Intracerebral Hemorrhage on CT

| 時間 | CT 表現 |
|---|---|
| **即刻** | 高密度（血液蛋白質，主要為血紅素）|
| **約 3 天** | 血塊因脫水而密度更高 |
| **3 天後** | 密度開始下降，由外向內萎縮 |
| **約 2 個月後** | 可能僅剩小範圍低密度 |

## 腦疝 / Brain Herniation

### 腦疝分類 / Types of Brain Herniation

| 類型 Type | 特徵 Features |
|---|---|
| **大腦鐮下疝 Subfalcine herniation** | 最常見；腦組織經大腦鐮下方疝入對側；側腦室及透明隔向對側偏移 |
| **經小腦幕疝 Transtentorial herniation（如鉤回疝 uncal herniation）** | 第二常見；顳葉內側（鉤回）經小腦幕切跡向下移位；壓迫同側顳角，導致對側顳角擴大 |
| **扁桃體疝 Tonsillar herniation** | 後顱窩腦組織經枕骨大孔向下移位 |

### 腦疝的後果 / Consequences of Herniation

- 腦組織損傷
- 顱神經及血管受壓（導致出血或缺血）
- 腦脊液循環受阻（導致水腦症）
- 腦幹受壓

## 瀰漫性軸索損傷 / Diffuse Axonal Injury (DAI)

### 病因與臨床 / Etiology and Clinical Features

| 要點 Key Point | 說明 |
|---|---|
| **病因** | 加速/減速力導致軸索廣泛損傷 |
| **機制** | 皮質下軸索深部受損 |
| **意識** | 從受傷瞬間即失去意識 |
| **常見原因** | 摩托車/汽車事故 |
| **好發部位** | **胼胝體**最常受累 |
| **預後** | 頭部外傷中**預後最差** |

### 影像學表現 / Imaging Features

| 影像類型 | 表現 Findings |
|---|---|
| **CT** | 可能正常或低估損傷程度；表現類似創傷性腦內出血 |
| **MRI** | **首選**檢查；T1、T2 可見亮點；Gradient echo 或 SWI 序列最敏感 |
| **SWI（磁敏感加權成像）** | 點狀低信號（暗）病變 |

### MRI 診斷要點 / MRI Diagnostic Points

| 要點 | 說明 |
|---|---|
| **SWI 序列** | 對檢測點狀出血最敏感 |
| **T1 加權** | 小出血點可呈高信號 |
| **T2 加權** | 顳、頂顱頸交界處或胼胝體內多發亮點 |
| **典型表現** | 無數低信號病變（GRE/SWI）或高信號病變（T2）|

---

## 臨床要點 / Clinical Key Points

> - **非增強 CT 為急性頭部外傷首選**：主要目標是發現威脅生命且可治療的病變
> - **線性骨折的重要性**：在於評估是否伴隨顱內損傷
> - **凹陷性骨折**：可伴隨 underlying brain injury，可能需要手術處理
> - **顱底骨折**：最嚴重，可伴 CSF 漏（鼻漏、耳漏）
> - **眼眶爆裂骨折**：眼眶氣腫 + 眼眶下壁或內壁骨折 + 眼外肌嵌頓
> - **硬膜外血腫**：雙凸形、透鏡狀；95% 伴顱骨骨折；不跨顱縫
> - **硬膜下血腫**：新月形；可跨顱縫；急性 SDH 預示更嚴重腦損傷
> - **DAI**：MRI（尤其是 SWI）首選；胼胝體最常受累；預後最差
> - **頭部外傷初步評估重點**：佔位效應 + 出血
