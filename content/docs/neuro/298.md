## 黏液囊腫 / Mucocele

| 特徵 | 說明 |
|---|---|
| **本質** | 竇口阻塞導致的擴張無氣竇 |
| **病因** | 通常為炎症（最常見）或腫瘤 |
| **CT特徵** | 竇壁變薄；內容物均質 |
| **MRI信號** | 信號多變（取決於脫水程度）；隨時間推移：T1漸高、T2漸低 |
| **與正常竇的對比** | 晚期T2明顯低信號可模擬正常含氣竇——需仔細複查所有序列 |

## 內翻性乳頭狀瘤 / Inverted Papilloma

| 特徵 | 說明 |
|---|---|
| **本質** | 鼻竇黏膜的良性分葉狀上皮腫瘤 |
| **惡性關聯** | 10-20%可與鱗狀細胞癌相關 |
| **典型影像所見** | **腦迴樣強化模式**——增強檢查上的曲線形、分葉狀強化 |
| **與黏液囊腫的對比** | 整個實性腫瘤都強化（對比黏液囊腫的液體無強化）|
| **骨質變化** | 可塑型骨質（remodel） |
| **治療** | 手術切除 |
| **復發率** | 約15% |

### 內翻性乳頭狀瘤 vs 黏液囊腫 / Comparison

| 特徵 | 內翻性乳頭狀瘤 | 黏液囊腫 |
|---|---|---|
| **本質** | 良性上皮腫瘤 | 竇口阻塞 |
| **竇擴張** | 否（骨質重塑）| 是 |
| **強化** | 腦迴樣強化（整個腫瘤）| 無（液體）|
| **惡性風險** | 10-20% | 無 |
| **復發率** | ~15% | 低 |

### 臨床要點 / Clinical Key Points

> - **黏液囊腫**：竇口阻塞→竇擴張；MRI信號取決於脫水程度
> - **內翻性乳頭狀瘤**：腦迴樣強化=特徵；10-20%與鱗狀細胞癌相關
> - **與鱗狀細胞癌的關聯**：任何內翻性乳頭狀瘤患者術前需排除並發惡性
> - 兩者都有復發風險；內翻性乳頭狀瘤復發率達15%
