# Neuroimaging - Page 343

![Page 343](/core_radiology/images/neuro/page-343.png)

## 原發性椎骨腫瘤 / Primary Osseous Vertebral Tumors

---

### 中老年人的原發性椎骨腫瘤 / Middle-Aged/Older Adults

| 腫瘤 | 特點 |
|---|---|
| **脊索瘤** | 老年；脊索殘留；骶尾部最常見（其次斜坡）|
| **漿細胞瘤** | 溶骨性膨脹性病變；多發性骨髓瘤前驅 |
| **軟骨肉瘤** | 低度惡性；T2高信號；軟骨基質 |

### 青少年和年輕成人的原發性椎骨腫瘤 / Adolescents/Young Adults

| 腫瘤 | 特點 |
|---|---|
| **動脈瘤樣骨囊腫（ABC）** | 青少年；進行性破壞；MRI可見液-液平面 |
| **軟骨母細胞瘤** | 良性但侵襲性；罕見於脊柱 |
| **骨樣骨瘤** | 青少年； Nocturnal pain relieved by NSAIDs |
| **骨肉瘤** | 惡性；可產生骨樣基質 |

---

### 脊索瘤 / Chordoma

| 特徵 | 說明 |
|---|---|
| **本質** | 起源於脊索殘留的惡性腫瘤 |
| **好發人群** | 老年 |
| **最常見位置** | 骶尾部（最常見）、斜坡（第二常見）|
| **15%** | 可發生於椎體（最常見宮頸）|
| **MRI** | T2高信號；侵襲性腫塊；明顯強化 |

---

### 漿細胞瘤 / Plasmacytoma

| 特徵 | 說明 |
|---|---|
| **本質** | 溶骨性膨脹性病變 |
| **好發人群** | 晚期成年 |
| **與骨髓瘤關聯** | 被認為是多發性骨髓瘤的前驅 |
| **特點** | 孤立性病變；多發=骨髓瘤 |

---

### 軟骨肉瘤 / Chondrosarcoma

| 特徵 | 說明 |
|---|---|
| **分級** | 低度惡性 |
| **MRI** | T2高信號（似脊索瘤）|
| **CT特點** | 軟骨「弧-環」鈣化 |

---

### 硬膜外脂肪瘤病 / Epidural Lipomatosis

| 特徵 | 說明 |
|---|---|
| **本質** | 硬膜外脂肪過度生長 |
| **並發症** | 可壓迫神經結構；嚴重可致馬尾綜合徵 |
| **病因** | 皮質類固醇（Cushing病/綜合徵）、肥胖 |

### 硬膜外脂肪瘤病的病因 / Causes

| 病因 | 說明 |
|---|---|
| **外源性類固醇** | 全身性比硬膜外注射更常見 |
| **Cushing病/綜合徵** | 內源性皮質醇過多 |
| **病態肥胖** | 罕見原因 |

### 臨床要點 / Clinical Key Points

> - **脊索瘤**：老年；骶尾部最常見；T2高信號
> - **漿細胞瘤**：孤立性溶骨病變；為骨髓瘤前驅
> - **ABC**：青少年；液-液平面是MRI特點
> - **硬膜外脂肪瘤病**：類固醇使用或Cushing綜合徵的並發症
