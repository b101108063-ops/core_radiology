# Neuroimaging - Page 281

![Page 281](/core_radiology/images/neuro/page-281.png)

## 化膿性感染 / Pyogenic Abscess

### 病因 / Etiology

| 途徑 | 說明 |
|---|---|
| **血源性播散** | 最常見 |
| **直接蔓延** | 來自鼻竇炎或乳突炎 |
| **細菌性腦膜炎的並發症** | 可為並發症 |

### 膿瘋的演變分期 / Evolution and Staging

| 分期 | 時間 | 特徵 |
|---|---|---|
| **早期腦炎** | 早期 | 非特異性T2延長，不均勻強化 |
| **晚期腦炎** | 逐漸演變 | 病變開始局限 |
| **早期膿瘋** | 約2週 | 離散性病變形成 |
| **晚期膿瘋** | 完全形成 | 成熟膿瘋 |

> 膿瘖完全形成約需**2週**

### 化膿性膿瘋的典型影像學表現 / Classic Imaging Appearance

| 特徵 | 說明 |
|---|---|
| **CT/MRI** | 環形強化的腫塊 |
| **T2加權** | **邊緣呈低信號**（特點；與膠質瘤/轉移瘤不同）|
| **邊緣特點** | **薄且光滑**（對比膠質瘤/轉移瘤的厚而不規則）|
| **DWI** | **受限擴散**：DWI極亮、ADC暗 |
| **囊內容物** | DWI高信號、ADC低信號 |

### 腦室周圍病變的特點 / Periventricular Lesions

| 特徵 | 說明 |
|---|---|
| **典型特點** | 膿瘖囊朝向腦室的壁更薄 |
| **即將破裂的徵兆** | 腦室邊緣中斷 |
| **破裂後果** | 腦室炎；死亡率極高 |

### 與膠質瘤/轉移瘤的鑑別 / Differentiation from Glioma/Metastasis

| 特徵 | 膿瘖 | 膠質瘤/轉移瘤 |
|---|---|---|
| **T2邊緣** | **薄且光滑，低信號** | 厚且不規則 |
| **DWI** | **受限擴散**（高信號）| 通常無受限 |
| **強化** | 均勻薄環 | 厚而不規則 |

### 臨床要點 / Clinical Key Points

> - **化膿性膿瘋**：DWI高信號+ADC低信號是最具鑑別價值的序列
> - **T2低信號邊緣**（薄且光滑）是膿瘖的特徵（與腫瘤鑑別的關鍵）
> - 腦室周圍膿瘋朝向腦室的壁更薄；破裂可致腦室炎（死亡率極高）
> - 完全形成約需2週；早期（腦炎期）為非特異性強化
