# Neuroimaging - Page 248

![Page 248](/core_radiology/images/neuro/page-248.png)

## 軸內損傷 / Intra-Axial Injury

---

###  coup/contrecoup 機制 / Coup/Contrecoup Mechanism

| 特徵 | 說明 |
|---|---|
| **機制** | 腦在撞擊處及撞擊點180°對側均可能受傷，因腦在顱內二次撞擊顱骨壁所致 |
| **解釋** | 撞擊後腦在顱內來回移動，在撞擊側（coup）和對側（contrecoup）均可能受損 |

---

### 皮層挫傷 / Cortical Contusion

| 特徵 | 說明 |
|---|---|
| **機制** | 腦皮層表面創傷性撞擊顱骨內板粗糙面 |
| **受累部位** | 腦溝顶部；可發生於coup或contrecoup位置 |
| **亞急性期** | 亞急性皮層挫傷可呈**環形強化**，若有外傷史應在環形強化鑑別診斷中考慮 |
| **慢性期** | 慢性挫傷在CT上呈腦軟化症；MRI更特異，顯示周圍含鐵血紅素沉積（T2低信號＋GRE暈染偽影）|

---

### 腦實質內血腫 / Intraparenchymal Hematoma

| 特徵 | 說明 |
|---|---|
| **創傷性腦實質血腫** | 可發生於各位置：從皮層挫傷到基底節出血（豆紋動靜脈剪切）|
| **亞急性期** | 亞急性腦實質血腫可呈環形強化 |

---

### 瀰漫性軸索損傷 / Diffuse Axonal Injury (DAI)

| 特徵 | 說明 |
|---|---|
| **機制** | 腦的剪切-應變變形 |
| **別名** | 又稱**創傷性軸索損傷（Traumatic Axonal Injury, TAI）**；因損傷模式為多灶性而非瀰漫性 |
| **病因** | 旋轉減速及隨後的再加速力，超過軸索有限的彈性容量 |
| **CT敏感性** | 對DAI相對不敏感；出血性DAI可在受累區域顯示微小高密度灶 |
| **MRI敏感性** | 檢測DAI比CT敏感得多，需多序列：FLAIR、GREDWI |

### DAI分級 / DAI Grading

| 分級 | 受累位置 |
|---|---|
| **I級** | 僅灰白質交界處 |
| **II級** | 累及胼胝體 |
| **III級（最嚴重）** | 累及背外側中腦 |

> 分級越高，預後越差

### DAI的MRI序列敏感性 / MRI Sequence Sensitivity for DAI

| 序列 | 敏感性 | 適用情況 |
|---|---|---|
| **GRE** | 極高 | 出血性DAI |
| **FLAIR** | 最高 | 非出血性DAI |
| **DWI** | 高 | 急性DAI（細胞毒性水腫＋細胞腫脹→受限擴散）|

### 創傷性軸索損傷的常見位置 / Common DAI Locations

| 位置 | 說明 |
|---|---|
| **灰白質交界處** | 最常見部位之一 |
| **胼胝體** | II-III級DAI |
| **背外側中腦** | III級DAI；提示最嚴重損傷 |

### 臨床要點 / Clinical Key Points

> - **coup/contrecoup**：撞擊側和對側均可受傷
> - **皮層挫傷**：亞急性期可呈環形強化（需結合外傷史）；慢性期MRI可見含鐵血黃素沉積
> - **DAI**：剪切力導致軸索損傷；MRI比CT敏感得多
> - **GRE對出血性DAI極敏感**；FLAIR對非出血性DAI最敏感
> - **DAI分級**：I級→II級→III級（背外側中腦）；分級越高預後越差
> - **DWI**：急性DAI可見擴散受限（細胞毒性水腫）
