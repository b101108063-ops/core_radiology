# Neuroimaging - Page 330

![Page 330](/core_radiology/images/neuro/page-330.png)

## 頸部淋巴結 / Cervical Lymph Nodes

### 頸部淋巴結分區概覽 / Overview

| 分區 | 位置 |
|---|---|
| **IA** | 頦下區（submandibular）|
| **IB** | 下頜下區（submandibular）|
| **IIA** | 頸靜脈上區（內側）|
| **IIB** | 頸靜脈上區（外側）|
| **III** | 頸靜脈中區 |
| **IV** | 頸靜脈下區 |
| **VA** | 副神經區（上）|
| **VB** | 副神經區（下）|

### 頸部淋巴結分區的邊界 / Boundaries

| 邊界結構 | 說明 |
|---|---|
| **下頜骨** | IA/IB上界 |
| **舌骨** | IB/II水平 |
| **甲狀軟骨** | III/IV水平 |
| **環狀軟骨** | IV/V水平 |
| **胸鎖乳突肌後緣** | VA/VB後界 |
| **前斜角肌後緣** | VB下界 |
| **鎖骨** | VB下界 |

---

### 頸部淋巴結引流的臨床意義 / Clinical Significance

| 區域 | 引流腫瘤類型 |
|---|---|
| **IA/IB** | 口腔、面部結構 |
| **II/III/IV** | 咽喉、、甲狀腺 |
| **VA/VB** | 頭部、頸部皮膚 |

### 頸部淋巴結分區與鱗狀細胞癌 / SCC Association

| 原發腫瘤 | 常見淋巴結轉移分區 |
|---|---|
| **口腔** | I, II, III |
| **咽喉** | II, III |
| **，甲狀腺** | VI |

### 淋巴結大小標準 / Size Criteria

| 標準 | 說明 |
|---|---|
| **短軸直徑** | >10-15mm（不同分區略有不同）|
| **頸靜脈二腹肌淋巴結** | >8mm |

### 淋巴結轉移的影像特徵 / Imaging Features of Metastasis

| 特徵 | 說明 |
|---|---|
| **大小** | 增大（但正常大小也可有轉移）|
| **形態** | 圓形（非橢圓形）|
| **皮髓質界限** | 模糊或消失 |
| **壞死** | 高信號（CT低密度）|

### 臨床要點 / Clinical Key Points

> - **淋巴結分區IA-IB**：頦下和下頜下
> - **淋巴結分區II-IV**：頸靜脈上中下區（II最大）
> - **淋巴結分區VA/VB**：副神經區
> - 淋巴結位移和強化模式是評估轉移的關鍵
> - 鱗狀細胞癌主要轉移至II、III區
