# Neuroimaging - Page 238

![Page 238](/core_radiology/images/neuro/page-238.png)

## 固有垂體腫塊 / Intrinsic Pituitary Mass

---

### 垂體微腺瘤 / Pituitary Microadenoma

| 特徵 | 說明 |
|---|---|
| **定義** | 垂體腺瘤<10mm |
| **症狀** | 患者因激素過剩症狀就醫（非佔位效應）|
| **MRI特徵** | 多數相對於正常垂體呈**低強化**；ACTH分泌性腺瘤可呈**高強化** |

---

### 垂體大腺瘤 / Pituitary Macroadenoma

| 特徵 | 說明 |
|---|---|
| **定義** | 腺瘤>10mm |
| **症狀** | 通常以佔位效應就診（如視交叉受壓）而非內分泌失調 |
| **骨性蝶鞍** | 常擴大 |
| **頸內動脈關係** | 可包繞但**不狹窄**（對比腦膜瘤或轉移瘤可狹窄頸內动脉）|
| **藥物治療後出血** | 垂體大腺瘤在藥物治療後可出血，產生複雜MRI表現 |
| **瘤內出血 vs 垂體卒中** | 瘤內出血是影像學發現；垂體卒中是臨床綜合徵（劇烈頭痛＋內分泌功能障礙，由原本正常的垂體出血引起）|

### 垂體大腺瘤的MRI特徵 / MRI Features of Macroadenoma

| 特徵 | 說明 |
|---|---|
| **信號** | T1/T2多變 |
| **強化** | 不均勻強化 |
| **視交叉受壓** | 向上移位 |
| **海綿竇受累** | 可包繞頸內动脉（但不狹窄）|

---

### 淋巴細胞性垂體炎 / Lymphocytic Hypophysitis

| 特徵 | 說明 |
|---|---|
| **本質** | 自體免疫性炎症性疾病 |
| **好發人群** | **圍產期女性** |
| **可累及** | 垂體和漏斗部 |
| **症狀** | 尿崩症、頭痛、視覺障礙、內分泌功能障礙 |
| **MRI特徵** | 垂體柄增粗並明顯強化；垂體增大（似大腺瘤）|
| **治療** | 對類固醇治療有反應 |

---

### 肉芽腫性垂體炎 / Granulomatous Hypophysitis

| 病因 | 說明 |
|---|---|
| **結節病** | 系統性肉芽腫病 |
| **韋格納肉芽腫病** | 肉芽腫性多血管炎 |
| **結核** | 感染性病因 |
| **朗格漢斯細胞組織細胞增生症（LCH）** | 兒童疾病；可累及垂體柄 |

### 肉芽腫性垂體炎 vs 淋巴細胞性垂體炎

- 影像學表現相同
- 確診需結合臨床和實驗室檢查

---

### Rathke裂囊腫 / Rathke's Cleft Cyst

| 特徵 | 說明 |
|---|---|
| **位置** | 可限於垂體內，但更常見於垂體外 |
| **內容物信號** | 取決於蛋白含量；低蛋白→CSF樣；高蛋白→T1高信號 |

---

## 垂體腫瘤鑑別診斷 / Pituitary Tumor Differential

| 腫瘤 | 強化 | 臨床特徵 |
|---|---|---|
| **微腺瘤** | 低強化（相對正常垂體）| 激素過剩症狀 |
| **大腺瘤** | 不均勻強化 | 佔位效應（視交叉受壓）|
| **淋巴細胞性垂體炎** | 垂體柄增粗＋強化 | 圍產期女性；尿崩症 |
| **肉芽腫性垂體炎** | 垂體柄增粗＋強化 | 系統性疾病史 |

### 臨床要點 / Clinical Key Points

> - **垂體微腺瘤**：<10mm；ACTH瘤可高強化；其他多為低強化
> - **垂體大腺瘤**：>10mm；可包繞但不狹窄頸內动脉；視交叉受壓上移
> - **垂體卒中**：原本正常的垂體突然出血的臨床綜合徵（劇烈頭痛＋內分泌障礙）
> - **淋巴細胞性垂體炎**：圍產期女性；尿崩症；對類固醇有反應
> - **垂體瘤 vs 腦膜瘤**：腺瘤可包繞但不狹窄頸內动脉；腦膜瘤趨向於狹窄頸內动脉
