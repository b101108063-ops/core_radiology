# Neuroimaging - Page 228

![Page 228](/core_radiology/images/neuro/page-228.png)

## 結節下巨大星形細胞瘤 / Subependymal Giant Cell Astrocytoma (SEGA)

### 概述 / Overview

| 特徵 | 說明 |
|---|---|
| **WHO分級** | I級（低級別星形細胞瘤變異型）|
| **與結節性硬化症的關聯** | 與**結節性硬化症（Tuberous Sclerosis）**高度相關 |
| **結節性硬化症的其他表現** | 腦室膜下結節、皮層/皮層下錯構瘤 |
| **SEGA的典型位置** | 側腦室**Monro孔**附近 |
| **影像特徵** | 強化的腫塊 |

---

### 結節下瘤 / Subependymoma

| 特徵 | 說明 |
|---|---|
| **腫瘤本質** | 低級別腫瘤；起源不明；可能起源於腦室膜下星形膠質細胞、腦室內壁的室管膜細胞或共同前體細胞 |
| **好發人群** | 中年和老年成人；常為**偶然發現** |
| **最常見位置** | 第四腦室**下端（obex）**；或側腦室**Monro孔** |
| **強化特徵** | **通常不強化**（關鍵特徵！）|
| **CT特徵** | 可見高密度灶（因鈣化）|
| **MRI特徵** | T1等信號；FLAIR稍高信號 |
| **與其他腫瘤的關係** | 與SEGA（結節性硬化症相關）或室管膜瘤**無直接相關** |

---

### 腦室內腫瘤鑑別診斷 / Intraventricular Tumor Differential

| 腫瘤 | 強化 | 典型位置 | 年齡/特徵 |
|---|---|---|---|
| **SEGA** | 強化 | Monro孔附近 | 結節性硬化症患者 |
| **Subependymoma** | **不強化** | 第四腦室下端/Monro孔 | 中老年成人；偶然發現 |
| **室管膜瘤** | 強化 | 第四腦室（兒童）/脊髓（成人）| 兒童後顱窩 |
| **中樞神經細胞瘤** | 強化 | 透明隔 | 年輕成人；多囊性 |
| **脈絡叢乳頭狀瘤** | 明顯強化 | 側腦室三角區（兒童）/第四腦室（成人）| <1歲嬰兒最常見 |
| **腦室內腦膜瘤** | 均勻強化 | 側腦室三角區 | 老年患者 |

---

### SEGA與Subependymoma的比較 / SEGA vs Subependymoma

| 特徵 | SEGA | Subependymoma |
|---|---|---|
| **WHO分級** | I級 | 低級別 |
| **關聯疾病** | 結節性硬化症 | 無特殊關聯 |
| **強化** | 強化 | **不強化** |
| **典型位置** | Monro孔附近 | 第四腦室下端或Monro孔 |
| **好發人群** | 結節性硬化症患者 | 中老年成人 |
| **發現方式** | 結節性硬化症篩查 | 偶然發現 |

### 臨床要點 / Clinical Key Points

> - **SEGA**：結節性硬化症的標誌性腦腫瘤；側腦室Monro孔附近；需定期監測
> - **Subependymoma**：第四腦室下端（obex）最常見；**不強化**是特點；中老年成人偶然發現
> - **不強化**是區分Subependymoma與SEGA、室管膜瘤的關鍵
> - 腦室內腫瘤的定位（位置＋強化與否）是鑑別診斷的核心
