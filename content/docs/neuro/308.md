# Neuroimaging - Page 308

![Page 308](/core_radiology/images/neuro/page-308.png)

## 中耳疾病 / Middle Ear Pathology

---

### 頸靜脈球體瘤 / Glomus Tympanicum

| 特徵 | 說明 |
|---|---|
| **本質** | 腎上腺外嗜鉻細胞瘤（副神經節瘤）；僅限於中耳 |
| **發病率** | 最常見的原發中耳腫瘤 |
| **臨床表現** | 搏動性耳鳴；傳導性聽力損失 |
| **內視鏡所見** | 鼓膜後血管性紅色腫塊 |

---

### 面神經鞘瘤 / Facial Nerve Schwannoma

| 特徵 | 說明 |
|---|---|
| **本質** | 顳骨內CN VII的慢生長腫瘤 |
| **最常受累段** | 膝神經節；其後為迷路段和鼓室段 |
| **臨床表現** | 多數以面神經麻痹就診；高達30%無面神經症狀 |
| **CT所見** | 受累面神經所通過的骨性管道擴大；通常**無鈣化** |
| **MRI** | 快速對比強化 |

### 面神經在顳骨內的分段 / Facial Nerve Segments in Temporal Bone

| 分段 | 徑路 | 分支 |
|---|---|---|
| **迷路段** | 從內耳道到膝神經節（位於耳蝸上方）| →岩大神經（支配唾液分泌）|
| **鼓室段（水平段）** | 在外半規管下方走行 | — |
| **乳突段（降段）** | 向下走行，從莖突後緣出顱 | →鐙骨肌神經；→鼓索神經（舌前2/3味覺）|

---

### 膽固醇肉芽腫（膽固醇囊腫）/ Cholesterol Granuloma

| 特徵 | 說明 |
|---|---|
| **本質** | 顱骨尖最常見的良性病變；也可見於中耳 |
| **機制** | 對膽固醇結晶的巨細胞反應；初始由阻塞氣房引發 |
| **內視鏡所見** | 鼓膜後**藍色**腫塊 |
| **MRI T1** | **高信號**（特點）|

### 膽固醇肉芽腫 vs 膽脂瘤 / Cholesterol Granuloma vs Cholesteatoma

| 特徵 | 膽固醇肉芽腫 | 膽脂瘤 |
|---|---|---|
| **內視鏡顏色** | **藍色** | 白色 |
| **擴散** | 不受限 | 受限 |
| **T1 MRI** | **高信號** | — |

### 臨床要點 / Clinical Key Points

> - **頸靜脈球體瘤**：中耳最常見原發腫瘤；鼓膜後紅色腫塊；搏動性耳鳴
> - **面神經鞘瘤**：膝神經節最常受累；30%無面癱症狀；CT無鈣化
> - **膽固醇肉芽腫**：T1高信號是特點（與膽脂瘤鑑別）
