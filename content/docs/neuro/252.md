# Neuroimaging - Page 252

![Page 252](/core_radiology/images/neuro/page-252.png)

## Willis環的關鍵穿通支及變異 / Circle of Willis: Critical Perforators & Variants

---

### 關鍵穿通支 / Critical Perforators

| 分支 | 起源 | 供應區域 |
|---|---|---|
| **Heubner迴旋動靜脈** | ACA A1段 | 尾狀核頭、內囊前肢 |
| **內側紋狀體穿通支** | ACA A1段 | 內側基底節 |
| **外側紋狀體穿通支** | MCA | 外側殼核、外部囊、內囊後肢 |
| **前丘腦穿通支** | 後交通動靜脈（P-comm）| 丘腦 |
| **Percheron動靜脈** | PCA P1段（變異）| 雙側腹內側丘腦＋中腦上部 |
| **前脈絡膜動靜脈** | ICA（分叉前）| 視交叉、海馬、內囊後肢 |

### Percheron動靜脈梗塞 / Artery of Percheron Infarct

| 特徵 | 說明 |
|---|---|
| **變異本質** | 一支 dominant thalamic perforator供應雙側腹內側丘腦和中腦上部，起源於P1段 |
| **梗塞表現** | 雙側腹內側丘腦梗塞；可伴或不伴中腦梗塞 |
| **中腦受累時** | 梗塞呈「V形」 |
| **鑑別診斷** | 深靜脈血栓形成也可導致雙側丘腦梗塞 |

### P-comm動靜脈瘤 / P-comm Aneurysm

| 特徵 | 說明 |
|---|---|
| **位置** | 走行於視束和第III顱神經之間 |
| **臨床表現** | 可因局部佔位效應導致第III顱神經麻痹 |

## Willis環的正常解剖變異 / Normal Anatomic Variants

| 變異 | 發生率 | 臨床意義 |
|---|---|---|
| **A1段發育不全或缺如** | 10% / 罕見 | 影響前循環供血 |
| **A-comm缺如** | 5% | 影響雙側ACA交通 |
| **雙重或叢狀A-comm** | — | 與動靜脈瘤相關 |
| **單側ACA（Azygos ACA）** | 3% | 與全前腦發育不良相關 |
| **P-comm發育不全或缺如** | 34% / 罕見 | 影響後交通 |
| **胎兒型PCA** | 約20% | PCA由ICA（經P-comm）供血 |
| **P1段發育不全** | — | 影響後循環供血 |

### 單側ACA / Azygos ACA

| 特徵 | 說明 |
|---|---|
| **發生率** | 3% |
| **相關疾病** | 與**全前腦發育不良（holoprosencephaly）**相關 |

### 胎兒型PCA / Fetal PCA

| 特徵 | 說明 |
|---|---|
| **本質** | PCA完全由同側ICA經擴大的P-comm供血 |
| **發生率** | 約20% |

---

### 正常Willis環解剖 / Normal Circle of Willis

> **正常Willis環解剖僅見於約25%的人群**

### 臨床要點 / Clinical Key Points

> - **Heubner迴旋動靜脈**：從A1發出（而非A2）；供應尾狀核頭和內囊前肢
> - **Percheron動靜脈**：雙側丘腦腹內側梗塞的罕見原因；當中腦受累呈V形
> - **P-comm動靜脈瘤**：可致第III顱神經麻痹
> - **Willis環變異**：正常解剖僅25%；認識變異對評估卒中和動靜脈瘤至關重要
> - **胎兒型PCA**（20%）：PCA由ICA供血；介入治療時需注意
