# Neuroimaging - Page 319

![Page 319](/core_radiology/images/neuro/page-319.png)

## 眼眶感染 / Orbital Infection

### 眼眶感染概覽 / Overview

| 病因 | 說明 |
|---|---|
| **最常見病因** | 鼻竇感染直接蔓延 |
| **其他病因** | 外傷、異物、牙源性感染 |

### 眼眶感染的演變過程 / Spectrum

| 疾病 | 嚴重程度 |
|---|---|
| **瞼蜂窩組織炎（Preseptal cellulitis）** | 最輕 |
| **眼眶蜂窩組織炎/phanled葛** | 進展中 |
| **骨膜下膿腫** | 嚴重 |
| **眼眶膿腫** | 更嚴重 |
| **海綿竇血栓** | 最嚴重 |

---

### 瞼蜂窩組織炎 / Preseptal Cellulitis

| 特徵 | 說明 |
|---|---|
| **本質** | 瞼的淺層感染 |

---

### 眼眶蜂窩組織炎/phanled葛 / Orbital Cellulitis/Phlegmon

| 特徵 | 說明 |
|---|---|
| **本質** | 眼眶內感染（未形成膿腔）|
| **MRI** | 眶內結構強化 |

---

### 骨膜下膿腫 / Subperiosteal Abscess

| 特徵 | 說明 |
|---|---|
| **本質** | 骨膜下已形成膿腔 |
| **臨床表現** | 眼球突出、視力障礙 |
| **治療** | 靜脈抗生素＋手術引流 |

---

### 海綿竇血栓 / Cavernous Sinus Thrombosis

| 特徵 | 說明 |
|---|---|
| **本質** | 眼眶感染的最嚴重並發症 |
| **臨床表現** | 海綿竇受累導致多發顱神經麻痹 |

### 眼眶感染的蔓延途徑 / Routes of Spread

| 途徑 | 說明 |
|---|---|
| **鼻竇直接蔓延** | 最常見 |
| **眶上靜脈（無瓣膜）** | 感染向顱內蔓延 |
| **眼靜脈** | 感染向海綿竇蔓延 |

### 眼眶感染與顱內並發症 / Intracranial Complications

| 並發症 | 說明 |
|---|---|
| **腦膿腫** | 可為硬膜外、硬膜下或腦實質膿腫 |
| **腦膜炎** | 軟膜-蛛網膜炎症 |

### 臨床要點 / Clinical Key Points

> - **眼眶感染最常見病因**：鼻竇炎蔓延
> - **骨膜下膿腫**：需手術引流的眼科急症
> - **海綿竇血栓**：感染可沿無瓣膜眼靜脈向顱內蔓延
> - 眶上靜脈和眼靜脈是眼眶至顱內的感染通道
