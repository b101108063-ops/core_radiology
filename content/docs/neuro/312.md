# Neuroimaging - Page 312

![Page 312](/core_radiology/images/neuro/page-312.png)

## 顱骨骨折 / Temporal Bone Fractures

### 骨折分類 / Classification

| 分類 | 基礎 |
|---|---|
| **迷路破壞性 vs 迷路保留性** | 最新分類（與臨床結局最相關）|
| **縱向 vs 橫向** | 歷史分類（仍常用）|

---

### 縱向骨折 / Longitudinal Fracture

| 特徵 | 說明 |
|---|---|
| **方向** | 與顱骨長軸平行 |
| **發病率** | **最常見** |
| **聽小骨** | 常受累 |
| **聽力損失** | **傳導性** |
| **面神經損傷** | 20% |
| **並發症** | 鼓膜破裂時有後天性膽脂瘤風險 |

---

### 橫向骨折 / Transverse Fracture

| 特徵 | 說明 |
|---|---|
| **方向** | 與顱骨長軸垂直 |
| **骨質迷路** | 更易受累 |
| **聽力損失** | **感覺神經性** |
| **面神經損傷** | **50%** |

### 縱向 vs 橫向骨折 / Longitudinal vs Transverse

| 特徵 | 縱向 | 橫向 |
|---|---|---|
| **方向** | 與長軸平行 | 與長軸垂直 |
| **發病率** | **更常見** | 較少 |
| **聽力損失** | 傳導性 | 感覺神經性 |
| **面神經損傷** | 20% | **50%** |

### 臨床要點 / Clinical Key Points

> - **縱向骨折**：最常見；傳導性聽力損失；20%面癱
> - **橫向骨折**：面癱風險更高（50%）；感覺神經性聽力損失
> - **迷路破壞性骨折**：臨床結局更差
> - 面神經和聽小骨是顱骨骨折評估的關鍵結構
