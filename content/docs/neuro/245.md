# Neuroimaging - Page 245

![Page 245](/core_radiology/images/neuro/page-245.png)

## 松果體區腫瘤 / Pineal Region Tumors

---

### 生殖細胞瘤 / Germinoma

| 特徵 | 說明 |
|---|---|
| **發病率** | 松果體區**最常見**腫瘤 |
| **發病年齡** | 青少年期（10-19歲）為高峰期 |
| **性別分布** | 松果體生殖細胞瘤**男性遠更常見**；鞍上生殖細胞瘤無性別差異 |
| **細胞特徵** | 高細胞性腫瘤；CT稍高密度；T1/T2等信號；ADC圖**低信號** |
| **特徵性表現** | 典型「**吞沒**」松果體並促進其鈣化，導致中央鈣化區 |
| **推薦檢查** | 建議行全神經軸成像（因可發生軟膜-蛛網膜種植）|
| **治療** | 放療；預後極好 |
| **特殊情況** | 松果體生殖細胞瘤可同時伴有鞍上生殖細胞瘤（同步發生）|

---

### 畸胎瘤 / Teratoma

| 特徵 | 說明 |
|---|---|
| **發病率** | 松果體區**第二常見**腫瘤 |
| **預後** | 較生殖細胞瘤差 |
| **影像特徵** | 信號不均勻 |
| **脂肪內容** | 腫瘤內脂肪提示畸胎瘤 |
| **並發症** | 易出血；可有粗大鈣化 |

---

### 松果體囊腫 / Pineal Cyst

| 特徵 | 說明 |
|---|---|
| **發病率** | MRI常見；屍檢系列中高達**40%** |
| **性別分布** | 女性更常見 |
| **大小** | 多數<1cm；無症狀 |
| **症狀** | 少數因佔位效應引起症狀 |
| **隨訪** | 小型松果體囊腫通常不需常規隨訪（極少數會增大）|
| **囊腫特徵** | 多數囊腫不完全為單純性；多數在FLAIR上不完全抑制；多數有輕微邊緣強化；約25%可有囊壁鈣化 |

### 松果體囊腫 vs 松果體細胞瘤 / Pineal Cyst vs Pineocytoma

| 特徵 | 松果體囊腫 | 松果體細胞瘤 |
|---|---|---|
| **強化** | 輕微邊緣強化 | 任何實性成分均強化 |
| **囊性** | 囊性 | 可有囊性變 |
| **信號** | FLAIR不完全抑制 | 多變 |

> **陷阱**：若對比劑給藥後延遲（>60分鐘）成像，Gd對比劑可滲透進入囊腫，使其呈現為實性

---

### 松果體細胞瘤 / Pineocytoma

| 特徵 | 說明 |
|---|---|
| **本質** | 低級別（WHO I或II級）松果體細胞腫瘤，生長緩慢 |
| **強化** | 任何實性成分均強化 |
| **囊性變** | 可有囊性改變，可能與松果體囊腫難以鑑別 |

---

### 松果體母細胞瘤 / Pineoblastoma

| 特徵 | 說明 |
|---|---|
| **本質** | 高度惡性WHO IV級腫瘤；兒童；與髓母細胞瘤同為**原始神經外胚層腫瘤（PNET）**家族 |
| **ADC值** | 高細胞性→**ADC低值** |
| **三側性視網膜母細胞瘤** | 當同時存在雙側視網膜母細胞瘤時使用此術語（視網膜和松果體均為光感覺器官）|
| **四側性視網膜母細胞瘤** | 此外鞍結節也受累 |
| **腦積水** | 常因阻塞性腦積水就診 |
| **特徵性表現** | 松果體區浸潤性腫塊，可侵犯鄰近結構 |
| **鈣化模式** | 與生殖細胞瘤「吞沒」並使松果體鈣化不同，松果體母細胞瘤呈**「爆裂樣」外周鈣化** |
| **轉移** | 高度傾向**軟膜-蛛網膜種植**和CSF播散 |

### 松果體區腫瘤總覽 / Pineal Region Tumor Summary

| 腫瘤 | WHO分級 | 特徵性影像 |
|---|---|---|
| **生殖細胞瘤** | — | 高細胞性；ADC低值；「吞沒」松果體並使其鈣化 |
| **畸胎瘤** | — | 含有脂肪；不均勻；出血/鈣化 |
| **松果體囊腫** | — | 囊性；FLAIR不完全抑制；邊緣強化 |
| **松果體細胞瘤** | I-II級 | 實性；強化 |
| **松果體母細胞瘤** | IV級 | 浸潤性；「爆裂樣」外周鈣化；ADC低值；CSF播散 |

### 臨床要點 / Clinical Key Points

> - **生殖細胞瘤**：松果體區最常見；青少年男性；放療預後極好；可同時有鞍上病灶
> - **松果體囊腫**：40%屍檢可見；女性多見；多數<1cm；FLAIR不完全抑制
> - **松果體母細胞瘤**：高度惡性PNET；兒童；「爆裂樣」外周鈣化；CSF播散
> - **三側性視網膜母細胞瘤**：雙側視網膜＋松果體（均為光感覺器官）
> - **松果體囊腫延遲強化陷阱**：對比劑給藥>60分鐘後成像可使囊腫呈實性強化
