# Neuroimaging - Page 316

![Page 316](/core_radiology/images/neuro/page-316.png)

## 副神經節瘤（血管球瘤）/ Paragangliomas (Glomus Tumors)

### 概述 / Overview

| 特徵 | 說明 |
|---|---|
| **本質** | 起源於副神經節嗜鉻細胞的腫瘤；與腎上腺外嗜鉻細胞瘤組織學相同 |
| **發病率** | <5%為惡性 |
| **關聯** | 與MEN 1和NF 1相關，常為多發 |
| **MRI特徵** | 「鹽和胡椒」外觀（腫瘤內流空效應）|

---

### 頸靜脈球瘤 / Glomus Jugulare

| 特徵 | 說明 |
|---|---|
| **本質** | 頸靜脈孔最常見的原發腫瘤 |
| **好發人群** | 中老年女性 |
| **臨床表現** | 搏動性耳鳴、傳導性聽力損失 |
| **CT所見** | 骨質「蛀蝕」性破壞 |

### 鼓室球瘤 / Glomus Tympanicum

| 特徵 | 說明 |
|---|---|
| **本質** | 僅限於中耳的副神經節瘤 |
| **內視鏡所見** | 血管性紅色鼓膜後腫塊 |

### 鼓室頸靜脈球瘤 / Glomus Jugulotympanicum

| 特徵 | 說明 |
|---|---|
| **本質** | 頸靜脈球瘤蔓延至中耳 |

---

### 鑑別診斷 / Differential of Vascular Middle Ear Mass

| 疾病 | 特點 |
|---|---|
| **鼓室球瘤** | 血管性紅色鼓膜後腫塊 |
| **迷走頸內動靜脈** | 先天變異 |
| **鼓膜血管瘤** | 血管瘤 |

### 臨床要點 / Clinical Key Points

> - **副神經節瘤**：<5%惡性；「鹽和胡椒」MRI特徵
> - **頸靜脈球瘤**：女性；搏動性耳鳴；骨質蛀蝕性破壞
> - 副神經節瘤與MEN 1和NF 1相關
