# Neuroimaging - Page 240

![Page 240](/core_radiology/images/neuro/page-240.png)

## Rathke裂囊腫 / Rathke's Cleft Cyst

### 概述 / Overview

| 特徵 | 說明 |
|---|---|
| **本質** | Rathke囊的胚胎殘留；由簡單柱狀或立方上皮組成 |
| **與顱頜囊瘤的對比** | 顱頜囊瘤由鱗狀上皮和角蛋白組成；Rathke裂囊腫為簡單上皮 |
| **好發人群** | 中年成人；女性發病率是男性的2倍 |
| **發病率** | 屍檢研究中高達22%（臨床上通常無症狀或偶然發現）|

### 影像學特徵 / Imaging Features

| 特徵 | 說明 |
|---|---|
| **信號** | 取決於囊內蛋白含量 |
| **低蛋白** | T1/T2與CSF等信號 |
| **高蛋白** | T1高信號；FLAIR不完全抑制（因蛋白質內容）|
| **強化模式** | **無內部強化**；可有輕微邊緣強化 |
| **「爪徵」（Claw sign）** | 強化後的垂體組織完全包裹囊腫 |

### Rathke裂囊腫 vs 顱頜囊瘤 / Key Distinguishing Features

| 特徵 | Rathke裂囊腫 | 顱頜囊瘤 |
|---|---|---|
| **強化** | **無內部強化**（可有邊緣強化）| **明顯強化** |
| **鈣化** | **無鈣化** | **幾乎總是鈣化** |
| **與垂體關係** | 可與垂體融合 | **幾乎總是與垂體分開** |
| **囊內液** | 取決於蛋白含量 | 機器油（含角蛋白/膽固醇）|

## 鞍旁腦膜瘤 / Parasellar/Suprasellar Meningioma

| 特徵 | 說明 |
|---|---|
| **發病率** | 成人鞍上區**第二常見**腫瘤 |
| **好發人群** | 中年女性；典型表現為視覺障礙（視路受累）|
| **起源** | 鞍區的腦膜反折：結節鞍（tuberculum sella）、床突、蝶骨平板、蝶骨嵴 |
| **信號** | T1等信號；T2信號多變 |
| **強化** | **均勻明顯強化**；常見強化硬膜尾 |
| **骨質改變** | 可因血管活性因子引起鄰近骨質**骨肥厚（hyperostosis）** |
| **與垂體關係** | 蝶鞍通常正常；垂體可明確識別（與腺瘤不同）|
| **關鍵影像所見** | 趨向於**包繞並狹窄**海綿竇或床突上段頸內动脉 |
| **CT特徵** | 可有鈣化 |

### 腦膜瘤 vs 垂體大腺瘤 / Meningioma vs Pituitary Macroadenoma

| 鑑別點 | 腦膜瘤 | 垂體大腺瘤 |
|---|---|---|
| **起源** | 鞍旁腦膜 | 垂體 |
| **蝶鞍大小** | 正常 | **擴大** |
| **垂體識別** | **可明確識別** | 被腫瘤取代 |
| **頸內动脉** | **狹窄** | 包繞但不狹窄 |
| **骨質改變** | 骨肥厚 | 蝶鞍擴大 |
| **強化硬膜尾** | **有** | 無 |

---

### 鞍上區/鞍旁腫塊鑑別總結 / Summary of Suprasellar/Parasellar Masses

| 腫瘤 | 年齡 | 強化 | 鈣化 | 與垂體關係 |
|---|---|---|---|---|
| **顱頜囊瘤** | 兒童 | 強化 | **幾乎總是鈣化** | 與垂體分開 |
| **Rathke裂囊腫** | 中年 | **無**（可有邊緣）| 無 | 可融合 |
| **垂體大腺瘤** | 成人 | 強化 | 無 | 取代垂體 |
| **腦膜瘤** | 中年女性 | 均勻強化 | 可有 | 垂體正常/分開 |

### 臨床要點 / Clinical Key Points

> - **Rathke裂囊腫**：中年女性；無強化無鈣化（與顱頜囊瘤的關鍵鑑別）；蛋白含量決定信號
> - **爪徵**：強化垂體組織包裹囊腫（Rathke裂囊腫的特徵）
> - **鞍旁腦膜瘤**：中年女性；第二常見成人鞍上腫瘤；趨向狹窄頸內动脉；可有骨肥厚
> - **垂體大腺瘤**：蝶鞍擴大＋垂體被取代＋不狹窄頸內动脉
> - **顱頜囊瘤 vs Rathke裂囊腫**：強化+鈣化 vs 無強化無鈣化
