# Neuroimaging - Page 283

![Page 283](/core_radiology/images/neuro/page-283.png)

## 弓漿蟲病 / Toxoplasmosis

### 概述 / Overview

| 特徵 | 說明 |
|---|---|
| **發病率** | AIDS患者最常見的腦腫塊病變 |
| **病原體** | 寄生蟲*Toxoplasma gondii* |
| **CD4閾值** | CD4<100 cells/μL時AIDS患者易感 |
| **排名** | AIDS中第二常見CNS感染（第一位：HIV腦炎）|

### 典型影像學表現 / Typical Imaging Appearance

| 特徵 | 說明 |
|---|---|
| **部位** | 基底節最典型 |
| **數量** | 單發或多發環形強化病變 |
| **CT** | 基底節水腫區＋不明顯高密度腫塊 |
| **MRI FLAIR** | 基底節不均勻腫塊伴廣泛水腫 |
| **強化** | **光滑環形強化** |

### 特異性徵象 / Specific Signs

| 徵象 | 說明 |
|---|---|
| **非對稱靶徵（Asymmetric target sign）** | 不常見但相對特異；描述強化壁上的離心性強化結節 |

### 與CNS淋巴瘤的鑑別 / Differential: CNS Lymphoma

| 鑑別點 | 弓漿蟲病 | CNS淋巴瘤 |
|---|---|---|
| **擴散受限** | **無** | 有（高細胞性）|
| **rCBV（灌注）** | 不升高 | **升高** |
| **FDG-PET** | **低代謝** | 高代謝 |
| **Thallium閃爍掃描** | 不攝取 | 攝取 |

### 弓漿蟲病的影像特徵總結 / Summary

| 檢查 | 所見 |
|---|---|
| **CT** | 基底節水腫＋不明顯高密度 |
| **MRI FLAIR** | 不均勻腫塊＋水腫 |
| **強化** | 光滑環形強化 |
| **FDG-PET** | 不對稱低代謝（受累側）|
| **Thallium** | 不攝取 |

### 臨床要點 / Clinical Key Points

> - **弓漿蟲病**：AIDS患者最常見腦腫塊；CD4<100時易感；基底節單發或多發環形強化
> - **與淋巴瘤的關鍵鑑別**：弓漿蟲病**無擴散受限**、rCBV不升高、PET低代謝
> - **非對稱靶徵**：弓漿蟲病的相對特異性表現
> - 免疫抑制患者基底節強化的首要鑑別：弓漿蟲病 vs CNS淋巴瘤
