# 破裂性動脈瘤、水腦症、腦萎縮與腦腫瘤 / Ruptured Aneurysms, Hydrocephalus, Cerebral Atrophy, and Brain Tumors

## 破裂性腦動脈瘤 / Ruptured Cerebral Aneurysms

### 病因與分類 / Etiology and Classification

| 特徵 | 說明 |
|---|---|
| **最常見類型** | 囊狀（漿果樣）動脈瘤（Berry / Saccular aneurysm）|
| **病因** | 先天性血管壁薄弱（通常位於 Willis 環血管分叉處）|
| **家族傾向** | 約 10% 病例有家族史 |
| **相關疾病** | 結締組織疾病 |
| **增長因素** | 高血壓、年齡增長 |
| **破裂風險** | 較大的動脈瘤破裂風險較高；研究顯示 10 mm 為臨界破裂大小 |

### 臨床表現 / Clinical Presentation

| 特徵 | 說明 |
|---|---|
| **典型主訴** | 「我這輩子最嚴重的頭痛」（"worst headache of my life"）|
| **破裂後出血** | 進入蜘蛛膜下腔 |
| **非創傷性蜘蛛膜下腔出血的最常見原因** | 佔 80% |

### 其他蜘蛛膜下腔出血原因 / Other Causes of SAH

| 病因 | 說明 |
|---|---|
| **動靜脈畸形（AVM）** | |
| **腦內出血突破** | |
| **澱粉樣血管病（Amyloid angiopathy）** | |

### 影像學檢查 / Imaging

| 檢查 | 角色 |
|---|---|
| **CT 血管造影（CTA）** | 快速；可 3D 重建；首選之一 |
| **MRI 血管造影（MRA）** | 可無創、time-of-flight（TOF）技術無需對比劑 |
| **3D 重建** | CTA 後處理可生成 3D 影像 |

### 蜘蛛膜下腔出血的 CT 表現 / CT Findings of SAH

| 表現 | 說明 |
|---|---|
| **急性出血** | 高密度 |
| **好發區域** | 腦溝、基底池（最易見）|
| **大腦鐮** | 可呈高密度、增寬、邊緣不規則 |
| **最大出血區域** | 通常指示破裂點位置 |

### 澱粉樣血管病 / Cerebral Amyloid Angiopathy

| 特徵 | 說明 |
|---|---|
| **本質** | β-類澱粉蛋白沉積於顱內小至中等血管壁（中膜和外膜）|
| **好發區域** | 額葉、頂葉 |
| **後果** | 血管彈性喪失、易碎 |
| **MRI GRE 序列** | 可見病變（常規 CT 或 MRI 序列不可見）|
| **出血特點** | 通常為大面積、單葉出血；可多發、同時多處 |

## 水腦症 / Hydrocephalus

### 定義 / Definition

> **水腦症**：腦室系統因 CSF 容量增加而擴張

### CSF 循環 / CSF Circulation

| 步驟 | 說明 |
|---|---|
| **產生** | 脈絡叢（主要在側腦室和第四腦室）|
| **流動** | 側腦室 → 室間孔（Monro）→ 第三腦室 → 中腦水管（Sylvius）→ 第四腦室 → 枕大池（Magendie）及外側孔（Luschka）|
| **路徑一** | CSF 向上流經大腦凸面，在蜘蛛膜顆粒處吸收入血 |
| **路徑二** | CSF 向下流經脊髓蜘蛛膜下腔，被吸收或返回大腦 |

### 病因分類 / Etiology

| 病因 | 說明 |
|---|---|
| **CSF 吸收障礙（交通性）** | 蜘蛛膜顆粒層面 CSF 吸收受阻（如蜘蛛膜下腔出血、腦膜炎）|
| **CSF 流出受阻（非交通性/阻塞性）** | 腫瘤、囊腫或其他阻塞性病變 |
| **CSF 過度產生（少見）** | 脈絡叢乳頭狀瘤 |

### 水腦症 vs 腦萎縮 / Hydrocephalus vs. Cerebral Atrophy

| 特徵 | 水腦症 | 腦萎縮 |
|---|---|---|
| **腦室擴大** | 不成比例地擴大 | 成比例擴大 |
| **腦溝** | 正常或變平 | 同時擴大 |
| **CSF 動力學** | 異常 | 正常 |
| **顳角** | 對 CSF 壓力增加敏感；常擴大 | |

> **顳角**：正常情況下幾乎不可見；水腦症時 > 2 mm

---

## 非交通性（阻塞性）水腦症 / Noncommunicating (Obstructive) Hydrocephalus

| 特徵 | 說明 |
|---|---|
| **機制** | 腦室系統中某處阻塞 |
| **第四腦室** | 正常大小（與交通性不同）|
| **常見原因** | 腫瘤或囊腫阻塞第三腦室或第四腦室出口 |

---

## 交通性水腦症 / Communicating Hydrocephalus

| 特徵 | 說明 |
|---|---|
| **機制** | CSF 吸收障礙（通常在蜘蛛膜顆粒）|
| **第四腦室** | **擴張**（與非交通性不同）|
| **CSF 流速** | 腦室內及大腦凸面均通暢 |
| **常見原因** | 蜘蛛膜下腔出血、腦膜炎 |
| **治療** | 腦室-腹腔分流術（VP shunt）|

---

## 正常壓力水腦症 / Normal Pressure Hydrocephalus (NPH)

| 特徵 | 說明 |
|---|---|
| **類型** | 交通性水腦的一種 |
| **發病年齡** | 通常 60-70 歲 |
| **經典型三聯症** | 步態異常、癡呆、尿失禁 |
| **治療** | 腦室-腹腔分流術（VP shunt）— CSF 引流至腹腔被吸收 |
| **特徵** | CSF 壓力正常 |

### NPH 的 CT/MRI 表現 / Imaging Findings

| 表現 | 說明 |
|---|---|
| **腦室擴大** | 特別是顳角 |
| **腦溝** | 正常或變平（不擴大）|
| **第四腦室** | 擴大 |

---

## 腦萎縮 / Cerebral Atrophy

| 特徵 | 說明 |
|---|---|
| **本質** | 灰質和白質同時喪失 |
| **相關疾病** | 癡呆、阿茲海默症 |
| **機制** | 正常腦組織減少，被動形成CSF填充的空隙 |
| **CSF 動力學** | 正常（與水腦症不同）|
| **腦室和腦溝** | 成比例擴大 |

> **關鍵鑑別點**：腦萎縮時腦室和腦溝**成比例**擴大；水腦症時腦室**不成比例**地比腦溝大

---

## 腦腫瘤 / Brain Tumors

### 膠質瘤 / Gliomas

| 特徵 | 說明 |
|---|---|
| **發病率** | 佔所有腦腫瘤 30%；為最常見原發性惡性腦腫瘤（80%）|
| **亞型** | 多形性膠質母細胞瘤（GBM，>50%）、星形細胞瘤（~20%）、室管膜瘤、寡樹突膠質細胞瘤、混合型膠質瘤 |
| **好發年齡/性別** | 男性 65-75 歲 |
| **好發部位** | 額葉、顳葉 |
| **預後** | 膠質母細胞瘤最差 |

### 多形性膠質母細胞瘤 / Glioblastoma Multiforme (GBM)

| 特徵 | 說明 |
|---|---|
| **特性** | 高度惡性；浸潤性生長 |
| **彌散途徑** | 沿白質束浸潤；可穿過胼胝體至對側（蝴蝶狀膠質瘤）|
| **壞死** | 常見 |
| **強化** | 部分強化 |
| **水腫** | 顯著血管源性水腫 |
| **腦外轉移** | 不常見 |

---

## 轉移瘤 / Metastases

| 特徵 | 說明 |
|---|---|
| **發病率** | 佔所有顱內腫瘤 40%；為最常見惡性顱內腫瘤（總體）|
| **原發來源** | 肺癌、乳腺癌、黑色素瘤最常見 |
| **好發部位** | 灰白質交界處（gray-white junction）|
| **數量** | 通常多發，也可單發 |
| **CT 表現** | 非增強：低密度或等密度 |
| **強化模式** | 病灶強化；可呈環形強化 |
| **水腫** | 血管源性水腫，且水腫程度常**與腫瘤大小不成比例** |

---

## 腦膜瘤 / Meningioma

| 特徵 | 說明 |
|---|---|
| **發病率** | 最常見的原發性腦腫瘤（良性和惡性）；最常見的軸外（extra-axial）腫瘤 |
| **好發人群** | 中年女性 |
| **常見部位** | 矢狀竇旁、大腦凸面、蝶骨脊、小腦橋角 |
| **生長特性** | 慢速生長；手術切除後預後佳 |
| **多發性** | 可能與神經纖維瘤病第二型（NF2）相關 |

### 腦膜瘤的 CT 表現 / CT Features of Meningioma

| 表現 | 說明 |
|---|---|
| **非增強 CT** | >50% 呈高密度；約 20% 含鈣化 |
| **增強掃描** | 明顯均勻強化 |
| **鄰近水腫** | 可伴血管源性水腫 |

---

## 前庭神經鞘瘤 / Vestibular Schwannoma (Acoustic Neuroma)

| 特徵 | 說明 |
|---|---|
| **本質** | 最常見的顱神經鞘瘤 |
| **最常見症狀** | 聽力減退 |
| **其他症狀** | 耳鳴、平衡障礙 |
| **發生部位** | 第八顱神經（聽神經）行程；小腦橋角（CPA）|
| **與 NF2 關係** | 雙側時高度提示 NF2 |

### 影像學表現 / Imaging

| 檢查 | 表現 |
|---|---|
| **MRI（首選）** | 幾乎總是強化；通常均勻強化 |
| **CT** | 橋小腦角軟組織塊 |

---

## 臨床要點 / Clinical Key Points

> - **破裂性腦動脈瘤**：「最嚴重頭痛」為典型主訴；CTA/MRA 可檢出
> - **蜘蛛膜下腔出血**：高密度在腦溝、基底池；大腦鐮可增寬
> - **水腦症**：腦室不成比例擴大（比腦溝明顯）；顳角對壓力最敏感
> - **交通性水腦症**：第四腦室**擴大**；非交通性：**正常大小**
> - **正常壓力水腦症（NPH）**：經典型三聯症（步態、癡呆、尿失禁）；可治療（分流術）
> - **腦萎縮**：腦室和腦溝**成比例**擴大；CSF 動力學正常
> - **膠質母細胞瘤**：高度惡性；可穿過胼胝體（蝴蝶狀）；不均勻強化伴壞死
> - **轉移瘤**：灰白質交界處；水腫與腫瘤大小不成比例；常多發
> - **腦膜瘤**：中年女性；軸外腫瘤；CT 高密度伴鈣化；明顯強化
> - **前庭神經鞘瘤**：MRI 為最敏感檢查；均勻強化；雙側提示 NF2
