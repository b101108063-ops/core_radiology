# Neuroimaging - Page 301

![Page 301](/core_radiology/images/neuro/page-301.png)

## 腮腺惡性腫瘤 / Malignant Parotid Neoplasms

---

### 黏液表皮樣癌 / Mucoepidermoid Carcinoma

| 特徵 | 說明 |
|---|---|
| **發病率** | 僅約5%的腮腺腫瘤，但是最常見的原發腮腺惡性腫瘤 |
| **低級別** | 典型呈強化腫瘤，T2高信號；MRI上與良性多形性腺瘤無法區分 |
| **治療** | 手術切除 |

---

### 腺樣囊性癌 / Adenoid Cystic Carcinoma

| 特徵 | 說明 |
|---|---|
| **發病率** | 最常見的下頜下腺和舌下腺惡性腫瘤；第二常見腮腺惡性腫瘤 |
| **特點** | 沿神經蔓延的強烈傾向；常以顱神經麻痹或感覺異常就診 |
| **局部復發** | 非常高風險 |
| **轉移** | 高達50%有轉移性疾病；但即使有大面積轉移，患者可存活數年 |
| **關鍵影像特徵** | 強化腫瘤伴神經周圍蔓延 |

---

### 癌性多形性腺瘤 / Carcinoma ex Pleomorphic Adenoma

| 特徵 | 說明 |
|---|---|
| **惡性轉化風險** | 最初5年1.5%；15年9.5% |
| **好發人群** | 老年患者 |
| **典型表現** | 原有腫塊迅速增大 |
| **MRI特徵** | 與良性多形性腺瘤不同：T1和T2均**低信號** |

---

### 鱗狀細胞癌 / Squamous Cell Carcinoma

| 特徵 | 說明 |
|---|---|
| **本質** | 腮腺原發鱗狀細胞癌非常罕見（正常腮腺無鱗狀上皮）|
| **病因** | 慢性炎症可誘導鱗狀上皮化生 |
| **影像** | 侵襲性大腫塊，常有淋巴結轉移 |

---

## 炎症性唾液腺疾病 / Inflammatory Salivary Disease

### 唾液腺結石病 / Sialolithiasis and Obstructive Sialadenitis

| 特徵 | 說明 |
|---|---|
| **結石部位** | 80-90%位於下頜下腺（黏液性分泌物且偏鹼性）|
| **下頜下腺結石的原因** | 分泌物黏稠且偏鹼性＋導管上行路徑導致尿液淤積 |

---

### 結節病 / Sarcoidosis

| 特徵 | 說明 |
|---|---|
| **腮腺受累** | 高達30%的結節病患者可見腮腺受累；通常表現為雙側無痛性腫大 |
| **葡萄膜腮腺熱（Uveoparotid fever）** | 雙側葡萄膜炎、腮腺增大、面神經麻痹；對結節病有病理學特異性 |
| **影像** | Gallium-67閃爍成像產生經典型「熊貓徵」 |

### 臨床要點 / Clinical Key Points

> - **腺樣囊性癌**：沿神經蔓延（感覺異常/麻痹）；50%遠處轉移；是下頜下腺最常見惡性腫瘤
> - **黏液表皮樣癌**：5%腮腺腫瘤；MRI上與多形性腺瘤無法區分
> - **癌性多形性腺瘤**：原有腫塊迅速增大=惡性轉化信號
> - **結節病**：腮腺增大；「熊貓徵」；葡萄膜腮腺熱有診斷特異性
