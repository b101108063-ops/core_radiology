## 腦部正常解剖 / Normal Brain Anatomy

### 斷層掃描解剖 / Cross-Sectional Anatomy on CT

| 結構 Structure | 位置 Position | 說明 Description |
|---|---|---|
| **腳間池 Interpeduncular cistern** | 中腦 | 位於兩側大腦腳之間，腳間池前方為鞍上池 |
| **鞍上池 Suprasellar cistern** | 蝶鞍上方 | 通常呈五或六角星形外觀 |
| **Sylvian 裂（外側裂）** | 雙側對稱 | 含有 CSF，分隔顳葉與額葉、頂葉 |
| ** lentiform nucleus（豆狀核）** | 基底節區 | 由外側的 putamen（殼核）和內側的 globus pallidus（蒼白球）組成 |
| **第三腦室 Third ventricle** | 中線 | 狹窄裂隙狀 |
| **松果體 Pineal gland** | 第三腦室後方 | |
| **四疊體池 Quadrigeminal plate cistern** | 松果體後方 | |
| **第四腦室 Fourth ventricle** | 後顱窩 | 倒 U 形結構，CT 上呈黑色（含 CSF）|
| **小腦 Cerebellum** | 第四腦室後方 | |
| **橋腦 Pons / 延髓 Medulla oblongata** | 第四腦室前方 | |
| **小腦幕 Tentorium cerebelli** | 分隔後顱窩與幕上區 | |

### 腦室系統 / Ventricular System

| 結構 Structure | 說明 Description |
|---|---|
| **側腦室 Lateral ventricles** | 額角（前角）圍繞尾狀核頭部；顳角位於顳葉下方，正常很小；後角（枕角）位於枕葉 |
| **室間孔 Foramen of Monro** | 連接側腦室與第三腦室 |
| **中腦水管 Cerebral aqueduct** | 連接第三與第四腦室 |
| **透明隔 Septum pellucidum** | 分隔兩側額角 |
| **胼胝體 Corpus callosum** | 連接左右大腦半球；嘴部（genu）在前，壓部（splenium）在後 |

### 基底節與周圍結構 / Basal Ganglia and Surrounding Structures

| 結構 Structure | 說明 Description |
|---|---|
| **尾狀核 Caudate nucleus** | 組成 striatum（紋狀體）的一部分 |
| **殼核 Putamen** | 與尾狀核合稱 striatum |
| **蒼白球 Globus pallidus** | 內側基底節結構 |
| **丘腦 Thalamus** | 位於基底節後方 |
| **內囊 Internal capsule** | 介於基底節與丘腦之間 |

### 大腦皮質與白質 / Cortex and White Matter

- **皮質 Cortex**：由灰質組成，含有神經元細胞體，呈現溝（sulci）和迴（gyri）結構
- **白質 White matter（髓質）**：位於皮質下方，含髓鞘軸突束
- **大腦鐮 Falx cerebri**：位於大腦縱裂中，分隔兩大腦半球，常見鈣化

## CT 密度 / CT Densities

### 基本原則 / Basic Principle

> **非增強 CT 掃描中，白色（高密度）通常代表骨頭（鈣質）或血液；無金屬異物情況下**

| 密度類型 | 病因 Examples |
|---|---|
| **高密度（Hyperdense / Bright）** | 血液、鈣質、金屬 |
| **等密度（Isodense）** | 正常腦組織、某些亞急性硬膜下血腫、蛋白質含量高的病變 |
| **低密度（Hypodense / Dark）** | 脂肪（非常見於頭部）、空氣、水（如 CSF）、慢性硬膜下血腫/水囊瘤 |

### 生理性鈣化 / Physiologic Calcifications

| 位置 Location | 說明 |
|---|---|
| **松果體 Pineal gland** | 隨年齡增加而增多 |
| **基底節 Basal ganglia** | 雙側對稱性 |
| **脈絡叢 Choroid plexus** | 側腦室內 |
| **大腦鐮 / 小腦幕 Falx / Tentorium** | 硬膜鈣化 |

### 靜脈注射對比劑後可增強的正常結構 / Normal Structures That Enhance with Contrast

- 靜脈竇（Venous sinuses）
- 脈絡叢（ Choroid plexus）
- 腦下垂體（ Pituitary gland）及其柄部

## MRI 與腦部 / MRI and the Brain

### MRI 優勢 / MRI Advantages

| 優勢 | 說明 |
|---|---|
| **軟組織對比解析度** | 優於 CT |
| **檢測與分期** | 對顱內及脊髓病變首選 |
| **脫髓鞘疾病** | 比 CT 更敏感 |
| **早期中風檢測** | 擴散加权成像（DWI）可在發病後 20-30 分鐘檢出 |

### MRI 劣勢 / MRI Limitations

| 劣勢 | 說明 |
|---|---|
| **鈣化檢測** | 不如 CT 敏感（MRI 上呈現信號缺失）|
| **骨質評估** | 不如 CT 敏感 |
| **植入金屬** | 心律調節器等可能禁忌 |

### T1 與 T2 權重影像 / T1 and T2 Weighted Imaging

| 特徵 | T1 權重 | T2 權重 |
|---|---|---|
| **CSF** | 暗（黑） | 亮（白）|
| **灰質** | 灰階 | 較白 |
| **白質** | 較白 | 灰階 |
| **脂肪** | 亮（白）| 亮（白）|

### 評估原則 / Evaluation Approach

1. **尋找佔位效應（Mass effect）**：觀察腦室、基底池、腦溝的位置及形態變化
2. **尋找血液**：高密度（CT）/ 各時期 MRI 信號變化
3. **比較左右側**：許多結構為成對出現
4. **注意增強模式**：均勻、環形、不規則等

## 臨床要點 / Clinical Key Points

> - **MRI 為檢測顱內病變的首選**：因軟組織對比解析度優於 CT
> - **非增強 CT 為急性頭部外傷首選**：快速、可及時發現威脅生命的顱內出血
> - **CT 密度判讀原則**：白 = 骨頭（鈣質）或血液；黑 = CSF、空氣、脂肪
> - **MRI 訊號多變**：同一病變在不同脈衝序列上可呈現不同信號
> - **評估頭部創傷時**：首先確認是否有佔位效應及出血
