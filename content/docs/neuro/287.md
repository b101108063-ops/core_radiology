# Neuroimaging - Page 287

![Page 287](/core_radiology/images/neuro/page-287.png)

## 頸部感染 / Neck Infection

---

### 筋膜解剖：咽後間隙 / Fascial Anatomy - Retropharyngeal Space

| 間隙 | 說明 |
|---|---|
| **咽後間隙** | 位於咽後方的潛在間隙；從顱底延伸至上縱隔；外側為頸總和咽旁間隙 |
| **翼狀筋膜** | 直接位於咽後間隙後方 |
| **危險間隙** | 翼狀筋膜分隔的潛在間隙；是感染從頸部向下蔓延至膈肌的通道 |
| **椎前間隙** | 顱頸區椎前間隙的前部；位於椎體前方，被椎前筋膜包繞 |

---

### 口腔底筋膜解剖 / Fascial Anatomy - Floor of Mouth

| 間隙 | 說明 |
|---|---|
| **舌下間隙** | 位於舌底的潛在間隙；位於頦舌肌和頦舌骨肌內側；下方為口底肌群 |
| **下頜下間隙** | 直接位於舌下間隙下方；兩者之間以口底肌為界；但舌下間隙後方與下頜下間隙延續 |

---

### 口腔底感染：Ludwig angina / Ludwig Angina

| 特徵 | 說明 |
|---|---|
| **本質** | 口腔底的蜂窩組織炎 |
| **累及間隙** | 頦下、舌下、下頜下間隙 |
| **臨床優先** | 舌可迅速向後移位；確保氣道通暢是臨床首要任務 |
| **影像所見** | 口腔底的水腫和滲出改變 |

### 臨床要點 / Clinical Key Points

> - **咽後間隙**：感染可向上蔓延至顱底，向下至縱隔；危險間隙是感染的傳播通道
> - **Ludwig angina**：口腔底蜂窩組織炎；確保氣道通暢是首要
> - **舌下間隙和下頜下間隙**：以口底肌為界，但後方延續
