# Neuroimaging - Page 267

![Page 267](/core_radiology/images/neuro/page-267.png)

## 可逆性腦血管收縮綜合徵 / Reversible Cerebral Vasoconstriction Syndrome (RCVS)

### 概述 / Overview

| 特徵 | 說明 |
|---|---|
| **本質** | 非創傷性、非動靜脈瘤性SAH和缺血的病因 |
| **臨床表現** | 雷擊樣頭痛；特徵為持續（但可逆）的腦血管收縮 |

---

## 動靜脈瘤形態與病理 / Aneurysm Morphology and Pathology

---

### 囊狀動靜脈瘤 / Saccular Aneurysm

| 特徵 | 說明 |
|---|---|
| **又稱** | 漿果狀動靜脈瘤（berry aneurysm）|
| **本質** | arterial wall的局竈性外突，最常見於Willis環的分叉處 |
| **指向** | 動靜脈瘤指向進入分叉處的血流方向 |
| **好發人群** | 幾乎僅見於成人；女性略多 |
| **病因** | 血流動力學應力＋血管壁獲得性退變的組合 |

### 囊狀動靜脈瘤的危險因素 / Risk Factors for Saccular Aneurysm

| 類型 | 因素 |
|---|---|
| **非遺傳性** | 高血壓；炎症性血管病（如大動脈炎、巨細胞性動脈炎）|
| **遺傳性疾病** | 結締組織疾病（Marfan、Ehlers-Danlos）；多囊腎；神經纖維瘤病I型 |

### 動靜脈瘤的解剖 / Aneurysm Anatomy

| 結構 | 說明 |
|---|---|
| **瘤頸（neck）** | 連接動靜脈瘤與母血管的開口 |
| **瘤體（body）** | 動靜脈瘤囊 |
| **頸體比** | 影響治療選擇；相對小頸的動靜脈瘤更易於線圈栓塞 |

### 囊狀動靜脈瘤按大小分類 / Size Classification

| 大小 | 直徑 |
|---|---|
| **小型** | <1 cm |
| **中型** | >1 cm 且 <2.5 cm |
| **巨型** | >2.5 cm |

> 越大越容易破裂；巨型動靜脈瘤常因佔位效應引起顱神經麻痹

---

### 梭形動靜脈瘤 / Fusiform Aneurysm

| 特徵 | 說明 |
|---|---|
| **本質** | 段性動脈擴張，無明確瘤頸 |
| **病因** | 通常為粥樣硬化；可由慢性夾層引起 |
| **位置** | 與囊狀不同，不發生於分叉處；椎基底系統比前循環更常見 |
| **特點** | 比囊狀少見；因無瘤頸與系統循環隔絕，更難治療 |

---

### 黴菌性（感染性）動靜脈瘤 / Mycotic (Infectious) Aneurysm

| 特徵 | 說明 |
|---|---|
| **發病率** | 僅佔所有顱內動靜脈瘤的**2-4%** |
| **病因** | 敗血症栓子；**細菌性心內膜炎**是最常見的栓子來源 |
| **特點** | 與囊狀不同，形成於**遠端血管循環**（Willis環以遠）|
| **破裂風險** | 脆弱，易破裂 |

---

### 腫瘤性動靜脈瘤 / Oncotic Aneurysm

| 特徵 | 說明 |
|---|---|
| **病因** | 腫瘤導致 |
| **常見原因** | 良性左心房黏液瘤可在外周栓塞，導致遠端腫瘤性動靜脈瘤 |

---

### 外傷性假性動靜脈瘤 / Traumatic Pseudoaneurysm

| 特徵 | 說明 |
|---|---|
| **本質** | 外傷後形成；不具備典型三層血管壁結構 |
| **近端狹窄** | 動靜脈瘤近端的血管通常表現為異常管腔狹窄 |
| **特點** | 與黴菌性類似，趨向於遠端發生 |
| **易損位置** | 鄰近骨質的血管（基底動靜脈、椎動靜脈）易發生夾層性動靜脈瘤 |

### 臨床要點 / Clinical Key Points

> - **RCVS**：雷擊樣頭痛＋可逆性腦血管收縮
> - **囊狀動靜脈瘤**：最常見；Willis環分叉處；大小是破裂風險的關鍵
> - **梭形動靜脈瘤**：無瘤頸；椎基底更常見；更難治療
> - **黴菌性動靜脈瘤**：2-4%；心內膜炎病史；遠端循環；易破裂
> - **巨型動靜脈瘤**：常以佔位效應就診（顱神經麻痹）
