# Neuroimaging - Page 305

![Page 305](/core_radiology/images/neuro/page-305.png)

## 前顱底惡性腫瘤 / Malignant Anterior Skull Base Neoplasms

---

### 前顱窩腫瘤概覽 / Overview

| 要點 | 說明 |
|---|---|
| **影像學的角色** | 不是給出單一診斷，而是幫助外科醫生確定可切除性和最佳手術入路 |
| **重要描述內容** | 骨質破壞、腦實質侵犯、眼眶和海綿竇蔓延 |

### 眼眶侵犯 / Orbital Invasion

| 要點 | 說明 |
|---|---|
| **常見途徑** | 通過紙樣板（眼眶內側壁，最薄弱）|
| **腦侵犯的表現** | 可僅表現為血管性水腫（即使無強化異常）|

---

### 嗅神經母細胞瘤 / Esthesioneuroblastoma (Olfactory Neuroblastoma)

| 特徵 | 說明 |
|---|---|
| **本質** | 惡性神經脊腫瘤；起源於特化嗅上皮 |
| **組織學** | 與小細胞肺癌、神經母細胞瘤相似 |
| **年齡分布** | 雙峰分布：青少年期和中年 |
| **CT特徵** | 稍高密度（高細胞性）；常有鈣化 |
| **MRI特徵** | T1和T2中等信號（高細胞性）|
| **特異性所見** | 顱內部分邊緣的囊性病變（某些作者認為對嗅神經母細胞瘤有病理學特異性）|

---

### 鱗狀細胞癌 / Squamous Cell Carcinoma (SCC)

| 特徵 | 說明 |
|---|---|
| **發病率** | 鼻竇和鼻腔**最常見的惡性腫瘤** |
| **最常見原發部位** | 上頜竇 |
| **CT特徵** | 侵襲性、強化腫塊伴骨質破壞 |
| **與良性疾病的對比** | 強化是與良性炎症疾病（如鼻竇息肉、黏液囊腫）鑑別的關鍵 |

---

### 腺樣囊性癌 / Adenoid Cystic Carcinoma

| 特徵 | 說明 |
|---|---|
| **起源** | 可起源於鼻竇腔的小唾液腺 |
| **轉移** | 局部淋巴結轉移罕見；遠處轉移常見 |
| **MRI特徵** | T1和T2均呈水信號；但與囊腫不同，有強化 |
| **神經周圍蔓延** | 前顱底來源的腺樣囊性癌三叉神經周圍蔓延率高 |
| **評估要點** | 增強掃描評估顱神經對檢測輕微神經周圍蔓延最敏感 |

---

### 橫紋肌肉瘤 / Rhabdomyosarcoma

| 特徵 | 說明 |
|---|---|
| **發病率** | 兒童頭頸部最常見腫瘤 |
| **說明** | 在兒童影像章節討論 |

### 臨床要點 / Clinical Key Points

> - **嗅神經母細胞瘤**：雙峰年齡分布；邊緣囊性所見是特點
> - **鱗狀細胞癌**：鼻竇最常見惡性；骨質破壞＋強化與良性疾病鑑別
> - **腺樣囊性癌**：遠處轉移常見；三叉神經周圍蔓延是特點
> - 前顱底腫瘤的影像學目標是評估**可切除性**，而非確診
