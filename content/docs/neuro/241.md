![Page 241](/core_radiology/images/neuro/page-241.png)

## 鞍上區其他病變 / Other Suprasellar Lesions

---

### 視路膠質瘤 / Optic Pathway Glioma

| 特徵 | 說明 |
|---|---|
| **本質** | 累及視路（視神經、視交叉、視束）的星形細胞瘤 |
| **發病率** | 兒童鞍上區**第二常見**腫瘤（最常見為顱頜囊瘤）|
| **與NF1的關聯** | 相當一部分視路膠質瘤患者患有**神經纖維瘤病I型（NF1）** |
| **成人型** | 與兒童的低級別腫瘤不同，成人視路膠質瘤為侵襲性腫瘤 |
| **影像特徵** | T1等信號；T2高信號；通常強化 |

### NF1相關影像標誌 / NF1 Imaging Signs

| 所見 | 說明 |
|---|---|
| **視路膠質瘤** | NF1患者的鞍上區腫瘤 |
| **其他NF1表現** | 室管膜下結節、皮層/皮層下錯構瘤 |

---

### 生殖細胞瘤 / Germinoma

| 特徵 | 說明 |
|---|---|
| **發病率** | **最常見的顱內生殖細胞腫瘤** |
| **好發位置** | 80%發生於**松果體區**；20%發生於**鞍旁區** |
| **好發人群** | 兒童和青少年 |
| **影像特徵** | 均質、明顯強化的中線腫塊；T2低信號；ADC圖低信號（高細胞性）|

### 鞍上區vs松果體區生殖細胞瘤 / Suprasellar vs Pineal Germinoma

| 位置 | 特徵 |
|---|---|
| **松果體區** | 男性遠更常見 |
| **鞍上區** | 無性別差異 |

---

### 表皮樣囊腫與皮樣囊腫 / Epidermoid and Dermoid Cysts

| 特徵 | 表皮樣囊腫 | 皮樣囊腫 |
|---|---|---|
| **本質** | 先天性良性包裹囊腫 | 先天性良性包裹囊腫 |
| **好發人群** | 中年成人 | 年輕成人男性 |
| **好發位置** | CPA最常見；也可見於鞍旁區 | 後顱窨最常見；也可見於鞍旁區 |
| **T1/T2信號** | 與CSF相同 | 可含囊內脂肪 |
| **FLAIR** | **高信號**（不完全抑制）| 高信號 |
| **DWI** | **受限擴散** | 受限擴散 |
| **並發症** | — | 破裂可致化學性腦膜炎或腦室炎 |

### 皮樣囊腫的脂肪內容 / Dermoid Fat Content

- 皮樣囊腫可含囊內脂肪
- 破裂可引起**化學性腦膜炎或腦室炎**

---

### 動靜脈瘤 / Aneurysm

| 特徵 | 說明 |
|---|---|
| **位置** | 鞍上下床突段頸內动脉囊狀動靜脈瘤可類似鞍上腫瘤 |
| **重要性** | **絕對不要對可能是動靜脈瘤的腫塊進行活檢！** |
| **MRI線索** | 常規MRI序列上可見**搏動偽影** |
| **確診** | **CTA或MRA** |

---

### 鞍上區病變總結 / Suprasellar Lesions Summary

| 病變 | 特徵 |
|---|---|
| **顱頜囊瘤** | 兒童最常見；鈣化+囊性+強化 |
| **視路膠質瘤** | 兒童第二常見；NF1相關；T2高信號 |
| **生殖細胞瘤** | 兒童/青少年；明顯強化；鞍上或松果體 |
| **皮樣囊腫** | 含脂肪；破裂致化學性腦膜炎 |
| **表皮樣囊腫** | DWI受限；FLAIR不完全抑制 |
| **動靜脈瘤** | 不可活檢；MRA/CTA確診 |

### 臨床要點 / Clinical Key Points

> - **視路膠質瘤**：兒童鞍上第二常見；NF1相關；成人為侵襲性
> - **生殖細胞瘤**：兒童青少年；鞍上或松果體；T2低信號+ADC低值（高細胞性）
> - **鞍旁區轉移瘤**：**乳腺癌**是最常見累及鞍旁區的轉移瘤
> - **鞍上區囊腫**：表皮樣（DWI受限）vs 皮樣（含脂肪可破裂致化學性腦膜炎）
> - **動靜脈瘤**：MRI可見搏動偽影；**絕對不可活檢**；MRA/CTA確診
