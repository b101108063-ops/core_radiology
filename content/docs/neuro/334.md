# Neuroimaging - Page 334

![Page 334](/core_radiology/images/neuro/page-334.png)

## 硬膜內髓外腫瘤 / Intradural Extramedullary Lesions

---

### 神經鞘瘤（神經鞘瘤 vs 神經纖維瘤）/ Nerve-sheath Tumors

| 特徵 | 神經鞘瘤 | 神經纖維瘤 |
|---|---|---|
| **發病率** | 更常見 | 較少 |
| **年齡** | 老年患者 | 年輕成人 |
| **關聯** | 無特異性 | NF1 |
| **包膜** | 有包膜 | 無包膜 |
| **神經累及** | 偏心性（可保留神經）| 完全環形累及 |
| **手術** | 可「剝出」（保留神經）| 需切除神經 |

### 神經鞘瘤/神經纖維瘤的MRI特徵 / MRI Features

| 特徵 | 說明 |
|---|---|
| **形態** | 啞鈴形（15%同時有硬膜內和硬膜外）|
| **椎間孔擴大** | 典型所見 |
| **T2信號** | T2高信號 |
| **強化** | 均勻強化 |

### 靶徵 / Target Sign

| 特徵 | 說明 |
|---|---|
| **本質** | T2像上中心低信號伴周邊高信號 |
| **意義** | 提示良性 |

---

### 腦膜瘤 / Meningioma

| 特徵 | 說明 |
|---|---|
| **本質** | 起源於蛛網膜帽細胞的良性腫瘤 |
| **好發人群** | 老年女性 |
| **典型位置** | 頸椎（脊髓前方）；胸椎（脊髓後方）|
| **MRI** | 均勻強化 |
| **CT** | 常鈣化 |
| **經典型所見** | 寬基底硬膜 |

---

### 表皮囊腫 / Epidermoid Cyst

| 特徵 | 說明 |
|---|---|
| **本質** | 罕見的後天脊髓腫瘤 |
| **病因** | 新生兒腰椎穿刺時皮膚成分植入 |
| **部位** | 通常為硬膜內髓外；偶爾髓內 |
| **T1** | 低信號 |
| **T2** | 高信號 |
| **特點** | **受限擴散**（與Arachnoid囊腫鑑別）|

---

### 皮樣囊腫 / Dermoid Cyst

| 特徵 | 說明 |
|---|---|
| **本質** | 先天性囊腫 |
| **好發人群** | 通常兒童期出現 |
| **內容物** | 含有巨觀脂肪 |
| **T1** | **高信號**（脂肪）|
| **並發症** | 罕見破裂可致致命性化學性腦膜炎 |

### 臨床要點 / Clinical Key Points

> - **神經鞘瘤 vs 神經纖維瘤**：神經鞘瘤可偏心生長並保留神經；神經纖維瘤與NF1相關
> - **腦膜瘤**：老年女性；胸椎後方/頸椎前方；鈣化常見
> - **表皮囊腫**：受限擴散（與arachnoid囊腫的關鍵鑑別）
> - **皮樣囊腫**：T1高信號（脂肪）；可破裂致化學性腦膜炎
