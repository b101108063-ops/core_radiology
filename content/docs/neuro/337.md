# Neuroimaging - Page 337

![Page 337](/core_radiology/images/neuro/page-337.png)

## 脊柱腫瘤定位 / Spine Tumor Localization

### 三個間室的鑑別診斷 / Three-Compartment Differential

| 間室 | 位置 | 常見疾病 |
|---|---|---|
| **髓內** | 軟膜內、脊髓實質內 | 星形細胞瘤、室管膜瘤、血管母細胞瘤、脫髓鞘 |
| **硬膜內髓外** | 硬膜內、脊髓外 | 神經鞘瘤、腦膜瘤、皮樣/表皮囊腫、粘液乳頭狀室管膜瘤 |
| **硬膜外** | 硬膜外 | 退行性疾病、椎骨腫瘤、硬膜外轉移、血管瘤、硬膜外脂肪瘤病 |

---

### 間室定位的步驟 / Steps for Localization

| 步驟 | 操作 |
|---|---|
| **第一步** | 確定腫瘤在哪個間室 |
| **第二步** | 根據間室縮小鑑別診斷 |

### 間室邊界 / Compartment Boundaries

| 間室 | 邊界 |
|---|---|
| **髓內** | 軟膜（pia）深面 |
| **硬膜內髓外** | 硬膜內、軟膜外 |
| **硬膜外** | 硬膜外 |

---

### 硬膜外病變的常見病因 / Common Extradural Causes

| 病因 | 說明 |
|---|---|
| **轉移** | 最常見硬膜外腫瘤 |
| **椎間盤脫出** | 最常見非腫瘤性硬膜外病變 |
| **感染/膿腫** | 硬膜外膿腫 |
| **血管瘤** | 椎體血管瘤（T2高信號）|

### 脊柱腫瘤影像評估要點 / Imaging Checklist

| 評估內容 | 意義 |
|---|---|
| **腫瘤位置** | 確定間室 |
| **脊髓信號** | 評估脊髓水腫/軟化 |
| **骨質破壞** | 侵襲性 vs 良性 |
| **強化模式** | 實性 vs 囊性 |

### 臨床要點 / Clinical Key Points

> - **脊柱腫瘤定位**：首先確定在三個間室中的位置
> - **髓內**（星形細胞瘤/室管膜瘤）— 硬膜內髓外（神經鞘瘤/腦膜瘤）— 硬膜外（轉移）
> - 間室定位決定了鑑別診斷和活檢策略
> - MRI是評估脊柱腫瘤的首選成像方式
