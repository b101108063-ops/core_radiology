# Neuroimaging - Page 243

![Page 243](/core_radiology/images/neuro/page-243.png)

## 鞍上區腫塊的鑑別診斷 / Differential Diagnosis of Suprasellar Mass

### 概述 / Overview

> **鞍上區腫塊的鑑別診斷高度依賴於患者年齡**

---

### 兒童鞍上區腫塊 / Suprasellar Mass in a Child

| 診斷特徵 | 診斷 |
|---|---|
| 鈣化、強化、複雜囊性腫塊？與垂體分開？ | **顱頜囊瘤** |
| T2高信號、強化腫塊？有NF1繼發表現？ | **視路膠質瘤** |
| 明顯強化的中線腫塊？有脂肪？（皮樣——少見）| **生殖細胞瘤** |
| 不強化、灰質等信號腫塊？痴笑樣癲癇？性早熟？ | **下丘腦錯構瘤** |
| 強化、增粗的垂體柄？尿崩症？ | **Langerhans細胞組織細胞增生症垂體炎** |

---

### 成人鞍上區腫塊 / Suprasellar Mass in an Adult

| 診斷特徵 | 診斷 |
|---|---|
| 垂體腫塊向上延伸？蝶鞍擴大？ | **垂體大腺瘤** |
| 明顯強化＋蝶鞍正常？有強化硬膜尾？鄰近骨肥厚？狹窄相鄰血管？ | **腦膜瘤** |
| 鈣化、強化、複雜囊性腫塊？與垂體分開？ | **顱頜囊瘤** |
| 不強化的囊性腫塊無鈣化？ | **Rathke裂囊腫** |
| 與血池強化程度相同的強化？若有血栓則有鈣化邊緣？ | **動靜脈瘤** |
| 強化、增粗的垂體柄？尿崩症？ | **淋巴細胞性或肉芽腫性垂體炎** |

### 垂體炎補充說明 / Hypophysitis Additional Notes

| 病因 | 臨床場景 |
|---|---|
| **淋巴細胞性垂體炎** | 圍產期女性 |
| **肉芽腫性垂體炎** | 其他情況（非圍產期）|

---

### 鞍上區病變年齡鑑別總表 / Age-Based Summary

| 病變 | 兒童 | 成人 | 強化 | 鈣化 |
|---|---|---|---|---|
| **顱頜囊瘤** | ✅（最常見）| ✅（少見）| ✅ | ✅ |
| **視路膠質瘤** | ✅ | ✅（侵襲性）| ✅ | ❌ |
| **生殖細胞瘤** | ✅ | ✅ | ✅ | ❌ |
| **下丘腦錯構瘤** | ✅ | ❌ | ❌ | ❌ |
| **垂體大腺瘤** | ❌ | ✅（最常見）| ✅ | ❌ |
| **腦膜瘤** | ❌ | ✅ | ✅ | 可有 |
| **Rathke裂囊腫** | 少見 | ✅ | ❌（邊緣可有）| ❌ |
| **動靜脈瘤** | 少見 | ✅ | 與血池相同 | 血栓時有 |
| **LCH垂體炎** | ✅ | 少見 | ✅ | ❌ |

### 臨床要點 / Clinical Key Points

> - **年齡是首要考量**：兒童首先考慮顱頜囊瘤；成人首先考慮垂體大腺瘤
> - **不強化**：下丘腦錯構瘤、Rathke裂囊腫
> - **強化+鈣化**：顱頜囊瘤（兒童）
> - **強化+無鈣化**：垂體大腺瘤、腦膜瘤（成人）
> - **增粗垂體柄+尿崩症**：LCH垂體炎（兒童）、淋巴/肉芽腫性垂體炎（成人）
> - **與血池強化程度相同**：高度提示動靜脈瘤
