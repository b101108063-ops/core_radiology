# Neuroimaging - Page 338

![Page 338](/core_radiology/images/neuro/page-338.png)

## 髓內腫瘤 / Intramedullary Tumors

### 概述 / Overview

| 統計 | 數值 |
|---|---|
| **星形細胞瘤+室管膜瘤** | 佔所有髓內腫瘤的95% |
| **其他** | 血管母細胞瘤、脫髓鞘病變 |

---

### 星形細胞瘤 / Astrocytoma

| 特徵 | 說明 |
|---|---|
| **年齡** | 兒童最常見 |
| **級別** | 通常低級別（I-II）|
| **MRI** | 紡錘形脊髓擴張；多水平蔓延 |
| **囊性成分** | 約1/3出現 |
| **脊髓空洞** | 可伴隨 |
| **強化** | 幾乎總是強化 |
| **出血** | 罕見 |

### 室管膜瘤 / Ependymoma

| 特徵 | 說明 |
|---|---|
| **年齡** | 成人最常見 |
| **起源** | 脊髓中央管室管膜細胞 |
| **關聯** | NF2（尤其兒童）|
| **出血** | 常見（與星形細胞瘤的關鍵鑑別）|
| **T2所見** | 周邊含鐵血黃素（暗邊）|
| **囊性改變** | 腫瘤囊腫和極性囊腫常見 |

### 星形細胞瘤 vs 室管膜瘤 / Key Differences

| 特徵 | 星形細胞瘤 | 室管膜瘤 |
|---|---|---|
| **年齡** | 兒童 | 成人 |
| **出血** | 罕見 | **常見** |
| **與NF關聯** | NF1 | **NF2** |
| **MRI鑑別** | 困難 | 困難 |

---

### 血管母細胞瘤 / Hemangioblastoma

| 特徵 | 說明 |
|---|---|
| **發病率** | 罕見（第三常見髓內腫瘤）|
| **關聯** | VHL病（1/3相關）|
| **MRI特點** | 顯著強化＋囊腫＋流空 |
| **15%** | 同時有髓內和硬膜內髓外成分 |

### 脫髓鞘病變 / Demyelinating Lesion

| 特徵 | 說明 |
|---|---|
| **本質** | 活動性MS斑塊可強化並類似腫瘤 |
| **與腫瘤鑑別** | **無脊髓擴張** |

### 臨床要點 / Clinical Key Points

> - **星形細胞瘤**：兒童最常見；低級別；出血罕見
> - **室管膜瘤**：成人最常見；出血常見；與NF2相關
> - **血管母細胞瘤**：VHL相關；三聯徵（囊腫、強化、流空）
> - MRI上出血支持室管膜瘤而非星形細胞瘤
