## 結構性輸尿管病變 / Structural Ureteral Lesions

### 腎盂輸尿管連接處阻塞 / Ureteropelvic Junction Obstruction (UPJ Obstruction)

#### 臨床特點 / Clinical Features
- 可為原發性或繼發性（感染、結石或既往手術）
- **原發性 UPJ 阻塞**可能原因：
  - 先天性無蠕動段輸尿管
  - 輸尿管在腎盂的高位插入
  - 橫越血管造成外源性壓迫

#### 診斷要點 / Diagnostic Key Points
- **關鍵影像學發現：** 腎盂擴張而輸尿管口徑正常

---

### 輸尿管囊腫 / Ureterocele

#### 疾病名稱 / Disease Name
**輸尿管囊腫（Ureterocele）**

#### 定義 / Definition
- 輸尿管最遠端部分的局灶性擴張，突出至膀胱內

#### 分型 / Classification

| 類型 | 特點 |
|---|---|
| **原位性（Orthotopic）** | 輸尿管正常插入；常見於成人；又稱「簡單型、成人型、膀胱內」；通常無症狀 |
| **異位性（Ectopic）** | 發生於重複集合系統，上極輸尿管異位插入膀胱；通常在兒童確診 |
| **假性輸尿管囊腫（Pseudoureterocele）** | 遠端輸尿管套疊入膀胱，可由腫瘤、放射性膀胱炎或輸尿管膀胱連接處結石引起 |

#### 影像學特點 / Imaging Features
- CT 表現取決於類型
- 重複輸尿管可見雙套輸尿管
- 上極輸尿管囊腫可見積水和上極輸尿管擴張

#### 診斷要點 / Diagnostic Key Points
| 類型 | 影像學特點 |
|---|---|
| 原位性 | 正常插入，膀胱內囊腫；成人 |
| 異位性 | 重複系統，上極輸尿管囊腫；兒童 |
| 假性 | 遠端輸尿管套疊；繼發於腫瘤/放射性膀胱炎/UVJ 結石 |

---

### 臨床要點 / Clinical Key Points
- **UPJ 阻塞：** 腎盂擴張 + 正常口徑輸尿管；先天性或後天性
- **輸尿管囊腫：** 膀胱內輸尿管末端囊性擴張
- **原位性：** 成人，無症狀，通常不需要治療
- **異位性：** 兒童，與重複集合系統相關
- **假性輸尿管囊腫：** 輸尿管套疊入膀胱，需找出根本原因（腫瘤、結石、放射性）
