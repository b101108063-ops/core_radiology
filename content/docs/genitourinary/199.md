# Genitourinary Imaging - Page 199

![Page 199](/core_radiology/images/genitourinary/page-199.png)

## 前列腺癌分期 / Prostate Cancer Staging

### 分期的主要目標 / Primary Goal
- **區分手術性疾病和非手術性疾病**
  - 腫瘤限於腺體內（T2）：通常適合根除性前列腺切除術
  - 腫瘤扩散至腺體外（T3 及以上）：通常非手術治療（如抗雄激素和放射治療）

---

### T 分期 / T-Staging

| 分期 | 描述 |
|---|---|
| **T1** | 僅由活檢發現的腫瘤 |
| **T2** | 腫瘤限於前列腺內 |
| &nbsp;&nbsp;&nbsp;&nbsp;T2a | 單側葉的 <50% |
| &nbsp;&nbsp;&nbsp;&nbsp;T2b | 單側葉的 >50% |
| &nbsp;&nbsp;&nbsp;&nbsp;T2c | 腫瘤累及雙側葉 |
| **T3** | 腫瘤穿透前列腺包膜；可累及精囊 |
| **T4** | 腫瘤侵犯精囊以外的鄰近結構 |

---

### N 分期 / N-Staging

| 分期 | 描述 |
|---|---|
| **N1** | 區域淋巴結轉移 |
| **M1a** | 非區域（盆腔外）淋巴結 |

---

### M 分期 / M-Staging

| 分期 | 描述 |
|---|---|
| **M0** | 無遠處轉移 |
| **M1a** | 非區域淋巴結 |
| **M1b** | 骨轉移 |
| **M1c** | 其他轉移 |

---

### 分期示例：T2a 前列腺癌 / Staging Example: T2a Prostate Cancer

| 影像學發現 | 說明 |
|---|---|
| T2 軸位（直腸線圈） | 左側後周邊區低信號灶；侷限於腺體內 |
| ADC 圖 | 腫瘤呈受限擴散（ADC 圖上呈低信號） |
| 動態對比增強 | 腫瘤相對高強化 |

- 腫瘤完全限於腺體內，小於單側葉的 50% → **T2a**
- 因腫瘤很小，擴散成像和動態對比增強有助於提高特異性

---

### 臨床要點 / Clinical Key Points
- **T2a vs T2b：** 以單側葉 50% 為界
- **T2c：** 雙側葉受累
- **T3a：** 僅包膜外侵犯；精囊未受累
- **T3b：** 腫瘤侵犯精囊
- **N1：** 區域淋巴結轉移
- **M 分期：** M1a（非區域淋巴結）、M1b（骨轉移）、M1c（其他）
