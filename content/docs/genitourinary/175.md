## Text Content

### 腎臟 / Kidneys — 腎臟佔位診斷方法 / Diagnostic Approach to a Renal Mass

#### 腎臟佔位多期 CT 掃描協定 / Renal Mass Protocol Multiphase CT

| 時相 | 延遲時間 | 用途 |
|------|---------|------|
| **平掃期（Unenhanced）** | — | 基線，用於量化增強程度 |
| **腎實質期（Nephrographic）** | 100 秒 | 評估強化的關鍵時相（與平掃對比） |
| **泌尿道期（Pyelographic / Excretory）** | 15 分鐘 | 鑑別水腎與囊腫；顯示收集系統關係 |

**泌尿道期的關鍵應用：**

| 情況 | 平掃表現 | 泌尿道期表現 |
|------|---------|------------|
| 水腎 | 扩张 | **顯影劑填充**（高密度） |
| 腎竇囊腫 | 扩张 | **不顯影** |

> **反流性腎病（Reflux nephropathy）**：腎盞擴張可模擬囊性腎臟佔位，泌尿道期可見顯影劑填充擴張腎盞

#### 評估強化（CT 和 MRI）

**CT 強化標準（相對於平掃的絕對 HU 增加值）：**

| 強化程度 | HU 增加 | 意義 |
|---------|--------|------|
| 無強化 | **<10 HU** | |
| 模糊強化 | **10-19 HU** | |
| 明確強化 | **≥20 HU** | |

**MRI 強化標準（相對於平掃的訊號強度百分比增加）：**

| 強化程度 | % 增加 | 意義 |
|---------|--------|------|
| 無強化 | **<15%** | |
| 模糊強化 | **15-19%** | |
| 明確強化 | **≥20%** | |

> **病灶太小無法判斷**：若直徑小於掃描層厚的兩倍，則無法準確判斷衰減或強化（例如：3 mm 層厚，<6 mm 病灶無法準確評估）

#### 腎臟佔位穿刺活檢適應症 / Indications for Renal Mass Biopsy

- 已知原發腫瘤患者：區分腎細胞癌與轉移
- 區分腎感染與囊性腫瘤
- 確診高密度、均勻強化的佔位（MRI 排除後）：可能為少脂肪性血管肌肉脂肪瘤或腎細胞癌
- 多共病症、腎切除高風險患者：確診可疑腎佔位
- 腎佔位燒灼治療前行：確保正確組織診斷

---

### 臨床要點 / Clinical Key Points
> - **CT 強化診斷閾值**：≥20 HU（相對於平掃）＝明確強化；<10 HU＝無強化
> - **MRI 強化診斷閾值**：≥20% 訊號增加＝明確強化
> - **泌尿道期（15 分鐘）**：區分水腎（顯影劑填充）與腎竇囊腫（不顯影）；也用於盞憩室和手術規劃
> - 病灶 <6 mm（3 mm 層厚）時無法準確評估強化
> - 穿刺活檢適應症：原發腫瘤分期、囊性/感染鑑別、少脂肪 AML 確診、高風險患者
