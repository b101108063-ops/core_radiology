## Text Content

### 多囊性腎疾病與腎臟腫瘤風險 / Multicystic Renal Disease and Risk for Renal Neoplasm

#### 體染色體顯性多囊性腎病（ADPKD）

| 項目 | 說明 |
|------|------|
| 長期透析患者病因 | 佔 10% |
| 發病年齡 | 通常 30-40 歲 |
| 臨床表現 | 上腹痛、進行性腎功能衰竭；腎臟可大到觸及；高血壓和血尿常見（因結石或囊腫破裂入收集系統） |
| 顱內血管 | 約半數患者有威利斯環囊狀動脈瘤 |

- 傳統認為 ADPKD 不增加腎細胞癌風險，但部分作者認為風險輕微增加
- ADPKD 相關 RCC：發病年齡較輕，常為雙側性、多灶性，肉瘤樣型比例較高
- 診斷複雜性：多發（常為出血性）囊腫＋常伴腎功能不全（可能無法使用靜脈注射對比劑）

#### 獲得性囊性腎病（終末期腎病）

| 項目 | 說明 |
|------|------|
| 風險 | 腎細胞癌風險增加 |
| 發生率 | 約 2-3%（對比普通人群 1/10,000） |

### 腎臟感染與發炎 / Renal Infection and Inflammation

#### 腎盂腎炎 / Pyelonephritis

**腎盂腎炎**是腎實質的感染，是腎臟最常見的細菌感染；通常由膀胱逆行上升引起。

| 項目 | 說明 |
|------|------|
| 影像發現 | 非特異性；高達 75% 影像可能正常 |
| 表現形式 | 單側腎臟增大、楔形或條紋狀低強化區、腎周條索影；泌尿道上皮可增厚高強化 |

**單側腎臟增大的鑑別診斷：**
- 腎盂腎炎
- 急性輸尿管阻塞
- 腎靜脈血栓形成
- 代償性肥大

**條紋狀腎造影（Striated nephrogram）：** 對比增強圖像上從腎皮質延伸到髓質的線狀低密度區

| 條紋狀腎造影的鑑別診斷 |
|------------------------|
| 腎盂腎炎 |
| 急性尿路阻塞 |
| 腎梗塞 |
| 腎腫瘤（尤其是淋巴瘤浸潤型） |
| 腎靜脈血栓或血管炎 |
| 放射性腎炎 |
| 腎挫傷（通常局灶性） |

- **局灶性腎盂腎炎（focal pyelonephritis）**：可模擬腎臟腫塊
- 患側可見輕度水腎（因細菌內毒素降低蠕動），不應與阻塞性尿路病混淆

### 臨床要點 / Clinical Key Points
> - **ADPKD**：30-40 歲發病；10% 透析患者病因；約 50% 有顱內囊狀动脉瘤；傳統認為不增加 RCC 風險
> - **獲得性囊性腎病**：透析患者；RCC 風險增加（2-3%）
> - **條紋狀腎造影**鑑別診斷：腎盂腎炎、急性阻塞、腎梗塞、淋巴瘤、靜脈血栓、放射性腎炎
> - **局灶性腎盂腎炎**可模擬腎腫塊；輕度水腎為常見表現
