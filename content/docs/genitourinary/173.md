## Text Content

### 嗜鉻細胞瘤 / Pheochromocytoma

**嗜鉻細胞瘤**是嗜鉻細胞的腫瘤，通常起源於腎上腺髓質。可引起**高血壓**和**發作性頭痛/出汗**。

#### 10% 規則 / Rule of 10's

| 特徵 | 比例 |
|------|------|
| 腎上腺外 | 10% |
| 雙側性 | 10% |
| 惡性 | 10% |
| 家族性/症候群性 | 10% |

#### 相關症候群

| 症候群 | 特點 |
|--------|------|
| **MEN 2A / 2B** | 通常為雙側腎上腺內嗜鉻細胞瘤 |
| **Von Hippel-Lindau（VHL）** | |
| **神經纖維瘤病第一型（NF1）** | |
| **Carney's 三徵** | 胃腸道平滑肌肉瘤＋肺軟骨瘤＋腎上腺外嗜鉻細胞瘤 |

#### 腎上腺外嗜鉻細胞瘤（副神經節瘤）

- 腎上腺外嗜鉻細胞瘤稱為**副神經節瘤（Paraganglioma）**
- 最常見的腹腔內位置：**Zuckerkandl 器**（主動脈分叉處）
- 膀胱罕見副神經節瘤：特徵性臨床表現為**排尿後暈厥（post-micturition syncope）**

#### 頭頸部副神經節瘤（Glomus tumors）

| 位置 | 名稱 |
|------|------|
| 鼓膜 | Glomus tympanicum |
| 頸靜脈孔 | Glomus jugulare |
| 頸動脈體 | 頸動脈體瘤（Carotid body tumor） |
| 迷走神經 | Glomus vagale |

#### 核醫檢查

- **I-123 MIBG**：用於腎上腺嗜鉻細胞瘤轉移評估
- **In-111 pentetreotide（octreotide 類似物）**：用於副神經節瘤定位

> 理論上：先做尿/血漿甲基腎上腺素確診，再做影像定位和分期；臨床上常因疑似症狀直接做 CT

---

### 臨床要點 / Clinical Key Points
> - **嗜鉻細胞瘤**：10% 規則（腎上腺外/雙側/惡性/家族性各 10%）；與 MEN2、VHL、NF1、Carney 三徵相關
> - **副神經節瘤**：腎上腺外最常見於 Zuckerkandl 器（主動脈分叉）；膀胱副神經節瘤→排尿後暈厥
> - **MRI T2 高訊號**是嗜鉻細胞瘤的典型表現；CT 上大病灶常見壞死
> - 核醫：I-123 MIBG（嗜鉻細胞瘤轉移）；In-111 pentetreotide（副神經節瘤定位）
