# Genitourinary Imaging - Page 190

![Page 190](/core_radiology/images/genitourinary/page-190.png)

## 良性輸尿管腫塊與發炎性疾病 / Benign Ureteral Masses and Inflammatory/Infectious Ureteral Disease

### 良性輸尿管腫塊 / Benign Ureteral Masses

| 病變 | 特點 |
|---|---|
| **纖維上皮息肉（Fibroepithelial polyp）** | 最常見的良性輸尿管腫瘤；好發於近端輸尿管；有長柄；呈現為細長平滑的管狀病變 |
| **泌尿道上皮乳頭瘤（Urothelial papilloma）** | 罕見良性腫瘤，可長得很大類似惡性腫瘤 |
| **內翻性乳頭瘤（Inverted papilloma）** | 良性腫塊，中心為泌尿道上皮 |

---

### 發炎性與感染性輸尿管疾病 / Inflammatory and Infectious Ureteral Disease

#### 囊性輸尿管炎 / Ureteritis Cystica

| 項目 | 內容 |
|---|---|
| **性質** | 對慢性泌尿系統發炎（如慢性感染或結石）的良性反應 |
| **部位** | 單側，輸尿管近端 1/3 和腎盂 |
| **惡性風險** | **無惡性潛能** |
| **影像學特點** | 腎盂或輸尿管內多個微小充盈缺損 |

- 膀胱對應病變稱為**囊性膀胱炎（Cystitis cystica）**，表現為膀胱底部多個圓形輪廓缺損

#### 白斑病（鱗狀化生）/ Leukoplakia (Squamous Metaplasia)

| 項目 | 內容 |
|---|---|
| **性質** | 罕見的泌尿道上皮發炎症性疾病，因特徵性白斑而得名 |
| **惡性風險** | 腎集合系統受累時**無明顯惡性風險**；但膀胱白斑病與鱗狀細胞癌有相關性 |
| **影像學特點** | 扁平原發性腫塊或局灶性壁增厚；可呈「燈芯絨」外觀 |

#### 軟化斑 / Malacoplakia

| 項目 | 內容 |
|---|---|
| **性質** | 與慢性泌尿系統感染（通常為大腸桿菌）相關的發炎性疾病 |
| **好發人群** | 中年女性 |
| **惡性風險** | **無惡性潛能** |
| **影像學特點** | 多個扁平充盈缺損，好發於**遠端輸尿管** |

#### 輸尿管結核 / Ureteral Tuberculosis

| 項目 | 內容 |
|---|---|
| **特點** | 多灶性輸尿管狹窄提示輸尿管結核 |
| **佐證** | 腎結核（實質鈣化和疤痕）和/或膀胱結核（膀胱容量小、壁增厚）證據 |

---

### 輸尿管充盈缺損的鑑別診斷 / Differential Diagnosis of Ureteral Filling Defect

| 疾病 | 說明 |
|---|---|
| **泌尿道上皮癌（TCC）** | 最常見的輸尿管惡性腫瘤 |
| 輸尿管結石 | 非增強圖像上幾乎總是可見 |
| 血塊 | - |
| 白斑病 | 可呈「燈芯絨」外觀 |
| 感染性碎屑（如黴菌球） | - |
| 軟化斑 | 多個扁平缺損，遠端輸尿管 |
| 脫落的乳頭 | - |
| 良性輸尿管腫塊 | 如纖維上皮息肉 |

---

### 臨床要點 / Clinical Key Points
- **纖維上皮息肉：** 最常見的良性輸尿管腫瘤；有長柄，近端輸尿管好發
- **囊性輸尿管炎：** 無惡性潛能；多個微小充盈缺損
- **軟化斑：** 中年女性；遠端輸尿管多個扁平缺損
- **輸尿管結核：** 多灶性狹窄為特徵
- **泌尿道上皮癌是輸尿管充盈缺損的首要擔憂**
