## 腎臟感染（續）/ Renal Infections (continued)

### 腎積膿 / Pyonephrosis

#### 疾病名稱 / Disease Name
**腎積膿（Pyonephrosis）**

#### 臨床特點 / Clinical Features
- 感染的集合系統阻塞
- 口語化稱為「**高壓下的膿（Pus under pressure）**」
- 需緊急經皮腎造口引流

---

### 腎膿腫 / Renal Abscess

#### 疾病名稱 / Disease Name
**腎膿腫（Renal Abscess）**

#### 臨床特點 / Clinical Features
- 腎臟內局限性膿性積液，最常見於急性細菌性腎盂腎炎中小膿腫融合
- 可類似囊性腎臟腫塊

#### 治療 / Treatment
| 大小 | 處理 |
|---|---|
| <3 cm | 保守治療 |
| ≥3 cm | 經皮穿刺引流 |

---

### 氣腫性腎盂腎炎 / Emphysematous Pyelonephritis

#### 疾病名稱 / Disease Name
**氣腫性腎盂腎炎（Emphysematous Pyelonephritis）**

#### 臨床特點 / Clinical Features
- 嚴重腎臟感染，以腎實質被**氣體取代**為特徵
- 由產氣菌和腎梗塞共同引起
- **幾乎僅見於糖尿病患者**
- **外科急症，需緊急腎切除術**

#### 診斷要點 / Diagnostic Key Points
- CT 表現：氣體取代腎臟的某部分，可延伸至輸尿管
- 需緊急手術干預

---

### 黃色肉芽腫性腎盂腎炎 / Xanthogranulomatous Pyelonephritis (XGP)

#### 疾病名稱 / Disease Name
**黃色肉芽腫性腎盂腎炎（Xanthogranulomatous Pyelonephritis, XGP）**

#### 臨床特點 / Clinical Features
- 慢性腎臟感染，由**阻塞性結石**引起，導致腎實質被纖維脂肪發炎組織取代
- 最常見病原菌：**奇異變形桿菌（Proteus mirabilis）**和大腸桿菌（*E. coli*）
- 臨床表現：腰痛、發燒、體重減輕等非特異性全身症狀；常見貧血和血尿

#### 診斷要點 / Diagnostic Key Points
- **CT 是首選檢查**，表現包括：
  - 腎實質脂肪替代
  - 顯著腎周發炎條紋影
  - **鹿角結石（Staghorn calculi）**
  - 腎臟增大、強化降低
- **「熊爪徵（bear paw sign）」**：低衰減纖維脂肪團塊呈放射狀排列，類似熊爪

| XGP 形態 | 說明 |
|---|---|
| 瀰漫型（85%） | - |
| 局灶型 | 又稱「腫塊型 XGP」，可類似腎臟腫瘤 |

#### 鑑別診斷 / Differential Diagnosis
- 急性阻塞性結石伴腎積膿
- 腎/泌尿道上皮腫瘤伴鈣化

#### 治療 / Treatment
- **腎切除術**

### 腎結核 / Renal Tuberculosis

#### 疾病名稱 / Disease Name
**腎結核（Renal Tuberculosis）**

#### 臨床特點 / Clinical Features
- 由**血行播散**引起的腎實質結核分枝桿菌感染
- 約 10% 伴有活動性肺結核
- 初始感染通常累及雙側腎臟，慢性改變常為單側性

#### 診斷要點 / Diagnostic Key Points
- 影像學表現：實質鈣化、疤痕、乳頭壞死、漏斗部狹窄
- **末期腎結核** → **自體腎切除（Autonephrectomy）**和特徵性的「**膏狀腎（Putty kidney）**」外觀（萎縮、鈣化的腎臟）

---

### 臨床要點 / Clinical Key Points
- **腎積膿：** 感染的阻塞集合系統；緊急經皮腎造口引流
- **腎膿腫：** <3 cm 保守治療；≥3 cm 穿刺引流
- **氣腫性腎盂腎炎：** 糖尿病患者；氣體取代腎實質；外科急症
- **黃色肉芽腫性腎盂腎炎：** 鹿角結石 + 腎實質脂肪替代 + 熊爪徵；腎切除術
- **腎結核：** 乳頭壞死、漏斗部狹窄、膏狀腎
