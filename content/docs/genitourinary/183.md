# Genitourinary Imaging - Page 183

![Page 183](/core_radiology/images/genitourinary/page-183.png)

## Text Content

### 腎積膿 / Pyonephrosis

**腎積膿**是阻塞收集系統的感染，口語稱為「加壓的膿」。治療為**緊急經皮腎造口術**。

---

### 腎膿腫 / Renal Abscess

- 腎膿腫是腎臟內局限性化膿性集合，最常見於急性細菌性腎盂腎炎的小膿腫融合
- 可模擬囊性腎細胞癌
- **治療：<3 cm 保守治療；>3 cm 經皮穿刺引流**

---

### 氣性腎盂腎炎 / Emphysematous Pyelonephritis

**氣性腎盂腎炎**是一種以氣體取代腎實質為特徵的嚴重腎臟感染，由產氣菌和腎梗塞共同引起。

| 特徵 | 說明 |
|------|------|
| 好發人群 | **幾乎只見於糖尿病患者** |
| 治療 | **外科急症，需緊急腎切除** |
| CT 表現 | 氣體取代腎臟部分或全部；氣體可延伸至輸尿管 |

> 氣性腎盂腎炎是**外科急症**，區別於腎積膿（兩者都見於阻塞性尿路病）

---

### 黃色肉芽腫性腎盂腎炎 / Xanthogranulomatous Pyelonephritis (XGP)

**XGP**是一種因阻塞性結石引起的**慢性腎臟感染**，導致腎實質被纖維脂肪發炎組織取代。

| 項目 | 說明 |
|------|------|
| 常見菌種 | **Proteus mirabilis** 和 **Escherichia coli** |
| 臨床表現 | 腰痛、發燒、體重減輕（非特異性）；貧血和血尿常見 |
| 分型 | 瀰漫型（85%）或局灶型（又称「腫瘤性 XGP」） |

**CT 特徵：**

| 表現 | 說明 |
|------|------|
| 腎臟 | 明顯增大、強化差的腎臟 |
| 鹿角形結石 | 常見 |
| 筋膜增厚 | Zuckerkandl's fascia 和 Gerota's fascia |
| 腎周條索影 | |
| 後腹腔淋巴結病 | |
| **熊爪徵（bear paw sign）** | 低密度纖維脂肪團塊呈放射狀排列，形似熊爪 |

**鑑別診斷：** 急性阻塞性結石伴腎積膿，或腎/過渡細胞腫瘤伴鈣化

> **注意：** "lobster claw sign" 是乳頭壞死的表現；"bear paw sign" 是 XGP 的表現（兩者不要混淆）

---

### 臨床要點 / Clinical Key Points
> - **腎積膿**：阻塞＋感染；緊急經皮腎造口術
> - **腎膿腫**：<3 cm 保守；>3 cm 穿刺引流；可模擬囊性 RCC
> - **氣性腎盂腎炎**：幾乎只見於糖尿病；外科急症（緊急腎切除）；氣體取代腎實質
> - **XGP**：慢性阻塞性結石引起；**熊爪徵**是特徵性表現；需與腎腫瘤鑑別
> - **Bear paw sign**（XGP）vs **Lobster claw sign**（乳頭壞死）：兩者不要混淆
