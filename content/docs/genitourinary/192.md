# Genitourinary Imaging - Page 192

![Page 192](/core_radiology/images/genitourinary/page-192.png)

## Text Content

### 膀胱 / Bladder

#### 膀胱結石 / Bladder Stones

| 項目 | 說明 |
|------|------|
| 危險因子 | 尿瀦留（最常見：膀胱出口阻塞）和慢性炎症 |
| 偏離中線的結石 | 提示可能被膀胱腫瘤或前列腺增大推移；或位於輸尿管囊腫/膀胱憩室內的結石 |

#### 膀胱尿路上皮癌 / Bladder Transitional Cell Carcinoma (TCC)

| 項目 | 說明 |
|------|------|
| 發病情況 | 老年人；男性多見；最常見的膀胱癌（膀胱是泌尿道最常見的惡性腫瘤部位） |
| 危險因子 | 吸菸、芳香胺 |
| 臨床表現 | **無痛性血尿** |

**分期與治療：**

| 分期 | 說明 | 治療 |
|------|------|------|
| **器官局限** | 非肌肉浸潤性（70%） | 內視鏡切除 |
| | 浸潤性（25%） | 根除性膀胱切除＋淋巴結清除 |
| **轉移性（5%）** | | 全身化療 |

> 注意：即使 CT 尿路造影陰性，如臨床上懷疑膀胱癌，仍需做膀胱鏡檢查

#### 膀胱腺癌 / Bladder Adenocarcinoma

| 項目 | 說明 |
|------|------|
| 發病情況 | 罕見 |
| 相關 | 與**臍尿管（urachal）殘餘**相關 |

**臍尿管腺癌：** MRI T2 高訊號且明顯強化的腫塊，直接位於膀胱上方；同時連接膀胱和臍部

---

### 臨床要點 / Clinical Key Points
> - **膀胱 TCC**：最常見膀胱癌；無痛性血尿；70% 非肌肉浸潤（內視鏡切除）；25% 浸潤性（膀胱切除）
> - **膀胱腺癌**：罕見；與臍尿管殘餘相關
> - 偏離中線的膀胱結石：需注意是否有膀胱腫瘤或前列腺增大推移
> - 臨床上懷疑膀胱癌時，CTU 陰性不能免除膀胱鏡檢查
