## Text Content

### 卵巢囊腫與腫瘤 / Ovarian Cysts and Neoplasms

#### 卵巢囊腫

| 類型 | 說明 |
|------|------|
| **功能性囊腫**（濾囊囊腫、黃體囊腫） | 正常月經週期的偶發結果；通常在 6-8 週內自行消退 |
| **巧克力囊腫（Endometrioma）** | 子宮內膜異位症的囊腫；T1 和 T2 均為高訊號（「闇黑巧克力」外觀） |
| **囊腺瘤（Cystadenoma）** | 漿液性（薄壁單房）或黏液性（多房性；T1 高訊號） |

#### 卵巢惡性腫瘤

| 腫瘤類型 | 特徵 |
|---------|------|
| **漿液性囊腺癌（Serous cystadenocarcinoma）** | 最常見的卵巢惡性腫瘤；通常為雙側性；乳頭狀突起 |
| **黏液性囊腺癌（Mucinous cystadenocarcinoma）** | 體積通常較大；單側；可達巨大體積 |
| **生殖細胞腫瘤** | 畸胎瘤（dermoid cyst）：包含脂肪、囊變；皮樣囊腫 |
| **性索間質腫瘤** | 顆粒細胞瘤（granulosa cell tumor）：可產生雌激素 |

#### 卵巢囊腫的 MRI 特徵

| 囊腫類型 | T1 訊號 | T2 訊號 | 強化 |
|---------|---------|---------|------|
| 簡單囊腫 | 低 | 高 | 無 |
| 巧克力囊腫 | **高** | 高或中等 | 無 |
| 黏液性囊腺瘤 | 高 | 高 | 囊壁/分隔輕度強化 |
| 皮樣囊腫（畸胎瘤） | 混合（脂肪高訊號） | 混合 | 無（脂肪抑制序列確認） |

### 子宮內膜異位症 / Endometriosis

| 項目 | 說明 |
|------|------|
| 定義 | 子宮內膜組織出現在子宫外（卵巢、子宮韌帶、腹膜等） |
| **巧克力囊腫** | 卵巢內的出血性子宮內膜異位囊腫；T1 和 T2 均高訊號 |
| 診斷 | 腹腔鏡＋病理學確診；MRI 是重要的術前評估工具 |
| 併發症 | 不孕、疼痛、腸道/膀胱受累 |

---

### 臨床要點 / Clinical Key Points
> - **巧克力囊腫**：T1 和 T2 均高訊號（「闇黑巧克力」）；為卵巢內，子宮內膜異位症特徵
> - **畸胎瘤（皮樣囊腫）**：含脂肪；脂肪抑制序列確認
> - **漿液性囊腺癌**：最常見卵巢惡性腫瘤；雙側性；乳頭狀突起
> - **黏液性囊腺癌**：可達巨大體積；單側
> - 子宮內膜異位症：巧克力囊腫＋腹膜病灶；可侵犯腸道和膀胱
> - 影像上，**T1 高訊號的卵巢囊腫**應考慮：巧克力囊腫、黏液性囊腺瘤/癌、畸胎瘤（脂肪）
