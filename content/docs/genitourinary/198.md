## Text Content

### 攝護腺癌分期範例 / Staging Examples of Prostate Cancer

#### 範例一：T2a N0 M0（可手術治療）

- 腫瘤**完全局限於腺體內**
- 腫瘤累及不到單側葉的 50%（T2a）
- 高級 MRI 技術（DWI 和 DCE-MRI）對這種小病灶特別有幫助，可提高特異度

#### 範例二：T3b N1（通常非手術治療）

| 發現 | 分期意義 |
|------|---------|
| 雙側葉大部分週邊區被腫瘤取代 | T3（腺外延伸） |
| 左側腺外蔓延，精囊被腫瘤包圍 | **T3b**（精囊侵犯） |
| 區域淋巴結存在 | **N1** |

> 當解剖圖像已清楚顯示惡性行為時，高級 MRI 技術價值有限（無需額外功能成像確認）

---

### 攝護腺癌 MRI 報告要點

| 項目 | 說明 |
|------|------|
| 腫瘤位置 | 週邊區（最常見）/ 中央腺體 |
| 腫瘤大小 | 最大徑（cm） |
| 腫瘤範圍 | 單側葉/雙側葉；估計所佔葉比例 |
| 包膜外延伸（EPE） | 有/無；如存在：單側/雙側 |
| 精囊侵犯 | 有/無（T3b） |
| 鄰近結構侵犯 | 有/無（T4） |
| 淋巴結狀態 | N0/N1 |
| 骨轉移 | M0/M1b（如有骨骼掃描或 MRI 證據） |

---

### 臨床要點 / Clinical Key Points
> - **T2a** 腫瘤（<50% 單側葉）→ 根除性切除候選；**T3b N1**（精囊侵犯＋淋巴結轉移）→ 非手術治療
> - MRI 報告需明確：腫瘤位置、大小、葉內範圍、包膜外延伸、精囊侵犯、淋巴結狀態
> - **精囊被腫瘤包圍（engulfment）**是 T3b 的確切證據
> - 區域淋巴結 = 閉孔、髂內、髂外、骶前淋巴結；任何這些淋巴結增大均為 N1
