## Text Content

### 膀胱創傷 / Bladder Trauma

#### CT 膀胱造影適應症與方法

| 項目 | 說明 |
|------|------|
| **首選檢查** | **CT 膀胱造影（CT cystography）** |
| **關鍵要求** | 膀胱需**完全充盈**才能評估膀胱破裂；延遲成像的 IV 對比劑研究**敏感度不夠**，不是標準照護 |
| 容積 | 至少 **350 mL**（或患者能耐受的最大量） |
| 對比劑 | 稀釋水溶性對比劑（50 mL IV 對比劑＋500 mL 溫熱生理鹽水） |
| 注入方式 | 經重力作用，袋子抬高 **40 cm** 高於膀胱 |

> 男性患者膀胱損傷可能伴有**尿道損傷**；如有尿道口出血或肉眼血尿，應在放置 Foley 導管前行**逆行性尿道造影（RUG）**

#### 膀胱損傷分類

| 類型 | 說明 |
|------|------|
| **腹膜外破裂**（最常見） | 與骨盆骨折相關；保守治療（導尿管） |
| **腹膜內破裂** | 膀胱頂部爆裂；需手術修復 |
| **混合型** | |

---

### 腹膜外膀胱破裂 / Extraperitoneal Bladder Rupture

| 項目 | 說明 |
|------|------|
| 發生率 | 至少是腹膜內破裂的兩倍 |
| 與骨盆骨折關聯 | 比腹膜內破裂更常見 |
| **特徵性徵象** | **Molar tooth sign（磨牙徵）**：倒 U 形對比劑外滲至 Retzius 間隙 |
| 治療 | **保守治療**（放置導尿管） |

---

### 腹膜內膀胱破裂 / Intraperitoneal Bladder Rupture

| 項目 | 說明 |
|------|------|
| 機制 | 膀胱充盈時受壓，於頂部爆裂進入腹膜 |
| **pathognomonic 影像表現** | 對比劑**進入腸道之間的腹膜腔** |
| 治療 | **手術治療** |

---

### 臨床要點 / Clinical Key Points
> - **CT 膀胱造影**：膀胱完全充盈（≥350 mL）是評估膀胱破裂的關鍵
> - **腹膜外破裂**（最常見）vs **腹膜內破裂**：前者與骨盆骨折相關，保守治療；後者需手術修復
> - **Molar tooth sign**：腹膜外破裂的特徵性表現（倒 U 形對比劑外滲至 Retzius 間隙）
> - 男性創傷患者：如有尿道口出血或肉眼血尿，先行 **RUG** 再放 Foley 導管
