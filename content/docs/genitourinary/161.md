# Genitourinary Imaging - Page 161

![Page 161](/core_radiology/images/genitourinary/page-161.png)

## 瀰漫性腹膜疾病 / Diffuse Peritoneal Disease

### 腹膜癌病 / Peritoneal Carcinomatosis

#### 疾病名稱 / Disease Name
**腹膜癌病（Peritoneal Carcinomatosis）**

#### 臨床特點 / Clinical Features
- 代表播散至腹膜表面的轉移瘤
- **胃癌、卵巢癌、乳癌、肺癌、胰臟癌、膽道癌、結腸癌和黑色素瘤**可轉移至腸繫膜淋巴結
- **網膜餅（Omental caking）**：網膜脂肪被腫瘤和纖維化取代
- **黏液性腺癌**是最常見引起腹膜癌病的腫瘤類型
- 可伴有**克魯肯伯瘤（Krukenberg tumors）**（卵巢轉移，常為雙側）

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：**
  - 網膜改變：網膜脂肪密度增加、結節狀或板狀增厚
  - 腹膜增厚和結節
  - 腹水
  - 腸繫膜受累
- **「三明治徵（Sandwich Sign）」：** 腸繫膜淋巴瘤特徵，淋巴結塊從兩側包夾腸繫膜脂肪和血管（被形容為「麵包」），脂肪和血管為「餡料」

#### 鑑別診斷 / Differential Diagnosis
- 結核性腹膜炎
- 腹膜間皮瘤
- 硬化性腹膜炎

#### 治療 / Treatment
- 腫瘤細胞減滅術 + 腹腔熱化療（HIPEC）

### 偽腹膜黏液瘤 / Pseudomyxoma Peritonei

#### 疾病名稱 / Disease Name
**偽腹膜黏液瘤（Pseudomyxoma Peritonei）**

#### 臨床特點 / Clinical Features
- 通常來源於**闌尾黏液性腫瘤**或卵巢黏液性囊腺瘤
- 黏液性腫瘤細胞種植於腹膜，產生大量黏液

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：**
  - 腹膜和網膜瀰漫性黏液性物質沉積
  - 肝脾邊緣壓迫徵（ scalloped appearance）
  - 腹水但不同於普通腹水（CT 值略高）
  - 「囊腫」樣外觀
- **特徵性：** 黏液性物質在腹腔內重 力性分布

#### 鑑別診斷 / Differential Diagnosis
- 腹膜癌病（黏液性腺癌来源）
- 結核性腹膜炎
- 腹膜膠質瘤病

---

### 臨床要點 / Clinical Key Points
- **腹膜癌病：** 瀰漫性腹膜轉移；黏液性腺癌最常見；網膜餅是晚期表現；胃癌、卵巢癌為常見原發灶
- **偽腹膜黏液瘤：** 闌尾黏液性腫瘤為主要來源；CT 可見黏液性物質「重力性」分布；與腹膜癌病不同
- **三明治徵：** 腸繫膜淋巴瘤特徵性表現
- **克魯肯伯瘤：** 胃癌或結腸癌卵巢轉移（雙側卵巢腫塊）
