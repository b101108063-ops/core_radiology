![Page 172](/core_radiology/images/genitourinary/page-172.png)

## 良性腎上腺腫塊 / Benign Adrenal Masses

### 骨髓脂肪瘤 / Myelolipoma

#### 疾病名稱 / Disease Name
**骨髓脂肪瘤（Myelolipoma）**

#### 臨床特點 / Clinical Features
- 良性腎上腺腫瘤，由**骨髓細胞**（紅血球前體，不是肌肉的「myo」）和**脂肪細胞**組成
- 通常為偶然發現，無內分泌活性

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：**
  - 主要為脂肪衰減的腫塊
  - 伴有局限性軟組織衰減區域
  - 與腎臟分界清楚
- **具有巨觀脂肪的腎上腺腫塊幾乎是骨髓脂肪瘤的診斷標準**
- 需與**後腹腔脂肪肉瘤**鑑別：脂肪肉瘤通常體積較大，可推移（而非起源於）腎上腺

| 特點 | 骨髓脂肪瘤 | 脂肪肉瘤 |
|---|---|---|
| 位置 | 起源於腎上腺 | 後腹腔，可推移腎上腺 |
| 脂肪分布 | 侷限性軟組織區域 | 多變 |
| 與腎臟關係 | 分界清楚 | 可能推移腎臟 |

#### 鑑別診斷 / Differential Diagnosis
- 後腹腔脂肪肉瘤（Liposarcoma）
- 腎血管平滑肌脂肪瘤（AML）（名稱相似但無關，AML 位於腎臟）

### 腎上腺囊腫 / Adrenal Cyst

#### 疾病名稱 / Disease Name
**腎上腺囊腫（Adrenal Cyst）**

#### 臨床特點 / Clinical Features
- 不常見，影像學特徵類似其他部位囊腫
- 通常為偶然發現

#### 囊腫分類 / Classification of Adrenal Cysts

| 類型 | 頻率 | 特點 |
|---|---|---|
| **內皮囊腫（Endothelial cysts）** | 45%（最常見） | 可能為淋巴管性或血管性 |
| **假性囊腫（Pseudocysts）** | 39% | 繼發於腎上腺出血；無上皮內壁；周邊可能鈣化 |
| **上皮囊腫（Epithelial cysts）** | 9%（罕見） | - |

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：** 薄壁、光滑、無強化、 水衰減內容物
- 複雜性囊腫可能難以與囊性/壞死性腫瘤鑑別

#### 治療 / Treatment
- 小而無症狀的囊腫：無需處理
- 大而有症狀的囊腫（壓迫胃/十二指腸）：手術切除
- 棘球囊病（Hydatid disease）：罕見，可產生複雜囊性病變伴內膜

---

### 臨床要點 / Clinical Key Points
- **骨髓脂肪瘤：** 含有巨觀脂肪 = 幾乎特異性診斷；與脂肪肉瘤的區別在於起源位置
- **腎上腺囊腫：** 內皮囊腫最常見（45%）；假性囊腫與出血相關
- 囊性與實性腎上腺腫塊的鑑別首要依靠**強化特徵**
