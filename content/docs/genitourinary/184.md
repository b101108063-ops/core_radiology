# Genitourinary Imaging - Page 184

![Page 184](/core_radiology/images/genitourinary/page-184.png)

## 泌尿系統結石 / Nephrolithiasis and Ureterolithiasis

### 疾病名稱 / Disease Name
**泌尿系統結石（Nephrolithiasis / Ureterolithiasis）**

### 臨床特點 / Clinical Features
- 常見疾病，表現為**腎絞痛**
- 通常有血尿，但完全阻塞時可能無血尿

### 結石類型與 X 線顯影 / Stone Types and Radiograph Visibility

| 結石類型 | 發生率 | X 線片 | CT |
|---|---|---|---|
| 含鈣結石（草酸鈣/磷酸鈣、純草酸鈣、純磷酸鈣） | **73%** | 顯影 | 全部顯影 |
| 尿酸結石 | - | **不顯影** | 顯影 |
| 黃嘌呤結石 | - | 不顯影 | 顯影 |
| 基質結石 | - | 不顯影 | 顯影 |
| 純鳥糞石 | - | 不顯影 | 顯影 |
| 茚地那韋結石（HIV 患者抗逆轉錄病毒治療） | - | 不顯影 | **不顯影**（除非常見的未鈣化基質結石） |

### 診斷要點 / Diagnostic Key Points

**CT 非增強所見：**
- 單側腎積水
- 腎周條紋影
- **軟組織邊緣徵（Soft tissue rim sign）**：結石周圍有小量軟組織暈（代表水腫的輸尿管壁），有助於區分靜脈石與輸尿管結石

| 徵象 | 說明 |
|---|---|
| **軟組織邊緣徵** | 結石周圍水腫的輸尿管壁 → 輸尿管結石（而非血管鈣化） |

## 乳頭壞死 / Papillary Necrosis

### 疾病名稱 / Disease Name
**乳頭壞死（Papillary Necrosis）**

### 臨床特點 / Clinical Features
- 腎乳頭組織的壞死和脫落
- 可引起**肉眼血尿**，並可導致慢性腎功能不全

### 病因 / POSTCARD 記憶法

| 字母 | 病因 |
|---|---|
| **P** | 腎盂腎炎（Pyelonephritis） |
| **O** | 阻塞（Obstruction） |
| **S** | 鐮狀細胞病（Sickle cell disease） |
| **T** | 結核（Tuberculosis） |
| **C** | 肝硬化（Cirrhosis） |
| **A** | 鎮痛劑/NSAIDs（Analgesics） |
| **R** | 腎靜脈血栓（Renal vein thrombosis） |
| **D** | 糖尿病（Diabetes mellitus） |

### 診斷要點 / Diagnostic Key Points

**CT 尿路造影延遲期表現：**
- 多個小的腎盞外造影劑池（鄰近腎盞）

**三個經典泌尿放射學徵象：**

| 徵象 | 描述 |
|---|---|
| **Ball on tee sign（球在球座上徵）** | 造影劑填充中央乳頭 |
| **Lobster claw sign（龍蝦爪徵）** | 造影劑僅填充乳頭周邊（勿與 XGP 的熊爪徵混淆） |
| **Signet ring sign（印章環徵）** | 造影劑圍繞脫落的乳頭 |

---

### 臨床要點 / Clinical Key Points
- **含鈣結石**佔所有泌尿系統結石的 73%
- **軟組織邊緣徵**有助於區分靜脈石與輸尿管結石
- **POSTCARD 記憶法**：腎盂腎炎、阻塞、鐮狀細胞病、結核、肝硬化、鎮痛劑、腎靜脈血栓、糖尿病
- **乳頭壞死三徵**：球在球座上徵、龍蝦爪徵、印章環徵
- 印章環徵：脫落乳頭被造影劑環繞
