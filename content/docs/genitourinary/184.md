## Text Content

### 黃色肉芽腫性腎盂腎炎（續）/ Xanthogranulomatous Pyelonephritis (Continued)

- **治療：** 腎切除（Nephrectomy）

---

### 腎結核 / Renal Tuberculosis

| 項目 | 說明 |
|------|------|
| 病原 | **結核分枝桿菌（Mycobacterium tuberculosis）** |
| 感染途徑 | 血行播散 |
| 肺部 TB | 約 10% 患者有活動性肺結核 |

- 初始腎結核感染通常為**雙側性**；慢性改變往往為**單側性**

**影像表現：**

| 表現 | 說明 |
|------|------|
| 實質鈣化 | |
| 疤痕 | |
| 乳頭壞死 | |
| 漏斗部狹窄 | 可導致腎盞阻塞 |
| **終末期腎結核（Autonephrectomy）** | 腎臟萎縮鈣化；形成特徵性「**油灰腎（putty kidney）**」外觀 |

---

### 腎結石與輸尿管結石 / Nephrolithiasis and Ureterolithiasis

| 項目 | 說明 |
|------|------|
| 症狀 | 腎絞痛；血尿通常存在（完全阻塞時可能缺席） |
| 結石成分 | 含鈣結石（草酸鈣+磷酸鈣、草酸鈣、磷酸鈣）佔 **73%** |
| X 光可透性結石 | 尿酸結石、黃嘌呤結石、基質結石、純鳥糞石、茚地那韋結石（HIV 患者） |

**軟組織邊緣徵（Soft tissue rim sign）：**

| 意義 | 說明 |
|------|------|
| 目的 | 區分靜脈石（phlebolith）與輸尿管結石 |
| 表現 | 結石周圍有薄層軟組織暈（代表水腫的輸尿管壁）＝輸尿管結石 |

**阻塞的次要徵象：** 同側水腎、腎周條索影

---

### 乳頭壞死 / Papillary Necrosis

**乳頭壞死**是腎乳頭組織的壞死和脫落，臨床可引起**肉眼血尿**，並可導致慢性腎功能不全。

#### POSTCARD 記憶口訣

| 字母 | 病因 |
|------|------|
| **P** | Pyelonephritis（腎盂腎炎） |
| **O** | Obstruction（阻塞） |
| **S** | Sickle cell disease（鐮狀細胞病） |
| **T** | Tuberculosis（結核） |
| **C** | Cirrhosis（肝硬化） |
| **A** | Analgesics/NSAIDs（止痛藥/NSAIDs） |
| **R** | Renal vein thrombosis（腎靜脈血栓） |
| **D** | Diabetes mellitus（糖尿病） |

#### 經典影像徵象

| 徵象 | 描述 |
|------|------|
| **Ball on tee sign** | 對比劑填充中央乳頭 |
| **Lobster claw sign** | 對比劑僅填充乳頭周邊 |
| **Signet ring sign** | 對比劑圍繞脫落的乳頭 |

> CT 泌尿道延遲期可見腎盞旁多發小對比劑池（extravasation of contrast）

---

### 臨床要點 / Clinical Key Points
> - **腎結核**：血行感染；10% 有活動性肺 TB；終末期形成「油灰腎（putty kidney）」——萎縮鈣化腎
> - **含鈣結石**佔尿路結石 73%；軟組織邊緣徵提示輸尿管結石（非靜脈石）
> - **POSTCARD**：腎盂腎炎、阻塞、鐮狀細胞、結核、肝硬化、止痛藥、靜脈血栓、糖尿病
> - **乳頭壞死三聯徵**：Ball on tee、**Lobster claw**（別與 XGP 的 bear paw 混淆）、Signet ring
> - Bear paw sign = XGP；Lobster claw sign = 乳頭壞死
