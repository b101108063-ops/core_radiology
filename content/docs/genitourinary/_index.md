### 憩室炎 / Diverticulitis

**憩室炎**是結腸憩室發生**微小穿孔（microperforation）和急性炎症**。CT 是首選診斷工具，並用於評估疾病嚴重程度及併發症。

- 左結腸比右結腸受累常見得多
- 急性憩室炎與**微小穿孔性結腸癌**往往難以區分；多數作者建議急性期緩解後進行結腸鏡隨訪

#### 單純性憩室炎 / Uncomplicated Diverticulitis

無影像學上的腸道穿孔證據（即使組織病理學上所有憩室炎都伴有細菌移位）。CT 表現：**腸壁增厚**及**結腸旁脂肪條索影（fat stranding）**，通常圍繞責任憩室（culprit diverticulum）。

#### 複雜性憩室炎 / Complicated Diverticulitis

| 併發症類型 | 說明 |
|------------|------|
| **膿腫（Abscess）** | 結腸旁或肝臟膿腫 |
| **腸外氣體（Extraluminal air）** | 穿孔表現 |
| **腸阻塞（Bowel obstruction）** | |
| **腸道瘺管（Bowel fistula）** | **膀胱結腸瘺（Colovesical fistula）**最常見；影像上表現為膀胱內氣體（排除導尿管因素） |
| **血栓形成（Thrombosis）** | 腸系膜靜脈血栓 |

**治療：**
- 單純性憩室炎 → **保守治療**
- 膿腫 → 通常可**經皮穿刺引流**
- 手術適應症：**瘺管**或**復發性憩室炎**（曾兩次保守治療失敗）

---

### 網膜附件炎 / Epiploic Appendagitis

**網膜附件炎**是憩室炎的**良性臨床模擬者**，由結腸上懸垂的正常脂肪標籤（附屬物）**扭轉**引起。

**特徵性影像表現：** 病灶呈**橢圓形脂肪密度**，附著於正常結腸壁，伴輕度脂肪條索影。橫斷面上，中央高密度點代表網膜附件的**血栓性中心靜脈**。

> **治療：** 使用**抗炎藥物**，不使用抗生素或手術。

---

### 臨床要點 / Clinical Key Points
> - **憩室炎**CT 首選；左結腸為主；需與結腸癌鑑別
> - **複雜性憩室炎**：腸外氣體、膿腫、瘺管（膀胱結腸瘺最常見）、腸阻塞
> - **網膜附件炎**： pathognomonic 橢圓形脂肪密度病灶附著結腸壁；治療為抗炎藥物

### 腸繫膜與腹膜 / Mesentery and Peritoneum — Anatomy

#### 腹膜 / Peritoneum

- 腹膜是一層薄薄膜，由**單層間皮細胞（mesothelial cells）**構成，下方有膜下脂肪細胞、淋巴細胞和白血球支撐
- **臟層腹膜（Visceral peritoneum）**：覆蓋所有腹膜內器官表面
- **壁層腹膜（Parietal peritoneum）**：覆蓋腹膜腔外壁
- 腹膜腔的**最低位點**（仰臥和站立均為）：女性為**Douglas 窩（pouch of Douglas）**，男性為**膀胱後隙（retrovesical space）**

#### 腸繫膜 / Mesentery

**腸繫膜**是三層真正的膜，每層供應一段腸道並連接到後腹壁。每層膜都由夾在腹膜層之間的血管和淋巴管網絡組成：

| 腸繫膜名稱 | 供應腸道 | 走行/位置 |
|-----------|----------|-----------|
| **小腸繫膜（Small bowel mesentery）** | 空腸和迴腸 | 從左上腹的**屈氏韌帶（ligament of Treitz）**斜行走向右下腹的**迴盲部（ileocecal junction）** |
| **橫結腸繫膜（Transverse mesocolon）** | 橫結腸 | 連接後方橫結腸與後腹壁 |
| **乙狀結腸繫膜（Sigmoid mesentery）** | 乙狀結腸 | 連接乙狀結腸與後腹壁 |

#### 網膜 / Omentum

大網膜和小網膜是附著於胃的特化腸繫膜，**不連接後腹壁**：

| 網膜名稱 | 連接關係 |
|---------|-----------|
| **大網膜（Greater omentum）** | 胃 ↔ 橫結腸前面（大型帷幔狀結構，覆蓋前腹） |
| **小網膜（Lesser omentum）** | 胃 ↔ 肝臟 |

---

### 臨床要點 / Clinical Key Points
> - **臟層腹膜**覆蓋器官；**壁層腹膜**覆蓋腔壁；**Douglas 窩**（女性）和**膀胱後隙**（男性）是腹膜腔最低位
> - 三個**真正腸繫膜**：小腸繫膜、橫結腸繫膜、乙狀結腸繫膜
> - **大網膜**連接胃與橫結腸；**小網膜**連接胃與肝臟；兩者均不連接後腹壁

---

### 「朦朧腸繫膜」/"Misty" Mesentery

#### 概述 / Overview

- 腸繫膜由脂肪皺襞組成，腸道動靜脈及靜脈和淋巴引流從中穿行
- 正常 CT 上看不到腸繫膜本體（因為主要由脂肪組成，與腹腔內脂肪融為一體），只能看到其中的血管
- 當腸繫膜被**液體、炎症細胞、腫瘤或纖維組織**浸潤時，腸繫膜密度增加，腸繫膜血管變得模糊不清——這些往往是某些疾病的**首發線索**

#### 腸繫膜水腫 / Mesenteric Edema

| 病因類型 | 說明 |
|----------|------|
| **全身性病因** | 充血性心臟衰竭、低蛋白血症、第三間隙液體蓄積 |
| **局灶性病因** | 腸繫膜血管血栓形成、Budd-Chiari 症候群、IVC 阻塞 |

> 腹部血管損傷時可見腸壁增厚、腸道積氣（pneumatosis）或腸繫膜靜脈積氣

#### 腸繫膜炎症 / Mesenteric Inflammation

- **最常見的上腹部病因：急性胰臟炎**
- 其他局灶性炎症：闌尾炎、發炎性腸道疾病、憩室炎
- **腸繫膜脂膜炎（Mesenteric panniculitis）**：特發性炎症疾病，表現為瀰漫性「朦朧腸繫膜」

#### 腹腔內出血 / Intra-abdominal Hemorrhage

- 腹腔內出血傾向於局部聚集在出血血管周圍（除非量大）
- 病因：外傷、術後、抗凝治療

#### 腫瘤浸潤 / Neoplastic Infiltration

- **最常見：非何杰金淋巴瘤（Non-Hodgkin lymphoma）**，通常伴有巨大淋巴結病
- 腸繫膜受累在接受治療後可能更明顯（「朦朧腸繫膜」僅限於含治療後淋巴結的區域）
- 其他可侵犯腸繫膜的腫瘤：胰臟癌、結腸癌、乳癌、胃腸道間質瘤（GIST）、間皮瘤

---

### 臨床要點 / Clinical Key Points
> - **朦朧腸繫膜**＝腸繫膜密度增加、血管模糊；病因包括水腫、炎症、出血、腫瘤
> - **急性胰臟炎**是最常見的上腹部腸繫膜炎症原因
> - **非何杰金淋巴瘤**是最常見的腸繫膜腫瘤（原發性腸繫膜腫瘤罕見）
> - 局灶性腸繫膜水腫：血栓、Budd-Chiari、IVC 阻塞

## 腸繫膜腫瘤 / Mesenteric Masses

### 類癌 / Carcinoid

#### 疾病名稱 / Disease Name
**類癌（Carcinoid）**

#### 臨床特點 / Clinical Features
- 胃腸道類癌相比其他胃腸道惡性腫瘤較少見，但是**最常見的小腸腫瘤**
- 通常發生在**遠端迴腸**
- 通常以腔內腫塊起病，可通過直接延伸或淋巴轉移繼發擴散至腸繫膜
- 高達 **80%** 的類癌擴散至腸繫膜

#### 診斷要點 / Diagnostic Key Points
- **CT 表現（特徵性）：**
  - 增強軟組織腫塊
  - 放射狀線性 bands 延伸至腸繫膜脂肪（**≠浸潤性腫瘤**，而是腫瘤釋放血清素引起的強烈**促纖維增生性反應**）
  - 鈣化常見
- **MRI：** T2 高信號；肝轉移在肝膽對比劑圖像上最清楚

#### 鑑別診斷 / Differential Diagnosis
| 診斷 |
|---|
| 類癌 |
| 韌帶樣腫瘤（Desmoid tumor） |
| 硬化性腸繫膜炎 |

---

### 韌帶樣腫瘤 / Desmoid Tumor

#### 疾病名稱 / Disease Name
**韌帶樣腫瘤（Desmoid Tumor）**

#### 臨床特點 / Clinical Features
- 良性但**局部侵襲性**腫塊，由增殖的纖維組織組成
- **加納綜合症（Gardner syndrome）**（家族性腺瘤性息肉病的變異型）患者更常見腸繫膜韌帶樣腫瘤
- 可為散發性或與加納綜合症相關

#### 診斷要點 / Diagnostic Key Points
- **CT：** 大多數與肌肉等衰減，但大腫瘤可見中央壞死
- **特徵性影像表現：** 組織 strands 放射狀延伸至相鄰腸繫膜脂肪（類似類癌和硬化性腸繫膜炎）

#### 鑑別診斷 / Differential Diagnosis
- 類癌
- 硬化性腸繫膜炎
- 淋巴瘤

---

### 硬化性腸繫膜炎 / Sclerosing Mesenteritis

#### 臨床特點 / Clinical Features
- 罕見的發炎性疾病，導致腸繫膜根部的脂肪壞死和纖維化

#### 診斷要點 / Diagnostic Key Points
- 影像表現：腸繫膜腫塊伴軟組織條紋延伸至相鄰脂肪
- 鈣化可能存在
- **腸繫膜脂膜炎（Mesenteric Panniculitis）**是其變異型，炎症為主，表現為急性腹痛

#### 治療 / Treatment
- 消炎藥物、免疫調節劑或手術（依賴病情）

---

### 臨床要點 / Clinical Key Points
- **類癌：** 最常見小腸腫瘤；遠端迴腸好發；腸繫膜轉移表現為增強腫塊 + 放射狀線性條紋（促纖維增生性反應）；80%扩散至肠系膜
- **韌帶樣腫瘤：** 纖維性良性腫塊；加纳综合征患者需警惕
- **硬化性腸繫膜炎：** 腸繫膜根部纖維化；与类癌、韧带样肿廙组成硬化性肠系膜肿块鉴别诊断

## 瀰漫性腹膜疾病 / Diffuse Peritoneal Disease

### 腹膜癌病 / Peritoneal Carcinomatosis

#### 疾病名稱 / Disease Name
**腹膜癌病（Peritoneal Carcinomatosis）**

#### 臨床特點 / Clinical Features
- 代表播散至腹膜表面的轉移瘤
- **胃癌、卵巢癌、乳癌、肺癌、胰臟癌、膽道癌、結腸癌和黑色素瘤**可轉移至腸繫膜淋巴結
- **網膜餅（Omental caking）**：網膜脂肪被腫瘤和纖維化取代
- **黏液性腺癌**是最常見引起腹膜癌病的腫瘤類型
- 可伴有**克魯肯伯瘤（Krukenberg tumors）**（卵巢轉移，常為雙側）

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：**
  - 網膜改變：網膜脂肪密度增加、結節狀或板狀增厚
  - 腹膜增厚和結節
  - 腹水
  - 腸繫膜受累
- **「三明治徵（Sandwich Sign）」：** 腸繫膜淋巴瘤特徵，淋巴結塊從兩側包夾腸繫膜脂肪和血管（被形容為「麵包」），脂肪和血管為「餡料」

#### 鑑別診斷 / Differential Diagnosis
- 結核性腹膜炎
- 腹膜間皮瘤
- 硬化性腹膜炎

#### 治療 / Treatment
- 腫瘤細胞減滅術 + 腹腔熱化療（HIPEC）

---

### 偽腹膜黏液瘤 / Pseudomyxoma Peritonei

#### 疾病名稱 / Disease Name
**偽腹膜黏液瘤（Pseudomyxoma Peritonei）**

#### 臨床特點 / Clinical Features
- 通常來源於**闌尾黏液性腫瘤**或卵巢黏液性囊腺瘤
- 黏液性腫瘤細胞種植於腹膜，產生大量黏液

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：**
  - 腹膜和網膜瀰漫性黏液性物質沉積
  - 肝脾邊緣壓迫徵（ scalloped appearance）
  - 腹水但不同於普通腹水（CT 值略高）
  - 「囊腫」樣外觀
- **特徵性：** 黏液性物質在腹腔內重 力性分布

#### 鑑別診斷 / Differential Diagnosis
- 腹膜癌病（黏液性腺癌来源）
- 結核性腹膜炎
- 腹膜膠質瘤病

---

### 臨床要點 / Clinical Key Points
- **腹膜癌病：** 瀰漫性腹膜轉移；黏液性腺癌最常見；網膜餅是晚期表現；胃癌、卵巢癌為常見原發灶
- **偽腹膜黏液瘤：** 闌尾黏液性腫瘤為主要來源；CT 可見黏液性物質「重力性」分布；與腹膜癌病不同
- **三明治徵：** 腸繫膜淋巴瘤特徵性表現
- **克魯肯伯瘤：** 胃癌或結腸癌卵巢轉移（雙側卵巢腫塊）

### 腹膜假黏液瘤 / Pseudomyxoma Peritonei

**腹膜假黏液瘤**是一種以腹膜腔內大量黏液為特徵的**低度惡性腫瘤**。

- 主要認為由**闌尾的黏液性腺瘤或腺癌**產生；卵巢或結腸是否可為原發部位仍有爭議
- 女性患者中，高達 **30%** 伴有卵巢腫塊，但這些通常被認為是轉移性沉積
- 以前認為由**良性闌尾黏液囊腫**引起，現知遠比原先認為的少見
  - **20%** 的闌尾腺瘤或腺癌會導致腹膜假黏液瘤
  - 只有 **2%** 的闌尾黏液囊腫會導致腹膜假黏液瘤

| 項目 | 說明 |
|------|------|
| **CT 表現** | 分葉狀腹水（5-20 HU，比普通腹水密度高）；肝臟邊緣特徵性**扇形壓跡（scalloping）** |
| **臨床表現** | 復發性黏液性腹水（「果凍腹」） |
| **治療** | 手術治療＋加溫腹腔內化療（HIPEC） |

> 進階疾病的**肝臟邊緣扇形壓跡**是 pathognomonic 表現

---

### 臨床要點 / Clinical Key Points
> - **腹膜假黏液瘤**：低度惡性；主要來自闌尾黏液性腫瘤；女性 30% 伴卵巢轉移
> - **扇形壓跡（scalloping）**：肝臟邊緣被黏液侵蚀的特徵性表現，pathognomonic
> - 與黏液性腺癌的腹膜轉移需鑑別；治療為手術＋HIPEC

## 後腹腔解剖學 / Retroperitoneal Anatomy

### 局部解剖 / Topographic Anatomy

後腹腔可由**前腎筋膜（Gerota's fascia）**和**後腎筋膜（Zuckerkandl's fascia）**及**外側錐筋膜（ Lateral conal fascia）**分為三個間室：

| 間室 | 內容物 |
|---|---|

| **腎旁後間隙（Posterior pararenal space）** | 潛在空間，僅含脂肪；可作為炎症或腫瘤擴散的次級路徑 |

| 結構 | 位置/描述 |
|---|---|
| **腎上腺（Adrenals）** | 位於腎周間隙內 |
| **腎臟（Kidneys）** | 位於腎周間隙內 |
| **下腔靜脈（IVC）** | 後腹腔中央 |
| **主動脈（Aorta）** | 後腹腔中央 |
| **前腎筋膜（Gerota's fascia）** | 腎臟前方 |
| **後腎筋膜（Zuckerkandl's fascia）** | 腎臟後方 |

- 後腹腔由三個筋膜隔分為三個間室
- 腎上腺和腎臟位於**腎周間隙**內
- 胰臟和結腸位於**腎旁前間隙**內
- **腎旁後間隙**為潛在空間，是炎症或腫瘤扩散的途径
- 理解後腹腔間隙結構對於追踪疾病擴散路徑至關重要

## 後腹腔腫瘤 / Retroperitoneal Tumors

### 脂肪肉瘤 / Liposarcoma

#### 疾病名稱 / Disease Name
**脂肪肉瘤（Liposarcoma）**

#### 臨床特點 / Clinical Features
- 脂肪肉瘤是一組多樣化的腫瘤，是**最常見的原發性後腹腔腫瘤**
- 所有脂肪肉瘤中 **10–15%** 起源於後腹腔
- 最常見類型為**分化良好組**，由以下亞型組成：
  - 脂肪細胞型（Adipocytic）
  - 硬化型（Sclerosing）
  - 炎症型（Inflammatory）
- 脂肪細胞型脂肪肉瘤類似脂肪瘤，主要由脂肪組成，伴有代表膠原纖維的組織條紋

#### 惡性程度分級 / Malignancy Classification（由低到高）

| 惡性程度 | 亞型 |
|---|---|
| 最低 | 黏液型（Myxoid） |
| ↓ | 圓細胞型（Round-cell） |
| ↓ | 多形型（Pleomorphic） |
| 最高 | 去分化型（Dedifferentiated） |

- 侵襲性較強的亞型可能含有極少或無巨觀脂肪，與其他惡性軟組織腫塊難以區分

#### 鑑別診斷 / Differential Diagnosis
- 脂肪瘤（Lipoma）
- 畸胎瘤（Teratoma）
- 黏液樣脂肪肉瘤（Myxoid liposarcoma）
- 腎上腺髓脂瘤（Myelolipoma）

#### 診斷要點 / Diagnostic Key Points
- CT 表現主要取決於亞型
- 分化良好型：以脂肪衰減為主的腫塊，伴條紋狀軟組織
- 去分化型：軟組織密度為主，無明顯脂肪

---

### 後腹腔纖維化 / Retroperitoneal Fibrosis

#### 疾病名稱 / Disease Name
**後腹腔纖維化（Retroperitoneal Fibrosis）**

#### 臨床特點 / Clinical Features
- 罕見的發炎性疾病，導致後腹腔纖維組織增生，常引起**輸尿管阻塞**
- 可導致腎積水和腎功能受損
- 可能為特發性或與藥物、腫瘤、感染相關

#### 鑑別診斷：後腹腔纖維化 vs. 惡性淋巴結病

| 特點 | 後腹腔纖維化 | 惡性淋巴結病 |
|---|---|---|
| 主動脈位移 | **不**將主動脈抬高離開脊柱 | 將主動脈抬高離開脊柱 |
| 性質 | 發炎/纖維化 | 惡性 |
| 輸尿管侵犯 | 常見 | 變異 |
| 強化模式 | 均勻延遲強化 | 不均勻強化 |

#### 診斷要點 / Diagnostic Key Points
- CT 表現為軟組織腫塊環繞主動脈和/或下腔靜脈及輸尿管
- 纖維化組織趨向**不將主動脈抬高離開脊柱**（與惡性淋巴結病的關鍵鑑別點）
- 雙側腎積水和輸尿管擴張常見

#### 治療 / Treatment
- 皮質類固醇
- 輸尿管支架或腎造口引流
- 手術鬆解

---

### 臨床要點 / Clinical Key Points
- **脂肪肉瘤**：最常見原發性後腹腔腫瘤；分化良好型以脂肪衰減為主；侵襲性亞型可無明顯脂肪
- **後腹腔纖維化**：軟組織腫塊圍繞主/下肢血管；特徵為**不抬高主動脈**（區別於惡性淋巴結病）；常引起輸尿管阻塞
- **後腹腔三大常見腫瘤**：脂肪肉瘤（最常見）、平滑肌肉瘤、惡性纖維組織細胞瘤

## 腎上腺 / Adrenal Glands

### 解剖學 / Anatomy

#### 結構概述
- 腎上腺是倒置 Y 形的內分泌腺，主要通過釋放皮質醇和兒茶酚胺調節壓力反應
- 腎上腺皮質和髓質有完全不同的胚胎來源：
  - **皮質**：來源於間皮（Mesothelium）
  - **髓質**：來源於神經嵴（Neural crest）

#### 腎上腺皮質分層 / Adrenal Cortex Layers

| 層次 | 名稱 | 分泌激素 |
|---|---|---|
| 最外層 | **球狀帶（Zona glomerulosa）** | 醛固酮（Aldosterone） |
| 中間層 | **束狀帶（Zona fasciculata）** | 糖皮質激素（Glucocorticoids）——受垂體 ACTH 調控 |
| 最內層 | **網狀帶（Zona reticularis）** | 雄激素（Androgens） |

#### 腎上腺髓質 / Adrenal Medulla
- 分泌**兒茶酚胺**：去甲腎上腺素和腎上腺素（來源於酪氨酸 Tyrosine）
- 病變：嗜鉻細胞瘤（Pheochromocytoma）、神經母細胞瘤（Neuroblastoma）等

#### 皮質病變 / Cortex Pathology
| 病變 | 說明 |
|---|---|
| 腎上腺增生（Adrenal hyperplasia） | 皮質細胞增殖 |
| 腎上腺腺瘤（Adrenal adenoma） | 良性皮質腫瘤 |
| 腎上腺皮質癌（Adrenal cortical carcinoma） | 罕見惡性腫瘤 |

#### 髓質病變 / Medulla Pathology
| 病變 | 說明 |
|---|---|
| 嗜鉻細胞瘤（Pheochromocytoma） | 通常良性髓質腫瘤 |
| 神經母細胞瘤（Neuroblastoma） | 兒童最常見顱外實體腫瘤 |

---

### 腎上腺病變的生化學評估 / Biochemical Approach to Adrenal Lesions

#### 皮質功能過剩 / Adrenal Hyperfunction

| 症候群 | 病因 |
|---|---|
| **庫欣綜合徵（Cushing syndrome）** | 非垂體疾病引起的皮質醇過剩，如特發性腎上腺增生、腺瘤、異位 ACTH（如小細胞肺癌） |
| **庫欣病（Cushing disease）** | 由垂體 ACTH 過剩驅動的皮質醇過剩 |
| **康恩綜合徵（Conn syndrome）** | 醛固酮過剩，最常見於腎上腺腺瘤；引起高血壓和低血鉀；腺瘤通常較小，CT 可能難以檢測 |
| **腎上腺皮質癌** | 罕見皮質惡性腫瘤，通常導致所有皮質激素及前體的紊亂增加 |
| **嗜鉻細胞瘤** | 通常為良性的腎上腺髓質腫瘤，引起兒茶酚胺增加 |

---

### 臨床要點 / Clinical Key Points
- 腎上腺皮質分泌三種激素：醛固酮（球狀帶）、糖皮質激素（束狀帶）、雄激素（網狀帶）
- 腎上腺髓質分泌兒茶酚胺
- **康恩綜合徵**：小腎上腺腺瘤引起醛固酮過剩 → 高血壓 + 低血鉀
- **庫欣綜合徵**：皮質醇過剩，可來自腎上腺腺瘤或異位 ACTH
- **嗜鉻細胞瘤**：兒茶酚胺過剩，典型表現為陣發性高血壓、頭痛、出汗

## 腎上腺腺瘤與不確定性腎上腺腫塊的影像學 / Imaging of Adrenal Adenoma and the Indeterminate Adrenal Mass

### 腎上腺腺瘤 / Adrenal Adenoma

#### 疾病名稱 / Disease Name
**腎上腺腺瘤（Adrenal Adenoma）**

#### 臨床特點 / Clinical Features
- 腎上腺皮質的良性腫瘤
- 通常為偶然發現，但可能產生過多醛固酮引起續發性高血壓（**康恩綜合徵 Conn syndrome**）
- 常見臨床情境：已知惡性腫瘤患者需區分腎上腺腺瘤與腎上腺轉移

#### 診斷要點 / Diagnostic Key Points

**非增強 CT 診斷標準：**
- 腎上腺結節衰減值 **≤10 HU** 可可靠診斷為腺瘤，無需進一步影像或隨訪
- **80%** 的腺瘤為富含脂肪型（Lipid-rich），低於此閾值
- **≤20%** 為脂肪缺乏型（Lipid-poor），衰減值 >10 HU，非增強 CT 無法診斷

| 類型 | 非增強 CT 衰減值 | 診斷 |
|---|---|---|
| 富含脂肪型腺瘤 | **≤10 HU** | 直接診斷，無需隨訪 |
| 脂肪缺乏型腺瘤 | **>10 HU** | 需進一步檢查 |

**不确定性病灶：** 
- 非已知惡性腫瘤患者的小型均質病灶（>10 HU）極可能為脂肪缺乏型腺瘤，通常無需進階影像檢查

#### 化學位移 MRI（Chemical Shift MRI）/ 同相位與反相位成像
- 腺瘤含有細胞內脂肪（因類固醇生成），MRI 可檢測微小脂肪
- **同相位（In-phase）/ 反相位（Out-of-phase）成像**：脂肪和水分在同一體素時，反相位圖像顯示脂肪信號丟失（Fat drop-out）
- 腺瘤在反相位圖像上信號抑制，轉移瘤則否

#### 含有細胞內脂肪的惡性腫瘤（反相位也會丟失信號）

| 惡性腫瘤 | 說明 |
|---|---|
| 分化良好的腎上腺皮質癌 | 極罕見 |
| 透明細胞型腎細胞癌轉移 | - |
| 肝細胞癌轉移 | - |
| 脂肪肉瘤 | 主要為脂肪性腫塊，罕與腺瘤混淆 |

#### 碰撞瘤（Collision Tumor）
- 轉移瘤種植於已有腺瘤的腎上腺
- 如果「腺瘤」看起來不均質或大小增加，即使區域衰減值 <10 HU，也應考慮碰撞瘤

---

### 臨床要點 / Clinical Key Points
- **≤10 HU（非增強 CT）= 富含脂肪型腺瘤**，直接確診，無需隨訪
- **>10 HU + 需確診** → 腎上腺 washout CT 或化學位移 MRI
- **絕對 washout >60%** = 腺瘤
- 反相位 MRI：腺瘤信號抑制（丟失），轉移瘤通常不抑制
- **碰撞瘤**：已有腺瘤 + 近期增大/不均質 → 需警惕轉移

## 腎上腺 Washout CT / Adrenal Washout CT

### 原理 / Principle
- **腎上腺腺瘤**比轉移瘤更快洗脫對比劑
- 即使是富血供原發腫瘤的轉移瘤，腺瘤的對比劑洗脫也更快
- Washout 時相：最新證據顯示 **15 分鐘** washout 優於 10 分鐘，敏感性更高

### 絕對百分比 Washout（Absolute Percentage Washout）

$$\text{Washout \%} = \frac{E - D}{E - U} = \frac{\text{增強衰減值} - \text{延遲衰減值}}{\text{增強衰減值} - \text{非增強衰減值}}$$

| 參數 | 說明 |
|---|---|
| **E** | 增強期衰減值（60 秒） |
| **D** | 延遲期衰減值（15 分鐘） |
| **U** | 非增強期衰減值 |

**診斷閾值：絕對 washout >60% = 腺瘤**

### 相對百分比 Washout（Relative Percentage Washout）
- 若無非增強 CT，**相對 washout >40% = 腺瘤**

$$\text{相對 Washout \%} = \frac{E - D}{E} = \frac{\text{增強衰減值} - \text{延遲衰減值}}{\text{增強衰減值}}$$

### 病例說明 / Case Example

| 時相 | 衰減值 |
|---|---|
| 非增強 | 16 HU |
| 60 秒增強期 | 112 HU |
| 15 分鐘 washout | 46 HU |

**計算：**
$$\frac{112 - 46}{112 - 16} = \frac{66}{96} = 69\%$$

- **69% > 60% → 診斷為腺瘤**

### 腎上腺腫塊活檢適應症 / Role of Adrenal Mass Biopsy
- 完整影像檢查後仍無法確診的不確定性腎上腺腫塊
- 活檢安全且通常非常準確

---

### 腎上腺腺瘤與轉移瘤的鑑別診斷總結

| 特徵 | 腎上腺腺瘤 | 腎上腺轉移瘤 |
|---|---|---|
| 非增強 CT 衰減值 | **≤10 HU**（80% 為富含脂肪型） | 通常 >10 HU |
| 絕對 washout | **>60%** | <60% |
| 反相位 MRI 信號 | **抑制**（信號丟失） | 通常不抑制 |
| 細胞內脂肪 | 有 | 通常無（少數惡性腫瘤除外） |
| 臨床情境 | 通常偶然發現 | 已知惡性腫瘤分期 |

---

### 臨床要點 / Clinical Key Points
- **Washout CT 診斷流程：** 非增強 → 增強（60 秒）→ 延遲（15 分鐘）
- **>60% 絕對 washout = 腺瘤**（即使 >10 HU）
- **>40% 相對 washout**（無非增強時）= 腺瘤
- 15 分鐘 washout 敏感性優於 10 分鐘
- 不確定性病灶且臨床需確診時：化學位移 MRI 或活檢

## 良性腎上腺腫塊 / Benign Adrenal Masses

### 骨髓脂肪瘤 / Myelolipoma

#### 疾病名稱 / Disease Name
**骨髓脂肪瘤（Myelolipoma）**

#### 臨床特點 / Clinical Features
- 良性腎上腺腫瘤，由**骨髓細胞**（紅血球前體，不是肌肉的「myo」）和**脂肪細胞**組成
- 通常為偶然發現，無內分泌活性

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：**
  - 主要為脂肪衰減的腫塊
  - 伴有局限性軟組織衰減區域
  - 與腎臟分界清楚
- **具有巨觀脂肪的腎上腺腫塊幾乎是骨髓脂肪瘤的診斷標準**
- 需與**後腹腔脂肪肉瘤**鑑別：脂肪肉瘤通常體積較大，可推移（而非起源於）腎上腺

| 特點 | 骨髓脂肪瘤 | 脂肪肉瘤 |
|---|---|---|
| 位置 | 起源於腎上腺 | 後腹腔，可推移腎上腺 |
| 脂肪分布 | 侷限性軟組織區域 | 多變 |
| 與腎臟關係 | 分界清楚 | 可能推移腎臟 |

#### 鑑別診斷 / Differential Diagnosis
- 後腹腔脂肪肉瘤（Liposarcoma）
- 腎血管平滑肌脂肪瘤（AML）（名稱相似但無關，AML 位於腎臟）

---

### 腎上腺囊腫 / Adrenal Cyst

#### 疾病名稱 / Disease Name
**腎上腺囊腫（Adrenal Cyst）**

#### 臨床特點 / Clinical Features
- 不常見，影像學特徵類似其他部位囊腫
- 通常為偶然發現

#### 囊腫分類 / Classification of Adrenal Cysts

| 類型 | 頻率 | 特點 |
|---|---|---|
| **內皮囊腫（Endothelial cysts）** | 45%（最常見） | 可能為淋巴管性或血管性 |
| **假性囊腫（Pseudocysts）** | 39% | 繼發於腎上腺出血；無上皮內壁；周邊可能鈣化 |
| **上皮囊腫（Epithelial cysts）** | 9%（罕見） | - |

#### 診斷要點 / Diagnostic Key Points
- **CT 表現：** 薄壁、光滑、無強化、 水衰減內容物
- 複雜性囊腫可能難以與囊性/壞死性腫瘤鑑別

#### 治療 / Treatment
- 小而無症狀的囊腫：無需處理
- 大而有症狀的囊腫（壓迫胃/十二指腸）：手術切除
- 棘球囊病（Hydatid disease）：罕見，可產生複雜囊性病變伴內膜

---

### 臨床要點 / Clinical Key Points
- **骨髓脂肪瘤：** 含有巨觀脂肪 = 幾乎特異性診斷；與脂肪肉瘤的區別在於起源位置
- **腎上腺囊腫：** 內皮囊腫最常見（45%）；假性囊腫與出血相關
- 囊性與實性腎上腺腫塊的鑑別首要依靠**強化特徵**

## 惡性（或潛在惡性）腎上腺腫塊 / Malignant (or Potentially Malignant) Adrenal Masses

### 嗜鉻細胞瘤 / Pheochromocytoma

#### 疾病名稱 / Disease Name
**嗜鉻細胞瘤（Pheochromocytoma）**

#### 臨床特點 / Clinical Features
- 嗜鉻細胞瘤是**嗜鉻細胞**的腫瘤，通常起源於腎上腺髓質
- 可引起高血壓和陣發性頭痛/出汗
- **「10% 規則」：**

| 特點 | 比例 |
|---|---|
| 腎上腺外 | 10% |
| 雙側性 | 10% |
| 惡性 | 10% |
| 家族性/綜合徵相關 | 10% |

#### 相關綜合徵 / Associated Syndromes

| 綜合徵 | 特點 |
|---|---|
| **多發性內分泌腫瘤（MEN）2A 和 2B** | 通常為雙側性腎上腺內嗜鉻細胞瘤 |
| **馮·希佩爾-林道（von Hippel-Lindau）** | - |
| **神經纖維瘤病 1 型** | - |
| **卡尼三聯徵（Carney's triad）** | 胃平滑肌肉瘤、肺軟骨瘤、腎上腺外嗜鉻細胞瘤 |

#### 腎上腺外嗜鉻細胞瘤（副神經節瘤）/ Extra-adrenal Pheochromocytoma (Paraganglioma)
- 腎上腺外嗜鉻細胞瘤稱為**副神經節瘤**
- 最常見的腹腔內位置：**祖克坎德爾器官（Organ of Zuckerkandl）**（位於主動脈分叉處）
- 罕見位置：**膀胱**（典型表現為**排尿後暈厥 post-micturition syncope**）

#### 頭頸部副神經節瘤 / Head and Neck Paragangliomas（又稱**球瘤 Glomus tumors**）

| 位置 | 名稱 |
|---|---|
| 鼓膜 | 鼓室球瘤（Glomus tympanicum） |
| 頸靜脈孔 | 頸靜脈球瘤（Glomus jugulare） |
| 頸總動脈體 | 頸總動脈體瘤（Carotid body tumor） |
| 迷走神經 | 迷走神經球瘤（Glomus vagale） |

#### 核醫學顯像 / Nuclear Medicine Studies
- **I-123 MIBG：** 用於嗜鉻細胞瘤轉移評估
- **In-111 pentetreotide（奧曲肽類似物）：** 用於副神經節瘤定位

#### 診斷要點 / Diagnostic Key Points
- **CT：** 腎上腺區域較大的異質性腫塊，伴有中央壞死
- **MRI：** T2  加權圖像呈經典型高信號（亮信號）；大腫瘤可呈異質性
- 實驗室確診：尿/血漿**甲氧基腎上腺素（Metanephrines）**

---

### 臨床要點 / Clinical Key Points
- **嗜鉻細胞瘤：「10% 規則」— 10% 腎上腺外、10% 雙側、10% 惡性、10% 家族性**
- 典型 MRI 表現：**T2 高信號**（亮信號）
- **膀胱副神經節瘤：** 排尿後暈厥為特徵性臨床表現
- MEN 2A/2B、von Hippel-Lindau、神經纖維瘤病 1 型需排除嗜鉻細胞瘤

### 腎上腺皮質癌 / Adrenal Cortical Carcinoma

#### 疾病名稱 / Disease Name
**腎上腺皮質癌（Adrenal Cortical Carcinoma）**

#### 臨床特點 / Clinical Features
- 極罕見惡性腫瘤，發病率約 **1/1,000,000**
- 約 **66%** 為功能性，產生皮質激素紊亂
- 可表現為**庫欣綜合徵（Cushing syndrome）**、**高醛固酮血症**或**男性化**

#### 診斷要點 / Diagnostic Key Points
- **CT/MRI 表現：**
  - 大型異質性腫塊
  - 中央壞死和出血為典型表現
  - 可有鈣化

| 特點 | 說明 |
|---|---|
| 大小 | 通常較大（確診時） |
| 強化模式 | 異質性不均勻強化 |
| 壞死/出血 | 常見 |
| 功能狀態 | 66% 功能性 |

#### 預後 / Prognosis
- 預後差，發現時通常已為晚期

---

### 轉移瘤 / Metastasis

#### 臨床特點 / Clinical Features
- 屍檢研究顯示：已知原發腫瘤患者中 **>25%** 有腎上腺轉移
- 最常見的原發腫瘤：**肺癌**和**黑色素瘤**

#### 診斷要點 / Diagnostic Key Points
- 雙側腎上腺腫塊伴不均勻強化
- 需與腺瘤鑑別（ washout CT 或化學位移 MRI）

## 瀰漫性腎上腺疾病 / Diffuse Adrenal Disorders

### 腎上腺增生 / Adrenal Hyperplasia

#### 臨床特點 / Clinical Features
- 由長期應激反應或異位 ACTH 分泌引起
- 通常為雙側性

#### 診斷要點 / Diagnostic Key Points
- 雙側腎上腺均勻增大
- 腎上腺分支變得更飽滿

---

### 腎上腺出血 / Adrenal Hemorrhage

#### 臨床特點 / Clinical Features
- 可為自發性或由**抗凝治療**引起
- 抗凝治療相關出血：通常在開始抗凝治療後**前幾週**內發生
- **右側**腎上腺比左側更常受累

#### 診斷要點 / Diagnostic Key Points
- CT 表現可能類似腫塊，呈異質性衰減
- 最重要線索：有近期腎上腺 imaging 前後對比，新出現腎上腺腫塊
- **不出現強化**；隨訪時**大小減小**
- 典型非增強衰減值：**~46 HU**

| 時期 | CT 表現 |
|---|---|
| 急性期 | 高衰減（出血） |
| 亞急性/慢性 | 逐漸縮小，不強化 |

#### 鑑別診斷 / Differential Diagnosis
- 腎上腺轉移瘤
- 腎上腺皮質癌
- 嗜鉻細胞瘤

---

### 腎上腺鈣化 / Adrenal Calcification

#### 病因 / Etiology
| 病因 | 說明 |
|---|---|
| 韋格納肉芽腫（Wegener granulomatosis） | ANCA 相關血管炎 |
| 結核（Tuberculosis） | 歷史上的常見原因 |
| 組織胞漿菌病（Histoplasmosis） | 真菌感染 |
| 陳舊性出血 | 出血後遺 |

- 腎上腺鈣化**很少**引起腎上腺功能減退

---

### 臨床要點 / Clinical Key Points
- **腎上腺皮質癌：** 極罕見（1/1,000,000）；66% 功能性；大型異質性腫塊伴壞死/出血
- **轉移瘤：** >25% 癌症患者屍檢有腎上腺轉移；肺癌和黑色素瘤最常見
- **腎上腺出血：** 右側多見；抗凝治療後前幾週；無強化、隨訪縮小；需與新發腫瘤鑑別
- **腎上腺增生：** 雙側增大，由應激或異位 ACTH 引起
- **腎上腺鈣化：** 很少引起功能減退；常見於肉芽腫性疾病、結核、組織胞漿菌病

## 腎臟腫塊的診斷方法 / Diagnostic Approach to a Renal Mass

### 腎臟腫塊 CT 方案 / Renal Mass Protocol Multiphase CT

腎臟腫塊方案 CT 至少包含**三個期相**，每期提供重要診斷信息：

| 期相 | 時間 | 目的 |
|---|---|---|
| **非增強期（Unenhanced）** | — | 建立強化基準線 |
| **腎實質期（Nephrographic phase）** | 100 秒延遲 | 評估強化的關鍵期相 |
| **腎盂期（Pyelographic phase）** | 15 分鐘延遲 | 疑難解答；鑑別囊性腎臟腫塊的模擬病變 |

#### 腎盂期（排泄期）的關鍵應用
| 應用 | 表現 |
|---|---|
| **腎積水** | 腎盂期可見濃密造影劑填充（會顯影） |
| **腎竇囊腫** | 不會在腎盂期顯影 |
| **腎乳頭狀擴張（reflux nephropathy）** | 腎盂期可見顯影的擴張乳頭 |

- 腎盂期也可用於顯示**盞室憩室**及評估腎臟腫塊與集合系統的關係（手術規劃用）

---

### 強化評估標準 / Evaluating Enhancement Criteria

#### CT 強化標準（絕對 HU 值增加）

| 強化程度 | HU 增加 | 判讀 |
|---|---|---|
| **無強化** | <10 HU | 囊性病變 |
| **強化不確定** | 10–19 HU | 需進一步檢查 |
| **明確強化** | **≥20 HU** | 考慮實性腫瘤 |

#### MRI 強化標準（信號強度相對增加 %）

| 強化程度 | 信號增加 | 判讀 |
|---|---|---|
| **無強化** | <15% | 囊性病變 |
| **強化不確定** | 15–19% | 需進一步檢查 |
| **明確強化** | **≥20%** | 考慮實性腫瘤 |

> ⚠️ **小病變限制：** 病變直徑小於掃描層厚的兩倍時，視為「太小無法特徵分析」。例如：使用 3 mm 層厚，<6 mm 的病變無法準確判斷。

---

### 腎臟腫塊活檢適應症 / Indications for Renal Mass Biopsy

| 適應症 | 說明 |
|---|---|
| 已知原發腫瘤 | 區分腎細胞癌與轉移瘤 |
| 感染與囊性腫瘤 | 區分腎感染與囊性腫瘤 |
| 高密度均質強化腫塊 | 確診可能是小病灶 AML（脂肪少）還是 RCC |
| 多發合併症患者 | 腎切除術高風險時確診 |
| 消融治療前 | 確保正確組織學診斷 |

---

### 臨床要點 / Clinical Key Points
- **三時相 CT 方案：** 非增強 → 腎實質期（100秒）→ 腎盂期（15分鐘）
- **強化是區分良惡性的最重要特徵：**
  - <10 HU（CT）= 無強化
  - 10-19 HU = 不確定
  - **≥20 HU = 明確強化**
- **腎盂期可鑑別腎積水（顯影）與腎竇囊腫（不顯影）**
- 小於 6 mm 的病變（3 mm 層厚時）無法準確特徵分析

## 實性腎臟腫塊 / Solid Renal Masses

### 腎細胞癌 / Renal Cell Carcinoma (RCC)

#### 疾病名稱 / Disease Name
**腎細胞癌（Renal Cell Carcinoma, RCC）**

#### 臨床特點 / Clinical Features
- 腎細胞癌是較少見的腫瘤，起源於腎小管細胞，佔所有癌症的 **2–3%**
- **危險因子：** 吸煙、後天囊性腎病、**馮·希佩爾-林道（VHL）**、結節性硬化症

#### RCC 亞型 / RCC Subtypes

| 亞型 | 發生率 | 5 年存活率 | 特點 |
|---|---|---|---|
| **透明細胞型（Clear cell）** | ~75% | ~55% | 最常見；富血供，增強明顯；可為散發性或與 VHL 相關 |
| **乳頭狀（Papillary）** | — | 80–90% | 乏血供，增強輕度；「腺瘤」≤5 mm 為乳頭狀癌的一種 |
| **嫌色細胞型（Chromophobe）** | — | 90% | 預後最好 |
| **收集管癌（Collecting duct carcinoma）** | 罕見 | 差 | 罕見 |
| **髓質癌（Medullary carcinoma）** | 罕見 | 平均存活 15 個月 | 好發於有鐮狀細胞特質的年輕男性；極具侵襲性，化療無效 |

#### Robson 分期系統 / Robson Staging System

| 分期 | 描述 |
|---|---|
| **Stage I** | 腫瘤限於腎包膜內 |
| **Stage II** | 腫瘤超出腎包膜但仍在 Gerota's fascia 內 |
| **Stage III** | 血管和/或淋巴結侵犯 |
| &nbsp;&nbsp;&nbsp;&nbsp;IIIA | 腎靜脈或下腔靜脈侵犯 |
| &nbsp;&nbsp;&nbsp;&nbsp;IIIB | 淋巴結侵犯 |
| &nbsp;&nbsp;&nbsp;&nbsp;IIIC | 靜脈和淋巴結同時侵犯 |
| **Stage IVA** | 腫瘤穿過 Gerota's fascia 生長 |
| **Stage IVB** | 遠處轉移 |

#### 影像學要點 / Imaging Key Points
- CT/MRI 表現：腎靜脈或下腔靜脈內的**腫瘤血栓（Tumor thrombus）**
- 乳頭狀 RCC 因乏血供，增強較輕微
- 透明細胞型 RCC 增強最明顯

#### 鑑別診斷 / Differential Diagnosis
- 腎血管平滑肌脂肪瘤（AML）
- 嗜酸細胞瘤（Oncocytoma）
- 腎臟淋巴瘤
- 轉移瘤

#### 治療 / Treatment
- I–III 期通常可切除；靜脈侵犯（IIIA、IIIC）可能需改變手術入路
- 晚期：標靶治療（酪氨酸激酶抑制劑）、免疫治療

---

### 臨床要點 / Clinical Key Points
- **腎細胞癌：** 佔所有癌症 2-3%；透明細胞型最常見（75%）
- ** Robson 分期：** I 期（包膜內）→ II 期（筋膜內）→ III 期（血管/淋巴結）→ IV 期（筋膜外/遠處轉移）
- **乳頭狀 RCC：** 乏血供，預後較好（80-90% 存活率）
- **髓質癌：** 極具侵襲性，與鐮狀細胞特質相關，平均存活僅 15 個月
- **VHL 綜合徵患者：** 需定期篩查 RCC

## 血管平滑肌脂肪瘤 / Angiomyolipoma (AML)

### 疾病名稱 / Disease Name
**血管平滑肌脂肪瘤（Angiomyolipoma, AML）**

### 臨床特點 / Clinical Features
- **最常見的良性腎臟腫瘤**，由脂肪、平滑肌和紊亂的血管組成
- **60%** 為散發性；**40%** 與**結節性硬化症（Tuberous sclerosis）**相關（通常為雙側、多發性腎囊腫）

### 出血風險 / Risk of Hemorrhage
- 當腫瘤較大（**≥4 cm**）時有出血風險，可能與血管成分的动脉瘤性改變有關
- 小而無症狀的 AML 通常不需要隨訪或切除

### 診斷要點 / Diagnostic Key Points

**CT 表現：**
- 非鈣化性腎臟病變中出現**巨觀脂肪**是 AML 的特異性影像學表現
- 非脂肪部分增強明顯且均勻
- **幾乎不出現鈣化**

**MRI 表現：**
- 脂肪成分在所有序列上與腹膜後脂肪信號一致
- 脂肪抑制序列上脂肪信號消失
- **細胞內脂肪不是 AML 的特徵**，因此雙相位 MRI 上不應有明顯信號丟失

**超聲波表現：**
- 呈現高回聲
- 需注意：多達 1/3 的腎細胞癌也呈高回聲，超聲波無法可靠區分 AML 與 RCC

#### 乏脂肪型 AML（Fat-Poor AMLs）
- 約 **4%** 的 AML 不含可見巨觀脂肪，呈現為高密度強化腫塊
- MRI 是下一步檢查，**T2 加權圖像**對區分 AML 與 RCC 最有用

| T2 信號 | 提示 |
|---|---|
| **T2 高信號** | 提示腎細胞癌（透明細胞型）→ 可直接手術 |
| **T2 低信號** | 非特異性，可能為乳頭狀 RCC 或乏脂肪 AML → 需活檢 |

### 鑑別診斷 / Differential Diagnosis
- 腎細胞癌（RCC）
- 腎上腺髓脂肪瘤（Myelolipoma）
- 後腹腔脂肪肉瘤

---

### 臨床要點 / Clinical Key Points
- **巨觀脂肪** = AML 的特異性診斷標準（非鈣化性腎臟病變中）
- **≥4 cm** AML 出血風險增加
- **結節性硬化症患者**：40% 伴有 AML，需定期監測
- **乏脂肪 AML（4%）**：需 MRI 進一步評估；T2 高信號提示透明細胞型 RCC
- 超聲波高回聲不可靠（1/3 RCC 也可呈高回聲）

---

## 嗜酸細胞瘤與腎臟淋巴瘤 / Oncocytoma and Renal Lymphoma

### 嗜酸細胞瘤 / Oncocytoma

#### 疾病名稱 / Disease Name
**嗜酸細胞瘤（Oncocytoma）**

#### 臨床特點 / Clinical Features
- 最常見的手術切除的**良性腎臟腫塊**
- 影像學表現與**腎細胞癌（RCC）**有重疊，無法可靠區分

#### 診斷要點 / Diagnostic Key Points
| 特點 | 說明 |
|---|---|
| 非增強 CT | 等衰減腫塊 |
| 中央 | 可能有中央疤痕（呈現為中央低密度區域） |
| 強化模式 | 均勻強化 |
| 鑑別診斷 | 影像學無法可靠區分 RCC；需病理確診 |

#### 鑑別診斷 / Differential Diagnosis
- 腎細胞癌
- 嫌色細胞型 RCC（嗜酸細胞可在嫌色細胞型 RCC 中出現）

---

### 腎臟淋巴瘤 / Renal Lymphoma

#### 臨床特點 / Clinical Features
- **原發性腎臟淋巴瘤罕見**（腎臟不含原生淋巴組織）
- 可由血行播散或後腹腔直接侵犯

#### 腎臟淋巴瘤的病變模式 / Patterns of Disease

| 模式 | 發生率 |
|---|---|
| **多發性淋巴瘤結節（Multiple lymphomatous masses）** | 最常見（50%） |
| 單發性腎臟腫塊（Solitary renal mass） | - |
| 瀰漫性淋巴瘤浸潤，導致腎臟增大（Nephromegaly） | - |
| 後腹腔病變直接延伸（Direct extension） | - |

---

### 非腫瘤性實性腎臟腫塊 / Non-neoplastic Solid Renal Masses

| 病變 | 特點 |
|---|---|
| **局灶性腎盂腎炎（Focal pyelonephritis）** | 可類似實性腎臟腫塊；腎膿腫與囊性 RCC 難以區分 |
| **腎動靜脈畸形（AVM）** | 增強明顯，可模擬富血供腎臟腫塊；線索：患側腎靜脈不對稱強化（早期短路） |

---

### 臨床要點 / Clinical Key Points
- **嗜酸細胞瘤：** 最常切除的良性腎臟腫塊；均勻強化 + 中央疤痕提示但不能確診；影像學無法與 RCC 可靠區分
- **腎臟淋巴瘤：** 原發性罕見；多發結節為最常見模式（50%）；需與 RCC 鑑別
- **局灶性腎盂腎炎：** 可模擬實性腎臟腫塊
- **腎 AVM：** 增強明顯，注意不對稱腎靜脈強化（早期短路表現）

## 腎臟假性腫塊與綜合徵相關腎臟腫塊 / Renal Pseudotumors and Syndromic Renal Masses

### 腎臟假性腫塊 / Renal Pseudotumors

| 病變 | 說明 |
|---|---|
| **貝爾坦柱肥大（Hypertrophied column of Bertin）** | 貝爾坦柱是將腎皮質錨定至腎門的正常結構，連接各腎錐體；肥大時可類似腎臟腫塊 |
| **持續性胎兒分葉（Persistent fetal lobation）** | 胎兒腎臟分為離散的葉，有時這種分葉在成年後持續存在，導致皮質凹陷類似腎臟腫塊；兩側均有貝爾坦柱可與真正腫塊區分 |

---

### 與腎臟腫塊相關的綜合徵 / Syndromes with Renal Masses（均增加 RCC 風險）

#### 馮·希佩爾-林道綜合徵（von Hippel–Lindau, VHL）

| 項目 | 內容 |
|---|---|
| **遺傳方式** | 體染色體顯性，3 號染色體 VHL 抑癌基因突變 |
| **泌尿系統主要表現** | 雙側或多灶性腎細胞癌（通常為透明細胞型） |
| **其他泌尿系統表現** | 多灶性嗜鉻細胞瘤、腎囊腫 |
| **中樞神經系統表現** | 腦幹、小腦或脊髓的血管母細胞瘤 |
| **胰臟/肝臟表現** | 惡性神經內分泌胰臟腫瘤、胰臟漿液性囊腺瘤（良性）、胰/肝囊腫 |

#### 伯特-霍格-杜伯綜合徵（Birt–Hogg–Dube）

| 項目 | 內容 |
|---|---|
| **遺傳方式** | 體染色體顯性 |
| **腎臟表現** | 多發性腎嗜酸細胞瘤和腎細胞癌 |
| **其他表現** | 皮膚病變、肺囊性疾病 |

#### 結節性硬化症（Tuberous Sclerosis, TS）

| 項目 | 內容 |
|---|---|
| **遺傳方式** | 體染色體顯性，腫瘤抑制基因突變 |
| **腎臟主要表現** | 多發性雙側腎血管平滑肌脂肪瘤（AML）；約 50% 的 TS 患者至少有 1 個 AML |
| **腎囊腫** | 可見於約 25% 的患者 |
| **RCC 風險** | 增加，約 2–3% 的患者發生；診斷複雜性在於異常腎臟可能含有多發囊腫和/或 AML |
| **心臟表現** | 最常見的腫瘤為橫紋肌肌瘤；可在胎兒期通過超聲波檢測 |
| **肺部表現** | 平滑肌增殖導致囊性肺組織取代（與淋巴管肌瘤病相同）|

---

### 臨床要點 / Clinical Key Points
- **貝爾坦柱肥大**和**胎兒分葉持續存在**是常見的腎臟假性腫塊，避免不必要的活檢
- **VHL：** 3 號染色體突變；雙側/多灶性透明細胞型 RCC + 嗜鉻細胞瘤；CNS 血管母細胞瘤
- **Birt-Hogg-Dube：** 多發性腎嗜酸細胞瘤 + 皮膚病變 + 肺囊性疾病
- **結節性硬化症：** 多發性雙側 AML（50%）；心臟橫紋肌肌瘤；肺部淋巴管肌瘤病
- 所有三種綜合徵均增加 **RCC 風險**，需定期監測

## 囊性腎臟腫塊的鑑別診斷 / Approach to a Cystic Renal Mass

### 囊性腎臟腫塊的病因 / Etiology of Cystic Renal Masses
- 囊性腎臟腫塊可能是腫瘤性或感染性
- 引起囊性腎臟腫塊的兩個最常見病因：**腎細胞癌**和**腎膿腫**

---

### 腫瘤性囊性腎臟腫塊 / Neoplastic Differential

| 病變 | 特點 |
|---|---|
| **囊性腎細胞癌（Cystic RCC）** | RCC 最常見為實性，但也可表現為囊性 |
| **多房囊性腎瘤（Multilocular cystic nephroma）** | 良性囊性腫瘤，有強化隔；呈雙峰年齡分布（嬰兒男孩和中老年女性）；特徵為突入腎盂導致積水；成人與囊性 RCC 難以區分；兒童與囊性威爾姆氏瘤難以區分 |
| **混合上皮和間質瘤（MEST）** | 良性腫瘤，由上皮和間質成分組成；常見於中老年女性；可呈實性或囊性 |

---

### 非腫瘤性囊性腎臟腫塊 / Non-neoplastic Differential

| 病變 | 特點 |
|---|---|
| **腎膿腫（Renal abscess）** | 腎臟內的膿性積液 |
| **出血性腎囊腫（Hemorrhagic renal cyst）** | 無強化成分 |

---

### MRI 在複雜囊性腎臟腫塊評估中的作用 / Role of MRI

- MRI 的關鍵優勢：**更準確的強化特徵分析**（不受 CT 假強化現象影響）
- 對區分 **Bosniak IIF** 和 **Bosniak III** 病變最有用
- **MRI 對隔膜的檢測比 CT 更敏感**
- 缺點：鈣化難以檢測

---

## 腎囊腫與囊性腎臟腫塊 / Renal Cysts and Cystic Renal Masses

### 單純性腎囊腫 / Simple Renal Cyst

| 項目 | 說明 |
|---|---|
| 發生率 | 約 **50%** 的 50 歲以上患者可見 |
| 臨床意義 | 偶然發現，無需隨訪，即使很大也不需處理 |

**CT 診斷標準：**
- 衰減值接近 **0 HU**
- 無強化成分
- 薄壁不可見

**MRI 診斷標準：**
- T1 加權圖像：低信號
- T2 加權圖像：高信號
- 無強化成分

---

### 腎竇囊腫 / Renal Sinus Cyst

| 類型 | 特點 |
|---|---|
| **腎盂旁囊腫（Parapelvic cyst）** | 腎皮質囊腫突入腎竇；通常大但單發 |
| **腎竇周囊腫（Peripelvic cyst）** | 淋巴管來源；通常小而多發 |

---

### 高密度囊腫 / Hyperdense Cyst

| 項目 | 說明 |
|---|---|
| 非增強 CT | 衰減值 **>70 HU** 的均質囊腫 = 良性高密度囊腫（可能為先前出血） |
| 限制 | 若只有增強後圖像，無法確診（無法與強化腎臟腫塊區分） |

---

### 臨床要點 / Clinical Key Points
- 囊性腎臟腫塊常見病因：**RCC** 和**腎膿腫**
- **單純性腎囊腫**：50 歲以上患者 50% 可見；無需隨訪
- **高密度囊腫**：>70 HU（CT 非增強）= 良性；無非增強圖像時無法確診
- MRI 對 **Bosniak IIF vs III** 的區分比 CT 更準確
- **腎盂旁囊腫**（大、單發）vs **腎竇周囊腫**（小、多發）的鑑別

## 囊性腎臟腫塊的 Bosniak 分類 / Bosniak Classification of Cystic Renal Masses

### 分類概述 / Overview
- Bosniak 分類將囊性腎臟腫塊根據**惡性風險分層**
- 分期基於**形態學**，非大小（高密度囊腫除外）

### 處理原則 / Management Principles

| 類別 | 惡性風險 | 管理 |
|---|---|---|
| **I 和 II** | 無惡性風險 | 不需要隨訪 |
| **IIF** | 輕度惡性風險 | 需要影像隨訪 |
| **III 和 IV** | 懷疑/明顯惡性 | 手術病變 |

---

### Bosniak I 類 / Category I

| 項目 | 內容 |
|---|---|
| **描述** | 水衰減囊腫，薄壁，無強化區域 |
| **預後** | 始終良性，無需隨訪 |
| **影像特點** | 簡單囊腫 |

---

### Bosniak II 類 / Category II

| 項目 | 內容 |
|---|---|
| **描述** | 水衰減囊腫，含少量（≤3 條）毛髮樣隔膜；可有細微隔膜鈣化；無強化 |
| **附加** | 小（<3 cm）高衰減囊腫，無強化 |
| **預後** | 幾乎始終良性，無需隨訪 |

---

### Bosniak IIF 類 / Category IIF

| 項目 | 內容 |
|---|---|
| **描述** | 多發隔膜，最小平滑增厚（≤3 mm）；可有厚實和結節性鈣化；牆壁可能輕度強化 |
| **附加** | 大（>3 cm）高衰減囊腫，無強化 |
| **預後** | 通常良性，建議影像隨訪；形態改變或新發強化為惡性疑點 |
| **處理** | 隨訪 CT/MRI |

---

### Bosniak III 類 / Category III

| 項目 | 內容 |
|---|---|
| **描述** | 增厚、不規則的牆壁或隔膜，伴有可測量的強化 |
| **預後** | 懷疑惡性，但也可能為良性（如感染、多房囊性腎瘤） |
| **處理** | 若無合併症，手術切除 |

---

### Bosniak IV 類 / Category IV

| 項目 | 內容 |
|---|---|
| **描述** | 特點為與牆壁或隔膜分開的強化結節成分 |
| **預後** | 明顯惡性 |
| **處理** | 手術病變（除非有明顯合併症） |

---

### 總結表 / Summary Table

| 類別 | 描述 | 惡性風險 | 管理 |
|---|---|---|---|
| **I** | 簡單囊腫，薄壁，無強化 | 無（始終良性） | 無需隨訪 |
| **II** | 少數毛髮樣隔膜，無強化；小（<3 cm）高密度囊腫 | 幾乎無 | 無需隨訪 |
| **IIF** | 多發隔膜（≤3 mm），可有結節性鈣化；大（>3 cm）高密度囊腫 | 輕度 | 影像隨訪 |
| **III** | 增厚不規則壁/隔膜，可測量強化 | 懷疑（但可為良性） | 手術病變 |
| **IV** | 與壁/隔膜分开的强化结节 | 明顯惡性 | 手術病變 |

---

### 臨床要點 / Clinical Key Points
- **Bosniak I 和 II**：良性，無需隨訪
- **Bosniak IIF**：需影像隨訪；區別於 III 類的關鍵是無「可測量強化」
- **Bosniak III**：牆壁/隔膜增厚且有「可測量強化」；但仍可能為良性（感染、多房囊性腎瘤）
- **Bosniak IV**：與壁/隔膜分開的「強化結節」= 明顯惡性
- 分類基於形態學，非大小

---

## 多囊性腎臟疾病與腎細胞癌風險 / Multicystic Renal Disease and Risk for Renal Neoplasm

### 體染色體顯性多囊性腎臟病 / Autosomal Dominant Polycystic Kidney Disease (ADPKD)

#### 疾病名稱 / Disease Name
**體染色體顯性多囊性腎臟病（ADPKD）**

#### 臨床特點 / Clinical Features
- 佔長期透析患者的 **10%**
- 通常在**三四十歲**發病，初始表現為上腹痛，進行性腎功能衰竭
- 腎臟可增大至可觸及
- 常見高血壓和血尿（可能由於腎結石或囊腫破裂入集合系統）
- 約**一半患者**有威利斯環（Willis circle）囊狀動脈瘤

#### 影像學特點 / Imaging Features
- 腎臟顯著增大，含多發囊腫，由於出血而有不同的衰減值或信號強度

#### 惡性腫瘤風險 / Neoplasm Risk
| 觀點 | 內容 |
|---|---|
| 傳統觀點 | ADPKD 不增加腎細胞癌風險 |
| 較新觀點 | 一些作者認為風險輕度增加 |
| ADPKD 相關 RCC 特點 | 發病年齡較年輕；常為雙側性、多灶性、梭形細胞型 |

|---|---|
| 病因 | 終末期腎病透析相關囊性腎病 |

## 腎臟感染與發炎 / Renal Infection and Inflammation

### 腎盂腎炎 / Pyelonephritis

#### 疾病名稱 / Disease Name
**腎盂腎炎（Pyelonephritis）**

#### 臨床特點 / Clinical Features
- 腎實質感染，是腎臟最常見的細菌感染
- 細菌通常從膀胱**上行**感染

#### 診斷要點 / Diagnostic Key Points
- 影像學表現**非特異性**，多達 75% 的影像可能正常
- 表現形式：單側腎臟增大、楔形或條紋狀增強降低區、腎周條紋影
- 尿路上皮可增厚並高強化
- **條紋狀腎造影（Striated nephrogram）**：對比增強圖像上從皮質延伸至髓質的線狀低密度

| 條紋狀腎造影的鑑別診斷 | 說明 |
|---|---|
| 腎盂腎炎 | - |
| 急性尿路阻塞 | - |
| 腎梗塞 | - |
| 腎腫瘤（尤其淋巴瘤浸潤型） | - |
| 腎靜脈血栓或血管炎 | - |
| 放射性腎炎 | - |

#### 局灶性腎盂腎炎 / Focal Pyelonephritis
- 可類似腎臟腫塊
- 輕度積水可見（細菌內毒素減少蠕動所致），不應與阻塞性尿路病混淆

---

### 臨床要點 / Clinical Key Points
- **ADPKD：** 長期透析患者 10% 的病因；三四十歲發病；一半患者有顱內囊狀動脈瘤
- **後天囊性腎病：** 透析患者 RCC 風險增加（2-3%）
- **腎盂腎炎：** 最常見腎臟細菌感染；影像學 75% 可能正常；單側腎臟增大需考慮
- **條紋狀腎造影：** 非特異性，需結合臨床鑑別腎盂腎炎、腎梗塞、腫瘤等

### 黃色肉芽腫性腎盂腎炎 / Xanthogranulomatous Pyelonephritis (XGP)

#### 疾病名稱 / Disease Name
**黃色肉芽腫性腎盂腎炎（Xanthogranulomatous Pyelonephritis, XGP）**

#### 臨床特點 / Clinical Features
- 慢性腎臟感染，由**阻塞性結石**引起，導致腎實質被纖維脂肪發炎組織取代
- 最常見病原菌：**奇異變形桿菌（Proteus mirabilis）**和大腸桿菌（*E. coli*）
- 臨床表現：腰痛、發燒、體重減輕等非特異性全身症狀；常見貧血和血尿

#### 診斷要點 / Diagnostic Key Points
- **CT 是首選檢查**，表現包括：
  - 腎實質脂肪替代
  - 顯著腎周發炎條紋影
  - **鹿角結石（Staghorn calculi）**
  - 腎臟增大、強化降低
- **「熊爪徵（bear paw sign）」**：低衰減纖維脂肪團塊呈放射狀排列，類似熊爪

| XGP 形態 | 說明 |
|---|---|
| 瀰漫型（85%） | - |
| 局灶型 | 又稱「腫塊型 XGP」，可類似腎臟腫瘤 |

#### 鑑別診斷 / Differential Diagnosis
- 急性阻塞性結石伴腎積膿
- 腎/泌尿道上皮腫瘤伴鈣化

#### 治療 / Treatment
- **腎切除術**

---

### 腎結核 / Renal Tuberculosis

#### 疾病名稱 / Disease Name
**腎結核（Renal Tuberculosis）**

#### 臨床特點 / Clinical Features
- 由**血行播散**引起的腎實質結核分枝桿菌感染
- 約 10% 伴有活動性肺結核
- 初始感染通常累及雙側腎臟，慢性改變常為單側性

#### 診斷要點 / Diagnostic Key Points
- 影像學表現：實質鈣化、疤痕、乳頭壞死、漏斗部狹窄
- **末期腎結核** → **自體腎切除（Autonephrectomy）**和特徵性的「**膏狀腎（Putty kidney）**」外觀（萎縮、鈣化的腎臟）

---

### 臨床要點 / Clinical Key Points
- **腎積膿：** 感染的阻塞集合系統；緊急經皮腎造口引流
- **腎膿腫：** <3 cm 保守治療；≥3 cm 穿刺引流
- **氣腫性腎盂腎炎：** 糖尿病患者；氣體取代腎實質；外科急症
- **黃色肉芽腫性腎盂腎炎：** 鹿角結石 + 腎實質脂肪替代 + 熊爪徵；腎切除術
- **腎結核：** 乳頭壞死、漏斗部狹窄、膏狀腎

## 乳頭壞死 / Papillary Necrosis

### 疾病名稱 / Disease Name
**乳頭壞死（Papillary Necrosis）**

### 臨床特點 / Clinical Features
- 腎乳頭組織的壞死和脫落
- 可引起**肉眼血尿**，並可導致慢性腎功能不全

### 病因 / POSTCARD 記憶法

| 字母 | 病因 |
|---|---|
| **P** | 腎盂腎炎（Pyelonephritis） |
| **O** | 阻塞（Obstruction） |
| **S** | 鐮狀細胞病（Sickle cell disease） |
| **T** | 結核（Tuberculosis） |
| **C** | 肝硬化（Cirrhosis） |
| **A** | 鎮痛劑/NSAIDs（Analgesics） |
| **R** | 腎靜脈血栓（Renal vein thrombosis） |
| **D** | 糖尿病（Diabetes mellitus） |

### 診斷要點 / Diagnostic Key Points

**CT 尿路造影延遲期表現：**
- 多個小的腎盞外造影劑池（鄰近腎盞）

**三個經典泌尿放射學徵象：**

| 徵象 | 描述 |
|---|---|
| **Ball on tee sign（球在球座上徵）** | 造影劑填充中央乳頭 |
| **Lobster claw sign（龍蝦爪徵）** | 造影劑僅填充乳頭周邊（勿與 XGP 的熊爪徵混淆） |
| **Signet ring sign（印章環徵）** | 造影劑圍繞脫落的乳頭 |

### 臨床要點 / Clinical Key Points
- **含鈣結石**佔所有泌尿系統結石的 73%
- **軟組織邊緣徵**有助於區分靜脈石與輸尿管結石
- **POSTCARD 記憶法**：腎盂腎炎、阻塞、鐮狀細胞病、結核、肝硬化、鎮痛劑、腎靜脈血栓、糖尿病
- **乳頭壞死三徵**：球在球座上徵、龍蝦爪徵、印章環徵
- 印章環徵：脫落乳頭被造影劑環繞

## 皮質腎鈣化與皮質壞死 / Cortical Nephrocalcinosis and Cortical Necrosis

### 皮質腎鈣化 / Cortical Nephrocalcinosis

#### 定義 / Definition
- 腎皮質的**營養不良性外周鈣化**，髓質錐體不受累

#### 病因 / Etiology

| 病因 |
|---|
| 急性皮質壞死（Acute cortical necrosis） |
| 慢性腎小球腎炎（Chronic glomerulonephritis） |
| 慢性移植排斥（Chronic transplant rejection） |
| 高草酸尿症（Hyperoxaluria） |
| 阿爾波特綜合徵（Alport syndrome，遺傳性腎病伴聽力障礙） |

#### 影像學特點 / Imaging Features
- X 線片：腎皮質緻密鈣化
- 超聲：皮質緻密鈣化伴聲影，遮擋腎實質

---

### 皮質壞死 / Cortical Necrosis

#### 定義 / Definition
- 急性缺血性腎皮質壞死的罕見形式

#### 臨床特點 / Clinical Features
- 可導致皮質腎鈕化
- 高達 **50%** 的患者发展为慢性腎功能衰竭
- 缺血可由小血管痙攣或全身性低血壓引起
- 誘發因素：溶血-尿毒症綜合徵、血栓性微血管病

#### 診斷要點 / Diagnostic Key Points
- CT 表現：雙側皮質不強化
- 病因：小血管痙攣或低血壓

---

### 臨床要點 / Clinical Key Points
- **皮質腎鈕化：** 皮質外周鈣化，髓質不受累；常見於慢性腎小球腎炎、急性皮質壞死
- **皮質壞死：** 急性缺血性皮質損傷；高達 50% 進展為慢性腎衰竭
- 兩者關係：皮質壞死可導致皮質腎鈕化

## 腎創傷 / Renal Trauma

### AAST（美國創傷外科協會）腎創傷分級 / OIS/AAST Grading of Renal Trauma

| 等級 | 描述 | 治療 |
|---|---|---|
| **Grade I** | 腎挫傷或包膜下血腫（最常見，佔 95%） | 保守治療 |
| **Grade II** | 淺層裂傷（<1 cm）或局限性包膜下血腫，無尿液外滲 | 保守治療 |
| **Grade III** | 深層裂傷（>1 cm），無尿液外滲 | 通常保守治療 |
| **Grade IV** | 深層裂傷延伸至集合系統（引起尿液外滲）或腎动脉/靜脈損傷伴局限性出血 | 尿液外滲通常需手術修復；血管性 IV 損傷可血管內治療 |
| **Grade V** | 腎臟碎裂或腎門撕脫 | 通常手術治療 |

### CT 描述要點 / CT Description
- OIS 分級對創傷性腎动脉血栓形成、腎动脉假性動脈瘤、輸尿管撕脫（常見於腎盂輸尿管連接處）等重要損傷有所限制

| 特殊損傷 | 說明 |
|---|---|
| **創傷性腎动脉血栓（Traumatic renal artery thrombosis）** | 內膜撕裂啟動血栓形成；缺血約 2 小時後腎功能永久喪失 |
| **假性動脈瘤（Pseudoaneurysm）** | 动脉損傷，有高度致命性破裂風險；與主動脈密度相似；治療：血管內栓塞 |
| **Page kidney** | 因 prior trauma 導致的續發性高血壓；包膜下血腫壓迫腎實質降低血流；數月後發生高血壓；治療：穿刺引流血腫 |

---

### 臨床要點 / Clinical Key Points
- **Grade I 最常見（95%）**，多為腎挫傷
- **Grade III 陷阱：** 集合系統的血塊初期可能阻止尿液外滲，但血塊被尿激酶溶解後可能延遲發生尿液外滲
- **創傷性腎动脉血栓：** 缺血 2 小時後腎功能永久喪失
- **Page kidney：** 數月後發生高血血壓；包膜下血腫壓迫；穿刺引流可能有效

## 惡性輸尿管疾病 / Malignant Ureteral Disease

### 泌尿道上皮癌 / Transitional Cell Carcinoma (TCC)

#### 疾病名稱 / Disease Name
**泌尿道上皮癌（Transitional Cell Carcinoma, TCC）**

#### 臨床特點 / Clinical Features
- 上尿路惡性腫瘤雖然少見，但**泌尿道上皮癌是最常見的輸尿管腫瘤**
- 可表現為**多灶性（40%）**

#### 診斷要點 / Diagnostic Key Points
- **CT 尿路造影表現：**
  - 單個充盈缺損（典型表現）
  - 多發充盈缺損（40%）
  - 輸尿管壁局灶性增厚（較少見）
- 由於泌尿道上皮癌有多灶性特徵，**需評估膀胱是否有同時發生的腫瘤**

#### 鑑別診斷 / Differential Diagnosis
| 疾病 | 說明 |
|---|---|
| 泌尿道上皮癌（TCC） | 最常見的輸尿管惡性腫瘤 |
| 輸尿管結石 | 非造影劑圖像上幾乎總是可見 |
| 血塊 | - |
| 乳頭脫落 | - |
| 良性輸尿管腫塊 | 如纖維上皮息肉 |

---

### 臨床要點 / Clinical Key Points
- **CTU 為評估血尿的首選檢查**
- **泌尿道上皮癌（TCC）** 是最常見的輸尿管惡性腫瘤，可多灶性發生
- 膀胱同步評估至關重要
- 成人（≥40 歲）三時相 CTU；年輕患者可採用 split-bolus 方案降低輻射

## 良性輸尿管腫塊與發炎性疾病 / Benign Ureteral Masses and Inflammatory/Infectious Ureteral Disease

### 良性輸尿管腫塊 / Benign Ureteral Masses

| 病變 | 特點 |
|---|---|
| **纖維上皮息肉（Fibroepithelial polyp）** | 最常見的良性輸尿管腫瘤；好發於近端輸尿管；有長柄；呈現為細長平滑的管狀病變 |
| **泌尿道上皮乳頭瘤（Urothelial papilloma）** | 罕見良性腫瘤，可長得很大類似惡性腫瘤 |
| **內翻性乳頭瘤（Inverted papilloma）** | 良性腫塊，中心為泌尿道上皮 |

---

### 發炎性與感染性輸尿管疾病 / Inflammatory and Infectious Ureteral Disease

#### 囊性輸尿管炎 / Ureteritis Cystica

| 項目 | 內容 |
|---|---|
| **性質** | 對慢性泌尿系統發炎（如慢性感染或結石）的良性反應 |
| **部位** | 單側，輸尿管近端 1/3 和腎盂 |
| **惡性風險** | **無惡性潛能** |
| **影像學特點** | 腎盂或輸尿管內多個微小充盈缺損 |

- 膀胱對應病變稱為**囊性膀胱炎（Cystitis cystica）**，表現為膀胱底部多個圓形輪廓缺損

#### 白斑病（鱗狀化生）/ Leukoplakia (Squamous Metaplasia)

| 項目 | 內容 |
|---|---|
| **性質** | 罕見的泌尿道上皮發炎症性疾病，因特徵性白斑而得名 |
| **惡性風險** | 腎集合系統受累時**無明顯惡性風險**；但膀胱白斑病與鱗狀細胞癌有相關性 |
| **影像學特點** | 扁平原發性腫塊或局灶性壁增厚；可呈「燈芯絨」外觀 |

#### 軟化斑 / Malacoplakia

| 項目 | 內容 |
|---|---|
| **性質** | 與慢性泌尿系統感染（通常為大腸桿菌）相關的發炎性疾病 |
| **好發人群** | 中年女性 |
| **惡性風險** | **無惡性潛能** |
| **影像學特點** | 多個扁平充盈缺損，好發於**遠端輸尿管** |

#### 輸尿管結核 / Ureteral Tuberculosis

| 項目 | 內容 |
|---|---|
| **特點** | 多灶性輸尿管狹窄提示輸尿管結核 |
| **佐證** | 腎結核（實質鈣化和疤痕）和/或膀胱結核（膀胱容量小、壁增厚）證據 |

---

### 輸尿管充盈缺損的鑑別診斷 / Differential Diagnosis of Ureteral Filling Defect

| 疾病 | 說明 |
|---|---|
| **泌尿道上皮癌（TCC）** | 最常見的輸尿管惡性腫瘤 |
| 輸尿管結石 | 非增強圖像上幾乎總是可見 |
| 血塊 | - |
| 白斑病 | 可呈「燈芯絨」外觀 |
| 感染性碎屑（如黴菌球） | - |
| 軟化斑 | 多個扁平缺損，遠端輸尿管 |
| 脫落的乳頭 | - |
| 良性輸尿管腫塊 | 如纖維上皮息肉 |

---

### 臨床要點 / Clinical Key Points
- **纖維上皮息肉：** 最常見的良性輸尿管腫瘤；有長柄，近端輸尿管好發
- **囊性輸尿管炎：** 無惡性潛能；多個微小充盈缺損
- **軟化斑：** 中年女性；遠端輸尿管多個扁平缺損
- **輸尿管結核：** 多灶性狹窄為特徵
- **泌尿道上皮癌是輸尿管充盈缺損的首要擔憂**

## 結構性輸尿管病變 / Structural Ureteral Lesions

### 腎盂輸尿管連接處阻塞 / Ureteropelvic Junction Obstruction (UPJ Obstruction)

#### 臨床特點 / Clinical Features
- 可為原發性或繼發性（感染、結石或既往手術）
- **原發性 UPJ 阻塞**可能原因：
  - 先天性無蠕動段輸尿管
  - 輸尿管在腎盂的高位插入
  - 橫越血管造成外源性壓迫

#### 診斷要點 / Diagnostic Key Points
- **關鍵影像學發現：** 腎盂擴張而輸尿管口徑正常

---

### 輸尿管囊腫 / Ureterocele

#### 疾病名稱 / Disease Name
**輸尿管囊腫（Ureterocele）**

#### 定義 / Definition
- 輸尿管最遠端部分的局灶性擴張，突出至膀胱內

#### 分型 / Classification

| 類型 | 特點 |
|---|---|
| **原位性（Orthotopic）** | 輸尿管正常插入；常見於成人；又稱「簡單型、成人型、膀胱內」；通常無症狀 |
| **異位性（Ectopic）** | 發生於重複集合系統，上極輸尿管異位插入膀胱；通常在兒童確診 |
| **假性輸尿管囊腫（Pseudoureterocele）** | 遠端輸尿管套疊入膀胱，可由腫瘤、放射性膀胱炎或輸尿管膀胱連接處結石引起 |

#### 影像學特點 / Imaging Features
- CT 表現取決於類型
- 重複輸尿管可見雙套輸尿管
- 上極輸尿管囊腫可見積水和上極輸尿管擴張

#### 診斷要點 / Diagnostic Key Points
| 類型 | 影像學特點 |
|---|---|
| 原位性 | 正常插入，膀胱內囊腫；成人 |
| 異位性 | 重複系統，上極輸尿管囊腫；兒童 |
| 假性 | 遠端輸尿管套疊；繼發於腫瘤/放射性膀胱炎/UVJ 結石 |

---

### 臨床要點 / Clinical Key Points
- **UPJ 阻塞：** 腎盂擴張 + 正常口徑輸尿管；先天性或後天性
- **輸尿管囊腫：** 膀胱內輸尿管末端囊性擴張
- **原位性：** 成人，無症狀，通常不需要治療
- **異位性：** 兒童，與重複集合系統相關
- **假性輸尿管囊腫：** 輸尿管套疊入膀胱，需找出根本原因（腫瘤、結石、放射性）

## 腹膜內膀胱破裂 / Intraperitoneal Bladder Rupture

### 定義 / Definition
- 膀胱頂部和腹膜破裂，尿液外滲至腹腔

### 機制 / Mechanism
- 機制為膀胱充盈時受到壓力，導致膀胱頂部在腹膜內爆裂

### 診斷要點 / Diagnostic Key Points
- **CT 膀胱造影特異性表現：**
  - 對比劑在**腸曲之間交錯（interdigitating）**
  - 腸曲之間可見遊離液體
  - 膀胱本身在破裂層面完整

| 類型 | 特異性影像學表現 |
|---|---|
| **腹膜內膀胱破裂** | 對比劑在腸曲之間交錯（腸曲間對比劑） |
| **腹膜外膀胱破裂** | 磨牙徵（Retzius 間隙外對比劑） |

### 相關發現 / Associated Findings
- **休克腸（Shock bowel）：** 創傷休克時急性低血容量引起的腸道黏膜強化和腸壁增厚

### 治療 / Treatment
- **手術治療**

---

### 腹膜內 vs. 腹膜外膀胱破裂的鑑別 / Differentiation

| 特點 | 腹膜內 | 腹膜外 |
|---|---|---|
| 破裂部位 | 膀胱頂部 | 膀胱前外側壁（通常與骨盆骨折相關） |
| 對比劑分布 | 腸曲之間 | Retzius 間隙（磨牙徵） |
| 相關因素 | 膀胱充盈時受壓 | 骨盆骨折、骨片撕裂 |
| 治療 | 手術 | 保守（導尿管） |
| 發生率 | 較少 | **更常見（至少 2 倍）** |

---

### 臨床要點 / Clinical Key Points
- **腹膜內膀胱破裂：** 膀胱頂部破裂；對比劑在腸曲之間交錯；**手術治療**
- **腹膜外膀胱破裂：** 對比劑在 Retzius 間隙（磨牙徵）；**保守治療**
- 創傷時對比劑外滲至腸曲之間 = 腹膜內破裂的診斷標準
- 創傷患者出現休克腸（腸道黏膜高強化和增厚）提示急性低血容量

## 尿道 / Urethra

### 男性尿道解剖學 / Male Urethral Anatomy

#### 尿道分段 / Classification of Urethral Segments

| 分段 | 部位 |
|---|---|
| **後尿道（Posterior urethra）** |  |
| — 前列腺部（Prostatic） | - |
| — 膜部（Membranous） | - |
| **前尿道（Anterior urethra）** |  |
| — 球部（Bulbous） | - |
| — 陰莖部（Penile） | - |

#### 各段特點 / Key Points by Segment

| 尿道段 | 特點 |
|---|---|
| **前列腺部（Posterior）** | 穿行於前列腺內；被覆移行上皮；精阜是前列腺部後壁的顯著平滑肌嵴，為成對射精管口的位置；也是兒童後尿道瓣膜阻塞的部位；前列腺囊是午非管的殘餘，相當於女性，子宮和陰道的盲端同源結構 |
| **膜部（Posterior）** | 最短、最不活動的尿道段；被尿生殖膈（含外尿道括約肌和成對的 Cowper 腺）包繞 |
| **球部（Anterior）** | Cowper 腺排泄口的位置 |
| **陰莖部（Anterior）** | 最長的尿道段；被覆鱗狀上皮；陰莖部在龜頭處擴張，稱為**舟狀窩（Fossa navicularis）**；Littre 腺是陰莖部的小黏液腺 |

#### 臨床相關部位 / Clinical Correlation

| 疾病/操作 | 部位 |
|---|---|
| 經尿道前列腺切除術（TURP） | 前列腺部 |
| 淋病性狹窄 | 球部 |
| 導尿後狹窄 | 陰莖部（陰莖-陰囊交界處） |
| 後尿道瓣膜 | 精阜（兒童） |
| 尿道炎時 Littré 腺 | 陰莖部（炎症時造影更明顯） |

---

### 臨床要點 / Clinical Key Points
- **後尿道：** 前列腺部（移行上皮）和膜部（含外括約肌）
- **前尿道：** 球部（淋病性狹窄好發）和陰莖部（導尿後狹窄好發）
- **精阜：** 射精管口位置，也是後尿道瓣膜的阻塞部位
- **導尿後狹窄**常見於陰莖-陰囊交界處

## 男性尿道的影像學 / Imaging of the Male Urethra

### 逆行性尿道造影 / Retrograde Urethrogram (RUG)

| 項目 | 內容 |
|---|---|
| **目的** | 評估前尿道；懷疑尿道損傷、狹窄或瘻管時進行 |
| **技術** | 經舟狀窩插入帶球囊的無菌導管，充盈 1-2 mL 生理鹽水；在透視下手工注射約 10 mL 對比劑 |

---

### 排尿性膀胱尿道造影 / Voiding Cystourethrogram (VCUG)

| 項目 | 內容 |
|---|---|
| **目的** | 最佳評估後尿道；通常用於評估膀胱和排尿功能 |
| **技術** | 經無菌技術放置 Foley 導管入膀胱；向膀胱內灌注對比劑；患者在透視下排尿時進行顯影 |

---

### 尿道狹窄 / Urethral Stricture

| 病因 | 好發部位 |
|---|---|
| 性傳播疾病（最常見為淋病性慢性尿道炎） | **球部** |
| 創傷性騎跨傷 | **球部** |
| 醫源性導尿術後 | 陰莖-陰囊交界處（**陰莖部**） |

#### 併發症 / Complications
- 慢性尿道感染的併發症：**尿道周圍膿腫**，可導致**尿道會陰瘻**

---

### 尿道創傷 / Urethral Trauma

#### 損傷分類與機制

| 分型 | 特點 |
|---|---|
| **Type I–V** | 共五型；Type III 最常見 |
| **Type III（最常見）** | 尿生殖膈破裂；球膜部尿道破裂；對比劑外滲至骨盆和會陰 |

#### 臨床處理原則 / Clinical Management
- 創傷時若有尿道口出血、排尿疼痛或無法排尿，應緊急行 **RUG**
- RUG 顯示尿道損傷時，通常放置**恥骨上導管**

#### 影像學要點 / Diagnostic Key Points
| 分型 | RUG 表現 |
|---|---|
| **Type III** | 對比劑自由外滲至球膜部；外滲至骨盆和會陰 |

---

### 臨床要點 / Clinical Key Points
- **RUG** 最佳評估前尿道；**VCUG** 最佳評估後尿道
- **淋病性狹窄**和**騎跨傷狹窄**好發於**球部**；**導尿後狹窄**好發於**陰莖-陰囊交界處**
- **Type III 尿道損傷**最常見，球膜部破裂，對比劑外滲至骨盆和會陰
- 創傷時懷疑尿道損傷：先 RUG，確診後放置恥骨上導管

## 女性尿道 / Female Urethra

### 女性尿道解剖學 / Anatomy of the Female Urethra

| 特點 | 內容 |
|---|---|
| 長度 | 比男性尿道短得多 |
| 分段 | 不分為離散的段 |
| 上皮 | 近端 1/3 為移行上皮；遠端為複層鱗狀上皮 |
| 腺體 | Skene 腺（尿道旁腺），與男性前列腺同源，分泌黏液 |

---

### 尿道憩室 / Urethral Diverticulum

#### 臨床特點 / Clinical Features
| 項目 | 內容 |
|---|---|
| **臨床表現** | 排尿後滴瀝、尿道疼痛、性交疼痛；有時症狀模糊非特異性 |
| **發病機制** | 認為由 Skene 腺的發炎和慢性感染引起的腺體擴張所致 |
| **併發症** | 因尿瀦留易形成結石 |
| **惡性風險** | 極罕見情況下可發生腺癌 |

#### 影像學特點 / Imaging Features

| 序列 | 表現 |
|---|---|
| **T2 加權** | 尿道區域圓形高信號結構；冠狀位可見分葉狀 T2 高信號 |
| **T1 加權增強** | 憩室內和周圍無強化 |

| 形態 | 說明 |
|---|---|
| 橫斷面 | U 形，環繞正常減壓的尿道 |
| 矢狀面 | 圓形高信號結構，鄰近尿道 |

#### 鑑別診斷 / Differential Diagnosis
- 尿道囊腫
- 尿道腫瘤
- 膀胱陰道瘻

#### 治療 / Treatment
- 手術切除
- 結石需一併取出

---

### 臨床要點 / Clinical Key Points
- **女性尿道**不分段；Skene 腺與男性前列腺同源
- **尿道憩室：** 排尿後滴瀝 + 尿道疼痛；Skene 腺感染後腺體擴張；可並發結石和腺癌
- MRI 矢狀位和冠狀位可清晰顯示憩室與尿道的關係

## 前列腺 MRI / MRI of the Prostate

### 前列腺解剖學 / Prostate Anatomy

####  MRI 上可見的兩個組成部分

| 組成 | 說明 |
|---|---|
| **周邊區（Peripheral zone）** | T2 高信號；70% 的腺癌發生於此 |
| **中央腺（Central gland）** | 包括過渡區和中央區；MRI 上無法區分 |

#### 區域解剖學 / Zonal Anatomy

| 區域 | 位置/特點 |
|---|---|
| **前部纖維肌肉基質（Anterior fibromuscular stroma）** | - |
| **過渡區（Transition zone）** | 良性前列腺增生（BPH）發生部位 |
| **中央區（Central zone）** | 圍繞射精管 |
| **周邊區（Peripheral zone）** | 佔腺癌的 70% |

#### 年齡相關變化
| 年齡 | 變化 |
|---|---|
| 年輕男性 | 中央腺主要由中央區組成 |
| 老年人 | 過渡區增大（因 BPH）；中央腺主要由過渡區組成 |

---

### 前列腺癌 / Prostate Cancer

#### 典型 MRI 表現
| 特點 | 說明 |
|---|---|
| T2 加權 | 周邊區 T2 高信號內的**T2 低信號區域** |
| T1 加權 | 通常不能清楚顯示腫瘤 |

#### MRI 的局限性

| 侷限 | 說明 |
|---|---|
| 篩查不適用 | 成本高，敏感性和特異性低 |
| 並非所有腫瘤都可檢測 | 某些腫瘤在 T2 上不呈低信號；中央區腫瘤難以檢測 |
| 非特異性 | 周邊區 T2 低信號的鑑別診斷包括：前列腺炎、出血、雄激素剝奪治療後的退化性改變 |

#### 進階 MRI 技術

| 技術 | 表現 |
|---|---|
| **MRI 光譜分析** | 膽鹼峰升高、枸櫞酸峰降低（相較於正常前列腺） |
| **動態對比增強（DCE）** | 前列腺癌相對於周邊區早期強化 |
| **擴散成像（DWI）** | 前列腺癌呈**受限擴散**（ADC 圖上呈低信號） |

---

### 臨床要點 / Clinical Key Points
- **周邊區：** 70% 腺癌的發生部位；T2 高信號
- **過渡區：** BPH 發生部位
- **前列腺癌典型表現：** T2 低信號位於周邊區（周邊區正常為 T2 高信號）
- **MRI 光譜分析：** 膽鹼↑、枸櫞酸↓ = 前列腺癌
- **DCE：** 前列腺癌早期強化
- **DWI：** 前列腺癌受限擴散（ADC 低信號）

## 前列腺癌分期 / Prostate Cancer Staging

### 分期的主要目標 / Primary Goal
- **區分手術性疾病和非手術性疾病**
  - 腫瘤限於腺體內（T2）：通常適合根除性前列腺切除術
  - 腫瘤扩散至腺體外（T3 及以上）：通常非手術治療（如抗雄激素和放射治療）

---

### T 分期 / T-Staging

| 分期 | 描述 |
|---|---|
| **T1** | 僅由活檢發現的腫瘤 |
| **T2** | 腫瘤限於前列腺內 |
| &nbsp;&nbsp;&nbsp;&nbsp;T2a | 單側葉的 <50% |
| &nbsp;&nbsp;&nbsp;&nbsp;T2b | 單側葉的 >50% |
| &nbsp;&nbsp;&nbsp;&nbsp;T2c | 腫瘤累及雙側葉 |
| **T3** | 腫瘤穿透前列腺包膜；可累及精囊 |
| **T4** | 腫瘤侵犯精囊以外的鄰近結構 |

---

### N 分期 / N-Staging

| 分期 | 描述 |
|---|---|
| **N1** | 區域淋巴結轉移 |
| **M1a** | 非區域（盆腔外）淋巴結 |

---

### M 分期 / M-Staging

| 分期 | 描述 |
|---|---|
| **M0** | 無遠處轉移 |
| **M1a** | 非區域淋巴結 |
| **M1b** | 骨轉移 |
| **M1c** | 其他轉移 |

---

### 分期示例：T2a 前列腺癌 / Staging Example: T2a Prostate Cancer

| 影像學發現 | 說明 |
|---|---|
| T2 軸位（直腸線圈） | 左側後周邊區低信號灶；侷限於腺體內 |
| ADC 圖 | 腫瘤呈受限擴散（ADC 圖上呈低信號） |
| 動態對比增強 | 腫瘤相對高強化 |

- 腫瘤完全限於腺體內，小於單側葉的 50% → **T2a**
- 因腫瘤很小，擴散成像和動態對比增強有助於提高特異性

---

### 臨床要點 / Clinical Key Points
- **T2a vs T2b：** 以單側葉 50% 為界
- **T2c：** 雙側葉受累
- **T3a：** 僅包膜外侵犯；精囊未受累
- **T3b：** 腫瘤侵犯精囊
- **N1：** 區域淋巴結轉移
- **M 分期：** M1a（非區域淋巴結）、M1b（骨轉移）、M1c（其他）

## 前列腺癌分期示例：T3b N1 / Staging Example: T3b N1 Prostate Cancer

### 影像學發現 / Imaging Findings

| 序列 | 發現 |
|---|---|
| T2 軸位（直腸線圈） | 幾乎整個雙葉的周邊區被 T2 低信號腫塊替代；右側有殘留正常周邊區 |
| T2（稍低位置） | 左側腺體外扩散，左側精囊被包圍（engulfment） |
| T2（膀胱底部上方） | 雙側精囊內側異常 T2 低信號 |
| 最上層 T2 | 多個區域淋巴結 |

### 分期判讀 / Staging Interpretation

| 分期 | 判讀 |
|---|---|
| **T 分期** | 腫瘤累及雙葉大部分周邊區，明確顯示腺體外扩散 → **T3** |
| **T3b** | 腫瘤侵犯精囊（若僅包膜外扩散但精囊未受累，則為 **T3a**） |
| **N 分期** | 存在區域淋巴結 → **N1** |
| **最終分期** | **T3b N1** |

### 臨床處理 / Clinical Management
- **T3b N1 前列腺癌**通常**非手術治療**
- 治療選項：抗雄激素治療、放射治療、化學治療
- 進階 MRI 技術在此案例中附加價值有限，因為解剖成像已清楚顯示惡性行為

---

### 前列腺癌 T 分期總結 / Prostate Cancer T-Staging Summary

| 分期 | 描述 |
|---|---|
| T2 | 限於前列腺內 |
| T2a | <50% 單側葉 |
| T2b | >50% 單側葉 |
| T2c | 雙側葉 |
| T3a | 包膜外扩散（精囊未受累） |
| T3b | 精囊侵犯 |
| T4 | 侵犯鄰近結構（精囊除外） |

---

### 臨床要點 / Clinical Key Points
- **T3b = 精囊侵犯**（與 T3a 的區別點）
- **T3b N1** = 通常非手術治療
- 精囊被包圍（engulfment）是 T3b 的特徵性表現
- 區域淋巴結 = **N1**
- 前列腺癌的 MRI 分期需結合 T2、DWI、DCE 等多種序列綜合判讀
