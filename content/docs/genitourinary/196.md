# Genitourinary Imaging - Page 196

![Page 196](/core_radiology/images/genitourinary/page-196.png)

## Text Content

### 前列腺 MRI / MRI of the Prostate

#### 前列腺解剖 / Prostate Anatomy

| 結構 | 說明 |
|------|------|
| **週邊區（Peripheral zone）** | 70% 的攝護腺癌發生於此區 |
| **中央腺體（Central gland）** | 包括中央區（central zone）和過渡區（transition zone）；MRI 上無法區分 |
| 過渡區 | 為攝護腺增生（BPH）的發生部位；年輕人中央腺體以中央區為主，隨年齡增長，過渡區增大 |

#### 攝護腺癌的 MRI 表現

| 項目 | 說明 |
|------|------|
| 典型表現 | T2 強調像上呈**T2 低訊號**區域，位於 T2 高訊號的週邊區 |
| 侷限性 | MRI 可能無法檢出所有攝護腺癌；中央區癌症在 T2 圖像上難以檢測 |
| 鑑別診斷 | 除了攝護腺癌，T2 低訊號的鑑別還包括：**前列腺炎、出血、雄激素剝奪治療後的退化性改變** |

#### 高級 MRI 技術

| 技術 | 表現 |
|------|------|
| **MRI 光譜分析** | 膽鹼峰值升高、枸櫞酸鹽峰值降低（相對於正常攝護腺） |
| **動態對比增強（DCE-MRI）** | 攝護腺癌相對於週邊區早期強化 |
| **擴散加權成像（DWI）** | 攝護腺癌通常表現為**受限擴散（restricted diffusion）**（ADC 低訊號） |

---

### 臨床要點 / Clinical Key Points
> - **週邊區（70%）**：攝護腺癌最常見部位；MRI T2 高訊號
> - **中央腺體**：中央區＋過渡區（因 BPH 增大）；MRI 上無法區分這兩區
> - **典型 MRI 表現**：T2 低訊號位於週邊區（T2 高訊號）中
> - **DWI**：受限擴散（ADC 低訊號）提示惡性
> - **DCE-MRI**：癌腫相對於週邊區早期強化
> - MRI 不建議用於篩檢（成本高、敏感度和特異度低）
