## Text Content

### 實質性腎臟腫塊 / Solid Renal Masses

#### 腎細胞癌 / Renal Cell Carcinoma (RCC)

**腎細胞癌**起源於腎小管細胞，佔所有癌症的 **2-3%**。

| 危險因子 | 說明 |
|---------|------|
| 吸菸 | |
| 獲得性囊性腎病（ACKD） | 透析患者常見 |
| **Von Hippel-Lindau（VHL）** | 與透明細胞型 RCC 相關 |
| 結節性硬化症（Tuberous sclerosis） | |

#### RCC 組織亞型

| 亞型 | 比例 | 5 年生存率 | 特徵 |
|------|------|-----------|------|
| **透明細胞型（Clear cell）** | ~75% | ~55% | 最常見；強化明顯；可散發或與 VHL 相關 |
| **乳頭狀（Papillary）** | | 80-90% | 低血管性；輕度強化；腎「腺瘤」实为 ≤5 mm 乳頭狀癌 |
| **嫌色細胞型（Chromophobe）** | | **90%** | 預後最好 |
| **集合管癌（Collecting duct）** | 罕見 | 差 | |
| **髓質癌（Medullary）** | 罕見 | **平均存活 15 個月** | 主要影響鐮刀形紅血球特質年輕男性；化療無效 |

#### Robson's Staging System

| 分期 | 標準 |
|------|------|
| **Stage I** | 腫瘤局限於腎包膜內 |
| **Stage II** | 腫瘤超出腎包膜但仍在 Gerota's fascia 內 |
| **Stage III** | 血管和/或淋巴結侵犯 |
| → IIIA | 腎靜脈或 IVC 受侵 |
| → IIIB | 淋巴結侵犯 |
| → IIIC | 靜脈＋淋巴結同時侵犯 |
| **Stage IVA** | 腫瘤穿透 Gerota's fascia |
| **Stage IVB** | 遠處轉移 |

> Stage I-III 通常可切除，但靜脈侵犯（IIIA、IIIC）需改變手術策略

---

### 臨床要點 / Clinical Key Points
> - **RCC 佔所有癌症 2-3%**；危險因子：吸菸、ACKD、VHL、結節性硬化症
> - **透明細胞型（75%）**：最常見，強化最明顯，與 VHL 相關；5 年生存率 55%
> - **乳頭狀型**：低血管性，輕度強化，預後較好（80-90%）
> - **嫌色細胞型**：預後最好（90% 5 年生存率）
> - **髓質癌**：侵襲性極強（平均存活 15 個月），與鐮刀形紅血球特質相關
> - **Robson 分期**：I-II（包膜內/外）；III（血管/淋巴結）；IVA（穿透筋膜）；IVB（遠處轉移）
