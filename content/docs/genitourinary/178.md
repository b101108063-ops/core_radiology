# Genitourinary Imaging - Page 178

![Page 178](/core_radiology/images/genitourinary/page-178.png)

## 嗜酸細胞瘤與腎臟淋巴瘤 / Oncocytoma and Renal Lymphoma

### 嗜酸細胞瘤 / Oncocytoma

#### 疾病名稱 / Disease Name
**嗜酸細胞瘤（Oncocytoma）**

#### 臨床特點 / Clinical Features
- 最常見的手術切除的**良性腎臟腫塊**
- 影像學表現與**腎細胞癌（RCC）**有重疊，無法可靠區分

#### 診斷要點 / Diagnostic Key Points
| 特點 | 說明 |
|---|---|
| 非增強 CT | 等衰減腫塊 |
| 中央 | 可能有中央疤痕（呈現為中央低密度區域） |
| 強化模式 | 均勻強化 |
| 鑑別診斷 | 影像學無法可靠區分 RCC；需病理確診 |

#### 鑑別診斷 / Differential Diagnosis
- 腎細胞癌
- 嫌色細胞型 RCC（嗜酸細胞可在嫌色細胞型 RCC 中出現）

---

### 腎臟淋巴瘤 / Renal Lymphoma

#### 臨床特點 / Clinical Features
- **原發性腎臟淋巴瘤罕見**（腎臟不含原生淋巴組織）
- 可由血行播散或後腹腔直接侵犯

#### 腎臟淋巴瘤的病變模式 / Patterns of Disease

| 模式 | 發生率 |
|---|---|
| **多發性淋巴瘤結節（Multiple lymphomatous masses）** | 最常見（50%） |
| 單發性腎臟腫塊（Solitary renal mass） | - |
| 瀰漫性淋巴瘤浸潤，導致腎臟增大（Nephromegaly） | - |
| 後腹腔病變直接延伸（Direct extension） | - |

---

### 非腫瘤性實性腎臟腫塊 / Non-neoplastic Solid Renal Masses

| 病變 | 特點 |
|---|---|
| **局灶性腎盂腎炎（Focal pyelonephritis）** | 可類似實性腎臟腫塊；腎膿腫與囊性 RCC 難以區分 |
| **腎動靜脈畸形（AVM）** | 增強明顯，可模擬富血供腎臟腫塊；線索：患側腎靜脈不對稱強化（早期短路） |

---

### 臨床要點 / Clinical Key Points
- **嗜酸細胞瘤：** 最常切除的良性腎臟腫塊；均勻強化 + 中央疤痕提示但不能確診；影像學無法與 RCC 可靠區分
- **腎臟淋巴瘤：** 原發性罕見；多發結節為最常見模式（50%）；需與 RCC 鑑別
- **局灶性腎盂腎炎：** 可模擬實性腎臟腫塊
- **腎 AVM：** 增強明顯，注意不對稱腎靜脈強化（早期短路表現）
