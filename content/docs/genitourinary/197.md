## Text Content

### 攝護腺癌分期 / Staging of Prostate Cancer

#### 分期目標

**MRI 最重要的目標：區分可手術和不可手術的疾病**
- 腫瘤局限於腺體內（T2 期）→ 通常可接受根除性攝護腺切除術
- 腫瘤已擴散至腺體外（T3 及以上）→ 通常接受非手術治療（如抗雄激素和放射治療）

#### T 分期

| 分期 | 標準 |
|------|------|
| **T1** | 僅在活檢時發現 |
| **T2** | 腫瘤局限於攝護腺內 |
| → T2a | 單側葉的 <50% |
| → T2b | 單側葉的 >50% |
| → T2c | 腫瘤累及雙側葉 |
| **T3** | 腫瘤穿透攝護腺包膜；可侵犯精囊 |
| → T3a | 腫瘤延伸出包膜，但未侵犯精囊 |
| → T3b | 腫瘤侵犯精囊 |
| **T4** | 腫瘤侵犯包膜外的鄰近結構（非精囊） |

#### N 分期

- 任何區域淋巴結轉移 = **N1**
- 盆腔外淋巴結 = **M1a**

#### M 分期

| 分期 | 標準 |
|------|------|
| **M0** | 無遠處轉移 |
| **M1a** | 非區域淋巴結 |
| **M1b** | 骨轉移 |
| **M1c** | 其他轉移 |

---

### 臨床要點 / Clinical Key Points
> - **T2a**（<50% 單側葉）：可根除性切除；**T3a**（包膜外延伸）：需輔助治療；**T3b**（精囊侵犯）：需非手術治療
> - **N1**：區域淋巴結侵犯；**M1a/b/c**：遠處轉移
> - **MRI 關鍵任務**：區分 T2（可手術）與 T3+（不可手術）
> - **DWI 和 DCE-MRI** 可提高檢測和特異度，但對已明確顯示腺外侵犯的晚期腫瘤價值有限
