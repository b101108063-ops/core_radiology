## 惡性腎上腺腫塊（續）/ Malignant Adrenal Masses (continued)

### 嗜鉻細胞瘤（續）/ Pheochromocytoma (continued)
- 經典型 **MRI 表現：** T2  加權圖像呈高信號
- 大型嗜鉻細胞瘤在 MRI 和 CT 上均可呈現**異質性**

---

### 腎上腺皮質癌 / Adrenal Cortical Carcinoma

#### 疾病名稱 / Disease Name
**腎上腺皮質癌（Adrenal Cortical Carcinoma）**

#### 臨床特點 / Clinical Features
- 極罕見惡性腫瘤，發病率約 **1/1,000,000**
- 約 **66%** 為功能性，產生皮質激素紊亂
- 可表現為**庫欣綜合徵（Cushing syndrome）**、**高醛固酮血症**或**男性化**

#### 診斷要點 / Diagnostic Key Points
- **CT/MRI 表現：**
  - 大型異質性腫塊
  - 中央壞死和出血為典型表現
  - 可有鈣化

| 特點 | 說明 |
|---|---|
| 大小 | 通常較大（確診時） |
| 強化模式 | 異質性不均勻強化 |
| 壞死/出血 | 常見 |
| 功能狀態 | 66% 功能性 |

#### 預後 / Prognosis
- 預後差，發現時通常已為晚期

---

### 轉移瘤 / Metastasis

#### 臨床特點 / Clinical Features
- 屍檢研究顯示：已知原發腫瘤患者中 **>25%** 有腎上腺轉移
- 最常見的原發腫瘤：**肺癌**和**黑色素瘤**

#### 診斷要點 / Diagnostic Key Points
- 雙側腎上腺腫塊伴不均勻強化
- 需與腺瘤鑑別（ washout CT 或化學位移 MRI）

## 瀰漫性腎上腺疾病 / Diffuse Adrenal Disorders

### 腎上腺增生 / Adrenal Hyperplasia

#### 臨床特點 / Clinical Features
- 由長期應激反應或異位 ACTH 分泌引起
- 通常為雙側性

#### 診斷要點 / Diagnostic Key Points
- 雙側腎上腺均勻增大
- 腎上腺分支變得更飽滿

---

### 腎上腺出血 / Adrenal Hemorrhage

#### 臨床特點 / Clinical Features
- 可為自發性或由**抗凝治療**引起
- 抗凝治療相關出血：通常在開始抗凝治療後**前幾週**內發生
- **右側**腎上腺比左側更常受累

#### 診斷要點 / Diagnostic Key Points
- CT 表現可能類似腫塊，呈異質性衰減
- 最重要線索：有近期腎上腺 imaging 前後對比，新出現腎上腺腫塊
- **不出現強化**；隨訪時**大小減小**
- 典型非增強衰減值：**~46 HU**

| 時期 | CT 表現 |
|---|---|
| 急性期 | 高衰減（出血） |
| 亞急性/慢性 | 逐漸縮小，不強化 |

#### 鑑別診斷 / Differential Diagnosis
- 腎上腺轉移瘤
- 腎上腺皮質癌
- 嗜鉻細胞瘤

---

### 腎上腺鈣化 / Adrenal Calcification

#### 病因 / Etiology
| 病因 | 說明 |
|---|---|
| 韋格納肉芽腫（Wegener granulomatosis） | ANCA 相關血管炎 |
| 結核（Tuberculosis） | 歷史上的常見原因 |
| 組織胞漿菌病（Histoplasmosis） | 真菌感染 |
| 陳舊性出血 | 出血後遺 |

- 腎上腺鈣化**很少**引起腎上腺功能減退

---

### 臨床要點 / Clinical Key Points
- **腎上腺皮質癌：** 極罕見（1/1,000,000）；66% 功能性；大型異質性腫塊伴壞死/出血
- **轉移瘤：** >25% 癌症患者屍檢有腎上腺轉移；肺癌和黑色素瘤最常見
- **腎上腺出血：** 右側多見；抗凝治療後前幾週；無強化、隨訪縮小；需與新發腫瘤鑑別
- **腎上腺增生：** 雙側增大，由應激或異位 ACTH 引起
- **腎上腺鈣化：** 很少引起功能減退；常見於肉芽腫性疾病、結核、組織胞漿菌病
