# Genitourinary Imaging - Page 181

![Page 181](/core_radiology/images/genitourinary/page-181.png)

## 囊性腎臟腫塊的 Bosniak 分類 / Bosniak Classification of Cystic Renal Masses

### 分類概述 / Overview
- Bosniak 分類將囊性腎臟腫塊根據**惡性風險分層**
- 分期基於**形態學**，非大小（高密度囊腫除外）

### 處理原則 / Management Principles

| 類別 | 惡性風險 | 管理 |
|---|---|---|
| **I 和 II** | 無惡性風險 | 不需要隨訪 |
| **IIF** | 輕度惡性風險 | 需要影像隨訪 |
| **III 和 IV** | 懷疑/明顯惡性 | 手術病變 |

---

### Bosniak I 類 / Category I

| 項目 | 內容 |
|---|---|
| **描述** | 水衰減囊腫，薄壁，無強化區域 |
| **預後** | 始終良性，無需隨訪 |
| **影像特點** | 簡單囊腫 |

---

### Bosniak II 類 / Category II

| 項目 | 內容 |
|---|---|
| **描述** | 水衰減囊腫，含少量（≤3 條）毛髮樣隔膜；可有細微隔膜鈣化；無強化 |
| **附加** | 小（<3 cm）高衰減囊腫，無強化 |
| **預後** | 幾乎始終良性，無需隨訪 |

---

### Bosniak IIF 類 / Category IIF

| 項目 | 內容 |
|---|---|
| **描述** | 多發隔膜，最小平滑增厚（≤3 mm）；可有厚實和結節性鈣化；牆壁可能輕度強化 |
| **附加** | 大（>3 cm）高衰減囊腫，無強化 |
| **預後** | 通常良性，建議影像隨訪；形態改變或新發強化為惡性疑點 |
| **處理** | 隨訪 CT/MRI |

---

### Bosniak III 類 / Category III

| 項目 | 內容 |
|---|---|
| **描述** | 增厚、不規則的牆壁或隔膜，伴有可測量的強化 |
| **預後** | 懷疑惡性，但也可能為良性（如感染、多房囊性腎瘤） |
| **處理** | 若無合併症，手術切除 |

---

### Bosniak IV 類 / Category IV

| 項目 | 內容 |
|---|---|
| **描述** | 特點為與牆壁或隔膜分開的強化結節成分 |
| **預後** | 明顯惡性 |
| **處理** | 手術病變（除非有明顯合併症） |

---

### 總結表 / Summary Table

| 類別 | 描述 | 惡性風險 | 管理 |
|---|---|---|---|
| **I** | 簡單囊腫，薄壁，無強化 | 無（始終良性） | 無需隨訪 |
| **II** | 少數毛髮樣隔膜，無強化；小（<3 cm）高密度囊腫 | 幾乎無 | 無需隨訪 |
| **IIF** | 多發隔膜（≤3 mm），可有結節性鈣化；大（>3 cm）高密度囊腫 | 輕度 | 影像隨訪 |
| **III** | 增厚不規則壁/隔膜，可測量強化 | 懷疑（但可為良性） | 手術病變 |
| **IV** | 與壁/隔膜分开的强化结节 | 明顯惡性 | 手術病變 |

---

### 臨床要點 / Clinical Key Points
- **Bosniak I 和 II**：良性，無需隨訪
- **Bosniak IIF**：需影像隨訪；區別於 III 類的關鍵是無「可測量強化」
- **Bosniak III**：牆壁/隔膜增厚且有「可測量強化」；但仍可能為良性（感染、多房囊性腎瘤）
- **Bosniak IV**：與壁/隔膜分開的「強化結節」= 明顯惡性
- 分類基於形態學，非大小
