## 後腹腔腫瘤 / Retroperitoneal Tumors

### 脂肪肉瘤 / Liposarcoma

#### 疾病名稱 / Disease Name
**脂肪肉瘤（Liposarcoma）**

#### 臨床特點 / Clinical Features
- 脂肪肉瘤是一組多樣化的腫瘤，是**最常見的原發性後腹腔腫瘤**
- 所有脂肪肉瘤中 **10–15%** 起源於後腹腔
- 最常見類型為**分化良好組**，由以下亞型組成：
  - 脂肪細胞型（Adipocytic）
  - 硬化型（Sclerosing）
  - 炎症型（Inflammatory）
- 脂肪細胞型脂肪肉瘤類似脂肪瘤，主要由脂肪組成，伴有代表膠原纖維的組織條紋

#### 惡性程度分級 / Malignancy Classification（由低到高）

| 惡性程度 | 亞型 |
|---|---|
| 最低 | 黏液型（Myxoid） |
| ↓ | 圓細胞型（Round-cell） |
| ↓ | 多形型（Pleomorphic） |
| 最高 | 去分化型（Dedifferentiated） |

- 侵襲性較強的亞型可能含有極少或無巨觀脂肪，與其他惡性軟組織腫塊難以區分

#### 鑑別診斷 / Differential Diagnosis
- 脂肪瘤（Lipoma）
- 畸胎瘤（Teratoma）
- 黏液樣脂肪肉瘤（Myxoid liposarcoma）
- 腎上腺髓脂瘤（Myelolipoma）

#### 診斷要點 / Diagnostic Key Points
- CT 表現主要取決於亞型
- 分化良好型：以脂肪衰減為主的腫塊，伴條紋狀軟組織
- 去分化型：軟組織密度為主，無明顯脂肪

### 後腹腔纖維化 / Retroperitoneal Fibrosis

#### 疾病名稱 / Disease Name
**後腹腔纖維化（Retroperitoneal Fibrosis）**

#### 臨床特點 / Clinical Features
- 罕見的發炎性疾病，導致後腹腔纖維組織增生，常引起**輸尿管阻塞**
- 可導致腎積水和腎功能受損
- 可能為特發性或與藥物、腫瘤、感染相關

#### 鑑別診斷：後腹腔纖維化 vs. 惡性淋巴結病

| 特點 | 後腹腔纖維化 | 惡性淋巴結病 |
|---|---|---|
| 主動脈位移 | **不**將主動脈抬高離開脊柱 | 將主動脈抬高離開脊柱 |
| 性質 | 發炎/纖維化 | 惡性 |
| 輸尿管侵犯 | 常見 | 變異 |
| 強化模式 | 均勻延遲強化 | 不均勻強化 |

#### 診斷要點 / Diagnostic Key Points
- CT 表現為軟組織腫塊環繞主動脈和/或下腔靜脈及輸尿管
- 纖維化組織趨向**不將主動脈抬高離開脊柱**（與惡性淋巴結病的關鍵鑑別點）
- 雙側腎積水和輸尿管擴張常見

#### 治療 / Treatment
- 皮質類固醇
- 輸尿管支架或腎造口引流
- 手術鬆解

---

### 臨床要點 / Clinical Key Points
- **脂肪肉瘤**：最常見原發性後腹腔腫瘤；分化良好型以脂肪衰減為主；侵襲性亞型可無明顯脂肪
- **後腹腔纖維化**：軟組織腫塊圍繞主/下肢血管；特徵為**不抬高主動脈**（區別於惡性淋巴結病）；常引起輸尿管阻塞
- **後腹腔三大常見腫瘤**：脂肪肉瘤（最常見）、平滑肌肉瘤、惡性纖維組織細胞瘤
