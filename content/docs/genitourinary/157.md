# Genitourinary Imaging - Page 157

![Page 157](/core_radiology/images/genitourinary/page-157.png)

## Text Content

### 憩室炎 / Diverticulitis

**憩室炎**是結腸憩室發生**微小穿孔（microperforation）和急性炎症**。CT 是首選診斷工具，並用於評估疾病嚴重程度及併發症。

- 左結腸比右結腸受累常見得多
- 急性憩室炎與**微小穿孔性結腸癌**往往難以區分；多數作者建議急性期緩解後進行結腸鏡隨訪

#### 單純性憩室炎 / Uncomplicated Diverticulitis

無影像學上的腸道穿孔證據（即使組織病理學上所有憩室炎都伴有細菌移位）。CT 表現：**腸壁增厚**及**結腸旁脂肪條索影（fat stranding）**，通常圍繞責任憩室（culprit diverticulum）。

#### 複雜性憩室炎 / Complicated Diverticulitis

| 併發症類型 | 說明 |
|------------|------|
| **膿腫（Abscess）** | 結腸旁或肝臟膿腫 |
| **腸外氣體（Extraluminal air）** | 穿孔表現 |
| **腸阻塞（Bowel obstruction）** | |
| **腸道瘺管（Bowel fistula）** | **膀胱結腸瘺（Colovesical fistula）**最常見；影像上表現為膀胱內氣體（排除導尿管因素） |
| **血栓形成（Thrombosis）** | 腸系膜靜脈血栓 |

**治療：**
- 單純性憩室炎 → **保守治療**
- 膿腫 → 通常可**經皮穿刺引流**
- 手術適應症：**瘺管**或**復發性憩室炎**（曾兩次保守治療失敗）

### 網膜附件炎 / Epiploic Appendagitis

**網膜附件炎**是憩室炎的**良性臨床模擬者**，由結腸上懸垂的正常脂肪標籤（附屬物）**扭轉**引起。

**特徵性影像表現：** 病灶呈**橢圓形脂肪密度**，附著於正常結腸壁，伴輕度脂肪條索影。橫斷面上，中央高密度點代表網膜附件的**血栓性中心靜脈**。

> **治療：** 使用**抗炎藥物**，不使用抗生素或手術。

---

### 臨床要點 / Clinical Key Points
> - **憩室炎**CT 首選；左結腸為主；需與結腸癌鑑別
> - **複雜性憩室炎**：腸外氣體、膿腫、瘺管（膀胱結腸瘺最常見）、腸阻塞
> - **網膜附件炎**： pathognomonic 橢圓形脂肪密度病灶附著結腸壁；治療為抗炎藥物
