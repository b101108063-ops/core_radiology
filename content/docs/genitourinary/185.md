### 腎臟影像模式 / Renal Imaging Patterns

#### 延遲（持續性）腎造影 / Delayed (Prolonged) Nephrogram

**延遲腎造影**描述腎實質對靜脈注射對比劑的攝取緩慢、強化持續時間長、排泄延遲。

| 類型 | 常見病因 |
|------|---------|
| **單側延遲腎造影** | 急性輸尿管阻塞、腎靜脈血栓、腎动脉狹窄 |
| **雙側延遲腎造影** | 雙側阻塞、對比劑腎病、全身性低血壓、骨髓瘤腎病 |

> 病例：心導管術後數小時進行的平掃 CT 顯示雙側持續腎強化，腎盂系統顯影，並可見因遠端阻塞導致的腎盞破裂和尿液外滲

#### 髓質腎鈣化 / Medullary Nephrocalcinosis

**髓質腎鈣化**是腎髓質錐體的鈣化，通常腎功能保留。

| 病因 | 說明 |
|------|------|
| **高血鈣狀態** | 甲狀旁腺功能亢進、結節病等 |
| **髓質海綿腎** | 遠端收集管囊性擴張；可為單側或節段性 |
| **遠端（1 型）腎小管酸中毒（RTA）** | |
| **小兒呋塞米治療** | |

#### 腎竇囊腫 vs 水腎（泌尿道期鑑別）

| 病變 | 泌尿道期表現 |
|------|------------|

### 臨床要點 / Clinical Key Points
> - **延遲腎造影**：單側（阻塞/靜脈血栓/腎动脉狹窄）；雙側（雙側阻塞/對比劑腎病/低血壓/骨髓瘤）
> - **髓質腎鈣化**：病因包括甲狀旁腺亢進、髓質海綿腎、遠端 RTA；腎功能通常保留
> - **皮質腎鈣化**：慢性腎小球腎炎、壞死恢復期、甲狀旁腺減退等
> - **泌尿道期**是區分**水腎（顯影）與腎竇囊腫（不顯影）**的關鍵
> - Bear paw sign = XGP（纖維脂肪團塊呈放射狀排列）；腎竇囊腫（parapelvic/peripelvic）在泌尿道期不顯影
